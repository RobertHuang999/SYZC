## ASCII线框绘制规则

> 本节规则适用于本文件所有 ASCII 线框，填写时必须遵守。核心原则：**优先呈现更多信息，在信息密度高、可阅读的前提下保持对齐美观**。

### 宽度

先判断页面复杂度，选择尽可能宽但不超过上限的宽度：

- 字段少、结构简单（如登录页、简单表单）：控制在 80 字符以内
- 字段较多、含表格多列（如列表页、单据详情页）：**优先放宽到 90~100 字符**，**最多不超过 120 字符**
- **优先把字段横向排布，一行放不下时才换行**，不要为了窄而刻意折行、降低信息密度
- 每行按内容实际所需宽度画，不刻意撑满到上限；字段之间用 1-3 个半角空格分隔，留出视觉间距

### 对齐

- 使用等宽字体查看时，**视觉上整体对齐即可**，不强制要求字符级/宽度单位级完全相等
- 线框左右边界（`+`、`|`、`+`）应大体对齐，允许中文与半角符号混排带来的轻微偏差；**允许行尾 `|` 与最长行存在 1-3 个字符的视觉偏差**
- 字段之间用 1-3 个半角空格分隔，中英文混排导致错位时，用少量半角空格微调；**禁止用大量半角空格或连字符把行尾硬拉到与最长行等宽**
- 表格列之间用单条竖线 `|` 分隔，列宽按表头文字最短宽度设定，不统一拉齐到最长列
  - 示例：`| 名称/规格 | 编号 | 数量 | 单价 | 金额 |`，而不是把每列都拉成 `名称/规格` 的宽度

### 符号约定

| 元素  | 符号            |
| --- | ------------- |
| 输入框 | `[ ]`         |
| 下拉框 | `[ v ]`       |
| 按钮  | `[按钮文字]`      |
| 勾选框 | `[ ]` / `[x]` |

### 多字段处理

- 表格列数超宽时，**优先扩宽线框到 100 字符上限**；仍放不下时，再横向截断
- 截断时只保留前面的 **4-6 个核心业务字段** + 省略号（`...`）+ 操作/合计列
- 其余字段用图外一行文字说明（如"隐藏字段：xxx、xxx、xxx，实际页面可横向滚动查看"）
- 表格空行保留 2-3 行示意即可，不画过多空行占用高度

### 复杂页面拆分

- 整页壳层线框画一次（含左侧导航、顶栏、主工作区粗分）
- 主工作区内部（查询区、表单、子表、账单/其他信息、底栏）在后续独立小节中展开
- 不重复在每个小线框里重画左侧导航和顶栏

### 输出格式

- 用 markdown 代码块包裹，语言标记用 `text`
