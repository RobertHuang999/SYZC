# 5-1（输入）交付检查与原型派生

## 何时使用

主 PRD、字段清单、业务规则规格已完成，需要验证一致性，或生成 Demo、ASCII 与原型输入时使用。

## 输入资料

- `{菜单名}主PRD.md`。
- `{菜单名}字段清单.md`及适用的操作字段清单。
- `{菜单名}业务规则规格.md`。

## 产出文档

| 顺序 | 产出 |
| :---: | :--- |
| 1 | `{菜单名}业务用例数据推演.md` |
| 2 | `{菜单名}PRD套件README.md` |
| 3 | 套件交叉走查结果 |
| 4 | `{菜单名}_Demo_{页面}.md`、`{菜单名}_ASCII_{页面}.md` 与原型输入 |

## 完成标准

- 用例覆盖高风险规则的正向路径与阻断路径。
- 三件套之间字段、规则、状态、权限、场景与验收可追溯，走查无阻断项。
- Demo、ASCII 和原型只派生三件套内容，不新增业务字段、规则或流程。
- 通过下方 **「三件套交付检查清单」**（含规则编号与易读性）；全局规范真源见仓库根目录 [`AGENTS.md`](../../AGENTS.md) **4.0.7 节**。

> 本步骤不单独创建“验收测试矩阵”；验收要求写在主 PRD 与用例推演中。

## 三件套交付检查清单（编号与易读性）

> 规则/字段/主 PRD 编写过程中亦可逐项自检；换编号或合并规则后 **必须** 重跑本清单。

### A. 规则编号（简略 ID · 单一口径）

| # | 检查项 | 通过标准 |
| :---: | :--- | :--- |
| A1 | 业务规则规格文头 | 「统一引用规范」等引用块列明本菜单 **R/P/S/C/F/M** 系列（或正文可见）；**无**独立 `## 规则编号约定` 表（对齐 IoT 标杆） |
| A2 | 三件套与原型引用 | 只使用约定表中的简略 ID（如 **R02**、**P08**、**F13**），与 IoT/预警标杆一致 |
| A3 | 禁止混用别名 | SSOT 中无 `CFG-R*`、`CFG-PAR*`、`PAR-R*`、`WH-F*`、`WH-P01` 等带模块前缀编号 |
| A4 | 禁止双轨对照 | 无「P 与 PAR-R 对照表」或两套并行编号；归档目录若有旧号，须 README **迁移表**，SSOT 仅一套 |
| A5 | 跨模块引用 | 下游只引用上游真源 ID（例：仓库 **F13** 只读透出，开关逻辑只在基础配置 **R02**），不在下游重定义 |
| A6 | 换编号顺序 | 已按 **业务规则规格 → 字段清单 → 主 PRD → 衍生/跨模块** 同步；主 PRD 规则索引锚点与规格标题一致 |
| A7 | 规则标题格式 | 正文采用 **【中文规则名】(编号)**，不单独裸露编号 |

### B. 文案与格式（禁止 LaTeX · 产品可读）

| # | 检查项 | 通过标准 |
| :---: | :--- | :--- |
| B1 | 无 LaTeX | 三件套、ASCII、Demo、里程碑中无 `$...$`、`\le`、`\ge`、`\text{}` 等 |
| B2 | 长度与大小 | 使用「最多 N 字」「不超过 NMB」「1~50 字符」「大于 0」等中文表述 |
| B3 | 符号 | 流程箭头用「→」或「至」；接口/SQL 代码块内可保留 `<=`、`>=` |
| B4 | 界面与规则语气 | 提示语、规则说明为大白话，避免论文化长句（对齐 6.2 预警 / 6.3 基础配置风格） |

### C. 三件套一致性（走查）

| # | 检查项 | 通过标准 |
| :---: | :--- | :--- |
| C1 | 字段 ↔ 规则 | 字段清单引用的规则 ID 均在业务规则规格中存在；无未定义 ID |
| C2 | 主 PRD ↔ 规格 | 主 PRD 规则摘要与索引链接到规格对应小节，不重复粘贴规则全文 |
| C3 | 衍生文档 | ASCII/Demo 文头含「衍生 · 非 SSOT」；无新增字段/规则 ID |
| C4 | 修订记录 | 三件套文末修订记录已更新版本与变更说明 |

### E. 可选自动化自检（本菜单目录 grep）

在 **SSOT 三件套所在目录** 执行（归档目录除外）：

- `PAR-R|CFG-PAR|CFG-R\d|WH-F\d` → 应为 **0 处**
- `\$|\\le|\\ge|\\text\{` → 应为 **0 处**

## 输出模板选择

- 需要用具体业务数据验证复杂计算、库存占用、状态联动或预警穿透时，使用 `5-2（输出）业务用例数据推演模板`。
- 需要派生页面级 Demo 或 ASCII 时，使用 `5-3（输出）DemoPRD模板`。
- 菜单 README 直接按“主 PRD、字段清单、规则规格、衍生物、交付状态”生成简短索引，不再使用独立模板。
