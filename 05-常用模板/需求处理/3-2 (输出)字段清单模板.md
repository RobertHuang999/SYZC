# 字段清单模板（SYZC 业务对象通用版）

> **文档定位**：本文件是定义 SYZC 业务对象的字段字典、页面呈现、数据来源、取值精度、校验规则与快照机制的**唯一权威数据真源**。  
> **适用对象**：业务单据（入库/出库/质押/解押）、基础档案（货权/合同/设备）、库存余额、库存流水、设备事件与预警流水、风控规则配置等。  
> **权威源原则**：主 PRD 和 Demo PRD 只引用本文档定义的字段，严禁在其他文件中自行发明或重复定义字段全集。  
> **技术映射原则**：本模板面向业务与功能设计，统一采用业务中文命名；数据库字段物理映射由接口/数据库字典单独管理。  
> **版本**：V3.1 | 更新时间：YYYY-MM-DD | 责任人：产品团队

| 字段名称 | 所属对象 | 数据层级 | 字段分组 | 字段来源 | 数据类型 | 取值、单位与精度 | 必填规则 | 交互场景(列表/筛选/表单/详情) | 字段说明与校验规则 | 敏感与脱敏/备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **质押单号** | 质押申请单 | 主表 | 基础识别 | 系统生成 | 文本 | 字符串，格式 `ZY+YYYYMMDD+6位流水` | 系统自动 | 列表=是, 筛选=是, 表单=只读, 详情=是 | 本质押业务唯一法律编号，全局唯一，不可重复 | 否 |

## 三、列填写规范与枚举说明

| 列名 | 填写规范与枚举值 |
| :--- | :--- |
| **所属对象** | 填写字段属于哪一个业务实体（如：入库单主表、存货批次明细、设备预警流水、质押合同）。 |
| **数据层级** | 可选：`主表`、`明细表`、`汇总计算`、`流水表`、`事件表`、`系统审计`。 |
| **字段分组** | 可选：`基础识别`、`主体信息`、`仓库位置`、`存货信息`、`计量信息`、`金融风控`、`物联属性`、`审批信息`、`系统属性`。 |
| **字段来源** | 可选：`系统生成`、`用户填写`、`用户选择`、`基础档案快照`、`系统实时计算`、`物联设备上报`、`接口同步`、`动作联动更新`。 |
| **数据类型** | 可选：`文本`、`数字`、`金额`、`重量`、`日期时间`、`枚举`、`布尔`、`手机号`、`附件/存证`。 |
| **必填规则** | 可选：`必填`、`选填`、`条件必填`（附带条件说明）、`系统自动`。 |
| **交互场景** | 分别标明：`列表=(是/否)`，`筛选=(是/否)`，`表单=(填写/选择/只读/隐藏)`，`详情=(展示方式)`。 |
| **敏感与脱敏** | 标明是否包含个人隐私或商业机密；若包含，注明脱敏掩码规则（如手机号、银行卡号、身份证号）。 |

## 四、不可变快照字段清单（司法存证防线）

必须用表格明确在单据生效、质押锁定或告警生成瞬间固化的快照集合：

| 快照业务节点 | 快照固化字段 | 原始数据源头 | 固化目的 |
| :--- | :--- | :--- | :--- |
| 质押单审批通过生效 | 货主全称、仓库名称、存货单价、质押率、审批人员 | 客户档案、仓库档案、现货价格接口、审批人账户 | 防止后续档案变更、企业更名或市价波动影响质押法律效力 |
| 物联网告警流水生成 | 设备安装库位、设备固件版本、当时生效的预警规则版本(Version) | 设备档案、预警配置中心 | 满足 C08 规则版本不回写原则，保障存证历史可溯 |
```
