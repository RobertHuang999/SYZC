# SYZC 业务规则规格模板

> **文档定位**：本文件是 SYZC 独立菜单（业务单据、聚合查询、流水账簿、规则配置等）**状态机、动作约束、校验规则、计算公式、权限与风控规则的唯一定义来源**。  
> **关联依据**：配套使用 `2-1 (输入)状态机设计模板.md` 与 `2-2 (输入)单据状态与流转设计规范.md`。  
> **在 PRD 套件中的分工**：
> - 业务规则规格是**唯一规则与流程来源**：状态机、校验规则（Rxx）、计算公式（Cxx）、权限矩阵（Pxx），以及流程流转图，均统一定义于本文件。
> - Demo PRD 和主 PRD 仅**引用本文件的规则名称与编号（如【存货在库唯一性校验】(R01)）及流程章节**，严禁在其他页面规格中重复定义业务规则。
> **表达约束**：规则、场景、操作、验收与待确认项一律写为“【中文名称】(编号)”；状态与枚举默认中文，已有系统编码仅在必要时括注。本文不定义数据库字段、接口参数、报文或其他研发实现细节。
> **版本**：V1.0 | 更新时间：YYYY-MM-DD | 责任人：[设计人]

## 🛠️ 适用场景与范式裁剪指南

根据本菜单的**业务类型**，选择对应的范式结构（MECE 原则：不重不漏）：

| 菜单类型 | 典型 SYZC 场景 | 核心特征 | 模板裁减规则 |
| :--- | :--- | :--- | :--- |
| **范式 A：单据事务类** | 入库记录、出库记录、质押申请、解押申请、开锁申请 | 具备完整的状态生命周期（草稿 → 待审核 → 待执行/在押生效 → 完成/作废） | **保留全套状态机**：使用【范式 A】（保留 状态定义、状态流转表、动作能力矩阵、执行核销规则） |
| **范式 B：台账与流水类** | 库存流水、库存明细、存货管理、设备预警信息流水、门禁事务记录 | 无独立状态机，强调多维度组合检索、大批量快照呈现、只读审计与对账 | **移除状态机**：使用【范式 B】（聚焦 字段快照只读性、检索条件联动、导出风控、数据权限过滤） |
| **范式 C：配置与规则类** | 预警等级配置、设备预警配置、订单预警配置、开锁审批配置 | 规则策略包配置，涉及阈值判定、互斥约束、防抖机制与【历史流水不回写】(C08) | **移除单据状态机**：使用【范式 C】（聚焦历史流水不回写、策略卡片保存、互斥与防抖下沉、穿透联动） |
| **范式 D：基础档案类** | 货权档案、仓储合同、设备主档、人脸配置 | 基础主数据，生命周期为启用/停用，严禁物理删除，强调引用保护与快照 | **使用档案状态机**：使用【范式 D】（聚焦 启用/停用、删除拦截强校验、历史版本存证） |
| **范式 E：聚合入口/视图类** | 审批中心首页、我的申请、工作台、跨单据查询 | 聚合多个下游对象，不拥有或复制下游业务生命周期 | **不复制下游状态机**：仅定义聚合口径、预览/跳转、权限合并、数据隔离、缓存与失效规则 |

## 三、核心业务规则（使用【规则名称】(Rxx)）

- **【存货排他性锁定】(R01)**：一旦进入待审核或生效状态，所选仓库、库区、货位及具体钢卷/批次号立即置为锁定状态，严禁被其他质押申请单或出库单引用。
- **【自审禁止】(R02)**：单据的发起人与审批人不可为同一系统账户；若审批人打开本人发起的单据，页面强制隐藏【审核通过】/【审核驳回】按钮。
- **【质押率阈值控制】(R03)**：质押金额 / 评估总货值不得高于租户配置的最高质押率上限（如 70%），超限系统阻断提交。
- **【敏感操作存证要求】(R04)**：作废、强制平仓或提前解除锁定，必须弹出二次确认窗口并强制填写原因说明（≤200字），写入司法存证时间轴。

---

## 四、计算公式（使用【计算名称】(Cxx)）

- **【质押率计算】(C01)**：`质押率 = (融资申请金额 / 存货评估总价值) × 100%`。
- **【可用库存联动计算】(C02)**：`可用库存 = 总在库库存 - 在押锁定库存 - 待出库占用库存`。

---

## 五、权限与数据范围约束（使用【权限名称】(Pxx)）

- **【租户与机构数据隔离】(P01)**：本机构人员仅可查询本机构及其管辖监管仓库的数据，跨机构访问应被阻断。
- **【现场操作员权限】(P02)**：仅具备现场操作权限的人员允许执行称重核验与实物出入库登记。
```

# 范式 B：台账与流水类业务规则规格模板（无状态机）

```markdown
# {台账/流水名称} 业务规则规格

> **适用场景**：库存流水、预警信息流水、门禁记录等只读、大批量账簿检索场景。

## 一、台账定位与写入机制
- **数据源头**：明确本流水由哪些业务动作（入库、出库、移库、设备告警触发）自动追加写入。
- **【只读不可变性】(S02)**：流水账簿生成后仅供查询与追溯，不提供编辑或删除；发生冲正时，通过新增对应的反冲流水表达。

## 二、组合检索与性能规则（使用【规则名称】(Fxx)）
- **【必选筛选范围】(F01)**：为保障大批量流水检索性能，时间范围筛选默认限制最近 30 天，最大单次查询跨度不得超过 90 天。
- **【跨字段联动过滤】(F02)**：选择指定仓库后，库区下拉仅联动加载该仓库所属库区；选择货主后自动联动其在押合同。

## 三、字段快照只读规则（使用【规则名称】(Sxx)）
- **【历史存量固化】(S01)**：流水记录中的单价、货值、货主名称、设备规格严格保留事件发生时的原始快照，后续主数据变更不回写本流水。

## 四、导出与风控权限（使用【规则名称】(Pxx)）
- **【导出脱敏与频次限制】(P01)**：批量导出敏感财务流水必须具备管理员权限，单次导出最大限制 50,000 条，文件带动态水印。
```
