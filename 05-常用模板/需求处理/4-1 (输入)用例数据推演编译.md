# SYZC 业务用例数据推演编译指南

> **定位**：通过具体业务数值与沙盘推演，验证单菜单在实物库存、仓单货权、质押价值、IoT告警及资金流上的闭环性。  
> **适用范围**：SYZC 系统中涉及复杂计算、状态联动、库存占用释放或物联预警穿透的业务菜单。  
> **输出目标**：`[对应模块路径]/[菜单名]-用例数据推演.md`

---

## 喂入文件

请让 AI 读取以下文件：

- `AGENTS.md`（核心业务规则、预警穿透与审批机制）
- 当前菜单的业务输入资料与原型草稿
- `[对应模块路径]/[菜单名]-业务流程推演.md`
- `[对应模块路径]/[菜单名]主PRD.md`
- `[对应模块路径]/[菜单名]字段清单.md`
- `05-常用模板/需求处理/4-2 (输出)用例数据推演模板.md`

## 提示词

```text
请读取以上文件。现在开始编译【{业务模块}-{菜单名称}】PRD 套件的用例数据推演：

业务上下文插槽：
- 当前模块：{例如：02-仓储 / 03-融资监管 / 05-风控 / 01-工作中心}
- 菜单名称：{例如：质押申请 / 入库记录 / 设备预警信息 / 门禁开锁审核}
- 业务模式：{大宗存货质押监管 / 仓单流转 / IoT设备告警处置 / 专道审批 / 动态监库}

请注意：
- 本步骤只生成“{菜单名称}-用例数据推演.md”。
- 严禁空泛描述或使用“XXX”占位符，必须使用真实具体的大宗商品（如电解铜、热轧卷板、铝锭等）、真实数值（吨数、单价、货值、质押率、设备ID等）构建沙盘数据。
- 重点验证数据状态在各环节转移时的前后镜像：在押数量、可用数量、锁定状态、告警流水状态、审批状态与审计日志。
- 防污染约束：严格杜绝进销存普通商品零售及应收应付贸易结算场景，全盘采用动产质押与存货风控业务语境。

请创建或更新：
{对应输出目录}/{菜单名称}-用例数据推演.md

请严格参考《05-常用模板/需求处理/4-2 (输出)用例数据推演模板.md》，至少设计推演 2 个代表性业务场景：

### 推荐推演场景库（根据本菜单业务选取适用场景）：
- 【场景模式 1：正向全量闭环】
  - 如：大宗存货 100.00 吨入押 → 估值 500 万元 → 质押率 70%（融资金额 350 万元）→ 仓单质押生效与批次锁定 → 履约完毕全额解押解除锁定。
- 【场景模式 2：动态跌价预警与补仓/平仓】
  - 如：市场价格下跌 15% → 质押率触发补仓线预警 → 系统生成高危预警并推送 → 借款方追加质押物或追加保证金 → 质押率恢复安全区间 → 预警自动闭环。
- 【场景模式 3：IoT 设备异常穿透与现场核销】
  - 如：库区智能门锁离线超限 → 设备侧触发预警流水 → 系统判定库区存在在押订单 → 自动穿透生成订单预警流水 → 现场监管人员核销并解除 → 订单侧自动联动结案。
- 【场景模式 4：开锁审批专网专道与自审拦截】
  - 如：现场仓管员发起临时开锁申请 → 命中审批流 → 校验发起人与审批人（自审拦截保护）→ 合规主管审批通过 → 专道下发一次性临时密码并记录审计。

每个场景必须按以下结构推演：
1. **场景前置条件**：初始账户状态、仓库库位、现存量、关联质押单及设备状态。
2. **推演步骤时序数据表**：
   | 步骤 | 操作动作 | 触发主体 | 核心数据输入 | 系统内部处理及计算公式 | 数据状态变更快照 | 审计与日志记录 |
3. **推演数据资产对账表**：
   - 展示操作前、操作中、操作后的关键指标平衡校验（如：总物理库存 = 可用库存 + 在押锁定库存）。
4. **推演结论与验证点**：
   - 列出本用例验证了主 PRD 和业务规则中的哪几条核心规则（如 R01, R11, P06 等）。
```
