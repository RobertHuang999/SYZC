# SYZC 独立菜单主 PRD 编译指南

> **定位**：基于业务流程推演与字段清单粗纲，编译独立菜单 **PRD 套件**中的**主 PRD**；全文遵循 [AGENTS.md §4.0 三件套 + 衍生](../../AGENTS.md#40-prd-文档体系三件套--衍生全局规范) 全局规范。  
> **适用范围**：SYZC 系统各业务板块所有独立菜单（单据事务类、台账流水类、配置规则类、基础档案类）。  
> **输出目标**：`[对应模块路径]/[菜单名]主PRD.md`

---

## 一、文档体系（编写前必读）

### 1.1 三件套 + 衍生

| 层级 | 文档 | 职责 | 本指南步骤 |
| :--- | :--- | :--- | :--- |
| **核心** | `{菜单名}主PRD.md` | 业务、范围、架构、**页面功能说明**、场景、摘要、验收 | **本文** |
| **核心** | `{菜单名}字段清单.md` | 字段、筛选、列表、表单、控件 | 步骤 2（或已有粗纲） |
| **核心** | `{菜单名}业务规则规格.md` | 状态机、R/C/P 规则、时序、附录 | 步骤 3 |
| *衍生* | `_ASCII_` / `_Demo_` | 线框与原型输入 | 三件套定稿后同步 |
| *衍生* | 前端原型 `annotations/` | 运行时打点 | 三件套 + Demo 定稿后 |

**原则**：字段归字段清单，规则归业务规则规格，主 PRD 写**产品说明**（含页面做什么、怎么交互），**禁止**把三件套内容打散到 ASCII/Demo 后当作真源。

### 1.2 主 PRD 职责边界

**应写**：

- 业务背景与监控/痛点目标
- In Scope / Out of Scope
- 模块或台账定位、上下游、Mermaid 架构图
- **页面功能说明**（PC 列表/详情/表单/解除、H5 等各页：目标、路径、骨架、分区、行操作、V3.x 差异）
- 功能清单、业务场景 S01~Sxx
- 状态机与规则**摘要**（完整本体在业务规则规格）
- 权限摘要、边界异常、性能（台账类）、验收 V01~Vxx

**不应写**（引用它文档）：

- 完整字段表、列宽、控件枚举 → `{菜单名}字段清单.md`
- 状态流转表、R/C/P 规则全文、时序图 → `{菜单名}业务规则规格.md`
- ASCII 线框正文重复粘贴 → `_ASCII_*.md`（衍生）

### 1.3 推荐编译顺序

```text
步骤 1  主 PRD（本文）
步骤 2  字段清单（定稿或对齐粗纲）
步骤 3  业务规则规格
步骤 4  ASCII 线框（由三件套派生）
步骤 5  Demo 文档 + 前端原型（由三件套 + ASCII 派生）
```

## 四、三件套定稿后的衍生步骤（非本指南范围）

三件套评审通过后，按顺序执行：

1. **ASCII**：从主 PRD §页面功能说明 + 字段清单 + 规则规格派生；文头标注「衍生 · 非独立真源」。
2. **Demo**：从三件套 + ASCII 派生；供 AI/人工生成原型页面。
3. **原型标注**：`PrototypeDocument` 挂载 `prd` / `fields` / `rules` 三路径；Mermaid 与规则 ID 引用业务规则规格。

变更任何需求时：**先改三件套 → 再同步 ASCII/Demo → 最后改原型**（见 AGENTS.md §4.0.4）。
