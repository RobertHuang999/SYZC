# SYZC 页面规格 (Demo/ASCII) 编译指南

> **定位**：将独立菜单的主 PRD 和字段清单翻译为前端原型可直接实现的页面级规格说明（Demo PRD / ASCII 视图）。  
> **适用范围**：SYZC 系统各业务菜单的 PC 端及 H5 移动端前端页面。  
> **输出目标**：`[对应模块路径]/[菜单名]_Demo_[页面类型].md` 或 `[菜单名]_ASCII_[页面类型].md`

---

## 喂入文件

请让 AI 读取以下文件：

- `AGENTS.md`（第 4 章 前端原型与标注规范，工作中心/列表布局与自审禁止约束）
- `[对应模块路径]/[菜单名]主PRD.md`
- `[对应模块路径]/[菜单名]字段清单.md`（定稿版）
- `[对应模块路径]/[菜单名]-业务流程推演.md`
- `05-常用模板/需求处理/9-2 Demo PRD模板.md`

---

## 提示词

```text
请读取以上文件。现在开始编译【{业务模块}-{菜单名称}】的前端页面规格（Demo/ASCII PRD）：

业务上下文插槽：
- 当前模块：{例如：02-仓储 / 03-融资监管 / 05-风控 / 01-工作中心}
- 菜单名称：{例如：库存流水 / 质押申请 / 设备预警配置 / 门禁开锁审核}
- 目标终端：{PC 端 / H5 移动端}
- 页面形态组合：{三页结构(列表+新增编辑+详情) / 双页结构(列表+详情) / 配置面板(卡片+抽屉) / 审批流卡片}

请注意：
- Demo PRD 是页面交互与呈现规格的翻译，不是新的业务规则定义源。
- 字段名、枚举项、必填性必须完全来自于“字段清单.md”。
- 操作按钮显隐、禁用状态与二次确认逻辑必须完全来自“主PRD.md”的动作能力矩阵与状态机。
- 严格遵循 AGENTS.md 交互规范：
  - 自审禁止（P06/R11）：审批人不可审批自己发起的申请，本人发起的记录仅展示“详情”，不展示“去审批/去处理”；
  - 表单防误触：脏数据离开拦截（Dirty 提示）；
  - 敏感操作必须有二次确认弹窗并强制输入核查理由。

根据本菜单的实际交互需要，创建或更新对应的页面文件：
1. {对应输出目录}/{菜单名称}_Demo_列表页.md（或 ASCII 版）
2. {对应输出目录}/{菜单名称}_Demo_新增编辑页.md（如适用）
3. {对应输出目录}/{菜单名称}_Demo_详情页.md（或详情抽屉）
4. {对应输出目录}/{菜单名称}_Demo_操作弹窗规格.md（如适用：如批量核查解除预警弹窗、临时密码展示弹窗）

请严格参考《05-常用模板/需求处理/9-2 Demo PRD模板.md》进行输出，核心章节要求：

═══════════════════════════════════════
【列表页核心要素】
- 页面目标与路由路径
- 查询区筛选控件（严格来自字段清单“可筛选=是”）
- 状态快捷 Tab 栏（带统计计数，来自状态机）
- 列表表格列定义（严格来自字段清单“列表展示=是”，大宗商品数量标明单位与精度）
- 行操作与批量操作按钮（结合权限与状态联动，标明自审禁止策略）
- 分页、排序与空态/加载态规格

═══════════════════════════════════════
【表单页核心要素】（如适用）
- 表单分组结构（基础信息、存货/质押明细、风控参数、资料附件）
- 字段级呈现规则（只读/必填/下拉枚举/计算只读带出）
- 底部操作栏（取消、存草稿、提交审核，含二次确认文案与防重复提交）

═══════════════════════════════════════
【详情页核心要素】
- 头部状态条（当前状态 Badge、业务单号、创建时间、流程主操作按钮）
- 结构化信息卡片（业务主体、存货信息、风控指标、关联设备、不可变快照展示）
- 审批轨迹与操作时间轴（操作人、操作动作、审批意见、存证材料）
```
