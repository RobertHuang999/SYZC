## 一、列表页 Demo PRD 规格

### 1.1 页面基础信息
| 项目 | 规范说明 |
| :--- | :--- |
| **页面名称** | [菜单/模块名称]列表 |
| **路由路径** | `/仓储/库存查询/库存流水` 或 `/工作中心/审批中心/其他审批/开锁审核` |
| **布局骨架** | **双卡片结构**：查询筛选卡片 + 列表数据卡片（背景 `#F8FAFC`，白底卡片圆角，阴影柔和） |
| **权限编码** | 菜单权限：`MENU_[MODULE]_[CODE]`；按钮权限：`BTN_[CODE]` |

### 1.2 快捷状态 Tab 栏（带统计徽标）
当业务对象存在状态流转时，必须在表格上方提供状态过滤 Tab：
| Tab 名称 | 过滤状态逻辑 | 徽标 Badge 计数规则 |
| :--- | :--- | :--- |
| 全部 | 展示所有状态（默认选中） | 展示符合其他筛选条件的总记录数 |
| 待处理 / 待审核 | 仅展示 `PENDING` / `PENDING_AUDIT` 记录 | 动态展示待办数，超过 99 显示 `99+`；红色高亮徽标 |
| 已生效 / 执行中 | 仅展示 `ACTIVE` 记录 | 常规灰色徽标 |
| 已结案 / 已完成 | 仅展示 `RESOLVED` / `COMPLETED` 记录 | 绿色常规徽标 |

- **交互联动**：切换 Tab 时，列表数据自动刷新，页码重置为第 1 页；**不得重置**其他已输入的仓库、时间等筛选条件。

### 1.3 查询筛选区
- **筛选项严格来源于字段清单中「可筛选 = 是」的字段**。
- 支持【查询】、【重置】以及可收起的【高级筛选】（当筛选项超过 4 个时折叠）。

### 1.4 数据表格与操作列
- **表格列定义**：严格来源于字段清单中「列表展示 = 是」的字段。
- **大宗商品计量展示**：重量统一右对齐，标明单位（吨），精确到 3 位小数；金额带千分位（`¥ 1,234,567.89`）。
- **操作列按钮显隐与自审禁止（P06/R11）**：
  | 按钮名称 | 触发条件 / 权限 | 交互方式 |
  | :--- | :--- | :--- |
  | **详情** | 任何状态下均展示 | 点击跳转详情页或右侧滑出详情抽屉 |
  | **编辑** | 仅 `草稿` 状态可见 | 跳转新增编辑表单页 |
  | **去审批** | 仅 `待审核` 状态且**非本人申请**时可见 | 弹出审批弹窗；**若为当前登录人提交的单据，系统强制隐藏此按钮** |
  | **核查解除** | 仅符合 R16 解除条件的告警记录展示 | 弹出【现场核查解除预警弹窗】，必须录入情况说明与存证照片 |

### 1.5 批量操作与分页
- 支持列表行多选（Checkbox）；当勾选数据时，列表上方浮现批量操作条（如：【批量解除预警】、【批量导出】）。
- 物理分页：每页支持 20 / 50 / 100 条切换，展示总记录数与当前页码。

## 二、新增 / 编辑表单页 Demo PRD 规格

### 2.1 页面布局与表单分组
- 页面采用分步卡片（Step Cards）或折叠分组卡片布局：
  1. **第一组：主体与监管基础信息**（业务单号只读、货主企业选择、监管仓库与库区级联选择）；
  2. **第二组：存货 / 设备明细清单**（支持扫码录入/增行删除，包含钢卷号、品类、检斤重量、基准单价、质押率计算显示）；
  3. **第三组：资质附件与存证资料**（营业执照、仓储合同、现场地磅磅单、实物照片，支持拖拽上传）；
  4. **第四组：经办人与备注信息**。

### 2.2 交互与防护机制
- **只读与自动带出**：用户选择某货主或仓单后，系统自动带出其在库批次与可用重量；质押率字段根据输入金额与货值实时动态计算，不可手动修改。
- **防误触离开拦截（Dirty Check）**：当表单存在未保存的修改时，用户点击面包屑、返回或关闭标签页，浏览器弹出模态对话框拦截：“当前表单有未保存的修改，确定离开？”。
- **防重复提交**：点击【提交审核】按钮后，按钮立即置为 Loading 禁用状态，防止网络抖动导致重复提交生成多笔单据。

## 三、详情页 Demo PRD 规格

### 3.1 页面头部核心信息条
- **页面顶部固底/吸顶状态条**：
  - 核心单号（支持一键复制） + 状态彩色 Badge（如：在押生效 - 绿色，待审核 - 橙色，高危预警 - 红色）；
  - 关键 KPI 指标大字看板（如：质押融资金额、在押总重量、当前质押率、告警触发时间）；
  - 右侧主动作操作按钮组（根据当前状态与自审禁止规则动态渲染）。

### 3.2 结构化详情卡片
- **存货信息卡片**：展示存货批次列表、理论/实测重量、质押单价、所在货位坐标。
- **不可变快照卡片**：专门展示业务生效时的历史快照（单价快照、企业资质快照、审批人快照）。
- **物联监库卡片（如适用）**：展示关联监控摄像头实时画面/抓拍快照，展示门禁状态与传感器指标。
- **审批轨迹与操作时间轴（Timeline）**：
  - 垂直时间轴展示全生命周期：发起申请（时间/操作人） → 系统风控校验通过 → 审批通过（审批意见/附件） → 现场称重入押 → 结案解押。

## 四、常用操作弹窗与抽屉规格

### 4.1 现场核查解除告警弹窗（R16）
- **触发入口**：预警列表行操作【解除预警】或批量操作【批量解除】。
- **弹窗字段**：
  1. 预警事件简述（只读展示设备/订单信息及预警子类型）；
  2. 解除原因分类（下拉选择：现场设备已复位 / 正常作业移库 / 误报测试 / 现场险情已排除）；
  3. **核实情况说明（必填多行文本框，限制 ≤ 200 字，带字数统计）**；
  4. 现场存证照片（必须上传至少 1 张现场实拍水印照片）；
- **交互约束**：未输入说明或未上传照片时，【确认解除】按钮置灰禁用。

### 4.2 免审开锁直发临时密码展示弹窗（R31）
- **触发入口**：点击门锁行操作【获取门禁密码】且免审通过。
- **弹窗呈现**：
  1. 一次性 6 位数字临时动态密码（超大字号展示，提供【一键复制】按钮）；
  2. 密码有效倒计时（如：`密码将于 14分58秒 后失效`）；
  3. 注意事项文案：“该密码仅供本次授权开锁使用，系统已全路径记录审计流水”；
  4. 人脸门禁绝不调用短信 API；挂锁门禁支持【短信发送密码】辅助按钮。
