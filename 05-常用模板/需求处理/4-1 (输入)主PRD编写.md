# 4-1（输入）主 PRD 编写

## 何时使用

规则规格与字段清单已具备基本稳定版本，需要形成菜单级主 PRD 时使用。

## 输入资料

- 业务流程推演。
- `{菜单名}业务规则规格.md`。
- `{菜单名}字段清单.md`，有独立操作时同时读取操作字段清单。

## 产出文档

| 必选性 | 产出 |
| :--- | :--- |
| 必选 | `{菜单名}主PRD.md` |
| 按菜单类型自动选用 | 单据事务、台账流水、配置规则、基础档案或聚合入口模板 |

## 完成标准

- 主 PRD 只说明业务背景、范围、页面功能、场景、规则摘要、权限与验收。
- 字段细节引用字段清单，规则本体引用规则规格，避免重复定义。
- 主 PRD 中建立场景、规则、业务字段、操作与验收的追溯关系。

## 4-2 输出模板选型

| 菜单类型 | 选择模板 |
| :--- | :--- |
| 具备生命周期流转的业务单据 | `4-2-1（输出）业务单据类PRD模板` |
| 只读查询、流水或台账 | `4-2-2（输出）台账流水类PRD模板` |
| 阈值、策略、预警或审批配置 | `4-2-3（输出）配置与规则类PRD模板` |
| 长期维护、被业务引用的基础档案 | `4-2-4（输出）基础档案类PRD模板` |

聚合入口仅定义聚合口径、权限、跳转与依赖规则，不复制下游状态机。
