# 采购订单｜当前字段清单

> 用途：本文件描述当前页面的完整字段口径。作为基准生成本次需求中的完整字段快照。

## 单据头字段（示例数据）

| 字段         | 来源     | 必填 | 当前规则                                                    |
| ------------ | -------- | ---- | ----------------------------------------------------------- |
| 采购单号     | 系统生成 | 是   | 格式 `PO{YYYYMMDD}-{4位序号}`，审核后不可修改               |
| 供应商       | 用户选择 | 是   | 仅可选择启用中的供应商；审核后锁定                          |
| 入库仓库     | 用户选择 | 是   | 仅可选择启用中的仓库；审核后锁定                            |
| 下单日期     | 用户填写 | 是   | 默认为当天；允许补录过去日期，不允许未来日期                |
| 预计到货日期 | 用户填写 | 否   | 日期格式 `YYYY-MM-DD`                                       |
| 订单状态     | 系统生成 | 是   | `草稿/待审核/待入库/部分入库/已完成/已作废`；只能由动作变更 |
| 采购备注     | 用户填写 | 否   | 最多 200 字                                                 |
| 商品种数     | 系统计算 | 是   | 明细行数                                                    |
| 采购总数量   | 系统计算 | 是   | 各明细采购数量之和                                          |
| 采购总金额   | 系统计算 | 是   | 各明细金额之和，保留 2 位小数                               |

## 明细字段（示例数据）

| 字段                    | 来源     | 必填 | 当前规则                                 |
| ----------------------- | -------- | ---- | ---------------------------------------- |
| 商品编码                | 商品档案 | 是   | 仅可选择启用商品；一行对应一个商品       |
| 商品名称/条码/规格/单位 | 系统带出 | 是   | 随商品选择带出并做快照存储               |
| 采购数量                | 用户填写 | 是   | 正整数，且大于 0；审核后锁定             |
| 单价（含税）            | 用户填写 | 是   | 大于等于 0，保留 2 位小数；审核后锁定    |
| 税率                    | 用户填写 | 否   | `0%/3%/6%/9%/13%`                        |
| 金额（含税）            | 系统计算 | 是   | `采购数量 × 单价（含税）`，保留 2 位小数 |
| 累计已入库数量          | 下游回写 | 是   | 采购入库单确认后累加                     |
| 未入库数量              | 系统计算 | 是   | `采购数量 - 累计已入库数量`              |
| 行备注                  | 用户填写 | 否   | 最多 100 字                              |

## 系统字段

创建人、创建时间、最后修改人、最后修改时间、审核人、审核时间均由系统生成，详情页可查看；本次批量导入不允许在模板中填写这些字段。
