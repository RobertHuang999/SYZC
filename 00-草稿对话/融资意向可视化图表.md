## 2. 独家并发分配控制时序图

对应文件：[2_独家并发分配控制时序图.html](file:///Users/robert/Desktop/SYZC/00-%E8%8D%89%E7%A8%BF%E5%AF%B9%E8%AF%9D/%E8%9E%8D%E8%B5%84%E6%84%8F%E5%90%91%E5%8F%AF%E8%A7%86%E5%8C%96%E5%9B%BE%E8%A1%A8/2_%E7%8B%AC%E5%AE%B6%E5%B9%B6%E5%8F%91%E5%88%86%E9%85%8D%E6%8E%A7%E5%88%B6%E6%97%B6%E5%BA%8F%E5%9B%BE.html)

```mermaid
sequenceDiagram
    autonumber
    actor OP as 平台运营
    participant Sys as 系统(线索池)
    participant F1 as 资方 A
    participant F2 as 资方 B
    
    OP->>Sys: 审核通过，分配线索给【资方 A】
    Sys->>Sys: 写入 funderId = 'F1'
    Sys->>Sys: 状态扭转为 [待资方受理]
    Sys-->>F1: 独家展示线索
    Sys--x F2: 隐藏线索 (无权限)
    
    alt 资方 A 拒绝
        F1->>Sys: 驳回并填写原因
        Sys->>Sys: 状态扭转为 [资方已驳回]
        Sys-->>OP: 流转至【被拒记录池】
        OP->>Sys: 运营分析原因，重新分配
        Sys->>Sys: 下拉列表置灰【资方 A】
        OP->>Sys: 重新分配给【资方 B】
        Sys->>Sys: 覆盖 funderId = 'F2'
        Sys-->>F2: 独家展示线索
    else 资方 A 接受
        F1->>Sys: 接受并填写(授信金额, 期数)
        Sys->>Sys: 状态扭转为 [待发起业务]
    end
```

## 3. 核心状态流转图 (增强版)

对应文件：[3_核心状态流转图.html](file:///Users/robert/Desktop/SYZC/00-%E8%8D%89%E7%A8%BF%E5%AF%B9%E8%AF%9D/%E8%9E%8D%E8%B5%84%E6%84%8F%E5%90%91%E5%8F%AF%E8%A7%86%E5%8C%96%E5%9B%BE%E8%A1%A8/3_%E6%A0%B8%E5%BF%83%E7%8A%B6%E6%80%81%E6%B5%81%E8%BD%AC%E5%9B%BE.html)

```mermaid
stateDiagram-v2
    [*] --> Pending: 客户提交融资申请
    
    state 业务分发分支 {
        Pending --> DD_Pending: 开启尽调并分配
        Pending --> Approving: 关闭尽调，跳过直接分配
        Pending --> Closed: 运营判定无效，手动终止
    }
    
    state 尽调办理环节 {
        DD_Pending --> DD_Done: 尽调人员出具结论
        DD_Pending --> DD_Suspended: 触发[系统关闭尽调]全局开关
        DD_Suspended --> Approving: 运营异常处理(跳过尽调)
        DD_Suspended --> Closed: 运营异常处理(作废)
    }
    
    state 资方流转环节 {
        DD_Done --> Approving: 运营审核分配给资方
        Approving --> Passed: 资方接受，填写最终授信
        Approving --> Rejected: 资方拒绝(填写原因)
        
        Rejected --> Approving: 运营重新分配给新资方
        Rejected --> DD_Pending: 运营打回重新补充尽调
        Rejected --> Closed: 运营确认无法融资，手动终止
    }
    
    state 转化环节 {
        Passed --> Transformed: 成功发起抵质押业务
        Passed --> Closed: 客户主动放弃撤单
    }
    
    Transformed --> [*]
    Closed --> [*]
```
