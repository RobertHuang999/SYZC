## 一、需求背景与业务定位

### 1.1 业务背景
在大宗商品（电解铜、热轧卷板、铝锭、冻品等）仓储履约现场，出入库操作及初审审批通常依赖现场出入库单、地磅单与随车清单完成。审批通过后，单据置为 `APPROVED`（已通过），库存已生成或扣减，单据归档生效。
但在实际履约后，存在大量“后置单据/后补资料”：
1. **质检商检报告**：第三方 SGS/化验分析、出厂质保、动植物检疫报告通常在作业后 2~5 天才出具；
2. **衡重计量纠偏**：原随车磅单车牌少录一位或称重有微调，地磅站重新开具更正证明并加盖公章；
3. **结算凭证发票**：后补的仓储费结算单、对账单与运输发票；
4. **权属交接回执**：货转协议原件盖章件、出库交接单签字回执。

### 1.2 核心业务决策与边界定调（对齐最新业务决策）
1. **只增不删，禁止变更与删除（对齐最新决策）**：
   - 经业务多方讨论确认：**变更和删除资料都不合理**；
   - 所有已归档或后置补录资料**严禁就地修改、覆盖或物理删除**；
   - 彻底废除原“变更原资料 (CORRECTION)”模式，统一采用**【不可逆追加模式】**（对标抵质押业务 `[DZY-R22]` 不可逆追加机制），纠偏或新凭证均作为新单据后置补录追加。
2. **精准穿透历史流程阶段**：
   - 补录资料时必须明确**【关联流程阶段】**（如初审、过磅、终审、事后综合），精准解决业务“挂载到哪个作业环节”的诉求；
   - 严禁强行倒插或篡改历史审批快照，资料作为后置事件挂载在对应流程阶段下。
3. **极简录入，免输入资料类目与资料名称**：
   - 上传时**不需要用户挑选【资料类目】**（业务归属已由关联流程阶段表达，免去冗余的人工二级分类）；
   - 上传时**不需要用户手动填写【资料名称】**，系统自动继承原附件的真实文件名；
   - 弹窗仅保留：`关联流程阶段`（必选） + `附件上传`（必传） + `补充说明`（选填，最多 150 字）。
4. **详情页右上角取消【补充资料】按钮**：
   - 详情页右上角页头操作区**不放置【补充资料】按钮**，仅保留核心单据操作（撤销 / 提货码核销 / 返回）；
   - 补充资料操作统一收敛在详情页下方的**【资料管理】Tab** 内（提供全局上传与各阶段节点【+ 补充本阶段资料】快捷入口）。
5. **轻量优雅时间轴呈现（对齐系统标杆）**：
   - 废除传统死板表格，采用系统标准的时间轴流转设计（全部资料 N 份 + 搜索框 + 时间轴流程阶段折叠展开 + 资料卡片 + 预览/下载）。

## 二、系统基准对比与复用：抵质押业务【22-资料管理】

本方案底层设计理念完全复用系统现网标杆：**[07-22 抵质押业务-资料管理](../../02-PRD文档/🌟🌟🌟-最新基准版/B端PC/03-融资监管/07-抵质押业务-抵质押业务管理/操作业务/22-资料管理/资料管理主PRD.md)**：

### 2.1 复用的核心规则与模型
1. **版本不可逆追加机制 (`[DZY-R22] Append-Only Versioning`)**：
   - 单据生效后，严禁物理删除或覆盖原文件；
   - 任何补正与资料追加均作为新记录递增归档，确保金融与仓储监管证据链完整、司法存证全链路可溯。
2. **在线安全只读预览防泄密 (`[DZY-R22a]`)**：
   - 在客户端在线预览 PDF 或图片格式时，系统自动动态压印当前登录用户姓名、工号、当前查看时间的半透明斜向防截屏水印。
3. **14 维标准存证字段模型**：
   - 继承文件全局 ID、关联业务单号、流程阶段、文件名、格式、大小、版本号、上传人员及机构、时间戳、SHA-256 数字指纹，符合司法存证要求。

### 2.2 出入库业务特化对比

| 对比维度 | 抵质押业务【22-资料管理】(基准) | 出入库记录【资料管理】(本方案) |
| :--- | :--- | :--- |
| **主体对象** | 抵质押主订单 (`order_no`) | **出入库单号 (`order_no`) + 审批单号 (`approval_id`)** |
| **分类组织** | 固定 5 大类目（合同/登记/磅单/底稿/回单） | **流程履历时间轴阶段（申请初审/过磅核验/终审质检/事后补充）** |
| **资料录入** | 需指定类目与名称 | **极简录入：免填类目、免填名称（直接继承真实文件名）** |
| **入口呈现** | 行操作呼出右侧抽屉 | **列表行操作 2×2 快捷呼出抽屉 + 详情页【资料管理】独立 Tab** |
| **页头按钮** | 抽屉内部右上角追加 | **详情页右上角不放全局按钮，收敛至 Tab 内部各阶段节点** |

## 五、合规与权限规则总结

1. **不可逆追加原则 (`[DZY-R22]`)**：
   - 严禁就地修改、覆盖或物理删除已归档单据；
   - 纠偏必须通过追加新凭证进行补充，系统完整保存全路径履约事实。
2. **安全防截屏预览 (`[DZY-R22a]`)**：
   - 在线预览 PDF/图片时动态压印当前用户工号、姓名、时间的防伪防截屏水印。
3. **只增不删与阶段标清**：
   - 资料通过选择【关联流程阶段】归入作业环节，系统自动写入 `ADDITION` 属性并展示【事后补录】标识；
   - 详情页右上角不提供干扰性的【补充资料】按钮，操作收敛至【资料管理】Tab。
