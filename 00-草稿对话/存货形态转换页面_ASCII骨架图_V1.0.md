- 货主主体类型变化后清空已选货主。
- 货主、存货类型、仓库或抵质押单变化且已有投入时，确认后清空投入。

```text
                      +--------------------------------------------------------------------------+

                      +--------------------------------------------------------------------------+
```

数量联动：

```text
填写一级计划投入数量 -> 按现有库存分配规则自动分配二级数量
填写二级计划投入数量 -> 自动汇总一级计划投入数量
一级计划投入数量     = 该SKU全部二级计划投入数量之和
```

## 9. 状态与按钮速查

```text
+------------------+----------------------------+--------------------------------------------+
| 状态             | 页面主要按钮               | 说明                                       |
+------------------+----------------------------+--------------------------------------------+
| 新增未提交       | 取消、提交                 | 无保存草稿；关闭后数据不保留               |
| 审批中           | 查看、申请人撤回           | 撤回后终态并释放全部库存                   |
| 待完成           | 查看、完成、按权限作废     | 作废无需再次审批                           |
| 完成处理中       | 无                         | 防止重复完成和并发作废                     |
| 已完成           | 查看、血缘、预警跳转       | 不支持修改、撤回或业务冲正                 |
| 已撤回/已驳回    | 查看                       | 终态；需要继续时重新发起                   |
| 已作废           | 查看                       | 终态；全部锁定库存已释放                   |
+------------------+----------------------------+--------------------------------------------+
```
