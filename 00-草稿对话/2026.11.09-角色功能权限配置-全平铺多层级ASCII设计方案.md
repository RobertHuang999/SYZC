## 一、页面定位与入口

1. 页面名称：**功能与菜单权限配置**。
2. 归属：系统参考（与「功能与数据权限」「迭代记录」并列）。
3. 三个入口：
   * 右上角「全部原型」下拉里，位于「功能与数据权限」下方；
   * 系统参考页签的第三个页签；
   * 直接访问 `/系统参考/功能与菜单权限配置`。
4. 用途：按角色给菜单、页面、按钮逐项开通权限，供业务评审、风控对照与研发核对。
5. 本页**只配功能与菜单权限**，不配数据可见范围（数据范围仍看「功能与数据权限」页）。

## 二、数据口径

1. 数据取自现网权限库 `sys_permit.sql`，共 **1505 条**权限记录，覆盖 5 个终端渠道：

   | 渠道 | 记录数 | 启用 | 停用 |
   | :--- | ---: | ---: | ---: |
   | 机构 PC 业务端 | 863 | 794 | 69 |
   | 机构移动端 | 580 | 544 | 36 |
   | 平台 PC 运营端 | 27 | 27 | 0 |
   | 个人门户 PC 端 | 18 | 17 | 1 |
   | 个人门户移动端 | 17 | 16 | 1 |

2. 层级按数据库「上级 ID」还原，最深 7 级；不按权限编码拆层（编码只作唯一编号，存在历史遗留的不规则前缀）。
3. 页面上**不展示**权限编码、前端路由、读写模式；按编号搜索仍然可用。
4. 平台端、个人门户**没有「模块」层**，页面直接把根节点（目录或菜单）作为左侧导航项。

## 四、展示规则（最终口径）

### 1. 三态勾选，不做敏感色

* **蓝色实心**：已勾选；
* **蓝色横线**：部分勾选（下级只开了一部分）；
* **灰色空框**：未勾选；
* **浅灰虚线框**：已停用，不可勾选。

不再使用橙色、不再区分“敏感/高危”，也没有【一键关闭敏感高危】按钮。

### 2. 父子联动

* 勾父级：父级 + 全部下级一起勾上，并自动补上所有上级；
* 取消父级：父级 + 全部下级一起取消；
* 只勾部分下级：父级显示横线（半选）；
* 单个按钮被勾上时，自动把它的上级链路补齐。

### 3. 分组与层级

* 每一层分组标题都是「折叠箭头 + 勾选框 + 名称 + 已选/总数 + 全选 + 清空」；
* 勾选框控制整组，全选/清空同样作用于整组；
* **模块级且没有下级的权限**（如「外链平台」「数据走势」）用整行小卡片呈现，与「审批中心」「数据一览」同级；
* **没有下级按钮的菜单**用菜单卡片单行呈现，标注「无下级操作」；
* **带子操作的分组**用整行小面板：名称后跟蓝色徽标「含 N 项子操作」，下级缩进并用一条竖线连回父级；
* 菜单下再挂菜单（如「设备管理 → 监控设备」）按嵌套菜单卡片展示。

### 4. 停用权限怎么处理

* 默认只隐藏**停用的叶子权限**；
* 如果停用节点下面还有启用中的下级（原库里有 16 处，如「监管业务」「监管报告」「监管信息确认任务」），**父级保留并灰显，打「已停用」标记**，避免把下级提上来导致层级串位；
* 打开顶部【显示已停用】后，全部停用项都显示，浅灰、不可勾选；
* 停用分组不显示【全选 / 清空】（点了也无法授权）。

### 5. 折叠

* 每个分组标题左侧有折叠箭头，可单独收起/展开；
* 左侧「业务模块」右上角有【全部收起 / 全部展开】，一键控制当前渠道所有分组；
* 折叠不影响勾选状态和数量统计。

### 6. 搜索

* 支持页面名称、按钮名称、权限编号、前端路由；
* 搜索结果按「名称 + 层级标签 + 完整路径」展示，可直接勾选；
* 页面上不显示编号，但输入编号仍能命中。

### 7. 未挂载上级的权限

`sys_permit.sql` 里有 **12 条记录的上级 ID 不存在**，无法还原真实层级。页面把它们单独归入「未挂载上级的权限」分组，保留、可勾选、不丢数据。明细：

* `2025050501/02/04` 入库新增、入库详情、入库撤销（上级 `2025050500`）
* `2025050701/02/04` 出库新增、出库详情、出库撤销（上级 `2025050700`）
* `2025090501~05` 事务新增、事务详情、事务启停、事务编辑、事务删除（上级 `2025090500`）
* `20250909023` 预警详情（上级 `20250909022`）

## 五、角色与保存

1. 内置 4 个模拟角色：

   | 角色 | 预置授权范围（按权限编号前缀） |
   | :--- | :--- |
   | 资方风控审批岗 | 审批中心、融资管理、监管管理、风控、统计看板、移动端首页/业务概览/监管委托受理 |
   | 仓库管理员 | 仓储、仓单、物联设备、移动端工作台/仓储/业务发起 |
   | 平台运营管理员 | 配置管理、门户配置、机构管理、结算、统计看板 |
   | 机构业务专员 | 用户中心、合作方档案、交易、采购/销售需求、移动端首页/工作台/业务发起 |

2. 保存粒度：**角色 + 渠道**。例如“资方风控审批岗在机构 PC 业务端”的授权单独保存。
3. 保存写浏览器本地存储（localStorage），刷新、切角色、切渠道不丢；原型不接后端。
4. 底部固定栏显示：已配置菜单页面数、已开通操作权限数、本次变动数。
5. 操作按钮：
   * 【恢复示例授权】：把当前角色恢复到内置示例授权（需保存后生效）；
   * 【清除本机记录】：清掉本机保存的该角色该渠道记录，并还原示例授权；
   * 【放弃修改】：回到上次保存的状态；
   * 【保存权限】：写入本机。
6. 有未保存改动时切换角色或渠道，会先弹确认，避免误丢。

## 六、与初版设计稿的差异（以本节为准）

| 项目 | 初版设计稿 | 最终实现 |
| :--- | :--- | :--- |
| 渠道 | 只列机构 PC / 移动 / 平台三档 | 5 个渠道全量，顶部可切 |
| 颜色 | 四色（蓝/绿/橙/灰） | 三态（蓝/灰/浅灰），去掉橙色与高危按钮 |
| 读写标记 | 按钮后带“读/写” | 不展示 |
| 权限编码 | 分组标题旁显示编码 | 不展示；仍可搜索 |
| 子动作 | 行内胶囊 `(含: ...)` | 整行小面板 + 「含 N 项子操作」徽标 + 竖线连接 |
| 折叠 | 明确“无手风琴折叠” | 增加分组级折叠与全部收起/展开 |
| 停用项 | 未说明 | 默认隐藏叶子；有启用下级的停用父级保留灰显 |
| 角色 | 只举一个角色 | 4 个模拟角色 + 示例授权 |
| 保存 | 底部保存栏（未定义落点） | 按角色+渠道写本机存储，可恢复/清除/放弃 |
| 底部统计 | 固定写 48 页 / 242 项 | 按当前角色与渠道实时计算 |

## 七、前端落地要点

1. 数据由脚本从清单 Markdown 自动生成，不手抄：
   * 脚本：`03-前端原型demo/B端PC/scripts/generate-menu-permission-config.mjs`
   * 命令：`npm run generate:menu-permissions --prefix 03-前端原型demo/B端PC`
   * 输出：`src/features/menu-permission-config/data/menu-permissions.generated.ts`
2. 树还原、勾选联动、统计都在 `lib/permission-tree.ts`；本机存储见 `lib/selection-storage.ts`。
3. 页面与组件在 `features/menu-permission-config/`：
   * 页面：`pages/MenuPermissionConfigPage.tsx`
   * 平铺与折叠组件：`components/PermissionTree.tsx`
4. 本页不挂三件套标注，与「功能与数据权限」「迭代记录」两个参考页保持一致。
