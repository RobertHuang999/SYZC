## 业务说明

本字段清单用于规范 **SYZC 供应链金融存货监管系统** 中“普通存货与抵质押存货形态转换”单据的数据结构。支持 1:N、N:1、N:N 多种加工形态变动。

主表管理形态转换单的操作类型、风控告警打标、自定义审批流与试算结果；从表分别存储投入物明细（校验同源性与仓单隔离）与产出物明细（调取大宗行情计算货值并更新至质押单）。

## 枚举值定义

### 1. `StockCategory`（存货类别）
- **`FREE`（普通存货）**：自由库存，无质押管控，产出物仍为普通存货。
- **`PLEDGED`（抵质押存货）**：受质押合同与货权监管锁定，产出物强制继承挂载至原质押单。

### 2. `ConvertOrderStatus`（形态转换单状态）
- **`DRAFT`（草稿）**：初始新建，可修改、删除、发起试算。
- **`PENDING_APPROVAL`（待审批）**：已提交，进入自定义审批流。
- **`PROCESSING`（在产/加工中）**：审批通过，原料已被系统锁库扣减，正在物理加工。
- **`AUDIT_HANG`（稽核挂起）**：实收入库数量与预估产出数量偏差 > 5%，待监管复核。
- **`COMPLETED`（已完成）**：成品正式确认入库，质押物已完成重估挂载，单据归档。
- **`CANCELLED`（已取消）**：驳回或主动撤销作废。

### 3. `StockStatus`（库存状态）
- **`NORMAL`（正常自由库存）**：未质押未锁定的自由存货。
- **`PLEDGED`（质押监管中）**：已被质押单锁定的监管存货。
- **`IN_WARRANT`（仓单中）**：处于交易所电子仓单或已开质押仓单状态，**系统一律硬性禁止转换**。

## 字段约束与数据规则

### 1. 数据验证规则
* **`convertOrderNo`（单据编号）**：唯一索引，格式 `CVT-YYYYMMDD-XXX`。
* **`sourcePledgeId`（关联质押单ID）**：当 `stockCategory === 'PLEDGED'` 时为强制必填项；且系统校验投入物列表中所有物料的 `sourcePledgeId` 必须一致（**禁止跨质押单混合投料**）。
* **`stockStatus`（库存状态）**：提交时后端强校验，若包含 `IN_WARRANT`，接口返回 `HTTP 422: 仓单货物严禁加工转换`。
* **`marketPrice`（行情基准单价）**：只读字段，禁止前端提交自定义价格，一律以后端获取的行情基准价为准。

### 2. 货值与风险计算规则
* **`totalInputVal`（投入总货值）** = $\sum (\text{input\_item.quantity} \times \text{input\_item.unitPrice})$
* **`totalOutputVal`（产出总货值）** = $\sum (\text{output\_item.expectedQuantity} \times \text{output\_item.marketPrice})$
* **`isHighRisk`（是否高风险告警）** 判断公式（仅针对抵质押存货）：
  $$\text{若 } \text{totalOutputVal} \times \text{pledgeRate} < \text{loanPrincipalAmount} \implies \text{isHighRisk} = \text{true}$$

## TypeScript 类型定义

```typescript
// 形态转换单主实体
export interface StockConvertOrder {
  id: string; // 唯一标识
  convertOrderNo: string; // 单据编号
  stockCategory: StockCategory; // 存货类别
  sourcePledgeId?: string; // 关联质押单ID
  sourcePledgeNo?: string; // 关联质押单号
  warehouseId: string; // 监管仓库ID
  warehouseName: string; // 监管仓库名称
  status: ConvertOrderStatus; // 单据状态
  totalInputVal: number; // 投入总货值
  totalOutputVal: number; // 产出总货值
  valueDiff: number; // 货值差额
  coverageRatio?: number; // 转换后质押率
  isHighRisk: boolean; // 是否高风险告警
  riskWarningReason?: string; // 高风险告警原因
  approvalInstanceId?: string; // 审批流实例ID
  remark?: string; // 备注说明
  inputs: StockConvertInputItem[]; // 投入物明细
  outputs: StockConvertOutputItem[]; // 产出物明细
  createdAt: string; // 创建时间
  createdBy: string; // 创建人
  updatedAt: string; // 更新时间
  updatedBy: string; // 更新人
}

// 投入物明细实体
export interface StockConvertInputItem {
  itemId: string; // 明细项ID
  convertOrderId: string; // 关联转换单ID
  sequenceNo: number; // 行号
  stockId: string; // 关联存货ID
  skuCode: string; // 物料SKU编码
  skuName: string; // 物料名称
  specification?: string; // 规格型号
  unit: string; // 计量单位
  stockStatus: StockStatus; // 当前库存状态
  quantity: number; // 投入数量
  unitPrice: number; // 原料单价
  totalVal: number; // 投入金额小计
}

// 产出物明细实体
export interface StockConvertOutputItem {
  itemId: string; // 明细项ID
  convertOrderId: string; // 关联转换单ID
  sequenceNo: number; // 行号
  skuCode: string; // 物料SKU编码
  skuName: string; // 产出物料名称
  specification?: string; // 规格型号
  unit: string; // 计量单位
  expectedQuantity: number; // 预估产出数量
  actualQuantity?: number; // 实收入库数量
  marketPrice: number; // 行情基准单价
  priceSource: string; // 行情价格来源
  totalVal: number; // 预估产出金额
  actualTotalVal?: number; // 实收入库金额
}

// 枚举定义
export enum StockCategory {
  FREE = 'FREE', // 普通存货
  PLEDGED = 'PLEDGED' // 抵质押存货
}

export enum ConvertOrderStatus {
  DRAFT = 'DRAFT', // 草稿
  PENDING_APPROVAL = 'PENDING_APPROVAL', // 待审批
  PROCESSING = 'PROCESSING', // 在产/加工中
  AUDIT_HANG = 'AUDIT_HANG', // 稽核挂起
  COMPLETED = 'COMPLETED', // 已完成
  CANCELLED = 'CANCELLED' // 已取消
}

export enum StockStatus {
  NORMAL = 'NORMAL', // 正常自由库存
  PLEDGED = 'PLEDGED', // 质押监管中
  IN_WARRANT = 'IN_WARRANT' // 仓单中
}
```
