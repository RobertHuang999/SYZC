## 二、即时库存计算规则

### 2.1 现存（On Hand）

| 规则ID | 规则 |
| :--- | :--- |
| C01 | `现存 = 期初库存 + Σ入库流水数量 − Σ出库流水数量`，维度 = **商品编码 + 仓库编码**（一期不含批次）。 |
| C02 | 入库流水：`变动方向 = IN` 的流水数量之和。 |
| C03 | 出库流水：`变动方向 = OUT` 的流水数量之和。 |
| C04 | 期初来源：系统设置 · 期初初始化；未录入则期初 = 0。 |
| C05 | 任一流水写入失败则来源单据确认回滚，保证现存与流水一致。 |

**公式验证示例**：

```
现存 = 期初 + 所有入库 − 所有出库
```

### 2.2 占用（Allocated）

| 规则ID | 规则 |
| :--- | :--- |
| C11 | `占用` = 满足以下条件的销售订单明细数量之和：订单状态 ∈ {待出库, 部分出库}，且该行「未出库数量」> 0，按 **商品 + 仓库** 汇总。 |
| C12 | **零售单、采购订单不产生占用**；零售成交直接扣现存（context/06 RS-02）。 |
| C13 | 销售出库单确认后：现存减少，同时释放对应占用（未出库减少）。 |
| C14 | 销售订单驳回或取消且从未出库：占用归零。 |

### 2.3 可用（Available）

| 规则ID | 规则 |
| :--- | :--- |
| C21 | 计算值：`可用_raw = 现存 − 占用`。 |
| C22 | 展示值：`可用 = max(0, 可用_raw)`。 |
| C23 | 当 `可用_raw < 0` 时，列表「可用」列展示 `0`，并展示预警辅助信息「占用超过现存，请核对订单」（Banner 或行内图标）。 |

### 2.4 实时性

| 规则ID | 规则 |
| :--- | :--- |
| C31 | 用户查询时读取**已提交事务**后的最新余额，延迟目标 < 3 秒（同库读写）。 |
| C32 | **非定时快照**：不得用昨日 T+1 表作为本页唯一数据源。 |

## 三、库存预警规则

| 规则ID | 规则 |
| :--- | :--- |
| W01 | 仅当商品档案「安全库存」> 0 且已维护时参与预警。 |
| W02 | 当 `现存 ≤ 安全库存` 时，`库存预警 = 低于安全库存`（`LOW`）。 |
| W03 | 否则 `库存预警 = 正常`（`NONE`）。 |
| W04 | 安全库存未维护时，不展示预警 Tag，不参与筛选。 |
| W05 | 一期**不自动**生成补货单、不推送消息（context/07 二期「安全库存预警」）；本页仅视觉 Tag，数值来源为《商品档案字段清单》「安全库存」。 |

## 四、权限规则

| 规则ID | 规则 |
| :--- | :--- |
| P01 | 模块权限：「库存管理 · 即时库存查询 · 查看」。 |

## 五、筛选逻辑规则

| 规则ID | 规则 |
| :--- | :--- |
| F01 | 进入页面默认：`不显示零库存 = 开`；自动加载第一页数据。 |
| F02 | 点击「搜索」或切换「不显示零库存」均刷新列表，页码重置为 1。 |
| F03 | 商品、仓库、批次、现存上下限之间为 **AND** 关系。 |
| F04 | `不显示零库存 = 开` → 过滤 `现存 ≤ 0`；= 关 → 展示 `现存 ≤ 0` 行，现存=0 灰色，现存<0 红色。 |
| F05 | 现存下限、上限同时填写时，须 下限 ≤ 上限，否则 Toast「库存范围设置不正确」。 |
| F06 | 仅填下限时：`现存 ≥ 下限`；仅填上限时：`现存 ≤ 上限`。 |
| F07 | 批次号筛选：一期无批次数据时，输入任意非空批次返回空列表。 |
| F08 | 默认排序：仓库编码 ASC → 商品编码 ASC；支持用户点击列头切换现存/可用排序。 |

## 六、展示与导出规则

| 规则ID | 规则 |
| :--- | :--- |
| D01 | 三口径同屏：现存、占用、可用列不可隐藏。 |
| D02 | 预警 Tag 颜色：低于安全库存 = 橙色。 |
| D03 | 导出文件名：`即时库存_{YYYYMMDD_HHmmss}.xlsx`。 |
| D04 | 导出行数上限 50,000，超出提示缩小范围。 |
| D05 | 空列表：「暂无库存数据」或「暂无符合条件的库存，请调整筛选条件」。 |
