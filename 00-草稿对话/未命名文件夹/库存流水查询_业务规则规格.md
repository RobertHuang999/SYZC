# 库存流水查询 业务规则规格

> **文档定位**：库存流水查询的权限规则、数据范围、筛选逻辑、展示规则的唯一定义来源。页面 Demo PRD 与流程推演只引用本文件，不重复定义规则本体。
>
> **参考文档**：《库存流水查询主PRD》《库存流水查询字段清单》《context/07》《context/08》
>
> **版本**：V1.0 | 2026-05-26

---

## 一、能力定位

| 项目 | 内容 |
| :--- | :--- |
| 页面类型 | 只读查询列表 |
| 核心职责 | 多维度检索库存变动流水，支持导出与来源单据跳转 |
| 状态机 | **无** |
| 数据写入 | 仅系统在执行层确认 / 零售成交时写入，本模块无写操作 |

## 二、权限规则

### 2.1 模块权限

| 规则ID | 规则 |
| :--- | :--- |
| P01 | 用户须具备「库存管理 · 库存流水查询 · 查看」权限方可进入菜单。 |
| P02 | 「导出」为独立子权限「库存流水查询 · 导出」；无权限时工具条不展示导出按钮。 |
| P03 | 跳转来源单据须同时具备对应单据模块的「查看」权限，否则来源单号以只读文本展示。 |

### 2.2 数据范围规则

| 角色 | 数据范围 | 规则ID |
| :--- | :--- | :--- |
| 仓管 | `仓库 IN 用户管辖仓库列表` | P11 |
| 采购员、内勤、财务、管理员 | 全部仓库 | P12 |
| 未配置管辖仓库的仓管 | 等同「无数据」，列表为空，顶部 Banner：「未分配仓库权限，请联系管理员」 | P13 |

**管辖仓库判定**：取仓库档案「负责人」= 当前用户，或系统设置中为用户配置的仓库数据权限列表（一期采用模块级+仓库列表配置，不做行级动态 SQL 说明）。

## 三、筛选逻辑规则

### 3.1 触发条件

| 规则ID | 规则 |
| :--- | :--- |
| F01 | 点击「搜索」时校验：下列 **至少一项** 成立——商品已选、仓库已选、来源单据号非空、业务日期已选、来源单据类型≠「全部」、变动方向≠「全部」。 |
| F02 | 不满足 F01 时，不发起查询，Toast：「请至少选择一个查询条件」。 |
| F03 | 点击「重置」清空所有查询条件，不自动发起查询。 |
| F04 | 进入页面**不自动加载**列表数据，避免无条件下全表扫描。 |

### 3.2 各条件组合逻辑

| 规则ID | 规则 |
| :--- | :--- |
| F11 | 多条件之间为 **AND** 关系。 |
| F12 | **商品**：精确匹配 `商品编码`；未选则不限制商品。 |
| F13 | **仓库**：精确匹配 `仓库编码`；须落在用户数据权限范围内，否则忽略该条件并提示无权限（或整单无结果，实现取并集：无权限仓库不可选）。 |
| F14 | **来源单据类型**：选具体类型时 `来源单据类型 = 选中值`；选「全部」不限制。 |
| F15 | **来源单据号**：精确匹配；若同时选了单据类型，则类型与单号前缀须一致（如类型=采购入库，单号须以 `PI` 开头），否则返回空集。 |
| F16 | **变动方向**：`IN` / `OUT` 过滤；「全部」不限制。 |
| F17 | **业务日期**：`业务时间` 的日期部分 ∈ [开始日期 00:00:00, 结束日期 23:59:59]；仅选开始或仅选结束视为开放区间一端。 |
| F18 | 日期跨度 > 366 天时阻断，Toast：「查询时间范围不能超过一年」。 |

### 3.3 排序与分页

| 规则ID | 规则 |
| :--- | :--- |
| F21 | 默认排序：`业务时间 DESC`，其次 `流水号 DESC`。 |
| F22 | 分页：默认每页 20 条，可选 20/50/100。 |
| F23 | 切换页码不重置查询条件；修改条件后搜索，页码重置为 1。 |

## 四、展示与导出规则

| 规则ID | 规则 |
| :--- | :--- |
| D01 | **变动数量展示**：`变动方向=IN` 时展示 `+{变动数量}`；`OUT` 时展示 `-{变动数量}`。 |
| D02 | **来源单据类型**列表展示中文：采购入库、销售出库、零售、调拨、盘点、报损、采购退货出库。 |
| D03 | **导出**：导出当前筛选条件下全部记录（忽略分页）；列与列表默认列一致；文件名 `库存流水_{YYYYMMDD_HHmmss}.xlsx`。 |
| D04 | 导出行数 > 50,000 时阻断，Toast：「结果过多，请缩小筛选范围后重试」。 |
| D05 | 无数据时：表格区展示插图 +「暂无符合条件的库存流水，请调整筛选条件」。 |
| D06 | 查询超时（>30s）时 Toast：「查询超时，请缩小时间范围或增加筛选条件」。 |

## 五、流水写入规则（供研发对账，查询页只读）

> 本模块不写入数据；以下规则保证「查到的数据」与库存底账一致。

| 规则ID | 规则 |
| :--- | :--- |
| W01 | 写入时机 = 来源单据状态变为「已确认」或零售单「已成交」的同一事务内。 |
| W02 | 幂等键 = `来源单据号 + 来源明细行ID + 变动方向 + 仓库编码`（调拨调出/调入各一条）。 |
| W03 | 写入失败则来源单据确认**整体回滚**，不允许「库存已变、流水缺失」。 |
| W04 | 商品/仓库展示字段取写入时刻快照，后续档案变更不刷新历史流水。 |
