# SYZC 两页大屏设计方案与可视化提示词

> 文档类型：大屏设计方案草稿  
> 版本：V1.0  
> 创建日期：2026-08-04  
> 适用范围：预警大屏、价格趋势大屏  
> 数据范围：总机构视角，可按机构、仓库、货主筛选  
> 设计技术建议：Vue 3 + ECharts + Element Plus  

## 1. 设计结论

两页大屏保留，但必须明确页面职责：

| 页面 | 核心职责 | 不应承担的内容 |
| --- | --- | --- |
| 预警大屏 | 识别当前未解除风险、定位风险对象、推动处置 | 经营统计、纯操作流水、无风险的人员信息 |
| 价格趋势大屏 | 观察押品价格、库存价值、融资覆盖和经营变化 | 设备告警明细、主体诉讼明细、人工安防事件 |

预警大屏使用“风险事件”作为统一展示对象；价格趋势大屏使用“品类、价格、库存、押品价值、融资余额”作为统一分析对象。所有指标都必须显示统计时间、数据范围和数据来源。

## 2. 共享设计规范

### 2.1 页面尺寸与视觉层级

- 目标分辨率：`1920 × 1080`，兼容 `1366 × 768`。
- 页面采用深色监管驾驶舱风格，背景使用深蓝黑，不使用大面积渐变和装饰性光球。
- 主色：蓝色表示正常或信息，橙色表示关注，红色表示高风险，绿色仅表示正常状态。
- 所有图表标题使用中文，单位必须紧跟数值展示。
- 页面顶部固定显示：机构范围、仓库范围、最后更新时间、数据状态、自动刷新开关。
- 卡片圆角不超过 `8px`，不使用嵌套卡片。
- 图表只展示决策所需信息，避免同时出现多个相同含义的指标。

### 2.2 统一状态

| 状态 | 中文名称 | 颜色 | 说明 |
| --- | --- | --- | --- |
| `NORMAL` | 正常 | 绿色 | 指标未命中阈值，事件已关闭 |
| `NOTICE` | 关注 | 橙色 | 接近阈值或需要人工复核 |
| `HIGH` | 高风险 | 红色 | 已命中高风险规则，存在处置要求 |
| `PROCESSING` | 处理中 | 蓝色 | 已分派但尚未完成处置 |
| `CLOSED` | 已关闭 | 灰色 | 已完成处置，仅保留历史记录 |
| `NO_DATA` | 暂无数据 | 灰色 | 没有配置、没有数据或数据不适用 |

### 2.3 统一数据新鲜度

每个模块显示自身数据时间，不用页面刷新时间代替业务数据时间。

```text
行业价格：2026-08-04 14:30:00｜来源：外部价格接口
设备状态：2026-08-04 14:31:08｜来源：物联平台
押品风险：2026-08-04 14:30:00｜来源：风控计算
库存数据：2026-08-04 14:00:00｜来源：库存台账
```

## 3. 页面一：预警大屏

### 3.1 页面定位

页面标题：`存货监管风险预警大屏`

页面目标：在首屏识别最严重的风险、风险所在仓库和押品对象，并能继续查看预警详情或进入处置页面。

### 3.2 页面布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 存货监管风险预警大屏    机构范围｜仓库范围｜最后刷新时间｜数据状态              │
├────────────┬────────────┬────────────┬────────────┬──────────────────────────┤
│ 未解除预警  │ 高风险预警  │ 今日新增    │ 最久未处理  │ 离线设备仓库             │
├──────────────────────────────┬──────────────────────────────┬───────────────┤
│ 押品与价格风险                │ 设备与门禁风险                │ 主体与安防风险 │
│ 质押率/价值/监管时长           │ 在线率/传感器/门禁异常         │ 主体变更/诉讼/人工事件 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 未解除风险事件时间线：风险等级｜事件｜对象｜位置｜触发时间｜实际值｜阈值｜处理状态 │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 顶部指标

| 指标 | 口径 | 展示要求 |
| --- | --- | --- |
| 未解除预警 | 当前状态不为`CLOSED`的风险事件数 | 点击后按风险等级筛选下方时间线 |
| 高风险预警 | 当前状态为`HIGH`的风险事件数 | 红色突出，显示环比变化 |
| 今日新增 | 今日 `00:00:00` 至当前新生成的风险事件数 | 按系统时区统计 |
| 最久未处理 | 当前未关闭事件中，当前时间减触发时间的最大值 | 展示小时或天数 |
| 离线设备仓库 | 至少有一台有效设备处于离线状态的仓库数 | 点击后筛选设备与门禁风险 |

### 3.4 押品与价格风险模块

| 子模块 | 展示内容 | 规则 |
| --- | --- | --- |
| 质押率升高 | 订单号、货主、当前质押率、上期质押率、升幅、阈值 | 质押率必须基于有效押品价值和融资余额计算 |
| 押品价值下降 | 品类、押品货值、当前价、上期价、跌幅、价格时间、价格来源 | 外部行业参考价与机构评估价分开显示 |
| 监管时长异常 | 单号、监管开始时间、已监管时长、目标时长、超时天数 | 没有目标时长时只能显示“监管时长较长”，不能标记为超时 |
| 解押异常 | 今日解押笔数、金额、异常解押事件 | 普通解押属于业务动态，不计入预警总数 |

#### 核心计算口径

```text
质押率 = 融资余额 ÷ 有效押品评估价值 × 100%
押品价值变化率 = (当前有效价值 - 上期有效价值) ÷ 上期有效价值 × 100%
价格跌幅 = (当前参考价 - 对比时点参考价) ÷ 对比时点参考价 × 100%
监管超时天数 = 当前时间 - 监管开始时间 - 配置的目标监管时长
```

有效押品价值优先使用最新生效的机构评估价；没有机构评估价时，展示行业参考价并标记“非正式评估值”。

### 3.5 设备与门禁风险模块

| 子模块 | 展示内容 | 当前数据基础 | 必须补充 |
| --- | --- | --- | --- |
| 设备离线 | 设备名、设备类型、仓库、具体位置、最后心跳、离线时长 | 物联设备字段、设备状态 | 离线阈值、最后心跳时间 |
| 温感/烟感/火灾 | 设备名、实时值、阈值、持续时长、位置、处置状态 | 设备预警类型、预警内容、预警时间 | 实时传感器值、阈值、持续时间 |
| 门禁密码错误 | 仓库、位置、时间、失败次数、认证方式、人员、抓拍图 | 门禁事务记录 | 认证方式、认证结果、连续失败次数 |
| 人员/车辆异常 | 事件类型、仓库、位置、抓拍时间、证据、处置状态 | 当前资料未确认 | 摄像头算法事件或人工上报接口 |

设备离线不能仅依据列表中的“离线”状态判断，必须使用“当前时间 - 最后心跳时间”与离线阈值比较。

### 3.6 主体与安防风险模块

| 子模块 | 展示内容 | 设计要求 |
| --- | --- | --- |
| 主体变更 | 主体名称、变更类型、变更日期、影响订单、来源、状态 | 必须绑定主体ID，不能只存文本 |
| 诉讼事件 | 主体名称、立案/公告日期、案由、影响订单、来源、处置状态 | 需要有效期和来源附件 |
| 货架倒塌 | 仓库、库位、上报时间、影响范围、现场照片、是否阻断作业 | 人工事件，必须有处置状态 |
| 消防设施过期 | 设施名称、仓库、到期日、责任人、状态 | 需要消防设施台账 |
| 仓库管理员 | 当日管理员、值班时段、联系电话 | 作为运营信息，不计入风险事件 |

主体风险和安防事件都要显示“来源”和“当前状态”，不能把人工录入文本直接当成实时风险。

### 3.7 门禁事务时间线

按时间倒序展示最近事件，建议字段如下：

| 字段 | 说明 |
| --- | --- |
| 仓库名称 | 绑定仓库名称 |
| 库位/具体位置 | 门禁设备所在位置 |
| 发生时间 | 事件发生时间，精确到秒 |
| 认证方式 | 密码、人脸、远程开门等标准枚举 |
| 认证结果 | 成功、失败、超时、设备异常 |
| 操作员/人员 | 关联账号或识别人员 |
| 事务名称 | 开门、关门、密码错误等 |
| 抓拍证据 | 设备抓拍图，有则展示缩略图 |

现有门禁记录中的“事务名称、说明、人员、设备抓拍图、时间”可作为基础，但不能依赖事务名称推断认证方式和认证结果。

### 3.8 风险事件统一字段

```text
eventId              风险事件ID
domain               风险域：押品、价格、设备、门禁、货物、主体、安防
eventType            事件类型
severity             风险等级
subjectType          对象类型：订单、押品、设备、仓库、主体、库存批次
subjectId            对象ID
subjectName          对象名称
warehouseId          仓库ID
locationName         具体位置
triggeredAt          触发时间
actualValue          实际命中值
thresholdValue       配置阈值
triggerReason        触发原因
status               未处理、处理中、已关闭
handler              处理人
handledAt            处理时间
source               数据来源
evidence             证据附件或抓拍图
```

### 3.9 预警大屏交互状态

| 状态 | 页面反馈 |
| --- | --- |
| 正常 | 模块显示正常数量和最近更新时间 |
| 无数据 | 显示“当前范围暂无数据”，不显示虚假0值 |
| 部分接口失败 | 仅对应模块显示“数据获取失败”，其他模块继续展示 |
| 数据延迟 | 显示数据时间和“数据可能延迟”，不隐藏旧数据 |
| 事件点击 | 打开风险详情，显示阈值、实际值、来源、处置记录 |
| 自动刷新 | 刷新中显示状态，禁止重复请求 |

## 4. 页面二：价格趋势大屏

### 4.1 页面定位

页面标题：`押品价格与资产经营分析大屏`

页面目标：观察核心押品价格变化、价格波动对押品价值和融资覆盖的影响，并结合库存和当日业务动态判断资产风险。

### 4.2 页面布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 押品价格与资产经营分析大屏  机构｜仓库｜价格来源｜统计周期｜最后更新时间          │
├──────────────┬──────────────┬──────────────┬──────────────┬──────────────┤
│ TOP1品类      │ TOP2品类      │ TOP3品类      │ TOP4品类      │ TOP5品类      │
│ 当前价/涨跌幅 │ 当前价/涨跌幅 │ 当前价/涨跌幅 │ 当前价/涨跌幅 │ 当前价/涨跌幅 │
├─────────────────────────────────────────────┬──────────────────────────────┤
│ 近30日价格趋势：归一化指数折线图              │ 当前价格与业务价格对比表       │
├─────────────────────┬───────────────────────┼──────────────────────────────┤
│ 安全边际/覆盖率趋势    │ 品类库存占比/仓库库存分布 │ 30日波动率排名                 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 今日业务动态：新增质押｜解押｜入库｜出库｜巡库｜未解除异常                      │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 4.3 TOP5核心大宗商品

默认按当前在押押品货值排名，不按数量排名。

| 字段 | 展示内容 |
| --- | --- |
| 品类 | 大类、品类、规格 |
| 在押押品货值 | 元或万元，标明统计范围 |
| 当前有效价格 | 数值、单位、价格时间、价格来源 |
| 30日涨跌幅 | 当前价与30日前价格比较 |
| 月内高低点 | 30日最高价、最低价及日期 |
| 风险标识 | 价格下降、评估价缺失、数据过期等 |

如果业务必须按“在押数量”排名，必须增加单位筛选，不允许将吨、件、套混合排序。

### 4.4 30日价格趋势

主图使用归一化价格指数：

```text
归一化价格指数 = 当日价格 ÷ 30日前价格 × 100
```

主图展示不同品类的相对趋势；右侧或顶部展示各品类的绝对价格。每条曲线必须提供图例、单位、价格来源和最后更新时间。

缺少价格的日期不补零，使用断点或缺失标记；样本不足时显示“价格样本不足”。

### 4.5 当前品类价格与业务价格

不要把不同来源的价格合并为一个“业务价格”。建议使用对比表：

| 品类/规格 | 行业参考价 | 机构评估价 | 货品管理单价 | 当前采用价 | 价格来源 | 价格时间 | 差额 |
| --- | ---: | ---: | ---: | ---: | --- | --- | ---: |
| 电解铜/标准铜 |  |  |  |  |  |  |  |

字段定义：

- 行业参考价：外部价格接口提供，用于行情参考。
- 机构评估价：机构录入或接口同步，用于正式押品估值。
- 货品管理单价：货品主数据中的基础单价，不等于实时市场价。
- 当前采用价：按照业务规则实际参与押品价值计算的价格。

### 4.6 仓储成本与市场价格

建议拆成两个指标：

```text
综合成本金额 = 监管费用 + 仓储费用 + 利息成本 + 其他已确认成本
安全边际 = 有效押品价值 - 融资余额
覆盖率 = 有效押品价值 ÷ 融资余额 × 100%
```

图表展示：

- 左轴：仓储成本指数、市场价格指数，统一以统计周期首日为100。
- 右轴：安全边际或覆盖率。
- 下方占比：监管费用、利息成本、仓储费用、其他成本。

仓储成本、监管费率和利息成本当前资料未形成完整的统一口径，原型中必须标注为 Mock 数据或待接入数据，不能伪装成系统现值。

### 4.7 库存统计

| 图表 | 推荐口径 |
| --- | --- |
| 品类库存占比 | 默认按库存货值占比；支持切换到数量占比 |
| 仓库库存分布 | 横向条形图，按库存货值排序；支持数量/货值切换 |
| 总库存 | 展示总货值、按单位汇总的总数量；只有单位统一时才展示总吨位 |
| 在押库存 | 展示在押货值、在押数量、占总库存比例 |

如果存在吨、件、箱、套等混合单位，底部不得直接显示“总库存吨位”。

### 4.8 价格波动率

建议采用30日每日收益率标准差：

```text
日收益率 = (当日价格 - 前一交易日价格) ÷ 前一交易日价格
30日波动率 = 30日内日收益率的标准差
```

使用横向条形图或热力矩阵展示各品类，不再增加一张重复的价格折线图。展示样本天数，样本不足时标记“样本不足”。

### 4.9 今日业务动态

| 指标 | 统计规则 |
| --- | --- |
| 新增质押 | 今日审批通过或正式开立的抵质押单笔数、融资金额、押品货值 |
| 解押/解抵 | 今日成功完成的解押业务笔数、金额、押品货值 |
| 入库 | 今日入库完成的数量，按计量单位汇总 |
| 出库 | 今日出库完成的数量，按计量单位汇总 |
| 巡库检查 | 今日已完成的巡库/巡检次数 |
| 异常事件 | 今日新增事件数、当前未解除事件数分开统计 |

所有“今日”指标按系统时区的 `00:00:00` 至当前时间计算，业务单据必须按完成状态统计，不能按创建状态统计。

## 5. 数据准备分级

| 等级 | 内容 | 处理方式 |
| --- | --- | --- |
| 可直接原型化 | 押品列表、押品预警、设备列表、设备预警、门禁记录、库存货值、行业价格字段 | 使用真实字段名设计 Mock 数据 |
| 可计算后原型化 | 质押率趋势、押品价值变化、TOP5、库存占比、今日业务动态、设备离线时长 | 先确定计算口径，再生成 Mock 数据 |
| 必须补字段 | 目标监管期限、门禁认证方式、货物有效期、消防设施到期日、主体风险事件、成本和利息明细、设备实时值 | 原型中标注“待接入”或“Mock” |
| 当前不能直接承诺 | 人员/车辆算法异常、物联网识别货物形态变化 | 必须明确算法或人工上报数据源 |

## 6. 可视化生成总提示词

```text
你是一名资深B端供应链金融与仓储监管产品设计师，请基于以下要求生成一个可交互的高保真数据大屏原型。

项目：SYZC供应链金融存货监管系统。
技术：Vue 3 Composition API、ECharts、Element Plus，页面为1920×1080大屏，支持1366×768缩放。
语言：所有界面文字使用简体中文，不使用英文占位文案，不使用无意义的Lorem Ipsum。
视觉：深色监管驾驶舱风格，深蓝黑背景，蓝色表示信息，绿色表示正常，橙色表示关注，红色表示高风险；卡片圆角不超过8px，不使用装饰性渐变光球，不使用与业务无关的地图或3D模型。
交互：支持机构、仓库、货主、时间范围筛选；支持自动刷新；显示每个模块的数据更新时间和数据来源；支持点击图表或风险事件查看详情；支持正常、无数据、接口失败、数据延迟、加载中五种状态。
数据：使用真实供应链金融业务Mock数据，包括电解铜、螺纹钢、铝锭、聚乙烯、豆粕、仓库名称、抵质押单号、设备编码、库位编号、货主企业名称、预警等级和处理状态。
```

## 7. 预警大屏专用提示词

```text
请生成“存货监管风险预警大屏”，重点不是展示经营数据，而是帮助风控人员快速发现未解除风险并定位处置对象。

- 普通门禁事务不计入预警总数，只有失败、异常或未授权事件计入风险。
- 今日仓库管理员属于运营信息，不放入风险统计。
```

## 9. 验收清单

### 9.1 预警大屏

- [ ] 首屏可以区分高风险、关注、处理中和已关闭。
- [ ] 所有预警都能定位到订单、押品、设备、仓库或库存批次。
- [ ] 质押率预警显示实际值、历史值、阈值和触发原因。
- [ ] 监管超时不会在缺少目标期限时误报。
- [ ] 设备离线显示最后心跳和离线时长。
- [ ] 门禁记录显示认证方式和认证结果，不依赖文本猜测。
- [ ] 主体风险和人工安防事件显示来源、附件、状态和有效期。
- [ ] 普通门禁事务、仓库管理员不计入风险总数。
- [ ] 具备无数据、数据延迟和接口失败状态。

### 9.2 价格趋势大屏

- [ ] TOP5排名口径明确为在押货值或限定单位后的数量。
- [ ] 30日趋势使用归一化指数，不直接叠加不同单位的绝对价格。
- [ ] 行业参考价、机构评估价、货品管理单价分开展示。
- [ ] 安全边际和覆盖率使用同一统计范围、同一时间点的价值与融资余额。
- [ ] 混合计量单位时不显示错误的总吨位。
- [ ] 波动率展示算法、统计周期和样本数量。
- [ ] 今日业务动态只统计业务完成记录。
- [ ] 成本和利息数据明确标注真实数据、Mock数据或待接入数据。
