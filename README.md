# SYZC 供应链金融存货监管系统

SYZC 是森云科技面向资金方、仓储/监管企业、借款企业、核心企业及平台运营方建设的供应链金融存货监管系统。系统以物理库存为事实底座，连接数字仓单、货权、融资、风控、审批和数据驾驶舱，实现“货、仓、金”协同与全路径审计。

## 工作规范

- 输出使用简体中文；需求拆解遵循 MECE，单项任务控制在 2 个工作日以内。
- 货权、资金和库存相关操作必须具备强一致性、幂等性、防并发锁和审计日志。
- 风险预警按类型、配置阈值和实际命中值展示，并为每条规则配置通知、处置或阻断动作。
- Vue 原型使用 Vue 3 Composition API 与 Element Plus；Mock 数据贴近真实供应链金融业务。
- 正式文档进入 `02-PRD文档/`，过程材料进入 `00-草稿对话/`。

## 交付链路

```text
背景基线 → 需求定义 → 流程/字段设计 → PRD → 前端原型 → 评审与验收
```

每项交付都应回链到功能板块、核心场景、业务单据、角色权限、指标口径和审计要求。
