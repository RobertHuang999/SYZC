# 第2个提示词：按模块采集页面内容

请使用当前已登录的浏览器，按模块采集页面上实际看到的内容。

本阶段只记录字段、Tab、按钮、状态、关联入口和页面反馈，不下业务结论，不绘制完整状态机。

## 一、输入

以下三种方式任选或组合：

### 方式A：读取第1步页面地图

```text
页面地图：<系统采集>/01-系统菜单与页面地图.json
目标模块或页面大类：<例如：入库模块>
可选页面ID：<例如：P-INB-001、P-INB-002>
输出目录：<系统采集>
```

优先读JSON；没有JSON时读同目录Markdown。只处理目标范围内的页面。

### 方式B：直接提供URL

```text
目标URL：
- <URL 1>
- <URL 2>
目标模块或页面大类：<可选>
输出目录：<系统采集>
```

只用用户给出的URL，不自行扩展。无页面地图时，页面ID用临时编号如`P-DIR-001`，并注明「页面地图未提供」。

### 方式C：只给模块名

```text
目标模块或页面大类：<例如：入库模块>
输出目录：<系统采集>
```

在当前浏览器可见菜单中定位该模块，只展开目标分支，不做全系统普查。名称无法唯一匹配时列出候选并标「待确认」，不要自行挑选。定位不到就记录原因并停止，不猜URL。

### 处理顺序

1. 用户明确给出的URL或页面ID优先；
2. 其次按页面地图筛选；
3. 再按当前菜单定位模块；
4. 都没有时，先询问目标范围。

## 二、只读边界

1. 不执行新增、删除、保存、提交、审核、付款、收货、发运、导入、导出或批量处理。
2. 不退出登录，不切换账号、租户、组织、仓库、语言或时区。
3. 可以打开Tab、折叠区、下拉选项、只读弹窗和抽屉查看，看完关闭；不选会改变上下文的选项。
4. 可能改数据的按钮只记录名称和可见状态，不点击。
5. 不猜字段含义或状态流转条件；说不清的写入「待确认问题」。
6. 单页加载异常时记录现象，不反复重试。

## 三、逐页采集

对范围内每个页面记录：来源、页面ID、名称、模块、菜单路径、URL模板、实际URL、观察时间、账号或角色、租户、进入时的默认状态。

再按页面类型采集：

| 页面类型 | 重点看什么 |
|---|---|
| 列表页 | 查询条件、筛选项、列表列、状态标签、分页、批量/行内操作、详情/编辑/创建入口 |
| 新增/编辑/表单页 | 字段分组、字段名、控件类型、必填、可见状态、选项、联动、校验提示、保存或提交按钮名称；不填写、不提交 |
| 详情页 | 展示字段、单据状态、操作按钮、Tab、日志、关联单据、附件、只读弹窗 |
| 看板/报表/配置/扫码页 | 筛选、指标或表格列、Tab、配置项、启停、作用范围、页面反馈；不改配置、不执行扫码 |

补充约定：

- Tab和折叠区逐个查看一次，打不开的写原因；
- 下拉只打开查看，不选择；选项过多时记可见项和大约总数；
- 行尾「更多」最多看第1行一次；
- 关联入口只记名称和目标，不继续超出本次范围。

### 状态与操作

页面上出现状态时，只记当前看到的：

| 当前状态 | 出现位置 | 当前可见操作 | 本次是否点击 | 出现条件 | 证据状态 |
|---|---|---|---|---|---|

「本次是否点击」只写：`未点击`或`已打开只读入口`。

不为验证流转去点提交、审核、下载、撤销。没观察到的状态变化写「待核实」，不要补画状态机。

## 四、输出

每个页面一份记录，并出一份索引：

```text
<系统采集>/02-页面采集/<目标范围>/<pageId>-<页面名>.md
<系统采集>/02-页面采集/<目标范围>/00-采集索引.md
```

文件名去掉斜杠、冒号等不兼容字符。

## 五、交付前检查

1. 页面是否来自地图、用户URL或当前菜单中的目标模块？
2. 字段、按钮、Tab、状态是否保留页面原名？
3. 是否标注了出现条件，未看到的内容是否标「待核实」？
4. 是否没有执行会改数据的操作？
5. 采集索引与单页文件是否一致？

完成后停止。
