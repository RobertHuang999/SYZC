# 业务系统基准资料梳理

## 目标

将用户授权的业务后台页面整理为一个模块目录下的三份 Markdown 文档：

- `字段清单.md`：说明页面中有哪些字段以及字段如何展示。
- `页面说明.md`：说明页面结构、查询条件、表格列、页面操作和异常状态。
- `业务规则.md`：说明字段校验、状态流转、权限限制和业务约束。

三份文档必须使用页面编号和字段 ID 相互关联，避免重复维护同一字段定义。

## 安全边界

- 仅处理用户明确授权的业务系统。
- 登录、验证码、多因素认证和单点登录必须由用户本人完成。
- 不读取、保存或输出密码、Cookie、Local Storage、Session Storage、浏览器配置和密钥。
- 不绕过登录、权限、验证码、风控或访问限制。
- 默认只读采集，不提交表单，不改变业务数据。
- 禁止点击删除、审批、放行、解押、提货授权、额度调整、状态变更等有副作用的操作。
- 遇到可能产生业务影响的按钮、弹窗或确认操作时，停止并请求用户确认。
- 身份证号、手机号、银行卡号和合同敏感信息只记录字段名称，示例值必须脱敏。

## 开始前

1. 确认业务系统地址、梳理范围、目标模块和期望输出位置。
2. 使用浏览器打开业务系统。
3. 如果页面要求登录，暂停操作并提示用户自行完成登录。
4. 用户明确回复“已登录，可以开始”后，才开始页面采集。
5. 记录系统名称、当前角色、租户（如页面可见）和采集时间。
6. 如果用户没有指定范围，先梳理菜单树，不直接遍历全部页面。

## 浏览器采集规则

- 浏览器操作必须遵循当前环境提供的浏览器控制规范。
- 优先读取页面中可见的标题、标签、占位符、表格表头、按钮名称、提示信息和校验文案。
- 不通过浏览器存储、网络凭据或会话文件获取信息。
- 页面跳转、加载或接口请求失败时，记录页面和错误信息，不反复提交请求。
- 检查分页、标签页、折叠区域、抽屉、弹窗和详情页，但不触发危险操作。
- 对新增或编辑页面，只读取控件定义，不填写会触发提交或联动副作用的数据。
- 可以读取已经展示的下拉、单选和多选选项；如果点击选项可能改变业务数据，则停止操作。
- 页面状态不明确、权限不足或出现二次确认时，保留当前状态并请求用户判断。

## 采集范围

按照以下顺序梳理：

1. 一级菜单、二级菜单、页面名称和页面路径。
2. 查询条件区域、查询按钮和重置按钮。
3. 列表表格列、排序、筛选、分页和行级操作。
4. 新增页、编辑页、详情页和查看抽屉。
5. 弹窗、分步表单、折叠区域和标签页。
6. 状态标签、状态流转和状态相关操作。
7. 空数据、加载中、加载失败、权限不足和字段校验状态。
8. 导入、导出、下载、打印和批量操作入口。

## 编号规则

- 页面编号格式：`模块缩写-PAGE-序号`，例如 `INV-PAGE-001`。
- 字段 ID 格式：`模块缩写-FIELD-序号`，例如 `INV-FIELD-001`。
- 页面名称、字段名称和字段编码无法确认时，不得编造，填写“未确认”。
- 同一业务字段在多个页面出现时，复用同一个字段 ID，并在页面字段表中引用它。

## 三份文档的写作要求

### 一、字段清单.md

只记录字段定义和页面上的字段表现，不重复描述完整业务流程。

至少包含：

- 字段 ID
- 所属页面
- 字段名称
- 字段编码
- 控件类型
- 数据类型
- 是否必填
- 是否可编辑
- 展示规则
- 枚举值
- 校验规则
- 来源
- 置信度
- 待确认事项

推荐表头：

| 字段 ID | 页面 | 字段名称 | 字段编码 | 控件类型 | 数据类型 | 必填 | 可编辑 | 展示规则 | 来源 | 置信度 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|

### 二、页面说明.md

只记录页面级内容，不重复展开每个字段的详细定义。

每个页面至少包含：

- 页面编号
- 页面名称和页面类型
- 页面目的
- 页面结构
- 查询条件
- 表格列
- 页面操作
- 页面跳转关系
- 空数据、加载失败和权限不足状态
- 危险操作的识别结果

推荐页面结构：

```markdown
## INV-PAGE-001 质押库存列表

### 页面目的

### 页面结构

### 查询条件

### 表格列

### 页面操作

### 异常状态
```

### 三、业务规则.md

只记录可验证的业务约束、状态流转和权限限制。

至少包含：

- 规则编号
- 规则名称
- 规则描述
- 触发条件
- 系统处理
- 例外情况
- 影响页面
- 影响字段 ID
- 来源和确认状态

状态流转和复杂业务流程使用 Mermaid 表达。例如：

```mermaid
flowchart LR
A[待监管] --> B[监管中]
B --> C[异常]
C --> D[已冻结]
C --> B
D --> B
```

## 来源和置信度

来源只能使用以下值：

- 页面明确展示
- 页面交互确认
- 接口或文档确认
- AI 推测
- 待人工确认

页面只能证明页面可见字段和交互表现，不能单独证明真实数据库字段、后端接口字段编码或完整权限模型。相关内容必须单独标注来源。

## 输出目录

将结果保存为以下结构：

```text
模块名称/
├── 字段清单.md
├── 页面说明.md
└── 业务规则.md
```

三份文档顶部使用统一元信息：

```yaml
模块: 质押库存管理
版本: v1.0
状态: 待评审
负责人: 待填写
采集时间: 2026-08-03
```

## 质量检查

输出前必须确认：

- 三份文档均已生成，并且模块名称、版本和采集时间一致。
- 页面编号和字段 ID 唯一且可相互引用。
- 字段清单没有混入大段页面流程说明。
- 页面说明没有重复维护字段校验规则。
- 业务规则均有来源、影响页面或待确认标记。
- 查询条件、表格列、详情字段、编辑字段和页面操作均已覆盖。
- 已记录空数据、加载失败、权限不足和校验错误状态。
- 危险操作只记录，不执行。
- 敏感信息已脱敏。
- 无法确认的内容没有被写成确定事实。

## 重要限制

浏览器页面采集适合建立页面基准资料。接口字段、数据库字段、真实权限和后端校验规则必须以授权的接口文档、接口响应、数据库字典或研发确认结果为准。
