# 05-移动端色彩与视觉系统规范

---

## 🎨 1. 风控与业务状态语义色 (Semantic Status Colors)

在供应链金融存货监管系统中，**状态颜色承载了强烈的风控指令含义**，必须严格遵循语义化标准，杜绝颜色滥用与前后矛盾：

| 业务状态 | 推荐颜色 | 适用场景 | 颜色代码 | 错误示范 |
| :--- | :--- | :--- | :--- | :--- |
| **正常 / 在库 / 已通过** | 翠绿色 (Emerald) | 正常质押中、正常在库、审批通过、IoT设备在线 | `#10b981` / `bg-emerald-50 text-emerald-700` | 用红色写“同意” |
| **流转中 / 处理中 / 待办** | 经典蓝 (Primary Blue) | 质押中、提货中、待我审批、已受理 | `#1875f0` / `bg-blue-50 text-blue-700` | 用灰色显示正常流程 |
| **预警 / 审核中 / 待处理** | 活力橙 (Amber / Orange) | 价格跌价预警、待审核、待复核、临期提醒 | `#f59e0b` / `bg-amber-50 text-amber-700` | 预警状态用绿色 |
| **风险 / 驳回 / 离线 / 熔断** | 警示红 (Rose / Red) | 跌破平仓线、巡检异常、审批驳回、设备离线 | `#ef4444` / `bg-rose-50 text-rose-700` | 拒绝/驳回用绿色 |
| **质押锁定 / 特殊监管** | 科技紫 (Indigo / Purple) | 仓单已锁定、司法冻结、特定第三方监管 | `#6366f1` / `bg-indigo-50 text-indigo-700` | 冻结状态用灰色(像废弃) |
| **已结清 / 已注销 / 已废弃** | 中性灰 (Slate) | 仓单已注销、单据已作废、历史归档 | `#64748b` / `bg-slate-100 text-slate-600` | 已注销还用亮蓝色 |

## 📱 2. 工作台 5 列应用网格色彩栅格

工作台采用 **每行 5 列等宽彩色圆角图标矩阵**，统一采用 12px 圆角方形底座 + 纯白高对比度图标：

```
┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐
│ [📦] │  │ [📄] │  │ [📁] │  │ [🛡️] │  │ [⬇️] │
│ 存货 │  │ 仓单 │  │ 货权 │  │ 证据 │  │ 入库 │
└──────┘  └──────┘  └──────┘  └──────┘  └──────┘
 经典蓝    活力橙    湖水蓝    警示红    深海蓝
```

* **主色分布标准**：
  * **主业务流（存货/仓单/出入库/移库）**：以 `#1875f0`（蓝）、`#fb8c00`（橙）、`#43a047`（绿）、`#e53935`（红）交替呈现，形成明晰的视觉节奏；
  * **风控预警（设备预警/押品预警/异常）**：统一采用 `#f57c00`（橙）、`#e53935`（红）；
  * **基础配置与系统设置**：采用稳重的 `#1875f0`（蓝）与 `#43a047`（绿）。

## 🔤 3. 移动端字体与间距栅格

* **基础字体**：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；
* **层级阶梯**：
  * **页面大标题**：`18px` / `font-bold`（如：工作台、业务办理）；
  * **卡片标题 / 单号**：`14px` / `font-semibold`；
  * **正文属性 / 关键指标**：`12px` / `font-medium`；
  * **辅助说明 / 时间戳 / 权限标签**：`10px ~ 11px` / `text-gray-400 ~ text-gray-500`；
* **间距栅格**：全页面遵循 **4px 栅格基数**（卡片内边距统一为 `12px` 或 `14px`，卡片外间距 `12px`）。
