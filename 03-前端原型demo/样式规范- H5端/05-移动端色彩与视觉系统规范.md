# 05-移动端色彩、字体与视觉系统规范

> 本章是 H5 的「地基」：主色、中性色、状态语义色、字号阶梯、圆角与间距。
> 页面结构见 [01-整体架构与导航规范](./01-移动端整体架构与导航规范.md)。

---

## 1. 交互主色

H5 的按钮、链接、选中态统一用 **Tailwind 的 `blue-600`（`#2563eb`）**，这也是工程里实际用得最多的蓝（`bg-blue-600` 141 处、`text-blue-600` 152 处）。

| 用途 | 取值 | 类名 |
| :--- | :--- | :--- |
| 主按钮底色 / 主链接文字 | `#2563eb` | `bg-blue-600` / `text-blue-600` |
| 按下态 | `#1d4ed8` | `active:bg-blue-700` |
| 选中浅底（胶囊、标签） | `#eff6ff` | `bg-blue-50` |
| 选中描边 | `#bfdbfe` | `border-blue-200` |
| 焦点圈 | 主色 20% 透明 | `focus:ring-2 focus:ring-blue-500/20` |
| 主按钮文字 | 白色 | `text-white` |

**统一走常量**：按钮、胶囊、吸底按钮的固定样式都在 `B端H5/src/shared/h5-ui-theme.ts`（`H5_PRIMARY`、`H5_PILL_PRIMARY`、`H5_DETAIL_BTN_PRIMARY` 等），新页面直接引用，不要手写一套新的蓝色按钮。

### 1.1 关于「品牌蓝 #1875f0」

规范旧版把 `#1875f0` 定为主色，但工程里只剩 **19 处**在用（底栏选中、工作台图标配色数组），正文交互清一色是 `blue-600`。

- **口径**：主色以 `blue-600` 为准。
- `#1875f0` 视为历史遗留色，只在底栏和工作台图标里出现；**新页面不要再用 `#1875f0`**。
- 收敛计划（含与 PC 主色 `#165dff` 的关系）写在 [README 已知偏差](./README.md) 里。

## 3. 状态语义色

状态承载风控含义，**同一状态在列表、详情、弹窗里必须同色**。统一用「浅底 + 同色描边 + 深一档文字」：

| 语义 | 用色 | 类名组合 | 典型场景 |
| :--- | :--- | :--- | :--- |
| 正常 / 已通过 / 已结案 / 在线 | 翠绿 Emerald | `bg-emerald-50 text-emerald-700 border-emerald-200` | 审批通过、预警已解除、设备在线 |
| 待处理 / 待审核 / 预警中 | 琥珀 Amber | `bg-amber-50 text-amber-700 border-amber-200` | 待我审批、预警待处置、临期提醒 |
| 公示中 / 特殊业务档 | 橙色 Orange | `bg-orange-50 text-orange-700 border-orange-200` | 未公示、公示中 |
| 驳回 / 高危 / 离线 / 强平 | 玫红 Rose | `bg-rose-50 text-rose-700 border-rose-200` | 审批驳回、跌破平仓线、设备离线 |
| 质押锁定 / 司法冻结 / 特殊监管 | 靛蓝 Indigo | `bg-indigo-50 text-indigo-700 border-indigo-200` | 仓单锁定、监管冻结 |
| 已结清 / 已作废 / 已注销 / 归档 | 中性灰 Slate | `bg-slate-100 text-slate-600 border-slate-200` | 单据作废、规则停用、已归档 |

规则：

1. 状态用**标签**，不要用纯色文字或整行变色。
2. 等级（预警等级、严重程度）颜色由业务字典给出（如 `event.severityColor`），页面只负责渲染色点/色块 + 名称，**禁止在页面里写死彩虹色**。
3. 「正常」不用蓝色表示——蓝色只代表「进行中/可操作」，绿色才代表「结果正常」。

### 3.1 单据流水状态的标准映射

入库、出库等单据的审核状态统一按下表取色（与 `RecordCard` 的 `statusTone` 一致）：

| 状态 | 取值 | 用色 |
| :--- | :--- | :--- |
| 待审核 | `PENDING` | 琥珀 `amber` |
| 审核中 | `PROCESSING` | 主色蓝 `blue` |
| 已通过 | `APPROVED` | 翠绿 `emerald` |
| 未通过 | `REJECTED` | 玫红 `rose` |
| 已撤销 | `WITHDRAWN` | 中性灰 `slate` |

出库单目前固定为「已通过」，按翠绿展示；类型胶囊（质押出库 / 普通出库等）**不参与语义配色**，统一中性描边。

## 4. 工作台 5 列图标网格

工作台是 H5 的视觉门面，结构固定：**每行 5 列等宽**，彩色圆角方形底座 + 白色线性图标 + 下方两行小字。

| 元素 | 规格 |
| :--- | :--- |
| 网格 | `grid grid-cols-5 gap-x-1 gap-y-3.5` |
| 图标底座 | `40px × 40px`、圆角 `12px`、白色图标 `20px`、`shadow-xs` |
| 文字 | `10px`、最多两行、居中 |
| 角标 | 右上角红色圆点徽标，`16px` 高、`9px` 字、白描边 |
| 分组卡 | 白底、圆角 `16px`、内边距 `14px`、组标题 `12px` 粗体 |

**配色规则**（按分组循环取色，见 `WorkspacePage` 的 `GROUP_ACCENT_COLORS`）：

| 分组 | 取色序列 |
| :--- | :--- |
| 仓储 | `#1875f0` `#f57c00` `#0288d1` `#e53935` `#1976d2` |
| 融资/监管 | `#1875f0` `#43a047` `#0288d1` `#1976d2` `#e53935` |
| 交易 | `#e53935` `#1e88e5` `#43a047` |
| 风控 | `#f57c00` `#e53935` `#43a047` `#1e88e5` |
| 结算 | `#1875f0` `#43a047` `#e53935` |
| 用户中心 | `#1875f0` `#0288d1` `#43a047` `#1976d2` |
| 配置管理 | `#1875f0` `#43a047` `#0288d1` `#1976d2` |

- **风控类只用橙、红**，不要用绿色，避免「预警」被看成「正常」。
- 新增工作台入口时，在该分组的取色序列里顺延取色，不要临时挑一个新颜色。

## 5. 字体与字号

### 5.1 首选字体：PingFang SC（苹方）

全站字体栈：

```text
"PingFang SC", -apple-system, BlinkMacSystemFont, "Microsoft YaHei", "Segoe UI", Roboto, sans-serif
```

- 已在 `@theme` 与 `@layer base` 两处统一声明，新增页面不要自带字体。
- `--font-mono` 同样被重定义成苹方，所以即使误写 `font-mono` 也不会变成等宽英文；但**业务单号、时间、数量仍然禁止主动写 `font-mono`**（工程里还有 1 处历史用法，改动时顺手去掉）。
- `tabular-nums`（等宽数字）**允许**：金额、吨数、时间列使用，字体仍是苹方。

### 5.2 字号阶梯

| 层级 | 字号 | 字重 | 用在哪 |
| :--- | :--- | :--- | :--- |
| 页面大标题 | `18px` | 粗体 | 四个 Tab 首页的标题栏（首页、我的目前是 16px，属历史不一致） |
| 关键单号 / 核心数值 | `16px` | 粗体 | 详情页顶部单号、首页指标数字 |
| 卡片 / 板块标题 | `14px` | 粗体 | `SectionCard` 标题、分组卡标题 |
| 正文 / 字段值 / 卡片主行 | `12px` | 常规或中等 | 详情字段、列表信息 |
| 辅助说明 / 时间戳 / 标签 | `10px`～`11px` | 常规 | 次要信息、角标 |

规则：

1. 一个页面里最多出现 4 档字号，别在一屏里凑出 5、6 种。
2. 标签（字段名）与值同字号时，**靠颜色区分层级**（标签次要灰、值主文本），不要靠缩小字号硬压。
3. 数字不要用等宽英文字体撑宽，金额、重量保留 PRD 规定的小数位。

## 6. 圆角与间距

### 6.1 圆角

| 元素 | 圆角 |
| :--- | :--- |
| 列表卡、详情板块、分组卡 | `12px`（`rounded-xl`） |
| 弹层内容块、摘要卡 | `12px`（`rounded-xl`） |
| 表单分组卡（`NativeInfoCard`）、按钮组、小方块 | `8px`（`rounded-lg`） |
| 工作台宫格分组卡（特例） | `16px`（`rounded-2xl`） |
| 胶囊按钮 / 状态胶囊 | 全圆 `rounded-full` |
| 工作台图标底座 | `12px` |

现状提醒：`rounded-xl`（12px）约 107 处、`rounded-2xl`（16px）约 30 处。**统一口径是 12px**：入库/出库记录卡已共用 `RecordCard`（12px），`H5_CARD` 也已改为 12px；工作台宫格分组卡保留 16px 作为特例。

### 6.2 间距

- 全站按 **4px 栅格**取间距。
- 列表页滚动区：左右 `14px`、上下 `12px`、卡片之间 `12px`。
- 卡片内边距：标准 `14px`（`p-3.5`）；紧凑信息块 `12px`。
- 卡片之间的间距**只给一次**：外层用 `space-y-3` 后，卡片不要再加 `mb-3`（现存部分列表存在双间距，改动时去掉其一）。
- 详情页板块之间 `12px`；表单分组之间 `12px`。

---

## 7. 深色模式

H5 没有深色模式，也没有切换入口。**新页面不写 `dark:` 变体。**

## 8. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 新页面用 `#1875f0` 当主色 | 用 `blue-600` 系列或直接引用 `h5-ui-theme` 常量 |
| 同一页面混用 `gray-500` 和 `#232D39/60` | 统一 `#232D39` 系列 |
| 预警状态用绿色 | 预警用琥珀，高危用玫红 |
| 冻结、锁定用灰色（看着像废弃） | 用靛蓝 |
| 页面里写死等级色 | 取字典色 |
| 列表卡再叠一层 `mb-3` | 间距只由外层 `space-y-3` 提供 |
| 金额、吨数用等宽英文字体 | 苹方 + `tabular-nums` |
| 一个页面出现六七种字号 | 控制 4 档以内 |
