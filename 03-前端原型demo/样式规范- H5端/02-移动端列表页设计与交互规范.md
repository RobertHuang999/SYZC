# 02-移动端列表页设计与交互规范

> 列表是 H5 用得最多的一类页面。本章把「筛选条 + 卡片列表」的写法定死。
> 外壳与滚动隔离见 [01-整体架构与导航规范](./01-移动端整体架构与导航规范.md)，色值与字号见 [05-色彩与视觉系统规范](./05-移动端色彩与视觉系统规范.md)。

---

## 1. 一屏结构

```text
标题栏 NavBar
筛选条（固定，不随列表滚动）        ← H5_FILTER_BAR
  ├─ 第一行：更多筛选按钮 + 搜索框
  └─ 第二行：横向滚动的下拉胶囊
列表滚动区（卡片）                  ← H5_LIST_SCROLL
```

- 筛选条与列表之间的分隔由筛选条的底边框提供，不要再加阴影或色块。
- 列表滚动区：左右 `14px`、上下 `12px`、卡片间距 `12px`（`space-y-3`）。
- 筛选条不随列表滚动，列表滚动时标题栏与筛选条都保持不动。

---

## 2. 筛选：两层结构

H5 不做 PC 那种「一行四个筛选项」，分两层：

### 2.1 第一层：首屏（搜索 + 常用条件）

**第一行**（左到右）：

1. 「更多筛选」图标按钮：`32px` 方形、圆角 `8px`、灰色漏斗图标；已选条件数 > 0 时右上角挂蓝色数量角标（`14px` 圆点、`9px` 白字）。
2. 搜索框：占满剩余宽度。

**第二行**：横向滚动的下拉胶囊，放 2～5 个最常用维度（状态、类型、仓库、货主等）。

```text
[▣ 更多筛选②] [ 请输入单号/货主/货物规格        🔍 ]
[预警状态 ▾] [预警类型 ▾] [全部仓库 ▾] →
```

### 2.2 第二层：更多筛选抽屉

- 点击「更多筛选」从**底部**弹出抽屉（`FilterDrawer`），最高占屏 80%，内部条件区可滚。
- 抽屉结构固定：标题「更多筛选」+ 关闭 → 条件区 → 底部「重置 / 确定」。
- 点「确定」后关闭抽屉并刷新列表；点「重置」只清抽屉内条件。
- **禁止**做成右侧滑出抽屉（旧规范写的是右侧，与实现不符）。

### 2.3 状态筛选怎么放

- 状态维度一般就是第一行的一个下拉胶囊（`DropdownFilterPill`）。
- 只有状态少（3～4 个）且高频切换的页面，才在抽屉内用胶囊芯片组（`rounded-full px-2.5 py-1 text-xs`）。
- **不要**在首屏做「多层 Tab + 多层下拉」叠三层，最多两层。

### 2.4 与 PC 的口径

- 筛选维度、字段名、下拉选项与 PC 保持一致；H5 只改承载方式（胶囊 + 抽屉），不减少筛选项。
- 同样遵守「草稿态 → 点确定/查询才生效」，**禁止输入即刷列表**。
- 例外：搜索框在部分列表页是边输边筛（`updateFilter` 同步 applied），这类页面必须在 PRD/标注里说明；新页面默认点查询才生效。

## 3. 控件样式

| 控件 | 规格 |
| :--- | :--- |
| 筛选条容器 | 白底、底部 1px 分割线、左右 `14px`、上下 `10px`、行间距 `8px` |
| 搜索框 | 高约 `34px`、圆角 `12px`、底 `#f4f5f7`、`12px` 字、聚焦时白底 + 蓝色焦点圈；有内容时右侧显示清除圆点 |
| 下拉胶囊（未选中） | `12px` 字、圆角 `8px`、上下 `6px` 左右 `10px`、底 `#232D39/5`、字 `#232D39/70` |
| 下拉胶囊（已选中） | 蓝底 `blue-50` + 蓝字 `blue-600` + `border-blue-200`，字重加粗，箭头变蓝并翻转 |
| 下拉面板 | 白底、圆角 `12px`、最大高 256px 内部滚动、最小宽 `150px`、最大宽 240px、带阴影 |
| 紧凑胶囊（一行等分） | 每个 `flex-1`、`11px` 字、左右 `6px`、文字超长省略 |
| 抽屉内胶囊芯片 | `rounded-full`、`px-2.5 py-1`、`12px` 字 |

胶囊行的三种排法：

1. **横向滚动**（默认）：不换行、可左右滑、隐藏滚动条。
2. **等分单行**：条件 3～4 个且都很短时，用 `H5_FILTER_PILL_ROW` + `compactRow`，每项等宽。
3. **抽屉内分组**：条件多时按「基础维度 → 状态/等级 → 仓库/时间」分组排，时间范围占一整行。

## 4. 列表卡片（标准结构）

移动端卡片统一采用 **「类型条 → 主信息 → 指标块 → 经办信息 → 操作行」** 五段：

```text
┌────────────────────────────────────────────┐
│ 入库·普通入库                          ⚠   │ ← 类型条（浅底、11px 次要色）
├────────────────────────────────────────────┤
│ [森] 森云科技有限公司  91xxxxxx  [ 单据 ]  │ ← 主信息行（主体 + 标识 + 快捷入口）
│ ┌────────────────────────────────────────┐ │
│ │ 入库单号     RK2026...                  │ │ ← 浅灰底指标块（12px，左右对齐）
│ │ 仓库名称     宝山1号仓                  │ │
│ │ 入库货品     热轧卷板 Q235B…            │ │
│ │ 入库日期     2026-08-25                 │ │
│ │ 入库数量     1,250.00 吨                │ │
│ └────────────────────────────────────────┘ │
│ 制单人：张三                                │ ← 经办信息（11～12px 弱化）
│ 制单时间：2026-08-25 10:30                  │
│                    下载记录  资料管理  查看详情 │ ← 操作行（一行最多 4 个胶囊）
└────────────────────────────────────────────┘
```

要点：

1. **第一行是业务分类**，不是不可读的技术 ID；技术编号放详情页。
2. 主信息行给**业务主体名**，长名称单行省略；右侧可放一个高频快捷入口（如「单据」下载）。
3. 指标块浅灰底、圆角 `8px`、内边距 `12px`，指标名次要色、值主文本色，**左右对齐**；指标 3～6 条为宜。
4. 经办信息用弱化色，制单人和时间各占一行。
5. 操作行右对齐，**一行最多 4 个胶囊按钮**；超过 4 个时，第 4 个位置换成【更多操作】胶囊，点击后在**卡片内向下展开**其余按钮（不用底部面板）。
6. 卡片整体可点进详情时，卡片上不要再放「详细」这类小文字链接。

### 4.1 卡片外观

| 项 | 规格 |
| :--- | :--- |
| 容器 | 白底、圆角 `12px`、描边 `#232D39/5`～`#e5e7eb`、`shadow-xs`～`shadow-sm` |
| 点击反馈 | `active:scale-[0.99]` |
| 内边距 | `14px` |
| 头部条 | 浅底 `#232D39/[0.02]`、上下 `10px`、左右 `14px`、底部分割线；左侧单号，右侧类型与状态胶囊 |
| 指标块 | 底 `#232D39/5`、圆角 `8px`、内边距 `12px` |
| 卡片间距 | `12px`（只由外层 `space-y-3` 提供，卡片不要再加 `mb-3`） |

### 4.2 标杆样例：入库记录卡 / 出库记录卡

H5 台账列表以 **入库记录卡**（`InboundRecordCard`）和 **出库记录卡**（`OutboundRecordCard`）为标准样例，新页面照这两个抄。

两者共同的结构（也就是标准五段）：

1. **头部条**：左侧单号（12px 次要色），右侧「类型胶囊 + 状态胶囊」（10px）；
2. **主体行**：圆形首字图标 + 主体名称（14px 加粗）+ 标识（12px 次要）；
3. **指标块**：浅灰底、圆角 8px，4～6 条左名右值；
4. **经办信息**：制单人、操作时间两行，12px 弱化色；
5. **操作行**：右对齐，胶囊按钮（描边中性 / 跳转主色），**一行最多 4 个**。

两个样例已统一为一套（共用 `shared/components/RecordCard.tsx`）：

| 项 | 统一结果 |
| :--- | :--- |
| 卡片圆角 | `12px`（`rounded-xl`） |
| 头部 | 左侧单号 + 右侧类型胶囊（中性描边）+ 状态胶囊（语义色） |
| 操作数量 | 一行最多 4 个胶囊；超过 4 个时第 4 个换成【更多操作】胶囊，点击在卡片内向下展开 |
| 类型胶囊 | 统一中性描边，不再使用调色板外的紫 / 青 |

> 新页面直接复用 `RecordCard`：传 `orderNo / detailTo / typeLabel / statusLabel / ownerName / metrics / person / time / actions`，弹层用 `children` 塞进去。

### 4.3 单号在 H5 的展示口径

与 PC **不同**（PC 严禁截断，H5 允许）：

- H5 卡片内单号可以单行省略（`max-w-[65%] truncate`），因为手机宽度有限。
- 单号用主色 `text-blue-600`，点击直接进详情，用户可以到详情页看完整单号。
- 卡片外（详情页、弹窗）一律完整展示，不截断。

## 5. 卡片操作与危险动作

| 场景 | 规则 |
| :--- | :--- |
| 高频操作 | 直接放胶囊按钮（圆角全圆、`12px` 中等字重），**一行最多 4 个** |
| 超过 4 个 | 第 4 个位置换成【更多操作】胶囊（带下箭头），点击在卡片内**向下展开**其余按钮；展开后同一胶囊变「收起」 |
| 危险操作（删除、注销、平仓） | **禁止**出现在卡片右上角或列表上；进详情页，或二次确认弹窗 + 说明后果 |
| 展开式操作 | 允许在卡片内向下展开其余按钮；展开区最多再占两行，展开/收起时卡片高度平滑变化，不整页跳动 |

### 5.1 三种状态长什么样

```text
【A · 正好 4 个：全部直出，不出现「更多操作」】
┌────────────────────────────────────────────────┐
│ 20617289020070320130      (质押出库) (已通过)   │
├────────────────────────────────────────────────┤
│ (四) 四川建龙物资有限公司                          │
│      91510100MA6XXXXXXX                        │
│ ┌────────────────────────────────────────────┐ │
│ │ 货物名称  有色金属-电解铜-国标 等 2 种   ›   │ │
│ │ 出库数量                         700 吨     │ │
│ │ 仓库名称  海霸王仓库 · ZY20260528001         │ │
│ └────────────────────────────────────────────┘ │
│ 制单人          lxy（四川享宇科技有限公司）       │
│ 操作时间              2026-06-03 10:18:22       │
│                                                │
│   [单据下载] [资料管理] [查看详情] [下载记录]     │
└────────────────────────────────────────────────┘

【B · 超过 4 个：前 3 个直出，第 4 格换成「更多操作」】
│   [单据下载] [资料管理] [查看详情] [更多操作 ⌄]   │  ← 点这里展开
└────────────────────────────────────────────────┘

【C · 展开后：其余按钮在下方换行排，第 4 格变「收起」】
│   [单据下载] [资料管理] [查看详情] [收起 ⌃]       │
│                          [下载记录] [打印单据]    │  ← 向下展开，右对齐
└────────────────────────────────────────────────┘
```

规则：

- **槽位固定 4 个**：≤4 个全部直出；>4 个时前 3 个 + 第 4 格【更多操作 ⌄】。
- 展开区沿用同一套胶囊，右对齐、自动换行，**最多再占两行**。
- 展开/收起只改这一张卡片的高度，不影响其他卡片与页面滚动位置。

## 6. 空态、刷新与分页

1. **空态**：居中说明原因 + 可选「重置筛选」；不要只写「暂无数据」四个字。
   - 例：「暂无符合条件的设备预警 · 试试调整筛选条件」。
2. 列表底部不做传统分页：移动端用**滚动加载**或「加载更多」。
   - **原型现状**：目前列表是一次性把 Mock 数据全部渲染，没有实现下拉刷新与分页加载，这是原型范围外的功能，规范只约定「以后要做时的位置」。
3. 加载中：骨架屏或居中 Loading，不遮挡最后一条卡片的操作区。

## 7. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 首屏平铺 4 列筛选项控件 | 搜索 + 胶囊 + 底部抽屉 |
| 每次输入都重新请求列表 | 点「确定/查询」才生效 |
| 「更多筛选」做成右侧抽屉 | 底部弹出抽屉 |
| 点「更多」弹底部面板、盖住列表 | 在卡片内向下展开，最多再占两行 |
| 卡片里到处是「详细」小字链接 | 点卡片进详情，操作行一行最多 4 个胶囊 |
| 卡片首行放一串哈希 / UUID | 首行放业务名称与分类 |
| 列表右上角直接放删除图标 | 删除进详情或二次确认 |
| 卡片外面再套一层灰底卡片 | 一层卡片，信息块用浅色底区分即可 |
| 空态只写「暂无数据」 | 说明原因 + 重置入口 |
