## 0. 本次修订（v1.0 → v1.1）

v1.0 按「设计理想态」写，与已落地的 `B端H5` 有多处对不上。v1.1 做了一次**规范对齐实现**的校准：

| 章节 | 改了什么 |
| :--- | :--- |
| 01 架构与导航 | 删除与实现不符的 390px 手机外壳示例；补齐 `NavBar`、底部 Tab 栏、滚动隔离、返回逻辑、安全区的真实参数 |
| 02 列表页 | 筛选从「右侧抽屉」改为「搜索 + 胶囊 + **底部**抽屉」；卡片结构改为实现里的五段式；补充单号在 H5 可截断的口径 |
| 03 详情页 | 字段排布从「名在上值在下」改为**左名右值**（实现主流）；补充摘要卡、分页签、`SectionCard` 竖色条语义 |

## 5. 核心原则

1. **一屏三段**：标题栏（固定）+ 内容（独立滚动）+ 底栏/操作栏（固定）。
2. **筛选两层**：首屏只放搜索 + 常用胶囊，其余进底部抽屉，不堆三层。
3. **卡片信息五段**：类型 → 主体 → 指标 → 经办 → 操作；操作用胶囊按钮，一行最多 4 个，超出折叠为【更多操作】。
4. **详情最多两层**：板块卡内不再套卡片，字段默认左名右值。
5. **表单先选形态**：高频采集用原生行式，字段多用标签在上式，同组不混用。
6. **危险动作不上列表**：删除、注销、平仓一律进详情或二次确认。

## 6. 构建前检查（与速查文档第 5 节一致）

- [ ] 外壳：`MobileShell` + 独立滚动区，底栏不被顶走；标注包裹用 `H5_SCROLL_HOST`
- [ ] 返回：`navigate(-1)` + `handleStackBack` 兜底，没有硬编码 `backTo="/"`
- [ ] 列表：搜索 + 胶囊 + 底部抽屉；卡片五段；操作胶囊一行 ≤ 4 个，超出用【更多操作】向下展开
- [ ] 列表：卡片不再额外加 `mb-3`；单号可截断但点击进详情
- [ ] 详情：摘要卡 + 板块；`SectionCard` 显式传竖条色；字段左名右值；无数据不渲染
- [ ] 详情：吸底操作栏存在时，滚动区留 `pb-24`
- [ ] 表单：同组只用一种形态；数字/日期/多选走对应控件与底部弹层
- [ ] 表单：步骤条 + 末尾按钮或吸底栏；提交按钮有禁用与「提交中…」态
- [ ] 视觉：主色 `blue-600`、文本 `#232D39`、页面底 `#edf2f8`，新页面不再出现 `#1875f0`
- [ ] 安全区：所有吸底元素带 `env(safe-area-inset-bottom)`
- [ ] 标注：`PrototypeDocument` 三件套 + `AGENTS.md` 4.2 打点
