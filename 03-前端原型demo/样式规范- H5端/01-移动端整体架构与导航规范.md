# 01-移动端整体架构与导航规范

> 本章管「页面外面那一圈」：手机机身、状态栏、导航栏（含胶囊按钮）、底部四大 Tab、滚动隔离、返回逻辑。
> 色值与字号见 [05-色彩、字体与视觉系统规范](./05-移动端色彩与视觉系统规范.md)。

---

## 1. 四大主场景（底部常驻 Tab）

H5 / 小程序（机构端）固定四个 Tab，常驻底部，顺序不可调换：

```mermaid
graph TD
    Root[SYZC 移动机构端]
    Root --> Tab1[1. 首页]
    Root --> Tab2[2. 工作台]
    Root --> Tab3[3. 业务办理]
    Root --> Tab4[4. 我的]

    Tab1 --> Tab1_1[指标看板 / 现场画面 / 待办卡片]
    Tab2 --> Tab2_1[按业务线分组的 5 列应用宫格]
    Tab3 --> Tab3_1[内部审批 / 业务发起 / 客户需求审批 / 其他审批]
    Tab4 --> Tab4_1[账号信息 / 管辖仓库 / 权限说明]
```

| Tab | 路由 | 说明 |
| :--- | :--- | :--- |
| 首页 | `/m/home` | 经营与风控总览 |
| 工作台 | `/m/workspace` | 全部功能入口（二级、三级页面从这里进） |
| 业务办理 | `/m/tasks` | 审批与发起的待办聚合 |
| 我的 | `/m/profile` | 账号、权限、仓管辖范围 |

## 2. 外壳与视口

### 2.1 手机机身（工作台提供，页面不用自己画）

原型在电脑上打开时，`PrototypeAnnotationLayer` 的 `WorkbenchLayout` 会提供**手机机身**：

- 画布中间是 **390 × 844** 手机（可切 375 / 414），8px 深色边框、42px 圆角、投影。
- 机身顶部是 **iOS 状态栏**：左侧时间、中间灵动岛、右侧 5G 与电量。
- 机身底部是 **小白条**（Home 指示条）。
- 右侧「外观」默认选 **真机外观**；切到「无壳纯屏」时只保留圆角画板，不显示状态栏与小白条。

**硬性要求**：页面代码里**不要**再写 `max-w-[390px]`、`h-[844px]`、自造状态栏。机身、状态栏、缩放都由工作台统一管。

### 2.2 页面外壳（MobileShell）

- `MobileShell` 是手机屏幕里那一层：`relative flex flex-1 flex-col h-full w-full min-h-0 overflow-hidden bg-[#edf2f8]`。
- 每个页面用 `MobileShell` 包住，页面内容不许超出手机屏幕。

### 2.3 三段式纵向结构

```text
┌──────────────────────────────┐
│ 导航栏 NavBar（44px，固定）        │  shrink-0（含右上角胶囊按钮）
├──────────────────────────────┤
│ 内容区（独立滚动）                    │  flex:1; min-height:0; overflow-y:auto
│                              │
├──────────────────────────────┤
│ 底部 Tab 栏（50px + 安全区，固定）   │  shrink-0
└──────────────────────────────┘
```

**硬性要求**：

1. 外壳 `overflow-hidden`，内容区自己滚，底栏永远不被顶出屏幕。
2. 内容区必须带 `min-h-0`，否则 flex 子项撑破外壳、滚动失效。
3. 二级页面没有底部 Tab 栏，改为底部操作栏或吸底按钮（见 04 表单规范）。

## 3. 导航栏（NavBar）

按**小程序**样式统一：二级页面（列表、详情、表单）用 `NavBar` 组件（`B端H5/src/components/layout/NavBar.tsx`）。

| 元素 | 规格 |
| :--- | :--- |
| 高度 | `44px`，白底，底部 1px 分割线 |
| 左侧返回 | `44 × 44` 点击区，`24px` 细箭头，**不加圆形底色**，按下变淡 |
| 标题 | `17px` 半粗、**屏幕居中**、单行、超长省略 |
| 右侧业务按钮 | 排在胶囊左侧，只放**短按钮或图标**（建议不超过 2 个字） |
| 胶囊按钮 | `87 × 32`，距右 `8px`，全站固定展示，业务按钮不得覆盖它 |

**标题避让规则（已封装在 NavBar 里，不用页面自己算）**：

小程序的右上角被胶囊占掉约 95px。没有右侧按钮时，标题在整屏居中，两边各让出胶囊的宽度；有右侧按钮时，标题在「返回键」和「右侧按钮」之间居中，会**略微偏左**，换来标题完整显示、不压字。因此：**右侧不要放长文字按钮**（如「全部展开」这类）。

**发起类入口位置（以仓单开立为准）**：开立、新增这类"发起单据"的入口统一放在「业务办理 → 业务发起」，从业务办理进入；列表页（如仓单管理）只负责查询和单据操作，**不在列表里重复放「开立」按钮**，也不在导航栏右侧放它。需要临时主操作时，才用内容区按钮或右下角悬浮按钮。

**四个主 Tab 页**：不显示返回箭头（`showBack={false}`），标题固定为「首页 / 工作台 / 业务办理 / 我的」。

## 4. 底部 Tab 栏

按小程序原生 TabBar 规格：

| 元素 | 规格 |
| :--- | :--- |
| 内容区高度 | `50px`（不含安全区） |
| 安全区 | 底部追加 `env(safe-area-inset-bottom)`，iPhone 小白条不挡图标 |
| 背景 | 白色 95% + 背景模糊（`bg-white/95 backdrop-blur-md`），顶部 1px 分割线 |
| 图标 | `24px`，未选中细描边、选中加粗并轻微放大 |
| 文字 | `10px` |
| 未选中 | 灰 `#9ca3af` |
| 选中 | 蓝色 `#1875f0` + 加粗（历史色，见 05 第 1.1 节） |
| 点击反馈 | 按透明度变化（`active:opacity-70`） |

- 角标（待办数）用红色圆点，放在图标右上角。
- 底栏不参与页面滚动，也不随键盘弹起而隐藏（原型不做键盘适配）。
- 安全区必须加，这是真机上最常见的“底栏被小白条挡住”问题。

## 5. 滚动隔离

### 5.1 组件

列表页统一用 `TabScrollLayout`（`B端H5/src/components/layout/TabScrollLayout.tsx`）：**固定筛选头 + 下方独立滚动区**。

```text
<MobileShell>
  <NavBar />
  <TabScrollLayout header={<筛选区 />}>
    <列表滚动区 />
  </TabScrollLayout>
</MobileShell>
```

### 5.2 标注打点注意

给列表滚动区加标注打点时，包裹层必须用 `H5_SCROLL_HOST`（`relative flex min-h-0 flex-1 flex-col`），否则外层 `relative` 块不参与 flex，列表会滚不动。这是踩过的坑，源码里有注释，别再用普通 `div` 包一层。

## 6. 返回逻辑

1. **一律优先浏览器历史后退**（`navigate(-1)`），不要硬编码 `backTo="/"` 或写死某个列表页。
   - 从「工作台」进存货管理，返回回到「工作台」；从「业务办理」进客户入库需求，返回回到「业务办理」。
2. 深度链接（外部推链、扫码进入）没有历史可退时，才用 `handleStackBack(navigate, location, fallbackPath)`：优先用路由 state 里的 `returnTo`，其次历史后退，最后 `replace` 到兜底列表页。
3. 表单提交成功、外部推送等特殊链路，才允许显式跳到指定页面（例如提交成功后回 `/m/tasks`）。
4. 当前页有未保存改动时，返回要先弹确认（见 04 第 7 节）。

## 7. 三类页面骨架

### 7.1 列表页

```text
标题栏（NavBar：列表名）
筛选区（固定，不随列表滚动）
  ├─ 搜索框 + 状态胶囊 / 下拉胶囊行
  └─「更多筛选」→ 底部筛选抽屉
列表滚动区（卡片列表，12px 间距）
```

细则见 [02-列表页设计与交互规范](./02-移动端列表页设计与交互规范.md)。

### 7.2 详情页

```text
标题栏（NavBar：详情名）
摘要卡（单号 + 状态 + 关键信息）
分页签（可选：明细 / 审核记录 / 修改记录 / 资料）
板块列表（SectionCard）
底部操作栏（可选，吸底）
```

细则见 [03-详情页与时间线规范](./03-移动端详情页与时间线规范.md)。

### 7.3 新增 / 编辑页

```text
标题栏（NavBar：表单名）
步骤条（多步单据才有）
分组表单卡（原生行式或标签在上式）
吸底按钮栏（安全区适配）
```

细则见 [04-表单与新增编辑规范](./04-表单与新增编辑规范.md)。

## 8. 安全区

所有吸底元素（按钮栏、Tab 栏、弹层底部）必须处理 iPhone 底部安全区：

```text
padding-bottom: calc(0.75rem + env(safe-area-inset-bottom))
```

- 目前工程里有 `calc(...+env(...))` 与 `max(...)` 两种写法，**统一用 `calc` 这一种**。
- 吸底卡片、抽屉的底部按钮区同样要加，否则在真机上会被小白条挡住。

## 9. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 整页滚动，底栏被顶走 | 外壳固定高度，内容区独立滚动 |
| 返回写死 `backTo="/"` | `navigate(-1)` + `handleStackBack` 兜底 |
| 二级页面也挂底部四大 Tab | 二级页用返回 + 底部操作栏 |
| 页面里写死 `max-w-[390px]` 手机框 | 用工作台的手机机身与机型预设 |
| 导航栏右侧塞长文字按钮（「+ 开立」「全部展开」） | 放内容区、吸底栏或右下角悬浮按钮 |
| 页面自造状态栏或胶囊 | 状态栏由工作台统一，胶囊由 `NavBar` 统一 |
| 四个 Tab 页各写各的标题栏 | 统一 `NavBar` + `showBack={false}` |
| 标注包裹层用普通 `div` 导致列表滚不动 | 用 `H5_SCROLL_HOST` |
| 吸底按钮、Tab 栏不加安全区 | `calc(... + env(safe-area-inset-bottom))` |
| 标题栏高矮不一、标题字号乱飘 | 统一 44px / 17px 半粗 |
