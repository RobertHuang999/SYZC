## 📱 2. 视口与固定底栏布局规范 (Viewport & Scroll Isolation)

### 2.1 常见问题与痛点
- 传统实现将整个页面作为外层滚动容器，导致内容较长时，底部的 `BottomTabBar` 随页面下滑被顶到最底部甚至脱离视口，用户无法单手随时切换功能。

### 2.2 规范实现原则
1. **外层固定视口高度**：
   - 移动端外框容器必须严格设定为视口高度（如桌面模拟 `sm:h-[844px]`，真机 `h-screen`），并设置 `overflow: hidden`。
2. **三段式纵向布局**：
   - **顶部 Header / Status Bar**：`shrink-0`，常驻顶部；
   - **中间内容滚动区**：`flex: 1; min-height: 0; overflow-y: auto;`，内部卡片在此区域独立滚动；
   - **底部 Tab 栏 (BottomTabBar)**：`shrink-0; height: 56px;`，固钉在容器最底部，背景应用 `backdrop-blur` 磨砂玻璃效果，永远不随内容滚动位移。

```tsx
// 标准视口结构示例
export function MobileShell({ children }: { children: ReactNode }) {
  return (
    <div className="flex h-screen sm:h-[844px] w-full max-w-[390px] flex-col overflow-hidden bg-[#edf2f8]">
      {/* 1. 顶部状态栏 (固定) */}
      <div className="h-11 shrink-0 px-6 pt-1">...</div>
      
      {/* 2. 页面容器 (内含滚动区与底部导航) */}
      <div className="flex flex-1 flex-col min-h-0 overflow-hidden">
        {children}
      </div>
    </div>
  )
}
```

## 🔄 3. 路由与历史栈回退机制 (Route & Back Navigation)

### 3.1 核心原则
- **严禁硬编码全局跳转回首页**：在所有二级页面（列表页、详情页、表单页）的顶部 `NavBar` 返回按钮中，**严禁使用 `backTo="/"`**。
- **默认采用 `navigate(-1)` 动态回退**：
  - 用户从【工作台】点击进入“存货管理”，点击返回必须停留在【工作台】；
  - 用户从【业务办理】点击进入“客户入库需求”，点击返回必须停留在【业务办理】；
  - 用户从【首页】点击进入“押品预警”，点击返回必须停留在【首页】。
- **特殊链路显式指定**：仅当用户通过外部推送链接或深度表单提交完成后，才允许显式重定向至指定父级列表（如：表单提交成功后重定向至 `/m/tasks`）。
