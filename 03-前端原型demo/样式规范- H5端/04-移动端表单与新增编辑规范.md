# 04-移动端表单与新增编辑规范

---

## 📝 1. 表单分组与视觉层级

移动端表单必须采用 **分组卡片式结构（Card Grouping）**，严禁把 10+ 个输入框在白底上无间断平铺：

1. **基础信息组 (Basic Group)**：单据类型、所属仓库（级联选择器）、所属货主/借款主体。
2. **货物与明细组 (Commodity Group)**：商品分类、规格型号、数量/吨数、批次号、单价。
3. **风控与确权凭证 (Risk & Evidence Group)**：采购发票号、地磅凭证图、现场落位照片、提货码配置。
4. **经办与审核流 (Workflow Group)**：指定下一节点审批人、备注说明。

---

## 🎯 2. 输入控件与校验规范

| 控件类型 | 移动端规范要求 | 错误示范 |
| :--- | :--- | :--- |
| **必填项标识** | 红色星号 `*` 统一紧贴在 Label 左侧，提示语直接写在输入框内部占位符。 | 在右侧用长文字提示“本项必须输入” |
| **金额/数量输入** | 数字键盘唤起（`type="number"` 或 `inputmode="decimal"`），右侧带固定单位（如 `吨`、`万元`）。 | 纯纯文本输入框，用户需要自己打中文“吨” |
| **日期时间选择** | 底部唤起 iOS 滚轮式时间选择器，支持预设快捷选项（如“今天”、“3天内”）。 | 让用户手动输入 `2026-08-25` 字符串 |
| **单选/多选标签** | 超过 3 项采用底部弹窗列表，3 项以内采用胶囊单选按钮（Radio Capsule）。 | 挤在一行很小的原生单选圈 |

---

## 🔒 3. 底部提交与防重复机制 (Submit & Idempotency)

1. **底部吸底按钮栏 (Fixed Action Bar)**：
   - 提交按钮必须固定在移动端底部（带安全区适配 `safe-area-inset-bottom`）；
   - 左侧提供辅助按钮（如“存为草稿”或“取消”），右侧为主操作按钮（“提交申请”）。
2. **防重复点击与弱网保护**：
   - 点击提交后，按钮立即进入 `Loading` 状态并禁用，防止并发重复提交产生多笔重复单据；
   - 关键操作必须配备接口幂等性 Token。
