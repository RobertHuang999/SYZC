# 04-移动端表单与新增编辑规范

> 本章管「填表」：新增、编辑、分步采集。
> 外壳见 [01-整体架构与导航规范](./01-移动端整体架构与导航规范.md)，色值与字号见 [05-色彩与视觉系统规范](./05-移动端色彩与视觉系统规范.md)。

---

## 1. 先选表单形态

H5 有两种表单写法，别混用：

| 形态 | 长相 | 用在哪 | 组件 |
| :--- | :--- | :--- | :--- |
| **原生行式** | 一行一事：左字段名、右值/控件，行间有下分割线 | 高频采集：入库单、出库单、合作方档案 | `NativeInfoCard` + `NativeFormRow` |
| **标签在上式** | 字段名在上（12px 灰）、控件在下（整行） | 字段多、控件宽：仓库信息、配置类表单 | 分组卡片 + `label` + 控件 |

判断口诀：**「手机上像系统设置页那样一行一项」用原生行式；「像迷你表单、输入内容长」用标签在上式。**

同一个页面里两种可以并存（例如「主体信息」用原生行式、「地址」用标签在上式），但**同一个分组内必须统一**。

---

## 2. 原生行式表单

### 2.1 分组卡

统一用 `NativeInfoCard`（`B端H5/src/features/inbound-records/components/NativeInfoCard.tsx`）：

| 元素 | 规格 |
| :--- | :--- |
| 容器 | 白底、圆角 `8px`、无描边、底部外边距 `12px` |
| 卡头 | 左右内边距 `16px`、上下 `16px`、底部分割线 `#232D39/10` |
| 卡头图标 | 主色蓝、`20px`（可选） |
| 卡头标题 | `16px` 粗体、主文本色 |

### 2.2 行（`NativeFormRow`）

| 元素 | 规格 |
| :--- | :--- |
| 行高 | 最小 `36px`，上下内边距 `14px` |
| 布局 | 左字段名（固定不换行）+ 右内容（`flex-1`、右对齐） |
| 字段名 | `14px`、主文本色 |
| 必填星号 | 紧随字段名左侧，`#EF3E3E` |
| 分割线 | 行底 1px `#232D39/10`；最后一行不画 |
| 右侧箭头 | 可点击进入选择时显示 `›`（`16px`、30% 主文本色） |
| 输入框 | 无边框、透明底、`14px`、右对齐、占位符 `#232D39/30` |
| 可点击行 | 整行可点，键盘回车/空格也触发 |

带计数的多行输入（备注）在右下角显示 `已输入/上限`（如 `32/140`）。

### 2.3 标签在上式表单

| 元素 | 规格 |
| :--- | :--- |
| 字段名 | `12px` 中等字重、`gray-700`、下方间距 `6px` |
| 控件 | 整行宽、高 `36px`（多行 `80px` 起）、圆角 `8px`、描边 `#232D39/10` |
| 字段间距 | 上下 `12px` |
| 分组 | 用卡片分组（同 2.1），组与组之间 `12px` |

## 3. 控件与校验

| 场景 | 规范 |
| :--- | :--- |
| 数字 / 金额 / 重量 | 唤起数字键盘（`inputmode="decimal"`），右侧固定单位文字（吨 / 元 / 万元），**不要让用户手打单位** |
| 日期时间 | 点开底部弹出选择器（日期滚轮或日期区间弹窗），可给「今天 / 近 3 天」快捷项；禁止让用户手输 `2026-08-25` |
| 单选（≤3 项） | 胶囊单选（选中蓝底蓝字），如「企业货主 / 个人货主」 |
| 单选 / 多选（>3 项） | 底部弹出选择面板（`MobileDownSelectSheet` / 多选 Sheet），带搜索框 |
| 级联（仓库→库房、货品→规格） | 底部弹出级联面板，逐级选择，选完回填一行 |
| 图片 / 附件 | 九宫格上传，支持预览与删除；单张失败要单独提示 |
| 开关 | 用原生风格开关，右侧对齐 |

**校验提示**：

- 必填未填：字段下方 `11px` 玫红文字，或轻提示说明第一处错误。
- 提交被拦时，**滚动定位到第一个错误项**，不能只弹一句话让人自己找。
- 提示文案写「请选择入库日期」，不写「该字段不能为空」。

## 4. 分步表单与步骤条

适用于多阶段采集（入库、出库、移库），步数与顺序以 PRD 为准。

### 4.1 步骤条

统一用 `NativeInboundStepBar`（两步：基础信息 → 货品明细）。

| 元素 | 规格 |
| :--- | :--- |
| 位置 | NavBar 下方、第一个分组卡上方，上下 `16px` |
| 圆点 | `24px`；已完成/当前 = 浅蓝底 `blue-100`，未到 = `#232D39/20` 底 + 白色序号 |
| 圆点内容 | 已完成 = 蓝色勾（粗描边）；当前 = 蓝色实心小圆；未到 = 序号数字（`12px`） |
| 连接线 | 高 `2px`；已完成段 `blue-600`，未完成段 `blue-100` |
| 步骤名 | `12px`、当前/已完成为主文本色 + 中等字重，未到为 60% 透明度 |
| 布局 | 横向等分，每步最小宽 `72px` |

### 4.2 分步规则

1. 每步对应独立路由或独立滚动区；**上一步校验通过才能进下一步**。
2. 当前步内继续用分组卡（见第 2 节）。
3. 分步表单的下一步按钮放在**内容末尾**：全宽 `52px`、圆角 `8px`、主色底、`16px` 字。
   - 原因：步骤内容不长时，末尾按钮比固定吸底更省屏。
4. 最后一步提交成功后回业务办理列表，并给轻提示。
5. 「返回」时若当前步有改动，先确认再退回上一步或列表。

## 5. 提交按钮与防重复

### 5.1 两种提交方式

| 场景 | 做法 |
| :--- | :--- |
| 分步表单（入库/出库发起） | 内容末尾全宽主按钮「下一步 / 提交」 |
| 单页长表单（合作方档案、配置） | **固定吸底按钮栏**（见 5.2） |

### 5.2 吸底按钮栏

```text
position: fixed; left/right: 0; bottom: 0;
background: #fff; border-top: 1px solid rgba(35,45,57,.1);
padding: 12px 16px calc(12px + env(safe-area-inset-bottom));
```

- 按钮高约 `44px`、圆角 `12px`、`14px` 加粗字。
- 双按钮时：次要按钮描边蓝、主按钮蓝底，各占一半（`flex-1`）。
- 单按钮时整行铺满。
- 内容滚动区必须留出底部空间（`pb-24` 或等价），否则最后一项被挡。

### 5.3 防重复提交

- 点击后按钮立即置灰（`disabled`）并把文案改成「提交中…」「处理中…」，直到结果返回。
- 原型阶段用本地状态模拟即可；接真接口时必须带幂等标记，防止产生重复单据。

## 6. 底部弹层（选择、筛选、操作）

H5 的选择、筛选、更多操作统一从**底部**弹出，不用中间浮层堆小弹窗。

| 弹层 | 用途 | 规格 |
| :--- | :--- | :--- |
| 选择面板（Sheet） | 单选 / 多选 / 级联 / 日期 | 底部弹出、圆角上 `16px`、最高 80% 屏高、内部可滚、底部「取消 / 确定」 |
| 筛选抽屉（FilterDrawer） | 更多筛选条件 | 同上，标题「更多筛选」 |
| 操作面板（ActionSheet） | 底部弹出的一组次要操作（列表卡默认在卡片内向下展开，此组件留给仓单等老卡片与详情页） | 底部弹出，危险操作红色且单独分隔 |
| 确认弹窗 | 停用、删除、离开 | 居中弹窗，说明后果，取消在左、确认在右 |

- 弹层打开时背景加 `40%` 黑色遮罩，点击遮罩可关闭（确认类弹窗除外）。
- 弹层内按钮同样要处理底部安全区。

---

## 7. 离开拦截

1. 表单有任何改动时，点「返回」先弹确认：「当前填写内容尚未保存，确定离开吗？」。
2. 提交成功后清除改动标记，直接跳转，不再拦截。
3. 原型阶段用页面内确认即可（工程里已落地），`beforeunload` 刷新拦截属于待办。

---

## 8. 与 PC 的一致性

- 字段字典、必填规则、校验规则、状态机与 PC **完全一致**；H5 只改承载方式（分步、弹层、行式布局），**不减少必填项、不放宽校验**。
- 同一字段在两端的中文名必须一样，不能 PC 叫「入库日期」、H5 叫「到货时间」。

---

## 9. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 10 多个输入框在白底上无分组平铺 | 按业务分组，一组一张卡 |
| 同一分组里一半左名右值、一半标签在上 | 同组统一形态 |
| 让用户手输中文单位「吨」 | 数字键盘 + 固定单位后缀 |
| 日期让用户手打字符串 | 底部日期选择器 |
| 超过 3 个选项也挤成一行小圆点 | 底部选择面板 |
| 提交按钮只弹一句「有错误」 | 滚动到第一个错误项并说明 |
| 点提交后按钮还能连点 | 立即禁用 + 文案变「提交中…」 |
| 吸底栏挡住表单最后一项 | 滚动区留 `pb-24` |
| 选择器用中间浮窗套小盒子 | 统一底部弹层 |
| 有改动直接返回，内容悄悄丢失 | 离开前确认 |
