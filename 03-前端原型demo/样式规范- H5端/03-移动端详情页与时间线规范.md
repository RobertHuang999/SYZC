# 03-移动端详情页与时间线规范

> 详情页标准结构：标题栏 → 摘要卡 →（可选）分页签 → 板块列表 →（可选）吸底操作。
> 组件外观以 `SectionCard`、`NavBar` 的实现为准；色值见 [05-色彩与视觉系统规范](./05-移动端色彩与视觉系统规范.md)。

---

## 1. 页面结构

```text
┌──────────────────────────────┐
│ NavBar：详情名      [全部展开 ▾] │  ← 右侧可放「全部展开/收起」
├──────────────────────────────┤
│ 摘要卡：单号 + 状态标签 + 关键信息      │
├──────────────────────────────┤
│ 分页签：入库明细 / 审核记录 / 修改记录 / 资料 │  ← 可选，2～4 个
├──────────────────────────────┤
│ SectionCard · 基本信息                 │
│ SectionCard · 业务事实                 │
│ SectionCard · 审批 / 操作记录           │
├──────────────────────────────┤
│ 吸底操作栏（可选）                      │
└──────────────────────────────┘
```

- 滚动区：`space-y-2.5 px-3 py-3`，底部留出 `pb-24` 给吸底栏（有吸底栏时）。
- 板块默认全部展开；页面级提供「全部收起 / 全部展开」时放在 NavBar 右侧槽位。

### 1.1 标杆样例：入库详情 / 出库详情

H5 台账详情以 **入库详情**（`InboundRecordDetailPage`）和 **出库详情**（`OutboundRecordDetailPage`）为标准样例，结构固定：

```text
NavBar（标题 + 右侧「全部展开/收起」可选）
摘要卡（12px，单号 + 状态 + 制单人时间 + 4～6 条左名右值）
分页签（2～4 个：明细 / 审核记录 / 修改记录 / 资料管理）
平铺板块（12px 白卡，标题 + 左名右值字段；不折叠）
吸底操作栏（可选）
```

**两种板块写法，别混用：**

| 写法 | 用在哪 | 特点 |
| :--- | :--- | :--- |
| **平铺板块**（默认） | 台账、单据类详情（入库、出库、仓单） | `12px` 白卡、标题、不折叠；分组靠页签 |
| **可折叠板块** `SectionCard` | 监控、预警类详情（板块多、内容长） | `16px`、左侧竖色条、可单独折叠、可「全部展开」 |

规则：

1. 同一页面只用一种写法；台账类优先用**平铺板块**。
2. 页签负责「换维度」，折叠负责「收长度」，两者不要在同一页面重复堆叠。
3. `SectionCard` 的 16px 与平铺板块的 12px 是两套；后续收敛方向统一 12px（见 README 偏差表）。

## 2. 摘要卡

| 元素 | 规格 |
| :--- | :--- |
| 容器 | 白底、圆角 `12px`、描边 `#232D39/10`、内边距 `14px`、`shadow-xs` |
| 第一行 | 左：字段名「XX单号」（`12px` 次要色）；右：状态标签 |
| 单号 | `16px` 粗体、主文本色、单行完整展示（不截断） |
| 时间行 | `11px` 弱化色：「制单人：张三 2026-08-25 10:30」 |
| 关键信息 | 单号下方用**左名右值**行列出 4～6 条（货主、日期、类型、关联单号…），上下留 `6px` |
| 分隔 | 摘要卡内第一块与关键信息之间加 1px 浅分割线 |

状态标签用 05 第 3 节的语义色（如已通过 = 翠绿）。

---

## 3. 分页签（2～4 个）

当详情内容跨多个维度（明细 / 审核 / 修改 / 资料）时用分页签，避免页面无限拉长。

| 元素 | 规格 |
| :--- | :--- |
| 位置 | 摘要卡下方、板块列表上方 |
| 布局 | 一行等分（`flex`，每个 `flex-1`），不换行 |
| 项高 | `py-2`，`12px` 中等字重 |
| 选中态 | 底部 `2px` 主色线 + 主色文字 + 加粗 |
| 未选中 | `#232D39/60` |
| 切换 | 只切换内容区，不刷新整页、不重置滚动位置以外的状态 |

- 页签名称用业务语言（「入库明细」「审核记录」「修改记录」「资料管理」），不用「Tab1」。
- 页签数量超过 4 个时，改为「更多」下拉或拆成二级页面。

---

## 4. 板块（SectionCard）

每个业务语义块一张卡，统一用 `SectionCard`（`B端H5/src/components/ui/SectionCard.tsx`）。

| 元素 | 规格 |
| :--- | :--- |
| 容器 | 白底、圆角 `16px`、描边 `#e5e7eb` 90%、内边距 `14px`、`shadow-xs` |
| 标题行 | 左侧 `2px × 14px` 竖色条 + 标题（`14px` 粗体）+ 右侧插槽（标签、操作、展开/收起） |
| 折叠 | 默认展开；标题行右侧显示「收起 / 展开」+ 箭头，点击标题行整行可切换 |
| 标题下分隔 | 展开时标题下有 1px 浅分割线 |
| 板块间距 | `10px`（页面 `space-y-2.5`） |

### 4.1 竖色条代表什么

| 色 | 含义 | 建议取值 |
| :--- | :--- | :--- |
| 蓝 | 基本信息、设备、位置 | `#1875f0` |
| 橙 | 预警事实、风险、公示状态 | `#f57c00` / `#f97316` |
| 绿 | 正常、通过、结案类结论 | `#00a870` |
| 靛 | 审批记录、操作记录 | `#6366f1` |

**必须显式传色**：组件默认值是绿色，不传就会出现「基本信息也顶着绿条」的错位。新页面按上表传，不要依赖默认值。

### 4.2 板块怎么分

| 板块 | 放什么 |
| :--- | :--- |
| 基本信息 / 摘要 | 主体、仓库、时间、类型 |
| 业务事实 | 货物明细、预警内容、阈值、读数 |
| 凭证与附件 | 图片、PDF、现场照片 |
| 审批 / 操作记录 | 申请、结论、意见、处置动作 |

原则：

1. **最多两层**：`SectionCard` 内不再套卡片；明细用行式列表、表格或浅灰信息块。
2. 无数据的板块**不渲染**，不要留空卡片或一排「—」。
3. 一个板块内字段控制在 10 条以内，超了拆板块。

## 5. 字段展示

### 5.1 默认：左名右值（单行）

移动端详情默认用**一行「左字段名 + 右字段值」**，这是工程里的主流写法（`KeyValue` 及页面内联写法）：

```text
规则名称:                      设备离线预警规则
预警类型:                  设备预警 · 离线超过2小时
关联设备:           宝山1号仓-AI球机008# (DEV-008)
所属仓库:                        宝山1号智能化立体仓
```

| 元素 | 规格 |
| :--- | :--- |
| 行距 | `8px`（`space-y-2`） |
| 字段名 | `12px`、次要色 `#232D39/60` 或 `gray-500`、固定宽约 `96px`、不换行 |
| 字段值 | `12px`、主文本色、**右对齐**、允许换行 |
| 分隔 | 行与行之间不加分割线；整块字段用板块卡分隔 |

### 5.2 例外：什么时候改成上下结构

以下情况字段名在上、值在下（左对齐）：

1. 值很长（超过一行或含换行文本，如事由、备注、处置意见）；
2. 值是图片网格、表格、链路图等块状内容；
3. 一组指标需要双列并排（如「在库吨数 / 核定货值」）。

### 5.3 空值与占位

- 字段无值：**整条不渲染**（推荐），或在值位置显示「—」；同一页面只能选一种做法。
- 不允许出现 `null`、`undefined`、`--`、`None` 这类开发语言痕迹。

## 6. 业务流向与链路（涉及物权、位移的场景）

凡是「东西从 A 到 B」的业务（移库、加工、货权转让），必须用箭头链路表达，不能只放两行孤立文字：

```text
[源货位] 宝山立体库 A区-03 垛位  ➔  [目标货位] 宝山立体库 B区-11 垛位
[出让方] 江苏宏达贸易（王全）  ══ 货权过户 ══➔  [受让方] 无锡锡通科技（李四）
[投入原料] 苹果-优质 100 公斤  ➔ ⚙ 加工转化（出成率 92%）➔ [产出成品] 12 粒装 100 盒
```

- 箭头用 `➔`，文字说明写清动作（移库 / 过户 / 加工）。
- 两端信息缺失时，用「—」占位并说明原因，不要只画一个箭头。

## 7. 审批 / 操作记录

- 放在独立板块（或「审核记录」页签）里，**一个节点一条记录**，不要一个动作一张大卡。
- 单节点合并展示：申请人 + 结论 + 意见 + 时间 + 耗时。
- 状态徽标：`已通过`（翠绿）、`已驳回`（玫红）、`待处理`（琥珀）、`抄送知会`（主色蓝）。
- 节点顺序按时间正序（最早的在上）或倒序（最新的在上），**同一页面内保持一致**。
- 空记录：显示「暂无记录，等待审批」这类说明，不留白。

---

## 8. 凭证与存证

1. 图片：九宫格缩略图，点击全屏预览，可左右滑动切换。
2. PDF：文件名 + 大小，点击在应用内预览（不起新标签页）。
3. 仓单类存证：在摘要区或「资料管理」页签里给「下载存证」入口；中仓登准入类信息用标签展示（如「中仓登准入」）。
4. 存证类信息**不要**横插在两个板块中间阻断阅读，统一收敛到摘要区或资料页签。

---

## 9. 吸底操作栏（可选）

| 元素 | 规格 |
| :--- | :--- |
| 位置 | `absolute inset-x-0 bottom-0`，白底、顶部 1px 分割线 |
| 内边距 | 左右 `14px`、上下 `10px` + 底部安全区 |
| 按钮高 | `44px`；次要按钮描边、主按钮蓝底，主按钮略宽（`flex-[1.2]`） |
| 内容滚动区 | 必须留 `pb-24`，否则最后一块会被挡住 |

审批、发起、下载这类主操作才放吸底；只是查看的详情页不放。

## 10. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 单据 → 仓单 → 货物 → 批次 → 属性 五层套娃 | 最多两层，明细行式平铺 |
| 所有字段塞一个板块，没有标题 | 按语义拆多个 `SectionCard` |
| 板块竖条不传色，全都顶着绿条 | 按 4.1 节语义显式传色 |
| 长文本（事由、备注）也硬排成一行右对齐 | 改上下结构 |
| 无数据也渲染板块，显示一排「—」 | 不渲染该板块 |
| 一个审批动作一张大卡片，撑满一屏 | 单节点合并展示 |
| 存证信息插在两个板块中间 | 收敛到摘要区或资料页签 |
| 吸底栏挡住最后一行内容 | 滚动区留 `pb-24` |
| 页签里再放卡片套卡片 | 页签内容直接是板块或列表 |
