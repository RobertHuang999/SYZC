# 01-PC 端整体架构与页面骨架规范

---

## 1. 模块壳层

1. **顶栏模块导航**：`TopModuleNav` 切换仓储、融资监管、物联网与预警等一级模块。
2. **Sidebar**：
   - 仓储、融资监管、交易、风控、物联网 IOT 与预警、统计、结算、配置管理等模块**展示**左侧菜单树。
   - **工作中心**模块**不展示** Sidebar（与线上一致）。
3. **内容区**：
   - 标准业务页外层：`className="space-y-4 p-6"`。
   - 页面内垂直区块间距统一 `space-y-4`，大区块之间可用 `gap-4`。

## 2. 三类页面骨架

### 2.1 台账列表页

```text
┌─────────────────────────────────────────────────────────────┐
│ [可选] 页面标题 / 面包屑                                     │
├─────────────────────────────────────────────────────────────┤
│ Card · 筛选区                                                │
│  ├─ 筛选条件 │ [展开筛选] [新增?] [重置] [查询]               │
│  └─ grid lg:4 列 · 默认 4 个筛选项 · 展开区追加项            │
├─────────────────────────────────────────────────────────────┤
│ Card / page-surface · 列表区                                 │
│  ├─ 工具条（批量操作、导出等）                                │
│  ├─ Table（min-width 横向滚动）                              │
│  └─ 分页                                                     │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 台账详情页

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶栏摘要 Card：标题 + 状态 Tag + 行操作按钮（右对齐）         │
├─────────────────────────────────────────────────────────────┤
│ DetailSection · 基本信息                                     │
│ DetailSection · 业务明细 / 附件 / 处置材料 …（按需多块）      │
│ [可选] DetailSection · 时间轴 / 操作记录                     │
└─────────────────────────────────────────────────────────────┘
```

区块之间 `space-y-4`，**不要**再套一层大 Card 把所有 Section 包成第三层嵌套。

### 2.3 新增 / 编辑 / 配置页

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶栏：返回 + 页面标题 + [保存/取消] 或 分块内保存             │
├─────────────────────────────────────────────────────────────┤
│ Card · 基本信息（单列表单或两列 grid）                        │
├─────────────────────────────────────────────────────────────┤
│ Card · 策略/明细区（可折叠 CardHeader、内嵌 Table）           │
│   └─ 每块独立「保存该策略」+ 关闭策略二次确认 Dialog          │
└─────────────────────────────────────────────────────────────┘
```

---

## 3. 顶栏摘要区（列表详情通用）

- 容器：`rounded-xl border bg-card p-4`；宽屏 `lg:flex-row lg:items-center lg:justify-between`。
- 左侧：主标题（单号/规则名/设备名）+ 次要说明一行；状态用 Badge，不与标题抢行。
- 右侧：操作按钮组 `flex flex-wrap gap-2`，主操作 `default`，次要 `outline`/`ghost`。
- **返回**：详情/表单优先「返回列表」链接或 `outline` 按钮，不占用主按钮位。
