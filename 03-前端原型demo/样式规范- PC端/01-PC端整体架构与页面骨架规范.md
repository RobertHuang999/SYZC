# 01-PC 端整体架构与页面骨架规范

> 本章管「页面外围那一圈」：顶栏、模块导航、侧边栏、多页签、内容区。
> 色值、字号、控件尺寸统一见 [05-色彩、字体与表格视觉规范](./05-PC端色彩与表格视觉规范.md)。

---

## 1. 模块壳层

### 1.1 结构总览

PC 原型是**固定视口的后台壳**，不是普通网页：整页不滚动，只有内容区内部滚动。

```text
┌──────────────────────────────────────────────────────────────────────┐
│ ① 顶栏 Header（64px）：品牌 + 一级模块导航 …… 迭代记录 / 权限 / 账号 │
├──────────┬───────────────────────────────────────────────────────────┤
│ ② 侧边栏 │ ③ 多页签 PageTabs（40px 区）：[页签] [页签] [×]            │
│ Sidebar  ├───────────────────────────────────────────────────────────┤
│ 200px    │ ④ 内容区 page-surface（白底圆角、内部滚动）               │
│ (收起72) │    页面内：标题区 + 若干 Card / DetailSection             │
└──────────┴───────────────────────────────────────────────────────────┘
```

### 1.2 尺寸与固定规则

| 部位 | 规格 |
| :--- | :--- |
| 整页高度 | `100vh`，最小高 `620px`，**不出现整页滚动条** |
| 页面最小宽度 | `1080px`（窗口小于 1100px 时降为 `960px`），窄于此横向滚动 |
| 顶栏 | 高 `64px`，白底，底部分割线 `#f0f1f3`，左右内边距 `20px` |
| 侧边栏 | 宽 `200px`，收起后 `72px`；窄屏（<1100px）展开态降为 `180px` |
| 多页签区 | 高度区域 `40px`，页签本体高 `32px` |
| 内容区内边距 | 上 / 左右 `20px`，**底部 `0`**（让分页吸底与底边齐平；页面自身 `p-6` 已提供底部留白） |

> **注意**：内容区内边距（上 / 左右 `20px`）是壳层给的，页面自己再写 `p-6`（24px）会变成「20 + 24」的双层留白。这是当前工程的既成事实，新页面沿用 `space-y-4 p-6` 即可，不要额外再加一层 padding 容器。底部壳层留白为 `0`，这样列表分页吸底时能贴住内容区下沿。

### 1.3 顶栏

从右到左固定为：

1. **账号区**：圆形头像（28px）+ 姓名 + 下拉箭头。
2. **「功能与数据权限」入口**：32px 高描边按钮，点击进入全系统页面/按钮/数据范围对照页。
3. **迭代记录入口**：32px 高描边按钮，点击查看本次迭代变更说明。

左侧是品牌区（图标 34px + 文字「SYZC」）与一级模块导航。

### 1.4 顶部一级模块

固定 10 个，顺序不可随意增减：

工作中心 · 用户中心 · 仓储 · 融资/监管 · 交易 · 风控 · 物联网IOT与预警 · 统计/看板 · 结算 · 配置管理

- 每个模块项高 `40px`、字号 `14px`。
- **选中态用橙色**：文字 `#d99020`、底色 `#fff6e8`、圆角 `8px`（颜色口径见 05 第 3.1 节）。
- 模块项过多时导航区自己横向滚动，不换行、不折叠成「更多」。

### 1.5 侧边栏

| 模块 | 是否显示侧边栏 |
| :--- | :--- |
| 工作中心 | **不显示**（审批中心为卡片聚合页） |
| 用户中心、仓储、融资/监管、交易、风控、物联网IOT与预警、统计/看板、结算、配置管理 | 显示左侧菜单树 |

- 菜单项高 `44px`、字号 `14px`、圆角 `6px`；二级菜单左缩进到 `36px`。
- 选中项：主色文字 `#165dff` + 浅蓝底 `#e8f3ff`。
- 底部有「收起 / 展开」按钮，收起后只留图标（宽 `72px`）。
- 侧边栏自己纵向滚动，不影响内容区。

### 1.6 多页签

原型支持「一个浏览器标签页里开多个业务页」，规则如下：

1. 每次进入新路径，自动在页签区追加一个页签，标题取菜单名。
2. 只剩一个页签时**不显示关闭按钮**，避免关成空页面。
3. 关闭当前页签时，自动跳到它左边相邻的页签；左边没有就跳右边；都没有就回工作中心。
4. 关闭非当前页签，当前页面不受影响。
5. 深链参数（如 `applyNo`）在关闭页签时自动清掉，避免「关掉详情又被列表弹回详情」的循环。
6. 页签选中态同样是橙色系（与模块导航一致），不要用主色蓝。

### 1.7 内容区

- 统一容器 `page-surface`：白底、圆角 `12px`、浅阴影、内部滚动。
- 页面根节点统一 `className="space-y-4 p-6"`；页面内垂直区块间距 `space-y-4`，大区块内部再按需 `gap-4`。
- **不要在 `page-surface` 外面再套一层带背景色的容器**，白底由它负责。

## 2. 页面标题区

业务页顶部统一是标题区，结构固定：

```text
一级标题（页面名）                      ← h1
一行灰色说明（这个页面能做什么）          ← 可选，text-sm 灰色
```

- 标题类名统一写 `text-2xl font-semibold tracking-tight`；**实际渲染是 20px**（被 `page-surface` 覆盖，见 05 第 1.1 节），这是全站统一结果，不要为了「看起来像 24px」去改类名。
- 说明文案写业务用途，不写「本页面用于……」这类废话，也不抄 PRD 条款。
- 标题区下方与筛选卡之间保持 `space-y-4`。

**详情页与表单页**在标题区之上再加一行面包屑：`上级列表名 / 当前页名`，底边有分割线。例如「货品管理 / 货品详情」。

> 面包屑是**推荐做法**：当前 30 个详情/表单页里只有 5 个落地，属于历史欠账。新页面按这一条实现，老页面改动时顺手补。

## 3. 三类页面骨架

### 3.1 台账列表页

```text
┌─────────────────────────────────────────────────────────────┐
│ 标题区：页面名 + 一行说明                                     │
├─────────────────────────────────────────────────────────────┤
│ Card · 筛选区                                                │
│  ├─ 筛选头：筛选条件 …… [展开筛选] [新增?] [重置] [查询]      │
│  └─ 栅格：md 两列 / lg 四列 · 默认露 4 项 · 展开区追加         │
├─────────────────────────────────────────────────────────────┤
│ Card · 列表区                                                │
│  ├─ 工具条（批量操作、导出等，可选）                          │
│  ├─ 表格（最小宽 980px，容器内横向滚动）                      │
│  └─ 分页（共 N 条 + 每页条数 + 页码 + 前往）                  │
└─────────────────────────────────────────────────────────────┘
```

细则见 [02-列表页与筛选区规范](./02-PC端列表页与筛选区规范.md)。

### 3.2 台账详情页

```text
┌─────────────────────────────────────────────────────────────┐
│ 面包屑：上级列表 / 当前页                                     │
├─────────────────────────────────────────────────────────────┤
│ 顶栏摘要卡：标题 + 状态标签 + 关键单号/编号 + 右侧操作按钮     │
├─────────────────────────────────────────────────────────────┤
│ DetailSection · 基本信息                                     │
│ DetailSection · 业务明细 / 附件 / 处置材料 …（按需多块）      │
│ [可选] DetailSection · 操作记录                              │
└─────────────────────────────────────────────────────────────┘
```

- 区块之间 `space-y-4`。
- **不要**再套一层大 Card 把所有板块包成第三层嵌套。
- 细则见 [03-详情页子板块规范](./03-PC端详情页子板块规范.md)。

### 3.3 新增 / 编辑 / 配置页

```text
┌─────────────────────────────────────────────────────────────┐
│ 面包屑 + 顶栏：返回 + 页面标题 + [保存/取消] 或 分块内保存     │
├─────────────────────────────────────────────────────────────┤
│ Card · 基本信息（两列栅格为主）                               │
├─────────────────────────────────────────────────────────────┤
│ Card · 策略/明细区（可折叠卡头、内嵌表格）                    │
│   └─ 每块独立「保存该策略」+ 关闭策略二次确认弹窗             │
└─────────────────────────────────────────────────────────────┘
```

- 细则见 [04-新增编辑与配置页规范](./04-PC端新增编辑与配置页规范.md)。
- 简单 CRUD（字段少于 8 个、一次提交）：基本信息一个 Card + 底部操作条即可，不要为凑结构硬拆多块。

## 4. 顶栏摘要卡（列表、详情、表单通用）

- 容器：`flex flex-col gap-4 rounded-xl border bg-card p-4 lg:flex-row lg:items-center lg:justify-between`。

  > 圆角写 `rounded-xl`，但实际渲染是 `8px`（被覆盖层统一），见 05 第 1.1 节。

- 左侧：主标题 + 状态标签 + 一行关键信息（单号、编号、时间），状态标签**不与标题抢同一行位置**，跟着标题后面走。
- 右侧：操作按钮组 `flex flex-wrap gap-2`；主操作（编辑、提交）用主色按钮，次要（返回列表、设置价格）用描边按钮。
- 「返回列表」始终是描边按钮或文字链接，**不占主按钮位**。

## 5. 未实现菜单

已收录但还没做的路由，统一用 `PrototypeEmptyPage` 占位，**不要**给占位页单独发明一套壳层或空状态设计。

## 6. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 页面自己加 `min-h-screen` 或外层滚动容器 | 整页固定，只在 `page-surface` 内滚 |
| 给工作中心加左侧菜单树 | 工作中心无侧边栏，用审批中心卡片聚合 |
| 页签选中态用主色蓝 | 与模块导航一致，用橙色 |
| 关掉最后一个页签后停在空白页 | 只剩一个页签时隐藏关闭按钮 |
| 标题区下面又套一层带背景的 div | 白底由 `page-surface` 提供 |
| 详情页在最外层再包一个大 Card | 摘要卡 + 多个 `DetailSection` 平铺 |
