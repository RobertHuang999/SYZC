# 05-PC 端色彩与表格视觉规范

---

## 1. 全局字体与排版约束（Typography）

### 1.1 全局首选字体：PingFang SC（苹方）
PC 端原型全站**统一强制使用 `PingFang SC`** 作为第一优先级主字体。Tailwind 配置与全局 CSS 继承栈统一为：
```css
font-family: "PingFang SC", -apple-system, BlinkMacSystemFont, "Microsoft YaHei", "Segoe UI", Roboto, sans-serif;
```

### 1.2 字体使用禁令与业务排版原则
1. **严禁滥用 `font-mono`**：
   - 业务单号（出库单号、入库单号、关联单号）、时间、货主统一社会信用代码、数量等**常规业务数据严禁添加 `font-mono` 或 `tabular-nums`**。
   - `font-mono` 会强制将字体替换为机械窄长等宽英文字体（Monaco/Courier 等），导致数字与中文视觉严重割裂。
2. **单号完整展示原则（禁止省略截断）**：
   - 列表单号列宽度必须充分预留（通常 `w-[210px]` 左右），**严禁简单粗暴添加 `truncate` 导致单号出现 `...` 截断**。
   - 单号使用 `whitespace-nowrap font-medium text-primary hover:underline`，并支持优雅的 hover 复制按钮。
3. **日期时间排版标准**：
   - 日期时间统一优先使用 `@/shared/components/TableCells` 的 `<TableDateTimeCell value={...} plain />` 单行标准呈现（如 `2026-06-03 10:15:00`），字体完整继承 PingFang SC，列宽预留 `w-[160px]`。
   - 若特殊场景需要分行展示，时分秒亦必须继承主字体（PingFang SC），严禁对下半截时间单独加 `font-mono text-xs text-muted-foreground`。

## 2. 固定操作列（Sticky Action Column）防穿透规范

1. **绝对禁止半透明底色**：
   - `sticky right-0` 操作列在横向滚动时，左侧滑入的内容会经过操作列下方。
   - **必须**使用 100% 不透明的实体背景：
     - **表头操作列**：`bg-slate-100 dark:bg-slate-800 text-foreground/80`；
     - **数据行操作列**：`bg-white dark:bg-slate-900 group-hover:bg-slate-50 dark:group-hover:bg-slate-800 transition-colors`。
2. **边框与阴影标准**：
   - 必须配置左侧隔离边框与渐变阴影：`border-l border-border/80 shadow-[-8px_0_16px_-4px_rgba(0,0,0,0.08)]`。

## 3. page-surface 列表页

列表宿主可使用 `page-surface` 类统一按钮、表格容器样式：

- 表格外容器：浅边框、约 `12px` 圆角，横向 `overflow-x: auto`。
- 表格最小宽度约 **980px**（多列复杂台账建议 **1240px~1360px**），保证列对齐；小屏滚动而非压缩列宽至不可读。
- 行内按钮 `min-height: 32px`，圆角约 `6px`。

## 5. 状态语义（Badge / Tag）

与 H5 风控语义对齐，PC 列表/详情状态 Tag 保持一致含义：

| 语义 | 用途示例 |
| :--- | :--- |
| 待处置 / 进行中 | 预警待处理、审批中 |
| 已结案 / 成功 | 已解除、已通过 |
| 作废 / 失效 | 规则停用、单据作废 |
| 预警 / 高危 | 等级色与等级字典配置色一致 |

等级色点：列表筛选项、详情等级展示使用字典返回色，不硬编码彩虹色。

---

## 6. 表格

1. 表头：浅底、字重 medium，与 body 分隔线清晰。
2. 数值列：右对齐；金额/吨数保留 PRD 规定小数位。
3. 操作列：固定右侧或最小宽度，链接按钮 `ghost`/`link` 尺寸 `sm`。
4. 空态：表格内居中插画/文案，不留空白 tbody。

---

## 7. Toast 与反馈

- 操作结果：`toastMessage` 或统一 Toast 组件，约 3 秒自动消失。
- 校验失败：优先字段旁提示 + 顶部 Toast 摘要；不只用 `alert`（原型可 `window.confirm` 仅用于离开确认）。
