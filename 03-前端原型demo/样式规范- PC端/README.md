## 5. 核心原则

1. **一页两区**：标准台账列表 = 上筛选 Card + 下列表 Card，中间 `space-y-4`。
2. **筛选项默认一行四个**：`lg` 下 4 列，第 5 项起放进「展开筛选」，禁止默认堆两行以上。
3. **详情禁止左右 Label-Value 表行**：统一上下结构（灰小字标签 + 深色内容值）。
4. **配置页分块可独立保存**：多策略时块内保存 + 块级 Dirty，与简单 CRUD 的单次提交区分。
5. **样式改动先看 05 第 1 节**：`page-surface` 覆盖层会让页面里的字号、圆角、控件高度类名失效，要改就改 `index.css`。
6. **表格一列只表达一件事**：数字右对齐、状态用标签、空值统一「—」、操作列最多 3 个/行（见 06）。

## 6. 已知偏差与收敛计划

以下是「规范已写明、工程尚未对齐」的项，按优先级排列，**新页面一律按规范写，老页面顺路修**：

| 优先级 | 偏差 | 影响面 | 处理方式 |
| :--- | :--- | :--- | :--- |
| 高 | `body` 字体栈缺「Microsoft YaHei」，Windows 上中文会掉到系统默认 | 全站 | 改 `index.css` 的 `body` 字体声明，与 `@theme` 统一 |
| 高 | 无统一轻提示组件，停留时间有 5 种 | 全站 | 抽 `Toast` 组件，统一 2500ms |
| 中 | 固定操作列底色 4 种、阴影写法不一 | 约 20 个列表 | 改动该列时统一到 05 第 4.3 节 |
| 中 | 只有 7 个文件用 `TableRowActionPanel`，另有 6 处手写链接按钮 | 约 13 个表格 | 改动该表时换成组件（宽度、换行、危险项分隔才可控） |
| 中 | 老表仍是 44px 内容自适应行高，只有入库记录改成标准 72px | 其余台账 | 改到哪张表就换哪张，不做专项返工 |
| 中 | 操作列宽度从 80px 到 280px 混用，未按按钮数定宽 | 约 13 个表格 | 按 06 第 5.2 节定宽 |
| 中 | 勾选行没有底色反馈，只勾了复选框 | 预警类批量列表 | 补 `bg-blue-50/60` 行高亮 |
| 中 | 表格容器圆角 `rounded-md` / `rounded-lg` 混用 | 少数列表 | 新页面用 `rounded-lg` |
| 中 | 空态只有一行文字，无原因说明与「重置筛选」 | 多数列表 | 后续统一空态组件 |
| 低 | 空值写法混用：`—` / `--` / `——` | 少数页面 | 统一「—」 |
| 低 | 状态色 `green-*` 4 处与 `emerald-*` 50 处并存 | 预警结案类 | 统一 emerald |
| 低 | 「预警等级」1 项筛选用 flex 排布、门禁设备用 6 列栅格 | 2 个列表页 | 改动时：等级页保持例外，门禁设备收敛到 `lg:grid-cols-4` |
| 低 | 详情/表单页面包屑只落地了 5 处（共 30 个页面） | 详情、表单 | 新页面按 01 第 2 节补，老页面顺路补 |
| 低 | 浏览器刷新拦截（`beforeunload`）未接 | 配置页、表单页 | 按需补监听 |
