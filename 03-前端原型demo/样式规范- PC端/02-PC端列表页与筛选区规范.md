# 02-PC 端列表页与筛选区规范

> 列表页是原型里出现最多的一类页面，本章把「筛选区 + 列表区」的写法定死。
> 颜色、表格行高、操作列样式见 [05-色彩、字体与表格视觉规范](./05-PC端色彩与表格视觉规范.md)。

---

## 1. 一页两区

标准台账列表 = **上面筛选卡 + 下面列表卡**，两卡之间 `space-y-4`，外面再套 `space-y-4 p-6` 与标题区。

```text
标题区（页面名 + 说明）
Card · 筛选卡：筛选头 + 默认栅格 +（展开后）追加栅格
Card · 列表卡：工具条（可选）+ 表格 + 分页
```

- 两区**不合并成一个 Card**，必须有视觉分隔。
- 页面根节点：`className="space-y-4 p-6"`。

---

## 2. 筛选区容器

1. 外层 `Card`，内容区 `CardContent` 加 `className="space-y-4 pt-4"`。
2. 结构自上而下：**筛选头 → 默认筛选项栅格 →（条件渲染）展开筛选项栅格**。
3. 筛选头与栅格之间靠 `space-y-4` 拉开，不额外加分割线；筛选头自带底部分割线。

---

## 3. 筛选头

统一用 `WarningFilterHeader` 组件（`B端PC/src/components/business/WarningListPrimitives.tsx`），不要页面内手写。

布局：`flex flex-wrap items-center justify-between gap-2 border-b border-border pb-3`。

| 区域 | 内容 |
| :--- | :--- |
| 左 | 文案「筛选条件」，`text-sm font-medium` |
| 右（从左到右） | 展开/收起筛选 → **新增**（若有）→ 额外操作 → 重置 → 查询 |

**展开 / 收起**：

- 默认收起，只露第一行 4 个筛选项。
- 收起时按钮文案「展开筛选」+ 下箭头；展开时「收起筛选」+ 上箭头。
- 必须带 `aria-expanded`，与实际展开状态同步。
- 筛选项不超过 4 个、没有需要收起的条件时（如大类管理只有「名称 + 状态」），**不渲染展开按钮**。

**重置与查询**：

- 「查询」主色按钮 `size="sm"`；「重置」描边按钮 `size="sm"`。
- 筛选条件分两份状态：**草稿态（draft）** 与 **生效态（applied）**。
- 输入、选择只改草稿态；点「查询」才写进生效态并回到第 1 页；列表数据只读生效态。
- **禁止**输入即刷新列表；输入框里按回车等价于点「查询」。

---

## 4. 筛选项栅格

### 4.1 默认区

- 栅格：标准写法 `grid gap-4 sm:grid-cols-2 lg:grid-cols-4`。
  - 硬指标只有一条：**`lg`（≥1024px）及以上固定 4 列，一行排 4 个**。
  - 窄屏降为 2 列或 1 列都可以；工程现状多数只写了 `lg:grid-cols-4`（窄屏变单列），效果可接受，不算违规。
- **默认露出 4 个**筛选项（`lg` 下一行排满）；窗口在 `md` 档位时两列。
- 单项结构：

```text
字段名（text-xs / 次要灰色）      ← Label
控件（w-full，高 34px）          ← Input / Select / 级联选择 / 多选
```

- 字段名字号 `text-xs`、颜色用次要灰（`text-muted-foreground`），**不要**用 `text-sm` 加粗，避免筛选区比数据区还抢眼。
- 字段名控制在 2～6 个字。
- 控件宽度一律 `w-full`，高度由覆盖层统一成 `34px`。

### 4.2 推荐摆放顺序

业务主维度（名称 / 单号）→ 等级或状态 → 组织 / 仓库 → 时间（时间类优先放展开区）。

### 4.3 展开区

1. 第 5 个及以后的筛选项、时间范围（开始～结束）一律放展开区。
2. 展开区继续用同一套栅格；需要占两列的用 `lg:col-span-2`（如「入库开始日期 ～ 结束日期」）。
3. 展开区与默认区在同一个 Card 内连续排布，不加额外的块级背景或内嵌卡片。
4. **禁止**默认态露出超过 4 项、把筛选区堆到两行以上（业务确有需要必须评审通过）。

### 4.4 例外

1. **只有 1～2 项筛选**的页面（如「预警等级」只有「是否启用」）不必硬凑 4 列，可用 `flex ... lg:flex-row lg:items-end lg:justify-between` 左右排布，筛选头操作按钮放右侧。
2. 时间范围控件、级联树等宽度需求特殊的筛选项，可以单独占两列，但仍受「默认一行、最多 4 项」的总量约束。
3. **门禁设备列表**目前用 `lg:grid-cols-6` 排了 6 个短字段，属历史写法；该页面字段短、勉强能看，但改动时统一回 `lg:grid-cols-4`，第 5、6 项移到展开区。

## 5. 列表区

### 5.1 容器

- 列表外层 `Card`，内容区 `CardContent className="space-y-3 pt-4"`。
- 表格外面再包一层带边框的圆角容器：`overflow-hidden rounded-lg border`，横向溢出在容器内滚动。
- 表格最小宽度 `min-w-[980px]`～`min-w-[1000px]`；列很多的复杂台账用 `min-w-[1240px]` 以上。

### 5.2 工具条（可选）

- 需要批量操作、导出时，在表格上方放一行工具条，与表格之间 `gap-3`。
- 勾选后出现批量操作条，用浅琥珀底提示当前选中条数，例如「已选择 3 条 · 仅『已结案且未公示』可勾选」，右侧放批量按钮。
- 批量危险操作必须二次确认，且确认弹窗里写清影响范围。

### 5.3 列与内容

| 列类型 | 规范 |
| :--- | :--- |
| 序号列 | 宽 `64px`，居中；横向滚动时固定在左侧 |
| 单号列 | 16 位以内 `200px` 单行；17 位以上超长号 `130px`～`150px` 折两行，完整展示、禁止截断，详见 05 第 2.4 节 |
| 名称 / 长文本列 | 用 `HoverOverflowText` 省略 + 悬停看全文，或给足宽度 |
| 时间列 | 用 `TableDateTimeCell`，列表推荐 `stackedPlain`（日期上行、时间下行） |
| 人员 + 时间列 | 用 `TablePersonTimeCell` / `TableProcessedInfoCell` |
| 状态列 | 用标签，颜色按 05 第 3.3 节语义色 |
| 操作列 | 固定右侧，内容统一用 `TableRowActionPanel` |

> **单元格怎么排、列宽怎么给、空值怎么写**：见 [06-表格行与操作列规范](./06-PC端表格行与操作列规范.md) 第 3 节。

### 5.4 操作列

- 固定右侧（`sticky right-0`），底色必须 100% 不透明，细节见 05 第 4.3 节。
- 列内不写裸按钮，统一用 `TableRowActionPanel`：一行最多 3 个、最多直出 9 个、超出进「更多」。
- 操作列宽度按实际按钮数预留（1 列约 82px、2 列约 150px、3 列约 218px，含内边距）。
- 按钮顺序、语气色、禁用与占位规则见 [06-表格行与操作列规范](./06-PC端表格行与操作列规范.md) 第 5 节。

### 5.5 分页（吸底，不随行滚动）

统一用 `WarningListPagination` 组件，**固定在列表区底部**：表格内容滚动时，分页条保持可见，不跟着滚走。

```text
共 N 条                                        每页 [20 条/页 ▾]  ‹ 1 2 … 9 ›  前往 [3 ▾] 页
```

- 位置：`sticky bottom-0`，白底 + 顶部 1px 分割线 + 上投影，盖住下方滚过的行；左右铺满卡片（`-mx` 抵消卡片内边距）；**底边与内容区底边齐平**（壳层 `.main-area` 底部不留白），不再留 20px 灰边。
- 左：「共 N 条」，次要灰，`text-sm`。
- 右：每页条数下拉（`w-24`，默认 10 / 20 / 50）+ 页码（含省略号）+ 前往指定页下拉（`w-20`）。
- 翻页、改每页条数都要与「生效态筛选」联动；改每页条数时回到第 1 页。
- 分页必须是列表卡片的**最后一个元素**，下面不再放其他内容，否则吸底会挡内容。
- **层级**：分页条 `z-30`，必须高于表格固定操作列（`z-20`）与序号列（`z-10`），否则行数据会盖在分页上（踩过的坑）。

### 5.6 空态

- 表格内一行居中提示，说明原因并给出下一步（如「暂无数据，可调整筛选条件后重试」）。
- 有筛选条件的页面，空态旁提供「重置筛选」。
- 不允许留空白表身，也不允许用假数据把表格撑满。

## 6. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 筛选项没有头栏，重置/查询散落在页面角落 | 统一 `WarningFilterHeader`，按钮右对齐 |
| 10 多个筛选项默认全露、占掉半屏 | 默认 4 项 + 展开筛选 |
| 筛选和列表挤在一个 Card 里 | 筛选卡 + 列表卡两张 |
| 输入框一改就请求列表 | 草稿态 / 生效态分离，点查询才生效 |
| 筛选字段名用 `text-sm` 加粗，比数据还显眼 | `text-xs` 次要灰 |
| 操作列半透明、滚动后文字叠在一起 | 不透明底色 + 隔离线 + 阴影 |
| 单号列 `truncate` 出现省略号 | 16 位内 200px 单行；超长号 130～150px 折两行，完整展示 |
| 分页只放一个页码输入框 | 用 `WarningListPagination` 标准结构 |
