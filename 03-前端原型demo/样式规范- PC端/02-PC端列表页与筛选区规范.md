# 02-PC 端列表页与筛选区规范

---

## 1. 筛选区容器

1. 筛选区必须放在 **白底 Card** 内：`Card` + `CardContent`，与列表区视觉分离。
2. Card 内结构自上而下：
   - **筛选头**（见第 2 节）
   - **默认筛选项栅格**（见第 3 节）
   - **展开筛选项栅格**（见第 4 节，条件渲染）

---

## 2. 筛选头（固定交互）

筛选头布局：`flex flex-wrap items-center justify-between gap-2 border-b border-border pb-3`。

| 区域 | 内容 |
| :--- | :--- |
| 左 | 文案「筛选条件」`text-sm font-medium` |
| 右 | 按钮组，顺序建议：**展开/收起筛选** → **新增**（若有）→ 额外操作 → **重置** → **查询** |

**展开/收起**：

- 默认 `expanded = false`，仅展示第一行 4 个筛选项。
- 按钮文案：收起时「展开筛选」+ 下箭头；展开时「收起筛选」+ 上箭头。
- 使用 `aria-expanded` 与展开状态同步。

**查询与重置**：

- 「查询」为主按钮 `size="sm"`；「重置」为 `outline`。
- 筛选条件分 **draft**（表单态）与 **applied**（点击查询后生效），列表数据只读 applied，避免输入即刷列表。

---

## 3. 默认筛选项栅格（一行四个）

- 栅格：`grid gap-4 lg:grid-cols-4`。
- **默认可见**筛选项数量：**4 个**（对应 lg 下一行排满）。
- 每个筛选项结构：
  - 上方 `Label`：`text-sm`，字段名简短（2～6 字为宜）。
  - 下方控件：`Select` / `Input` / 级联选择 / 多选下拉，**宽度 `w-full`**。
- 筛选项类型建议顺序：业务主维度 → 等级/状态 → 组织/仓库 → 时间或编号（时间类可放展开区）。

---

## 4. 展开区筛选项

1. 当存在第 5 个及以上筛选项、或时间范围等宽控件时，放入 `expanded === true` 才渲染的区域。
2. 展开区继续使用 `grid gap-4 lg:grid-cols-4`；需要占两列时使用 `lg:col-span-2`（如「开始日期 至 结束日期」）。
3. 展开区与默认区**同一 Card 内连续栅格**， expanded 块前可加 `border-t pt-4` 与默认区弱分隔（可选）。
4. **禁止**默认态下超过 4 个筛选项同时露出导致两行以上堆叠（除非业务明确要求且评审通过）。

---

## 5. 列表区

1. **容器**：
   - 推荐列表外包一层 Card；表格外层使用 `page-surface` 时，表格容器带 `border rounded-xl`，横向溢出可滚动。
2. **表格**：
   - 最小宽度约 980px，列多时在容器内横向滚动，不挤压筛选项区。
   - 状态列用 Badge/语义色，长文本列省略号 + title 或详情页查看全文。
3. **行操作**：
   - 高频 1～2 个链接/按钮列内展示；更多收到「更多」下拉，避免操作列过宽。
4. **批量**：
   - 复选列 + 表头上方批量工具条；批量危险操作必须二次弹窗且必填说明（字数上限按 PRD）。
5. **分页**：
   - 右下或列表 Card 底部：`每页条数` + 页码 + 上一页/下一页；与筛选 applied 状态联动。

---

## 6. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 筛选项无头栏，重置/查询散落在页面角落 | 统一筛选头 + 右对齐操作组 |
| 10+ 筛选项默认全部展开占半屏 | 默认 4 项 + 展开筛选 |
| 筛选与列表混在一个 Card 无分隔 | 筛选 Card + 列表 Card / surface |
| 输入框一改就请求列表 | draft/applied 分离，点查询才生效 |
