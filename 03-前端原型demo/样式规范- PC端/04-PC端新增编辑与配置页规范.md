# 04-PC 端新增编辑与配置页规范

---

## 1. 适用场景

本规范适用于 **配置类、多策略、多步骤保存** 的新增/编辑页（如预警规则、审批配置、复杂订单策略包）。  
简单 CRUD（字段少于 8 个、单次提交）可合并为单 Card + 底栏保存，但顶栏与 Dirty 规则仍遵循本节。

---

## 2. 页面骨架

```text
┌─ 顶栏 Card ─────────────────────────────────────────────┐
│ [← 返回]  页面标题（新增/编辑 + 业务主键）    [全局操作?] │
└─────────────────────────────────────────────────────────┘
┌─ Card · 基本信息 ───────────────────────────────────────┐
│ 规则名、关联订单/设备、通知对象等 · grid 2～4 列           │
└─────────────────────────────────────────────────────────┘
┌─ Card · 策略/明细区 ─────────────────────────────────────┐
│ CardHeader：区块标题 + 说明文案                            │
│ 策略 1 [Switch] ─ 展开字段 / 内嵌 Table ─ [保存该策略]    │
│ 策略 2 …                                                 │
└─────────────────────────────────────────────────────────┘
```

- 垂直间距：`space-y-4 p-6`。
- **不强制 Tab**：策略块以 **Card 内折叠/展开** 或 **纵向多 Card** 组织；若业务步骤清晰且超过 3 个大阶段，可用 Tab，但每 Tab 内仍用 Card 分块。

---

## 3. 基本信息区

1. 独立 `Card` + `CardHeader`（`CardTitle` 如「基本信息」）+ `CardContent`。
2. 字段布局：`grid gap-4 sm:grid-cols-2 lg:grid-cols-3` 或 4 列，与详情四列体系对齐。
3. 每项：`Label` 在上、控件在下；必填星号在 Label 旁。
4. 关联主数据（订单号、设备范围）变更时，下方策略区联动刷新 Mock 数据并提示未保存策略。

---

## 4. 策略/多区块区

1. **标题**：说明「逐条独立保存」「至少启用 1 项」等业务约束（文案来自 PRD）。
2. **单策略块**：
   - 块头：序号 + 策略名 + 启用 Switch。
   - 块体：该策略专属字段；含明细时用 **内嵌 Table**（可编辑行），不用弹窗代替整表（行级选择除外）。
   - 块脚：主按钮「保存该策略」；仅该块 Dirty 时可点。
3. **关闭/停用策略**：Switch 关到 OFF 时，若 PRD 要求二次确认 → `Dialog`，说明停用后果（作废未处理流水等），确认后再写入表单态。
4. **至少一项有效**：全局校验：关闭最后一项有效策略时 Toast 阻断，不提交。

---

## 5. 业务弹窗

| 场景 | 规范 |
| :--- | :--- |
| 选择设备/货物/订单 | 大号 `Dialog`，内嵌筛选 + 表格多选/单选，确认带回显列表 |
| 删除/停用/偏离推荐配置 | `Dialog` + 说明后果 + 确认/取消 |
| 处置方式偏离推荐 | 单独确认 Dialog，展示推荐值与当前值对比 |
| 图片/凭证 | 预览 Modal，不在表单 Card 内无限拉高 |

弹窗 footer：取消 `outline`，确认 `default`； destructive 用红色强调文案，不单靠按钮颜色。

---

## 6. Dirty 与离开防护

1. 配置页策略级 Dirty：任一块未保存修改时，路由离开、`beforeunload` 须拦截或 `window.confirm`。
2. 单页级 Dirty：整表 `dirty` 标志 + 浏览器刷新拦截。
3. 保存成功：Toast + 清除对应块 Dirty；编辑态可递增版本号展示（只读字段）。

---

## 7. 与台账表单的区别

| 维度 | 台账新增（如入库单 PC） | 配置/策略页（本节） |
| :--- | :--- | :--- |
| 保存 | 通常底栏一次提交 | 分块保存 + 可选整单发布 |
| 结构 | 基本信息 + 货物明细 Card | 基本信息 + 多策略 Card |
| 弹窗 | 关联单、附件、审批流选择 | 设备/订单选择、策略停用确认 |

PC 端简单入库/出库表单：基本信息区可复用本节 Card 规范，明细区用可折叠行 Card；若步骤大于 2 段，优先分 **路由分步** 或 **顶部步骤条**（与 H5 步骤语义一致，步数按 PRD）。

---

## 8. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 10 个策略一次保存，无 Dirty 粒度 | 逐策略保存 + 块级 Dirty |
| 设备选择用原生多选 `<select>` | Dialog + 表格勾选 |
| 停用策略无确认 | Dialog 说明业务后果 |
| 表单页无返回 | 顶栏返回 + 列表 deep link |
