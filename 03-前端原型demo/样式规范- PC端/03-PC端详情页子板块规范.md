# 03-PC 端详情页子板块与字段规范

---

## 1. 子板块（DetailSection）

每个业务语义块使用**独立白底卡片板块**，结构固定为：**标题栏 + 内容区**。

### 1.1 视觉 token

| 元素 | 规范 |
| :--- | :--- |
| 外框 | 白底 `#fff`，边框 `1px solid #e5e6eb`，圆角 `8px` |
| 标题栏 | 内边距约 `18px 24px 16px`，底部分割线 `#f0f1f3` |
| 标题字 | `17px` / `font-weight 600` / 色 `#1d2129` |
| 内容区内边距 | 约 `22px 24px 24px` |

### 1.2 板块划分原则

- **基本信息**：单号、状态、时间、主体、仓库等摘要字段。
- **业务事实**：预警内容、货物明细、阈值快照、IoT 读数等。
- **凭证与附件**：图片栅格、PDF 链接、现场照片；整块可 `grid-column: 1 / -1` 通栏。
- **处置/审批材料**：仅在有数据或状态允许时展示，不与基本信息混块。
- **时间轴/操作记录**：单独一块，节点合并展示（申请+结论+意见），禁止一节点一巨 Card。

板块之间页面级间距 `space-y-4`。

---

## 2. 字段展示（DetailField · 上下结构）

**强制**：字段名与字段值采用**上下结合**，禁止 PC 详情使用「左 Label 右 Value」两列表格作为默认样式。

### 2.1 结构

```text
┌─ detail-field ─────────────────┐
│  字段名称（灰、小字）            │  ← detail-field-label
│  字段内容（深、正文）            │  ← detail-field-value
└────────────────────────────────┘
```

| 元素 | 规范 |
| :--- | :--- |
| 标签 | `#86909c`，`13px`，行高 20px |
| 内容 | `#1d2129`，`14px`，行高 22px；空值显示「—」 |
| 字段间距 | 列间距约 `28px`，行间距约 `22px` |

### 2.2 内容区栅格

- 内容区默认 **4 列等分**：`grid-template-columns: repeat(4, minmax(0, 1fr))`。
- 视口宽度小于约 1100px 时降为 **3 列**。
- 通栏内容（表格、图片组、长文本、嵌套子表）：子元素占 `grid-column: 1 / -1`。
- 单字段内如需再拆子字段，可嵌套 `DetailField`，嵌套间距略减（约 4px）。

---

## 3. 顶栏与板块关系

1. **顶栏摘要 Card**（见 01 规范）承载：标题、状态、关键单号、主操作。
2. **DetailSection 不重复**顶栏已展示的主标题与状态，除非 PRD 要求详情正文再次固定展示（如打印视图）。
3. 图片字段：缩略图网格 + 点击放大 Modal；多图用相册式切换。

---

## 4. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 所有字段塞一个 Card 无标题分块 | 按语义多个 DetailSection |
| Label 与 Value 同一行左右对齐 | DetailField 上下结构 |
| 5 层 Card 嵌套明细 | 明细 Table 通栏或跳转子页 |
| 空板块占位 | 无数据则不渲染该 Section |
