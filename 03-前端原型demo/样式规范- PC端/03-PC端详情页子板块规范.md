# 03-PC 端详情页子板块与字段规范

> 本章是 PC 视觉里**与代码吻合度最高**的一份：`DetailSection` / `DetailField` 的样式已经固化在 `src/index.css` 的 `.detail-section`、`.detail-field` 里。
> 新增详情页直接复用这两个组件，不要自己写卡片和字段排版。

---

## 1. 页面结构总览

```text
面包屑（上级列表 / 当前页）                     ← 有底部分割线
顶栏摘要卡（标题 + 状态 + 关键编号 + 操作按钮）  ← 见 01 第 4 节
DetailSection · 基本信息
DetailSection · 业务明细 / 字段明细
DetailSection · 附件凭证（有数据才出现）
DetailSection · 操作记录（有数据才出现）
```

- 区块之间统一 `space-y-4`。
- **不要再在最外层包一个大 Card**，看板类页面也别把各板块塞进一个卡片里做第三层嵌套。

---

## 2. 子板块（DetailSection）

每个业务语义块一张独立白底卡片，结构固定为「标题栏 + 内容区」。

### 2.1 视觉参数（与代码一致，不要自行改）

| 元素 | 参数 |
| :--- | :--- |
| 外框 | 白底 `#ffffff`、边框 `1px solid #e5e6eb`、圆角 `8px` |
| 标题栏 | 内边距 `18px 24px 16px`，底部分割线 `#f0f1f3` |
| 标题文字 | `17px`、字重 `600`、颜色 `#1d2129`、行高 `24px` |
| 内容区内边距 | `22px 24px 24px` |
| 字段网格间距 | 列间距 `28px`、行间距 `22px` |

### 2.2 板块怎么分

| 板块 | 放什么 |
| :--- | :--- |
| 基本信息 | 单号、状态、时间、主体、仓库等摘要字段 |
| 业务事实 | 预警内容、货物明细、阈值快照、设备读数等 |
| 凭证与附件 | 图片网格、PDF 链接、现场照片；整块通栏 |
| 处置 / 审批材料 | 有数据或状态允许时才出现，不与基本信息混块 |
| 操作记录 | 单独一块；一次审批的申请、结论、意见合并展示 |

规则：

1. **无数据的板块不渲染**，不留「暂无」空块占位。
2. 板块标题写业务语言（「基础规格档案」「入库收集信息配置」），不要写「信息 1」「详情」。
3. 一个板块内字段控制在 4～16 个；超过就拆板块，不要靠滚动长度凑。
4. 板块标题不重复顶栏已展示的主标题和状态。

## 3. 字段展示（DetailField）

**强制上下结构**：字段名在上、字段值在下。PC 详情页**禁止**默认使用「左标签右内容」的两列表格行。

### 3.1 结构与参数

```text
┌─ detail-field ─────────────────┐
│ 字段名称（次要灰、13px）         │  ← detail-field-label
│ 字段内容（正文色、14px）         │  ← detail-field-value
└────────────────────────────────┘
```

| 元素 | 参数 |
| :--- | :--- |
| 标签 | `#86909c`、`13px`、行高 `20px` |
| 内容 | `#1d2129`、`14px`、行高 `22px` |
| 标签与内容间距 | `6px` |
| 空值 | 统一显示「—」，用 `formatEmptyValue` 处理，不要显示 `null`、`undefined`、空字符串 |

### 3.2 内容区栅格

- 默认 **4 列等分**：`grid-template-columns: repeat(4, minmax(0, 1fr))`。
- 窗口宽度小于约 `1100px` 时降为 **3 列**。
- 整行内容（表格、图片组、长文本、嵌套子表）占满一行：`grid-column: 1 / -1`。
- 单个字段里再拆子字段时嵌套 `DetailField`，嵌套后间距收紧到 `4px`。
- 字段值过长时自动换行（`overflow-wrap: anywhere`），**不要**加 `truncate`，详情页要看全文。

### 3.3 字段值里的常见写法

| 内容 | 写法 |
| :--- | :--- |
| 单号 / 编码 | 正文色 + 右侧小号复制按钮；可加粗（`font-medium`）但不套等宽字体 |
| 时间 | 完整到秒，如 `2026-06-03 10:15:00`，继承正文字体 |
| 金额 / 吨数 | 千分位 + 固定小数位，右对齐的场景用表格 |
| 状态 | 标签（颜色按 05 第 3.3 节），不要写成纯文字 |
| 布尔 / 是否 | 写「是 / 否」或「启用 / 停用」，不写 `true / false` |
| 图片 | 缩略图网格，点击放大查看，多图支持左右切换 |
| 附件 | 文件名 + 大小 + 下载/预览，列表形式，条数多时要能折叠 |

---

## 4. 顶栏与板块的分工

1. 顶栏摘要卡承载：主标题、状态、关键编号、主操作按钮。
2. 板块正文**不重复**顶栏已经给出的主标题与状态（打印视图等特殊场景除外，需在 PRD 里写明）。
3. 附件、图片等需要整块展示的内容，放到独立板块并通栏，不要塞进四列栅格硬挤。

---

## 5. 反面设计

| ❌ 禁止 | ✅ 应做 |
| :--- | :--- |
| 所有字段塞进一个 Card，没有标题分区 | 按业务语义拆多个 `DetailSection` |
| 标签和值左右对齐排成表格行 | `DetailField` 上下结构 |
| 五层卡片嵌套展示明细 | 明细用表格通栏，或跳转子页面 |
| 没数据的板块也渲染一个空卡片 | 无数据直接不渲染 |
| 详情页字段值加 `truncate` 只显示半截 | 允许换行，长内容整行展示 |
| 自己写 `.detail-section` 的样式覆盖 | 复用组件，改样式只改 `index.css` 一处 |
| 空值显示「空」「无」「/」混用 | 统一「—」 |
