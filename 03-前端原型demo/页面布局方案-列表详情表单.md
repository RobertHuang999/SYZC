# 页面布局方案 · 列表 / 详情 / 新增编辑

> **这是什么**：一页看懂三类页面「长什么样、每一块放什么、怎么排」。
> **条文真源**仍是 [`样式规范- PC端/`](./样式规范-%20PC端/README.md) 与 [`样式规范- H5端/`](./样式规范-%20H5端/README.md)；本文只画骨架，方便对齐认知。
> **怎么用**：新菜单开工前先照本文选骨架 → 填字段 → 最后挂标注三件套。

## 0. 三句话记住

| 页面 | 一句话 | 关键记忆点 |
| :--- | :--- | :--- |
| 列表页 | 上面筛、下面表（PC）/ 卡片（H5） | PC：**筛选项一行 4 个，第 5 个起折叠** |
| 详情页 | 上面一张摘要，下面一堆板块 | 字段**名在上值在下**（PC）/ **左名右值**（H5） |
| 新增编辑页 | 上面基本信息，下面明细或策略 | PC 一次提交；H5 分步 + 吸底按钮 |

### 1.2 点「展开筛选」之后

```text
│ 筛选条件                          [收起筛选 ⌃] [+ 新增] [重置] [查询]   │
│ ───────────────────────────────────────────────────────────────────────  │
│  入库单号        货主名称        入库类型         仓库名称               │  ← 默认区（4 个）
│  [__________]    [__________]    [请选择  ⌄]      [全部仓库  ⌄]         │
│                                                                          │
│  入库日期（占两列）              货品名称         制单人                 │  ← 展开区（第 5 个起）
│  [开始日期] 至 [结束日期]        [全部货品 ⌄]     [请选择  ⌄]           │
```

### 1.3 四条硬规矩

| 规矩 | 说明 |
| :--- | :--- |
| **一行 4 个** | 桌面宽度下固定 4 列；少于 4 个就左对齐排，不拉伸铺满；多于 4 个**必须**折叠 |
| **第 5 个起折叠** | 点「展开筛选」才出现，展开区仍按 4 列排；日期范围占 2 列 |
| **按钮顺序固定** | 展开/收起 → 新增（若有）→ 额外操作 → 重置 → 查询，全部靠右 |
| **点了查询才生效** | 输入只改草稿，点「查询」才刷新列表；重置清空并回到第 1 页 |

### 1.4 列表区要点

- 筛选卡、列表卡是**两张分开的卡**，中间留 16px。
- 表格横向可滚；**操作列固定在最右边**，底色不透明。
- 操作列一行最多 3 个按钮，最多直出 9 个，第 10 个起收进「更多」。
- 单号完整显示，**不许打省略号**，悬停出现复制按钮。
- 分页固定在列表底部：左边「共 N 条」，右边每页条数 + 页码 + 前往。

```text
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.2 三条硬规矩

| 规矩 | 说明 |
| :--- | :--- |
| **字段名在上、值在下** | 每个字段是一个「灰小字标签 + 深色内容值」的竖排小块，**禁止**做成左边标签、右边值的表格行 |
| **一行 4 个字段** | 桌面 4 列；窗口窄于约 1100px 自动降 3 列；表格、图片、长文本**整行通栏** |
| **按业务分板块** | 每个板块一张白卡，有自己的标题（基本信息 / 业务事实 / 附件 / 操作记录）；没数据的板块直接不显示 |

### 2.3 摘要卡放什么

- 左边：主标题（货品名 / 单号 / 规则名）+ 状态标签 + 一行关键信息（编号、时间）。
- 右边：主操作（编辑、提交）+ 次要操作（返回列表、设置价格）。
- **返回列表永远是次要按钮**，不抢主按钮的位置。

## 3. PC · 新增 / 编辑页

### 3.1 骨架图

```text
┌ 货品管理 / 新增货品 ───────────────────────────── ← 面包屑             │
├─ 顶栏 ──────────────────────────────────────────────────────────────────┤
│ [← 返回]   新增货品                                     [取消] [保存]   │
├─ 基本信息 ──────────────────────────────────────────────────────────────┤
│  所属大类 *        所属品类 *        货品名称 *                          │
│  [请选择  ⌄]       [请选择  ⌄]       [________________]                 │
│                                                                          │
│  计量单位 *        参考单价 *        执行标准                            │
│  [吨  ⌄]           [________] 元     [________________]                 │
├─ 明细 / 策略区 ─────────────────────────────────────────────────────────┤
│  预警策略配置（逐条独立保存 · 至少启用 1 项）   ← 卡头写业务约束         │
│  ┌────────────────────────────────────────────────────────────────────┐ │
│  │ 01 价格预警        [开关]            ● 未保存     [保存该策略]      │ │
│  │    阈值 [____] 元/吨   通知对象 [____]                              │ │
│  └────────────────────────────────────────────────────────────────────┘ │
│  ┌────────────────────────────────────────────────────────────────────┐ │
│  │ 02 库存预警        [开关]            ✓ 已保存                       │ │
│  └────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.2 两种保存方式，先判断再选

| 情况 | 骨架 | 保存放哪 |
| :--- | :--- | :--- |
| **简单表单**（字段少于 8 个，一次填完） | 一张基本信息卡 +（可选）一张明细卡 | 顶栏右侧「保存 / 取消」或底部操作条 |
| **配置类 / 多策略**（多个独立块，可分别启用） | 基本信息卡 + 多个策略卡 | **每个块自己「保存该策略」**，块头显示「● 未保存 / ✓ 已保存」 |

### 3.3 硬规矩

- 基本信息**两列为主**，字段都很短才用三列，**不要挤四列**。
- 字段名在上、控件在下；必填星号紧贴字段名。
- 有未保存改动时点返回，必须弹确认（「当前有未保存修改，确定离开吗？」）。
- 选设备、选订单这类要用**大弹窗 + 表格勾选**，不用原生多选下拉。

## 4. H5 · 列表页

```text
┌──────────────────────────────┐
│ ‹ 入库记录                   │ ← 标题栏 44px
├──────────────────────────────┤
│ [▣②] [ 请输入单号/货主/货物 🔍] │ ← 「更多筛选」按钮 + 搜索框
│ [入库类型 ▾][货主 ▾][仓库 ▾] →  │ ← 横向滚动的下拉胶囊
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ 入库 · 普通入库        ⚠  │ │ ← 类型条
│ │ [森] 森云科技  91xx… 单据  │ │ ← 主信息行
│ │ ┌──────────────────────┐ │ │
│ │ │ 入库单号    RK2026…   │ │ │ ← 浅灰底指标块
│ │ │ 仓库名称    宝山1号仓  │ │ │   （左名右值）
│ │ │ 入库货品    热轧卷板   │ │ │
│ │ │ 入库数量    1,250 吨   │ │ │
│ │ └──────────────────────┘ │ │
│ │ 制单人 张三               │ │ ← 经办信息
│ │ 2026-08-25 10:30          │ │
│ │   [单据下载][资料管理][查看详情][更多操作⌄] │ │ ← 操作行，一行 4 个胶囊
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ … 第二张卡片 …            │ │
│ └──────────────────────────┘ │
├──────────────────────────────┤
│ 首页    工作台   业务办理   我的 │ ← 底部四大 Tab
└──────────────────────────────┘
```

要点：

- 首屏只放**搜索 + 常用胶囊**，其余条件点「更多筛选」从**底部**弹出。
- 卡片固定五段：类型 → 主体 → 指标块 → 经办 → 操作。
- 卡片上操作放**胶囊按钮，一行最多 4 个**；超过 4 个时第 4 个换成【更多操作】，点它在卡片内向下展开。
- 单号在卡片里可以省略，点击进详情看完整号。

- 字段默认**左名右值**（跟 PC 相反）；长文本、图片、表格才改上下结构。

- 竖色条按语义：蓝=基本信息、橙=风险、绿=结论、靛=记录。
- 有吸底栏时，内容底部要留出空间，别挡住最后一条。

## 6. H5 · 新增 / 编辑页

```text
┌──────────────────────────────┐
│ ‹ 入库单填写                  │
├──────────────────────────────┤
│  ①────────────②              │ ← 步骤条（多步单据才有）
│ 基础信息      货品明细         │
├──────────────────────────────┤
│ ▎货主信息                     │ ← 分组卡（白底、圆角 8px）
│  货主类型      [企业][个人]    │
│ *货主名称         森云科技  📷 │ ← 一行一项：左名右值
│  入库日期      2026-08-25  ›  │
│ *入库类型         普通入库  ›  │
│  备注            __________   │
├──────────────────────────────┤
│        [      下一步      ]   │ ← 内容末尾全宽按钮
└──────────────────────────────┘
```

要点：

- 两种形态二选一：**原生行式**（左名右值，高频采集）或**标签在上式**（字段多、控件宽），同一组不能混。
- 多步表单用步骤条，下一步按钮放内容末尾；长表单用固定底部按钮栏（带安全区）。
- 选择类一律从底部弹出（单选/多选/级联/日期），不用中间小弹窗。

## 7. 两端对照一张表

| 维度 | PC | H5 |
| :--- | :--- | :--- |
| 列表筛选 | 筛选卡 + **一行 4 个** + 展开区 | 搜索 + 下拉胶囊 + **底部抽屉** |
| 列表形态 | 表格（横向滚动、操作列固定） | 卡片五段式 |
| 列表操作 | 操作列最多 3 个/行，最多直出 9 个 | 卡片底部胶囊一行最多 4 个，超出用【更多操作】向下展开 |
| 单号 | 完整显示，禁止省略 | 可省略，点击进详情 |
| 详情布局 | 面包屑 → 摘要卡 → 多板块 | 标题栏 → 摘要卡 → 页签 → 板块 |
| 详情字段 | **名在上、值在下**，4 列栅格 | **左名右值**，一行一条 |
| 新增编辑 | 基本信息卡 + 明细/策略卡 | 步骤条 + 分组卡 |
| 保存方式 | 顶栏/底部提交；配置类块内保存 | 内容末尾按钮或固定吸底栏 |
| 导航 | 顶部模块 + 侧边栏 + 多页签 | 返回 + 底部四大 Tab |

## 8. 新菜单怎么落地（三步）

1. **选骨架**：按本文第 1～6 节找到对应页面类型，照抄骨架（不要自创）。
2. **填内容**：把 PRD 的字段按板块/分组塞进去；筛选项按「业务主维度 → 状态 → 组织/仓库 → 时间」排，超 4 个就折叠。
3. **挂标注**：补 `PrototypeDocument` 三件套与打点（`AGENTS.md` 4.2），再走 [`原型页面布局速查.md`](./原型页面布局速查.md) 第 5 节检查清单。

## 9. 最常见做错的四件事

| 错误 | 正确 |
| :--- | :--- |
| PC 筛选项堆两行、10 个全露 | 一行 4 个，其余折叠 |
| PC 详情做成「左标签右值」表格行 | 标签在上、值在下 |
| H5 详情把字段名放上面、值放下面一长条 | 左名右值，一行一条（长文本除外） |
| 新增编辑页把所有字段平铺在一张卡上 | 按业务分组，一组一张卡 |
