## 维护与演进准则

1. **功能与权限基线**：任何新增或调整的功能，必须先在 `04` 中明确所属板块、菜单路径、操作按钮、业务规则与 RBAC 权限编码。
2. **端到端流程真源**：任何业务流程变迁，必须在 `06` 中更新 Mermaid 流程图，并详细注明前置校验、后置影响、异常分支与全路径审计要素。
3. **安全与合规红线**：严格遵循 `07` 中的强制硬拦截规则（如自审禁止、人脸门禁短信阻断、物联穿透只读与现场解除闭环等），不得在任何子模块中放宽安全约束。
4. **口径一致性**：涉及数值、金额、公式与状态机，必须严格遵循 `05` 与 `08` 的统一定义，杜绝私设口径。
