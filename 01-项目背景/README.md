## 维护规则

1. 任何新增功能必须先映射到 `04` 的板块、角色和权限。
2. 任何流程变更必须同步说明前置条件、后置影响、异常分支、状态和审计。
3. 业务名称和指标口径不能在配套文档中自行改写；发现冲突时以基准文档为准并登记待确认项。
4. 关键流程使用 Mermaid；正式结论放在本目录或对应的 PRD，过程草稿放在 `00-草稿对话/`。
