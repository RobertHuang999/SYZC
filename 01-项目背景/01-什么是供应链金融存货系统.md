# 什么是 SYZC 供应链金融存货监管系统

## 1. 系统定义

SYZC 是面向资金方、仓储/监管企业、借款企业、核心企业及平台运营方的供应链金融存货监管系统。系统围绕“货、仓、金”建立可追溯的业务链：以物理库存为事实底座，以数字仓单和货权档案承载资产，以融资与风控控制质押和释放，以审批中心统一发出业务指令。

系统记录并联动入库、仓单开立、抵/质押、出库、转让、移库、异动、盘点、预警、交易、统计、结算和配置等能力。具体功能范围以 [04-主要功能模块和清单](./04-主要功能模块和清单.md) 为准，端到端流程以 [06-核心业务场景和流程](./06-核心业务场景和流程.md) 为准。

## 2. 四层业务底座

| 层次 | 作用 | 典型对象 |
| :--- | :--- | :--- |
| 物理作业层 | 采集并管理现场收发存事实 | 入库、出库、移库、盘点、设备 |
| 资产确权层 | 将库存组织为可追溯资产凭证 | 数字仓单、货权档案、存证 |
| 金融业务层 | 管理融资、质押、解押、补仓和处置 | 融资意向、质押单、解押、平仓 |
| 风控与驾驶舱层 | 估值、预警、审批、统计和审计 | 风险事件、待办、报表、看板 |

## 3. 核心价值

- 让入库证据、库存明细、仓单和货权材料能够相互追溯。
- 用质押占用、解押放行和出库核销控制货权释放。
- 用盯市估值、敞口覆盖率和分级预警支持贷中风险处置。
- 用统一审批、权限隔离、幂等控制和审计日志支撑多方协同。

## 4. 不应混淆的概念

库存明细是物理账实对象，数字仓单是系统资产凭证，货权档案是权属证据集合，质押单是金融控制关系；四者关联但不互相替代。系统提供数字化记录、校验和指令控制，不替代法定登记、合同效力、资金清算或司法裁判。
