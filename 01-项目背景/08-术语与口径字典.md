# 术语与口径字典

## 1. 核心业务术语

| 术语 | 统一定义 |
| :--- | :--- |
| 库存明细 | 按货品、批次、货位、数量/重量记录的物理库存单元，不当然代表可融资资产 |
| 数字仓单 | 由合规入库事实和证据生成的电子资产凭证，具备版本、签名和追溯关系 |
| 货权档案 | 合同、发票、运单、提单及其他权属材料组成的证据集合 |
| 质押占用 | 库存或仓单被有效融资业务锁定的控制关系 |
| 放行指令 | 在需要解押或替代担保的出库情形下，由资金方或授权审批方生成的出库授权；并非所有抵/质押单项下出库都自动适用 |
| 盯市估值 | 根据项目约定行情源对押品当前价值进行动态计算 |
| 融资敞口 | 尚未收回的融资本金及按项目规则计入的应计金额 |
| 敞口覆盖率 | 押品当前盯市价值与融资敞口的比率；用于风险判断，具体阈值和动作以项目配置及 `06` 为准 |

## 2. 角色口径

| 角色 | 责任边界 |
| :--- | :--- |
| 资金方 | 授信、质押审核、放款结果确认、解押和风险处置 |
| 仓储/监管企业 | 收发存、盘点、设备和现场证据、仓单基础数据 |
| 借款企业/货主 | 入库、融资、补仓、出库和转让申请及材料提交 |
| 核心企业/交易参与方 | 采购、销售或业务协同中提供的主体和交易资料 |
| 平台运营方 | 机构、权限、参数、接口和运行管理，不代替资金方决策 |
| 审计/监管查看方 | 在授权范围内只读查看报表、证据和日志 |

## 3. 指标公式

`初始质押率 = 融资金额 / 初始押品估值 × 100%`

`盯市价值 = Σ（净重 × 当前市场价格 × 品级/质量系数）`

`敞口覆盖率 = 盯市价值 / 融资敞口 × 100%`

`需补充价值 = 融资敞口 / 目标覆盖口径 - 当前盯市价值`

公式中的价格、净重、质量系数、折扣率、目标值和预警线必须来自可追溯数据源或项目配置。阈值触发关系、补仓和处置步骤以 `06` 为准。

## 4. 数据与审计口径

库存、仓单、质押、预警和审批均以最新有效版本参与计算；历史版本只用于追溯，不得重复计入。指标计算必须记录计算时间、行情源、数据版本、公式版本和结果。操作日志至少包含操作人、机构、时间、来源终端、幂等键、前后数据镜像和关联证据。

## 5. 价格与价值精度口径

| 业务场景 | 默认/切换单位 | 精度与格式规范 | 适用范围与说明 |
| :--- | :--- | :--- | :--- |
| **价格/单价录入** | 元 | 保留 **2 位小数** | 人工录入或配置单价时统一标准（如 `1,234.56` 元） |
| **价值/金额展示（元）** | 元（默认） | 保留 **6 位小数**（带千分位） | 页面及报表默认展示精度（如 `1,234,567.890123` 元） |
| **价值/金额展示（万元）** | 万元（切换） | 保留 **10 位小数**（带千分位） | 用户切换单位为万元时的展示精度（如 `123.4567890123` 万元） |

- **换算与精度控制**：后端存储与中台计算统一采用高精度 Decimal 保存；展示层根据用户选择的单位（元/万元）自动进行转换与千分位格式化渲染，确保切换单位时数值无损且不产生舍入误差。

## 6. 移动端时间筛选与自动补全口径

| 场景 / 操作行为 | 触发条件 | 自动补齐/赋值规则 | 实际查询范围与影响说明 |
| :--- | :--- | :--- | :--- |
| **仅选择结束时间** | 用户在移动端仅设置了【结束时间】，【开始时间】为空 | `开始时间` 默认自动赋值为与 `结束时间` **相同的时间/日期** | 消除未约束开始时间导致后端检索极长历史数据的问题，查询范围精确锁定为该单日/特定时刻 |
| **仅选择开始时间** | 用户在移动端仅设置了【开始时间】，【结束时间】为空 | `结束时间` 默认自动赋值为与 `开始时间` **相同的时间/日期** | 自动形成闭环的时间区间，防止开放式尾部大范围数据查询 |
| **两者均选择** | 用户分别设置了【开始时间】与【结束时间】 | 按用户实际选择的时间区间执行 | 正常区间查询，前端校验需满足 `开始时间 <= 结束时间` |
| **重置 / 清空** | 用户点击清空或重置时间筛选按钮 | 双侧时间同步清空重置为 `null` | 恢复默认无时间约束或全局缺省规则，不触发强行补全 |

- **时间颗粒度与查询范围**：
  - **日期颗粒度（YYYY-MM-DD）**：当系统自动补齐相同日期（如选择结束日期 `2026-08-06`，开始日期自动补齐为 `2026-08-06`），后端实际查询区间为该日 `00:00:00` 至 `23:59:59`，实现快捷定位单日数据。
  - **时间戳颗粒度（YYYY-MM-DD HH:mm:ss）**：补齐相同时间戳，确保单点精准查询。
- **前端交互与状态回显**：前端时间组件在触发 `change` 或 `blur` 事件时，同步更新 Vue 响应式绑定变量（`formData.startTime` / `formData.endTime`），并双向绑定回显至 UI 输入框，使用悉知当前实际生效的查询时间。
