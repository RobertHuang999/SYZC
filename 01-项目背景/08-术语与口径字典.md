# 术语与口径字典

## 1. 核心业务与技术术语

| 术语名称 | 英文标识 / 代码 | 统一业务定义与系统口径 |
| :--- | :--- | :--- |
| **预警严重度** | `Severity Level` / `severity_code` | 全域风控评级字典（03/01），支持租户 2~20 档动态维护，包含名称、颜色、`sort_order` 权重及 `sync_to_order_warn` 穿透开关。 |
| **物联穿透告警** | `IoT Penetration Alert` (`ALT-IOT`) | 当设备预警等级配置穿透且触发告警时，自动向关联在押订单生成的押品预警流水；订单侧只读，须在设备端核销后联动闭环。 |
| **开锁专网专道** | `Dedicated Unlock Flow` | 独立于常规通用工作流引擎的门禁开锁极速审批通道，挂载于「其他审批 → 开锁审核」，保障现场高频开锁秒级实时响应。 |
| **自审禁止** | `Self-Approval Prohibition` (P06/R11) | 系统强制安全原则：开锁审批人严禁审批自己发起的开锁申请单，本人申请页面强行隐藏去审批入口。 |
| **防抖模型** | `Debounce Model` | 设备预警事件过滤机制：瞬态安防（防拆/破门/剪锁）锁定为 0 延时即时触发；传感器超限支持持续时长（秒/分）或连续次数防抖。 |
| **一单一配** | `One-Order-One-Config` (R04) | 1 笔抵质押或监管订单 1:1 绑定 1 条有效综合预警规则包，涵盖超时、跌价、盘点、巡检、质押率及贷中风控 6 大策略。 |
| **智风控异步调度** | `Smart Risk OpenAPI Dispatch` | 贷中风控向第三方智风控平台发起异步模型评估，生成全局唯一 `task_id`，模型拒绝时回调生成押品高危预警。 |
| **不可变存证快照** | `Immutable Snapshot` | 风险公示、数字仓单、质押生效等核心凭证固化的历史事实副本，禁止物理删除与篡改，采用私有 OSS 15 分钟时效签名。 |
| **数字仓单** | `Digital Warehouse Receipt` (`DWR`) | 经标准入库核验开立的电子资产凭证，具备唯一编号、数字签名与货权溯源链。 |
| **质押占用** | `Pledge Occupation` | 货物或仓单被有效融资业务锁定的系统级控制状态，锁定期间严禁出库、转让或移库。 |
| **放行指令** | `Release Instruction` | 在押货物出库前，由资金方根据还款或替代担保情况出具的有期电子授权指令。 |
| **盯市动态估值** | `Mark-to-Market Valuation` | 依据项目约定的外部行情源对押品当前净重与质量系数进行的实时公允价值计算。 |

## 2. 角色与权责边界口径

| 角色主体 | 英文编码 | 核心责任与业务边界 |
| :--- | :--- | :--- |
| **平台超级管理员** | `R-SYS-ADMIN` | 租户机构、系统参数、RBAC 角色权限与全局规则配置，不介入具体单据审批。 |
| **风控经理** | `R-RISK-MGR` | 预警等级维护、订单综合规则配置、贷中风控调度、风险公示与取消公示审核。 |
| **风控专员** | `R-RISK-OFF` | 日常预警流水跟进、处置凭证复核、发起风险公示与开锁审核。 |
| **物联运维人员** | `R-IOT-OPS` | 监控锚点绘制、设备位置绑定、设备预警配置、门禁取密与现场预警核销。 |
| **业务/客户经理** | `R-ORDER-OP` | 借款人意向受理、融资申请跟进、发起抵质押单、跟进解押与出库放行。 |
| **合作资金方** | `R-FIN-FUNDER` | 融资方案提交、单次授信金额录入、抵质押审核、出库放行指令签发与平仓指令。 |
| **审计/监管查看方** | `R-VIEWER` | 授权范围内全流程证据链、单据快照、BI 看板与全路径审计日志只读复核。 |

## 3. 风控指标计算公式

$$\text{初始质押率} = \frac{\text{融资金额}}{\text{初始押品评估总价值}} \times 100\%$$

$$\text{当前盯市总价值} = \sum \Big( \text{押品实收净重} \times \text{实时市场单价} \times \text{品级质量折让系数} \Big)$$

$$\text{当前敞口覆盖率} = \frac{\text{当前盯市总价值}}{\text{未结清融资敞口余额}} \times 100\%$$

$$\text{需追加补仓价值} = \frac{\text{融资敞口余额}}{\text{目标警戒覆盖率口径}} - \text{当前盯市总价值}$$

> **规则校验**：公式中的单价、净重、折让系数及预警阈值均来自可追溯系统快照。平仓线预警等级权重必须大于等于补仓线预警等级权重（R18）。

## 4. 价格与价值精度规范

| 业务场景 | 默认/切换单位 | 精度与格式化规范 | 说明与实现要求 |
| :--- | :--- | :--- | :--- |
| **价格/单价录入** | 元 | 保留 **2 位小数**（如 `1,234.56` 元） | 人工录入或配置单价统一标准。 |
| **价值/金额展示（元）** | 元（默认） | 保留 **6 位小数**（带千分位，如 `1,234,567.890123` 元） | 页面及报表默认展示精度。 |
| **价值/金额展示（万元）** | 万元（切换） | 保留 **10 位小数**（带千分位，如 `123.4567890123` 万元） | 用户切换单位为万元时的无损展示精度。 |

- **存储与换算**：后端与数据库统一采用 `Decimal(28, 12)` 高精度存储；前端根据单位切换自动渲染，保证数值无损与零舍入误差。

## 5. 移动端时间筛选与自动闭环口径

| 用户操作行为 | 触发条件 | 自动补齐/赋值规则 | 实际查询范围与影响说明 |
| :--- | :--- | :--- | :--- |
| **仅选择结束时间** | 仅选择【结束时间】，【开始时间】为空 | `开始时间` 自动赋值为与 `结束时间` **相同的日期/时间** | 精确锁定为该单日（`00:00:00` ~ `23:59:59`），防止检索全历史。 |
| **仅选择开始时间** | 仅选择【开始时间】，【结束时间】为空 | `结束时间` 自动赋值为与 `开始时间` **相同的日期/时间** | 自动形成单日闭环，避免开放式超大范围查询。 |
| **两者均选择** | 分别设置了开始与结束时间 | 按用户实际选择区间执行 | 正常区间查询，校验 `开始时间 <= 结束时间`。 |
| **重置/清空** | 点击重置或清空按钮 | 双侧时间同步置为 `null` | 恢复默认无时间约束规则。 |
