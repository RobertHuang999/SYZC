# 第1个提示词：采集页面清单

请使用当前已打开并登录的浏览器，采集系统的菜单结构和页面入口。

本阶段只产出页面地图，不采集字段，不分析业务规则，不截图，不复刻界面。

```text
01 页面清单：菜单结构、页面路由
02 页面采集：字段、Tab、按钮、状态、关联入口
03 模块整理：功能矩阵、字段字典、状态整理、待确认清单
```

## 一、输入

```text
系统名称：<SYZC>
当前账号或角色：<管理员 拥有全部权限>
当前租户、组织或仓库：<页面可见时填写，否则写未展示>
输出目录：<系统采集>
```

页面未展示的信息写「未展示」，不要猜测。只采集当前账号、当前租户下实际出现的导航，不代表系统全部功能。

## 二、只读边界

1. 不点击删除、提交、确认、导出、下载、保存、审核、批量处理。
2. 不退出登录，不切换账号、租户、组织、仓库、语言或时区，不关闭当前入口标签页。
3. 不猜测URL或隐藏菜单；只使用页面上实际出现的菜单、链接和导航入口。
4. 创建页、编辑页最多打开一次以确认路由，不填写、不保存、不提交。
5. 下拉、抽屉、面板只查看当前内容，看完关闭，不改选项。
6. 没看到的内容写「未观察到」，不要写成「不存在」。

## 三、采集步骤

### 1. 入口快照

记录页面标题、当前URL、账号或角色、租户或仓库、顶部导航、左侧菜单、是否有iframe，以及登录、权限或加载异常。

### 2. 读取菜单

按顶部导航、左侧菜单、展开后的子菜单依次发现入口。折叠目录要展开。每个已发现菜单项都保留，即使暂时打不开。

### 3. 确认页面路由

按菜单顺序打开入口，记录最终URL、页面名称、页面类型、菜单路径、首次入口和访问状态。同一路由只保留一条。

页面类型使用中文，并附英文码便于后续关联：

| 中文 | 英文码 |
|---|---|
| 看板页 | dashboard |
| 列表页 | list |
| 详情页 | detail |
| 新增页 | create |
| 编辑页 | edit |
| 表单页 | form |
| 扫码页 | scan |
| 报表页 | report |
| 配置页 | settings |
| 待判断 | unknown |

弹窗、抽屉、操作菜单没有独立路由时，不单独占一条页面记录，写入「仅交互入口」。

### 4. 动态路由

- 列表页最多下钻1层到详情或编辑页；
- 同一种动态路由只留1个真实示例，并归纳URL模板；
- 不因业务对象ID不同拆成多条页面；
- 本阶段不采字段、不切Tab、不分析状态流转。

URL模板：静态页等于实际URL；动态参数用`:paramName`，含义不明时用`:p1`、`:p2`。

### 5. 去重与访问状态

- 筛选、分页、排序、hash、Tab参数造成的重复：合并；
- 多入口指向同一页：保留首次入口，其余写备注。

访问状态只用：`已访问`、`需要参数`、`需要登录`、`需要权限`、`没有数据`、`加载失败`、`跳转失败`、`待人工确认`。

证据状态只用：`已观察`（已打开）、`待核实`（仅从菜单发现、尚未打开）。

模块名按菜单层级归类，无法判断时写「未归类」。

### 6. 停止条件

以下为防跑飞保护，不是系统完整度结论：

- 页面超过10秒无内容：记录现象后跳过；
- 无权限或缺参数：保留入口，不猜测；
- 唯一页面路由达到80条后，停止发现新页面，其余写入未访问入口；
- 总时长超过60分钟后停止，直接输出已有结果。

## 四、输出

先写结构化数据，再生成可读文档：

```text
<系统采集>/01-系统菜单与页面地图.json
<系统采集>/01-系统菜单与页面地图.md
```

Markdown由JSON生成，不要两边分别手写。

补充约定：

- `pageId`格式：`P-{模块缩写}-{3位序号}`，用于关联菜单和页面；

- `stoppedEntries`记录因权限、参数、时间或安全边界未继续访问的入口；
- `interactionOnlyEntries`记录无独立路由的弹窗、抽屉或操作菜单。

## 五、交付前检查

1. 菜单是否来自当前账号实际可见导航？
2. 页面路由是否都来自真实菜单或链接，没有猜测？
3. 是否已合并重复页面，动态路由是否用了`:param`模板？
4. 是否没有采集字段、按钮细节或业务结论？
5. Markdown是否由同一份JSON生成？

完成后停止。
