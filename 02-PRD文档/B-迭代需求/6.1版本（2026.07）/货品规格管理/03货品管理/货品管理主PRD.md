# 货品管理主PRD

> **模块定位**：货品规格管理第 3 节点（SKU 主档），作为最小业务与交易核算单元，维护动态规格参数、计量参数与单位、入库收集信息配置（逐项必填）、基准参考单价（元/万元精度）与设价日志，实现自身/有效状态双层控制、入库强校验与两阶段安全删除。
> **版本**：V1.0 | 更新时间：2026-08-14 | 责任人：森云科技（Senyun Technology）

## 1. 业务背景与功能范围

货品管理是 SYZC 存货监管系统“货-仓-金”全链路的最小实体基石。货品（SKU）继承品类所定义的动态规格维度，并绑定计量单位、入库信息收集规则和参考单价，向入库单、实时库存、数字仓单、动产质押与融资核算提供唯一的货品规格与价格参照。

| 包含功能 | 不包含功能 |
| :--- | :--- |
| 货品列表与左侧大类/品类层级树联动展示；<br/>添加货品（填写规格值、计量参数、单位）；<br/>入库收集信息配置（从预置项中勾选并设置逐项必填）；<br/>编辑货品与入库配置（入库引用强拦截）；<br/>启用/停用货品与有效状态实时计算；<br/>设置价格（元/万元展示精度）与查看修改记录；<br/>货品删除（阶段一启用拦截 + 阶段二入库单扫描）；<br/>货品全量详情预览与审计追溯。 | 入库单、出库单业务办理与实物质检；<br/>数字仓单生成、流转与解押办理；<br/>融资授信审批与额度扣减；<br/>大宗商品外部行情自动拉取与自动调价。 |

## 2. 状态机与流转

### 2.1 状态枚举

| 状态维度 | 状态值 | 含义 | 下游选择约束 |
| :--- | :--- | :--- | :--- |
| **自身状态 (`status`)** | 启用 (`ENABLED`)、停用 (`DISABLED`) | 货品自身维度的维护状态 | 可由维护人员直接切换 |
| **有效状态 (计算得出)** | 有效启用、无效停用 | $\text{有效启用} \iff \text{自身启用} \land \text{品类启用} \land \text{大类启用}$ | **仅有效启用货品允许被下游新建业务选择** |
| **删除状态 (`is_deleted`)** | 未删除 (`0`)、已删除 (`1`) | 逻辑删除标记，前台不可见 | 仅停用且无入库单时允许删除，不可恢复 |

### 2.2 动作能力矩阵

| 动作 | 启用状态 | 停用状态 | 已删除 |
| :--- | :---: | :---: | :---: |
| **查看列表/预览** | ✅ | ✅ | ❌ |
| **添加货品** | ✅ | ✅ | ❌ |
| **编辑货品** | ✅（需无入库数据） | ✅（需无入库数据） | ❌ |
| **设置价格** | ✅ | ✅ | ❌ |
| **查看修改记录** | ✅ | ✅ | ❌ |
| **停用货品** | ✅ | ❌ | ❌ |
| **启用货品** | ❌ | ✅（重算有效状态） | ❌ |
| **删除货品** | ❌（阶段一阻断） | ✅（阶段二无入库单允许） | ❌ |
| **下游新建选择** | ✅（仅限有效启用） | ❌ | ❌ |

## 3. 核心业务规则

1. **R-SKU-01（SKU 唯一性）**：同一租户同品类下，`动态规格参数组合 + 计量参数 + 单位` 严格唯一。
2. **R-SKU-02（有效状态计算）**：货品自身启用且所属品类与所属大类均启用时，有效状态为“有效启用”，方可被入库单、仓单、抵质押与加工业务新建选择。
3. **R-SKU-03（入库收集联动与校验）**：货品从预置项（货品基础类、生产质检类、仓储要求类）中配置采集项及必填；入库单选择货品后动态生成字段并执行必填、数值区间与日期关系强校验。
4. **R-SKU-04（价格管理与缺价提示）**：单价按元录入存储（保留 2 位小数），支持元（6位+千分位）与万元（10位）切换展示；设价自动记录日志；若未设价，下游统一提示「系统未设置的单价」。
5. **R-SKU-05（编辑入库拦截）**：一旦产生入库单，后端强阻断规格、计量单位及入库收集配置的修改。
6. **R-SKU-06（两阶段安全删除）**：启用不可删；停用状态必须扫描入库单，无入库单方可二次确认后逻辑删除（`is_deleted = 1`）。

| **SKU-03** | 入库收集信息配置 | 系统管理员、配置维护人员 | 货品表单内【入库收集信息】区域，点击【添加入库收集信息】从系统预置项（货品基础类、生产质检类、仓储要求类）选择并逐项设置【必填】 | - 预置项涵盖包装方式、产地、批次号、生产企业、危险品等级、质量等级、生产日期、过期时间、保质期、检验日期、检验机构、检验报告编号、存储方式、温湿度、水分、杂质率；<br/>- 逐项设置是否必填；未配置时入库单不展示额外字段 |

| **SKU-05** | 启用/停用货品 | 系统管理员、配置维护人员 | 行操作列【启用】/【停用】按钮，点击唤起二次确认 | - 启用前校验父级状态：若所属品类或大类处于停用状态，有效状态仍为无效，禁止下游选择；<br/>- 停用提示「停用后后续新增业务无法选择，但历史已产生数据不受影响」；更新最后修改时间 |

| **SKU-08** | 预览货品详情 | 全部角色 | 行操作列【预览】按钮，唤起弹窗只读展示货品基础属性、动态规格、计量参数、入库收集配置、当前单价及系统审计信息 | 全量只读展示 |
| **SKU-09** | 删除货品（两阶段校验） | 系统管理员、配置维护人员 | 行操作列【删除】按钮 | **阶段一（状态强控）**：启用状态阻断并提示「启用状态下的【大类/品类/货品】不可删除，请先停用。」<br/>**阶段二（入库单扫描）**：停用状态扫描入库单：<br/>- 存在入库单：阻断并提示「该【大类/品类/货品】已有业务数据产生，不可删除！」<br/>- 无入库单：弹出二次确认「删除后不可恢复！」，确认后执行逻辑删除（`is_deleted = 1`） |
| **SKU-10** | 操作留痕与审计 | 系统、管理员 | 记录创建人、创建时间、更新时间，记录设价历史与操作日志 | 记录货品新建、属性编辑、入库配置变更、启停、设价、删除操作人、IP、时间戳与前后快照 |

## 二、端侧差异说明

- **PC 端**：支持货品列表全量展示、大类品类左侧导航树、动态规格拆列、入库收集预置项选择与逐项必填配置、设置价格与修改记录弹窗、货品预览及两阶段删除；
- **移动端**：本期支持在入库单、仓单、抵质押与加工业务办理中选择已启用的有效货品，并根据入库收集配置动态渲染录入表单。

## 5. 验收重点

| 编号 | 验收项 | 输入条件 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **V-SKU-01** | SKU 重复配置拦截 | 同品类下录入相同规格组合、计量参数和单位 | 保存失败，Toast 提示「该货品规格配置已存在，请重新输入」 |
| **V-SKU-02** | 有效状态计算过滤 | 货品自身启用但所属大类或品类已停用 | 有效状态计算为无效停用，入库单等下游新建无法检索选择 |
| **V-SKU-03** | 入库收集项必填校验 | 货品配置了必填入库项，入库单提交时未填 | 前后端均阻断提交，提示对应字段必填 |
| **V-SKU-04** | 设价与历史留痕 | 录入元单价并保存 | 更新当前单价，价格修改记录中新增一条操作流水 |
| **V-SKU-05** | 未设单价下游提示 | 货品单价为空，在加工/抵质押单据中引用 | 价格位置统一展示「系统未设置的单价」 |
| **V-SKU-06** | 编辑入库拦截 | 已产生入库单的货品，点击编辑保存 | 阻断保存，弹出阻断弹窗「该货品已有业务数据产生，不可编辑！」 |
| **V-SKU-07** | 启用删除拦截 | 处于启用状态的货品点击删除 | 阻断操作，提示「启用状态下的【大类/品类/货品】不可删除，请先停用。」 |
| **V-SKU-08** | 停用删除业务拦截 | 存在入库单的停用货品点击删除 | 阻断操作，提示「该【大类/品类/货品】已有业务数据产生，不可删除！」 |
| **V-SKU-09** | 无入库数据删除成功 | 停用货品且无入库单，二次确认删除 | 执行逻辑删除，列表不再展示，删除后不可恢复 |
