# 物联设备主需求文档

> **版本**：V1.0 | 2026-08-06
> **读者**：研发工程师、测试工程师、产品复核
> **编写依据**：物联设备字段清单、监控设备主 PRD
> **字段基准**：[`物联设备字段清单.md`](./物联设备字段清单.md) 是本功能所有字段、枚举和字段规则的唯一基准

## 1. 业务背景

物联设备是仓储监管场景中的环境数据采集设备，支持温度、湿度、烟感、氧气、二氧化碳及多功能设备。系统负责展示设备基础信息、当前物联数据，并通过“设备数据”页面查看设备关联订单产生的温湿度预警记录。

物联设备列表不承载审批单据，也不建立独立设备业务状态机。重命名、仓库绑定和移除设备属于设备维护操作；设备数据属于查询和只读展示操作。

## 2. 功能范围

**本期范围**：

- 物联设备列表、组合筛选和字段展示；
- 重命名、仓库绑定、设备数据和移除设备四个行操作；
- 设备进入“设备数据”页面时获取一次当前设备的温度、湿度；
- 展示当前设备关联订单产生的温湿度预警记录及处理信息；
- 设备操作的权限校验、幂等处理、并发控制和审计记录。

**不在本期范围**：

- 物联设备接入、注册和第三方设备基础档案创建；
- 温度、湿度历史曲线或持续实时刷新；
- 温湿度预警的处理、解除和处置；
- 订单审批、订单解绑等业务办理过程；
- 物联设备独立业务状态机。

## 3. 模块定位

| 项目 | 内容 |
| :--- | :--- |
| 模块层级 | 设备基础数据与物联数据查询层 |
| 核心职责 | 维护设备名称和仓库位置，展示设备采集数据及订单温湿度预警记录 |
| 数据来源 | 三方设备平台、系统设备配置、用户仓库绑定操作、订单风险预警模块 |
| 上游依赖 | 三方设备接入、仓库/库房/分区档案、账号与数据权限、订单及风险预警数据 |
| 下游引用 | 订单风控配置、设备预警信息、押品预警信息、设备事务通知及其他风险联动模块 |
| 业务单据 | 不生成独立业务单据，不建立单据状态机 |

## 4. 页面与字段规则

### 4.1 列表字段与排序

列表字段定义继承自[`物联设备字段清单.md`](./物联设备字段清单.md)。列表业务字段展示顺序如下：

> 序号、设备原名称、系统内名称、设备编码、设备类型、绑定仓库、具体位置、物联数据、修改人员、更新时间。

绑定状态仅作为筛选项，不参与列表展示。操作属于列表交互列，不作为业务数据字段。

“物联数据”根据设备类型展示三方平台实际返回的数值：温度设备展示温度值，湿度设备展示湿度值，二氧化碳设备展示二氧化碳值，氧气设备展示氧气值；多功能设备展示多个实际返回的数值。未返回的指标不展示，物联数据不参与搜索。

### 4.2 数据可见范围

物联设备查询和行操作继承监控设备的数据权限原则：

| 设备绑定情况 | 可见规则 |
| :--- | :--- |
| 已绑定仓库 | 登录用户拥有该仓库数据权限时可见；无对应仓库权限时不返回设备数据 |
| 未绑定仓库 | 当前租户内具备有效账号且拥有物联设备菜单查看权限的用户可见 |
| 已移除设备 | 有效设备列表不展示；历史业务详情按快照规则保留 |

“所有用户可见”仍受租户隔离、账号有效性和菜单功能权限限制，不代表跨租户可见。

## 5. 操作功能

### 5.1 操作总览

| 操作 | 入口 | 是否改变设备基础数据 | 规则来源 |
| :--- | :--- | :---: | :--- |
| 重命名 | 列表“操作”列 | 是 | 继承[监控设备主 PRD·5.2 重命名](../01监控设备/监控设备主PRD.md#52-重命名) |
| 仓库绑定 | 列表“操作”列 | 是 | 继承[监控设备主 PRD·5.3 仓库绑定](../01监控设备/监控设备主PRD.md#53-仓库绑定) |
| 设备数据 | 列表“操作”列 | 否 | 本文档第5.2节 |
| 移除设备 | 列表“操作”列 | 是 | 继承[监控设备主 PRD·5.7 移除设备](../01监控设备/监控设备主PRD.md#57-移除设备) |

重命名、仓库绑定和移除设备与监控设备使用一致的弹窗、权限、校验、并发控制、幂等、跨模块联动、异常处理和审计规则。物联设备不复制或另行改写上述规则；如监控设备规则发生变更，物联设备同步继承最新版本。

### 5.2 设备数据

#### 5.2.1 页面进入与当前数据

| 规则项 | 规则 |
| :--- | :--- |
| 操作入口 | 从物联设备列表“操作”列点击“设备数据” |
| 权限校验 | 校验物联设备菜单查看权限、设备数据查看权限、租户权限、机构权限和设备数据权限 |
| 当前数据请求 | 进入页面时，针对当前设备实时请求一次温度、湿度数据 |
| 展示内容 | 展示本次请求返回的当前温度值和当前湿度值 |
| 刷新规则 | 本期仅进入页面时请求一次，不持续轮询、不自动刷新；手动刷新能力待后续确认 |
| 数据来源 | 三方设备平台实时数据接口 |
| 页面职责 | 发起数据请求并展示返回值，不修改设备基础数据、订单数据或预警处理状态 |

当前温度、湿度数据的单位、精度、采集时间、数值为空、设备离线和异常值展示规则待接口资料确认。未返回的数值展示“暂无数据”，不得使用旧数据冒充本次请求结果。

#### 5.2.2 预警记录

设备数据页面同时展示当前设备关联订单产生的全部温湿度预警记录及处理信息。该逻辑与[监控设备主 PRD·5.5 查看回放](../01监控设备/监控设备主PRD.md#55-查看回放)中“回放页面只读展示预警列表”的逻辑一致，但不展示监控回放画面。

| 规则项 | 规则 |
| :--- | :--- |
| 数据范围 | 当前设备绑定或曾绑定订单后，在订单上产生的温度、湿度预警记录；具体历史留存范围以风险预警模块为准 |
| 展示方式 | 多条预警以列表展示，每条预警独立记录 |
| 预警处理归属 | 预警处理由风险预警模块负责，物联设备端仅只读展示 |
| 操作限制 | 不提供处理、解除、修改预警状态或补录处置结果入口 |
| 关联条件 | 查询必须使用设备编码及订单关联标识，不得使用列表行号作为关联条件 |

预警记录至少展示以下信息，最终字段以风险预警模块实际返回定义为准：

| 预警信息 | 展示规则 |
| :--- | :--- |
| 订单信息 | 展示产生预警的订单标识或订单名称，用于区分不同订单来源 |
| 预警时间 | 展示预警产生时间 |
| 预警类型 | 展示温度预警或湿度预警 |
| 监测值 | 展示产生预警时的温度或湿度实际值 |
| 阈值信息 | 展示命中的预警阈值或规则区间 |
| 处理状态 | 展示当前预警处理状态 |
| 处理人 | 预警已处理时展示处理人 |
| 处理时间 | 预警已处理时展示处理时间 |
| 处理说明 | 预警已处理时展示处置说明 |

#### 5.2.3 页面状态与异常

| 场景 | 处理规则 |
| :--- | :--- |
| 当前数据加载中 | 展示加载状态；请求未完成前不得展示旧设备或其他设备数据 |
| 当前数据为空 | 温度或湿度无返回值时分别展示“暂无数据” |
| 预警记录为空 | 展示空状态，明确当前设备暂无关联温湿度预警记录 |
| 当前数据接口失败 | 保留页面结构，提示当前设备数据获取失败；不得修改设备字段或预警记录 |
| 预警记录接口失败 | 当前数据与预警记录分区独立处理；预警区提示加载失败，不影响当前数据区展示 |
| 权限校验失败 | 不返回设备数据和预警记录，不展示可绕过权限的详情内容 |
| 设备已移除 | 页面请求时重新校验设备有效性；无效时禁止继续查询并提示设备不可用 |
| 返回设备不一致 | 三方返回的设备编码与当前请求设备编码不一致时丢弃结果并记录异常日志 |

## 6. 权限、并发与审计

### 6.1 权限规则

1. 所有列表查询和操作接口必须同时校验菜单功能权限、操作权限、租户权限、机构权限和设备绑定仓库数据权限。
2. 前端隐藏操作按钮只用于交互优化，后端必须独立执行权限校验。
3. “设备数据”页面的当前数据和预警记录必须分别执行服务端权限校验，不得因其中一个接口有权限而放宽另一个接口的数据范围。

### 6.2 并发与幂等规则

- 重命名、仓库绑定和移除设备继承监控设备主 PRD中的版本校验、锁或等效并发控制规则。
- 设备数据请求使用设备编码作为幂等关联键；禁止使用列表行号或设备名称作为唯一请求条件。
- 页面快速重复点击“设备数据”时，前端应防重复提交；服务端仍需校验请求上下文和设备有效性。
- 设备已移除、设备编码不匹配或设备权限发生变化时，请求不得写入任何设备或预警数据。

### 6.3 审计规则

重命名、仓库绑定和移除设备继承监控设备审计要求。以下设备数据行为也需记录操作日志：

| 行为 | 审计内容 |
| :--- | :--- |
| 进入设备数据页面 | 操作人、设备编码、请求时间、权限校验结果、请求标识和操作结果 |
| 获取当前温湿度 | 数据请求时间、设备编码、返回成功/失败、失败原因和第三方请求标识；不篡改第三方原始值 |
| 查询预警记录 | 操作人、设备编码、订单关联条件、查询时间、返回数量、权限校验结果和操作结果 |
| 查询失败 | 记录接口名称、请求标识、失败原因、设备编码和异常上下文；敏感信息按角色脱敏 |

## 7. 验收重点

| 编号 | 验收项 |
| :--- | :--- |
| A01 | 行操作仅包含重命名、仓库绑定、设备数据、移除设备四项 |
| A02 | 重命名、仓库绑定和移除设备完整继承监控设备对应规则，不产生独立分叉逻辑 |
| A03 | 点击“设备数据”进入页面时，针对当前设备实时获取一次温度、湿度并展示 |
| A04 | 设备数据页面不持续轮询、不自动刷新，不展示其他设备或上一次设备的缓存值 |
| A05 | 设备关联订单产生的温湿度预警全部以列表展示，并展示处理状态、处理人等处理信息 |
| A06 | 物联设备端只读展示预警，不提供处理、解除或修改预警状态入口 |
| A07 | 当前温湿度接口和预警记录接口分区处理，任一接口失败不影响另一分区的正确展示 |
| A08 | 所有请求以设备编码和权限上下文校验，设备已移除或返回设备不一致时不得展示错误数据 |
| A09 | 设备数据查询、当前值获取、预警记录查询及失败请求均写入审计日志 |
