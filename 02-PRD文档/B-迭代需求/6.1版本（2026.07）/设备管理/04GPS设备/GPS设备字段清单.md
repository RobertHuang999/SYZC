# GPS设备字段清单

> **文档定位**：GPS设备所有字段的唯一定义来源。下游需求文档、原型和关联功能只引用字段名称，不重复定义字段规则。
>
> **引用规则**：下游需要引用GPS设备字段时，标注“继承自GPS设备”；需要保留设备历史信息时，标注“快照字段”。
>
> **修改原则**：字段定义变化只修改本文件，并同步更新版本和修订记录。
>
> **版本**：V1.3 | 更新时间：2026-08-07
>
> **页面范围**：当前版本涉及GPS设备筛选区、列表页、行操作、实时定位、运动轨迹及页面级三方平台入口；新增页、编辑页和设备详情页暂不纳入本字段清单。

## 三、展示与引用规则

- 列表业务字段展示顺序：序号、设备原名称、系统内名称、设备编码、车辆信息、绑定仓库、具体位置、修改人员、更新时间。
- 筛选字段：设备名称（实际查询系统内名称）、车辆信息（模糊匹配）、设备状态（下拉精确匹配）、仓库（实际查询绑定仓库）、具体位置（模糊匹配）；其中“仓库”引用字段“绑定仓库”。
- GPS设备当前不定义“绑定状态”字段，也不提供“绑定状态”筛选项；设备是否绑定仅通过“绑定仓库”字段展示和筛选。
- “操作”属于列表交互列，不作为业务数据字段。当前行操作包括：重命名、绑定仓库、实时定位、运动轨迹、移除设备；具体规则见下方“行操作规则”。页面级按钮“GPS平台规则配置”和“GPS平台基础数据”属于独立的三方平台入口，不计入当前行操作。
- `设备原名称`、`系统内名称`、`设备编码` 和 `车辆信息` 的真实字段编码及接口来源待研发确认；字段编码未确认前，下游文档以中文字段名称引用，不自行固化英文属性名。
- GPS设备维护操作需进行租户、机构和菜单权限校验；涉及绑定关系、名称或位置更新时，应采用服务端版本校验、锁或等效并发控制，并将操作前后数据写入操作审计日志。
- 设备编码作为设备维护操作的幂等关联键；绑定、解绑、名称或位置更新不得仅使用列表行号作为请求关联条件。
- GPS平台规则配置和GPS平台基础数据通过联登跳转三方平台，按钮是否展示由对应的独立配置权限决定；三方平台内部页面、字段和操作规则不在本清单内定义。

## 五、实时定位页面规则

> 实时定位从列表行操作进入，页面以地图为主要展示区域，并通过地图标记和信息弹窗展示车辆及定位设备信息。本节只定义当前图片已确认的页面展示规则，不固化尚未确认的接口字段编码和定位刷新机制。

### 1. 页面区域

| 页面区域 | 展示规则 |
| :--- | :--- |
| 地图展示 | 展示实时定位地图、车辆当前位置及周边地理信息 |
| 车辆定位标记 | 在地图上标识车辆当前位置，并支持打开对应信息弹窗 |
| 信息弹窗 | 展示当前车辆、司机、当前位置和定位设备的详细信息 |

### 2. 信息弹窗字段

| 页面项目 | 展示规则 | 字段关系与备注 |
| :--- | :--- | :--- |
| 车牌号 | 当前车辆的车牌号码，例如“辽JGJ440” | 引用“车辆信息”中的车牌号；车牌号格式待车辆数据来源确认 |
| 状态 | 展示当前车辆状态及持续时长，例如“停车1天”“离线5天” | 状态枚举、状态判定来源和状态更新时间待确认 |
| 司机姓名 | 展示车辆对应司机的姓名 | 车辆关联司机信息；司机关联关系和无值展示规则待确认 |
| 手机号码 | 展示车辆对应司机的手机号码 | 司机联系方式；敏感信息需按角色脱敏，脱敏规则待确认 |
| 当前位置 | 展示当前定位地址，精确到街道门牌号 | 定位地址解析规则、地址获取失败和无定位数据展示规则待确认 |
| 更新时间 | 展示定位信息最后更新时间；格式为 `YYYY-MM-DD HH:mm:ss` | 以定位数据服务端时间为准；与设备基础信息的“更新时间”不是同一字段 |
| 系统名称 | 展示定位设备名称，例如“定位设备02#” | 对应设备字段“系统内名称”；页面右侧说明中的“系统内容”建议统一修正为“系统名称” |
| 设备序号 | 展示设备在系统中的序列名称，例如“LU005” | 定位页面展示字段；是否对应独立持久化字段待研发确认 |
| 设备编号 | 展示设备唯一标识码，例如“4534534534534” | 对应设备字段“设备编码”，设备维护请求使用设备编码作为幂等关联键 |

### 3. 状态持续时长展示

- 持续时长统一按“天-小时-分钟”展示。
- 超过60分钟换算为1小时，超过24小时换算为1天。
- 当天数和小时数均为0时不展示0天和0小时；例如“0天0小时12分钟”展示为“12分钟”。
- “停车1天”“离线5天”等示例中的状态名称和持续时长需由定位数据服务返回或由服务端按状态起始时间计算，具体实现方式待研发确认。

## 六、运动轨迹页面规则

> 运动轨迹从列表行操作进入，页面展示当前用户具有仓库权限的数据。用户选择设备和查询时间范围后，查询指定时间段内的历史轨迹，并在地图上展示车辆行驶路径。

### 1. 数据权限与查询条件

| 页面项目 | 展示或交互规则 | 备注 |
| :--- | :--- | :--- |
| 数据范围 | 仅展示当前用户具有仓库权限的数据 | 查询接口必须按当前用户、租户、机构和仓库数据权限进行服务端校验 |
| 设备信息 | 有车牌时展示系统内设备名称和车牌信息；无车牌时展示设备名称并标识“未绑定” | 从单个设备行操作进入时，原型说明支持默认填充设备信息且不可修改；是否隐藏设备选择控件待确认 |
| 开始时间 | 查询历史轨迹的起始时间；格式为 `YYYY-MM-DD HH:mm:ss` | 默认不填充日期；具体默认值待确认 |
| 结束时间 | 查询历史轨迹的结束时间；格式为 `YYYY-MM-DD HH:mm:ss` | 默认不填充日期；具体默认值待确认 |
| 查询范围 | 开始时间至结束时间的日期范围必须小于等于31天 | 超出范围提示：“暂时只支持查询31天内的数据” |
| 查询按钮 | 点击后加载指定时间段内的历史轨迹 | 查询期间应防止重复提交，并处理无轨迹数据、接口超时和查询失败 |

### 2. 地图与状态分段展示

| 展示区域 | 展示规则 |
| :--- | :--- |
| 历史轨迹地图 | 展示历史轨迹地图和车辆行驶路径；地图交互能力及底图服务待确认 |
| 状态分段列表 | 历史轨迹按车辆状态分段展示，一个状态对应一段轨迹记录 |
| 状态分段卡片 | 展示更新时间、系统内名称、设备状态、司机姓名、车牌号、状态持续时长、起止时间，并提供“查看详情”入口 |
| 轨迹详情弹窗 | 点击“查看详情”后展示该段轨迹的车辆、司机、起止地址、总里程和定位设备信息 |
| 位置字段 | 状态分段列表当前不展示位置；轨迹详情中展示结束地址作为历史轨迹终点地址 | 原型备注指出地址解析过多可能导致卡顿，地址解析和展示性能规则待确认 |

### 3. 页面字段

#### 3.1 查询区字段

| 页面项目 | 展示规则 | 字段关系与备注 |

| 设备原名称 | 展示设备出厂或原始名称，例如“LU005” | 对应“设备原名称”或三方平台原始设备名称，具体取值映射待确认 |
| 设备编号 | 展示设备唯一标识码，例如“4534534534534” | 对应设备字段“设备编码” |
| 地图展示 | 展示历史轨迹地图和车辆行驶路径 | 属于页面展示区域，不作为独立持久化业务字段 |

### 4. 设备状态枚举与时长展示

- 原型当前展示的设备状态为：`1离线`、`2停车`、`3行驶`、`4静止`；状态编码、状态判定规则和状态优先级待研发确认。
- 状态持续时长统一按“天-小时-分钟”展示。
- 超过60分钟换算为1小时，超过24小时换算为1天。
- 当天数和小时数均为0时不展示0天和0小时；例如“0天0小时12分钟”展示为“12分钟”。
- 未发生状态或无法计算持续时长时，原型展示“--”；具体空值展示规则待确认。
