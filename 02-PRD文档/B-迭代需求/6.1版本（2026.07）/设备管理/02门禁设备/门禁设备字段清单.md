## 三、展示与引用规则

- 列表业务字段展示顺序：序号、设备原名称、系统内名称、设备编码、设备类型、状态、绑定仓库、具体位置、修改人员、更新时间。绑定状态仅作为筛选项，不参与列表展示；页面“设备名称”是“系统内名称”的查询标签，不单独定义字段。
- 筛选字段：设备名称（实际查询系统内名称）、设备类型、设备状态（实际查询“状态”字段）、仓库、绑定状态、更新时间；其中“仓库”引用字段“绑定仓库”，“更新时间”使用日期范围筛选。
- “操作”属于列表交互列，不作为业务数据字段。当前行操作包括：重命名、仓库绑定、设备数据、获取门锁密码、移除设备和人脸配置；其中仅挂锁门禁展示“获取门锁密码”，仅人脸门禁展示“人脸配置”。各操作的具体规则见下方“行操作规则”。
- `设备原名称`、`系统内名称`、`设备编码` 和 `设备类型` 的真实字段编码及接口来源待研发确认；`状态`由门禁设备实时接口返回，页面筛选项名称为“设备状态”，二者为同一字段。字段编码未确认前，下游文档以中文字段名称引用，不自行固化英文属性名。
- 设备维护操作需进行租户、机构和菜单权限校验；涉及绑定关系、名称或位置更新时，应采用服务端版本校验、锁或等效并发控制，并将操作前后数据写入操作审计日志。
- 设备编码作为设备维护操作的幂等关联键；绑定、解绑、名称或位置更新不得仅使用列表行号作为请求关联条件。

## 六、获取门锁密码规则

> 本操作仅适用于设备类型为“挂锁门禁”的设备。操作权限由登录账号角色配置决定，前端展示和服务端接口均需进行权限校验。

| 页面项目 | 展示或交互规则 | 校验与后置影响 |
| :--- | :--- | :--- |
| 操作权限 | 操作按钮权限由登录账号角色赋予的“获取门锁密码”操作权限控制 | 无对应角色权限时不展示或不可调用；服务端必须再次校验，不能仅依赖前端隐藏 |
| 操作按钮 | 挂锁门禁设备展示“获取门锁密码”；人脸门禁不展示该操作 | 设备类型和操作权限均满足时才允许发起请求 |
| 提示弹窗 | 点击按钮后弹出“获取门锁密码提示”弹窗；弹窗展示当前设备信息和安全提示，明确密码将下发至登录账号手机短信，禁止随意透露给他人 | 弹窗关闭或点击“取消”时不发送短信、不生成或返回密码 |
| 设备标识 | 弹窗展示当前操作的门锁设备，例如“LU-006” | 使用设备编码或服务端设备关联键识别设备，不得使用列表序号作为请求条件 |
| 事由 | 弹窗提供“事由”下拉选择，标记为必填，默认提示“请选择”；下拉枚举包括：出库、入库、移库、参观、其他 | 未选择事由时阻止确认提交；提交时随密码请求日志记录事由选项 |
| 备注 | 弹窗提供“备注”文本域，选填，最多50个字 | 超过50个字时阻止提交；备注内容随请求记录，具体特殊字符规则待确认 |
| 确认下发 | 点击“确认”后，系统自动向登录账号绑定的手机号下发门锁密码短信 | 应防止重复提交；当前版本密码有效期为3天；短信模板、接口超时和失败重试策略列为后续可优化项 |
| 密码展示 | 短信下发后，门锁密码返回页面并展示给当前操作人 | 当前版本密码有效期为3天；是否掩码、是否允许复制以及页面关闭后的再次查看规则列为后续可优化项 |
| 审计记录 | 记录操作人、角色、设备编码、事由、备注、请求标识、短信下发结果、密码获取结果和操作时间 | 审计日志不得记录门锁密码明文或短信内容；失败请求同样必须留痕 |
