# 入库收集项配置字段清单

> **文档定位**：本文件是定义 SYZC 存货监管系统【配置管理 → 货品规格管理 → 入库收集项配置】独立菜单所有业务字段、交互控件、保质期度量白名单与系统字段的**唯一权威数据真源（SSOT）**。
>
> **引用与上下游契约**：
> - 本菜单集中维护入库收集项元数据标准，为下游 [06-货品规格管理-货品管理](../06-货品规格管理-货品管理/货品管理字段清单.md) 提供可选字段池与保质期单位白名单。
> - 下游货品管理 (SKU) 建档时从本菜单定义的白名单中**为具体商品指定专属固定保质期单位**（如花椒配年、八角配月），并设置是否必填与建议默认数值。
> - 仓储 WMS 入库单依据货品主档配置动态渲染表单，保质期单位锁定只读，现场仓管员如实独立填报生产日期、保质期数值与过期时间。
>
> **设计原则**：**通俗易懂、极致轻量、大白话业务导向**。杜绝生硬技术术语与冗余表单负担，专注于仓储监管实际可见可配的核心要素。
>
> **版本**：V3.0（与 06 货品管理对齐「货品端四件事」口径） | 更新时间：2026-10-29 | 责任人：森云科技（Senyun Technology）

### 6.1 控件类型枚举
| 控件类型名称 | 适用业务场景说明 | 仓库现场 WMS 入库单表单呈现行为 |
| :--- | :--- | :--- |
| **单行文本输入框** | 批次号、生产厂家、检验机构等常规文本信息 | 标准单行文本输入框 |
| **下拉单选框** | 包装方式、外观等级、存储方式等固定选项 | 下拉单选面板 |
| **日期选择器** | 生产日期、过期时间、送检日期等关键日期 | 日历日期选择器（格式：`YYYY-MM-DD`） |
| **数字区间框** | 温度要求（℃）、湿度要求（%RH）等指标范围 | 两个数字框（最小值 至 最大值），带固定单位后缀 |
| **百分比数值框** | 水分含量（%）、杂质率（%）等质量比率参数 | 单数字输入框，固定带 `%` 后缀，校验 0 至 100 |
| **周期组合项** | **保质期专属**（数值 + 固定只读单位） | **正整数输入框 + 锁定单位文本标签**（现场仓管员仅录数值，单位只读锁死免选） |
| **省市区三级联动** | 产地、发货地等行政区划溯源字段 | 三个联动下拉框（省 → 市 → 区），逐级带出，最终落库为「省/市/区」完整文本 |
