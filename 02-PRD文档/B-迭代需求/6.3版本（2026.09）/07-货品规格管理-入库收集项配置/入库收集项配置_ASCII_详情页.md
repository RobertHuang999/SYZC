## 3. 录入效果预览 — 七种控件形态

> 【输入提示】统一作为输入框内的浅灰占位文字展示；数字区间框因拆成两个数字框，提示语单独放在框下一行。列表【预览】弹窗与详情页右侧「入库单录入样式」两处渲染规则一致。

```text
+-- 单行文本输入框 ------------------------------------------------------------------------------------------+
|                                                                                                            |
|     批次号  *                                                                                              |
|     [ 请输入批次号                             ]                                                           |
|                                                                                                            |
+------------------------------------------------------------------------------------------------------------+

+-- 下拉单选框 ----------------------------------------------------------------------------------------------+
|                                                                                                            |
|     包装外观等级  *                                                                                        |
|     [ 请根据现场验货核验外观等级           v ]                                                             |
|     可选：A级优等品 / B级合格品 / C级折价品                                                                |
|                                                                                                            |
+------------------------------------------------------------------------------------------------------------+

+-- 日期选择器 ----------------------------------------------------------------------------------------------+
|                                                                                                            |
|     生产日期  *                                                                                            |
|     [ 请选择货物出厂生产日期            📅 ]                                                               |
|                                                                                                            |
+------------------------------------------------------------------------------------------------------------+

+-- 数字区间框 ----------------------------------------------------------------------------------------------+
|                                                                                                            |
|     温度要求  *                                                                                            |
|     [ 最小值 ] 至 [ 最大值 ]  ℃                                                                            |
|     例如：-18 至 -15                                                                                       |
|                                                                                                            |
+------------------------------------------------------------------------------------------------------------+

+-- 百分比数值框 --------------------------------------------------------------------------------------------+
|                                                                                                            |
|     水分含量  *                                                                                            |
|     [ 请输入实验室实测水分含量比率 ] %                                                                     |
|                                                                                                            |
+------------------------------------------------------------------------------------------------------------+

+-- 省市区三级联动 ------------------------------------------------------------------------------------------+
|                                                                                                            |
|     产地  *                                                                                                |
|     [ 请选择省份  v ] [ 请选择城市  v ] [ 请选择区县  v ]                                                 |
|     省 → 市 → 区逐级带出，最终落库为「四川省 / 雅安市 / 汉源县」                                           |
|                                                                                                            |
+------------------------------------------------------------------------------------------------------------+

+-- 周期组合项（保质期） ------------------------------------------------------------------------------------+
|                                                                                                            |
|     保质期  *                                                                                              |
|     [ 请输入正整数保质期数值… ] 个月                                                                       |
|     单位只读，由货品主档指定                                                                               |
|                                                                                                            |
+------------------------------------------------------------------------------------------------------------+
```
