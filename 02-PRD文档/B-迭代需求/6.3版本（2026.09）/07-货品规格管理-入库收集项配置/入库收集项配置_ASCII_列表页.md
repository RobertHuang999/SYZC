## 2. 字段与行操作说明

1. **序号（第 1 列）**：当前分页内数字递增（1, 2, 3...），非物理主键。
2. **收集项名称（第 2 列）**：加粗展示，点击支持跳转查看详情。遵循【收集项名称唯一性校验规则】(R01)。
3. **控件类型（第 3 列）**：展示具体类型（周期组合项/日期选择器/百分比数值框/数字区间框/下拉单选框/单行文本输入框/省市区三级联动）。遵循【系统核心收集项保护机制】(R02)。
4. **度量单位/选项摘要（第 4 列）**：直观展示关键信息（如单位标签、保质期天/月/年、下拉前两项选项），免去点进详情查阅成本；无单位项展示破折号 `—`。
5. **状态（第 5 列）**：状态徽章展示（`🟢 启用` / `⚪ 停用`）。遵循【收集项启用与停用规则】(R03)。
6. **创建时间（第 6 列）**：格式 `YYYY-MM-DD HH:mm:ss`，默认按创建时间倒序排布。
7. **操作（末列）**：
   - **【详情】**：点击进入收集项详情页，只读查看，不改变任何数据；
   - **【预览】**：点击弹出录入效果预览弹窗，静态展示该收集项在仓储入库单中的录入形态，只读，不改变任何数据；
   - **【编辑】**：跳转编辑页（`/入库收集项配置/编辑/:id`），回填数据；
   - **【配置单位】**：**仅在【保质期】行展示**，点击打开保质期度量单位配置弹窗；
   - **【停用/启用】**：点击弹出二次确认弹窗（带收集项名称与存量不受影响说明），确认后即时切换状态；
   - **【删除】**：
     - 系统核心内置项（保质期、生产日期、过期时间）：按钮置灰禁用并展示锁定图标 `🔒`，悬停轻量提示：**「系统核心字段，禁止删除」**；
     - 启用中自定义项：点击弹出拦截提示：**「启用状态下的收集项不可删除，请先停用。」**；
     - 停用中自定义项：系统后台快速探测下游引用。若有引用阻断提示：**「该收集项已被使用，不可删除！请先前往解绑。」**；若无引用则弹出二次确认：**「确定彻底删除该收集项吗？删除后不可恢复。」**。遵循【两阶段安全删除控制规则】(R04)。

## 3. 核心交互弹窗线框

### 3.1 【保质期度量单位配置】弹窗 (操作列【配置单位】触发)

```text
+--------------------------------------------------------------------+
| 保质期度量单位配置                                             [X] |
+--------------------------------------------------------------------+
|                                                                    |
|  * 允许启用的保质期单位:                                           |
|    ┌─────────────────────────────────────────────────────────────┐  |
|    │ [ ON  开启 ]  按【天】计量 (适用于生鲜、冷链品类)           │  |
|    │                                                             │  |
|    │ [ ON  开启 ]  按【月】计量 (适用于调味品、粮油、预包装大宗) │  |
|    │                                                             │  |
|    │ [ ON  开启 ]  按【年】计量 (适用于花椒、中药材、长储商品)   │  |
|    └─────────────────────────────────────────────────────────────┘  |
|                                                                    |
|  * 推荐基准单位:                                                   |
|    [ 按【月】计量 (MONTH)                                      v ]  |
|                                                                    |
+--------------------------------------------------------------------+
|                                              [ 取 消 ]  [ 保 存 ]  |
+--------------------------------------------------------------------+
```

> **交互说明**：
> - 开关联动：天、月、年三项开关不可同时关闭，至少保持 1 项开启。若试图关闭最后一个开关，系统提示：**「至少保留一个可用保质期单位」**。
> - 推荐单位：下拉选项联动自开启的单位开关。遵循【保质期度量单位白名单与基准推荐规则】(R05)。

> **交互说明**：
> - 预览按当前【控件类型】静态渲染七种形态之一（单行文本 / 下拉单选 / 日期选择器 / 数字区间框 / 百分比数值框 / 周期组合项 / 省市区三级联动），只读不可输入；
