## 四、货品链真源（6.3 决策）

> **2026-10-19 范围裁切**：**07 入库收集项配置**、**06 货品管理** 收集项/保质期配置 **本期暂定（不交付）**；6.3 联调与入库作业 **沿用基准版** 品类/货品/入库动态收集口径。下表为 **后续版本目标态**，供三件套预埋对照。

| 层级 | 职责 |
| :--- | :--- |
| **07 入库收集项配置** | 字段元数据 + 保质期 **可选单位白名单**（天/月/年）+ 默认推荐单位 |
| **品类管理（基准版）** | 从字段池勾选收集模板；**可向 SKU 提供默认保质期单位建议**，不锁定下游 |
| **06 货品管理 SKU** | **执行真源**：为 SKU 指定固定保质期单位、必填、建议默认数值；有入库单后单位只读 |
| **WMS 入库单** | 按 SKU 配置渲染；单位只读（SKU-F04） |
