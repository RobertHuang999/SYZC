## 四、货品链真源（6.3 决策）

| 层级 | 职责 |
| :--- | :--- |
| **07 入库收集项配置** | 字段元数据 + 保质期 **可选单位白名单**（天/月/年）+ 默认推荐单位 |
| **品类管理（基准版）** | 从字段池勾选收集模板；**可向 SKU 提供默认保质期单位建议**，不锁定下游 |
| **06 货品管理 SKU** | **执行真源**：为 SKU 指定固定保质期单位、必填、建议默认数值；有入库单后单位只读 |
| **WMS 入库单** | 按 SKU 配置渲染；单位只读（SKU-F04） |

## 五、合作方地址活跃池（6.3 决策）

| 规则 | 说明 |
| :--- | :--- |
| **PA-R06** | 有效个人货主占用的证件地址持续占用活跃池；**不因冻结而释放** |
| **PA-R06a 改址** | 允许编辑证件地址；保存成功后 **旧标准化地址出池、新地址入池**（须过准入唯一校验）；历史业务快照不回写 |
| **无注销/无移除货主** | 不通过移除货主释放地址；搬家走 **档案改址 (PA-R06a)** |
