## 3. 控件类型动态联动表单区域线框

### 3.1 联动 A：控件类型选择【下拉单选框 (SELECT)】

选择下拉单选框时，表单动态展开【下拉选项集合】配置区，支持动态添加/删除选项（至少配置 1 项）：

```text
|  * 控件类型:                                                |
|    [ 下拉单选框 (固定枚举选项)                            v ]  |
|                                                             |
|  * 下拉选项集合配置 (至少添加 1 项):                        |
|    ┌─────────────────────────────────────────────────────┐  |
|    │ 序号 | 选项标签文案 (≤20字)                | 操作    │  |
|    ├──────┼─────────────────────────────────────┼─────────┤  |
|    │  1   │ [ A级优等品                       ] │ [删除]  │  |
|    │  2   │ [ B级合格品                       ] │ [删除]  │  |
|    │  3   │ [ C级次品 (需复检)                ] │ [删除]  │  |
|    └─────────────────────────────────────────────────────┘  |
|    [ + 添加下拉选项 ]                                        |
|    ℹ️ 下游 WMS 入库单将呈现为标准下拉选择框                 |
```

### 3.2 联动 B：控件类型选择【单数值 (带单位)】或【数字区间框】

动态展开【度量单位标签】输入框（必填）：

```text
|  * 控件类型:                                                |
|    [ 数字区间框 (最小值~最大值)                            v ]  |
|                                                             |
|  * 度量单位标签:                                            |
|    [ %RH                                                 ]  |
|    常用单位快捷填入: [ %RH ]  [ ℃ ]  [ kg ]  [ MPa ]  [ 吨 ] |
|    ℹ️ 必填，≤10 字符；WMS 入库单将在输入框右侧固定贴标展示  |
```

### 3.3 联动 C：控件类型选择【单行文本输入框 (TEXT)】或【日期选择器 (DATE)】

自动折叠单位与选项配置区域，仅展示输入提示：

```text
|  * 控件类型:                                                |
|    [ 日期选择器 (YYYY-MM-DD)                              v ]  |
|                                                             |
|    度量单位与选项:                                          |
|    — （日期类字段无需配置单位与选项，入库时调用标准日历控件）|
```

## 4. 校验与异常交互弹窗线框

### 4.1 收集项名称租户内重复校验阻断 (FLD-V01 / R01)

当管理员输入的名称已存在于当前租户字段池中并点击保存时，输入框高亮红色告警，并弹出 Toast 阻断：

```text
|  * 收集项名称:                                              |
|    [ 存储温度要求                                         ]  |
|    ❌ 错误提示：当前租户下已存在名为【存储温度要求】的收集项，禁止重复创建！|
```

### 4.2 表单 Dirty 离开防误丢二次确认弹窗

当抽屉表单已录入内容但尚未保存，用户误触抽屉遮罩层或点击【X】/【返回】时，阻断关闭并弹出确认：

```text
+--------------------------------------------------------------------+
| 放弃未保存的内容？                                              [X] |
+--------------------------------------------------------------------+
|                                                                    |
|  ⚠️ 提示：当前表单内容已发生修改，尚未提交保存。                  |
|     直接关闭将丢失当前录入的所有字段元数据配置。                    |
|                                                                    |
+--------------------------------------------------------------------+
|                                              [ 继续编辑 ]  [ 确定放弃 ]|
+--------------------------------------------------------------------+
```

### 4.3 乐观锁并发冲突弹窗 (C02 并发保护)

多管理员同时编辑同一收集项时，版本发生变动阻断保存：

```text
+--------------------------------------------------------------------+
| 数据已被更新 — 保存失败                                         [X] |
+--------------------------------------------------------------------+
|                                                                    |
|  🚫 冲突提示：该收集项元数据已被其他管理员修改并提交（当前最新版   |
|     本为 V2）。为避免配置覆盖，系统已自动拦截本次提交。            |
|                                                                    |
|  处置要求：请点击【刷新数据】重新加载最新版本后再行编辑。          |
|                                                                    |
+--------------------------------------------------------------------+
|                                                        [ 刷新数据 ]|
+--------------------------------------------------------------------+
```
