## 2. 字段与只读规则打点对照表

| 区域 / 卡片 | 展示字段 | 取值说明 | 业务语义与规则索引 |
| :--- | :--- | :--- | :--- |
| **顶部状态栏** | `status` | 自身状态徽章 | 绿色【自身启用】或灰色【自身停用】（[SKU-F09](./货品管理业务规则规格.md#两阶段安全删除控制规则sku-f09)） |
| **顶部状态栏** | `valid_status` | 有效状态徽章 | 依据 自身、品类、大类均为启用 综合计算（[SKU-F11](./货品管理业务规则规格.md#有效启用状态多级综合计算规则sku-f11)） |
| **基础档案** | `spec_summary` | 规格取值拼接文本 | 展示该 SKU 独有的规格组合维度（[SKU-F01](./货品管理业务规则规格.md#货品sku唯一性校验规则sku-f01)） |
| **基础档案** | `unit_price` | 系统参考单价展示 | 支持元（保留6位+千分位）与万元（10位）双单位展示，直观清晰（[SKU-F05](./货品管理业务规则规格.md#系统参考单价维护与双精度展示规则sku-f05)） |
| **入库收集项** | `shelf_life_fixed`| **固定单位与建议值只读**| 明确展示该货品绑定的**固定度量衡单位（天/月/年）**及**建议数值**（[SKU-F03](./货品管理业务规则规格.md#入库收集信息配置与保质期固定单位指定规则sku-f03)） |
| **入库收集项** | `required_badge` | 必填状态标签 | 红星【必填 ★】或灰色【选填】（[SKU-F04](./货品管理业务规则规格.md#入库单动态联动与单位只读锁定规则sku-f04)） |
| **审计信息** | `audit_meta` | 创建/更新时间与操作人 | 记录谁在什么时间创建、更新，数据修改版本与历史痕迹全留存，防篡改追溯 |
| **底部按钮** | `btn_edit` | 编辑按钮 | 触发进入编辑页；若该货品已经产生过入库单，系统自动阻断拦截，弹窗提示不可编辑（[SKU-F08](./货品管理业务规则规格.md#编辑操作入库单强拦截规则sku-f08)） |
