## 二、建设目标与核心业务价值

1. **证件地址管理与准入风控**：证件登记地址收口在合作方主档；通过【合作方准入规则】实现个人货主在租户/项目范围内的**证件地址唯一性硬核验**，杜绝多主体冒用同一地址风险；
2. **平台底座与通用参数纳管**：统一【基础配置】与【仓库管理】在 6.3 版本的业务边界，支撑硬件网关对接、敏感脱敏凭证与多级仓库空间监管；
3. **统一主体识别主键**：建立以**身份证号（个人）/ 统一社会信用代码（企业）**为核心的租户内唯一合作方主数据层，彻底解决以往按手机号识别造成的主体冲突；
4. **角色关系与隔离冻结**：业务角色（货主、提货经办人、资金方、**服务方**；**无接收方/待生效**）挂于主档子表；**用户中心 → 合作方档案** 下 **四子菜单** 分域维护，支持按角色隔离冻结，不与 RBAC 登录权限混淆；
5. **存量业务单据大协同**：B 端 **6 大**存量单据（入库记录、出库记录、提货单、转让记录、仓单管理、客户管理）改造为引用合作方，并在写库存与货权变动时点固化**不可变业务快照 (C08)**；**不含**工作中心「客户入库预约」（C 端预约域，6.3 不涉及）；
6. **入库信息收集与货品配置（暂定）**：【入库收集项配置】与【货品管理】收集项/保质期配置 **本期不交付**，三件套作后续版本预埋；6.3 入库作业沿用基准版货品与动态收集口径；
7. **入库暂存登记（暂定开发）**：09 三件套与 R32 联动 **研发暂定排期**，菜单与转正通道随迭代放开（见 [08-版本范围与里程碑](./08-版本范围与里程碑.md)）。
