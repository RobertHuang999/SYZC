## 二、建设目标与核心业务价值

1. **证件地址管理与准入风控**：证件登记地址收口在合作方主档；通过【合作方准入规则】实现个人货主在租户/项目范围内的**证件地址唯一性硬核验**，杜绝多主体冒用同一地址风险；
2. **平台底座与通用参数纳管**：统一【基础配置】与【仓库管理】在 6.3 版本的业务边界，支撑硬件网关对接、敏感脱敏凭证与多级仓库空间监管；
3. **统一主体识别主键**：建立以**身份证号（个人）/ 统一社会信用代码（企业）**为核心的租户内唯一合作方主数据层，彻底解决以往按手机号识别造成的主体冲突；
4. **角色关系与隔离冻结**：业务角色（货主、提货经办人、接收方、资金方等）以独立角色关系子表管理，支持按角色独立冻结/解冻，不与系统 RBAC 权限混淆；
5. **存量业务单据大协同**：存量入库记录、出库记录、提货单、转让记录、仓单管理、客户入库预约、客户管理 7 大业务单据全面改造为引用合作方，并在写库存与货权变动时点固化**不可变业务快照 (C08)**；
6. **入库信息收集标准化与字典池中台化**：新增【入库收集项配置】独立菜单，建立标准元数据字段池；**SKU 为固定保质期单位执行真源**，WMS 入库只读锁定（天/月/年）及默认数值回填，彻底杜绝入库作业人员单位误选与数据撕裂。

## 三、新增与变更菜单（PC 端目标态）

| 导航路径 | 动作类型 | 交付优先级 | 核心说明 |
| :--- | :---: | :---: | :--- |
| **配置管理 → 平台管理 → 基础配置** | **模块重构** | **P0** | 六分类含 **合作方准入策略**（P01~P09）；取消独立「合作方准入规则」菜单 |
| **配置管理 → 仓库管理 → 仓库管理** | **模块重构** | **P0** | 仓库主档、库房、分区空间层级纳管与监管配置 |
| **合作方管理 → 合作方档案** | **新增一级/二级** | **P0** | 业务主体身份、证件地址、业务角色关系及五大标签页穿透详情 |
| **仓储、工作中心、交易存量单据** | **关联改造** | **P0** | 引用合作方主档与不可变快照；仓单持有人流水为 **P1**，详见 [08-版本范围与里程碑](./08-版本范围与里程碑.md) 与协同规格 |
| **配置管理 → 货品规格管理 → 货品管理** | **模块优化** | **P1** | SKU 指定固定保质期单位（只读下发 WMS）、必填与建议默认数值 |
| **配置管理 → 货品规格管理 → 入库收集项配置** | **新增三级** | **P1** | SaaS 级收集项字典池、控件类型、保质期单位范围与引用保护 |
