## 二、建设目标与核心业务价值

1. **统一主体识别主键**：建立以**身份证号（个人）/ 统一社会信用代码（企业）**为核心的租户内唯一合作方主数据层，彻底解决以往按手机号识别造成的主体冲突；
2. **角色关系与隔离冻结**：业务角色（货主、提货经办人、接收方、资金方等）以独立角色关系子表管理，支持按角色独立冻结/解冻，不与系统 RBAC 权限混淆；
3. **证件地址管理与准入风控**：证件登记地址收口在合作方主档；通过【合作方准入规则】实现个人货主在租户/项目范围内的**证件地址唯一性硬核验**，杜绝多主体冒用同一地址风险；
4. **存量业务单据大协同**：存量入库记录、出库记录、提货单、转让记录、仓单管理、客户入库预约、客户管理 7 大业务单据全面改造为引用合作方，并在写库存与货权变动时点固化**不可变业务快照 (C08)**；
5. **入库信息收集标准化**：货品规格管理入库收集信息支持保质期单位固定（天/月/年）及默认数值回填，彻底杜绝入库作业人员单位误选与数据撕裂。

## 三、新增与变更菜单（PC 端目标态）

| 导航路径 | 动作类型 | 交付优先级 | 核心说明 |
| :--- | :---: | :---: | :--- |
| **合作方管理 → 合作方档案** | **新增一级/二级** | **P0** | 业务主体身份、证件地址、业务角色关系及五大标签页穿透详情 |
| **配置管理 → 平台管理 → 合作方准入规则** | **新增二级** | **P0** | 个人货主证件地址必填、唯一校验策略卡片与历史检查门禁 |
| **配置管理 → 货品规格管理 → 货品管理** | **模块优化** | **P1** | 入库收集信息支持保质期单位固定（天/月/年）及默认数值回填 |
| **仓储、工作中心、交易存量单据** | **关联改造** | **P0** | 引用合作方主档与不可变快照，详见协同规格文档 |

> 注：移动端（H5）暂不设独立的合作方维护菜单，下游业务页面统一复用合作方选择与创建组件能力。
