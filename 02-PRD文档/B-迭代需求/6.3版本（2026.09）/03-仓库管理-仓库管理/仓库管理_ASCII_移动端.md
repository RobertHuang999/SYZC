## 1. 移动端整页架构与导航设计

| 菜单（工作台） | 原型路由 |
| :--- | :--- |
| 配置管理 → **仓库管理** | `/m/workspace/config/warehouse-management`（详情 `/:id` · 编辑 `/:id/edit`） |
| 配置管理 → **新增仓库**（独立添加入口） | `/m/workspace/config/new-warehouse` |

移动端采用轻量单列流式与卡片化布局，主要包含 **4 大主页面与操作抽屉群**：
1. **列表页（仓库管理菜单）**：顶部配额看板 + **中仓登准入仓**筛选 + 仓库名称搜索 + 卡片流（查看详情 / 删除 / 停启用 / 去编辑）；**无**底部「新增仓库」按钮；
2. **新增仓库页**：分卡片流式表单（基础信息、管理方信息、中仓登准入及扩展附件）+ 底部常驻【保存】按钮；
3. **查看仓库详情页**：顶部 4 Tab 切换（`基础信息` \| `库房配置` \| `分区配置` \| `设备设施`）+ 只读详情弹窗；
4. **编辑仓库页**：顶部 4 Tab 切换 + Tab2~4 独立添加/编辑抽屉（编辑库房、编辑分区、编辑设备、停用确认）。

## 6. PC 与移动端对齐矩阵

| 业务主题 / 模块 | PC 端呈现形态 | 移动端（H5）呈现形态 | 业务规则一致性（SSOT） |
| :--- | :--- | :--- | :---: |
| **列表页** | 宽屏多列 Table 表格，行操作 | 单列卡片流，首字头像 + 核心字段 + 卡片底栏操作按钮 | 完全一致（状态/增删查改） |
| **新增/编辑页** | 大卡片纵向表单，PC 级联选择器 | 单列分节卡片，移动端 Picker / ActionSheet，底部常驻保存 | 完全一致（个人/企业联动，中仓登4项必填） |
| **详情页** | 左右分栏布局（左主档、右上树表、右下设施） | 顶部 4 Tab 切换（`基础信息` / `库房配置` / `分区配置` / `设备设施`） | 完全一致（空间三级主档结构） |
| **库房/分区维护** | 行内操作 + Modal 居中弹窗 | 行尾快捷按钮 + 底部动作面板（ActionSheet / 弹窗） | 完全一致（同仓重名拦截，无存货停用） |
| **设备设施** | 独立小表格维护 | 独立卡片列表 + 独立添加/编辑抽屉 | 完全一致（台账管理，删除不校库存） |
| **出入库审核 (6.3)** | 库房行 Badge（受控/免审），表单移除单选 | 库房行/详情只读展示（受控/免审），抽屉表单移除单选 | 完全归口基础配置 R02（F13） |
| **监管员/片区经理** | Radio 切换「按人/按角色」，按人多选账号，按角色下拉单选系统角色；详情页根据类型展示个人姓名或角色名称 | Radio/Picker 切换「按人/按角色」，详情 Tab1 对应展示 | 完全一致（数据权限隔离 M01） |
