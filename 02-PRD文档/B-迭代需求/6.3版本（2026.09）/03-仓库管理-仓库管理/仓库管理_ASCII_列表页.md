## 2. 交互弹窗与阻断提示

### 2.1 确认停用二次确认弹窗

点击列表行操作【停用】时弹出：

```text
+------------------------------------------------------+
| 确认停用                                         [X] |
+------------------------------------------------------+
|                                                      |
|   (!)  请确认是否停用该仓库?                          |
|                                                      |
|                                  [ 取消 ]  [ 确定 ]  |
+------------------------------------------------------+
```

### 2.2 停用存货拦截提示（Toast 浮窗）

当仓库辖下任一库房或分区存在在库库存（库存数量 > 0）时，点击确认停用被服务端拦截：

```text
+------------------------------------------------------+
|  (X)  该仓库下有存货，停用失败                        |
+------------------------------------------------------+
```

*(对应业务规则规格 F07 仓库停用在库强阻断规则)*

### 2.3 启用状态删除拦截提示（Toast 浮窗）

对处于启用状态的仓库直接点击【删除】时拦截：

```text
+------------------------------------------------------+
|  (X)  该仓库处于启用状态，仅停用状态支持删除操作！     |
+------------------------------------------------------+
```

*(对应业务规则规格 F10 两阶段安全删除规则)*

## 3. 页面布局与元素说明

| 区域 | 控件/元素 | 说明与业务规则 |
| :--- | :--- | :--- |
| **页头看板** | 仓库配额提醒文案 | `当前可使用仓库数 99999972 个 \| 最多 99999999 个仓库同时使用`（租户容量管控） |
| **筛选操作栏** | `[ 添加仓库 ]` | 路由跳转至添加仓库全页面（`/配置管理/仓库管理/添加仓库`） |
| **筛选操作栏** | `[ 下载仓库信息登记表 ]` | 位于【添加仓库】旁，点击直接下载中仓登准入所需的《仓库信息登记表》空白模版文件（PDF/Word） |
| **筛选区** | `仓库名称` | 单行输入框，支持模糊匹配查询 |
| **筛选区** | `中仓登准入仓标记` | 下拉单选：全部 / 已准入 / 未准入 |
| **筛选操作栏** | `[ 重置 ]` | 点击重置所有筛选项为默认全部 |
| **筛选操作栏** | `[ 查询 ]` | 点击发起列表过滤筛选 |
| **列表表格** | `序号` | 纯数字序号，按分页自动连续计算 |
| **列表表格** | `仓库名称` | 仓库物理主档名称，同租户唯一（F03） |
| **列表表格** | `管理方名称` | 展示管理方企业全称或个人姓名 |
| **列表表格** | `中仓登准入仓标记` | 状态标签：已准入 / 未准入 |
| **列表表格** | `创建人 / 创建时间` | 录入人账号姓名与首次创建时间戳 |
| **列表表格** | `更新时间` | 最近修改并保存成功的时间戳 |
| **列表表格** | `状态` | 空间启用状态：`启用` / `停用` |
| **列表操作** | `查看` | 跳转仓库详情页（`P-CFG-WH-010-DETAIL`） |
| **列表操作** | `编辑` | 跳转仓库编辑页 |
| **列表操作** | `停用` / `启用` | 切换仓库状态；停用前必须通过在库库存强校验（F07） |
| **列表操作** | `删除` | 仅停用态且无下级库房时允许逻辑删除（F10） |
| **分页控件** | 分页栏 | 支持切换条数（10/20/50条）、翻页、页码直达 |
