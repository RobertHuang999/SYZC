## 2. 库房与分区维护模态弹窗

### 2.1 添加库房弹窗

点击【➕ 添加库房】或库房行【编辑】时弹出：

```text
+--------------------------------------------------------------+
| 添加库房                                                 [X] |
+--------------------------------------------------------------+
|                                                              |
|   * 库房名称:        [ 请输入库房名称                     ]  |
|                                                              |
|   * 出入库是否审核:  ( ) 是      ( ) 否                      |
|                      (注：6.3 起该项归口基础配置 R02，       |
|                       仓库表单中移除该项，改为只读 Badge)    |
|                                                              |
|     备注信息:        [ 请输入备注信息                     ]  |
|                      [                                    ]  |
|                      [                            0/500   ]  |
|                                                              |
|                                         [ 取消 ]   [ 确认 ]  |
+--------------------------------------------------------------+
```

### 2.2 添加分区弹窗

点击库房行【新增分区】或分区行【编辑】时弹出：

```text
+--------------------------------------------------------------+
| 添加分区                                                 [X] |
+--------------------------------------------------------------+
|                                                              |
|   * 分区名称:        [ 请输入分区名称                     ]  |
|                                                              |
|   * 所属库房:        [ 1号有色保税库房                  v ]  |
|                      (由所在库房行触发时自动锁定默认值)      |
|                                                              |
|     备注信息:        [ 请输入备注信息                     ]  |
|                      [                                    ]  |
|                      [                            0/500   ]  |
|                                                              |
|                                         [ 取消 ]   [ 确认 ]  |
+--------------------------------------------------------------+
```

### 2.3 库房/分区停用二次确认弹窗

在库房或分区行点击【停用】时弹出二次确认：

```text
+------------------------------------------------------+
| 提示                                             [X] |
+------------------------------------------------------+
|                                                      |
|   确定要停用库房"1号有色保税库房"吗?                 |
|   (若为分区则提示：确定要停用分区"电解铜 A01 货位区"吗?) |
|                                                      |
|                                  [ 取消 ]  [ 确定 ]  |
+------------------------------------------------------+
```

*(点击确定后校验在库库存；若有存货则 Toast 阻断「该库房下有存货，停用失败」F08/F09)*

## 4. 详情页与弹窗字段字典与校验说明

| 区域/弹窗 | 字段/控件 | 类型 | 必填 | 取值/规则 | 业务说明 |
| :--- | :--- | :--- | :---: | :--- | :--- |
| **基础信息卡片** | 仓库监管员类型 | 纯文本 | 只读 | `按人` 或 `按角色` | 决定监管员指派形态。按人指派具体员工；按角色指派监管团队 |
| **基础信息卡片** | 仓库监管员 | 纯文本 | 只读 | 按人：人员姓名列表<br>按角色：角色团队名称 | 按人示例：`张伟、李明`；按角色示例：`期货交割库现场监管组`、`特种危化品安全监管员` |
| **基础信息卡片** | 片区经理类型 | 纯文本 | 只读 | `按人` 或 `按角色` | 决定片区大区管理职责归属形态 |
| **基础信息卡片** | 片区经理 | 纯文本 | 只读 | 按人：人员姓名列表<br>按角色：角色团队名称 | 按人示例：`陈建国、王崇`；按角色示例：`华南大区片区总监角色`、`北方大区风控巡查组` |
| **库房弹窗** | 库房名称 | 文本输入框 | **必填** | 1~50 字符 | 同一仓库内库房名称唯一（F03） |
| **库房弹窗** | 出入库是否审核 | 单选组 | **老系统必填** | `( ) 是  ( ) 否` | **6.3 改造**：归口基础配置 R02，表单移除此项，列表只读透出 Badge（F13） |
| **库房弹窗** | 备注信息 | 多行文本框 | 选填 | 最多 500 字（0/500 计数） | 库房补充说明 |
| **分区弹窗** | 分区名称 | 文本输入框 | **必填** | 1~50 字符 | 同一库房内分区名称唯一（F03） |
| **分区弹窗** | 所属库房 | 下拉选择框 | **必填** | 当前仓库下有效库房 | 行操作新增时自动预选当前行库房 |
| **分区弹窗** | 备注信息 | 多行文本框 | 选填 | 最多 500 字（0/500 计数） | 分区物理位置或用途补充说明 |
| **设施弹窗** | 所在仓库 | 文本输入框 | 只读 | 当前仓库名称 | 自动回显，不可编辑 |
| **设施弹窗** | 设备设施名称 | 文本输入框 | **必填** | 1~50 字符 | 设施台账名称（F14） |
| **设施弹窗** | 数量与单位 | 双输入框 | 选填 | 数字 + 单位文本 | 例如：`1` + `吨`、`10` + `个` |
| **设施弹窗** | 有效期 | 日期选择器 | **必填** | `YYYY-MM-DD` | 设施维保或有效截止日期 |
| **库房/分区操作** | 停用 | 行操作按钮 | — | 触发存货校验 | 必须无在库库存方可停用（F08/F09） |
| **库房/分区操作** | 删除 | 行操作按钮 | — | 触发两阶段删除校验 | 启用态不可删；库房有分区/有入库单不可删（F11/F12） |
