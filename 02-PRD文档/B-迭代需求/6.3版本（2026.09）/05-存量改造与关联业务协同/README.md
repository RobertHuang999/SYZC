## 四、维护约定

1. **单据字段与规则变更**：先改对应菜单三件套（或 10/11 副本）→ 再回写 [协同规格](./合作方改造-存量业务单据协同规格.md) 摘要与附录 A → 同步 Demo `partner-stock-change-map.ts`。  
2. **迁移脚本变更**：只改 [迁移真源](./6.3合作方主数据-数据迁移与切流.md) → 同步协同规格 **附录 C** 摘要。  
3. **禁止**在 05 目录新建与 `04-1~04-4` 重复的子菜单三件套（见 [00-目录与路径清理走查记录](../00-目录与路径清理走查记录.md)）。
