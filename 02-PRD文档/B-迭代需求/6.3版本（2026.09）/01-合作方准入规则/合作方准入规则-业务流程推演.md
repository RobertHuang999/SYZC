# 合作方准入规则-业务流程推演

> **版本**：V2.0（A 方案） | **更新时间**：2026-10-09  
> **参考**：[主PRD](./合作方准入规则主PRD.md) · [业务规则规格](./合作方准入规则业务规则规格.md) · [字段清单](./合作方准入规则字段清单.md)

---

## 一、概述

- **入口**：`配置管理 → 平台管理 → 合作方准入规则` → **设置页**（无列表）。
- **可配项**：个人货主 **证件地址必填**、**证件地址唯一校验**。
- **企业货主**：页内只读说明；不参与个人双开关。
- **生效**：**保存即生效**；无启停/草稿。
- **唯一=开**：保存前存量检测；冲突则保存失败。
- **运行时**：各业务入口调用统一准入服务；冲突同步阻断（PAR-R07）。

---

## 二、端到端流程

```mermaid
flowchart TD
    Start(["打开准入策略设置页"]) --> Edit["调整双开关"]
    Edit --> Save["点击保存"]
    Save --> Loose{"放宽策略?"}
    Loose -->|是| Reason["填写变更原因"]
    Loose -->|否| Unique{"唯一=开?"}
    Reason --> Unique
    Unique -->|是| Scan["存量检测"]
    Unique -->|否| OK["落库+内部版本+1"]
    Scan -->|未通过| Block["保存失败+弹窗"]
    Scan -->|通过| OK
    OK --> Biz["业务提交调用准入服务"]
    Biz --> Pass{"通过?"}
    Pass -->|是| Cont["继续业务流程"]
    Pass -->|否| Rej["阻断+统一提示"]
```

## 四、默认预置

| 项 | 值 |
| :--- | :--- |
| 证件地址必填 | 是 |
| 证件地址唯一校验 | 开 |
| 每租户策略条数 | 1 |

---

## 五、关键分支

1. **存量冲突**：唯一=开且检测未通过 → 不能保存。
2. **C08**：保存后新业务用新双开关；历史单据快照不变。
3. **企业货主**：不套用个人双开关；按档案/认证校验证件地址。
4. **空地址 + 必填否 + 唯一开**：空不参与唯一比对（PAR-R04）。
