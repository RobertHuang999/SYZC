## 布局说明

| 区域 | 说明 |
| :--- | :--- |
| Sidebar | 选中「合作方准入规则」；点击菜单 **直接进入本页** |
| 分区 A | 唯一可编辑项：双开关 + 检测按钮 |
| 分区 B | 静态文案；无表单控件 |
| 分区 C | PAR-R07 产品说明 |
| 页脚 | 可选最近保存摘要；**不展示** V1/V2、规则编号 |
| 权限 | 超管可保存；运营只读（按钮隐藏） |

---

## 保存交互

| 步骤 | 行为 |
| :--- | :--- |
| 1 | 点击【保存】 |
| 2 | 若 必填 是→否 或 唯一 开→关 → 弹「变更原因」≤200 字 |
| 3 | 若 唯一=开 → 执行存量检测；未通过 → 保存失败，见下弹窗 |
| 4 | 成功 → Toast「保存成功」；更新最近保存摘要；内部版本+1（用户不可见） |
