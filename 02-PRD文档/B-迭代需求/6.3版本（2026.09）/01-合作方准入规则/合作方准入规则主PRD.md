## 1. 业务背景与目的

【合作方档案】维护主体数据；【合作方准入规则】回答：**个人货主在业务入口要不要填证件地址、要不要租户内一人一址**。企业货主在同一页 **只读说明**（按认证/档案维护地址，不参与个人一人一址）。

地址冲突视为硬性风险，须业务提交前拦截，**不进入审批中心**。

## 5. 页面功能说明

### 5.1 合作方准入策略 — 设置页（唯一 P0 页面）

- **路径**：`配置管理 → 平台管理 → 基础配置` → 左侧 **合作方准入策略**
- **线框**：[基础配置_ASCII_配置页 第3节](../02-平台管理-基础配置/基础配置_ASCII_配置页.md)

**页头**：标题「合作方准入策略」；副标题说明个人可配、企业见下方说明。

**分区 A — 个人货主（可配置）**

| 控件 | 说明 |
| :--- | :--- |
| 证件地址必填 | 单选 是/否 |
| 证件地址唯一校验 | 开关 开/关 |
| 检测存量数据 | 唯一=开时可点；结果弹窗 |
| 保存 / 取消 | 保存=生效；Dirty 离开拦截 |

**分区 B — 企业货主（只读）**

- 固定文案：营业执照登记地址由认证/档案维护；不参与个人一人一址；仍走统一准入但不套用 A 区双开关。

**分区 C — 固定说明**

- 地址冲突：同步拦截，不进审批中心。

**页脚（可选）**：最近保存时间、操作人（不展示规则版本号）。

**保存规则**：

1. 唯一=开 → 须存量检测通过才允许保存；
2. 必填 是→否 或 唯一 开→关 → 弹窗 **变更原因**（≤200 字）；
3. 成功 → 内部版本 +1、服务热更新、写审计。

### 5.2 历史存量检测弹窗

- **时机**：保存（唯一=开）、【检测存量数据】；
- **内容**：结论、冲突组数、缺地址数、脱敏清单、处理建议；
- **未通过**：不可保存唯一=开的配置。

### 5.3 已取消的页面（P0）

| 原页面 | P0 处理 |
| :--- | :--- |
| 列表页 | 取消；路由指向设置页 |
| 详情页 | 取消 |
| 新增第二条规则 | 取消 |

## 7. 非功能需求（摘要）

- 策略加载 ≤20ms；10 万主体存量扫描 ≤3s；保存后热更新 ≤1s。
- 冲突清单与错误提示不泄露第三方身份信息。
