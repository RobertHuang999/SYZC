## 二、需求摘要（说人话）

1. **PC 端** 以下任一页面点【批量导出】，弹出 **同一套**「选择导出内容」弹窗，勾选要导出的 **菜单/视图**，提交 **异步任务**，在【导出记录】中查看状态并下载。
2. **入口一致**：存货管理（仓库 / 货物 / 货主三个 Tab 共用入口）、库存明细、库存流水。
3. **默认行为**：弹窗内 **默认仅勾选「本菜单」分区**（见第三节）；可再勾选「其他菜单」跨模块导出。导出范围为 **权限内全量**，**不受当前列表页筛选条件影响**。
4. **库存明细全量口径**：与列表 **「仅查看有库存的」** 一致——只导出 **仍有库存余量** 的明细（可用数量与冻结数量合计大于 0）；已出清、余量为零的记录 **不进入** 明细 Sheet。界面文案不写「货位」，避免与库位物理概念混淆。

## 三、弹窗导出项（多选 · 本菜单 / 其他菜单分区）

弹窗引导语：**「请选择要导出的内容」**。选项分为两个视觉区块：

| 区块 | 说明 |
| :--- | :--- |
| **本菜单 · {当前菜单名}** | 用户当前所在菜单的导出项；**打开弹窗时默认全部勾选** |
| **其他菜单** | 可跨模块追加勾选；选项文案带菜单前缀（如「存货管理 · 仓库视图」） |

| 选项 ID | 本菜单区内文案 | 其他菜单区内文案 | 默认（按入口） |
| :--- | :--- | :--- | :--- |
| `STAT_REPO` | 仓库视图 | 存货管理 · 仓库视图 | 自「存货管理」进入：✅ |
| `STAT_GOODS` | 货物视图 | 存货管理 · 货物视图 | 自「存货管理」进入：✅ |
| `STAT_OWNER` | 货主视图 | 存货管理 · 货主视图 | 自「存货管理」进入：✅ |
| `DETAIL` | 仅仍有库存余量的明细 | 库存明细（仅仍有库存余量的明细） | 自「库存明细」进入：✅ |
| `FLOW` | 库存流水（列表） | 同左 | 自「库存流水」进入：✅ |

**至少勾选一项** 才可提交；全部为未勾选时阻断并提示：「请至少选择一种导出内容」。

## 四、全量边界（权限与各菜单固有口径）

**「全量」定义**：当前登录 **租户 / 机构** 下，该账号 **仓库数据权限** 允许看到的全部数据；**不** 含未授权仓库、**不** 跨租户。

| 导出项 | 全量时沿用的基准口径（不在弹窗重复配置） |
| :--- | :--- |
| 存货管理三视图 | 与基准列表 **重置后查询** 一致；列集、脱敏、未定价展示规则不变 |
| 库存明细 | **强制** 仅导出仍有库存余量的明细（IE-R02，同列表「仅查看有库存的」）；动态「其他信息」列展平规则 **上线合并基准时** 与字段清单对齐 |
| 库存流水 | 仅终态有效单据（入库已通过、出库已核销等），与基准 **【终态单据统计闭环】** 一致 |

弹窗底部 **上线用户说明**（`ProductFieldHint` 口径）：「导出为您有权限的全部数据，不受本页筛选影响。」

## 五、异步任务与交付物

| 项目 | 约定 |
| :--- | :--- |
| 任务模型 | 一次提交 = **一个** 异步任务 ID；状态：处理中 / 成功 / 失败（可重试，对齐存货管理 **【导出任务排队超时】** 体验） |
| 文件形态 | **仅单菜单**（只勾选存货管理三视图之一项或多项、或仅明细、或仅流水）：交付 **单个 `.xlsx` 多 Sheet**（+ 可选「导出说明」Sheet）。**跨菜单**（存货管理 / 库存明细 / 库存流水 **三类中勾选 ≥2 类**）：交付 **`.zip` 压缩包**，包内按菜单/视图拆分多个 `.xlsx`（或超大时拆多个文件），任务仍 **一条** |
| 文件命名 | 单菜单：`库存组合导出-{YYYYMMDDHHmmss}.xlsx`；跨菜单：`库存组合导出-{YYYYMMDDHHmmss}.zip` |
| 导出记录 | **租户内统一队列**：任意上述入口打开【导出记录】见 **同一列表**；弹窗列表列 **与基准一致**，仅 **序号、文件名、操作人、时间、状态、操作** 六列（不新增界面列）；跨菜单/单菜单、`.zip`/`.xlsx` 以 **文件名后缀** 区分 |
| 下载安全 | 与基准存货管理一致：对象存储临时签名、创建人本人可下、审计留痕 |

## 七、业务规则（6.3 增量编号 · 合并前仅本文有效）

### 【跨菜单导出入口统一规则】(IE-R01)

* 存货管理（三 Tab）、库存明细、库存流水五处 **【批量导出】** 均打开 **同一弹窗组件** 与 **同一后端创建任务接口**；`sourceMenu` 决定 **「本菜单」分区** 与 **默认勾选范围**（仅本菜单项，非五项全选）。

### 【库存明细导出默认仅有库存余量规则】(IE-R02)

* 组合导出中的 **库存明细** Sheet，必须应用与列表 **「仅查看有库存的」** 相同的过滤：只含 **仍有库存余量** 的行（可用数量与冻结数量合计大于 0）；已出清、余量为零的记录不导出。**不提供** 弹窗内切换「含零余量明细」；若未来需要，须单独立项改基准明细规则后再同步组合导出。
* 弹窗选项文案须表达 **余量口径**，禁止使用易误解为库位筛选的「仅有库存货位」等说法。

### 【组合导出与行级下载记录命名隔离规则】(IE-R03)

* **库存流水列表** 组合导出：文件名 / Sheet 名使用 **「库存流水（列表）」** 语义；**禁止** 与行操作 **【下载记录】**（单笔单据明细）共用同一权限码或同一导出类型枚举，避免审计与客服混淆。

### 【组合导出全量不受列表筛选规则】(IE-R04)

* 创建任务 **不读取** 当前页 `appliedFilters`、穿透锁定参数；仅读取弹窗勾选的 `exportTargets` + 账号数据权限。用户若需局部数据，须在未来版本单独立项（**非 6.3 范围**）。

### 【组合导出异步任务与记录统一规则】(IE-R05)

* 任务调度、导出记录弹窗、失败重试、下载签名策略 **继承** 存货管理 **【批量导出异步任务】(R17)**、**【导出记录历史弹窗】(R18)** 的产品要求；实现上 **一个** 导出记录服务实例，不按菜单拆三套前端 state。

### 【跨菜单导出 Zip 打包规则】(IE-R06)

* 当一次任务勾选的导出项 **同时覆盖** 存货管理（任一路径视图）、库存明细、库存流水 **中的两类及以上** 时，判定为 **跨菜单导出**，生成文件名 **必须以 `.zip` 结尾**，包内各菜单数据 **分文件** 存放，**禁止** 合并为单个 `.xlsx`。
* **仅单菜单**（例如只勾三个存货视图、或只勾明细、或只勾流水）：文件名 **`.xlsx`**，多 Sheet 同文件。
* 导出记录弹窗 **不新增列表列**；`.zip` / `.xlsx` 仅在 **文件名** 列体现。弹窗勾选触发跨菜单时须 **ProductFieldHint** 提示将打包为 Zip。

```text
                        |                                                      |
                        |                      [ 取消 ]    [ 开始导出 ]（主按钮） |
                        +------------------------------------------------------+
```

**默认**：打开时 **仅「本菜单」分区内项勾选**（自「存货管理」进入则三视图勾选；自明细/流水进入则对应一项勾选）（IE-R01）。

**校验**：

- 五项均未勾选 → 【开始导出】可点但提交后 Toast：`请至少选择一种导出内容`（或按钮置灰，二选一实现，推荐置灰 + 文案）。
- 无「库存明细」查看权限 → 第四行 `[☐]` **禁用置灰**，右侧灰字：`无库存明细查看权限`。
- 无「库存流水」查看权限 → 第五行同理。

**取消 / 点遮罩 / [X]**：关闭弹窗，不创建任务。

**【开始导出】**：关闭弹窗 → 右下角 Toast（见 11.3）→ 后台异步任务。
