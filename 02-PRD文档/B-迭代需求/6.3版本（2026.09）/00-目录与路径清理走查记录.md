## 一、清理目标

1. **合作方子菜单三件套唯一目录**：只维护 `04-合作方档案/04-1~04-4/`，**禁止**在 6.3 根目录平行复制 `13~16-合作方档案-*`（历史误建序号，与 08 序号 13「数据迁移」无关）。  
2. **菜单路径与原型路由**：PC 以 **用户中心 → 合作方档案 → 四子菜单** 为准；旧书签 **用户中心 → 合作方管理 → 合作方档案** 仅作重定向，不作为 SSOT。  
3. **跳转页与 SSOT**：`合作方档案主PRD|字段清单|业务规则规格.md` 仅为入口跳转，正文不得在此扩写。  
4. **跨库引用**：基准版、原型 `@docs`、权限 `baselineModuleDir` 一律指向 **04-x** 或 **公共三件套**，不得指向已废止的根级 13~16 目录。

```bash

rg '6\.3版本（2026\.09）/1[3-6]-合作方档案' .

# 不得把子菜单三件套写进已废止单页路径（权限 legacyPath 除外）
rg 'baselineModuleDir.*合作方档案/合作方档案主' .

# 原型文档 import 须含 04-1~04-4 或公共三件套
rg 'partner-archive-documents|partner-archive-documents.shared' 03-前端原型demo -l
```
