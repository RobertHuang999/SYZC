> **对齐字段清单 第一章 / 第七章**：
> 1. **主键与规则名称**：首列 `序号` 居左固定；`规则名称` 可点击高亮下钻进入 [合作方准入规则_ASCII_详情页](./合作方准入规则_ASCII_详情页.md)；
> 2. **适用业务场景列**：以彩色标签并列摘要呈现（C端认证/人工建档/入库记录/客户入库预约/追加货主），超出展示 `+N`；
> 3. **双开关独立呈现**：「地址必填」（是/否）与「地址唯一校验」（开启/关闭）独立占列展示，明确双开关互不替代；唯一开启时附带历史冲突检查状态标识（已检/未检）；
> 4. **规则版本号**：`V1`、`V2` 加粗展示；生效规则编辑保存后原子自增（PAR-R01 / C08 存量不回写）；
> 5. **行操作与状态联动**：生效中展示【编辑】【停用】；已停用与草稿展示【编辑】【启用】；【历史冲突检查】当且仅当唯一校验开启时高亮可点（PAR-P02 动作矩阵）。

## 布局说明

**顶部导航（Header）**：全局模块切换；当前选中「配置管理」板块。

**左侧菜单（Sidebar）**：平台管理组下展开，当前选中「合作方准入规则」二级菜单。

**主内容区（Main Content）**：

- **页头区**：主标题「合作方准入规则」+ 模块策略定位说明。
- **筛选区（Card 容器）**：
  - **右上角操作**：`[ 重置 ]` · `[ 查询 ]`（黄色主按钮） · `[ + 新增规则 ]`（带管理权限保护）；
  - **筛选项排布**：
    - 规则名称：单行文本输入框，支持租户内模糊检索；
    - 适用主体类型：下拉单选（全部主体类型 / 个人 / 企业）；
    - 适用业务场景：下拉多选，包含匹配五大业务场景；
    - 地址唯一校验：下拉单选（全部状态 / 开启 / 关闭）；
    - 规则状态：下拉单选（全部规则状态 / 草稿 / 生效中 / 已停用）；
  - 支持回车快捷触发查询；重置恢复全量列表。
- **数据表格区**：
  - 10 列排布：`序号`、`规则名称`、`适用主体`、`适用业务场景`、`地址必填`、`地址唯一校验`、`版本`、`状态`、`更新时间`、`操作`；
  - 默认排序：按 `更新时间` 倒序排列；
  - 租户预置：新租户初始化自动预置行 1「租户默认个人货主准入规则」（个人 + 货主 + 五大场景 + 必填=是 + 唯一=开 + 生效中）。
- **分页器**：默认 10 条/页。

## 核心交互弹窗线框

### 1. 【停用准入规则】二次确认弹窗 (PAR-R09)

```text
+--------------------------------------------------------------------+
| 停用准入规则确认                                                [X] |
+--------------------------------------------------------------------+
|                                                                    |
|  ⚠️ 警告：停用准入规则后，全系统新发起或生效的业务将不再执行该规则  |
|     约定的个人货主证件地址必填与唯一性校验！                        |
|                                                                    |
|  规则名称:    租户默认个人货主准入规则 (V1)                        |
|  适用场景:    C端认证、人工建档、入库记录、客户入库预约、追加货主   |
|                                                                    |
|  在途单据说明：审批流转中的单据不受停用影响，仍将按照提交时固化的  |
|                规则版本执行终审复检（版本锚定机制）。              |
|                                                                    |
|  * 停用原因:  [ 请录入停用该准入规则的原因说明（必填，≤200字）   ]  |
|               [ 系统配合仓储历史存量数据清洗，临时停用地址唯一校验]  |
|               0/200 字                                             |
|                                                                    |
+--------------------------------------------------------------------+
|                                              [ 取 消 ]  [ 确认停用 ]|
+--------------------------------------------------------------------+
```

### 2. 【启用规则】历史冲突检查未通过阻断弹窗 (PAR-R05 门禁阻断)

若规则的「个人货主证件地址唯一校验」处于【开启】状态，点击【启用】时系统后台自动调用历史数据扫描，发现冲突直接弹出阻断弹窗并禁止启用：

```text
+--------------------------------------------------------------------+
| 历史冲突检查未通过 — 禁止启用                                  [X] |
+--------------------------------------------------------------------+
|                                                                    |
|  🚫 阻断提示：系统扫描发现当前租户存量有效个人货主中存在同地址绑定  |
|     不同身份证号的严重冲突，严禁直接启用唯一校验！                 |
|                                                                    |
|  +-- 核心检测指标 ----------------------------------------------+  |
|  | 有效个人货主总数: 48 位  | 冲突地址组数: 2 组 (涉及 4 位主体)  |  |
|  +--------------------------------------------------------------+  |
|                                                                    |
|  冲突明细脱敏摘要：                                                |
|  ┌───────────────────────────────────────────────────────────────┐  |
|  │ 冲突组 1: 江苏省无锡市滨湖区金融一街88号... (涉及主体: PS-001, PS-003) │
|  │ 冲突组 2: 江苏省无锡市梁溪区清名桥街道... (涉及主体: PS-007, PS-009) │
|  └───────────────────────────────────────────────────────────────┘  |
|                                                                    |
|  处置要求：请前往【合作方档案】对上述主体执行角色移除或资料纠偏，  |
|            待冲突组数降为 0 后方可重新启用。                       |
|                                                                    |
+--------------------------------------------------------------------+
|                                              [ 导出明细 ]  [ 我知道了 ]|
+--------------------------------------------------------------------+
```
