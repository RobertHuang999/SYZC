## 4. 新增 / 编辑页面差异对比

| 对比维度 | 新增准入规则 (`/新增`) | 编辑准入规则 (`/编辑/:id`) | 业务规则依据 |
| :--- | :--- | :--- | :--- |
| **页面主标题** | 新增准入规则 | 编辑准入规则 — {规则名称} | 明确操作上下文 |
| **升版警告横幅** | 不展示 | **高亮展示黄色升版与 C08 不回写提醒** | PAR-R01 / C08 |
| **规则业务编号** | 不展示（保存时系统生成） | 展示，如 `PAR-DEFAULT-001`（只读） | 策略主键 |
| **规则版本号** | 初始默认为 `V1` | 展示当前生效版本，如 `V1` | PAR-R01 |
| **保存动作按钮** | 【保存为草稿】 / 【保存并启用】 | **【保存并生效】（生效中自动升版本）** | PAR-R01 |
| **变更原因录入** | 不触发 | **修改双开关或关键场景时强制录入** | PAR-R09 审计留痕 |
| **历史冲突检查** | 唯一校验开启时须点击检查通过 | 唯一校验开启时必须保持检查通过 | PAR-R05 门禁约束 |
| **规则运行状态** | 初始为 `⚪ 草稿` 或 `🟢 生效中` | **保持原运行状态**（生效中/已停用） | PAR-R09 禁止表单改状态 |

## 布局说明

**顶部导航 / 左侧菜单**：与 [列表页](./合作方准入规则_ASCII_列表页.md)、[详情页](./合作方准入规则_ASCII_详情页.md) 一致，处于「配置管理」一级板块与「平台管理 → 合作方准入规则」二级菜单。

**标签页（Tabs）**：顶部面包屑展示「首页」「合作方准入规则」以及当前页「编辑准入规则 — {规则名称}」。

**表单分区排布（双面板 Card 容器）**：
1. **基础规则配置**：规则编号、规则名称输入框、适用主体类型单选、适用角色复选、适用场景复选；
2. **个人货主准入控制策略**：个人货主证件地址必填（单选 是/否）、地址唯一校验（开关控件）、历史数据检查状态条（带立即检测按钮与结果标签）、冲突处理策略（固定只读呈现「阻断」）；
3. **策略运行态控制**：只读状态徽章与禁止表单内修改说明。

**表单交互联动特性**：
- **主体类型联动**：切换为主体类型「企业」时，个人货主双开关整块置灰禁用并弹出提示；切换回「个人」时恢复可配置状态；
- **唯一校验联动**：唯一校验开关置为【开启】时，下方历史检查状态条即刻点亮；若历史检查未通过，表单底部的【保存并生效】主按钮置灰禁用，直至检测通过；
- **防未保存离开**：监测表单 Dirty 状态，未保存点击导航时弹出离开拦截弹窗。

| **基础配置** | 适用业务场景 | 多选复选框组 (Checkbox)| 必填 | 五大业务场景多选；运行时按场景精确匹配 | PAR-R02 |
