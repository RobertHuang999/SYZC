## 3. DetailField 单字段排版结构规范

本模块严格遵循统一视觉组件原子规范，采用 **上 label 灰色（13px）、下 value 深色（14px）** 纵向排布，严禁 label 与 value 左右挤在同一行：

```text
┌──────────────────────────┐
│ 个人货主地址唯一校验     │  ← label: text-xs text-muted-foreground (灰色)
│ 🟢 开启 (一对一绑定)     │  ← value: text-sm font-medium text-foreground (深色)
└──────────────────────────┘
```

## 5. 示例数据对照（租户默认规则 · PAR-DEFAULT-001）
