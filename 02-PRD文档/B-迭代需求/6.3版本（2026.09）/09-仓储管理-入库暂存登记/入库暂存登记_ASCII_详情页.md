## 二、【已转正式】与【已作废】状态差异对比

### 2.1 状态印章与顶部字段差异
- **【已转正式】状态**：
  - 顶部状态印章展示：`[ 状态印章: 已转正式 🟢 ]`；
  - 关联正式单展示：`[ 关联正式单: 2026101415101200008 🔗 (19位，点击打开正式单) ]`；
  - 审计卡片透出：`转正提交: 王五 (仓库主管 / 2026-10-14 16:30:15 / 生成正式入库单)`；
  - 底部按钮栏：仅展示 `[ 返回列表 ]` 与 `[ 📄 查看正式入库单 ]`，禁用/隐藏编辑、转正与作废按钮。

- **【已作废】状态**：
  - 顶部状态印章展示：`[ 状态印章: 已作废 ⚪ ]`；
  - 审计卡片透出：`作废人: 赵六 (2026-10-14 17:00:00) | 作废原因: 货车司机与货主发生运费纠纷，现场取消入库并将货物运离仓库`；
  - 底部按钮栏：仅展示 `[ 返回列表 ]`，全表单永久只读。

## 三、作废登记单二次确认弹窗 (O02)

> **触发时机**：处于【待补全】状态下，用户点击底部【作废单据】按钮时唤起。

```text
+-----------------------------------------------------------------------------------------------+
|  作废入库暂存登记单                                                                        [x]|
+-----------------------------------------------------------------------------------------------+
|                                                                                               |
|  ⚠️  警告：确定作废该暂存登记单 (REG-20261014-00001) 吗？                                      |
|      作废后该登记单将永久只读归档，不可恢复，且不可再转为正式入库。                           |
|                                                                                               |
|  * 作废原因 (必填):                                                                           |
|  +-----------------------------------------------------------------------------------------+  |
|  | [ 请录入详细作废原因，如：现场退货取消入库、误登记重复单据等...                       ] |  |
```

## 四、转为正式入库确认与引导弹窗 (O03)

> **触发时机**：处于【待补全】状态下，用户在列表操作列或详情页底栏点击【🚀 转为正式入库】按钮时唤起。

```text
+-----------------------------------------------------------------------------------------------+
|  转为正式入库确认                                                                          [x]|
+-----------------------------------------------------------------------------------------------+
|                                                                                               |
|  🚀 即将为登记单 [REG-20261014-00001] 发起正式入库申请                                       |
|                                                                                               |
|  • 系统将把当前暂存的 入库类型、关联单号、货品 SKU、申报数量、库位与照片 完整预填至正式入库页； |
|                                                                                               |
|  📋 正式入库前置风控要求提示：                                                                |
|    1. 货主核验：货主若为【临时待核】，须在正式页重新选定标准档案企业（新货主须完成短信二元核验）； |
|    2. 库位清零：暂存未分配的库位将在正式页强制展开，须将未堆放数量全部清零 (R13)；            |
|    3. 现场照片：正式单须至少上传 1 张现场货物照片 (R16)；                                     |
|    4. 单号匹配：若关联单号为手填文本，须确保在系统内存在有效对应单据，否则阻断提交 (P06)；    |
|                                                                                               |
|  ℹ️ 只有在正式入库页点击【提交审核】成功后，当前暂存单才会回写为【已转正式】；中途取消不产生废单。   |
|                                                                                               |
+-----------------------------------------------------------------------------------------------+
|                                                  [ 取 消 ]          [ 确认并前往正式页 (推荐) ]|
+-----------------------------------------------------------------------------------------------+
```
