## 三、行操作能力与状态色彩映射

### 3.1 状态徽标与视觉表现
- **待补全**：橙色徽标（`bg-amber-50 text-amber-700 border-amber-200`），表示现场事实已记录，要素尚未齐备或等待转正；
- **已转正式**：绿色徽标（`bg-emerald-50 text-emerald-700 border-emerald-200`），表示已成功关联 19 位正式单并提交审核闭环；
- **已作废**：灰色徽标（`bg-slate-100 text-slate-500 border-slate-200`），表示现场取消或误录废弃。

### 3.2 行操作按钮权限约束
| 状态 | 允许操作 | 交互行为 | RBAC 权限依赖 |
| :---: | :--- | :--- | :--- |
| **待补全** | **【编辑】** | 跳转登记编辑页 (`mode=edit`)，可展开补库位、照片、修改数量 | `R-WH-IN-REG-EDIT` |
|  | **【转为正式入库】** | 弹出转正确认与引导窗 (O03)，确认后打开正式入库新增页预填快照 (P06) | `R-WH-IN-REG-CONVERT` |
|  | **【作废】** | 弹出作废确认窗 (O02)，必须录入作废原因（最多 200 字） | `R-WH-IN-REG-VOID` |
| **已转正式** | **【查看详情】** | 进入只读详情页，展示历史快照与关联正式单号 | `R-WH-IN-REG` |
|  | **【查看正式入库单】** | 新开标签页跳转至 `/仓储/入库管理/入库记录/详情?orderNo={19位正式单号}` | 依赖入库记录只读权限 |
| **已作废** | **【查看详情】** | 进入只读详情页，展示作废原因、作废人及作废时间 | `R-WH-IN-REG` |

## 四、筛选与搜索交互细节

1. **默认 4 项紧凑展示**：
   - 登记单号（支持单号前缀模糊检索）、入库日期范围（默认最近 30 天）、入库类型（普通/质押/抵押/监管服务/仓单下拉）、仓库名称（单选下拉，受限于用户数据权限 R05）；
2. **展开更多筛选**：
   - 点击【展开筛选 v】向下滑出单据状态、货主/送货说明综合检索、登记人、关联入库单号（精确匹配）；
3. **货主「临时待核」与「档案货主」标签展示**：
   - 当单据为手工自由录入说明时，展示说明文字并附带灰色标签【临时待核 🏷️】；
   - 当单据选定了系统合作方时，展示企业/个人名称并附带蓝色标签【档案货主】。
