## 二、从移动端「入库发起」切换通道 ActionSheet (O01)

> **触发方式**：现场人员在移动端 `业务办理 → 入库发起` 表单中，点击顶部常驻提示栏 *“现场紧急卸车？切换为暂存登记通道”* 时弹出。

```text
+-------------------------------------------------------------+
|                                                             |
|  切换至【入库暂存登记】通道                                 |
|  ---------------------------------------------------------  |
|  • 用于现场货主未定、单号未出、库位未分或照片未齐的备忘；   |
|  • 暂存单 不会 提交审批、不会 写入在库物理库存；            |
|  • 暂存单 不会 触发新货主短信二元核验验证码 (R03)；         |
|  ✨ 已录入的类型、单号、货品、数量、库位与照片将 原样带入。  |
|  ---------------------------------------------------------  |
|  [ 📋 带入已填信息并前往登记页 (推荐) ]                     |
|  [ 📄 前往空白登记页 (不带入内容) ]                         |
|  [ 取 消 (留在当前正式入库发起页) ]                         |
| +-------------------------------------------------------------+
```

## 三、小程序原生布局优化与改动要点

1. **原生胶囊区避让**：保留微信原生胶囊安全区 `( ··· | ⭕ )`；
2. **通栏提示条 (NoticeBar) 承接说明**：弱化繁复弹窗，突出“30秒极速记账”；
3. **货主一体化与类型放开**：全面放开入库类型；取消 Switch 货主开关，单一输入框支持档案快选与手填；
4. **库位默认折叠**：手机端屏幕寸土寸金，默认折叠库位分配，操作员单手即可在 2 屏内滑动完成保存。
