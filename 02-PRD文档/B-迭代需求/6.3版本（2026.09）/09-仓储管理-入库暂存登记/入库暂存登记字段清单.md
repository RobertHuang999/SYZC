# 入库暂存登记字段清单

> **文档定位**：仓储 / 入库管理 / **入库暂存登记**菜单（单据主表、货品明细、堆放位置、统计汇总、操作记录及弹窗）字段定义。与正式 **入库记录** 共用同一套货品、货主、库位字段口径；差异在暂存阶段门槛放宽、极速录入与弱校验。  
> **对齐基准**：[入库记录字段清单.md](../../../🌟🌟🌟-最新基准版/B端PC/02-仓储/09-入库管理-入库记录/入库记录字段清单.md)（SKU 选货 R11、计量单位只读 R11b、具体位置文本 20 字、影像与收集项结构）；6.3 正式单副本见 [10-仓储管理-入库记录](../10-仓储管理-入库记录/)。  
> **规则引用**：[入库暂存登记业务规则规格.md](./入库暂存登记业务规则规格.md)（P01～P09）；转正提交时叠加引用入库记录 **R03、R04、R06、R13、R16、R17** 等强校验。  
> **版本**：V1.5 | **更新时间**：2026-10-14 | **责任人**：森云科技（Senyun Technology）

---

## 0. 对象与字段层级说明

1. **单据主信息**：登记单号、入库日期、入库仓库、入库类型、关联单号（选填/支持手填）、货主/送货说明（智能一体化：档案联想或自由手填临时文本）、货主标识、入库库房、单据状态、关联正式入库单号、备注。  
2. **货品与堆放明细（双层嵌套结构）**  
   - **一级（货品规格）**：入库货品（SKU）、大类/品类/规格（SKU 反填）、计量参数（申报数量）、其他收集信息（选填）、货品备注、现场照片（选填）、补充资料（选填）。  
   - **二级（堆放位置 · 默认折叠选填）**：入库库房、入库分区、**具体位置**（文本最多 20 字）、堆放数量、未堆放数量（弱提示，不阻断）。  
3. **统计汇总**：货品品类数、货品总数量（申报总量）、堆放总数量、未堆放总数量。  
4. **系统与操作记录**：单据版本号、登记人/时间、最后修改人/时间、转正人/时间、作废人/时间/原因；H5 流转时间轴摘要。  
5. **操作弹窗**：正式页切换说明（O01 · 无损带入）、作废确认（O02）、转为正式入库确认与引导（O03）。

## 三、统计汇总字段

| 字段名称 | 计算方式 | 展示位置 | 说明 |
| :--- | :--- | :--- | :--- |
| **货品品类数** | 按 SKU 行数（大类-品类-规格去重统计） | 底栏 / 详情汇总卡 | 整数，至少 1 种 |

## 四、转正预填字段对照（登记 → 正式制单页）

> **目标页**：PC 四类型 → PC 新增入库（R32）；**仓单**（含 PC 端操作转正）→ H5 `/m/inbound/initiate?sourceRegId={REG}`（P06）；H5 暂存任意类型 → 同上 H5 链路（P10）。

| 登记侧字段 | 正式入库字段 | 预填与转正校验规则 |
| :--- | :--- | :--- |
| 入库日期 / 仓库 / 库房 / 备注 | 同名字段 | 原样带入；正式页库房若为空须补选并满足 R06 |
| 入库类型 | 入库类型 | **原样带入**（普通/质押/抵押/监管服务/仓单，不再强制降级） |
| 关联单号 | 关联单号 | **原样带入**；若为空且非普通入库，正式页强制要求下拉选择系统有效单据；若为手填文本，正式页自动比对匹配，匹配不到强制要求重新选择有效单号（P06） |
| 货主/送货说明 | 货主类型 / 名称 / 标识 | 若暂存已关联档案货主，原样带入；若为临时文本，正式页强制要求重新搜索选择标准合作方档案；新货主走 R03 二元短信核验 |
| SKU 行：SKU、计量、收集项、备注、照片、补充资料 | 同结构 | **原样无损带入，正式页可继续补齐与编辑**；正式提交审核时校验 R16 至少 1 张现场照片 |
| 二级：库房、分区、具体位置、堆放数量 | 同结构 | 原样带入；**正式入库页强制自动展开**，且正式提交审核前未堆放数量必须为 0（R13） |
| 登记单号 | （服务端 `sourceRegId` 关联，非正式单字段） | 提交审核时携带；正式单主表**不展示**来源暂存单号；追溯以本单【关联正式入库单号】及操作记录为准（R32） |

## 六、操作弹窗字段（O01 / O02）

### 6.1 正式入库页切换登记说明弹窗 (O01)
* **弹窗提示**：告知用户暂存单用于现场到货快速备忘，不进审批、不写在库物理库存、免发短信；
* **无损复制声明**：明确提示已录入的入库类型、关联单号（若已填）、货品 SKU、申报数量、库位、照片及补充资料将**原样无损复制带入**暂存单；
* **按钮动作**：【取消（留在正式页）】、【前往空白登记页】、【带入并前往登记页（推荐）】。

### 6.2 作废确认弹窗 (O02)
* **弹窗要素**：作废原因输入框（必填，最多 200 字）；
* **按钮动作**：【取消】、【确认作废】。

### 6.3 转为正式入库确认与引导弹窗 (O03)
* **触发时机**：处于【待补全】状态下，用户在列表操作列或详情页底栏点击【转为正式入库】时唤起；
* **弹窗提示**：
  1. 提示目标登记单号 `REG-yyyyMMdd-00001`；
  2. 声明当前登记的入库类型、关联单号（若已填）、SKU、数量、库位与照片将无损完整预填至正式制单页；**若为仓单且当前为 PC 端**，须额外提示「仓单正式入库须前往移动端入库发起」；
  3. 提醒转正前置风控要求：若货主为临时待核须重选标准档案货主（新货主须二元短信核验）、未分配库位将在正式页强制展开并清零（R13）、至少 1 张现场照片（R16）、手填关联单号须匹配系统有效单据（P06）；
  4. 声明结案时机：只有在正式制单页点击【提交审核】成功后，当前暂存单才会被回写为【已转正式】；中途取消不产生废单；
* **按钮动作**：【取消】、【确认并前往正式页 (推荐)】（PC 仓单场景按钮文案可为「前往移动端入库发起」）。

## 七、转正与结构实现口径（研发建议）

| 主题 | 建议口径 | 依据 |
| :--- | :--- | :--- |
| **主表库房为空 + 二级已分垛** | 转正打开正式页时：若主表【入库库房】为空但二级行已有库房，提交前须将二级涉及库房 **并集回写** 入主表多选库房，并执行 R06 同属性校验；禁止仅存在于二级而主表长期为空提交 | R12、R06 |
| **仅二级库房、主表未选** | 暂存允许保存（P04）；转正预填时自动汇总二级库房写入主表候选，用户可删改 | P04、P06 |
| **货主一体化 → R02 拆分** | 暂存【档案货主】转正时映射货主类型/名称/标识；**临时待核**强制清空并重新检索 R02 主体；个人档案须带身份证号条件字段 | P03、R02 |
| **sourceRegId 生命周期** | 仅制单会话与提交 API 携带；**不入**正式单列表/详情字段；服务端保留 REG↔19 位单号关系供 P10 回退 | R32、P10 |
| **PC 仓单转正** | 不打开 PC 新增页；O03 仅展示「请在手机端操作」+ H5  deep link（`/m/inbound/initiate?sourceRegId=`） | P06、R04a |
| **已转正式 + 正式驳回** | 监听正式单终态未通过/已撤销 → 登记单 P10 回退【待补全】，清空关联正式单号展示，操作记录保留失败单号 | P10 |
