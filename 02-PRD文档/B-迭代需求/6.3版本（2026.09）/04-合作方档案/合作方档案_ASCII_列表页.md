> **对齐字段清单 第一章 / 第八章**：
> 1. **复合主列展示**：「主体名称/身份标识」采用双行合并呈现。首行主体名称为系统高亮超链接，支持下钻直达详情页；第二行展示脱敏公民身份证号（隐藏中间 8 位）或 18 位统一社会信用代码；
> 2. **业务角色聚合列**：多角色以彩色标签横向并列，格式为 `[角色类型·角色状态]`。绿色代表正常、蓝色代表待补全、紫色代表待生效、橙色代表冻结、灰色代表失效；
> 3. **主体状态徽章**：`🟢 正常`（绿）、`🟠 冻结`（橙）。本期不提供注销，状态变更由操作列独立动作及二次弹窗驱动（遵循【状态变更按钮驱动规则】(PA-R08)）；
> 4. **行操作差异化显隐**：冻结主体隐藏【追加角色】，展示【解冻】；正常主体展示【冻结】；本期全流程不提供注销操作（遵循【合作方档案操作权限矩阵】(PA-P02) 与【列表多级加权排序规则】(PA-R11) 冻结沉底排序）；
> 5. **联系手机核验（方案 C · 列表侧）**：「联系手机」列第一行脱敏号码、第二行 🛡️ **已验证 / 未验证** 徽章；**不提供**行内【验证】按钮——主动补验入口仅在 [详情页](./合作方档案_ASCII_详情页.md) 页头【验证联系手机】（PA-P02）；金融入库被动补验见 [入库记录新增页 ASCII](../10-仓储管理-入库记录/入库记录_ASCII_新增页.md) 与 **PA-R04b / R03**。

## 布局说明

**顶部导航（Header）**：Logo、全局业务板块切换（当前高亮「合作方管理」）、操作员个人中心。

**左侧菜单（Sidebar）**：二级菜单树；当前选中「合作方管理 → 合作方档案」。

**主内容区（Main Content）**：

- **页头区**：主标题「合作方档案」+ 业务定位副标题说明。
- **筛选区（Card 容器）**：
  - **右上角工具条**：`[收起筛选/展开筛选]` · `[ 重置 ]` · `[ 查询 ]`（主题黄主按钮） · `[ + 新增合作方 ]`（带权限保护，跳转至新增页）；
  - **默认展示行（lg 四列栅格，对齐 PC 列表筛选规范）**：
    - 主体名称/身份标识：单行文本输入框，支持主体全称/真实姓名或身份证号/统一社会信用代码前缀/后缀模糊 OR 检索；
    - 主体类型：下拉单选（全部主体类型 / 个人 / 企业）；
    - 业务角色：下拉单选（全部业务角色 / 货主 / 提货经办人 / 接收方 / 资金方），筛选包含该角色的主体；
    - 主体状态：下拉单选（全部主体状态 / 正常 / 冻结）；
  - **展开折叠行（四列栅格）**：
    - 角色状态：下拉单选（全部角色状态 / 待补全 / 待生效 / 正常 / 冻结 / 失效）；
    - 创建来源：下拉单选（全部创建来源 / 人工建档 / C端认证 / 单据沉淀）；
    - **联系手机核验状态**：下拉单选（全部核验状态 / 已验证 / 未验证）；
    - 联系手机：单行文本输入框，11 位大陆手机号精确匹配；
    - 创建时间范围：起止日期选择（原型以 date 控件表达区间；线上一致精确到秒）；
  - 筛选交互：支持回车快捷查询；重置清空所有条件恢复默认第 1 页。
- **数据表格区**：
  - 列定义：`序号`（首列固定居左）、`主体名称/身份标识`、`主体类型`、`主体状态`、`联系手机`（号码 + 核验徽章双行）、`业务角色`、`创建人`（双行含创建时间，对齐入库「制单人」列）、`操作`（末列 sticky；2×2 / 3+2 栅格，见 **TableRowActionPanel** 规则）；
  - 默认多级加权排序：第一优先级主体状态加权（`正常` 排在前面，`冻结` 沉底排在后面）；第二优先级按在系统中首次建档的创建日期（`create_date`）倒序；第三优先级按建档时间戳（`create_time`）绝对倒序；单据静默沉淀的简易待补全主体作为正常主体按其建档日期正常排位（方案 A；遵循【列表多级加权排序规则】(PA-R11)）；序号按当前页动态计算；
  - 空值显示：严禁出现 `null`、`undefined` 或空白，无操作或数据为空统一显示 `——`。
- **分页组件**：默认 10 条/页，支持 10/20/50 条切换及页码跳转。
