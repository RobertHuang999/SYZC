> **对齐字段清单 第一章 / 第八章**：
> 1. **复合主列展示**：「主体名称/身份标识」采用双行合并呈现。首行主体名称为系统高亮超链接，支持下钻直达详情页；第二行展示脱敏公民身份证号（隐藏中间 8 位）或 18 位统一社会信用代码；
> 2. **其他合作档案列（条件列）**：仅展示经 **追加合作方档案角色** 关联的 **其他子菜单** 名称标签（可点击跳转）；无关联时本列隐藏或单元格 `——`；**不再**展示 `[货主·正常]` 等与当前菜单重复的标签；
> 3. **主体状态徽章**：`🟢 正常`（绿）、`🟠 冻结`（橙）。本期不提供注销，状态变更由操作列独立动作及二次弹窗驱动（遵循【状态变更按钮驱动规则】(PA-R08)）；
> 4. **行操作（四菜单一致 · 方案 A）**：固定位次 **详情 → 验证（未验证且可补验时，无则不占格）→ 编辑/补全资料 → 追加 → 冻结/解冻**；操作列 **每行最多 3 钮** 换行排列；冻结态无追加；
> 5. **联系手机核验（方案 C · 列表侧）**：「联系手机」列脱敏号码 + 🛡️ **已验证 / 未验证** 徽章；主动补验：**列表【验证】** 与 [详情页](./合作方档案_ASCII_详情页.md) 页头【验证联系手机】（**PA-P02**）；金融入库被动补验见入库新增页与 **PA-R04b**。
> 6. **待补全派生展示**：出库沉淀等场景必填项未齐时，`主体状态` 列并列 🔵 **待补全** 辅助徽章（**非**独立字段），与 🟢正常 并存；四菜单 **无**「资料完备状态」列/筛。

## archiveMenu · 四子菜单与旧路由

| 项 | 说明 |
| :--- | :--- |
| **组件复用** | 列表 / 新增 / 详情 **同一套页面**；路由或上下文注入 `archiveMenu`（研发枚举示例 `OWNER \| PICKUP_PERSON \| FUNDER \| SERVICE_PROVIDER`） |
| **PC 侧栏** | **用户中心** → 分组 **合作方档案**（仅标题）→ 四个并列菜单：**货主信息 / 提货人信息 / 资金方信息 / 服务方信息** |
| **列表数据域** | API 只返回 **当前 archiveMenu** 主档；**不存在**「合作方档案总列表」 |
| **右上角按钮** | 文案随菜单变化，如「+ 新增货主」「+ 新增提货人」 |
| **废止旧入口** | ~~用户中心 → 合作方管理 → 合作方档案~~ 单页总列表（`/用户中心/合作方管理/合作方档案`）；书签/外链须改指向四子菜单之一或做只读提示跳转 |

线框示例默认 **货主信息**；切换至提货人 / 资金方 / 服务方时：侧栏高亮项、页标题、新增按钮文案、隐式角色与 [04-x 子菜单字段清单](./README.md) 必填差异同步变化，壳层与表格列 **不变**。

## 布局说明

**顶部导航（Header）**：Logo、全局业务板块切换（当前高亮「用户中心」）、操作员个人中心。

**左侧菜单（Sidebar）**：**用户中心** 模块下展示 **合作方档案** 分组及其下 **四个子菜单**；当前示例选中 **货主信息**（**不提供**可点的「合作方档案」聚合页）。

**主内容区（Main Content）**：

- **页头区**：主标题为当前子菜单名（如「货主信息」）+ 一行说明（隐式角色与数据域）。
- **筛选区（Card 容器）**：
  - **右上角工具条**：`[收起筛选/展开筛选]` · `[ 重置 ]` · `[ 查询 ]`（主题黄主按钮） · `[ + 新增{子菜单简称} ]`（带权限保护，跳转至带 `archiveMenu` 的新增页）；
  - **默认展示行（lg 四列栅格，对齐 PC 列表筛选规范）**：
    - 主体名称/身份标识：单行文本输入框，支持主体全称/真实姓名或身份证号/统一社会信用代码前缀/后缀模糊 OR 检索；
    - 主体类型：下拉单选（全部主体类型 / 个人 / 企业）；**资金方信息 / 服务方信息** 菜单列表侧个人数据为空态为主；
    - 主体状态：下拉单选（全部主体状态 / 正常 / 冻结；**不含**派生「待补全」）；
    - 资料完备：下拉单选（全部资料完备 / 待补全 / 完整；与列表「待补全」徽章同判定）；
  - **无「业务角色」筛选项**（由当前子菜单 **隐式角色** 决定数据域，遵循 **【合作方子菜单分视图与隐式角色规则】(PA-R12)**）；
  - **展开折叠行（四列栅格，已彻底废止概念冲突的多余「角色状态」筛选）**：
    - **不提供创建来源筛选**（C端注册 / 人工建档 仅在详情【基础档案】第 2 行只读展示；货主两值、其余三菜单仅人工建档）；
    - **不提供营业执照 OCR**（**【企业营业执照 OCR 识别规则】(PA-R13)** 仅新增/编辑表单）；
    - **联系手机核验状态**：下拉单选（全部核验状态 / 已验证 / 未验证）；
    - 联系手机：单行文本输入框，11 位大陆手机号精确匹配；
    - 创建时间范围：起止日期选择（原型以 date 控件表达区间；线上一致精确到秒）；
  - 筛选交互：支持回车快捷查询；重置清空所有条件恢复默认第 1 页。
- **数据表格区**：
  - 列定义：`序号`（首列固定居左）、`主体名称/身份标识`、`主体类型`、`主体状态`（待补全时在徽章旁 **派生**「待补全」标签，**非**独立列）、`联系手机`（号码 + 核验徽章双行）、**有关联时** 条件列 `其他合作档案`、`创建人`（双行含创建时间，对齐入库「制单人」列）、`操作`（末列 sticky；含 **补全资料** / **追加合作方档案** / 冻结解冻，见 **TableRowActionPanel**）；**四子菜单列一致**；
  - 默认多级加权排序：第一优先级主体状态加权（`正常` 排在前面，`冻结` 沉底排在后面）；第二优先级按在系统中首次建档的创建日期（`create_date`）倒序；第三优先级按建档时间戳（`create_time`）绝对倒序；单据静默沉淀的简易待补全主体作为正常主体按其建档日期正常排位（方案 A；遵循【列表多级加权排序规则】(PA-R11)）；序号按当前页动态计算；
  - 空值显示：严禁出现 `null`、`undefined` 或空白，无操作或数据为空统一显示 `——`。
- **分页组件**：默认 10 条/页，支持 10/20/50 条切换及页码跳转。

## 核心交互弹窗线框

### 1.0 【冻结主体】前置强校验阻断提示弹窗（遵循【分菜单主体冻结与在途在库前置校验规则】(PA-R02)）

> **触发条件**：操作人员在列表行操作点击【冻结】时，系统前置校验该主体在租户内的资产与在途单据。若货主名下仍有在库/在押货物、提货人名下有待提货单据、资金方/服务方名下有进行中/在押中单据，则强阻断拦截并弹出本提示框，禁止进入原因录入与提交步骤。

```text
+--------------------------------------------------------------------+
|  (🚫) 无法冻结该货主主体                                        [X] |
|       主体名称：赵磊（货主信息 · PA-202609001）                     |
+--------------------------------------------------------------------+
|  +-- 阻断说明（单行产品文案） -----------------------------------+ |
|  | (i) 该货主名下仍有在库或在押货物，无法执行冻结。请先办理货物   | |
|  |     出库转让或解除质押，确保名下库存清零后再行冻结。           | |
|  +---------------------------------------------------------------+ |
+--------------------------------------------------------------------+
```

> **上线 UI 约束**：阻断弹窗**仅**展示标题、主体名称行与上表黄色说明区；**不**展示关联单据明细列表、处置建议段落、规则编号对照框；单据溯源在仓储/融资模块查询。

### 3.1 行追加 · PA-R03a 链路（列表行【追加】= 详情页头【追加合作方档案】）

```text
  行操作 / 详情页头 【追加合作方档案】
            │
            ▼
  弹窗 3（多选）──► 【继续】──► 预检 assemblePlan（只读，不写库）
            │                         │
            │              任一阻断 ──► 弹窗 A「追加未成功」
            │                         │
            └──────── 全过 ──► 弹窗 B「确认一并追加合作方档案」
                                      │
                        取消 ◄────────┤
                        确认 ──► 单事务 compositeAppend
                                      │
                        失败 ──► 弹窗 A（整单回滚，成功项清单为空）
                        成功 ──► 弹窗 C「追加成功」（分项）+ 刷新列表/详情 Tab2
```
