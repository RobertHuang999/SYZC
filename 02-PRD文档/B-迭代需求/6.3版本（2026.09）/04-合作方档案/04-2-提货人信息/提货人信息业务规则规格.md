## 二、核心业务规则

#### 【提货人信息库内匹配规则】(PP-R01)

* **【匹配范围】**：租户 + **提货人信息** 档案域；跨菜单同证号允许独立主档（**PA-R03**）；
* **【三角校验】**：**身份证号 + 姓名 + 手机号** 与本域库内记录须一致；冲突 Toast 文案区分「提货人/经办人」；
* **【不因货主域阻断】**：货主信息子菜单已有同证号主档，**仍可在本菜单新建** 另一条主档；
* **【证件地址】**：本菜单 **选填**；**不**执行货主 **P01**；缺址 **不**派生待补全；
* **【出库快捷建档】**：落库 **提货人信息** 主档、主体状态 **正常**；本菜单 **04-2 必填**（个人/企业见字段清单）未齐则 **派生待补全**（**非**独立状态字段，**不含**证件地址）；创建来源「出库快捷建档」；**禁止**失焦静默建档（**PA-R04a**）；
* **【补全资料】**（**方案 A**）：派生 **待补全** 时列表/详情 **编辑位** 文案为 **【补全资料】**（同编辑路由），录入完整必填项且 **PP-R01** 通过后徽章消失；
* **【出库引用】**：引用 **提货人信息** 主档时须必填项齐备且 **主体未冻结**（**PA-R01** + **PP-R01**）；
* **【短信】**：页面组件与货主共用；**不参与** 货主金融 **PA-R04b** 强制链路；
* **【冻结前置待提货单据强校验】**：操作提货人主体冻结时，执行公共 **【分菜单主体冻结与在途在库前置校验规则】(PA-R02)**；若该提货人名下存在处于待提货状态的出库单据（出库单/提货单状态为 `待提货`），强阻断禁止冻结，提示「该提货人名下存在待提货的出库单据，无法执行冻结。请等待现场提货完成或作废单据后再行冻结。」

## 三、验收用例

| 编号 | 场景 | 预期 |
| :--- | :--- | :--- |
| **PP-V01** | 本域三角不一致 | Toast 阻断 |
| **PP-V02** | 货主域已有同证号 | 本菜单仍可新建独立主档 |
| **PP-V03** | 出库快捷建档 | 提货人信息域 + **派生待补全** + 行内/详情 **【补全资料】** |
| **PP-V04** | 待补全办理出库 | 阻断并引导 **【补全资料】** |
| **PP-V05** | 名下有待提货单据时冻结 | 强阻断，弹出提示框列出待提货单号，禁止进入冻结确认（PA-R02） |
