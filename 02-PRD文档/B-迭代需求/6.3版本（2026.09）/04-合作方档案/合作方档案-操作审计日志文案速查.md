## 0. 三十秒看懂

```text
一条审计日志
├─ 第一行（摘要）：时间 · 操作人 · IP · 【徽章 actionName】
└─ 第二行（正文）：detail = 子句1 ； 子句2 ； …
```

**研发两步走：** ① 按下面 **§1 场景表** 定徽章 + 用哪些编号 → ② 到 **§2 子句表** 填 `{占位}` 拼成 detail。

**连接符**：多条子句只用中文分号 **`；`**。

## 1. 场景对照表（先查这张）

| 业务场景 | 徽章 actionName | detail 怎么写 |
| :--- | :--- | :--- |
| 管理端新建，未做短信 | 人工建档 | 整段 **V03** |
| 管理端新建，保存并验证 | 联系手机核验 | 整段 **V02** |
| 入库/出库/监管页快捷建档 | 入库快捷建档 等 | **E01**（见 §2 快捷句） |
| C 端实名回调 | C端实名认证建档 | 固定句：C端客户完成…实名认证，系统自动沉淀… |
| 编辑且有字段变更 | 编辑合作方档案 | **F02/F03/F04/F01** 按需多条 **；** 连接；都没有则 **F06** |
| 待补全 → 必填齐备 | 完善档案资料 | 主用 **F05**，另有变更再 **；** 加 F 系列 |
| 详情/制单只补验手机 | 联系手机核验 | 整段 **V01** |
| 追加合作方档案 | 追加合作方档案角色 | **X01**（多菜单就写多条 **；** 连接） |
| 冻结 / 解冻（列表或详情） | 冻结主体 / 解冻主体 | **R01** / **R02** |
| 出库入库等终审沉淀档案 | 单据静默沉淀 | **D01** |
| 终审固化快照 | 业务快照固化 | **D02** |
| 企业 B 端确认覆盖资料 | 确认更新企业资料 | **E02** |
| 资金方名称确认 | 确认更新资金方名称 | **E03** |

**不写日志**：没保存成功、没字段变更、用户取消（PA-R07 · 无动不写）。

## 2. 子句编号表（再查这张填 detail）

### 编辑 · F 系列

| 编号 | 模板 |
| :--- | :--- |
| **F01** | 变更{字段中文名}为【{新}】（原：{旧}） |
| **F02** | 变更业务联系电话为【{新手机号}】（原：{旧手机号}，短信二元核验通过） |
| **F03** | 变更证件登记地址为【{新完整地址}】 |
| **F04** | 变更证件登记地址为【{新完整地址}】，改址原因：{原因} |
| **F05** | 补全证件登记地址【{完整地址}】，主档必填项已齐备 |
| **F06** | 更新合作方档案基础资料 |

### 状态 · R 系列

| 编号 | 模板 |
| :--- | :--- |
| **R01** | 执行主体冻结管控，原因：{原因} |
| **R02** | 解冻恢复主体正常状态，说明：{说明} |

### 系统 · D 系列

| 编号 | 模板 |
| :--- | :--- |
| **D01** | {单据类型} {单号} 沉淀{对象}简易信息，{摘要} |
| **D02** | {单据类型} {单号} 审批通过，固化{角色}主体快照 (名称: {名称} / 证件: {证件号} / 地址: {地址摘要}) |

**D01 摘要常写**：联系手机已补齐 / 派生「待补全」，行操作引导「补全资料」 / 必填项已齐备，行操作展示「编辑」

### 核验 · 建档 · V 系列

| 编号 | 模板 |
| :--- | :--- |
| **V01** | 详情主动补验：短信二元身份确认通过，联系手机已验证（核心字段已锁定） |
| **V02** | 人工建档并短信验证成功（联系手机已验证，核心字段已锁定） |
| **V03** | 人工建档保存成功（联系手机未验证，金融场景提交前须补验） |

### 其他

| 编号 | 模板 |
| :--- | :--- |
| **X01** | 在【{目标菜单名}】创建独立主档或关联已有主档 |
| **E01** | {快捷建档场景固定句}；可选后缀「；保存并验证通过」 |
| **E02** | 确认更新企业资料：企业名称【{新}】（原：{旧}）；联系电话【{新}】（原：{旧}） |
| **E03** | 确认更新资金方名称：【{新}】（原：{旧}） |

**E01 固定句**：入库制单页快捷建档（默认联系手机未验证）｜出库制单页【快速添加经办人】建档｜监管办理页快捷建档（资金方/服务方信息域 · 企业主体）
