## 0. 三十秒看懂

```text
一条日志 = 第一行（时间·操作人·【动作】）+ 第二行（说明）
动作只有四类：【创建】【修改】【冻结】【解冻】   （6.3 无删档）
说明 = 组合句前缀 + 可选变更子句（多条用 ； 连接）
```

**两步：** ① 定 **动作**（下表）→ ② 选 **组合句**（§2）填 `{占位}`。

## 1. 动作对照表（先查这张）

| 动作 | 徽章 actionName（固定四选一） | 何时记 |
| :--- | :--- | :--- |
| **增** | `创建合作方档案` | 本菜单 **首次落库**：管理端新建、快捷建档、**C端注册**回调、**业务单据带出创建**（只记「创建了档案」，不写单据审批/快照） |
| **改** | `修改合作方档案` | 编辑/补全/追加其他菜单档案/确认更新企业资料等，且 **字段真有变更** 并保存成功 |
| **冻** | `冻结主体` | 列表或详情冻结成功，已录原因 |
| **解** | `解冻主体` | 解冻审批通过并执行成功，已录说明 |

**不记：** 无变更保存、校验失败、取消；**不记在本 Tab：** 单据「快照固化」类（主档未改）。

**特殊：** 仅短信核验、联系手机变已验证但无其他字段变更 → 仍用 **`修改合作方档案`**，说明用 **M02**。

**改址原因弹窗（与 M05 绑定）：** 仅 **货主信息 · 个人 · 编辑 · 原已保存证件地址 · 地址字段有变更** 时，保存前弹出改址确认并 **必填改址原因**；待补全首次补地址走 **M03**，不弹窗；企业/其他菜单改地址走 **M04**，不弹窗。工程判定：`shared/partner-archives/partner-change-address-pa-r06a.ts`。

## 2. 组合句（detail 模板）

### 2.1 增 · 创建（前缀任选一条）

| 编号 | 模板 |
| :--- | :--- |
| **C01** | 管理端人工创建：{未验证或已验证说明} |
| **C02** | 由{业务入口}快捷创建：{说明} |
| **C03** | C端注册（实名认证通过），系统自动创建：{说明} |
| **C04** | 由{单据类型} {单号} 业务带出创建：{说明} |

**占位说明**

- `{未验证或已验证说明}`：`联系手机未验证` / `联系手机已验证并完成短信核验`
- `{业务入口}`：`入库制单` / `出库制单` / `监管办理` 等
- `{说明}`：一句补全，如 `提货人必填项已齐` / `存在待补全项，需补全资料`

**成文示例：** `由出库记录 CK-20260928-011 业务带出创建：联系手机已补齐`

---

### 2.2 改 · 修改（前缀 + 变更子句）

**前缀（固定）：** `修改合作方档案：`

**变更子句（有多项就 `；` 拼接）：**

| 编号 | 子句模板 |
| :--- | :--- |
| **M01** | 变更{字段中文名}为【{新}】（原：{旧}） |
| **M02** | 联系手机完成短信核验，状态变为已验证 |
| **M03** | 补全证件登记地址【{地址}】，必填项已齐备（**待补全**首次补齐，**无**改址原因） |
| **M04** | 变更证件登记地址为【{新地址}】（原：{旧地址}）（一般编辑改址，**无**改址原因） |
| **M05** | 变更证件登记地址为【{新地址}】，改址原因：{原因}（**仅当**编辑页已弹出改址确认并**实际提交** `{原因}`；未弹窗/未填原因 **禁止**用 M05，改址写 **M04** 或 **M03**） |
| **M06** | 在【{目标菜单}】追加独立主档或关联已有主档 |
| **M07** | 确认更新企业资料：名称【{新}】（原：{旧}）；电话【{新}】（原：{旧}） |

**兜底：** 仅有保存但无法枚举字段时 → `修改合作方档案：更新基础资料`

**成文示例：** `修改合作方档案：变更业务联系电话为【139…】（原：138…，短信二元核验通过）`
