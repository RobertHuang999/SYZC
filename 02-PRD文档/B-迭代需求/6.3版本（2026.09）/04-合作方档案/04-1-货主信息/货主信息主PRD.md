## 1. 范围

| 包含 | 不包含 |
| :--- | :--- |
| **货主信息** 子菜单列表/新增/详情（组件与提货人、资金方共用） | 提货人/资金方库内规则（见 **04-2 / 04-3**） |
| 个人/企业货主建档、P01/P02、**WH-R01** | 公共状态机全文（见公共规则） |
| 入库 **R03** 快捷建档、转让挂接货主、**PA-R04b** 金融补验 | 关联业务单据 Tab（6.3 默认无） |

## 2. 菜单与权限

- **路径**：`用户中心 → 合作方档案 → 货主信息`（PC 侧栏；H5 四入口按钮之一）；
- **RBAC**：独立菜单权限位；
- **路由**：`archiveMenu=货主信息`。

## 3. 场景摘要

| 场景 | 说明 |
| :--- | :--- |
| 人工建档 | 隐式货主；免短信保存默认未验证；金融提交前补验 |
| 入库快捷建档 | 制单页【+ 快速添加货主】，域=货主信息 |
| 转让 | 申请阶段挂货主；驳回仍保留主档 |
| 跨菜单 | 同证号可在提货人信息另建主档 |
