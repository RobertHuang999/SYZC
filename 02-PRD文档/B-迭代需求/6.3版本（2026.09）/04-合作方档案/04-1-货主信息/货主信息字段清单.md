## 一、本菜单必填与控件差异（相对公共清单）

| 字段名称 | 本菜单必填 | 说明 |
| :--- | :---: | :--- |
| **主体类型** | 是 | 个人 / 企业可选 |
| **主体名称** | 是 | 个人姓名 / 企业全称 |
| **身份标识** | 是 | 身份证 / 信用代码；企业可 **OCR**（PA-R13） |
| **手机号 / 联系电话** | 是 | 11 位；列表展示核验徽章 |
| **经办人姓名** | 企业必填 | 个人不展示 |
| **证件地址** | 是（P01） | 多行；改址 **PA-R06a** |
| **追加合作方档案角色** | 选填 | 勾选其他子菜单；确认后在目标域 **创建/关联主档**（PA-R03 / PA-R12） |

## 二、列表与筛选（本菜单）

- 数据范围：**货主信息** 域主档 only；
- 筛选：主体名称/证号、主体类型、主体状态、企业 **OCR**、展开含核验状态/手机/创建时间等；
- 列：公共 8.1 默认 7 列；有关联时 **其他合作档案** 条件列；
- 行操作：**方案 A** 固定位次（详情 → 编辑/补全资料 → 追加合作方档案 → 冻结/解冻），与另外三菜单一致；
- **联系手机** 必填；**P01 开启** 时缺证件地址 **派生待补全**（仅本菜单）。

## 三、表单顺序（本菜单）

个人：类型 → 姓名 → 手机 → 身份证号 → 证件地址 → 追加合作方档案角色（选填）。  
企业：类型 → 企业全称（OCR）→ 经办人 → 联系电话 → 信用代码（OCR）→ 证件地址 → 追加合作方档案角色。
