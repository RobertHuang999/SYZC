## 二、核心业务规则

#### 【货主信息库内匹配与准入规则】(WH-R01)

* **【匹配范围】**：租户 + **货主信息** 档案域；遵循公共 **【主体识别与库内匹配总则】(PA-R03)** 跨菜单条款；
* **【create_channel】**：`B_ADMIN` / `C_CLIENT`；**B 端**企业名称或联系电话与库内不一致 → 二次确认（脱敏原值）后更新 + **PA-R07** 审计；**C 端** 不一致 → 阻断；
* **【个人货主】**：
  1. 按身份证号查本域库内主体；
  2. 命中且姓名+手机号完全一致 → 二次确认，不新建主档；
  3. 命中但姓名或手机号不一致 → Toast「货主身份信息已被绑定，无法重复使用」；
  4. 未命中证号：查本域手机号；已绑其他证号 → Toast「货主手机号已被绑定，无法重复使用」；
  5. 否则新建货主信息域主档并挂货主角色；
* **【企业货主】**：
  1. 按统一社会信用代码查本域；
  2. 命中且名称+联系电话完全一致 → 二次确认；
  3. 命中且不一致 → B/C 分支见上；
  4. 未命中 → 新建企业主档；
  5. **经办人姓名选填**：保存与待补全判定不要求企业经办人姓名；与 **提货人信息** 企业经办人必填区分（见 04-2 字段清单）；
* **【P01 证件地址必填】**：本菜单新增/编辑/补全/改址保存前，个人与企业 **证件地址非空**（公共 **PA-R04**）；
* **【P02 地址唯一】**：货主建档、改址、C 端落货主、**入库快捷建档**（有地址时）、**转让**挂接/生效时执行 **P02** 分池；作业单据 **不因 P01 缺址阻断**；
* **【企业 OCR】**：公共 **PA-R13**；回填后仍走本规则 WH-R01；
* **【入库快捷建档】**：档案归属 = 货主信息；规则见公共 **PA-R04a** 入库快捷建档条款；
* **【冻结前置货物强校验】**：操作货主主体冻结时，执行公共 **【分菜单主体冻结与在途在库前置校验规则】(PA-R02)**；若该货主在系统中存在在库货物或在押存量（包含可用库存、生效中/有效在押仓单），强阻断禁止冻结，提示「该货主名下仍有在库或在押货物，无法执行冻结。请先办理货物出库转让或解除质押，确保名下库存清零后再行冻结。」

## 三、验收用例

| 编号 | 场景 | 预期 |
| :--- | :--- | :--- |
| **WH-V01** | 本域证号命中信息不一致 | Toast「货主身份信息已被绑定…」 |
| **WH-V02** | 本域手机号占用 | Toast「货主手机号已被绑定…」 |
| **WH-V03** | 证号+信息一致 | 二次确认，不新建第二条主档 |
| **WH-V04** | 跨菜单同证号 | 货主信息已存在时，可在提货人信息再建独立主档（PA-R03） |
| **WH-V05** | 转让驳回 | 货主主档保留（PA-V07） |
| **WH-V06** | 质押入库未验证 | 提交前 **PA-R04b** 补验 |
| **WH-V07** | 名下有在库货物时冻结 | 强阻断，弹出提示框禁止进入冻结确认（PA-R02） |
