```text
| +----------------------------------------------------------------------------------------------------------+ |

| |  2   | 提货经办人   | 🔵 待补全| 出库单沉淀   | OUT20260918-001 [🔗]  | ——                  | ——       | 补全 移除 | |

```

> **业务角色子表行操作规则 (PA-P02 / PA-R05)**：
> - `待补全`：突出展示黄色主操作【补全资料】（弹窗补充必填地址过准入）、【移除角色】（仅非货主角色）；
> - `待生效`：展示【移除角色】（未终审单据允许撤回挂接）；
> - `正常`：展示【冻结角色】（风控隔离该角色）；【移除角色】（仅限非货主角色，**货主角色本期不可移除/不可注销**；须过存量无进行中业务强校验）；
> - `冻结`：展示【解冻角色】（审批通过后恢复该角色发单资格）；【移除角色】（仅限非货主角色）；
> - `失效`：终态只读，所有操作列渲染占位符 `——`。

## 5. 嵌入式场景：「查看货主」跳转

> **业务依据**：[主PRD 6.4 节](./合作方档案主PRD.md) 及 [字段清单 5.1 节](./合作方档案字段清单.md)。入库记录、客户入库预约等页面，选中已建档货主后展示【查看货主】链接。

- 点击后在**新标签页**打开 `/用户中心/合作方管理/合作方档案/详情/:id`；
- 不使用居中弹窗，不使用右侧抽屉；
- 证件地址、核验状态、业务角色都在合作方详情里看；
- 主体待补全或缺证件地址时，使用详情页头黄色【去补全资料】进入编辑页（主 PRD 场景 5）。

## 6. DetailField 单字段结构规范（与系统组件一致）

本模块详情页全面遵循统一 `DetailField` 视觉原子组件规范：**上 Label 灰色（13px）、下 Value 深色正文（14px）纵向堆叠排布**，严禁 Label 与 Value 左右并列：

```text
┌──────────────────────────┐
│ 合作方主体标识           │  ← label: text-xs text-muted-foreground (灰色)
│ PS-001  [复制]           │  ← value: text-sm font-medium text-foreground (深色)
└──────────────────────────┘
```
