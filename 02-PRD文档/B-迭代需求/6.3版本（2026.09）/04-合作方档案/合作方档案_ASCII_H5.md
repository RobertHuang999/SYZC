# 合作方档案 — 移动端（H5）ASCII 线框

> **文档定位**：**衍生文档**——由 [公共三件套](./README.md) + 子菜单三件套派生的 H5 线框；**四子菜单共用页面组件**，`archiveMenu` 区分。变更须先更新 [公共主PRD](./合作方主数据-公共主PRD.md) 6.6 / [公共字段清单](./合作方主数据-公共字段清单.md) 8.8，再同步本文件与 `03-前端原型demo/B端H5`。  
> **版本**：V1.2 | **更新时间**：2026-10-20  
> **菜单入口**：`工作台 → 用户中心` → **四入口按钮**（货主信息 / 提货人信息 / 资金方信息 / 服务方信息）  
> **原型路由（示例）**：列表 `/m/workspace/user-center/partner-archives/owner` · 详情 `…/owner/:id` · 表单 `/m/partner-archives/form?archiveMenu=OWNER`  
> **基准实现**：`03-前端原型demo/B端H5/src/features/partner-archives`  
> **配套 PC 线框**：[列表页](./合作方档案_ASCII_列表页.md) · [新增编辑页](./合作方档案_ASCII_新增编辑页.md) · [详情页](./合作方档案_ASCII_详情页.md)

## 0. 用户中心 · 四入口（进入列表前）

```text
+--------------------------------------------------+
|  <    用户中心                                    |
+--------------------------------------------------+
|  … 其他用户中心能力 …                             |
|  +----------------+  +----------------+          |
|  |  货主信息   >  |  |  提货人信息 >  |          |
|  +----------------+  +----------------+          |
|  +----------------+  +----------------+          |
|  |  资金方信息 >  |  |  服务方信息 >  |          |
|  +----------------+  +----------------+          |
+--------------------------------------------------+
```

**说明**：**无**聚合「合作方档案」总列表；与 PC 四子菜单 RBAC 分别授权（**【合作方子菜单分视图与隐式角色规则】(PA-R12)**）。

| | 档案归属：货主信息                            | |

## 3. 新增/编辑页

```text
+--------------------------------------------------+
|  <    新增货主 / 编辑货主                         |
+--------------------------------------------------+
| ┌─ 主体身份 ─────────────────────────────────┐   |
| | 主体类型              个人            >    |   |
| | 主体名称              [输入]               |   |
| | 身份标识              [输入]  [识别营业执照]│   |
| | 手机号                [11位]               |   |
| └────────────────────────────────────────────┘   |
| ┌─ 证件登记地址 ─────────────────────────────┐   |
| | 省 / 市 / 区 / 详细地址 textarea           |   |
| | （货主/提货人菜单必填；资方/服务方可选填）    |   |
| └────────────────────────────────────────────┘   |
| ┌─ 追加合作方档案角色（选填）────────────────┐   |
| | 勾选其他子菜单；确认后跨菜单建主档/关联      |   |
| | 当前菜单身份由 archiveMenu 隐式派生          |   |
| └────────────────────────────────────────────┘   |
+--------------------------------------------------+
|    [ 保存并验证 ]    [ 保存并提交 ]               |
+--------------------------------------------------+
```

**交互要点**：标题随 `archiveMenu` 变化；新增双按钮对齐 PC；跨菜单同证号保存提醒同 PC **6.1a**；Dirty 离开二次确认。
