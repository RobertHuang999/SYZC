## 2. 详情页

```text
+--------------------------------------------------+
|  <    合作方详情                                  |
+--------------------------------------------------+
| [! 待补全提示条（条件展示）]                      |
+--------------------------------------------------+
| +----------------------------------------------+ |
| | 赵磊   [个人] 🟢正常 [待补全]                | |
| | 身份标识：320106… · 合作方主体标识：PA-xxx [复制] |
| +----------------------------------------------+ |
| | 基础档案 | 业务角色(2) | 关联客户账号 | 关联业务单据 | 操作审计日志 |
| +----------------------------------------------+ |
| |  （Tab 内容区：键值对 / 角色卡片 / 时间轴）   | |
| +----------------------------------------------+ |
+--------------------------------------------------+
| [验证联系手机] [去补全资料] [追加角色] [冻结主体] |
+--------------------------------------------------+
```

**交互要点**：顶部基础信息区 + Tab 分区对齐入库详情；主体级操作在底部固定条；角色行操作在「业务角色」Tab 卡片内。

## 3. 新增/编辑页

```text
+--------------------------------------------------+
|  <    新增合作方 / 编辑合作方                     |
+--------------------------------------------------+
| ┌─ 主体身份 ─────────────────────────────────┐   |
| | 主体类型              个人            >    |   |
| | 主体名称              [输入]               |   |
| | 身份标识              [输入]               |   |
| | 手机号                [11位]               |   |
| └────────────────────────────────────────────┘   |
| ┌─ 证件登记地址 ─────────────────────────────┐   |
| | 省 / 市 / 区 / 详细地址 textarea           |   |
| └────────────────────────────────────────────┘   |
| ┌─ 业务角色（首次挂接）（仅新增）────────────┐   |
| | (货主) (提货经办人) (接收方) (资金方) chips  |   |
| └────────────────────────────────────────────┘   |
+--------------------------------------------------+
|    [ 保存并验证 ]    [ 保存并提交 ]               |
+--------------------------------------------------+
```

**交互要点**：新增双按钮对齐 PC（保存并验证 → 场景 3 短信，取消不落库）；编辑改号/个人改址走核验 Sheet；详情【验证联系手机】同 PC；Dirty 离开二次确认。
