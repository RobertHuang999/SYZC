## 二、跨文档引用标准与唯一定义规范

### 1. 引用展开标准
- **字段与枚举**：严禁仅标注“主数据”“档案”等模糊词，须明确取值范围、展示值、提交字段、服务端校验及快照逻辑。
- **权限与数据范围**：写清菜单权限、操作权限、仓库/订单数据权限与跨域校验。
- **唯一定义来源**：下游引用内容为**场景摘要**，若与源文档产生冲突，以源模块 唯一定义规格为准并提交修订。

## 三、文档编写与维护约束

1. **结构先行**：所有主 PRD 与规格文档严格遵循 V3.0 范式（第 1~10 章结构 + 业务规则单一真实数据源 R/C/P + 字段清单引用）。
2. **闭环无悬空**：所有异常流程、前置依赖、后置影响必须闭环；未知或待定业务明确标注“待确认”，严禁猜测伪造。
