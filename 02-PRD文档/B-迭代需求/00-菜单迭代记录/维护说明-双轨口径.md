## 三、权限 CSV 怎么写

1. **线上仍在用的页面**：保持 `active`，路径仍是 `2.仓储/设备管理`、`5.风控/风险信息`、`8.配置管理/预警配置` 等。
2. **6.2 目标路径**：另起一组行，`所属模块=9.物联网IOT与预警`，`记录状态=6.2-target`，按钮/可见范围与线上行一致（或按 6.2 PRD 更新）。
3. **线上行加迁移提示**：在 `变更说明` 追加  
   `【6.2目标态】迁至物联网IOT与预警 → …`  
   便于 diff，**不**改变当前 `active` 语义。
4. **6.2 取消的菜单**：线上行暂保留 `active`；目标态不再单独建页；迭代记录标「取消/合流」。

## 四、上线切换清单（模板）

```text
□ 1. 生产环境菜单采集 → 更新 08-系统采集
□ 2. 基准 B端PC/00-菜单地图.md §一 改为新顶栏（含物联网IOT与预警）
□ 3. 功能与数据权限清单：6.2-target → active；旧路径 → cancelled 或删行
□ 4. 00-菜单模块映射、页面-基准文档映射 同步
□ 5. npm run generate:reference
□ 6. 6.2/00-PC菜单地图（目标态）归档或合并进基准版
```

上线后若还有小调整：只改基准版 + `active` 行；回写 6.2 迭代记录「上线后修订」表即可。
