# 审批中心 业务规则规格

> **文档定位**：审批中心**平台层**状态机、任务分发、通用审批动作、权限与审计的**唯一定义来源**。各业务子类型的申请单据、凭证及后置业务规则由 `05-子类型/` 下对应规格维护。
>
> **参考文档**：[审批中心字段清单](./03-审批中心字段清单.md)、[审批中心总索引](./审批中心总索引.md)、[通用审批处理字段清单](./04-操作字段清单/01通用审批处理字段清单.md)
>
> **版本**：V1.0 | 2026-08-28

---

## 一、能力定位

| 项目 | 内容 |
| :--- | :--- |
| **模块层级** | 全系统审批平台层 |
| **菜单/入口** | 审批中心 → 待处理 / 已处理 / 抄送我的 / 我的申请记录 |
| **核心职责** | 接收**已接入流程配置**的子类型申请；按配置快照生成审批任务与待办；执行通用审批动作；保存审批轨迹 |
| **职责边界** | **不**定义各子类型申请主表字段与后置业务；**不**承接未接入流程配置的独立其他审批（如开锁申请走「其他审批—开锁审批」） |

## 二、审批任务

> 平台管理的待办单元；与业务申请状态联动但不替代申请主状态。字段见 [审批中心字段清单](./03-审批中心字段清单.md)。

### 2.1 状态定义

| 状态名称 | 枚举值 | 业务含义 | 是否终态 |
| :--- | :--- | :--- | :---: |
| 待处理 | `PENDING` | 等待当前审批人处理 | 否 |
| 已通过 | `APPROVED` | 该节点审批通过 | **是** |
| 已驳回 | `REJECTED` | 该节点审批驳回 | **是** |
| 已关闭 | `CLOSED` | 因撤回/超时/他人已通过而关闭 | **是** |

### 2.2 通用审批方式规则

| 审批方式 | 枚举值 | 平台处理 | 申请结果（由子类型消费） |
| :--- | :--- | :--- | :--- |
| 任一人通过 | `ANY_ONE` | 各节点 eligible 人员同时收到待办；任意一人通过后关闭其余未处理任务 | 任意一人通过即完成本审批节点 |
| 按顺序审批 | `SEQUENTIAL` | 按节点顺序逐个激活；当前节点内任一人处理即可推进 | 所有顺序节点均通过后申请才进入已通过 |

### 2.3 通用审批动作规则

| 规则ID | 规则 |
| :--- | :--- |
| **R10** | 任务须为待处理且关联申请未进入终态 |
| **R11** | 审批人不能审批自己发起的申请；角色节点展开时，申请人若在该角色内，不得作为 eligible 处理人 |
| **R12** | 按顺序审批时，前序节点须已全部通过 |
| **R13** | 驳回原因必填（子类型可在操作字段清单中定义展示方式） |
| **R18** | 审批动作使用申请状态和任务状态条件更新，避免多人并发产生两个相反结果 |
| **R19** | 本期不配置备用审批人和自动转派 |

> 子类型专属规则（如开锁申请的凭证、事务关联）见各子类型业务规则规格。

## 三、平台权限

| 规则ID | 规则分类 | 具体规则定义 | 异常/无权限处理 |
| :--- | :--- | :--- | :--- |
| **P04** | 审批操作 | 须为当前待办指定审批人且账号启用 | 「无审批权限」 |
| **P05** | 数据隔离 | 仓管角色：`仓库 IN User.AssignedWarehouses`；管理员：租户全量 | 自动追加 SQL 过滤 |

> 子类型申请查看、凭证撤销等权限见各子类型规格（如开锁申请 P03、P06、P07）。

## 四、并发、幂等与审计

| 规则ID | 规则 |
| :--- | :--- |
| **A02** | 审批动作必须使用状态条件更新，两个审批人并发操作时只能有一个动作成功 |
| **A04** | 审批轨迹记录操作人、时间、业务键、任务前后状态和失败原因 |
