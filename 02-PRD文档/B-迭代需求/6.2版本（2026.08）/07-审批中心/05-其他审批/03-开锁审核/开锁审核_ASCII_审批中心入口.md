## 布局说明

| 区域 | 说明 |
| :--- | :--- |
| 页面定位 | 工作中心首页内的「审批中心」聚合页；**无**独立左侧菜单项 |
| 卡片区块 | 「其他审批」下与「政策资讯审核」同级；本期新增「开锁审核」卡片 |
| 角标 | 展示当前用户 eligible 且申请状态=待审批的条数；无待办时不展示或展示 0 |
| 预览表格 | 选中「开锁审核」卡片后，页内下方展示最近若干条（默认待审批优先，最多 5 条） |
| 预览列 | 设备名称、绑定仓库、申请人、事由、申请状态、提交时间；**不**展示申请单号 |
| 预览操作 | 待审批 →「查看详情」「去处理」；终态 → 仅「查看详情」 |
| 查看更多 | 跳转 [完整列表页](./开锁审核_ASCII_列表页.md)，保留默认视图=待审批 |
| 职责边界 | **不进**「业务管理审批」下的待处理/已处理；无接入流程配置 |
