## 2. 背景与目标

SYZC 6.2 门禁开锁审批链路中，审批人需要在独立入口集中处理挂锁/人脸门禁的临时开锁申请。该入口归类为审批中心首页「其他审批」区块，**不**接入系统「接入流程配置」，因此**不**进入 07 审批中心「待处理/已处理」。

**本期目标**：

- 提供双端（PC/H5）开锁审批列表与详情页；
- 支持审批人按数据权限查看待处理与已处理申请；
- 提供通过、驳回操作及审批意见录入；
- 申请详情只读展示设备/位置/事由等快照信息；**所有参与审批的人员均可查看审批记录及最终审批人信息**；
- 审批动作回写申请状态并触发凭证生成（后置业务见 07 子类型）。

## 4. 用户与权限

权限矩阵以 [00-全局契约与RBAC权限矩阵](../00-全局契约与RBAC权限矩阵.md) 为准：


| 规则ID | 场景     | 要求                                          |
| ---- | ------ | ------------------------------------------- |
| P04  | 审批操作   | 须为当前 eligible 审批人且账号启用                      |
| P05  | 列表数据隔离 | 仓管：`仓库 IN User.AssignedWarehouses`；管理员：租户全量 |
| P06  | 自审禁止   | 审批人不能审批自己发起的申请（R11）                         |


子类型额外权限（凭证查看等）见 [开锁申请业务规则规格](../03-业务审批/04-我的申请管理/04-开锁审批/开锁申请业务规则规格.md)。

## 5. 页面与交互



### 5.0 审批中心入口（PC）

**路径**：工作中心 → **审批中心**（首页）→ **其他审批** → **开锁审核** 卡片

| 项目 | 说明 |
| :--- | :--- |
| 挂载位置 | 审批中心首页「其他审批」区块，与「政策资讯审核」并列；见 [审批中心入口 ASCII](./开锁审核_ASCII_审批中心入口.md) |
| 页面形态 | 卡片 + 角标（待审批数）+ 页内预览表格；**非**左侧树菜单 |
| 预览表格 | 默认展示最近待审批记录（最多 5 条）；列与完整列表 §一 一致，不含申请单号 |
| 预览操作 | 待审批 →「查看详情」「去处理」；终态 → 仅「查看详情」 |
| 查看更多 | 跳转 §5.1 完整列表页，默认视图=待审批 |
| 职责边界 | **不进**「业务管理审批」待处理/已处理；无接入流程配置 |



### 5.1 列表页（完整页）

**PC 路径**：工作中心 → 审批中心 → 其他审批 → 开锁审核 → 查看更多

**H5 路径**：业务办理 → 其他审批 → 开锁审批（与 `03-前端原型demo/B端H5` 一致，无需调整）


| 区域   | 内容                                              |
| ---- | ----------------------------------------------- |
| 筛选区  | 申请单号、设备名称/编码、绑定仓库、申请人、事由、申请状态、提交时间范围            |
| 列表列  | 见 [01列表与详情展示字段清单](./操作字段清单/01列表与详情展示字段清单.md) §一 |
| 默认视图 | 待审批（当前用户为 eligible 且申请状态=待审批）                   |
| 行操作  | 待审批 → 「审批」跳转详情；已处理 → 「查看」                       |




### 5.2 详情页


| 分区     | 内容                       | 数据来源                                   |
| ------ | ------------------------ | -------------------------------------- |
| 基础信息   | 申请单号、申请状态、提交时间           | 07 申请主表                                |
| 设备与位置  | 设备编码/名称、绑定仓库/库房/分区、具体位置  | 申请快照                                   |
| 申请内容   | 申请人、手机号（脱敏）、事由、备注、有效期 | 申请快照                                   |
| 审批配置快照 | 配置编号/版本、审批方式、审批节点        | 申请快照                                   |
| 审批记录   | 各节点处理人、结果、意见、时间；**全部 eligible 审批人均可查看**          | 审批任务轨迹                                 |
| 操作区    | 通过/驳回 + 审批意见             | 见 [02审批处理字段清单](./操作字段清单/02审批处理字段清单.md) |


`PENDING` 且当前用户 eligible 时展示操作区；否则只读。

### 5.3 审批操作交互

- **通过**：点击「通过」→ 可选填意见 → 提交 → Toast「审批通过」→ 返回列表并刷新；
- **驳回**：点击「驳回」→ 必填驳回原因 → 提交 → Toast「已驳回」→ 返回列表；
- 并发冲突：申请状态已变更时 Toast「审批失败：申请状态已变更」并刷新详情（R18）。

## 6. 状态与流转

本模块**不定义**申请主状态机；审批人可见状态与操作约束见 [开锁审核业务规则规格](./开锁审核业务规则规格.md) §二。

审批动作执行后，由 07 子类型消费结果并推进申请状态、触发凭证流程：

```mermaid
stateDiagram-v2
    [*] --> 待审批: 申请人提交
    待审批 --> 已通过: 审批人通过（其他审批）
    待审批 --> 已驳回: 审批人驳回（其他审批）
    已通过 --> [*]: 凭证流程（07子类型）
    已驳回 --> [*]
```
