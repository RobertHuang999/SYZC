## 0. 统一执行模型约束

- 本模块为 **08 审批人 UI 层**，消费 07 子类型已创建的申请与审批任务，**不**创建申请、**不**定义凭证规则。
- 审批动作执行时引用平台 R10–R13，入口为「其他审批—开锁审批」，**非** 07 待处理。
- 列表「待审批」= 申请状态 `PENDING` **且** 当前用户为配置快照展开的 eligible 处理人 **且** 对应审批任务为 `PENDING`。
- 列表「已处理」= 当前用户曾作为处理人完成通过/驳回，或申请已进入终态且用户为历史 eligible 处理人。

## 一、能力定位

| 项目 | 内容 |
| :--- | :--- |
| **模块层级** | 审批人交互层（其他审批独立入口） |
| **菜单/入口** | PC：工作中心 → 审批中心（首页）→ 其他审批 → **开锁审核** 卡片；H5：业务办理 → 其他审批 → **开锁审批**（与前端原型 demo 一致） |

## 二、列表与筛选规则

### 2.1 列表视图规则

| 视图 | 枚举 | 过滤条件 | 默认排序 |
| :--- | :--- | :--- | :--- |
| 待审批 | `TAB_PENDING` | 申请状态=`PENDING` AND 当前用户 eligible AND 任务状态=`PENDING` | 提交时间 ASC（先到先审） |
| 已处理 | `TAB_DONE` | 当前用户已处理 OR（申请终态 AND 用户曾为 eligible） | 提交时间 DESC |
| 全部 | `TAB_ALL` | 数据权限范围内全部申请 | 提交时间 DESC |

### 2.2 筛选字段规则

| 规则ID | 规则 |
| :--- | :--- |
| **L01** | 申请单号支持精确匹配 |
| **L02** | 设备名称/编码、申请人支持模糊匹配 |
| **L03** | 绑定仓库下拉选项受 P05 数据权限约束 |
| **L04** | 申请状态多选；与 Tab 视图叠加时取交集 |
| **L05** | 提交时间范围最大跨度 90 天 |

### 2.3 列表展示规则

| 规则ID | 规则 |
| :--- | :--- |
| **L06** | 列表字段只读，均来自申请快照，审批人不可 inline 编辑 |
| **L07** | 待审批行高亮或角标标识；已处理行展示最终审批结果摘要 |
| **L08** | 空列表展示「暂无待审批的开锁申请」/「暂无记录」 |

### 2.4 审批中心入口规则（PC）

| 规则ID | 规则 |
| :--- | :--- |
| **E01** | 入口挂载于审批中心首页「其他审批」区块，卡片文案「开锁审核」，与「政策资讯审核」并列 |
| **E02** | 卡片角标 = 当前用户 eligible 且申请状态=待审批的条数 |
| **E03** | 选中卡片后在页内展示预览表格（默认待审批优先，最多 5 条）；列口径同 L06，不含申请单号 |
| **E04** | 预览区待审批行提供「查看详情」「去处理」；终态仅「查看详情」 |
| **E05** | 「查看更多」跳转完整列表页；**不进**「业务管理审批」待处理/已处理 |

## 三、详情与操作区规则

### 3.1 详情只读规则

| 规则ID | 规则 |
| :--- | :--- |
| **D01** | 详情页全部业务字段只读；状态不可 Dropdown 修改 |
| **D02** | 审批配置快照只读展示，不可跳转编辑（编辑入口在 06 配置页） |
| **D03** | 申请人手机号按角色脱敏（如 `138****5678`） |
| **D04** | 凭证信息区：审批人**不**展示临时密码明文；仅展示凭证状态摘要 |
| **D08** | **审批可见性**：所有参与审批的人员（含已通过/已关闭待办的审批人）均可查看审批记录及最终审批人信息 |

### 3.2 操作区展示条件

| 操作 | 展示条件 | 引用规则 |
| :--- | :--- | :--- |
| 通过 | 申请=`PENDING` AND 用户 eligible AND 任务=`PENDING` | R10–R12 |
| 驳回 | 同上 | R10、R13 |
| 审批意见 | 与通过/驳回同显 | 最多 200 字 |
| 驳回原因 | 驳回时必填 | R13 |

### 3.3 操作区隐藏规则

| 规则ID | 规则 |
| :--- | :--- |
| **D05** | 申请非 `PENDING` 时隐藏通过/驳回，仅保留「返回」 |
| **D06** | 用户非 eligible 时隐藏操作区，展示「您不是当前审批人」 |
| **D07** | 用户为申请人本人时不可审批（R11），隐藏操作区 |

## 四、审批动作执行规则

> 动作执行后的申请状态推进、凭证触发、任务关闭等**后置规则**见 [开锁申请业务规则规格](../03-业务审批/04-我的申请管理/04-开锁审批/开锁申请业务规则规格.md) §2.4。本节仅定义 08 入口侧的触发与反馈。

| 规则ID | 触发动作 | 前置校验 | 成功反馈 | 失败反馈 |
| :--- | :--- | :--- | :--- | :--- |
| **A01** | 审批通过 | R10–R12、P04、P06 | Toast「审批通过」；返回列表 | Toast「审批失败：{原因}」 |
| **A02** | 审批驳回 | R10、R13、P04 | Toast「已驳回」；返回列表 | Toast「驳回失败：申请状态已变更」 |
| **A03** | 并发冲突 | R18 状态条件更新 | — | 刷新详情并提示 |

## 五、权限规则

| 规则ID | 规则分类 | 具体规则 | 无权限处理 |
| :--- | :--- | :--- | :--- |
| **P04** | 审批操作 | 须为 eligible 处理人且账号启用 | 「无审批权限」 |
| **P05** | 数据隔离 | 仓管：仓库 IN 管辖范围；管理员：租户全量 | SQL 自动过滤 |
| **P06** | 自审禁止 | 审批人不能审批自己发起的申请 | 隐藏操作区 |

> 完整 RBAC 矩阵见 [00-全局契约与RBAC权限矩阵](../00-全局契约与RBAC权限矩阵.md) 第四章 §1。
