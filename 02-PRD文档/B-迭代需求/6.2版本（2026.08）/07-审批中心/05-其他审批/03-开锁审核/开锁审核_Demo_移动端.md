> **动作与规则**：见《[开锁审核业务规则规格](./开锁审核业务规则规格.md)》§二～§四、U01~U04、A01~A03。

## 0. 移动端与 PC 差异摘要

| 维度 | PC Demo / ASCII | 移动端 Demo（本文件） |
| :--- | :--- | :--- |
| 一级入口 | 工作中心 → 审批中心 → 其他审批 → **开锁审核** 卡片 | 业务办理 → 其他审批 → **开锁审批** |
| 列表 | 表格 + 筛选栏 + Tab | **卡片列表** + 搜索框 + 状态下拉 |
| 详情 | 多分区只读大表单 + 审批操作区 | **页头摘要橙框** + SectionCard + 内嵌审批处理 |
| 审批处理 | 详情分区；驳回可弹窗 | **SectionCard 内 Textarea + 双按钮**；驳回 inline 校验 |
| 导出 / 批量 | ❌ | ❌ **不提供** |
| 底栏 | — | 🚫 **无固定悬浮操作栏**（审批按钮随 SectionCard 滚动） |

**移动端能力范围**：列表浏览与筛选、详情只读查看、待审批时通过/驳回；**无**发起申请、凭证明文、审批配置编辑。

### 0.1 PC 与移动端排版差异（⚠️ 生成必遵）

| 端 | 详情只读区 | 审批可填区 |
| :--- | :--- | :--- |
| PC | `DetailField` 上 label 下 value + 多列 Grid | 独立「审批操作」分区；驳回可弹窗 |
| 移动 H5 | `KeyValue` 左 label（w-20）右 value | SectionCard 内 label + textarea + 双按钮纵向堆叠 |

> 列表卡片**不展示申请单号**；申请单号仅在搜索框与详情页头展示。

## 3. 审批处理（详情页内嵌）

> H5 **无独立审批页**；规则见 [02审批处理字段清单](./操作字段清单/02审批处理字段清单.md)。

### 3.1 SectionCard「审批处理」

展示条件：申请=`待审批` AND eligible AND 任务=`待处理`（D01–D07）。

| 字段 | 控件 | 规格 |
| :--- | :--- | :--- |
| 审批意见 | `textarea` | 通过选填；驳回必填；≤200 字；`0/200` 计数 |
| 驳回 | 按钮 outline | 左列 |
| 通过 | 按钮 primary orange | 右列 |

### 3.2 提交流程

**通过**：

1. 可选填意见 → 点击「通过」
2. Toast「已通过，凭证生成中」
3. ~1.2s 后返回列表

**驳回**：

1. 填写意见 → 点击「驳回」
2. 空意见 → Toast「驳回须填写审批意见」
3. 成功 → Toast「已驳回」→ 返回列表

### 3.3 阻断场景

| 场景 | 反馈 |
| :--- | :--- |
| 状态已变更 | Toast「审批失败：申请状态已变更」→ 刷新详情 |
| 申请不存在 | 「申请单不存在或已不可见」 |
| 自审 | 隐藏操作区（R11） |

## 5. 反馈文案

| 操作 | 文案 |
| :--- | :--- |
| 通过成功 | 已通过，凭证生成中 / 审批通过 |
| 驳回成功 | 已驳回 |
| 驳回校验失败 | 驳回须填写审批意见 |
| 并发冲突 | 审批失败：申请状态已变更 |
| 列表无结果 | 暂无符合条件的开锁申请 |
| 详情不存在 | 申请单不存在或已不可见 |
