## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 开锁审批（移动列表） |
| 页面目标 | 按数据权限浏览待审批/已处理开锁申请，搜索筛选后进入详情或审批 |
| 菜单路径 | `业务办理 → 其他审批 → 开锁审批` |
| 页面路径 | `/m/approval/unlock-applies` |
| moduleId | `biz-approve-unlock-apply` |
| 骨架结构 | NavBar → 搜索 + 状态胶囊 → 卡片列表 |

> **无分页器**：Demo 全量渲染筛选结果（Mock 7 条可控）。
> **无 Tab 栏**：视图语义通过「状态」下拉胶囊实现（待审批 / 已处理 / 全部）。

## 3. 搜索与筛选区

容器：`shrink-0 border-b bg-white px-3.5 py-2.5`。

### 3.1 搜索框

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 搜索框 | `input[type=text]` | placeholder：`申请单号 / 设备 / 申请人 / 事由`；**输入即时过滤**（L01、L02） |
| 清除 | 图标按钮 | 有内容时显示 `X`，点击清空 keyword |
| 搜索图标 | `Search` | 无内容时右侧展示 |

**匹配字段**：申请单号（精确）、设备名称/编码（模糊）、申请人（模糊）、事由（模糊）。

### 3.2 状态胶囊

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 状态 | `DropdownFilterPill` | label：`状态`；**默认「待审批」**（L04） |
| 选项 | 单选 | 待审批 / 已处理 / 全部 |

**过滤逻辑**：

| 选项 | 过滤条件 |
| :--- | :--- |
| 待审批 | `status === PENDING` |
| 已处理 | `status ∈ {APPROVED, REJECTED, WITHDRAWN, EXPIRED, VOIDED}` |
| 全部 | 数据权限范围内不过滤状态 |

> 6.2 Demo **不提供**独立筛选抽屉；搜索 + 状态下拉即可。

## 4. 卡片列表

**默认排序**：待审批 → 提交时间 ASC；已处理/全部 → 提交时间 DESC。

### 4.1 单卡结构（UnlockApplyCard）

```text
┌──────────────────────────────┐
│ 🔒 {设备名称}        {状态Tag} │
│ ┌──────────────────────────┐ │
│ │ 绑定仓库  {仓库名}         │ │
│ │ 申请人    {姓名}({账号})   │ │
│ │ 事由      {事由枚举}       │ │
│ └──────────────────────────┘ │
│ 🕒 {提交时间}    {去审批|详情} ▸ │
└──────────────────────────────┘
```

| 卡片区域 | 字段来源 | 说明 |
| :--- | :--- | :--- |
| 头部 | 设备名称、申请状态 Tag | **不展示申请单号**（字段清单 §一） |
| 灰框 `slate-50/80` | 绑定仓库、申请人、事由 | KeyValue 横排，label `w-14` |
| 元信息 | 提交时间 | `formatDateTime`，格式 `YYYY-MM-DD HH:mm` |
| 底链 | 去审批 / 详情 | 待审批 → 橙色「去审批 ▸」；终态 → 「详情 ▸」 |

**整卡可点击**：跳转 `/m/approval/unlock-applies/{applyNo}`。

### 4.2 状态 Tag 配色

| 申请状态 | 样式 |
| :--- | :--- |
| 待审批 | `bg-amber-50 text-amber-700` |
| 已通过 | `bg-emerald-50 text-emerald-700` |
| 已驳回 | `bg-red-50 text-red-700`（Demo 可用 gray 兜底） |
| 已撤回 / 已失效 / 已作废 | `bg-gray-100 text-gray-600` |

### 4.3 卡片底链（与 ASCII §1.3 一致）

| 申请状态 + 权限 | 底链文案 | 跳转 |
| :--- | :--- | :--- |
| 待审批 + eligible | 去审批 ▸ | 详情页（含审批处理区） |
| 待审批 + 非 eligible | 详情 ▸ | 只读详情 |
| 已通过 / 已驳回 / 已撤回 / 已失效 / 已作废 | 详情 ▸ | 只读详情 |
