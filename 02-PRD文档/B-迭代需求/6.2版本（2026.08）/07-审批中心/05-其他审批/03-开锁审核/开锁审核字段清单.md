# 开锁审核字段清单

> **文档定位**：审批人侧「其他审批—开锁审批」页面字段的**唯一定义来源**。列表、详情、筛选与审批操作字段均在本文件维护完整口径；下游 PRD、ASCII、Demo 只引用字段名称，不重复定义字段规则。
>
> **页面范围**：PC — 工作中心 / 审批中心 / 其他审批 / **开锁审核**（卡片入口 + 完整列表）；H5 — 业务办理 / 其他审批 / **开锁审批**（与前端原型 demo 一致）。`biz_type` = `UNLOCK_APPLY`。
>
> **规则唯一定义来源**：[开锁审核业务规则规格](./开锁审核业务规则规格.md)
>
> **引用原则**：字段取值、枚举与持久化规则以各来源清单为准；本文件在「字段说明」标注引用出处。审批人页面全部只读展示字段来自申请提交快照，审批人不可 inline 编辑（L06、D01）。
>
> **职责边界**：本文件只维护审批人侧列表/详情展示与审批处理字段；申请人查看密码、复制密码及重新获取密码见 [07/03-业务审批/04-我的申请管理/04-开锁审批/02查看与下发凭证字段清单](../03-业务审批/04-我的申请管理/04-开锁审批/02-操作字段清单/02查看与下发凭证字段清单.md)。

## 六、展示与引用规则

- **列表默认列顺序**：设备名称 → 绑定仓库 → 申请人 → 事由 → 申请状态 → 提交时间 → 操作。
- **筛选区字段**：申请单号、设备名称、设备编码、绑定仓库、申请人、事由、申请状态、提交时间范围；视图 Tab（待审批 / 已处理 / 全部）与申请状态筛选叠加取交集（L04）。
- **详情页分区顺序**：基础信息（申请单号 + 申请状态）→ 设备与位置 → 申请内容 → 审批配置快照 → 审批记录 → 操作区。
- **编辑约束**：§一～§四全部只读；状态变更仅通过 §五审批动作触发。
- **敏感字段**：临时密码不在审批人详情展示（D04）；申请人手机号脱敏（D03）。
- **非 eligible / 非待审批**：隐藏 §五操作区，展示「您不是当前审批人」或仅保留返回（D05、D06）。
- **持久化唯一定义来源**：申请主表及快照字段以 07/01开锁申请主表字段清单为准；平台审批任务以 07/03审批中心字段清单为准；通用审批动作规则以 07/04通用审批处理字段清单为准。本文件字段口径变更须同步核对上述来源清单。
