## 分流规则（R-MYAPP）

> 流程申请规则沿用线上；本节为 6.2 新增约束。平台层规则见 [审批中心业务规则规格（基准）](../../../../🌟🌟🌟-最新基准版/B端PC/01-工作中心/01-审批中心/02-审批中心业务规则规格.md)。

| 规则ID | 规则 |
| :--- | :--- |
| **R-MYAPP-01** | PC 审批中心首页预览区**仅**展示「我的流程申请」，**不含** `UNLOCK_APPLY` |
| **R-MYAPP-02** | PC Tab「我的开锁申请」与 H5 筛选「开锁审批」查 `biz_type=UNLOCK_APPLY`，**含**需审批与免审（`approval_required` 区分）；**不**走平台待办与流程引擎 |
| **R-MYAPP-03** | H5 选中「开锁审批」时走 [04-开锁审批](./04-开锁审批/开锁申请业务规则规格.md) 规则；**不**展示流程节点状态 |
| **R-MYAPP-04** | H5 跨类型搜索：流程类匹配货主/资讯名称；开锁类匹配设备名称、设备编码、申请人（**不含**申请单号） |
| **R-MYAPP-05** | 从审批中心首页进入完整页时，默认 Tab=**我的流程申请** |
| **R-MYAPP-06** | `ROUTE-IOT-APPR-01` 落地时，默认 Tab=**我的开锁申请** 并打开 `apply_no` 详情 |
| **R-MYAPP-07** | Tab「我的融资租赁申请」6.2 **仅占位**，不注册新业务规则 |
| **R-MYAPP-08** | 筛选项「是否需要审核」：**是**=需审批；**否**=免审直发（`approval_required=false`） |
| **R-MYAPP-09** | `ROUTE-IOT-DIRECT-01`（可选）：免审成功后打开「我的开锁申请」Tab 并定位新记录详情 |
