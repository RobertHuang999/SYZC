## 布局说明

| 区域 | 说明 |
| :--- | :--- |
| 页面标题 | **我的申请管理**（PC 统一文案） |
| Tab 结构 | 三 Tab：**我的流程申请**（默认）/ **我的融资租赁申请**（占位）/ **我的开锁申请**（6.2 新增） |
| 我的流程申请 | 接入系统「接入流程配置」；列表/筛选/操作**沿用线上**，6.2 不改造业务正文 |
| 我的融资租赁申请 | **仅占位 Tab**；6.2 不增加字段、规则与 Demo |
| 我的开锁申请 | 轻量化申请（`UNLOCK_APPLY`）；不走流程引擎；列表/筛选字段见 [我的申请管理字段清单](./我的申请管理字段清单.md) §二 |
| 默认 Tab | 从 [01-审批中心首页预览](../01-审批中心首页预览/我的申请管理预览_ASCII.md)「查看更多」进入 → 默认 **我的流程申请**（R-MYAPP-05） |
| Deep link | 门禁发起后跳转 → 直接打开 **我的开锁申请** Tab 并定位详情（`ROUTE-IOT-APPR-01`） |
| 开锁 Tab 操作 | 待审批 → 详情、撤回；已通过 → 详情（含凭证区）；终态 → 详情 |
| 详情页 | 开锁详情引用 [04-开锁审批](../04-开锁审批/开锁申请主PRD.md)；**不**混用流程申请详情壳 |

## Tab 与数据通道对照

| Tab | 数据通道 | biz_type | 审批处理 |
| :--- | :--- | :--- | :--- |
| 我的流程申请 | 接入流程配置 + 平台审批任务 | `PROCESS_*` 等 | 待处理 / 已处理 |
| 我的融资租赁申请 | 占位 | — | — |
| 我的开锁申请 | 轻量化申请主表 · **开锁审批** | `UNLOCK_APPLY` | **其他审批 → 开锁审核**（[08](../../../05-其他审批/03-开锁审核/开锁审核主PRD.md)） |
