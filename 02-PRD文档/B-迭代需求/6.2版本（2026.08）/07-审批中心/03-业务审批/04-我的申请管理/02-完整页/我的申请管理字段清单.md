## 二、Tab · 我的开锁申请（PC 完整页）

> 下列「PC 可筛选」「列表展示」为本页**唯一口径**；主表字段清单 §可筛选 列须与本表保持一致。

| 字段名称 | 字段来源 | 取值说明 | 列表展示 | PC 可筛选 | 筛选控件 | 详情展示 | 字段说明 |
| :--- | :--- | :--- | :---: | :---: | :--- | :---: | :--- |
| 序号 | 系统生成 | 整数 | 是 | 否 | — | 否 | 列表行序号 |
| 申请单号 | 系统生成 | 文本；租户内唯一 | **否** | **否** | — | **是** | 隐藏字段；仅详情页展示 |
| 是否需要审核 | 主表字段 | 枚举：全部、是、否 | 是 | **是** | Select | 是 | **是**=需审批；**否**=免审直发（`approval_required=false`） |
| 提交时间 | 系统生成 | 日期时间 | 是 | **是** | DateRange | 是 | 映射主表**创建时间** |
| 申请状态 | 系统维护 | 待审批/已通过/已驳回/已撤回/已失效/已作废 | 是 | **是** | Select 多选 | 是 | 免审记录固定「已通过」 |
| 凭证状态 | 系统维护 | 未生成/生成中/已下发/… | 是 | **是** | Select 多选 | 是 | 关联凭证生命周期状态 |
| 设备名称 | 申请快照 | 文本 | 是 | **是** | Input 模糊 | 是 | 继承门禁设备系统内名称 |
| 设备编码 | 申请快照 | 文本 | 是 | **是** | Input 精确 | 是 | 继承门禁设备编码 |
| 设备类型 | 申请快照 | 挂锁门禁、人脸门禁 | 否 | **是** | Select 下拉 | 是 | 列表不展示；仅筛选与详情 |
| 绑定仓库 | 申请快照 | 文本 | 是 | **是** | Select 下拉 | 是 | 数据权限过滤 |
| 事由 | 申请快照 | 出库/入库/移库/参观/其他 | 是 | **是** | Select 下拉 | 是 | 业务事由 |
| 申请人 | 申请快照 | 姓名（账号） | 否 | **是** | Input 模糊 | 是 | 列表不展示；筛选与详情展示 |
| 配置编号 | 配置快照 | 文本 | 否 | **是** | Input 精确 | 是 | 运维/排查；列表不展示 |
| 操作 | — | 详情 / 撤回 | 是 | 否 | — | — | **仅**需审批且待审批可撤回 |

> **筛选区展示顺序**（与上表「PC 可筛选=是」字段一致）：是否需要审核 → 提交时间 → 申请状态 → 凭证状态 → 设备名称 → 设备编码 → 设备类型 → 绑定仓库 → 事由 → 申请人 → 配置编号。

详情分区与敏感字段见 [开锁申请字段清单 §2.5](../04-开锁审批/开锁申请字段清单.md#25-详情与其他)。
