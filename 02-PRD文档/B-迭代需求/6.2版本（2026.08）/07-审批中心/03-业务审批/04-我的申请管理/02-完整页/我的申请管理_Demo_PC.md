## 3. Tab · 我的开锁申请

### 3.1 筛选区

字段与控件**须与** [我的申请管理字段清单](./我的申请管理字段清单.md) §二 **完全一致**（展示顺序一致）：

| 字段 | 控件 | 说明 |
| :--- | :--- | :--- |
| 是否需要审核 | Select | 全部 / 是 / 否 |
| 提交时间 | DateRange | 映射主表创建时间 |
| 申请状态 | Select | 多选 |
| 凭证状态 | Select | 多选 |
| 设备名称 | Input | 模糊 |
| 设备编码 | Input | 精确 |
| 设备类型 | Select | 挂锁门禁 / 人脸门禁 |
| 绑定仓库 | Select | 数据权限过滤 |
| 事由 | Select | 出库 / 入库 / 移库 / 参观 / 其他 |
| 配置编号 | Input | 精确 |

> **不含**申请单号筛选项。

### 3.2 表格列

与字段清单 §二「列表展示=是」字段一致：

序号、申请状态、凭证状态、设备名称、设备编码、绑定仓库、事由、提交时间、操作。

> 申请单号、设备类型、申请人、配置编号**不在列表展示**；申请人、配置编号仅详情可见，配置编号可筛选。

### 3.3 行操作

| 申请状态 | 操作 |
| :--- | :--- |
| 待审批 | 详情、撤回 |
| 已通过 | 详情（含凭证区） |
| 已驳回 / 已撤回 / 已失效 | 详情 |

详情页字段与操作见 [查看与下发凭证字段清单](../04-开锁审批/02-操作字段清单/02查看与下发凭证字段清单.md)。
