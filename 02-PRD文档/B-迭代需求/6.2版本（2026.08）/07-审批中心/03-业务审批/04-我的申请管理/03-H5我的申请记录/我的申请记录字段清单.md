## 一、筛选条件

### 1.1 开锁审批（6.2）

选中左栏「**开锁审批**」时，**仅**以下三项作为查询条件（与流程类共用筛选壳，不展开 PC 级细筛）：

| 筛选项 | UI 文案 | 查询映射 | 说明 |
| :--- | :--- | :--- | :--- |
| 申请的业务类型 | 任务状态及类型 · 左栏「开锁审批」 | `biz_type=UNLOCK_APPLY` | 本板块固定为开锁申请 |
| 发起申请时间范围 | 发起日期 | 主表**创建时间**范围 | — |
| 是否需要审核 | 是否需要审核 | `approval_required` | **是**=需审批；**否**=免审直发记录 |

> **不含**：申请单号、申请状态右栏多选、设备/仓库独立筛项（PC 完整页才有）。

### 1.2 流程申请（沿用线上）

左栏流程大类 + 发起日期 + 是否需要审核；6.2 不展开。

## 二、开锁审批卡片摘要

| 卡片区域 | 字段 | 说明 |
| :--- | :--- | :--- |
| 顶栏 | 提交时间、类型标签 | 类型文案「开锁·临时授权」；免审追加 Tag「无需审核」 |
| 主标题 | 设备名称 | 左侧「锁」图标 |
| 摘要 | 绑定仓库、凭证状态、事由、发起人 | **不展示申请单号** |
| 状态 | 申请状态 Tag | — |
| 底链 | 查看详情 | 无「去审批」 |

申请单号仅在**详情页基础信息**展示。

## 三、统一搜索（顶栏）

| 类型 | 匹配字段 |
| :--- | :--- |
| 流程类 | 货主名称、资讯名称 |
| 开锁类 | 设备名称、设备编码、申请人（**不含**申请单号） |
