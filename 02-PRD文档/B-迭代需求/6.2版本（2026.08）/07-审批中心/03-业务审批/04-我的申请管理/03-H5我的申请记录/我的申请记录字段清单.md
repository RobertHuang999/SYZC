## 二、各 Tab 筛选条件

### 2.1 流程申请 Tab

无筛选（占位页）；展示「功能将在后续版本接入，与 PC 端「我的流程申请」Tab 保持一致」。

### 2.2 政策资讯 Tab

无筛选（占位页）；展示「功能将在后续版本接入，与 PC 端「我的政策资讯申请」Tab 保持一致」。

### 2.3 开锁审核 Tab

| 筛选项 | UI 文案 | 查询映射 | 说明 |
| :--- | :--- | :--- | :--- |
| 关键词 | 顶栏搜索 | 设备名称/编码/申请人 | **不含**申请单号 |
| 发起申请时间范围 | 发起日期 | 主表**创建时间** | — |
| 是否需要审核 | 是否需要审核 | `approval_required` | **是**=需审批；**否**=免审直发 |
| 申请状态 | 申请状态 | 主表申请状态 | 单选 Pill；默认「全部」 |
| 凭证状态 | 凭证状态 | 关联凭证生命周期状态 | 单选 Pill；默认「全部」；**5 态**；**生成失败**=密码服务调用失败（挂锁/人脸统一） |

> **不含**：申请单号、设备/仓库独立筛项（PC 完整页展开筛选才有）。

## 三、开锁审核 Tab 卡片摘要

| 卡片区域 | 字段 | 说明 |
| :--- | :--- | :--- |
| 顶栏 | 提交时间、类型标签 | 类型文案「开锁·临时授权」；免审追加 Tag「无需审核」 |
| 主标题 | 设备名称 | 左侧「锁」图标 |
| 摘要 | 绑定仓库、凭证状态、事由、发起人 | **不展示申请单号** |
| 状态 | 申请状态 Tag | — |
| 底链 | 查看详情 | 无「去审批」 |

申请单号仅在**详情页基础信息**展示。

## 四、统一搜索（开锁 Tab 顶栏）

| Tab | 匹配字段 |
| :--- | :--- |
| 开锁审核 | 设备名称、设备编码、申请人（**不含**申请单号） |

> 流程申请 / 政策资讯 Tab 为占位页，无搜索区。
