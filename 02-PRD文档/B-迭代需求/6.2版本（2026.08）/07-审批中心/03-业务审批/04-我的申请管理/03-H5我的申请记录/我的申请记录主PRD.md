## 1. 业务背景

**我的申请记录**是 H5 端 **业务管理审批 → 我的申请管理** 的统一个人申请列表。流程申请与**开锁审批**混合展示，通过「任务状态及类型」筛选区分。

> **与审批人侧区分**：「其他审批 → 开锁审批/开锁审核」为审批人入口，见 [03-开锁审核](../../../05-其他审批/03-开锁审核/开锁审核主PRD.md)；**不**与本页混用。

## 2. 功能范围

| 能力 | 说明 |
| :--- | :--- |
| 流程申请卡片 | 沿用线上 |
| 开锁审批卡片 | 左栏筛选「**开锁审批**」；筛选三项：业务类型 + 发起日期 + 是否需要审核（**否**=免审记录） |
| 搜索 | 流程：货主/资讯；开锁：设备名称/编码/申请人（**不含**申请单号，R-MYAPP-04） |
| 详情 | 开锁 → [04-开锁审批](../04-开锁审批/开锁申请主PRD.md) 申请人详情 |
