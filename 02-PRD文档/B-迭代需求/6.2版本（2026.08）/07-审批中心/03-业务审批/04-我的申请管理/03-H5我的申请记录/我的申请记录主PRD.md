## 1. 业务背景

**我的申请记录**是 H5 端 **业务管理审批 → 我的申请管理** 的个人申请入口，与 PC「我的申请管理」三 Tab 结构对齐，拆分为**流程申请 / 政策资讯 / 开锁审核**三个独立 Tab，避免混合列表信息过载。

> **与审批人侧区分**：「其他审批 → 开锁审批/开锁审核」为审批人入口，见 [03-开锁审核](../../../05-其他审批/03-开锁审核/开锁审核主PRD.md)；**不**与本页混用。

## 2. 功能范围

| Tab（H5） | 对应 PC Tab | 说明 |
| :--- | :--- | :--- |
| 流程申请 | 我的流程申请 | 占位「功能将在后续版本接入，与 PC 端「我的流程申请」Tab 保持一致」 |
| 政策资讯 | 我的政策资讯申请 | 占位「功能将在后续版本接入，与 PC 端「我的政策资讯申请」Tab 保持一致」 |
| 开锁审核 | 我的开锁申请 | 开锁卡片；搜索 + 是否需要审核 + 申请状态 + 凭证状态 + 发起日期 |

| 能力 | 说明 |
| :--- | :--- |
| URL 同步 | `?tab=process\|policy\|unlock-applies` |
| 筛选持久化 | 开锁 Tab sessionStorage |
| 详情 | 开锁 → [04-开锁审批](../04-开锁审批/开锁申请主PRD.md) 申请人详情（**不含凭证信息区**）；返回保留 Tab |
