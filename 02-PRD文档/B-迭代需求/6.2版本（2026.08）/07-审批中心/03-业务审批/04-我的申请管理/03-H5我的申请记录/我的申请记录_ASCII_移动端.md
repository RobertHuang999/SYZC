## 布局说明

| 区域 | 说明 |
| :--- | :--- |
| 页面标题 | **我的申请记录**（H5 统一文案） |
| 页头 Tab | 流程申请 / 政策资讯 / 开锁审核；与 PC 三 Tab 一一对应 |
| 搜索 | 仅开锁 Tab 有搜索/筛选；流程/政策 Tab 为占位 |
| 开锁 Tab 筛选 | **是否需要审核** + **申请状态** + **凭证状态** + **发起日期** |
| 开锁卡片摘要 | 设备名称、绑定仓库、凭证状态、事由、发起人；**不含申请单号** |
| 详情跳转 | 开锁 → 详情页；NavBar 返回 `?tab=unlock-applies` |

---

## 开锁卡片字段映射

| 卡片区域 | 流程申请（既有） | 开锁申请（6.2） |
| :--- | :--- | :--- |
| 右上角类型 | 质押·货物估值 等 | 开锁·临时授权 |
| 主标题 | 货主公司名称 | 设备名称 |
| 摘要行 1 | 质押货物/新质物 等 | 绑定仓库 + 凭证状态 |
| 摘要行 2 | 贷款金额 等 | 事由 + 发起人 |
