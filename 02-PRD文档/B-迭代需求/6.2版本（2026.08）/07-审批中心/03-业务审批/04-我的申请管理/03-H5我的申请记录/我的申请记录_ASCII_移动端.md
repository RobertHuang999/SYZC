## 布局说明

| 区域 | 说明 |
| :--- | :--- |
| 页面标题 | **我的申请记录**（H5 统一文案） |
| 搜索 | 流程类：货主/资讯；开锁类：设备名称、设备编码、申请人（**不含**申请单号） |
| 筛选 | 开锁审批三项：**申请的业务类型** + **发起日期** + **是否需要审核** |
| 开锁卡片摘要 | 设备名称、绑定仓库、凭证状态、事由、发起人；**不含申请单号** |
| 开锁卡片角标 | 左侧图标「锁」；类型文案「开锁·临时授权」 |
| 底链操作 | 开锁：**仅「查看详情」**（申请人侧无「去审批」）；流程类沿用线上 |
| 详情跳转 | 开锁 → [03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_Demo_详情页_移动端](../04-开锁审批/开锁申请_Demo_详情页_移动端.md)（含凭证区）；Deep link 同 PC `ROUTE-IOT-APPR-01` |

## 开锁卡片字段映射

| 卡片区域 | 流程申请（既有） | 开锁申请（6.2） |
| :--- | :--- | :--- |
| 右上角类型 | 质押·货物估值 等 | 开锁·临时授权 |
| 主标题 | 货主公司名称 | 设备名称 |
| 摘要行 1 | 质押货物/新质物 等 | 绑定仓库 + 凭证状态 |
| 摘要行 2 | 贷款金额 等 | 事由 + 发起人 |
