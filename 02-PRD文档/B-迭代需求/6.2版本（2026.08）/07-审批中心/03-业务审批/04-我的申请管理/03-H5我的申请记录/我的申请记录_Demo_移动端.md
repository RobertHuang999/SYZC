## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 我的申请记录 |
| 菜单路径 | 业务办理 → 内部审批 → 我的申请记录 |
| 路由建议 | `/m/module/biz-overview-my-apply` |
| 骨架结构 | NavBar → 搜索 → 筛选胶囊 → 卡片列表 |

> **与审批人侧区分**：H5「其他审批 → 开锁审批」(`/m/approval/unlock-applies`) 为审批人列表，**不**与本页混用。

## 2. 搜索

| 元素 | 规格 |
| :--- | :--- |
| placeholder | 流程：`搜索货主名称/资讯名称`；开锁选中时：`搜索设备名称/设备编码/申请人` |
| 流程类 | 匹配货主名称、资讯名称 |
| 开锁类 | 匹配设备名称、设备编码、申请人（**不含**申请单号） |

## 3. 筛选（开锁审批 · 三项）

| 筛选项 | 说明 |
| :--- | :--- |
| 申请的业务类型 | 左栏选中「开锁审批」→ `UNLOCK_APPLY` |
| 发起日期 | 创建时间范围 |
| 是否需要审核 | 全部 / 是 / 否；**否**=免审直发记录 |

> 开锁板块**不**展示 PC 级申请状态右栏、设备/仓库独立筛项。

## 4. 卡片模板

### 4.1 流程申请卡片（沿用线上）

时间、类型标签、货主、状态 Tag、业务摘要、底链（查看详情 / 重新发起等）。

### 4.2 开锁审批卡片（6.2）

| 区域 | 内容 |
| :--- | :--- |
| 顶栏 | 提交时间 + 「开锁·临时授权」 |
| 主标题 | 设备名称；左侧「锁」图标 |
| 摘要 | 绑定仓库、凭证状态、事由、发起人 |
| 状态 Tag | 申请状态 |
| 底链 | **仅「查看详情」** |

点击卡片或底链 → 申请人详情页（[03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_Demo_详情页_移动端](../04-开锁审批/开锁申请_Demo_详情页_移动端.md)）；Deep link 参数同 PC。

## 5. 详情页

开锁详情规格见 [开锁申请_Demo_详情页_移动端 §四](../04-开锁审批/开锁申请_Demo_详情页_移动端.md)；含凭证查看/短信重发，**无**审批操作区。
