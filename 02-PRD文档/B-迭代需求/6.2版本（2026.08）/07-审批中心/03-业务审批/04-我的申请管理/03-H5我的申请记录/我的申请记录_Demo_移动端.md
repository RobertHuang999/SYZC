## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 我的申请记录 |
| 菜单路径 | 业务办理 → 内部审批 → 我的申请记录 |
| 路由建议 | `/m/my-applies?tab=process\|policy\|unlock-applies` |
| 骨架结构 | NavBar → **页头 Tab** → 各 Tab 独立搜索/筛选 → 卡片列表 |

> **与 PC 对齐**：三 Tab 对应 PC「我的流程申请 / 我的政策资讯申请 / 我的开锁申请」；移动端 Tab 文案为「流程申请 / 政策资讯 / 开锁审核」。
>
> **与审批人侧区分**：H5「其他审批 → 开锁审批」(`/m/approval/unlock-applies`) 为审批人列表，**不**与本页混用。

## 2. 页头 Tab

| Tab | URL 参数 | 说明 |
| :--- | :--- | :--- |
| 流程申请 | `?tab=process`（默认） | 流程申请卡片列表 |
| 政策资讯 | `?tab=policy` | 占位「功能开发中」（与 PC 一致） |
| 开锁审核 | `?tab=unlock-applies` | 开锁申请卡片列表 |

切换 Tab 同步更新 URL；各 Tab 筛选条件**分别**持久化至 sessionStorage。

## 3. 各 Tab 搜索与筛选

### 3.1 流程申请 Tab

| 元素 | 规格 |
| :--- | :--- |
| placeholder | `搜索货主名称/资讯名称` |
| 发起日期 | 起止 date input |
| 匹配 | 货主名称、资讯名称 |

### 3.2 政策资讯 Tab

无筛选；展示占位说明。

### 3.3 开锁审核 Tab

| 筛选项 | 说明 |
| :--- | :--- |
| 搜索 | 设备名称 / 设备编码 / 申请人（**不含**申请单号） |
| 发起日期 | 创建时间范围 |
| 是否需要审核 | 全部 / 是 / 否；**否**=免审直发记录 |

## 4. 卡片模板

### 4.1 流程申请卡片（沿用线上）

时间、类型标签、货主、状态 Tag、业务摘要、底链（查看详情 / 重新发起等）。

### 4.2 开锁审核卡片（6.2）

| 区域 | 内容 |
| :--- | :--- |
| 顶栏 | 提交时间 + 「开锁·临时授权」 |
| 主标题 | 设备名称；左侧「锁」图标 |
| 摘要 | 绑定仓库、凭证状态、事由、发起人 |
| 状态 Tag | 申请状态 |
| 底链 | **仅「查看详情」** |

点击卡片或底链 → 申请人详情页（[开锁申请_Demo_详情页_移动端](../04-开锁审批/开锁申请_Demo_详情页_移动端.md)）；返回列表时回到 `?tab=unlock-applies`。

## 5. 详情页

开锁详情规格见 [开锁申请_Demo_详情页_移动端 §四](../04-开锁审批/开锁申请_Demo_详情页_移动端.md)；含凭证查看/短信重发，**无**审批操作区、**无**关联事务分区。
