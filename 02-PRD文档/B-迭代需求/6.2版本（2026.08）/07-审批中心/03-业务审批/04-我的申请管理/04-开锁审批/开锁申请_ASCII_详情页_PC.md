## 布局说明

**页头识别区**（`rounded-xl border bg-card p-4`）：申请单号、申请状态、凭证状态 Tag；右侧动作：

| 申请状态 | 页头动作 |
| :--- | :--- |
| 待审批 | 返回、撤回 |
| 已通过 / 已驳回 / 已撤回 / 已失效 / 已作废 | 返回 |

**内容分区**（`DetailSection` 卡片，字段清单 §2.5 顺序）：

| 分区 | 字段 |
| :--- | :--- |
| 基础信息 | 申请单号、申请状态、凭证状态、提交时间 |
| 设备与位置快照 | 设备编码/名称/类型、绑定仓库/库房/分区、具体位置、命中位置说明 |
| 申请内容 | 申请人、机构、手机号（脱敏）、事由、备注、预计使用时段 |
| 审批配置快照 | 配置编号/版本、审批方式、审批节点、审批超时时间 |
| 审批记录 | 节点、处理人、结果、意见/驳回原因、处理时间；终态追加最终审批结论 |
| 凭证信息 | 凭证编号、凭证状态、密码有效期、临时密码卡片；**挂锁**追加短信发送状态、重新下发短信 |
| 关联事务 | 关联事务状态、实际开锁时间、关联事务跳转 |

> **敏感字段**：临时密码仅申请人或授权查看人可见（R22、A05）；审批人侧 08 详情不展示明文。
> **全字段只读**：提交后不可编辑；状态变更仅通过撤回、审批、关闭等动作触发。
