```text
| 凭证编号   CRD-20260827015-001    凭证状态   [ 已下发 ]                        |
| 密码有效期 2026-08-27 08:30 ~ 2026-08-30 08:30 （挂锁默认 3 天）               |
| 临时密码   ┌─────────────────────────────────────┐                              |
|            │  ****5678              [ 复制 ]      │                              |
|            └─────────────────────────────────────┘                              |
|            密码仅页面展示，关闭详情后清除                                        |
+-------------------------------------------------------------------------------+
```

### 人脸 · 三方下发失败（可重试，不展示密码）

```text
+-- 凭证信息 -------------------------------------------------------------------+
| 设备类型   人脸门禁                                                            |
| 凭证状态   [ 密码下发失败 ]                                                    |
| 失败原因   三方门禁平台下发超时，请重新获取                                      |
| （不展示临时密码卡片）                                                         |
| 操作       [ 重新获取密码 ]  → 成功 → 展示密码 + 可复制 → 凭证 [ 已下发 ]      |
+-------------------------------------------------------------------------------+
```

### 挂锁 · 已下发（含短信失败场景）

```text
| 凭证状态 [ 已下发 ]  临时密码 ****5678 [ 复制 ]                                |
| 注：短信发送失败不改变凭证状态；密码以详情页为准（本模块不展示短信状态）          |
```

### 生成失败

```text
| 凭证状态 [ 生成失败 ]  失败原因：密码服务调用超时                              |
| 操作     [ 重新获取密码 ]                                                      |
```

### 已过期 / 被覆盖

```text
| 凭证状态 [ 已过期 ]  失效提示：凭证已过期，无法查看密码                          |
| 凭证状态 [ 已失效（被覆盖）]  失效提示：设备密码已被更新，原密码已失效            |
```

## 布局说明

**页头识别区**：申请单号、申请状态 Tag、**凭证状态 Tag**；待审批追加「撤回」。

**内容分区**（字段清单 §2.5）：

| 分区 | 字段 |
| :--- | :--- |
| 基础信息 | 申请单号、申请状态、**凭证状态**、提交时间、是否需要审核 |
| 设备与位置快照 | 设备编码/名称/类型、绑定仓库/库房/分区、具体位置 |
| 申请内容 | 申请人、机构、手机号（脱敏）、事由、备注、预计使用时段 |
| 审批配置快照 | 配置编号/版本、审批方式、审批节点、审批超时（**仅**需审批） |
| 审批记录 | 节点、处理人、结果、意见/驳回原因、处理时间（**仅**需审批） |
| **凭证信息** | 凭证编号、凭证状态、密码有效期、临时密码（条件）、失败原因（条件）、重新获取密码（条件） |

> **不含**：关联事务（W00）。
