> **字段定义**：见《[开锁申请字段清单](./开锁申请字段清单.md)》及子清单。
> **线框参考**：[开锁申请_ASCII_详情页_PC](./开锁申请_ASCII_详情页_PC.md)

> **版本**：V1.4 | 2026-09-02

> **端说明**：本文件为**申请人侧**详情；审批人侧见 [03-开锁审核/开锁审核_Demo_详情页](../../05-其他审批/03-开锁审核/开锁审核_Demo_详情页.md)（不含密码明文）。

> **6.2 范围说明**：申请人详情含「凭证信息」分区（密码展示/复制、重新获取密码）；页头与基础信息含凭证状态 Tag。列表/表格仍展示凭证状态列。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 开锁申请详情（申请人侧） |
| 页面目标 | 只读查看申请快照、审批记录；待审批可撤回 |
| 菜单路径 | `工作中心 → 审批中心 → 我的申请管理 → 我的开锁申请 → 详情` |

| 骨架结构 | 页头识别区 → 基础信息 → 设备与位置 → 申请内容 → （需审批）审批配置快照 → （需审批）审批记录 → **凭证信息** |

## 7. 审批配置快照 / 审批记录（DetailSection）

> **展示条件**：`needsApproval === true`（免审记录不展示此两分区）。

### 7.1 审批配置快照

配置编号、版本、审批方式、审批超时（如有）、审批节点。

### 7.2 审批记录（表格）

| 列 | 说明 |
| :--- | :--- |
| 节点 | 序号 |
| 处理人 | 姓名（账号） |
| 结果 | 通过 / 驳回 |
| 意见/驳回原因 | 文本 |
| 处理时间 | 日期时间 |

待审批且无记录：展示「暂无记录，等待审批」。终态可追加最终审批结论、驳回原因。

---

## 8. 凭证信息（DetailSection）

> 展示条件：`status === APPROVED` 或凭证状态非「未生成」。规则见 [02查看与下发凭证字段清单](./02-操作字段清单/02查看与下发凭证字段清单.md)。

| 字段 | 展示规格 |
| :--- | :--- |
| 凭证编号 | 文本 |
| 凭证状态 | Tag（**5 态**） |
| 密码有效期 | 起止时间 |
| 失败原因 | 凭证=生成失败时展示 |
| 临时密码 | 密码卡片 +  monospace 大字；**仅**凭证=已下发时展示 |
| 操作 | 凭证=生成失败 → `[ 重新获取密码 ]` |
| 失效提示 | 已过期 / 被覆盖时展示，隐藏密码卡片 |

| 操作 | 反馈 |
| :--- | :--- |
| 复制密码 | Toast「已复制到剪贴板」 |
| 重新获取密码 | Toast「密码已重新获取」；凭证→已下发 |
