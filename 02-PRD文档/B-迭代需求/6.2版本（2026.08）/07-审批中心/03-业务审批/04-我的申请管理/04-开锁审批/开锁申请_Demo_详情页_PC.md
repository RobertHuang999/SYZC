> **字段定义**：见《[开锁申请字段清单](./开锁申请字段清单.md)》及子清单。
> **线框参考**：[开锁申请_ASCII_详情页_PC](./开锁申请_ASCII_详情页_PC.md)

> **端说明**：本文件为**申请人侧**详情；审批人侧见 [03-开锁审核/开锁审核_Demo_详情页](../../05-其他审批/03-开锁审核/开锁审核_Demo_详情页.md)（不含密码明文）。

> **6.2 范围说明**：申请人详情**不含**「凭证信息」分区（密码展示/复制、短信重发暂不接入）；列表/表格仍展示凭证状态列。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 开锁申请详情（申请人侧） |
| 页面目标 | 只读查看申请快照、审批记录；待审批可撤回 |
| 菜单路径 | `工作中心 → 审批中心 → 我的申请管理 → 我的开锁申请 → 详情` |
| 页面路径 | `/工作中心/审批中心/我的申请管理/unlock-applies/:applyNo` |
| 骨架结构 | 页头识别区 → 基础信息 → 设备与位置 → 申请内容 → （需审批）审批配置快照 → （需审批）审批记录 |

## 2. DetailSection 布局规范（⚠️ 生成必遵）

与 dev 共用 `@/shared/components/DetailSection`：

| 层级 | 实现 |
| :--- | :--- |
| 分区 | `DetailSection`：标题 + 内容区 Card |
| 内容区 | **4 列 CSS Grid**（≤1100px → 3 列），`gap: 22px 28px` |
| 单字段 | `DetailField`：**label 在上、value 在下** |
| label | 13px、`#86909c` |
| value | 14px、`#1d2129` |

**禁止**：ElDescriptions 横向「左 label 右 value」。

## 3. 页头识别区

```text
开锁申请 {申请单号}   [ 申请状态Tag ]     [ ← 返回 ]  [ 撤回? ]
```

| 申请状态 | 页头动作 |
| :--- | :--- |
| 待审批 | 返回 / 撤回 |
| 已通过 / 已驳回 / 已撤回 / 已失效 / 已作废 | 返回 |

## 6. 申请内容（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| 申请人 | 姓名（账号） |
| 申请人所属机构 | 文本 |
| 申请人手机号 | 脱敏 `138****5678` |
| 事由 / 备注 | 文本 |
| 预计使用时段 | 起止时间 + helper「仅供审批参考」（**仅**需审批记录展示） |

---

## 7. 审批配置快照 / 审批记录（DetailSection）

> **展示条件**：`needsApproval === true`（免审记录不展示此两分区）。

### 7.1 审批配置快照

配置编号、版本、审批方式、审批超时（如有）、审批节点。

### 7.2 审批记录（表格）

| 列 | 说明 |
| :--- | :--- |
| 节点 | 序号 |
| 处理人 | 姓名（账号） |
| 结果 | 通过 / 驳回 |
| 意见/驳回原因 | 文本 |
| 处理时间 | 日期时间 |

待审批且无记录：展示「暂无记录，等待审批」。终态可追加最终审批结论、驳回原因。
