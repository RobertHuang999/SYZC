## 9. 凭证信息（DetailSection）

> **按设备类型渲染**（R31）：`deviceType === '挂锁门禁'` 时展示短信相关字段；人脸门禁**不渲染**短信状态与重发按钮。

| 字段 | 展示规格 | 适用 |
| :--- | :--- | :--- |
| 凭证编号 | 文本 | 全类型 |
| 凭证状态 | Tag | 全类型 |
| 密码有效期 | 起止；挂锁默认 3 天；人脸按申请参数 | 全类型 |
| 短信发送状态 | Tag；失败时展示失败原因摘要 | **仅挂锁** |
| 临时密码卡片 | 条件展示：`已通过` + `已下发` + 未过期未撤销；`****5678` + `[复制]` | 全类型 |
| 重新下发短信 | 按钮；条件：`挂锁` + `下发失败` 且凭证仍可用 | **仅挂锁** |

> R22：密码明文仅页面内存；复制不写审计；离开详情清除明文。

### 9.1 凭证异常态

| 凭证状态 | 页面表现 |
| :--- | :--- |
| 未生成 / 生成中 | 无密码卡片；生成中展示 loading |
| 生成失败 | 失败原因摘要；受控重试入口（如有权限） |
| 下发失败 | **挂锁**：可展示密码 + 「重新下发短信」；**人脸**：不适用此状态 |
| 已过期 / 已撤销 / 被覆盖 | 隐藏密码；展示失效提示 |
