## 5. SectionCard 字段

### 5.1 设备与位置（默认展开）

设备编码、设备类型、绑定仓库、库房/分区、具体位置。

### 5.2 申请内容（默认展开）

申请人、手机号（脱敏）、事由、备注、预计时段、提交时间。

### 5.3 审批配置快照（折叠）

配置编号、版本、审批方式、审批节点。

### 5.4 审批记录（折叠）

节点、处理人、结果、意见、时间；待审批展示「暂无记录，等待审批」。

### 5.5 凭证信息（条件展开）

> **R31**：按 `deviceType` 渲染；人脸**不含**短信状态与重发按钮。

凭证状态、密码有效期、临时密码卡片（条件）；**挂锁**追加：短信状态、重新下发短信按钮。

### 5.6 （已移除）

> 6.2 不展示「关联事务」分区（W00）。

## 6. 底部动作

| 申请状态 | 动作 |
| :--- | :--- |
| 待审批 | 全宽 `[ 撤回申请 ]` |
| 已通过 + 挂锁短信失败 | SectionCard 内 `[ 重新下发短信 ]` |
| 终态 | 无固定底栏 |

---

## 7. 凭证区交互

| 场景 | 规格 |
| :--- | :--- |
| 已下发且有效 | 密码卡片 `****5678` + 复制图标 |
| 生成中 | Loading + 「正在生成凭证…」 |
| 下发失败 | **挂锁**：展示失败原因 + 重发短信；**人脸**：不适用 |
| 被覆盖 | 「设备密码已被更新，原密码已失效」；隐藏密码 |
