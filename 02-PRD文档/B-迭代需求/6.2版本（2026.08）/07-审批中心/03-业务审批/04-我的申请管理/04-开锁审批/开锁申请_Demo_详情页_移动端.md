## 5. SectionCard 字段

### 5.1 设备与位置（默认展开）

设备编码、设备类型、绑定仓库、库房/分区、具体位置。

### 5.2 申请内容（默认展开）

申请人、手机号（脱敏）、事由、备注、预计时段、提交时间。

### 5.3 审批配置快照（折叠）

配置编号、版本、审批方式、审批节点、审批超时（如有）。

### 5.4 审批记录（折叠）

节点、处理人、结果、意见、时间；待审批展示「暂无记录，等待审批」。

### 5.5 凭证信息（默认展开）

> 规则见 [02查看与下发凭证字段清单](./02-操作字段清单/02查看与下发凭证字段清单.md)。

| 字段 | 规格 |
| :--- | :--- |
| 凭证状态 | KeyValue |
| 密码有效期 | 起止时间 |
| 失败原因 | 生成失败 |
| 重新获取密码 | 全宽按钮；凭证=生成失败 |
| 临时密码 | 仅凭证=已下发时展示 + 复制 |
| 失效提示 | 已过期 / 被覆盖 |

> **不含**「关联事务」分区（W00）。

## 6. 底部动作

| 申请状态 | 动作 |
| :--- | :--- |
| 待审批且需审批 | 全宽 `[ 撤回申请 ]` + 二次确认 |
