## 0. 移动端与 PC 差异摘要

| 维度 | PC 端 | 移动端（本文件） |
| :--- | :--- | :--- |
| 一级入口 | 我的申请管理 → Tab「我的开锁申请」 | 我的申请记录 → Tab「开锁审核」 |
| 列表 | 表格 + 11 项筛选 | 卡片 + 5 项筛选 Pill |

| 凭证详情 | DetailSection「凭证信息」 | SectionCard「凭证信息」（默认展开） |
| 撤回 | 页头按钮 | 底部 `[ 撤回申请 ]` |

## 5. 布局说明

**NavBar**：返回 `?tab=unlock-applies`（保留筛选）。

**页头摘要框**：申请单号、设备名称、**申请状态 Tag**、**凭证状态 Tag**。

**SectionCard + KeyValue**：

| 区块 | 字段 |
| :--- | :--- |
| 设备与位置 | 设备编码/类型、绑定仓库、库房/分区、具体位置 |
| 申请内容 | 申请人、手机号、事由、备注、有效期、提交时间 |
| 审批配置快照 | 配置编号/版本、审批方式、审批节点 |
| 审批记录 | 节点、处理人、结果、意见、时间 |
| **凭证信息** | 凭证状态、密码有效期、临时密码（条件）、失败原因（条件）、重新获取密码按钮（条件） |

**底部动作**：仅待审批且需审批时展示「撤回申请」。
