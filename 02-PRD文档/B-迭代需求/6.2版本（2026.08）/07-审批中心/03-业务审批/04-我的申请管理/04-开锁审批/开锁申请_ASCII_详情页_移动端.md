## 4. 布局说明

**NavBar**：返回 `?tab=unlock-applies`（保留筛选）。

**页头摘要框**：申请单号、设备名称、**申请状态** Tag（不含凭证 Tag）。

**SectionCard + KeyValue**：

| 区块 | 字段 |
| :--- | :--- |
| 设备与位置 | 设备编码/类型、绑定仓库、库房/分区、具体位置 |
| 申请内容 | 申请人、手机号、事由、备注、预计时段、提交时间 |
| 审批配置快照 | 配置编号/版本、审批方式、审批节点 |
| 审批记录 | 节点、处理人、结果、意见、时间 |

**底部动作**：仅待审批且需审批时展示「撤回申请」。
