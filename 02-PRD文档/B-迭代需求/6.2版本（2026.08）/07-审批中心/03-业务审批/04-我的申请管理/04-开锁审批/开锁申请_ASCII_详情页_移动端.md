## 0. 移动端与 PC 差异摘要

| 维度 | PC 端 | 移动端（本文件） |
| :--- | :--- | :--- |
| 一级入口 | 工作中心 → 我的申请管理 → Tab「我的开锁申请」 | 业务办理 → 我的申请记录 → 筛选「开锁审批」 |
| 列表 | 表格 + 11 项筛选 | 卡片 + 搜索框 + 三筛下拉（见 H5 列表 ASCII） |
| 详情 | DetailSection 4 列 Grid · 上 label 下 value | SectionCard + KeyValue · **左 label 右 value** |
| 凭证操作 | 密码卡片 + 复制；**挂锁**追加重新下发短信 | 人脸无短信区 |
| 撤回 | 页头按钮 | 页头或底部 `[ 撤回申请 ]` |
| 审批处理 | ❌ 不在申请人详情 | ❌ 审批人走 [03-开锁审核](../../05-其他审批/03-开锁审核/开锁审核_ASCII_移动端.md) |

### 0.1 PC 与移动端字段排版差异（⚠️ 生成必遵）

| 端 | 详情只读区 | 凭证区 |
| :--- | :--- | :--- |
| **PC** | `DetailField`：**上 label 下 value**，4 列 Grid | 密码卡片嵌入 DetailSection |
| **移动 H5** | `KeyValue`：**左 label（w-20）右 value** 横排 | 独立 SectionCard，全宽密码卡片 |

> 移动端**不要**套用 PC 宽表栅格；列表卡片**不展示申请单号**（字段清单 §2.1），申请单号仅在详情页头展示。

## 6. 布局说明

**NavBar**：左侧 `<` 返回列表（保留筛选条件）；标题「开锁申请详情」。

**页头摘要框**（`orange-50` / 品牌浅色背景）：申请单号、设备名称、申请状态 + 凭证状态 Tag。

**SectionCard**（`collapsible` 可选）：内部字段用 `KeyValue`（**左 label 右 value**，label 宽 `w-20`）。

| 区块 | 字段 | 字段清单 |
| :--- | :--- | :--- |
| 设备与位置 | 设备编码/类型、绑定仓库、库房/分区、具体位置 | 01主表 §三 |
| 申请内容 | 申请人、手机号（脱敏）、事由、备注、预计时段、提交时间 | 01主表 §二、§四 |
| 审批配置快照 | 配置编号/版本、审批方式、审批节点 | 01主表 §五 |
| 审批记录 | 节点、处理人、结果、意见/驳回原因、时间 | 01主表 §六 |
| 凭证信息 | 凭证状态、密码有效期、临时密码；**挂锁**追加短信状态、重新下发 | 02凭证、02查看与下发 |
| 关联事务 | 关联事务状态、实际开锁时间、跳转链接 | 03事务关联 |

**底部动作**：

| 申请状态 | 动作 |
| :--- | :--- |
| 待审批 | `[ 撤回申请 ]` |
| 已通过（挂锁·短信失败） | SectionCard 内 `[ 重新下发短信 ]` |
| 其他终态 | 无固定底栏 |

**敏感字段**：临时密码不写入缓存持久化；复制后不记录明文审计（A05）。
