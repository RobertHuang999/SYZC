## 2. 背景与目标

门禁临时开锁需经审批时，系统创建 **开锁申请**（`UNLOCK_APPLY`）记录授权意图；审批通过后生成临时凭证并下发。该类型**不**进入平台「待处理/已处理」，审批人通过 [03-开锁审核](../../05-其他审批/03-开锁审核/开锁审核主PRD.md) 处理。

**与门禁设备模块边界**：列表行「获取门锁密码 / 获取门禁密码」为**统一入口**；命中需审批配置 → 发起申请弹窗；未命中 → 门禁设备免审弹窗。**两条路径成功后均写入本模块 `UNLOCK_APPLY` 记录**，供申请人在「我的开锁申请 / 我的申请记录」查询；弹窗 UI 仍由门禁设备模块定义，单据生命周期由本模块定义。

**本期目标**：

- 支持从门禁设备发起申请（需审批）或直发凭证（免审）；
- 申请人在 PC Tab「我的开锁申请」/ H5 Tab「开锁审核」查看**全部**本人开锁记录（含需审批与**无需审核**），筛选项「是否需要审核」区分两类；
- 需审批：查看进度、撤回；审批通过后在详情页查看凭证（密码展示/复制、重新获取密码）；
- 免审：凭证在门禁设备弹窗内直发展示；写入申请记录供列表查询，详情可回看凭证；

## 3. 功能范围

### 3.1 本期范围

| 序号 | 功能 | 说明 |
| :---: | :--- | :--- |
| 1 | 发起（需审批） | 门禁设备列表 → 获取密码，**设备 ID 命中**需审批配置后提交申请 |
| 1b | 直发（免审） | 门禁设备列表 → 获取密码，**未命中**任何已启用配置的适用设备，确认后直发凭证并**自动创建** `approval_required=false` 记录 |
| 2 | 申请人查询 | PC：[02-完整页](../02-完整页/我的申请管理主PRD.md) Tab「我的开锁申请」；H5：[03-H5我的申请记录](../03-H5我的申请记录/我的申请记录主PRD.md) Tab「开锁审核」；「是否需要审核=否」筛出免审记录 |
| 3 | 撤回 | **仅**需审批且待审批时申请人可撤回 |
| 4 | 审批处理 | **不在本模块**——见 [03-开锁审核](../../05-其他审批/03-开锁审核/开锁审核主PRD.md) |
| 5 | 申请人查看凭证 | 详情页「凭证信息」分区：密码展示/复制、重新获取密码（见 [02查看与下发凭证字段清单](./02-操作字段清单/02查看与下发凭证字段清单.md)） |

### 3.2 不在本期范围

- 重新下发短信、凭证撤销、已使用回写（见业务规则 R31）；
- 审批配置 CRUD（见 [06-门禁开锁审批](../../06-门禁开锁审批/门禁开锁审批总索引.md)）；
- 申请详情「关联事务」及与门禁事务的强制关联（见业务规则 W00）；
- 接入平台待处理/已处理（研发已确认不做）；
- 审批人列表 UI（见 [05/03-开锁审核](../../05-其他审批/03-开锁审核/开锁审核主PRD.md)）。
