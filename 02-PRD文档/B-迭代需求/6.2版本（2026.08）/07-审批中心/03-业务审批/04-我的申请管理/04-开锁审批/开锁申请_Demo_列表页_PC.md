## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 我的申请管理 · Tab「我的开锁申请」 |
| 页面目标 | 申请人筛选、查看本人开锁记录（含需审批与免审），进入详情或撤回待审批单 |
| 菜单路径 | `工作中心 → 审批中心 → 我的申请管理 → 我的开锁申请` |
| 页面路径 | `/工作中心/审批中心/我的申请管理?tab=unlock-applies` |
| moduleId | `biz-my-applications-unlock` |
| 骨架结构 | 完整页 Tab 栏 + 筛选区 + 数据表格 + 分页 |

> **无独立菜单**：本 Tab 嵌入 [我的申请管理](../02-完整页/我的申请管理主PRD.md) 完整页；Deep link `ROUTE-IOT-APPR-01` 提交成功后默认选中本 Tab。

## 2. 查询区

### 2.1 布局说明

筛选区独立 Card，顶部工具行：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]`

**默认行**（4 列栅格）：是否需要审核、提交时间、申请状态、凭证状态。

**展开行**：设备名称、设备编码、设备类型、绑定仓库、事由、配置编号。

> **不含**申请单号筛选项（字段清单 §2.1）。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 是否需要审核 | `Select` | 全部（默认）/ 是 / 否；**否**筛选免审直发记录 |
| 提交时间 | `DateRangePicker` | 映射主表创建时间；最大跨度 90 天 |
| 申请状态 | `Select`（多选） | 待审批 / 已通过 / 已驳回 / 已撤回 / 已失效 |
| 凭证状态 | `Select`（多选） | 未生成 / 已下发 / 生成失败 / 已过期 / 已失效（被覆盖） |
| 设备名称 | `Input` | 模糊匹配 |
| 设备编码 | `Input` | 精确匹配 |
| 设备类型 | `Select` | 全部 / 挂锁门禁 / 人脸门禁 |
| 绑定仓库 | `Select` | 数据权限过滤的下拉 |
| 事由 | `Select` | 全部 / 出库 / 入库 / 移库 / 参观 / 其他 |
| 配置编号 | `Input` | 精确匹配；运维排查用 |

### 2.3 筛选交互

- 筛选为草稿态，点击「查询」或 Enter 后生效，页码重置为 1
- 点击「重置」：恢复默认并刷新
- 切换 Tab 离开再返回：保留上次查询条件

## 4. 表格

### 4.1 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 行勾选 | 不支持 |
| 列宽拖拽 | 支持 |
| 固定列 | 申请状态列左固定；操作列右固定 |
| 分页 | 默认 10 条/页，可选 10/20/50 |
| 默认排序 | 提交时间 DESC |
| 空状态 | 「暂无开锁申请」+ 「可从门禁设备发起临时开锁申请」 |
| 加载状态 | 表格 Skeleton |
| 错误状态 | Toast「加载失败，请重试」+ 重新加载 |

### 4.2 列定义

| 列名 | 内容说明 | 宽度 | 固定 |
| :--- | :--- | :--- | :---: |
| 序号 | 当前页从 1 起 | 64px | |
| 申请状态 | 状态 Tag | 110px | 左固定 |
| 凭证状态 | 文本或 Tag | 100px | |
| 设备名称 | 文本 | 140px | |
| 设备编码 | 文本 | 120px | |
| 绑定仓库 | 文本 | 120px | |
| 事由 | 枚举文本 | 80px | |
| 提交时间 | `YYYY-MM-DD HH:mm` | 160px | |
| 操作 | 行内文字操作 | 120px | 右固定 |

> **不展示列**：申请单号、设备类型、申请人、配置编号（申请人仅详情可见；配置编号可筛选/详情可见）。

### 4.3 申请状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 待审批 | 橙色（warning） |
| 已通过 | 绿色（success） |
| 已驳回 | 红色（danger） |
| 已撤回 / 已失效 | 灰色（info） |

### 4.4 行内操作

**不渲染 disabled 操作**。

| 申请状态 | 展示的操作 |
| :--- | :--- |
| 待审批 | 详情 / 撤回 |
| 已通过 | 详情 |
| 已驳回 / 已撤回 / 已失效 | 详情 |
| 已通过 + 生成失败 | 详情（含重新获取密码） |

| 操作 | 行为 |
| :--- | :--- |
| 详情 | 跳转 `/工作中心/审批中心/我的申请管理/unlock-applies/:applyNo` |
| 撤回 | 二次确认弹窗（见 §5）；仅申请人本人（R09） |
