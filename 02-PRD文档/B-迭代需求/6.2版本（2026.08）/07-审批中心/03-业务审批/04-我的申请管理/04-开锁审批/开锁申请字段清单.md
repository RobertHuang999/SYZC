# 开锁申请字段清单

> **文档定位**：审批中心子类型 `UNLOCK_APPLY`（开锁申请）的字段索引入口。规则唯一定义来源 见[《开锁申请业务规则规格》](./开锁申请业务规则规格.md)；流程推演见[《门禁开锁审批-业务流程推演》](../../../06-门禁开锁审批/门禁开锁审批-业务流程推演.md)。
>
> **平台引用**：
> - 我的申请记录子类型列表字段 → 见 §2 展示规则
> - 通用审批操作（通过/驳回/撤回）→ [《通用审批处理字段清单》](../../../../🌟🌟🌟-最新基准版/B端PC/01-工作中心/01-审批中心/03-业务审批/00-通用审批操作字段清单.md)（入口为「其他审批—开锁审批」，非待处理）
>
> **系统入口（研发已确认）**：
> - **审批人**：工作中心 → 审批中心 → 其他审批 → 开锁审批（PC）；业务办理 → 其他审批 → 开锁审批（H5）（**不**进 07 待处理/已处理）
> - **申请人**：PC 我的申请管理 → Tab「我的开锁申请」；H5 我的申请记录 → Tab「开锁审核」
>
> **引用规则**：
> - 设备相关字段继承自《门禁设备字段清单》，申请中保存为快照；
> - 发起申请表单共用字段继承自《获取门锁密码字段清单》，操作增量见[操作字段清单](./02-操作字段清单/操作字段清单索引.md)。
>
> **修改原则**：字段定义变化只修改对应子清单，并同步更新本索引与修订记录。
>
> **版本**：V2.5 | 更新时间：2026-09-02

## 2. 展示与引用规则

### 2.1 申请单号（隐藏字段）

- **申请单号**为系统内部业务键，**不在列表、卡片、筛选区展示**；仅在**详情页基础信息**展示，供客服核对与 Deep link（`ROUTE-IOT-APPR-01`）定位。
- 搜索/筛选**不提供**申请单号输入项（双端申请人侧一致）。

### 2.2 列表展示

| 端 | 展示列/卡片字段（顺序） |
| :--- | :--- |
| **PC** Tab「我的开锁申请」 | 见 [02-完整页/我的申请管理字段清单](../02-完整页/我的申请管理字段清单.md) §二 |
| **H5** Tab「开锁审核」卡片 | 设备名称（主标题）、绑定仓库、凭证状态、事由、发起人、申请状态 Tag；类型标签「开锁·临时授权」 |

> PC 首页预览区不含开锁（R-MYAPP-01）；开锁仅在 PC 完整页 Tab / H5 开锁 Tab 展示。

### 2.3 PC 筛选与列表（Tab「我的开锁申请」）

> **唯一定义来源**：[02-完整页/我的申请管理字段清单](../02-完整页/我的申请管理字段清单.md) §二（列表展示 + PC 可筛选 + 筛选控件）。

### 2.4 H5 Tab「开锁审核」（我的申请记录）

> **唯一定义来源**：[03-H5我的申请记录/我的申请记录字段清单](../03-H5我的申请记录/我的申请记录字段清单.md) §2.3

| 筛选项 | UI 文案 | 说明 |
| :--- | :--- | :--- |
| 关键词 | 顶栏搜索 | 设备名称 / 设备编码 / 申请人 |
| 发起申请时间范围 | 发起日期 | 映射主表创建时间 |
| 是否需要审核 | 是否需要审核 | 全部 / 是 / 否；**否**=免审直发记录 |
| 申请状态 | 申请状态 | 单选 Pill；默认「全部」 |
| 凭证状态 | 凭证状态 | 单选 Pill；默认「全部」 |

搜索匹配：**设备名称**、**设备编码**、**申请人**（R-MYAPP-04）；**不含**申请单号。

### 2.5 详情与其他

- **详情页分区**：基础信息（含申请单号、是否需要审核、**凭证状态**、提交时间）→ 设备与位置快照 → 申请内容 → （需审批）审批配置快照 → （需审批）审批记录 → **凭证信息**。**不含**关联事务（W00）。
- **列表/卡片**：仍展示**凭证状态**字段，供筛选与进度感知；详情页展开凭证明细与操作（复制、重新获取密码）。
- **编辑约束**：申请提交后全字段只读；状态变更仅通过撤回、审批、超时失效、系统复核作废等触发。
- **敏感字段**：临时密码、手机号按角色控制展示；密码明文严禁落库和写审计日志（规则 R22、A05）。
