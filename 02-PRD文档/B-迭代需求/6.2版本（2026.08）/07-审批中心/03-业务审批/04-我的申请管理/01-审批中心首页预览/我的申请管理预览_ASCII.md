## 布局说明

| 区域 | 说明 |
| :--- | :--- |
| 卡片入口 | 「我的申请管理」位于 **业务管理审批** 卡片区；点击滚动至下方预览表或等价跳转完整页 |
| 预览表 | **仅**「我的流程申请」最近 N 条（默认 5，按发起时间倒序） |
| 预览数据范围 | **不含开锁审批**（`UNLOCK_APPLY`）；开锁见 [02-完整页](../02-完整页/我的申请管理_ASCII_PC.md) Tab「我的开锁申请」（R-MYAPP-01） |
| 预览列 | 流程类型名称、货主信息、流程状态、货物信息、发起人、发起时间、操作 |
| 预览操作 | 详情 / 重新发起 / 撤销申请（按流程状态，沿用线上） |
| 查看更多 | 跳转 [02-完整页](../02-完整页/我的申请管理_ASCII_PC.md)；默认 Tab=**我的流程申请**（R-MYAPP-05） |
