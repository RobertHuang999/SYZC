## 1. 业务背景

在审批中心首页的 **业务管理审批** 卡片区，「**我的申请管理**」卡片下方挂载**流程申请预览表**（最近 N 条）。用户点击卡片或「查看更多」进入 [02-完整页](../02-完整页/我的申请管理主PRD.md)。

> **职责边界**：本 PRD **仅**定义「我的申请管理」卡片与预览表；**不**定义审批中心首页其他卡片区（待处理/已处理、客户需求审批、其他审批等）。

## 2. 功能范围

### 2.1 本期范围

| 区域 | 说明 |
| :--- | :--- |
| 我的申请管理卡片 | 位于 **业务管理审批** 卡片区，与待处理/已处理/抄送我的等并列 |
| 预览表 | **仅**展示「我的流程申请」最近 N 条（默认 5）；不含开锁审批（R-MYAPP-01） |
| 查看更多 | 跳转 [02-完整页](../02-完整页/我的申请管理主PRD.md)；默认 Tab=我的流程申请 |

### 2.2 不在本期范围

- 审批中心首页其他卡片区（沿用线上）；
- 开锁审批预览（见 R-MYAPP-01；完整页 Tab 见 02）；
- 子类型详情字段（见 [04-开锁审批](../04-开锁审批/开锁申请主PRD.md)）。
