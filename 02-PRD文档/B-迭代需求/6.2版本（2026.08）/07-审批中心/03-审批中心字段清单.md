# 审批中心字段清单

> **文档定位**：审批中心**平台层**字段的唯一基准——通用审批任务及待办/已办/我的申请记录列表字段。各业务子类型的申请主表及列表扩展字段由 `05-子类型/` 下对应清单维护。
>
> **流程规则**：[审批中心业务规则规格](./02-审批中心业务规则规格.md)
>
> **列表与子类型扩展**：接入流程配置的子类型，待办列表 = 本节字段 + 各子类型待办展示扩展（按 `biz_type` 动态组合）。**例外**：`UNLOCK_APPLY`（开锁申请）不进待处理，走「其他审批—开锁审批」，见 [开锁申请业务规则规格](./05-子类型/01-开锁申请/开锁申请业务规则规格.md)。
>
> **版本**：V1.3 | 更新时间：2026-08-28

## 一、审批任务字段（平台持久化对象）

> 通过 `biz_type` + `业务单号` 关联各子类型申请主表。适用于**已接入流程配置**并进入「待处理/已处理」的子类型。

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 任务编号 | 系统生成 | 文本；唯一 | 系统自动 | 是 | 是（精确） | 是 | 审批待办任务唯一编号 | — |
| 业务类型 | 系统注册 | 枚举 | 系统自动 | 是 | 是（下拉） | 是 | 审批子类型标识 | 决定待办展示扩展字段集 |
| 业务类型名称 | 系统注册 | 文本 | 系统自动 | 是 | 是（下拉） | 是 | 业务类型展示名 | 与 biz_type 一一对应 |
| 业务单号 | 系统关联 | 文本 | 系统自动 | 是 | 是（精确） | 是 | 关联的业务申请单号 | 点击跳转子类型详情 |
| 审批顺序号 | 系统生成 | 整数；从 1 开始 | 系统自动 | 否 | 否 | 是 | 对应审批节点的顺序 | 与配置节点序号一致 |
| 审批对象类型 | 系统快照 | 枚举：指定人员、指定角色 | 系统自动 | 否 | 否 | 是 | 该节点按人员还是角色指定 | 来自审批节点快照 |
| 处理人 | 系统带出并快照 | 文本；姓名（账号） | 系统自动 | 是 | 是（精确） | 是 | 当前待办指定处理人 | 任务粒度为「节点 × 账号」 |
| 任务状态 | 系统维护 | 枚举：`待处理`、`已通过`、`已驳回`、`已关闭` | 系统自动 | 是 | 是（多选） | 是 | 该审批节点当前状态 | 已关闭=因撤回/超时/他人已通过而关闭 |
| 审批结果 | 审批人操作 | 枚举：`通过`、`驳回` | 条件必填 | 是 | 是（下拉） | 是 | 该节点的审批结论 | 处理完成后写入；列表仅在已办展示 |
| 审批意见 | 审批人填写 | 文本；最多 200 字 | 选填 | 否 | 否 | 是 | 审批通过或驳回时的意见 | 操作字段见[通用审批处理字段清单](./04-操作字段清单/01通用审批处理字段清单.md) |
| 提交时间 | 系统关联 | 日期时间 | 系统自动 | 是 | 是（范围） | 是 | 业务申请提交时间 | 来自关联申请主表 |
| 处理时间 | 系统生成 | 日期时间 | 系统自动 | 是 | 是（范围） | 是 | 审批人完成处理的时间 | 待处理时为空 |
