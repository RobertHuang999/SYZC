## 2. 背景与目标

SYZC 6.2 引入门禁开锁审批链路后，需要将「审批待办大厅」从单一业务场景中抽象为**全系统可复用的审批平台**。审批中心承载统一的待办/已办/抄送/我的申请入口，各业务通过 `biz_type` 注册子类型，扩展申请主表、待办展示列与后置业务，而**不**在业务模块内重复实现审批任务分发与通用审批动作。

**本期目标**：

- 提供审批中心列表入口（待处理/已处理/抄送/我的申请记录）及统一详情壳（**接入流程配置**的子类型）；
- 按配置快照生成审批任务，支持「任一人通过」「按顺序审批」；
- 提供通过、驳回、撤回等通用审批动作及审计；
- 我的申请记录首期接入开锁申请（`UNLOCK_APPLY`）；其审批处理在「其他审批—开锁审批」，**不**占用待处理。

## 3. 功能范围

### 3.1 本期范围

| 序号 | 功能 | 说明 |
| :---: | :--- | :--- |
| 1 | 待处理 | 当前用户作为指定处理人的待办任务列表 |
| 2 | 已处理 | 当前用户已完成的审批任务历史 |
| 3 | 抄送我的 | 抄送通知列表（本期可占位，规则预留） |
| 4 | 我的申请记录 | 当前用户发起的各子类型申请汇总（含开锁申请 `UNLOCK_APPLY`） |
| 5 | 审批详情壳 | 平台任务信息 + 子类型业务分区（按 `biz_type` 动态加载） |
| 6 | 通用审批动作 | 通过、驳回、撤回（子类型决定是否开放撤回） |
| 7 | 子类型注册 | 我的申请记录：开锁申请；其他审批：开锁审批（**不进**待处理） |

### 3.2 不在本期范围

- 开锁申请接入「接入流程配置」及进入待处理/已处理（研发已确认不做）；

- 各子类型申请主表 CRUD 规则与字段（见 `05-子类型/`）；
- 各子类型审批配置 CRUD（如开锁审批配置见 `06/01-审批配置`）；
- 备用审批人、自动转派（R19：本期不配置）；
- 子类型后置业务执行细节（如凭证生成、短信下发，由子类型规格定义）。

## 4. 用户与权限

权限矩阵以 [00-全局契约与RBAC权限矩阵](../00-全局契约与RBAC权限矩阵.md) 为准，平台层关键规则：

| 规则ID | 场景 | 要求 |
| :--- | :--- | :--- |
| P04 | 审批操作 | 须为当前待办指定处理人且账号启用 |
| P05 | 列表数据隔离 | 仓管：`仓库 IN User.AssignedWarehouses`；管理员：租户全量 |

子类型额外权限（如开锁申请 P03、P06、P07）由各子类型业务规则规格维护，本模块在路由与列表过滤时透传数据权限上下文。

## 5. 页面与交互

### 5.1 列表壳 + 子类型扩展

待办/已办列表由**平台字段**与**子类型待办展示扩展字段**动态组合（**不含** `UNLOCK_APPLY`）：

```
待办列表列 = 03-审批中心字段清单 §一 + 已接入流程配置子类型的待办展示扩展
```

| 页面 | 平台字段（示例） | 子类型扩展（接入流程配置类） |
| :--- | :--- | :--- |
| 待处理 | 任务编号、业务类型、业务单号、处理人、任务状态、提交时间 | 按 biz_type 动态扩展 |
| 我的申请记录 | 业务单号、业务类型、提交时间 | 开锁申请：申请状态、凭证状态、设备编码等 |

点击「业务单号」跳转子类型详情；详情页分区：**平台审批记录** → **子类型业务信息**（见各子类型字段清单）。

### 5.2 通用操作区

审批详情页底部操作区加载 [04-操作字段清单/01通用审批处理字段清单](./04-操作字段清单/01通用审批处理字段清单.md) 定义的字段；子类型可追加异常处理类操作（如凭证撤销，见子类型操作字段清单）。

## 6. 状态与流转

### 6.1 审批任务（平台）

| 状态 | 枚举 | 说明 |
| :--- | :--- | :--- |
| 待处理 | `PENDING` | 等待当前审批人处理 |
| 已通过 | `APPROVED` | 该节点审批通过（终态） |
| 已驳回 | `REJECTED` | 该节点审批驳回（终态） |
| 已关闭 | `CLOSED` | 因撤回/超时/他人已通过而关闭（终态） |

任务状态**不替代**子类型申请主状态；两者通过 `biz_type` + 业务单号关联，由子类型规则消费平台审批结果。

### 6.2 与子类型申请状态联动

平台完成审批动作后，通知子类型更新申请主状态并触发后置流程（如开锁申请审批通过后进入凭证生成）。具体状态机见各子类型业务规则规格；平台仅保证 R10–R13、R18 约束下的任务一致性。

## 7. 通用审批动作

| 动作 | 入口 | 关键规则 |
| :--- | :--- | :--- |
| 通过 | 待处理详情 | R10–R12；R18 状态条件更新 |
| 驳回 | 待处理详情 | R10、R13（驳回原因必填） |
| 撤回 | 我的申请（子类型开放时） | 关闭未处理任务；具体可用状态由子类型定义 |

操作字段定义见 [04-操作字段清单/01通用审批处理字段清单](./04-操作字段清单/01通用审批处理字段清单.md)。

## 8. 子类型注册机制

| 扩展点 | 说明 | 开锁申请示例 |
| :--- | :--- | :--- |
| `biz_type` | 子类型唯一标识 | `UNLOCK_APPLY` |
| 业务规则唯一定义来源 | `05-子类型/{序号}/` 下业务规则规格 | 开锁申请业务规则规格 |
| 申请主表字段 | 子类型字段清单 | 01开锁申请主表字段清单 |
| 待办展示扩展 | 子类型操作字段清单 | 开锁申请：**不适用**，审批人页面由 [08-开锁审核](../08-开锁审核/开锁审核主PRD.md) 维护 |
| 审批处理入口 | 按接入渠道 | 开锁申请：工作中心 → 审批中心 → 其他审批 → 开锁审批（PC）；业务办理 → 其他审批 → 开锁审批（H5） |
| 我的申请记录 | 子类型注册 | 开锁申请 `UNLOCK_APPLY` |

已注册子类型索引见 [审批中心总索引 §四](./审批中心总索引.md#四已注册子类型)。

## 9. 非功能需求

| 类别 | 要求 |
| :--- | :--- |
| 并发与幂等 | 审批动作 A02：状态条件更新，并发仅一个成功 |
| 审计 | A04：记录操作人、时间、业务键、任务前后状态 |
| 性能 | 待办/已办列表支持分页；默认按提交时间倒序 |
| 安全 | 敏感字段（如临时密码）不得写入平台审计日志 |
