# 开锁审批-发起开锁申请字段清单

> **所属板块**：审批中心 / 子类型 / 开锁申请
> **触发入口**：门禁设备列表 → 获取门锁密码（挂锁）/ 获取门禁密码（人脸）
> **展示条件**：设备命中需审批配置，或全局审批开关开启
> **主数据引用**：[门禁设备字段清单](../../../../01-物联网IOT管理/02门禁设备/门禁设备字段清单.md)
> **共用字段引用**：[获取门锁密码字段清单](../../../../01-物联网IOT管理/02门禁设备/操作字段清单/04获取门锁密码字段清单.md)
> **流程规则**：[开锁申请业务规则规格](../开锁申请业务规则规格.md)

## 0. 字段继承说明

命中需审批规则时，表单在「获取门锁密码」基础上切换为审批申请模式。以下字段**直接继承**，不在本清单重复定义：

| 继承字段 | 继承来源 | 说明 |
| :--- | :--- | :--- |
| 设备编码 | 门禁设备字段清单 | 弹窗上下文带入 |
| 设备名称 | 门禁设备字段清单 | 安全提示文本展示 |
| 事由 | 获取门锁密码字段清单 | 下拉必选 |
| 备注 | 获取门锁密码字段清单 | 选填，最多 50 字 |

人脸门禁命中审批时，共用「事由」规则；次数、有效期等人脸专属字段见《获取门禁密码字段清单》，本清单不重复定义。

## 一、审批增量字段

| 字段名称 | 字段来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 预计使用时段 | 用户填写 | 日期时间范围选择器 | 必填 | 开始时间 ≤ 结束时间；仅供审批参考，不替代凭证有效期 |
| 申请单号 | 系统生成 | 提交成功提示 | 系统自动 | 提交成功后展示；重复提交返回原单号 |
| 申请状态 | 系统生成 | 提交成功提示 | 系统自动 | 提交成功后固定展示「待审批」 |
| 凭证状态 | 系统生成 | 提交成功提示 | 系统自动 | 提交成功后固定展示「未生成」 |

---

## 二、提交后不可见字段（服务端写入）

| 字段名称 | 字段来源 | 说明 |
| :--- | :--- | :--- |
| 请求幂等键 | 系统生成 | 60 秒防重复提交；重复请求返回原申请结果 |
| 设备与位置快照 | 系统带出并快照 | 固化提交时设备绑定仓库/库房/分区/具体位置 |
| 审批配置快照 | 系统匹配并快照 | 固化配置编号、版本、审批方式、审批人 |
| 命中位置说明 | 系统计算并快照 | 多绑定合并时记录全部命中位置 |

---

## 三、与免审分支的差异

| 对比项 | 免审（原获取门锁密码） | 需审批（本清单） |
| :--- | :--- | :--- |
| 提交后 | 直接调用密码服务并展示临时密码 | 创建申请单，状态=待审批，不生成密码 |
| 增量字段 | 无 | 预计使用时段 |
| 结果展示 | 临时密码、密码有效期、短信发送结果 | 申请单号、申请状态、凭证状态 |
| 共用字段 | 事由、备注、设备上下文 | 同上 |

提交须执行角色权限、仓库数据权限、手机号绑定、同设备在途申请及请求幂等校验（规则 R05–R08）。
