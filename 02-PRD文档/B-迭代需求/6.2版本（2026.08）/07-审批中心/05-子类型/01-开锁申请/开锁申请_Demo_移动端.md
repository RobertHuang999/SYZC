## 一、入口与页面范围

| 页面 | 入口 | 说明 |
| :--- | :--- | :--- |
| 发起申请 | 门禁设备 → 获取门锁密码 / 获取门禁密码；命中需审批规则后进入申请表单 | 继承设备上下文和事由字段，仅补充预计使用时段 |
| 我的申请记录 | H5：业务办理 → 我的申请记录 → 开锁申请 | 查看本人提交的申请状态和凭证状态 |
| 申请详情 | 我的申请记录 → 选择开锁申请 | 只读展示申请快照、审批记录和凭证结果 |

> 审批人处理入口是 H5「业务办理 → 其他审批 → 开锁审批」，属于 08 审批人侧页面，不与申请人详情混用。

## 二、发起申请

1. 从门禁设备操作进入申请表单，展示设备编码、设备名称、仓库/库房/分区和具体位置快照。
2. 填写事由、备注和预计使用时段，点击「提交申请」。
3. 提交成功后展示申请单号、申请状态「待审批」和凭证状态「未生成」。
4. 重复点击提交时返回原申请单号，不产生重复申请或密码。

## 三、我的申请列表

**列表字段**：申请单号、设备名称、绑定仓库、申请状态、凭证状态、提交时间、操作。

**筛选字段**：申请单号、申请状态、凭证状态、设备名称/编码、绑定仓库、提交时间范围。

**操作规则**：

- 待审批：进入详情查看申请进度，可撤回时显示「撤回」；不显示密码。
- 已通过：进入详情查看凭证状态；凭证已下发且仍有效时显示密码卡片。
- 已驳回、已撤回、已失效、已作废：可查看审批记录和结果原因，不显示密码。

## 四、申请详情与凭证

### 4.1 固定只读分区

- 设备与位置：设备编码、设备名称、绑定仓库、库房/分区、具体位置。
- 申请内容：申请人、事由、备注、预计使用时段、提交时间。
- 审批配置快照：配置编号、版本、审批方式、审批节点。
- 审批记录：节点、处理人、结果、意见/驳回原因、处理时间。
- 凭证信息：凭证状态、密码有效期、短信发送状态及失败原因摘要。

### 4.2 审批通过后的凭证操作

当申请状态为「已通过」且凭证状态为「已下发」时：

- 申请人或授权查看人可查看临时密码并使用复制图标按钮复制；
- 页面展示密码有效起止时间，不把预计使用时段当作密码有效期；
- 短信发送失败时允许「重新下发短信」，复用原密码，不重复生成凭证；
- 密码过期、撤销或被新密码覆盖后，隐藏密码卡片并展示失效原因；
- 审批人页面仅展示凭证状态摘要，不能通过审批详情查看密码明文。

## 五、异常与反馈

| 场景 | 页面反馈 | 后续操作 |
| :--- | :--- | :--- |
| 申请提交失败 | Toast 展示服务端失败原因 | 保留已填内容，允许修正后重试 |
| 存在同设备在途申请 | 提示已有申请单号 | 进入原申请详情，不重复提交 |
| 密码生成中 | 展示加载状态和「凭证生成中」 | 禁止重复点击生成 |
| 密码生成失败 | 展示失败原因摘要 | 按权限展示受控重试入口 |
| 短信下发失败 | 展示短信失败状态 | 点击「重新下发短信」；不重新生成密码 |
| 凭证被覆盖 | 提示「设备密码已被更新，原密码已失效」 | 返回设备重新发起申请 |
