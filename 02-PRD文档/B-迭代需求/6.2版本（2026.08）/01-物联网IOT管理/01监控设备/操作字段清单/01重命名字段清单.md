# 监控设备-重命名字段清单

> **文档定位**：**三件套核心**——字段唯一定义来源；配套主 PRD（业务与页面功能）、业务规则规格（规则与状态机）。ASCII/Demo 为衍生，须引用本文件字段名，不重复定义。

> **所属板块**：监控设备
> **字段类型**：行操作输入字段
> **主数据引用**：[监控设备字段清单](../监控设备字段清单.md)
> **流程规则**：[监控设备主PRD·5.2 重命名](../监控设备主PRD.md#52-重命名)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 隐藏请求参数 | 是 | 使用设备编码作为幂等关联键，不使用列表序号 |
| 原系统内名称 | 主数据 | 弹窗只读 | 系统带出 | 用于展示修改前值和审计 |
| 系统内名称 | 用户录入 | 文本输入框 | 是 | 最多50个字，不允许空值 |
| 操作人 | 系统生成 | 不展示或只读 | 是 | 取服务端认证身份 |
| 操作时间 | 系统生成 | 不展示 | 是 | 取服务端时间 |
| 操作结果 | 系统生成 | 消息提示 | 是 | 成功更新主数据；失败保留原值 |

审计至少记录设备编码、原名称、新名称、操作人、时间、数据版本和结果；具体校验、并发和异常规则引用主PRD。
