## 1. 组件概述

| 项目 | 内容 |
| :--- | :--- |
| 组件名称 | GetLockPasswordDialog |
| 适用设备 | 挂锁门禁 |
| 触发条件 | 列表行「获取门锁密码」且 **未** 命中需审批规则 |
| 容器 | `Dialog`，宽约 480px（PC）/ BottomSheet（H5） |
| 状态机 | `form` → `success` / `error` |

## 2. 入口路由（与需审批互斥）

```typescript
// 列表行 handler · 挂锁
const needApproval = await matchUnlockApprovalConfig(device)
if (needApproval) {
  openUnlockApplySubmitDialog({ deviceType: '挂锁门禁', ...context })
  return
}
openGetLockPasswordDialog(context) // 本文档组件
```

| 匹配结果 | 打开组件 |
| :--- | :--- |
| 免审 | **GetLockPasswordDialog**（本文档） |
| 需审批 | UnlockApplySubmitDialog |

## 4. 表单字段（state=form）

| 字段 | 控件 | 必填 | 规格 |
| :--- | :--- | :---: | :--- |
| 事由 | `Select` | 是 | 出库 / 入库 / 移库 / 参观 / 其他 |
| 有效期 | `datetime-local` ×2 | 是 | 与人脸免审一致；最长 24 小时 |
| 备注 | `Textarea` | 否 | 最多 50 字 |

底部 helper：「密码将发送至您绑定的手机号；最长有效期 24 小时；超过有效期凭证自动失效」。

| 按钮 | 行为 |
| :--- | :--- |
| 取消 | 关闭弹窗 |
| 获取密码 | 主操作；loading + 60 秒防重复 |

> 需审批与免审使用同一套「有效期」字段；成功态均引导至【我的申请记录】查看密码。

---

## 5. 成功结果区（state=success）

| 字段 | 展示 |
| :--- | :--- |
| 成功文案 | 「密码已生成」 |
| 引导说明 | 请前往 **【我的申请记录】→ 开锁申请** 查看密码（弹窗内**不**展示明文） |
| 主按钮 | **前往查看** → Deep link `?tab=unlock-applies&applyNo=xxx` |
| 次按钮 | 关闭 |

> 挂锁仍后台发送短信；明文仅在「我的申请记录」详情凭证区展示。

---

## 6. 校验与阻断

| 规则 | 反馈 |
| :--- | :--- |
| 事由未选 | 字段红字 |
| 有效期超 24h / 开始≥结束 | 字段红字 |
| 未绑定手机号 | 提交阻断 + Toast |
| 短信失败 | error 态，不展示密码 |
| 60 秒重复 | 「请求过于频繁，请稍后再试」 |
