## 2. 入口路由（与需审批互斥）

```typescript
// 列表行 handler · 挂锁
const needApproval = await matchUnlockApprovalConfig(device)
if (needApproval) {
  openUnlockApplySubmitDialog({ deviceType: '挂锁门禁', ...context })
  return
}
openGetLockPasswordDialog(context) // 本文档组件
```

| 匹配结果 | 打开组件 |
| :--- | :--- |
| 免审 | **GetLockPasswordDialog**（本文档） |
| 需审批 | UnlockApplySubmitDialog |

## 4. 表单字段（state=form）

| 字段 | 控件 | 必填 | 规格 |
| :--- | :--- | :---: | :--- |
| 事由 | `Select` | 是 | 出库 / 入库 / 移库 / 参观 / 其他 |
| 备注 | `Textarea` | 否 | 最多 50 字 |

底部 helper：「密码将以短信形式发送至您绑定的手机号，请凭此密码前往设备开锁，同时可在【我的申请记录】查看凭证。」

| 按钮 | 行为 |
| :--- | :--- |
| 取消 | 关闭弹窗 |
| 获取密码 | 主操作；loading + 60 秒防重复 |

> 需审批与免审表单字段一致，挂锁均取消【有效期】的填写；成功态均引导至【我的申请记录】查看密码。

---

## 5. 成功结果区（state=success）

| 字段 | 展示 |
| :--- | :--- |
| 标题 | 「开锁凭证已生成」 |
| 引导说明 | 临时密码已短信发送至绑定手机号，请凭此密码前往设备开锁，也可点击下方按钮查看详情 |
| 结果摘要 | 申请单号 / 申请状态=已通过 / 凭证状态=已下发 |
| 主按钮 | **查看申请详情** → Deep link `?tab=unlock-applies&applyNo=xxx` |
| 次按钮 | 返回设备列表 |

> 挂锁凭证通过/免审后固定为【已下发】状态，取消有效期，无已过期状态；明文可在「我的申请记录」详情凭证区展示与复制。

---

## 6. 校验与阻断

| 规则 | 反馈 |
| :--- | :--- |
| 事由未选 | 字段红字阻断 |
| 备注超 50 字 | 字段红字阻断 |
| 未绑定手机号 | 提交阻断 + Toast |
| 设备已有在途/生效凭证 | 提交阻断 + Toast「设备已有生效中凭证/在途申请，请等待处理完成」 |
| 60 秒重复 | 「请求过于频繁，请稍后再试」 |

## 8. 免审 vs 需审批

| 对比项 | 本文档（免审） | UnlockApplySubmitDialog |
| :--- | :--- | :--- |
| 表单字段 | 事由、备注（**取消有效期**） | **相同（取消有效期）** |
| 主按钮 | 获取密码 | 提交申请 |
