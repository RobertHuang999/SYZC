## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 门禁设备（H5） |
| 页面目标 | 移动端查看门禁设备并执行维护与获取密码操作 |
| 菜单路径 | `设备管理 → 门禁设备` |
| 页面路径 | `/m/access-control-devices` |
| 骨架结构 | 搜索栏 → 筛选 Chip → 卡片列表 → 上拉加载 |

---

## 2. 搜索与筛选

| 控件 | 规格 |
| :--- | :--- |
| 搜索框 | 模糊匹配系统内名称 |
| 设备类型 | 全部 / 挂锁门禁 / 人脸门禁 |
| 设备状态 | 全部 / 在线 / 离线 |
| 仓库 | 下拉；受数据权限 |
| 绑定状态 | 全部 / 已绑定 / 未绑定 |

筛选采用 BottomSheet 或顶部 Chip 展开；确认后刷新列表。

---

## 3. 设备卡片（DeviceCard）

```tsx
// 结构示意
<Card>
  <Header: 图标(锁/脸) + 系统内名称 + StatusBadge />
  <Meta: 设备编码 · 设备类型 />
  <Location: 绑定仓库 · 具体位置 />
  <Footer: 更新时间 />
  <Actions: 重命名 | 绑定 | 数据 | 获取密码 | 移除 />
</Card>
```

| 字段 | 展示 |
| :--- | :--- |
| 图标 | 挂锁 → 🔒；人脸 → 👤 |
| 状态 | `在线` 绿色圆点 / `离线` 灰色 |
| 未绑定 | 仓库「未绑定」、位置「未设置」 |

## 4. 行操作跳转

| 操作 | 目标 |
| :--- | :--- |
| 重命名 | BottomSheet / Dialog · 见 [重命名 Demo](./门禁设备_Demo_重命名与仓库绑定.md) |
| 绑定 | BottomSheet · 仓库绑定 |
| 数据 | 全屏或 BottomSheet · [设备数据 Demo](./门禁设备_Demo_设备数据.md) |
| 获取密码 | 挂锁 → [获取门锁密码 Demo](./门禁设备_Demo_获取门锁密码.md)；人脸 → [获取门禁密码 Demo](./门禁设备_Demo_获取门禁密码.md)；需审批 → 发起开锁申请 H5 版 |
| 移除 | 确认 Dialog · [移除设备 Demo](./门禁设备_Demo_移除设备.md) |

**不含**：人脸配置（PC 专属）。
