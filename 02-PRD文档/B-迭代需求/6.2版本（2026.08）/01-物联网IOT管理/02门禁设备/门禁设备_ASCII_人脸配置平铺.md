> **版本**：V1.0 | **更新时间**：2026-08-31
> **入口**：门禁设备列表 → 人脸行 →「人脸配置」
> **容器类型**：当前页 Drawer/平铺面板（**不跳转**）
> **字段清单**：[06人脸配置入口字段清单](./操作字段清单/06人脸配置入口字段清单.md)

> **移动端**：不纳入本模块移动端范围。

## 2. 授权 Switch 二次确认

```text

         |                                                              |

```

---

## 3. 空状态 — 无可分配人员

```text
+-- 人脸管理 — 人脸-FACE1 ───────────────────────────────────────────── [ x ] --+
|                                                                                |
|                         暂无符合条件的人员                                      |
|                                                                                |
|              未找到可分配的用户，前往管理页面 ❯                                  |
|                                                                                |
+--------------------------------------------------------------------------------+
```

> 仅空状态链接可跳转至「物联网IOT管理 → 人脸配置」管理页，并携带当前设备上下文。

---

## 4. 下发失败

Toast：「授权下发失败，请检查门禁设备网络」；Switch 自动回滚。
