## 0. 入口分流

```text
  列表行 [获取门锁密码]
           |
           v
      +----+----+
      | 匹配审批 |
      +----+----+
           |
     +-----+-----+
     |           |
  未命中        命中
  (免审)      (需审批)
     |           |
     v           v
  本文档      发起开锁申请 Modal
  §1~§3      (无「获取密码」直发)
```

| 分支 | 条件 | 文档 |
| :--- | :--- | :--- |
| **免审** | 未命中需审批配置 | **本文档** |
| **需审批** | 命中配置或全局审批开关 | [发起申请页 §1](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_ASCII_发起申请页.md) |

## 1. 表单弹窗 — 填写事由

```text
         +-- 获取门锁密码 ────────────────────────────────────── [ x ] --+
         |                                                              |
         |  🔒 挂锁-LK02（LK-2024-0082）                                  |
         |  华东一号仓 · A库1区东门                                        |
         |  ────────────────────────────────────────────────────────────  |
         |                                                              |
         |  * 事由:   [ 出库              v ]                            |
         |    备注:   [ 选填，最多50字________________ ]                  |
         |                                                              |
         |    💡 密码将发送至绑定手机号，请凭此密码前往设备开锁                 |
         |                                                              |
         |                              [ 取消 ]  [ 获取密码 ]            |
         +--------------------------------------------------------------+
```

> **与需审批差异**：主按钮为「获取密码」而非「提交申请」；表单字段与需审批一致（挂锁均取消有效期填写）。

## 2. 提交成功 — 引导至我的申请记录

```text
         +-- 获取门锁密码 ────────────────────────────────────── [ x ] --+
         |                                                              |
         |  开锁凭证已生成                                                |
         |                                                              |
         |  临时密码已短信发送至绑定手机号，请凭此密码前往设备开锁，也可点击下方按钮查看详情。|
         |                                                              |
         |  申请单号  UA20260831xxx    申请状态  已通过    凭证状态  已下发 |
         |                                                              |
         |                              [ 返回设备列表 ]  [ 查看申请详情 ]            |
         +--------------------------------------------------------------+
```

> 弹窗内不展示密码明文；挂锁取消有效期，凭证固定为「已下发」状态（无已过期状态；同设备后续再次申请执行阻止流程）。

## 3. 失败态

```text
         +-- 获取门锁密码 ────────────────────────────────────── [ x ] --+
         |  ❌ 密码发送失败，请稍后重试或联系管理员                          |
         |                              [ 关闭 ]                          |
         +--------------------------------------------------------------+
```

| 场景 | 提示 |
| :--- | :--- |
| 未绑定手机号 | 「当前登录账号未绑定手机号，无法获取开锁密码」 |
| 60 秒内重复 | 「请求过于频繁，请稍后再试」 |
| 设备已有在途申请/生效凭证 | Toast「设备已有生效中凭证/在途申请，请等待处理完成」 |
| 无权限 | Toast「无获取门锁密码权限」 |

## 4. 免审 vs 需审批对照（挂锁）

| 对比项 | 免审（本文档） | 需审批 |
| :--- | :--- | :--- |
| 触发 | 未命中审批配置 | 命中审批配置 |
| 表单字段 | 事由、备注（**取消有效期**） | **与免审相同（取消有效期）** |
| 主按钮 | 获取密码 | 提交申请 |
| 提交后 | 凭证固定「已下发」，短信通知开锁 | 申请单待审批，凭证「未生成」 |
| 文档 | 本文档 | [发起申请页 §1](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_ASCII_发起申请页.md) |
