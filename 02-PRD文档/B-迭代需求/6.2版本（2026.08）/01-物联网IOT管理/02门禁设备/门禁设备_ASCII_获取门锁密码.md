> **版本**：V1.1 | **更新时间**：2026-08-31

> **容器类型**：Modal 弹窗（宽约 480px）
> **字段清单**：[04获取门锁密码字段清单](./操作字段清单/04获取门锁密码字段清单.md)

> **需审批分支**：[07-开锁申请/发起申请页](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_ASCII_发起申请页.md) §1

## 0. 入口分流

```text
  列表行 [获取门锁密码]
           |
           v
      +----+----+
      | 匹配审批 |
      +----+----+
           |
     +-----+-----+
     |           |
  未命中        命中
  (免审)      (需审批)
     |           |
     v           v
  本文档      发起开锁申请 Modal
  §1~§3      (无「获取密码」直发)
```

| 分支 | 条件 | 文档 |
| :--- | :--- | :--- |
| **免审** | 未命中需审批配置 | **本文档** |
| **需审批** | 命中配置或全局审批开关 | [发起申请页 §1](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_ASCII_发起申请页.md) |

## 1. 表单弹窗 — 填写事由

```text
         +-- 获取门锁密码 ────────────────────────────────────── [ x ] --+
         |                                                              |
         |  🔒 挂锁-LK02（LK-2024-0082）                                  |
         |  华东一号仓 · A库1区东门                                        |
         |  ────────────────────────────────────────────────────────────  |
         |                                                              |
         |  * 事由:   [ 出库              v ]                            |
         |    备注:   [ 选填，最多50字________________ ]                  |
         |                                                              |
         |    💡 密码将发送至您绑定的手机号，有效期 3 天                     |
         |                                                              |
         |                              [ 取消 ]  [ 获取密码 ]            |
         +--------------------------------------------------------------+
```

> **与需审批差异**：无「预计使用时段」；主按钮为「获取密码」而非「提交申请」。

## 3. 失败态

```text
         +-- 获取门锁密码 ────────────────────────────────────── [ x ] --+
         |  ❌ 密码发送失败，请稍后重试或联系管理员                          |
         |                              [ 关闭 ]                          |
         +--------------------------------------------------------------+
```

| 场景 | 提示 |
| :--- | :--- |
| 未绑定手机号 | 「当前登录账号未绑定手机号，无法获取开锁密码」 |
| 60 秒内重复 | 「请求过于频繁，请稍后再试」 |
| 无权限 | Toast「无获取门锁密码权限」 |

## 4. 免审 vs 需审批对照（挂锁）

| 对比项 | 免审（本文档） | 需审批 |
| :--- | :--- | :--- |
| 触发 | 未命中审批配置 | 命中审批配置 |
| 表单字段 | 事由、备注 | 事由、备注、**预计使用时段** |
| 主按钮 | 获取密码 | 提交申请 |
| 提交后 | 直接展示密码 + 短信 | 申请单待审批，不生成密码 |
| 文档 | 本文档 | [发起申请页 §1](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_ASCII_发起申请页.md) |
