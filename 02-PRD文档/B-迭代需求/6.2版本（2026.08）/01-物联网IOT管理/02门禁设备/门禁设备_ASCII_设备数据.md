## 交互规则

| 规则 | 说明 |
| :--- | :--- |
| 默认 Tab | 事务记录 |
| 数据范围 | 仅当前设备（device_code 唯一参数） |
| 只读 | 无增删改；无预警处置按钮 |
| 独立加载 | 两 Tab 接口独立；单 Tab 失败不影响另一 Tab |
| 设备已移除 | Toast「当前设备已被移除」+ 关闭弹窗 + 刷新列表 |
