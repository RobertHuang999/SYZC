## 4. 人员列表

| 列 | 规格 |
| :--- | :--- |
| 人员姓名 | 文本 |
| 账号 | 脱敏展示 |
| 人脸状态 | 已录入 / 未录入 |
| 开锁密码 | 已录入 / 未录入 |
| 授权状态 | `Switch`；已授权排前 |
| 操作提示 | ⓘ Tooltip：「开启/关闭 用户用于开门的权限」 |

**准入过滤**（服务端）：
- 人脸状态=已录入 **或** 开锁密码=已录入；
- 禁用账号不展示；
- 人员列表按机构数据权限；授权操作按设备绑定仓库数据权限。

---

## 5. Switch 交互

1. 用户切换 Switch；
2. 弹出 `ConfirmDialog`：「确认为 {姓名} 开启/关闭 {设备名} 的开锁权限？」；
3. 确认 → API 下发/撤销凭证；
4. 成功 → 更新 Switch；失败 → 回滚 + Toast「授权下发失败，请检查门禁设备网络」。

---

## 6. 空状态

- 文案：「暂无符合条件的人员」；
- CTA：「未找到可分配的用户，前往管理页面 ❯」→ 跳转人脸配置管理页。
