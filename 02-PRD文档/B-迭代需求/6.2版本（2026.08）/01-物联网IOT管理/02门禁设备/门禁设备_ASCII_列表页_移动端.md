## 卡片字段映射

| 卡片区域 | 字段 | 说明 |
| :--- | :--- | :--- |
| 标题行 | 系统内名称 | 主标题 |
| 标题行右 | 状态 Tag | 在线 / 离线 |
| 副标题 | 设备编码 · 设备类型 | — |
| 位置行 | 绑定仓库 · 具体位置 | 未绑定显示「未绑定」 |
| 时间行 | 更新时间 | — |
| 底栏操作 | 行操作按钮 | 见下表 |

---

## 行操作（移动端）

| 设备类型 | 底栏按钮 |
| :--- | :--- |
| 挂锁门禁 | 重命名、绑定、数据、**获取密码**（→ 获取门锁密码 BottomSheet）、移除 |
| 人脸门禁 | 重命名、绑定、数据、**获取密码**（→ 获取门禁密码 BottomSheet）、移除 |

> 移动端不展示「人脸配置」入口；人脸授权管理仅在 PC 端操作。
