## 确认弹窗

```text
         +-- 提示 ──────────────────────────────────────────── [ x ] --+
         |                                                              |
         |  ⚠️ 确认移除该门禁设备？                                      |
         |                                                              |
         |  设备类型：  挂锁门禁                                         |
         |  系统内名称：挂锁-LK02                                         |
         |  设备编码：  LK-2024-0082                                      |
         |                                                              |
         |  移除后将：                                                    |
         |  · 设备从有效列表中移除                                        |
         |  · 解除订单、风险、规则及仓库绑定                               |
         |  · 人脸门禁将同步解除人脸配置授权关系                           |
         |  · 未处理风险将失效                                            |
         |                                                              |
         |  * 移除说明：[ 设备已迁移至新仓库，原位置停用________ ]        |
         |                                                              |
         |                              [ 取消 ]  [ 确认移除 ]            |
         +--------------------------------------------------------------+
```

---

## 结果反馈

| 结果 | 反馈 |
| :--- | :--- |
| 成功 | Toast「设备已移除」+ 关闭弹窗 + 列表刷新（该行消失） |
| 失败 | Toast「移除设备失败，请联系管理员」；设备保持原状态 |
| 子操作失败 | 全量回滚，同上失败提示 |
