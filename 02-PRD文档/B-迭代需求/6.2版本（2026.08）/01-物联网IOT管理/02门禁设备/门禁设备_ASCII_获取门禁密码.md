## 1. 配置弹窗 — 填写参数

```text
         +-- 获取门禁密码 ────────────────────────────────────── [ x ] --+
         |                                                              |
         |  👤 人脸-FACE1（FACE-2024-001）                               |
         |  华南二号仓 · B库主入口                                         |
         |  ────────────────────────────────────────────────────────────  |
         |                                                              |
         |  * 事由:        [ 入库                          v ]          |
         |  * 有效期:      [ 2026-08-31 14:00 ] ~ [ 2026-08-31 18:00 ]    |
         |  * 开锁次数:    [ - ]  [  3  ]  [ + ]   （1~100，默认1）       |
         |    备注:        [ 选填，最多50字________________ ]              |
         |                                                              |
         |    💡 最长 24h；超时凭证自动失效；请前往我的申请记录查看密码      |
         |                                                              |
         |                              [ 取消 ]  [ 获取密码 ]            |
         +--------------------------------------------------------------+
```

> **与需审批差异**：主按钮为「获取密码」；成功态引导至我的申请记录（弹窗内不展示明文）。

## 3. 免审 vs 需审批对照（人脸）

| 对比项 | 免审（本文档） | 需审批 |
| :--- | :--- | :--- |
| 触发 | 未命中审批配置 | 命中审批配置 |
| 表单字段 | 事由、**有效期**、开锁次数、备注 | **与免审相同** |
| 主按钮 | 获取密码 | 提交申请 |
| 提交后 | 引导至我的申请记录 | 申请单待审批，不生成密码 |
| 短信 | 均不涉及 | 均不涉及 |

---

## 4. 与挂锁差异对照

| 项目 | 挂锁 · 获取门锁密码 | 人脸 · 获取门禁密码 |
| :--- | :--- | :--- |
| 短信下发 | ✅ 必须（免审/审批通过后） | ❌ 不涉及 |
| 绑定手机号 | ✅ 免审/需审批均须（挂锁收短信） | ❌ 不要求 |
| 凭证展示 | 我的申请记录详情 | 我的申请记录详情 |
| 专属字段 | 无 | 开锁次数 |
| 字段顺序 | 事由→有效期→备注 | 事由→有效期→开锁次数→备注 |

---

## 5. 校验提示

| 场景 | 提示 |
| :--- | :--- |
| 开锁次数非 1~100 | 「开锁次数须为 1~100 的整数」 |
| 有效期超 24h | 「密码有效期最大不得超过 24 小时」 |
| 备注超 50 字 | 前端拦截 |
| 密码生成失败 | 「密码生成失败，请稍后重试或联系管理员」 |
