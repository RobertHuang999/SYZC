## 0. 入口分流

```text
  列表行 [获取门禁密码]
           |
           v
      +----+----+
      | 匹配审批 |
      +----+----+
           |
     +-----+-----+
     |           |
  未命中        命中
  (免审)      (需审批)
     |           |
     v           v
  本文档      发起开锁申请 Modal
  §1~§2      (§2 含人脸专属字段 + 预计使用时段)
```

| 分支 | 条件 | 文档 |
| :--- | :--- | :--- |
| **免审** | 未命中需审批配置 | **本文档** |
| **需审批** | 命中配置或全局审批开关 | [发起申请页 §2](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_ASCII_发起申请页.md) |

## 1. 配置弹窗 — 填写参数

```text
         +-- 获取门禁密码 ────────────────────────────────────── [ x ] --+
         |                                                              |
         |  👤 人脸-FACE1（FACE-2024-001）                               |
         |  华南二号仓 · B库主入口                                         |
         |  ────────────────────────────────────────────────────────────  |
         |                                                              |
         |  * 事由:        [ 入库                          v ]          |
         |  * 开锁次数:    [ - ]  [  3  ]  [ + ]   （1~100，默认1）       |
         |  * 有效期:      [ 2026-08-31 14:00 ] ~ [ 2026-08-31 18:00 ]    |
         |    备注:        [ 选填，最多50字________________ ]              |
         |                                                              |
         |    💡 最长有效期 24 小时；密码仅在当前页面展示，请妥善保管          |
         |                                                              |
         |                              [ 取消 ]  [ 获取密码 ]            |
         +--------------------------------------------------------------+
```

> **与需审批差异**：无「预计使用时段」；主按钮为「获取密码」；提交后直接展示密码卡片。

```text
         +-- 临时开锁密码 ────────────────────────────────────── [ x ] --+
         |                                                              |
         |  ┌────────────────────────────────────────────────────────┐  |
         |  │              临时开锁密码                               │  |
         |  │                   8 5 6 7 7 8                            │  |
         |  │  开锁次数：3 次    剩余次数：3 次                          │  |
         |  │  有效期：2026-08-31 14:00 ~ 2026-08-31 18:00             │  |
         |  │              [ 复制密码 ]                                │  |
         |  └────────────────────────────────────────────────────────┘  |
         |                              [ 关闭 ]                          |
         +--------------------------------------------------------------+
```

> 6 位系统唯一数字密码；**不发送短信**；关闭后不保留明文。

## 3. 免审 vs 需审批对照（人脸）

| 对比项 | 免审（本文档） | 需审批 |
| :--- | :--- | :--- |
| 触发 | 未命中审批配置 | 命中审批配置 |
| 表单字段 | 事由、开锁次数、有效期、备注 | 同上 + **预计使用时段** |
| 主按钮 | 获取密码 | 提交申请 |
| 提交后 | 直接展示密码卡片 | 申请单待审批，不生成密码 |
| 短信 | 均不涉及 | 均不涉及 |
| 文档 | 本文档 | [发起申请页 §2](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_ASCII_发起申请页.md) |

## 4. 与挂锁差异对照

| 项目 | 挂锁 · 获取门锁密码 | 人脸 · 获取门禁密码 |
| :--- | :--- | :--- |
| 短信下发 | ✅ 必须（免审/审批通过后） | ❌ 不涉及 |
| 绑定手机号 | ✅ 免审/需审批均须（挂锁收短信） | ❌ 不要求 |
| 凭证展示 | 页面 + 短信 | **仅页面** + 复制 |
| 专属字段 | 无 | 开锁次数、有效期 |

---

## 5. 校验提示

| 场景 | 提示 |
| :--- | :--- |
| 开锁次数非 1~100 | 「开锁次数须为 1~100 的整数」 |
| 有效期超 24h | 「密码有效期最大不得超过 24 小时」 |
| 备注超 50 字 | 前端拦截 |
| 密码生成失败 | 「密码生成失败，请稍后重试或联系管理员」 |
