## 2. 页头

| 元素 | 内容 |
| :--- | :--- |
| 标题 | `设备数据 — {系统内名称}（{设备编码}）` |
| 关闭 | 右上角 × |

请求上下文：`deviceCode`（必填，隐藏参数）。

---

## 3. Tab：事务记录

- 复用门禁事务记录模块列定义（不在此重复字段）；
- 可选筛选：操作类型、时间范围；
- 表格 + 分页；
- 空态：「暂无事务记录」；
- 加载失败：Tab 内 Error + 重试按钮。

## 4. Tab：预警记录

- 只读表格；列：预警时间、预警类型、预警级别、处理状态、处理人、摘要；
- **禁止**渲染「处理」「解除」等操作按钮；
- 底部 helper：「预警处置请前往设备预警信息模块」。

## 5. 加载策略

```text
打开 Drawer
  ├─ parallel fetch: transactions(deviceCode), alerts(deviceCode)
  ├─ 默认展示 transactions Tab
  └─ 各 Tab 独立 loading / error / empty
```
