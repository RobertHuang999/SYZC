## 2. 筛选区

| 字段 | 控件 | 匹配方式 | 备注 |
| :--- | :--- | :--- | :--- |
| 设备名称 | `Input` | 模糊 | 实际查询「系统内名称」 |
| 设备类型 | `Select` | 精确 | 挂锁门禁 / 人脸门禁 |
| 设备状态 | `Select` | 精确 | 在线 / 离线 |
| 仓库 | `Select` | 精确 | 绑定仓库；受仓库数据权限限制 |

| 更新时间 | `DateRangePicker` | 范围 | — |

操作：`[重置]` 清空草稿；`[查询]` 提交筛选；Enter 等同查询。

## 4. 行操作

共用操作（所有设备类型）：

| 操作 | 行为 |
| :--- | :--- |
| 重命名 | 打开 [重命名 Modal](./门禁设备_Demo_重命名与仓库绑定.md) |
| 仓库绑定 | 打开 [仓库绑定 Modal](./门禁设备_Demo_重命名与仓库绑定.md) |
| 设备数据 | 打开 [设备数据 Drawer](./门禁设备_Demo_设备数据.md) |
| 移除设备 | 打开 [移除设备 Modal](./门禁设备_Demo_移除设备.md) |

按设备类型：

| 设备类型 | 额外操作 | 说明 |
| :--- | :--- | :--- |
| 挂锁门禁 | 获取门锁密码 | 免审 → [获取门锁密码 Dialog](./门禁设备_Demo_获取门锁密码.md)；需审批 → [发起开锁申请](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_Demo_发起申请页.md) |
| 人脸门禁 | 人脸配置 | [人脸配置平铺 Panel](./门禁设备_Demo_人脸配置平铺.md) |
| 人脸门禁 | 获取门禁密码 | 免审 → [获取门禁密码 Dialog](./门禁设备_Demo_获取门禁密码.md)；需审批 → 发起开锁申请 |

权限：无对应操作权限时隐藏按钮；后端独立校验。

**路由伪代码**（§4 行操作点击后）：

```typescript
async function onGetPassword(row: AccessDevice) {
  const needApproval = await matchUnlockApprovalConfig(row)
  if (needApproval) {
    openUnlockApplySubmitDialog(row) // 需审批 · 见 07 Demo
  } else if (row.deviceType === '挂锁门禁') {
    openGetLockPasswordDialog(row)   // 免审
  } else {
    openGetAccessPasswordDialog(row) // 免审
  }
}
```

**Mock 建议**：列表至少各备 1 条「免审设备」与「需审批设备」，便于原型切换两种弹窗（可在 Mock 字段 `needsApproval: boolean` 标记，仅原型用）。

## 6. 空态与异常

| 场景 | 反馈 |
| :--- | :--- |
| 无数据 | 表格空态「暂无门禁设备」 |
