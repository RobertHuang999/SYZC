## 1. 重命名弹窗

```text
         +-- 重命名 ────────────────────────────────────────── [ x ] --+
         |                                                              |
         |  设备编码：  LK-2024-0082（只读）                              |
         |  原名称：    挂锁-LK02（只读）                                  |
         |                                                              |
         |  * 系统内名称：[ 挂锁-LK02-东门________________ ]  ≤50字       |
         |                                                              |
         |                              [ 取消 ]  [ 保存 ]                |
         +--------------------------------------------------------------+
```

---

## 2. 仓库绑定弹窗

```text
         +-- 仓库绑定 ──────────────────────────────────────── [ x ] --+
         |                                                              |
         |  设备：挂锁-LK02（LK-2024-0082）                               |
         |  ────────────────────────────────────────────────────────────  |
         |                                                              |
         |  绑定仓库：  [ 华东一号仓              v ]  （单选，可清空）     |
         |  绑定库房：  [ A库, B库                v ]  （多选，归属仓库）   |
         |  绑定分区：  [ A1区, A2区              v ]  （多选，归属库房）   |
         |  具体位置：  [ A库1区东门________________ ]  ≤50字               |
         |                                                              |
         |  已选位置预览：                                                 |
         |  · 华东一号仓 / A库 / A1区                                       |
         |  · 华东一号仓 / B库 / —                                         |
         |                                                              |
         |                              [ 取消 ]  [ 保存 ]                |
         +--------------------------------------------------------------+
```

---

## 3. 阻断提示

| 场景 | 提示 |
| :--- | :--- |
| 名称空或超 50 字 | 字段校验 |
| 设备已绑定有效订单 | 「该设备已绑定有效订单，请先解绑后再修改。」 |
| 库房不归属所选仓库 | 「所选库房必须归属于绑定仓库」 |
| 并发冲突 | 「设备信息已被他人修改，请刷新后重试」 |
