# 门禁设备_Demo_获取门禁密码

> **文档定位**：AI 生成「获取门禁密码」弹窗前端原型的输入文档（人脸门禁 · **免审**分支）。
> **字段定义**：[05获取门禁密码字段清单](./操作字段清单/05获取门禁密码字段清单.md)
> **线框参考**：[门禁设备_ASCII_获取门禁密码](./门禁设备_ASCII_获取门禁密码.md)
> **需审批分支**：[开锁申请_Demo_发起申请页](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/开锁申请_Demo_发起申请页.md)
> **业务规则**：[门禁设备业务规则规格](./门禁设备业务规则规格.md) §〇、R03、R07
> **版本**：V1.2 | 2026-08-31

> **⚠️ 系统设计约束**：人脸门禁凭证**不下发短信**，仅在页面临时密码卡片展示并提供复制。

---

## 1. 组件概述

| 项目 | 内容 |
| :--- | :--- |
| 组件名称 | GetAccessPasswordDialog |
| 适用设备 | 人脸门禁 |
| 触发条件 | 列表行「获取门禁密码」且 **未** 命中需审批 |
| 容器 | 配置 `Dialog` → 结果 `Dialog`（或同 Dialog 切换） |
| 状态机 | `form` → `credential-card` / `error` |
| 短信 | **不调用**；UI **不渲染**短信相关字段 |

---

## 2. 入口路由（与需审批互斥）

```typescript
const needApproval = await matchUnlockApprovalConfig(device)
if (needApproval) {
  openUnlockApplySubmitDialog({ deviceType: '人脸门禁', ...context })
  return
}
openGetAccessPasswordDialog(context) // 本文档组件
```

| 匹配结果 | 打开组件 |
| :--- | :--- |
| 免审 | **GetAccessPasswordDialog**（本文档） |
| 需审批 | UnlockApplySubmitDialog（含开锁次数、有效期 + 预计使用时段） |

---

## 3. 配置表单（state=form）

| 字段 | 控件 | 必填 | 规格 |
| :--- | :--- | :---: | :--- |
| 事由 | `Select` | 是 | 出库 / 入库 / 移库 / 参观 / 其他 |
| 开锁次数 | `InputNumber` + Stepper | 是 | 1~100 整数，默认 1 |
| 有效期 | `DateTimeRangePicker` | 是 | 开始默认当前；跨度 ≤ 24h |
| 备注 | `Textarea` | 否 | 最多 50 字 |

底部 helper：「最长有效期 24 小时；密码仅在当前页面展示，请妥善保管」。

| 按钮 | 行为 |
| :--- | :--- |
| 取消 | 关闭 |
| 获取密码 | 主操作；loading + 60 秒防重复 |

> **不含**「预计使用时段」— 该字段仅在需审批分支出现。

---

## 4. 临时密码卡片（state=credential-card）

| 元素 | 规格 |
| :--- | :--- |
| 密码展示 | 6 位数字，大号等宽字体 |
| 开锁次数 | 配置次数 / 剩余次数 |
| 有效期 | 起止 DateTime |
| 复制按钮 | Toast「已复制」 |
| 关闭 | 清除内存明文 |

**禁止渲染**：短信发送状态、重新下发短信、绑定手机号提示。

---

## 5. 校验

| 规则 | 反馈 |
| :--- | :--- |
| 事由空 | 字段错误 |
| 次数 <1 或 >100 | 「开锁次数须为 1~100 的整数」 |
| 结束 - 开始 > 24h | 「密码有效期最大不得超过 24 小时」 |
| 密码服务失败 | error 态 |

## 7. 免审 vs 需审批

| 对比项 | 本文档（免审） | UnlockApplySubmitDialog |
| :--- | :--- | :--- |
