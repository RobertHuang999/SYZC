## 2. WarehouseBindDialog

| 项目 | 内容 |
| :--- | :--- |
| 组件 | `WarehouseBindDialog` |
| 触发 | 行操作「仓库绑定」 |

| 字段 | 控件 | 必填 | 规则 |
| :--- | :--- | :---: | :--- |
| 绑定仓库 | `Select` 单选 | 否 | 最多 1 个；变更时级联清空下级 |
| 绑定库房 | `Select` 多选 | 否 | 须归属绑定仓库 |
| 绑定分区 | `Select` 多选 | 否 | 须归属所选库房 |
| 具体位置 | `Input` | 否 | ≤50 字 |
| 已选位置预览 | 只读列表 | — | 仓库/库房/分区层级展示 |

**级联**：仓库变更 → 清空库房、分区；库房变更 → 清空无效分区。

**保存校验**：
- 有效订单绑定 → 阻断；
- 层级归属；
- 版本号/乐观锁。
