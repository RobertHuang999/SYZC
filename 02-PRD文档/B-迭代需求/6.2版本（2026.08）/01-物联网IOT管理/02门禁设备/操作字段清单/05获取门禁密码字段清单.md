# 门禁设备-获取门禁密码字段清单

> **所属板块**：门禁设备
> **适用设备**：人脸门禁
> **主数据引用**：[门禁设备字段清单](../门禁设备字段清单.md)
> **流程规则**：[门禁设备主PRD·5.5.3 人脸门禁获取门禁密码](../门禁设备主PRD.md)
> **下发通道**：[业务规则规格 §〇](../门禁设备业务规则规格.md) — **人脸不涉及短信**，凭证仅页面展示与复制

> **流程分支**：列表行「获取门禁密码」→ 匹配审批配置 → **免审**走本清单；**需审批**走 [01发起开锁申请字段清单](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/02-操作字段清单/01发起开锁申请字段清单.md)（表单字段与免审一致）。

**字段顺序（自上而下）**：事由 → **有效期** → 开锁次数 → 备注

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 弹窗上下文 | 是 | 使用设备编码关联请求和审计 |
| 设备名称 | 主数据 | 安全提示文本 | 系统带出 | 展示当前人脸门禁设备 |
| 事由 | 用户选择 | 下拉框 | 是 | 出库、入库、移库、参观、其他 |
| 有效期 | 用户选择 | 日期时间范围 | 是 | 开始时间默认当前时间，最长24小时 |
| 开锁次数 | 用户录入 | 数字输入/步进器 | 是 | 1~100次整数，默认1 |
| 备注 | 用户录入 | 文本域 | 选填 | 最多50个字 |
| 临时开锁密码 | 密码服务 | 不在弹窗展示 | 接口返回 | 免审提交后引导至【我的申请记录】·开锁申请查看与复制 |
| 凭证生成结果 | 密码服务 | 结果提示 | 是 | 记录成功、失败或超时；**不含短信字段** |
| 操作审计日志 | 系统生成 | 不展示 | 是 | 记录设备、事由、次数、有效期、结果和时间 |
| 开锁记录 | 系统生成 | 不展示 | 是 | 成功后创建 `approval_required=false` 的 `UNLOCK_APPLY` 记录；同步「获取密码成功」门禁事务；申请人可在我的申请记录回看 |

提交需执行角色权限、设备类型、参数范围和60秒防重复提交校验。**不要求**绑定手机号；**不调用**短信服务。
