# 门禁设备-获取门锁密码字段清单

> **所属板块**：门禁设备
> **适用设备**：挂锁门禁
> **主数据引用**：[门禁设备字段清单](../门禁设备字段清单.md)
> **流程规则**：[门禁设备主PRD·5.5.2 挂锁门禁获取门锁密码](../门禁设备主PRD.md)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 弹窗上下文 | 是 | 使用设备编码关联请求和审计 |
| 设备名称 | 主数据 | 安全提示文本 | 系统带出 | 展示当前挂锁设备标识 |
| 事由 | 用户选择 | 下拉框 | 是 | 出库、入库、移库、参观、其他 |
| 备注 | 用户录入 | 文本域 | 选填 | 最多50个字 |
| 临时密码 | 密码服务 | 密码展示弹窗 | 接口返回 | 短信发送成功时展示；关闭后不留存明文 |
| 密码有效期 | 系统生成 | 密码展示弹窗 | 系统生成 | 当前规则为3天 |
| 短信发送结果 | 短信服务 | 结果提示 | 是 | 记录成功、失败或超时，不记录密码明文 |
| 操作审计日志 | 系统生成 | 不展示 | 是 | 记录设备、事由、备注、结果和时间 |

提交需执行角色权限校验和60秒防重复提交；密码明文不得进入审计日志或数据库日志。
