# 门禁设备-获取门锁密码字段清单

> **所属板块**：门禁设备
> **适用设备**：挂锁门禁
> **主数据引用**：[门禁设备字段清单](../门禁设备字段清单.md)
> **流程规则**：[门禁设备主PRD·5.5.2 挂锁门禁获取门锁密码](../门禁设备主PRD.md)
> **下发通道**：[业务规则规格 §〇](../门禁设备业务规则规格.md) — **挂锁须短信下发**至绑定手机号

> **流程分支**：列表行「获取门锁密码」→ 匹配审批配置 → **免审**走本清单直发密码；**需审批**走 [01发起开锁申请字段清单](../../07-审批中心/03-业务审批/04-我的申请管理/04-开锁审批/02-操作字段清单/01发起开锁申请字段清单.md)（表单字段与免审一致）。

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 弹窗上下文 | 是 | 使用设备编码关联请求和审计 |
| 设备名称 | 主数据 | 安全提示文本 | 系统带出 | 展示当前挂锁设备标识 |
| 事由 | 用户选择 | 下拉框 | 是 | 出库、入库、移库、参观、其他 |
| 有效期 | 用户选择 | 日期时间范围 | 是 | 开始时间默认当前时间，最长 24 小时；与人脸门禁免审一致 |
| 备注 | 用户录入 | 文本域 | 选填 | 最多50个字 |
| 临时密码 | 密码服务 | 不在弹窗展示 | 接口返回 | 免审提交后引导至【我的申请记录】·开锁申请查看 |
| 密码有效期 | 用户选择 | 凭证字段 | 是 | 与表单「有效期」一致；超过结束时间凭证自动变为已过期 |
| 短信发送结果 | 短信服务 | 结果提示 | 是 | 记录成功、失败或超时，不记录密码明文 |
| 操作审计日志 | 系统生成 | 不展示 | 是 | 记录设备、事由、备注、结果和时间 |
| 开锁记录 | 系统生成 | 不展示 | 是 | 成功后创建 `approval_required=false` 的 `UNLOCK_APPLY` 记录；同步「获取密码成功」门禁事务；申请人可在我的申请记录回看 |

提交需执行角色权限校验和60秒防重复提交；密码明文不得进入审计日志或数据库日志。
