# GPS设备-移除设备字段清单

> **所属板块**：GPS设备
> **主数据引用**：[GPS设备字段清单](../GPS设备字段清单.md)
> **流程规则**：继承[监控设备移除设备字段清单](../../01监控设备/操作字段清单/06移除设备字段清单.md)及[监控设备主PRD·5.7](../../01监控设备/监控设备主PRD.md#57-移除设备)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 确认弹窗上下文 | 是 | 使用设备编码作为幂等关联键 |
| 车辆信息 | 主数据 | 确认弹窗只读 | 系统带出 | 展示当前车辆关联信息 |

| 移除说明 | 用户录入 | 文本域 | 是 | 记录本次移除原因 |
| 定位数据关联处理结果 | 定位模块 | 结果明细 | 是 | 记录设备从有效列表移除及历史快照处理结果 |

| 操作审计日志 | 系统生成 | 不展示 | 是 | 记录操作前后快照、操作人、时间和结果 |
