## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 押品预警信息详情 |
| 页面目标 | 只读查看单条押品预警事实，并按类型跳转处置 |
| 菜单路径 | `预警信息 → 押品预警信息 → 详情` |
| 页面路径 | `/预警信息/押品预警信息/详情/:id` |
| 骨架结构 | 页头识别区（Card）→ 基本信息 → 预警事实 [→ 穿透信息] [→ 处置信息/无效说明] |

> **6.2 Demo 不展示「业务熔断状态」**；是否公示不在详情展示，用页头「公示风险」控制（C12）。
> **无页头副标题**（与列表页区分）。

## 2. DetailSection 布局规范（⚠️ 生成必遵）

与 dev 共用组件 `@/shared/components/DetailSection` + `index.css`：

| 层级 | 实现 |
| :--- | :--- |
| 分区 | `DetailSection`：标题 + 内容区 Card |
| 内容区 | `detail-section-content`：**4 列 CSS Grid**（≤1100px → 3 列），`gap: 22px 28px` |
| 单字段 | `DetailField`：**label 在上、value 在下**（`flex-direction: column; gap: 6px`） |
| label 样式 | 13px、`#86909c`（`detail-field-label`） |
| value 样式 | 14px、`#1d2129`（`detail-field-value`） |

```text
┌─ DetailSection: 基本信息 ─────────────────────────────────────────────┐
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   ← 4列 grid         │
│  │预警订单   │ │订单类型  │ │预警类型  │ │预警等级  │                       │
│  │PO2026…  │ │抵/质押   │ │抵质押率…│ │● L4 …  │   ← 上名下达           │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘                       │
└────────────────────────────────────────────────────────────────────────┘
```

**禁止**：ElDescriptions 横向「左 label 右 value」、或 `el-form` 一行两列的表单行布局。

## 3. 页头识别区

```text
{预警类型} · {预警订单}   [ {WarningStatusBadge} ]     [ ← 返回 ]  [ 解除预警* / 查看设备事件** / 公示风险*** ]
```

容器：`rounded-xl border bg-card p-4`，`lg:flex-row` 左右布局。

### 3.1 按钮规格

| 按钮 | variant | 图标 | 行为 |
| :--- | :--- | :--- | :--- |
| 返回 | outline | ArrowLeft | Link → `/预警信息/押品预警信息` |
| 解除预警 | default | — | 跳转抵质押订单信息页（R31/P04） |
| 查看设备事件 | secondary | — | Link → `/预警信息/设备预警信息/详情/:id`（P05） |
| 公示风险 | default | — | 打开 `PublishConfirmDialog`（C12） |

### 3.2 页头动作矩阵（`getDetailHeaderActions`）

| 状态 | 类型 | 页头动作 |
| :--- | :--- | :--- |
| 未处理（有效） | 商业 6 类 | 返回 / 解除预警 |
| 未处理（有效） | 物联穿透 | 返回 / 查看设备事件 |
| 已处理（有效） | 任意 | 返回 / 公示风险（未公示时） |
| 未处理（无效） | 任意 | 返回 |

## 4. 基本信息卡片（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| 预警订单 | 订单号 |
| 订单类型 | 抵/质押 / 监管（第四章订单快照） |
| 预警类型 | 7 类之一 |
| 预警等级 | `SeverityLevelDisplay`：色块圆点 + `{severityCode} {severityName}` |
| 预警来源 | 订单配置触发 / 物联穿透 / 历史 |
| 规则名称 | 触发快照（穿透类为设备规则名） |

## 5. 预警事实卡片

| 字段 | 展示规格 |
| :--- | :--- |
| 预警内容 | 主 PRD 第3.4节模板全文（可跨列） |
| 预警时间 | 完整秒级时间 |
| 预警抓拍图 | `available` → link 按钮「查看触发抓拍大图」；`failed` → 「抓拍失败」；`none` → 「无抓拍图」 |
| 触发快照 | 商业类：LTV/跌幅/配置版本等 |
