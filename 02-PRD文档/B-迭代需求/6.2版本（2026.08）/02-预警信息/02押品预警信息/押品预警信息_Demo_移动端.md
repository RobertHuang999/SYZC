> **字段定义**：见《[押品预警信息字段清单](./押品预警信息字段清单.md)》，本文件只写页面呈现规则，严禁重复定义。
> **动作与规则**：见《[押品预警信息业务规则规格](./押品预警信息业务规则规格.md)》第五至四章；R23、R31、C12。
> **线框参考**：[押品预警信息_ASCII_移动端](./押品预警信息_ASCII_移动端.md)
> **PC 对照**：[列表页 Demo](./押品预警信息_Demo_列表页.md) · [详情页 Demo](./押品预警信息_Demo_详情页.md)

## 0. 移动端与 PC 差异摘要

| 维度 | PC Demo | 移动端 Demo（本文件） |
| :--- | :--- | :--- |
| 菜单 | 预警信息 → 押品预警信息 | **项目监管 → 预警管理 → 订单预警** |
| 列表 | 宽表 + 行内操作 | **卡片列表** + 文本链动作 |
| 筛选 | 表单平铺 | **顶部胶囊** + 筛选抽屉 |
| 详情 | 整页多分区 | **页头摘要灰框** + 折叠手风琴 |
| 商业类解除 | 跳转抵质押订单 | **同 R31**（不在本模块弹窗解除） |
| 穿透类 | 跳转 02/01 | **看设备事件 ▸**（P05） |
| 公示 | 批量公示 + 单条 | **同 C12**（批量勾选模式 + 确认弹窗） |
| 导出 | ✅ F04 | ❌ **不提供** |
| 底栏 | — | 🚫 **无固定悬浮底栏**（批量模式顶栏暂显确认条） |

**移动端能力范围**（COL-01~03、COL-05、COL-08）：列表/详情/抓拍；商业类解除跳转抵质押订单；穿透类跳转设备事件；已处理未公示 → 公示风险/批量公示。**无**本模块人工解除表单。

## 1. 列表页

### 1.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 订单预警（移动） |
| 菜单路径 | `项目监管 → 预警管理 → 订单预警` |

| 骨架结构 | NavBar → 搜索 + 筛选胶囊 + 批量公示 → 卡片列表 → 上拉加载 |

> **无状态 Tab 栏**：预警状态通过筛选胶囊/抽屉过滤；**默认 F01**：近 30 天 + 未处理（有效）。

### 1.2 NavBar

| 元素 | 规格 |
| :--- | :--- |
| 左侧 | `<` 返回 |
| 标题 | 订单预警 |

### 1.3 搜索与筛选区

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 搜索框 | `SearchInput` | placeholder：`订单号 / 预警内容` |
| 类型 | 胶囊 | 7 类快捷选 |
| 等级 | 胶囊 | 03/01 启用档 |
| 状态 | 胶囊 | 全部 / 未处理（有效）/ 未处理（无效）/ 已处理（有效）；**默认未处理（有效）** |
| 来源 | 胶囊 | 全部 / 订单配置触发 / 物联穿透 / 历史 |
| 更多筛选 | 文字按钮 | 打开筛选抽屉（§1.4） |
| 批量公示 | 文字按钮 | C12；无「已处理+未公示」候选时 **disabled** |

### 1.4 筛选抽屉

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 预警订单 | `Input` | 模糊匹配 |
| 预警类型 | `CheckboxGroup` | 7 类多选 |
| 预警等级 | `CheckboxGroup` | 03/01 启用档多选 |
| 预警来源 | `RadioGroup` | 全部 / 订单配置触发 / 物联穿透 / 历史 |
| 预警状态 | `CheckboxGroup` | 三种状态 |
| 是否公示 | `RadioGroup` | 全部 / 未公示 / 已公示 |
| 预警时间 | `DateRange` | 默认近 30 天；跨度 >366 天阻断（F03） |

抽屉底栏：`重置` · `确定`。

> **不展示**：业务熔断状态（6.2 UI 隐藏）。

### 1.5 卡片列表

**默认排序**：预警时间 DESC（F02）。

#### 单卡结构

```text
┌──────────────────────────────┐
│ {预警订单}        {等级色块}  │
│ {预警类型}                    │
│ ┌──────────────────────────┐ │
│ │ 来源     {预警来源}       │ │
│ │ 内容     {预警内容摘要}   │ │
│ │ 抓拍     🖼️ 有预警图     │ │
│ └──────────────────────────┘ │
│ 🕒 {预警时间}                │
│ {状态 Tag} · {公示状态可选}   │
│     解除预警 ▸ / 看设备事件 ▸  │
│     公示风险 ▸ / 详情 ▸       │
└──────────────────────────────┘
```

#### 卡片底链（与 PC 行操作一致）

| 状态 + 类型 | 展示底链 |
| :--- | :--- |
| 未处理（有效）· 商业 6 类 | **解除预警 ▸** · 详情 ▸ |
| 未处理（有效）· 穿透类 | **看设备事件 ▸** · 详情 ▸ |
| 已处理（有效）· 未公示 | **公示风险 ▸** · 详情 ▸ |
| 已处理（有效）· 已公示 | 详情 ▸ |
| 未处理（无效） | 详情 ▸ |

| 底链 | 行为 |
| :--- | :--- |
| 解除预警 ▸ | 跳转抵质押订单信息页（R31，`order_id` + `warn_id` + `return_route`） |
| 看设备事件 ▸ | 跳转 02/01 设备预警信息（P05，`device_event_id` + `warn_id`） |
| 公示风险 ▸ | 打开公示确认弹窗（§3.4） |
| 详情 ▸ | 跳转移动详情页 |

### 1.6 批量公示勾选模式（C12）

点击「批量公示」进入模式：

| 元素 | 规格 |
| :--- | :--- |
| NavBar | `< 批量公示` · 右侧 `[取消]` |
| 提示 | 「已选 N 条 · 仅已处理未公示可勾选」 |
| 卡片 | 左侧复选框；**仅**已处理（有效）+ 未公示可选 |
| 底栏 | `[ 下一步：确认公示 ]` 主按钮 |

选中后进入 §3.4 公示确认弹窗。

### 1.7 空态 / 加载

同设备预警信息移动列表：空态插图、Skeleton、上拉加载更多。

### 2.3 页头摘要灰框

| 字段 | 展示 |
| :--- | :--- |
| 状态 Tag + 预警等级 | — |
| 预警类型 · 预警来源 | 副标题 |

### 2.4 折叠手风琴

| 区块 | 展示条件 | 字段 |
| :--- | :--- | :--- |
| 触发快照 | 商业类 | LTV / 跌幅 / 配置版本 |
| 穿透信息 | 穿透类 | 触发设备、物理子类型、触发位置、关联事件编号/ID |

| 无效说明 | 未处理（无效） | 无效原因（C11） |

### 2.5 页内动作链

| 状态 | 类型 | 动作链 |
| :--- | :--- | :--- |

| 已处理（有效）· 未公示 | 任意 | 公示风险 ▸ · 返回列表 |

## 3. 弹窗与跳转

### 3.1 解除预警无权限（R31 / P04）

| 项目 | 规格 |
| :--- | :--- |
| 触发 | 解除预警跳转抵质押订单时无项目管理权限 |
| 标题 | 权限不足 |
| 内容 | 您暂无该订单对应项目的管理权限，无法跳转办理。如需处理，请联系项目经理或系统管理员开通【项目管理】菜单权限。 |
| 按钮 | `[ 我知道了 ]` |

### 3.2 穿透类误操作（R23）

Toast：「物联穿透类预警须至设备事件台账核销」

### 3.3 公示确认弹窗（C12 · 单条/批量共用）

| 项目 | 规格 |
| :--- | :--- |
| 标题 | 公示风险确认 |
| 内容 | 已选择 N 条【已处理（有效）且未公示】记录列表 + 「公示后将进入【02/04 风险公示】候选池…」 |
| 按钮 | `[ 确认公示 ]` · `[ 取消 ]` |

| 场景 | 文案 |
| :--- | :--- |
| 已公示重复 | 「该预警已公示，不可重复操作」 |
| 非已处理 | 「仅已处理（有效）预警可公示」 |

### 3.4 跨模块说明

- **解除办理**：6.2 不在押品移动端正向弹窗解除；用户经 R31 进入**抵质押订单模块**填写情况说明（R32 参考 PC 列表弹窗线框）
- **OPT-FUSE-01 出库熔断**：移动端 6.2 **不实现**
