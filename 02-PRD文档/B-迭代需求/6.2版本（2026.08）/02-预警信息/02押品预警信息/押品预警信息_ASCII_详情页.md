## 布局说明

**页头识别区**（`rounded-xl border bg-card p-4`，左右 flex）：

- 左侧：`h1` 预警类型 + 预警订单 + `WarningStatusBadge`
- 右侧：动作按钮组，按第五章动作矩阵 / 类型处置对照显隐

| 状态 | 类型 | 页头动作 |
| :--- | :--- | :--- |
| 未处理（有效） | 商业类（6 类） | 返回、解除预警* |
| 未处理（有效） | 物联穿透 | 返回、查看设备事件** |
| 已处理（有效） | 任意 | 返回、公示风险*** |
| 未处理（无效） | 任意 | 返回 |

\* 跳转对应**抵质押订单信息页**办理（R31/P04）；无权限见[列表页弹窗线框](./押品预警信息_ASCII_列表页.md#解除预警跳转无权限提示r31--p04)。  
\*\* 须 P05；无 IoT 权限隐藏入口。  
\*\*\* 且未公示（C12）；已公示不展示该按钮。

**内容分区**（`DetailSection` 卡片）：

| 层级 | 规格 |
| :--- | :--- |
| 分区容器 | 白底 Card：标题栏 `detail-section-header` + 内容区 `detail-section-content` |
| 内容区栅格 | `display: grid; grid-template-columns: repeat(4, 1fr); gap: 22px 28px` |
| 响应式 | `max-width: 1100px` 时降为 **3 列** |
| 单字段 | `DetailField`：**label 在上、value 在下**（`flex-direction: column`），每个字段占 1 个 grid 单元 |
| 跨列字段 | 预警内容、预警抓拍图、触发快照等长文本/交互字段可 `grid-column: 1 / -1` 占满整行 |

| 分区 | 字段（按 grid 单元排列） |
| :--- | :--- |
| 基本信息 | 预警订单、订单类型、预警类型、预警等级、预警来源、规则名称 |
| 预警事实 | 预警内容（跨列）、预警时间、预警抓拍图、触发快照（商业类） |
| 穿透信息 | 触发设备、物理子类型、触发位置、关联事件编号、关联事件（仅物联穿透） |
| 处置信息 | 处理时间/人、情况说明、现场照片、解除预警抓拍图（仅已处理） |
| 无效说明 | 无效原因（仅未处理无效，叠在预警事实区） |

> **本期不展示**：是否公示（第一章详情=否，用页头「公示风险」显隐）、业务熔断状态、Version、预警信息唯一标识。
