## 2. 查询区

### 2.1 布局说明

筛选 Card 容器，顶部 `WarningFilterHeader`：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]`（Enter 等同查询）

**默认行**（4 列栅格）：预警订单、预警类型、预警等级、预警来源。

**展开行**（点击「展开筛选」后显示）：预警状态、是否公示、预警时间。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 预警订单 | `Input` | 模糊匹配订单号 |
| 预警类型 | 多选下拉（Checkbox） | 7 类枚举；空选=全部 |
| 预警等级 | 多选下拉（Checkbox） | 03/01 启用档；提交 `severity_level_id`；空选=全部；展示色块+编码+名称 |
| 预警来源 | `Select` | 全部（默认）/ 订单配置触发 / 物联穿透 / 历史 |
| 预警状态 | `Select` | 全部 / 未处理（有效）/ 未处理（无效）/ 已处理（有效）；**默认「未处理（有效）」**（F01）；展开后可见 |
| 是否公示 | `Select` | 全部（默认）/ 未公示 / 已公示；展开后可见 |
| 预警时间 | 日期范围 + 快捷按钮 | 含今天/本周/本月/近30天；**默认近 30 天**（F01）；展开后可见；跨度 >366 天阻断（F03） |

### 2.3 筛选交互

- 进入页面按 F01 默认条件自动加载（未处理（有效）+ 近 30 天）
- 筛选值为草稿态，点击「查询」后生效，页码重置为 1
- 点击「重置」恢复 `DEFAULT_FILTERS`（含 F01 默认）并刷新
- 「收起筛选」隐藏预警状态/是否公示/预警时间三行
- 全量检索须至少保留一项非「全部」筛选条件

> **不展示筛选项**：业务熔断状态（6.2 UI 隐藏）。
