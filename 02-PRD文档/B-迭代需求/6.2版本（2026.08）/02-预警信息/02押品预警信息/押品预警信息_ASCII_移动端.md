# 押品预警信息 — 移动端 ASCII 线框

> **版本**：V1.1 | **更新时间**：2026-08-24
> **适用端**：App / H5 / 小程序（项目监管移动端）
> **菜单路径**：`项目监管 → 预警管理 → 订单预警`（PC 对照：`预警信息 → 押品预警信息`）
> **页面路径**：`/m/supervision/order-warnings`（列表）· `/m/supervision/order-warnings/{id}`（详情）
> **基准来源**：`03-前端原型demo/B端H5` 押品预警信息模块
> **配套文档**：[主PRD](./押品预警信息主PRD.md) · [字段清单](./押品预警信息字段清单.md) · [业务规则规格](./押品预警信息业务规则规格.md) 第四至五章、R23、R31~R32、COL-R14、C12
> **PC 线框**：[列表页](./押品预警信息_ASCII_列表页.md)（含弹窗） · [详情页](./押品预警信息_ASCII_详情页.md)

## 0. 移动端与 PC 差异摘要

| 维度 | PC 端 | 移动端（本文件） |
| :--- | :--- | :--- |
| 菜单 | 预警信息 → 押品预警信息 | 项目监管 → 预警管理 → 订单预警 |
| 列表 | 宽表 + 行内操作 | 全卡片 + 文本链动作 |
| 筛选 | 表单区平铺 | 顶部胶囊 + 筛选抽屉 |
| 详情 | 整页多分区只读表单 | 页头摘要灰框 + 折叠手风琴 |
| 商业类解除 | 跳转抵质押订单信息页 | 同 R31（**不在本模块弹窗解除**） |
| 穿透类处置 | 跳转设备预警信息详情 | 同 P05「看设备事件」 |
| 公示风险 / 批量公示 | ✅ COL-08 | ✅ COL-08（单条底链 + 列表批量模式） |
| 导出 | ✅ F04 | ❌ 6.2 移动端不提供 |
| 底栏 | — | 🚫 **无固定悬浮操作栏**（随内容滚动；批量模式顶栏暂显确认条） |

**移动端能力范围**（对齐主 PRD COL-01~03、COL-05、COL-08）：列表浏览与筛选、详情查看、抓拍预览；商业类「解除预警」跳转抵质押订单；穿透类「看设备事件」跳转 02/01（只读）；已处理（有效）且未公示 → **公示风险**（单条）/ **批量公示**（列表勾选模式）。**无**本模块人工解除表单。

**穿透类 vs 商业类**（R23）：

| 维度 | 商业类 (`ORDER_CONFIG`) | 穿透类 (`IOT_PENETRATION`) |
| :--- | :--- | :--- |
| 解除预警 | ✅ 跳转抵质押订单（R31/P04） | ❌ 不展示 |
| 看设备事件 | ❌ | ✅ 跳转 02/01（P05） |
| 自动解除 | 业务回写 R33 | COL-R14 DeviceEventReleased |

> 列表「批量公示」勾选后，或列表/详情「公示风险 ▸」触发；单条公示复用同一弹窗（仅 1 条）。PC 宽版见 [列表页 弹窗线框](./押品预警信息_ASCII_列表页.md#批量公示风险确认c12)。



| :--- | :--- | :--- |

| 非已处理公示 | C12 | 「仅已处理（有效）预警可公示」 |
| 无公示权限 | P01 | 隐藏入口或 403 |
