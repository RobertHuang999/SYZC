# 贷中风控管理 PC Demo 规格

## 页面入口

- 菜单：`02-预警信息 / 贷中风控管理`
- 路由：`/预警信息/贷中风控管理`
- 详情：`/预警信息/贷中风控管理/详情/:id`

## 列表规格

| 区域 | 展示与交互 |
| :--- | :--- |
| 筛选区 | 订单号模糊匹配、执行状态、是否可执行；查询提交 draft，重置同时清空 draft/applied 并回到第 1 页 |
| 列表区 | 序号、订单号、货主名称、押品信息、订单类型、风控模型、执行次数、预警次数、执行状态、最近执行时间、操作 |
| 操作列 | 可执行记录显示「执行」「详情」；不可执行记录保留「详情」，执行按钮禁用并提示原因 |
| 执行反馈 | 成功显示轻提示并更新异步状态；接口失败显示错误提示，数据不被误改 |
| 分页 | 支持页码和每页条数切换，切换后回到第 1 页；空结果显示「暂无数据」 |

## 验收样例

1. 修改筛选后点击「重置」，输入框、下拉框和结果集均恢复默认。
2. 点击「详情」进入执行历史，返回后不出现空白页或路由丢失。
3. 点击「执行」后出现成功提示；同一订单处于处理中时再次点击应阻断。
4. 1366x768 和 1440x900 下，宽表不覆盖分页和操作列，长文本使用省略/悬浮查看。
