## 0. 移动端能力范围

列表浏览与筛选、详情查看、抓拍预览、人工解除提交；**无**规则配置、**无**列表导出、**无**频次时间轴、**无**批量解除（V3.4 PC 专属）。

---

## 1. 列表页

```text
+----------------------------------+
| <        设备预警信息             |
+----------------------------------+
| 🔍  [ 规则名称 / 设备 / 内容     ] |
| [状态·待处置] [类型·全部] [等级·全部] [仓库·全部] |
| 更多筛选                          |
+----------------------------------+
| ┌──────────────────────────────┐ |
| │ 人体入侵               ● L5   │ |
| │ 设备图像识别预警 · 行人入侵    │ |
| │ 设备 CAM1  内容 行人入侵       │ |
| │ 08-20 13:05   待处置 · 有效   │ |
| │        解除 ▸  详情 ▸         │ |
| └──────────────────────────────┘ |
| ┌──────────────────────────────┐ |
| │ 库温告警               ● L4   │ |
| │ 08-20 14:20   待处置 · 有效   │ |
| │        详情 ▸  （无解除 R14'） │ |
| └──────────────────────────────┘ |
+----------------------------------+
```

**默认排序**：预警时间 DESC。

### 筛选抽屉

预警类型、预警等级、预警状态、所属仓库、**预警时间**（**无**触发频次）。
