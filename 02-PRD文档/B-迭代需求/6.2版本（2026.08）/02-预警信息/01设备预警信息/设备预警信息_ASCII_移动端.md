> **版本**：V1.2 | **更新时间**：2026-08-24

> **配套文档**：[主PRD](./设备预警信息主PRD.md) · [字段清单](./设备预警信息字段清单.md) · [业务规则规格](./设备预警信息业务规则规格.md) 第四至五章、R01~R15、C01~C06
> **PC 线框**：[列表页](./设备预警信息_ASCII_列表页.md) · [详情页](./设备预警信息_ASCII_详情页.md) · [解除页](./设备预警信息_ASCII_解除页.md)
> **共用容器**：频次时间轴抽屉见 [解除页 第7章](./设备预警信息_ASCII_解除页.md#7-频次时间轴抽屉解除页--详情页共用--c02)

## 0. 移动端与 PC 差异摘要

| 维度 | PC 端 | 移动端（本文件） |
| :--- | :--- | :--- |
| 列表 | 宽表 + 行内操作 | 全卡片 + 文本链动作 |
| 筛选 | 可展开筛选 Card | 搜索框 + 顶部胶囊 + 筛选抽屉 |
| 详情 | 多分区只读大表单 | 页头摘要灰框 + 折叠手风琴 |
| 解除 | 列表/详情**弹窗**两步解除 | **独立解除页** + 文末主按钮 |
| 导出 | ❌ 6.2 Demo 不提供 | ❌ 6.2 移动端不提供 |
| 写操作 | 弹窗解除 | 解除页（同 R04/R11/R14/P04） |
| 底栏 | — | 🚫 **无固定悬浮操作栏**（随内容滚动） |

**移动端能力范围**（对齐主 PRD EVT-01~04）：列表浏览与筛选、详情查看、频次时间轴、抓拍预览、人工解除提交；**无**规则配置写操作、**无**列表导出。

### 0.1 PC 与移动端字段排版差异（⚠️ 生成必遵）

| 端 | 详情/解除只读区 | 解除可填区 |
| :--- | :--- | :--- |
| **PC** | `DetailField`：**上 label 下 value**，4 列 Grid | `ReleaseMaterialForm`：Label 在上、控件在下，跨列占满 |
| **移动 H5** | `KeyValue`：**左 label（w-20）右 value** 横排 | 原生表单：Label/block 在上、Textarea/Upload 在下 |

> 移动端**不要**套用 PC 的 4 列 DetailField 栅格；PC **不要**套用 H5 的 KeyValue 横排。

### 1.3 布局说明

**NavBar**：左侧 `<` 返回首页；标题「设备预警信息」。

**卡片字段投影**（字段清单 第一章，列表展示=是）：

| 卡片区域 | 字段 | 说明 |
| :--- | :--- | :--- |
| 头部 | 规则名称、预警等级 | 等级色块 Tag + 编码 |

### 2.6 布局说明

**页头摘要灰框**（`#f8fafc` 背景）：等级 Tag + 状态；字段用 `KeyValue`（**左 label 右 value**，label 宽 `w-20` 灰色）。

**折叠手风琴**（`AccordionItem`，默认收起）：内部同样使用 `KeyValue` 横排。

| 区块 | 字段 | 字段清单 |
| :--- | :--- | :--- |
| 频次与时间 | 触发历史入口、防抖留痕 | 第一章 / 第三章 |
| 处置信息 | 处理时间/人、情况说明、现场照片、解除抓拍 | 第一章 / 第二章 |
| 规则快照 | 阈值、防抖、升级策略 | 第三章 |
| 系统审计 | Event ID、Version、数据源、创建/更新时间 | 第一章 / 第三章 |

**页内动作链**（非固定底栏）：`查看频次时间轴 ▸` · `解除预警 ▸`（条件）· `返回列表`；已处理/无效/仅自动类型按动作矩阵隐藏解除。

**抓拍**：列表缩略图 tap → 全屏预览（R13 时效签名；P05）。

## 3. 解除页

### 3.1 整页线框（人体入侵 · 累计 3 次）

```text
+----------------------------------+
| <      解除预警                   |
+----------------------------------+
| ┌──────────────────────────────┐ |
| │ 人体入侵                        │ |
| │ L5 紧急危险 · 未处理（有效）     │ |
| │                              │ |
| │ 类型      设备图像识别/行人入侵  │ |  ← 摘要：label + value 行内
| │ 仓库      一号钢材仓·B库       │ |
| │ 设备      CAM1（DEV-CAM-0001）  │ |
| │ 内容      行人入侵             │ |
| │ 首次时间  08-20 12:40:00      │ |
| └──────────────────────────────┘ |
|                                  |
| 💡 提交后将联动同位置监控即时抓拍…  |
|                                  |
| 情况说明 *                        |  ← Label 在上
| ┌──────────────────────────────┐ |
| │ 请描述现场核查与处置情况          │ |  ← Textarea 在下
| └──────────────────────────────┘ |
| 0/200                            |
|                                  |
| 现场照片                          |
| [ 拍照 / 从相册选择 ]             |
|                                  |
|         [ 确认解除 ]             |
|         取消                      |
+----------------------------------+
```

> 点击「确认解除」→ 二次确认弹窗（同 PC）→ Toast「解除成功」→ 返回列表。
> 摘要灰框为行内 label/value；表单区 Label 在上、控件在下（**非** PC DetailField 栅格）。

### 3.2 挂锁破坏场景片段

```text
| 剪杆破坏  L5 紧急危险  4次         |
| 预警内容  智能挂锁 LK11 剪杆破坏    |
| * 情况说明  [ 误报，检修专用工具… ] |
| [ 拍照 / 相册 ]  [ 挂锁现场.jpg ]  |
|         [ 确认解除 ]             |
```

### 3.3 阻断场景

| 场景 | 规则 | 移动端表现 |
| :--- | :--- | :--- |
| 仅自动类型进入解除页 | R14 | 橙色提示框「该类型预警不支持人工解除，请等待自动恢复」 |
| 情况说明为空 | R04 | Toast「请填写情况说明」 |
| 超 200 字 | R04 | Toast「情况说明不可超过 200 字」 |
| 已处理 / 无效 | R11 | 不展示解除入口 |
| 无处理权限 | P04 | 不展示「确认解除」 |
| 仓库越权 | P02 | 不可进入或阻断 |

**入口**：列表卡片「解除 ▸」、详情页「解除预警 ▸」；须 **未处理（有效）+ R14**。

**照片上传**：优先调起相机（现场场景）；格式 jpg/png/jpeg，单张≤5MB，最多 10 张（R04）。
