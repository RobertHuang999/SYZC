## 2. 查询区

### 2.1 布局说明

筛选 Card 容器，顶部 `WarningFilterHeader`：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]`（Enter 等同查询）

**默认行**（4 列栅格）：预警类型、预警等级、预警状态。

**展开行**（点击「展开筛选」后显示）：所属仓库、触发频次、首次预警时间。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 预警类型 | 多选下拉（Checkbox） | 6 大类（含常规通行与操作事务）；空选=全部 |
| 预警等级 | 多选下拉（Checkbox） | 03/01 启用档；提交 `severity_level_id`；空选=全部；展示色块+编码+名称 |
| 预警状态 | `Select` | 全部 / 未处理（有效）/ 未处理（无效）/ 已处理（有效）；**默认「未处理（有效）」** |
| 所属仓库 | `Select` | P02 数据权限过滤；默认「全部」；展开后可见 |
| 触发频次 | `Select` | 全部 / 高频（>5 次）；默认「全部」；展开后可见 |
| 首次预警时间 | 日期范围 + 快捷按钮 | 含今天/本周/本月；默认空；展开后可见 |

### 2.3 筛选交互

- 筛选值为草稿态，点击「查询」后生效，页码重置为 1
- 点击「重置」恢复 `DEFAULT_FILTERS`（含预警状态=未处理（有效））并刷新
- 「收起筛选」隐藏所属仓库/触发频次/首次预警时间三行

## 4. 表格

### 4.1 列定义

| 列名 | 内容说明 | 宽度 |
| :--- | :--- | :--- |
| 序号 | 当前页从 1 起，公式 `(page-1)*pageSize+index+1` | 64px |
| 规则名称 | 链接，点击进入详情 | 140px |
| 预警等级 | 色块圆点 + 编码 + 名称 | 100px |
| 预警类型 | 6 大类全称 | 120px |
| 预警内容/设备 | 组合摘要截断 + Tooltip 全文 | 200px |
| 抓拍 | 图标；多张时附 `(N)`；无图/失败展示 `—` | 64px |
| 预警次数 | 可点击展开频次时间轴（C02）；Count>1 橙色高亮 | 100px |
| 状态 | 状态 Badge | 100px |
| 最近时间 | 格式 `MM-DD HH:mm` | 140px |
| 操作 | 行内文字链接 | 120px |

> 首次预警时间、处理时间、处理人可在列设置展开或于详情查看。

### 4.2 状态 Badge

| 状态 | 颜色 | 备注 |
| :--- | :--- | :--- |
| 未处理（有效） | 橙色 | — |
| 已处理（有效） | 绿色 | 常规通行与操作事务简写「已处理」 |
| 未处理（无效） | 灰色 | — |

### 4.3 行内操作

| 状态 + 类型 | 展示的操作 |
| :--- | :--- |
| 未处理（有效）+ 允许人工（R14） | 解除 / 详情 |
| 未处理（有效）+ 仅自动恢复 | 详情 |
| 未处理（无效）/ 已处理 | 详情 |

| 操作 | 行为 |
| :--- | :--- |
| 解除 | 打开 `ReleaseConfirmDialog`（两步：确认 → 填写材料 → 提交） |
| 详情 | 跳转 `/预警信息/设备预警信息/详情/:id` |
| 预警次数点击 | 打开 `TriggerHistoryDrawer`（右侧抽屉） |

## 5. 解除弹窗（ReleaseConfirmDialog）

### 5.1 第一步 — 确认

| 元素 | 规格 |
| :--- | :--- |
| 标题 | 确认解除 |
| 文案 | 确认解除该轮次告警？提交后将归档整轮 {N} 次触发。 |
| 按钮 | `[取消]` `[确认并填写说明]` |

### 5.2 第二步 — 填写材料

| 元素 | 规格 |
| :--- | :--- |
| 标题 | 填写解除说明 |
| 情况说明 | Textarea，必填，≤200 字，字数计数 |
| 现场照片 | 上传按钮，jpg/png/jpeg，单张≤5MB，最多 10 张 |
| 解除抓拍 | 文案提示「提交时将联动同位置监控即时抓拍」 |
| 按钮 | `[返回确认]` `[取消]` `[提交解除]` |

**成功**：Toast「解除成功 — {规则名称}」→ 列表移除该事件。
