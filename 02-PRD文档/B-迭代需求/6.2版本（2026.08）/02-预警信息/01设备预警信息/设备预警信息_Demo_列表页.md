# 设备预警信息_Demo_列表页

> **文档定位**：AI 生成「设备预警信息列表」前端原型的输入文档。
> **字段定义**：见《[设备预警信息字段清单](./设备预警信息字段清单.md)》第一章。
> **线框参考**：[设备预警信息_ASCII_列表页](./设备预警信息_ASCII_列表页.md)
> **版本**：V1.3 | 2026-09-08

---

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 设备预警信息列表 |
| 页面目标 | 查看设备侧预警流水，筛选后进入详情/解除；支持批量解除 |
| 页面路径 | `/预警信息/设备预警信息` |
| 骨架结构 | 页头标题 + 筛选 Card + 批量工具条 + 数据表格 + 分页 |

---

## 2. 查询区

**默认行**：预警类型、预警等级、预警状态。

**展开行**：所属仓库、预警时间（**无**触发频次）。

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 预警类型 | `Cascader / WarningTypeCascadeSelect`（级联多选） | 6 大类（含常规通行与操作事务）及具体子类型级联多选，支持大类全选/半选与子类型精确检索；提交 `warningTypes` 与 `subTypes` |
| 预警等级 | 多选下拉 | 03/01 启用档 |
| 预警状态 | Select | 默认「待处置 · 有效」 |
| 所属仓库 | Select | P02 过滤 |
| 预警时间 | 日期范围 + 快捷 | 今天/本周/本月 |

---

## 3. 批量工具条

| 元素 | 规格 |
| :--- | :--- |
| 已选计数 | `已选 {N} 条` |
| 批量解除 | 未选中或选中含不可解除项时 disabled；点击打开 `BatchReleaseDialog` |

**复选框规则**：仅 `OPEN_VALID` + `disposition_mode=ACTION_REQUIRED` 可选；表头全选当前页可选项。

---

## 4. 表格

| 列名 | 内容说明 | 宽度 |
| :--- | :--- | :--- |
| 复选框 | 行首，R14' 门控 | 48px |
| 序号 | 当前页序号 | 64px |
| 规则名称 | 链接 → 详情 | 140px |
| 预警等级 | 色块 + 编码 + 名称 | 100px |
| 预警类型 | 6 大类 | 120px |
| 预警内容/设备 | 摘要 + Tooltip | 200px |
| 抓拍 | 图标或 `—` | 64px |
| 预警时间 | `MM-DD HH:mm` | 140px |
| 状态 | Badge | 100px |
| 操作 | 解除 / 详情 | 120px |

**默认排序**：预警时间 DESC。

### 行内操作

| 状态 + 类型 | 操作 |
| :--- | :--- |
| 待处置 · 有效 + R14' | 解除 / 详情 |
| 待处置 · 有效 + 仅自动 | 详情 |
| 已结案 / 已作废 | 详情 |

---

## 5. 解除弹窗

### 单条 ReleaseConfirmDialog

- 确认文案：「确认解除该条告警？提交后将归档本条记录。」
- 材料步：情况说明（必填 ≤200 字）、现场照片（选填）
- 成功：Toast「解除成功 — {规则名称}」

### 批量 BatchReleaseDialog

- 确认文案：「确认批量解除已选 {N} 条告警？」
- 统一情况说明 + 可选现场照片
- 成功：Toast「成功 {M} 条，失败 {K} 条」
