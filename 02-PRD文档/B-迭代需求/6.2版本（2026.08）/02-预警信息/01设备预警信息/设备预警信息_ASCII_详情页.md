## 布局说明

| 分区 | 字段 |
| :--- | :--- |
| 基本信息 | Event ID、规则名称、预警类型、子类型、预警等级、预警状态 |
| 触发事实与位置 | 所属仓库、关联设备、预警内容、预警抓拍图 |
| 时间与处置 | 预警时间、处理时间、处理人、情况说明、现场照片、解除抓拍 |
| 规则快照 | 处置策略、监控阈值、升级策略（触发时固化，**不含**防抖条件） |
