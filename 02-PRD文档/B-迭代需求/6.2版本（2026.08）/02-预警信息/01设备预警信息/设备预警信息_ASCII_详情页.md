## 布局说明

**页头识别区**（`rounded-xl border bg-card p-4`，左右 flex）：

- 左侧：`h1` 规则名称 + `WarningStatusBadge`
- 右侧：动作按钮组，按 [第五章 动作能力矩阵](./设备预警信息业务规则规格.md#五动作能力矩阵) 显隐

| 状态 | 页头动作 |
| :--- | :--- |
| 未处理（有效）+ 允许人工处置类型 | 返回、解除预警、查看频次 |
| 未处理（有效）+ 仅自动 | 返回、查看频次 |
| 未处理（无效） | 返回、查看频次 |
| 已处理（有效） | 返回、查看频次 |

**内容分区**（`DetailSection` 卡片）：

| 层级 | 规格 |
| :--- | :--- |
| 分区容器 | 白底 Card：标题栏 `detail-section-header` + 内容区 `detail-section-content` |
| 内容区栅格 | `display: grid; grid-template-columns: repeat(4, 1fr); gap: 22px 28px` |
| 响应式 | `max-width: 1100px` 时降为 **3 列** |
| 单字段 | `DetailField`：**label 在上、value 在下**（`flex-direction: column`），每个字段占 1 个 grid 单元 |
| 跨列字段 | 预警内容、预警抓拍图等长文本/交互字段可 `grid-column: 1 / -1` 占满整行 |

| 分区 | 字段（按 grid 单元排列） |
| :--- | :--- |
| 基本信息 | Event ID、规则名称、预警类型、子类型、预警等级、预警状态（无效时 value 区附失效原因） |
| 触发事实与位置 | 所属仓库、关联设备、预警内容（可跨列）、预警抓拍图（可跨列） |
| 频次与时间 | 预警次数（value 含橙色数字 +「查看触发历史」）、首次/最近预警时间、防抖留痕 |
| 处置信息 | 处理时间/人、情况说明、现场照片、解除抓拍；未处理或瞬态自动结案无材料时 value=`—` |
| 规则快照 | 监控阈值、防抖条件、升级策略（触发时固化，只读） |

> **处置信息展示条件**：仅 `已处理（有效）` 且存在解除材料快照（情况说明/现场照片/解除抓拍任一非空）时回显材料，否则各字段 `—`。
> **本期不展示**：系统审计分区、订单穿透明细、升级通知发送日志。
