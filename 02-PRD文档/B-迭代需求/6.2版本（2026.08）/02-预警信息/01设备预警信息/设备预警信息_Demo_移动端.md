## 0. 移动端与 PC 差异摘要

| 维度 | PC Demo | 移动端 Demo（本文件） |
| :--- | :--- | :--- |
| 列表 | 宽表 + 行内操作 | **卡片列表** + 文本链动作 |
| 筛选 | 可展开筛选 Card | **搜索框** + 顶部胶囊 + 筛选抽屉 |
| 详情 | 多分区只读大表单 | **页头摘要灰框** + 折叠手风琴 |
| 解除 | 列表/详情**弹窗**两步解除 | **独立解除页** + 文末主按钮 |
| 导出 | ❌ | ❌ **不提供** |
| 底栏 | — | 🚫 **无固定悬浮操作栏**（随内容滚动） |

**移动端能力范围**（EVT-01~04）：列表浏览与筛选、详情查看、频次时间轴、抓拍预览、人工解除提交；**无**规则配置、**无**列表导出。

### 0.1 PC 与移动端排版差异（⚠️ 生成必遵）

| 端 | 详情/解除只读 | 解除可填 |
| :--- | :--- | :--- |
| PC | `DetailField` 上 label 下 value + 4 列 grid | `ReleaseMaterialForm` Label 在上 |
| 移动 H5 | `KeyValue` 左 label（w-20）右 value | `label` + `textarea`/`input` 纵向堆叠 |

## 1. 列表页

### 1.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 设备预警信息（移动） |
| 菜单路径 | `预警信息 → 设备预警信息` |
| 页面路径 | `/m/iot/device-warning-events` |
| 骨架结构 | NavBar → 搜索 + 筛选胶囊 → 卡片列表 |

> **无状态 Tab 栏**：预警状态通过筛选胶囊/抽屉过滤。
> **无分页器**：全量渲染筛选结果（Demo 数据量可控）。

### 1.2 NavBar

| 元素 | 规格 |
| :--- | :--- |
| 左侧 | `<` 返回首页（`/`） |
| 标题 | 设备预警信息 |

### 1.3 搜索与筛选区

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 搜索框 | `SearchInput` | placeholder：`规则名称 / 设备 / 内容`；**输入即时过滤** |
| 状态 | 胶囊 `FilterCapsule` | 显示「状态·未处理」或「状态·全部」；点击打开抽屉 |
| 类型 | 胶囊 | 显示「类型·N」或「类型·全部」 |
| 等级 | 胶囊 | 显示「等级·N」或「等级·全部」 |
| 仓库 | 胶囊 | 显示仓库名或「仓库·全部」 |
| 更多筛选 | 文字链 | 打开筛选抽屉（§1.4） |

### 1.4 筛选抽屉（FilterDrawer）

自底部弹出半屏抽屉：

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 预警类型 | `ToggleChip` 多选 | 6 大类 |
| 预警等级 | `ToggleChip` 多选 | 03/01 启用档 |
| 预警状态 | `select` | 全部 / 未处理（有效）/ 未处理（无效）/ 已处理（有效）；**默认「未处理（有效）」** |
| 所属仓库 | `select` | P02 过滤 |
| 触发频次 | `select` | 全部 / 高频（>5 次） |
| 首次预警时间 | 日期范围 | 起止日期 |

抽屉底栏：`重置` · `确定`。胶囊与抽屉字段**双向联动**。

### 1.5 卡片列表

**默认排序**：最近预警时间 DESC。

#### 单卡结构（DeviceWarningCard）

```text
┌──────────────────────────────┐
│ {规则名称}            {等级Tag} │
│ {预警类型} · {预警子类型}      │
│ ┌──────────────────────────┐ │
│ │ 设备     {设备名}         │ │
│ │ 内容     {预警内容}       │ │
│ │ 仓库     {所属仓库}       │ │
│ │ 抓拍     有触发图         │ │  （有图时）
│ └──────────────────────────┘ │
│ 最近 {MM-DD HH:mm}  ⚡ {N} 次  │  （Count>1 时可点击）
│ {状态标签}                    │
│   查看频次 ▸  解除 ▸  详情 ▸   │
└──────────────────────────────┘
```

| 卡片区域 | 字段来源 | 说明 |
| :--- | :--- | :--- |
| 头部 | 规则名称、预警等级 Tag | 字段清单第一章 |
| 副标题 | 预警类型、预警子类型 | — |
| 灰框 `#f8fafc` | 设备、预警内容、仓库、抓拍 | 核心事实摘要 |
| 元信息 | 最近预警时间、预警次数、预警状态 | Count>1 高亮可点击 |
| 底链 | 查看频次 / 解除 / 详情 | 按动作矩阵显隐 |

**次数点击 / 「查看频次 ▸」**：打开底部频次抽屉（§4）。

#### 卡片底链（与 PC 行操作一致）

| 状态 + 类型 | 展示底链 |
| :--- | :--- |
| 未处理（有效）+ R14 允许人工 | 查看频次 ▸ · **解除 ▸** · 详情 ▸ |
| 未处理（有效）+ 仅自动恢复 | 查看频次 ▸ · 详情 ▸ |
| 未处理（无效）/ 已处理（有效） | 查看频次 ▸ · 详情 ▸ |

| 底链 | 行为 |
| :--- | :--- |
| 详情 ▸ | 跳转 `/m/iot/device-warning-events/{id}` |
| 解除 ▸ | 跳转 `/m/iot/device-warning-events/{id}/release` |
| 查看频次 ▸ | 打开底部频次抽屉 |

### 1.6 空态 / 加载 / 错误

| :--- | :--- |

## 2. 详情页

### 2.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面路径 | `/m/iot/device-warning-events/{id}` |
| 骨架结构 | NavBar → 页头摘要灰框 → 折叠手风琴 → 页内动作链 |

### 2.2 NavBar

标题：`{规则名称}`。

### 2.3 页头摘要灰框（KeyValue 横排）

使用 `KeyValue` 组件：`flex gap-3`，label `w-20 text-gray-500`，value `flex-1`。

| 字段 | 展示规格 |
| :--- | :--- |
| 等级 Tag + 状态 | 灰框顶部一行 |
| 规则名称 / 类型 / 设备 / 仓库 / 内容 / 时间 / 次数 / 抓拍 | KeyValue 行 |

### 2.4 折叠手风琴（AccordionItem，默认收起）

| 区块 | 字段 |
| :--- | :--- |
| 频次与时间 | 触发历史入口、防抖留痕 |
| 处置信息 | 处理时间/人、情况说明、现场照片、解除抓拍 |
| 规则快照 | 阈值、防抖、升级策略 |
| 系统审计 | Event ID、Version、数据源、创建/更新时间 |

### 2.5 页内动作链（非 fixed 底栏）

| 状态 + 类型 | 动作链 |
| :--- | :--- |
| 未处理（有效）+ 允许人工 | 查看频次时间轴 ▸ · 解除预警 ▸ · 返回列表 |
| 未处理（有效）+ 仅自动恢复 | 查看频次时间轴 ▸ · 返回列表 + 💡「该类型预警由系统自动恢复，不支持人工解除。」 |
| 未处理（无效） | 查看频次时间轴 ▸ · 返回列表（附失效原因） |
| 已处理（有效） | 查看频次时间轴 ▸ · 返回列表（**无**解除预警） |

## 3. 解除页

### 3.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面路径 | `/m/iot/device-warning-events/{id}/release` |
| 骨架结构 | NavBar → 只读摘要灰框 → 解除材料表单 → 文末主按钮 |

> 移动端**唯一写操作页**；PC 主流程为弹窗，移动为独立页。

### 3.2 NavBar

标题：解除预警；返回至详情页。

### 3.3 只读摘要灰框

| 字段 | 展示 |
| :--- | :--- |
| 规则名称 + 状态 + 等级 | 摘要行 |
| 类型、仓库、设备、内容 | 文本行 |
| 首次时间 | — |
| Version | Demo 可见 |

> **不展示**：规则快照、触发抓拍大图。

### 3.4 解除材料表单（纵向 · Label 在上）

| 字段 | 控件 | 排版 |
| :--- | :--- | :--- |
| 情况说明 | `label` + `textarea` | Label 在上（含 `*`）；Textarea 在下；`0/200` 计数 |
| 现场照片 | `label` + file input | Label 在上；虚线框上传区在下 |

**辅助提示**（表单上方）：
- 提交后将联动同位置监控即时抓拍
- 确认解除后归档整轮 N 次触发并取消升级任务

### 3.5 提交区（文末，非 fixed）

| 按钮 | 规格 |
| :--- | :--- |
| 确认解除 | 主色全宽；情况说明为空或超 200 字时 disabled |
| 取消 | 文字链，返回详情页 |

**二次确认**：`window.confirm`「确认解除该轮次告警？提交后将归档整轮 {N} 次触发。」

**成功**：Toast「解除成功」→ 返回列表。

### 3.6 阻断场景

| 场景 | 反馈 |
| :--- | :--- |
| 仅自动类型进入 | 橙色提示框「该类型预警不支持人工解除，请等待自动恢复」 |
| 情况说明为空 | Toast「请填写情况说明」 |
| 超 200 字 | Toast「情况说明不可超过 200 字」 |
| 已处理/无效 | 不展示入口 |
| 无权限 P04 | 不展示「确认解除」 |
