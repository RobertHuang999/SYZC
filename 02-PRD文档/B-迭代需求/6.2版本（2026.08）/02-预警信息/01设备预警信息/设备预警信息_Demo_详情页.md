## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 设备预警信息详情 |
| 页面目标 | 只读查看单条预警流水；支持弹窗解除 |
| 页面路径 | `/预警信息/设备预警信息/详情/:id` |
| 骨架结构 | 页头识别区 → 基本信息 → 触发事实与位置 → 时间与处置 → 规则快照 |

---

## 2. 页头识别区

```text
{规则名称}   [ {WarningStatusBadge} ]     [ ← 返回 ]  [ 解除预警* ]
```

| 状态 + 类型 | 页头动作 |
| :--- | :--- |
| 待处置 · 有效 + R14' | 返回 / 解除预警 |
| 待处置 · 有效 + 仅自动 | 返回 |
| 已结案 / 已作废 | 返回 |

> **V3.4 移除**：「查看频次 N次」按钮、`TriggerHistoryDrawer`。

---

## 3. 内容分区

### 基本信息
Event ID、规则名称、预警类型、子类型、预警等级、预警状态

### 触发事实与位置
所属仓库、关联设备、预警内容、预警抓拍图

### 时间与处置
预警时间、处理时间、处理人、情况说明、现场照片、解除抓拍

### 规则快照
处置策略快照、监控阈值、升级策略（**无**防抖条件字段）
