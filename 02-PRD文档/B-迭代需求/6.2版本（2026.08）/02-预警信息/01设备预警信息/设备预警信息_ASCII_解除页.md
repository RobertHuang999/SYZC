## 1. 列表/详情页解除弹窗（主流程）

> **6.2 PC Demo 基准**：列表行「解除」与详情页「解除预警」均在当前页弹出 Dialog 完成，不跳转独立解除页。

### 1.1 第一步 — 二次确认

```text
+------------------------------------------+
|  确认解除                            [x] |
|  确认解除该轮次告警？提交后将归档整轮 3 次触发。 |
|                                          |
|              [ 取消 ]  [ 确认并填写说明 ]  |
+------------------------------------------+
```

### 1.2 第二步 — 填写解除材料（ReleaseMaterialForm · 上名下达）

```text
+----------------------------------------------------------+
|  填写解除说明                                        [x] |
|  请填写现场核实情况，提交后将归档本轮 3 次预警。              |
|                                                          |
|  * 情况说明                                              |
|  +------------------------------------------------------+|
|  | 经现场安保核实，系例行巡库检修…                        ||
|  +------------------------------------------------------+|
|  最多 200 字，必填                        已输入 28/200    |
|                                                          |
|  现场照片                                                |
|  选填，jpg/png/jpeg，单张≤5MB，最多 10 张                 |
|  [ 上传照片 ]   [ 现场照片1.jpg x ]                       |
|                                                          |
|  解除抓拍                                                |
|  提交时将联动同位置监控即时抓拍，提交后可在详情页查看。      |
|                                                          |
|  💡 确认解除后将归档整轮 3 次触发，状态变为「已处理（有效）」|
|                                                          |
|  [ 返回确认 ]  [ 取消 ]  [ 提交解除 ]                     |
+----------------------------------------------------------+
```

> 弹窗内表单为**纵向表单**：每项 `Label` 在上、控件/说明在下（`space-y-2`），**禁止**做成左 label 右 input 的表单行。

> 点击「提交解除」→ Toast「解除成功 — {规则名称}」→ 列表页移除该事件 / 详情页返回列表。

## 4. 弹窗解除 vs 完整页解除 vs 详情页 差异

| 对比项 | 详情页（只读） | 弹窗解除（主流程） | 完整页解除（备用） |
| :--- | :--- | :--- | :--- |
| 容器 | 详情页 | 列表/详情页 Dialog | 独立页面 |
| 页头动作 | 返回、解除预警*、查看频次 | 取消 / 确认并填写说明 / 提交解除 | 返回、取消、**确认解除** |
| 预警摘要 / 触发事实 | 只读展示 | 弹窗内不展示（上下文已知） | 只读展示（同详情） |
| 情况说明 / 现场照片 | 已处理时只读回显 | **可填写**（R04） | **可填写**（R04） |
| 解除抓拍 | 已处理时展示结果 | 提交前提示「将联动抓拍」 | 提交前提示「将联动抓拍」 |
| Version | — | 隐藏携带（R12） | 隐藏携带（R12） |
| 规则快照 / 系统审计 | 规则快照只读 | **不展示** | **不展示** |
| 入口条件 | 全状态可查看 | 仅 **未处理（有效）+ R14** | 须 releaseConfirmed 导航态 |
| 提交后 | — | **已处理（有效）** | **已处理（有效）** |

\* 详情页「解除预警」按钮弹出解除 Dialog；已处理/无效态不展示该按钮。

## 布局说明

**顶部导航 / 左侧菜单**：与 [列表页](./设备预警信息_ASCII_列表页.md)、[详情页](./设备预警信息_ASCII_详情页.md) 一致。

**弹窗解除分区**（字段清单 第二章）：

1. **确认步**：归档整轮 N 次触发的二次确认文案。
2. **材料步**：情况说明（必填 ≤200 字）、现场照片（选填）、解除抓拍说明（R08 系统自动）、Version 隐藏字段。

**完整页表单分区**（字段清单 第二章 + 摘要上下文）：

| 分区 | 组件 | 排版规格 |
| :--- | :--- | :--- |
| 预警摘要（只读） | `DetailSection` + `DetailField` | 4 列 grid；上 label 下 value；字段同详情页 |
| 触发事实（只读） | `DetailSection` + `DetailField` | 同上；预警内容/抓拍可跨列 |
| 解除材料（可填） | `DetailSection` + `ReleaseMaterialForm` | Form 跨列占满；Label 在上、Textarea/Upload 在下 |

> 完整页排版规范与 [详情页布局说明](./设备预警信息_ASCII_详情页.md#布局说明) 共用 `DetailSection` / `index.css`。

## 提交校验要点

| 规则编号 | 场景 | 预期 |
| :--- | :--- | :--- |
| R04 | 情况说明为空 | 阻断，提示「请填写情况说明」 |
| R04 | 情况说明 >200 字 | 阻断，提示「情况说明不可超过 200 字」 |
| R04 | 现场照片格式/大小/数量超限 | 阻断，提示文件约束 |
| R11 | 流水非「未处理（有效）」 | 阻断，提示「该预警已处理或已失效」 |
| R12 | Version 冲突 | 阻断，提示「数据已被他人修改，请刷新重试」 |
| R14 | 瞬态已结案 / 仅自动恢复类型 | **不展示**解除入口（如温湿度数值异常、正常刷脸通行） |
| P04 | 无 IoT 处理权限 | 不展示「提交解除」/「确认解除」 |
| P02 | 流水不在操作人仓库权限内 | 阻断或不可进入 |

## 入口对照

| 动作 | 来源 |
| :--- | :--- |
| 弹窗解除 | 列表行「解除」；详情页「解除预警」（未处理有效 + R14） |
| 完整页解除 | 携带 releaseConfirmed 导航态进入 `/预警信息/设备预警信息/解除/:id` |
| 频次时间轴抽屉 | 详情/完整页「查看触发历史」或列表 `N次`（第7章） |

**不可进入解除的状态/类型**：

| 条件 | 处理 |
| :--- | :--- |
| 未处理（无效） | 无解除入口（第五章 动作矩阵） |
| 已处理（有效） | 无解除入口；材料在详情页只读回显 |
| 温湿度/GPS 数值异常 | 无解除入口，走 R03 自动恢复 |
| 常规通行与操作事务 | R06 瞬态已处理，无解除入口 |
