## 1. 列表/详情页解除弹窗（主流程 · 单条）

### 1.1 第一步 — 二次确认

```text
+------------------------------------------+
|  确认解除                            [x] |
|  确认解除该条告警？提交后将归档本条记录。   |
|              [ 取消 ]  [ 确认并填写说明 ]  |
+------------------------------------------+
```

### 1.2 第二步 — 填写解除材料

```text
+----------------------------------------------------------+
|  填写解除说明                                        [x] |
|  * 情况说明  [ Textarea ≤200字 ]                          |
|  现场照片  [ 上传照片 ]                                   |
|  解除抓拍  提交时将联动同位置监控即时抓拍                  |
|  [ 返回确认 ]  [ 取消 ]  [ 提交解除 ]                     |
+----------------------------------------------------------+
```

## 2. 列表页批量解除弹窗（R16）

```text
+----------------------------------------------------------+
|  批量解除                                            [x] |
|  确认批量解除已选 {N} 条告警？                             |
|  * 情况说明  [ Textarea ≤200字 ]                          |
|  现场照片  [ 上传照片 ]                                   |
|              [ 取消 ]  [ 提交批量解除 ]                   |
+----------------------------------------------------------+
```

> 每条选中流水独立联动解除抓拍；Version 逐条携带。

---

## 3. 完整页模式（备用）

页头：`解除预警 — {规则名称}` · `[ ← 返回 ]` `[ 取消 ]` `[ 确认解除 ]`

只读摘要区：Event ID、规则名称、类型/子类型、等级、状态、**预警时间**（**无**预警次数/最近时间）。

可填区：`ReleaseMaterialForm`（情况说明、现场照片）。

## 4. 流水生成说明

```text
  硬件上报 / 通行事务 → 厂商接入网关（防抖/去重）→ iot_event_ledger 逐条自动落账
  用户写操作：单条解除 / 批量解除（R14' + P04）
```
