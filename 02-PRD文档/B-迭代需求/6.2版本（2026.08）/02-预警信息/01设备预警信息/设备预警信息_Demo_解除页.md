## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 写操作 | 单条解除 / 批量解除（列表页） |
| PC 主流程 | `ReleaseConfirmDialog` / `BatchReleaseDialog` 弹窗 |
| 完整页路径 | `/预警信息/设备预警信息/解除/:id`（备用） |

---

## 2. 单条解除弹窗

| 步骤 | 文案 |
| :--- | :--- |
| confirm | 「确认解除该条告警？提交后将归档本条记录。」 |
| materials | 情况说明（必填 ≤200 字）、现场照片（选填）、Version hidden |

---

## 3. 批量解除弹窗（R16）

| 元素 | 规格 |
| :--- | :--- |
| 标题 | 批量解除 |
| 文案 | 「确认批量解除已选 {N} 条告警？」 |
| 情况说明 | 统一填写，逐条写入 |
| 提交 | 逐条 Version 校验；部分失败汇总 |

---

## 4. 完整页摘要（只读）

Event ID、规则名称、类型/子类型、等级、状态、**预警时间**（无预警次数/最近时间）。
