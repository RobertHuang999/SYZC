# 风险公示 PC Demo 规格

## 页面入口

- 菜单：`02-预警信息 / 风险公示`
- 路由：`/预警信息/风险公示`
- 详情：`/预警信息/风险公示/详情/:id`

## 列表规格

| 区域 | 展示与交互 |
| :--- | :--- |
| 筛选区 | 规则名称、订单号、货主名称模糊查询，状态下拉；查询提交 draft，重置同时清空 draft/applied |
| 列表区 | 序号、预警订单、货主、预警类型、预警内容、抓拍、预警时间、处理时间、处理人、公示状态、公示时间、操作 |
| 操作列 | 仅显示「详情」；公示副本不提供原始预警解除或编辑入口 |
| 状态展示 | 公示状态使用明确文本；日期为空展示 `—`；长文本省略并支持悬浮查看 |
| 分页 | 支持页码和每页条数切换；空结果显示「暂无数据」 |

## 验收样例

1. 选择状态并查询后，列表只展示匹配的公示副本；点击重置后恢复全量默认结果。
2. 点击订单号或详情进入详情页，返回列表不丢失当前路由。
3. 1366x768 和 1440x900 下，字段不互相覆盖，宽表可横向查看；详情页底部操作和长文本不裁切。
