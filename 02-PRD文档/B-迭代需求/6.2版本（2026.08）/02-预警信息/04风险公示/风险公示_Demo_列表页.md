# 风险公示 PC Demo 规格

> **文档定位**：**衍生文档**——由三件套派生的原型输入；**非独立真源**。业务见[主PRD §4 PC 列表页](./风险公示主PRD.md#41-pc-列表页)，字段见[字段清单](./风险公示字段清单.md)，规则见[业务规则规格](./风险公示业务规则规格.md)，线框见[ASCII](./风险公示_ASCII_列表页.md)。变更须先更新三件套。
## 页面入口

- 菜单：`02-预警信息 / 风险公示`
- 路由：`/预警信息/风险公示`
- 详情：`/预警信息/风险公示/详情/:id`

## 列表规格

| 区域 | 展示与交互 |
| :--- | :--- |
| 筛选区 | PC：规则名称/订单号/货主/预警类型四字段模糊搜索（AND）；H5：字段下拉 + 关键词；列表固定仅展示已公示；不含公示时间日期范围筛选；查询提交 draft，重置同时清空 draft/applied |
| 列表区 | 序号、预警订单号、预警类型、公示标题与内容摘要、现场抓拍图、最近一次公示时间、最新操作人、公示状态、操作 |
| 操作列 | 仅显示「详情」；公示副本不提供原始预警解除或编辑入口 |
| H5 详情 | 底部【取消公示】【重新公示】与 PC 对齐；取消说明 Bottom Sheet 必填 ≤200 字 |
| 状态展示 | 公示状态使用明确文本；日期为空展示 `—`；长文本省略并支持悬浮查看 |
| 分页 | 支持页码和每页条数切换；空结果显示「暂无数据」 |

## 验收样例

1. 输入筛选条件并查询后，列表只展示匹配的已公示副本；点击重置后恢复全量默认结果。
2. 点击订单号或详情进入详情页，返回列表不丢失当前路由。
3. 1366x768 和 1440x900 下，字段不互相覆盖，宽表可横向查看；详情页底部操作和长文本不裁切。
