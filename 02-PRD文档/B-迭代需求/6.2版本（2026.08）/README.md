# SYZC 6.2 版本（2026.08）迭代需求总览与索引

> **版本**：V2.9 | **更新日期**：2026-08-28
>
> **架构定位**：SYZC 供应链金融存货监管系统 6.2 迭代全景总索引与全局入口。本版本将物联网资产、运行时风险预警监控与风控规则配置全链路解耦，重构为 **【01-物联网IOT管理】**、**【02-预警信息】**、**【03-预警配置】** 三大目标态主干，以及 **【04-历史迁移与割接方案】** 过渡态割接文档；**【06-门禁开锁审批】**、**【07-审批中心】**、**【08-开锁审核】** 为 6.2 门禁开锁审批扩展链路。
>
> **文档规范**：全量迭代模块对齐 V3.0 标杆（主 PRD 第 1~10 章 + 业务规则规格唯一定义来源 + 字段清单 + ASCII 页面线框）。

> **本期 PC 原型验收范围**：纳入 `02-预警信息` 与 `03-预警配置` 的 PC 页面；`01-物联网IOT管理` 五个设备台账本期不纳入 PC 原型验收，仅验收 PRD、字段清单和业务规则，PC 菜单保留占位入口。
>
> **全局契约与权限**：跨模块生命周期、路由跳转与角色权限详见 [00-全局契约与RBAC权限矩阵.md](./00-全局契约与RBAC权限矩阵.md)。
>
> **根目录跨板块文档命名**：`00-` 前缀表示版本根目录下的跨模块导读/契约（非独立板块文件夹）；板块目录按 `01-`～`08-` 编号（**05 预留未用**）。

## 四、历史基准 vs 6.2 迭代 对照

| 6.1 原基准归属 | 6.2 迭代新归属 | 重构说明 |
| :--- | :--- | :--- |
| **01设备管理** 01~04、06 设备档案 | **01-物联网IOT管理** 01~05 | 保持基础档案标准，提供统一资产底座 |
| **01设备管理** 05门禁事务记录 | **02-预警信息** 01设备预警信息 | 独立菜单取消，底层流水合流至设备预警信息（`常规通行与操作事务`） |
| **02风险管理** 02设备预警 + 03事务通知配置 | **03-预警配置** 02设备预警配置 | 两配置菜单合并重构为 5 大类统一规则配置 |
| **02风险管理** 01订单预警配置 | **03-预警配置** 03订单预警配置 | 11 类整合为 6 类，绑定动态预警等级 ID |
| — | **03-预警配置** 01预警等级 | 6.2 新增租户 2~20 档动态等级底座 |
| **03风险信息** 01设备预警 + 03事务通知信息 | **02-预警信息** 01设备预警信息 | 两信息流水合并重构，支持时间轴与自动/人工解除 |
| **03风险信息** 02押品预警信息 | **02-预警信息** 02押品预警信息 | 升级支持物联穿透只读告警与单据跳转去处理 |
| **03风险信息** 04贷中风控管理 | **02-预警信息** 03贷中风控管理 | 承接贷中风控模型异步执行与结果跟踪 |
| **03风险信息** 05风险公示 | **02-预警信息** 04风险公示 | 承接已处理有效风险对外合规披露 |
