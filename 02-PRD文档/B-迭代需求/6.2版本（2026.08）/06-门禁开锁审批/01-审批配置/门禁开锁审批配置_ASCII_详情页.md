## 布局说明

**页头识别区**：配置名称 + 状态 Tag + 操作按钮（返回 / 编辑 / 停用或启用）。

**内容分区**（`DetailSection` 卡片）：

| 分区 | 字段（按 grid 单元排列） |
| :--- | :--- |
| 基础识别与范围 | 配置编号、配置名称、适用设备（可跨列 + 查看设备清单抽屉） |
| 审批策略 | 审批方式（固定任一人通过）、审批超时时间、配置版本；审批节点只读表格 |
| 系统审计 | 状态、停用原因（已停用时展示）、创建人/时间、更新人/时间 |

**页头识别区**：配置名称 + 状态 Tag + 操作按钮（返回 / 编辑 / 停用或启用 / **删除**仅已停用）。

**不展示**：Version、操作审计日志完整流水（后台 A01–A02 可查）。**删除**仅已停用，二次确认见列表页 C08。
