## 3. 新增 / 编辑差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 页签标题 | 新增开锁审批配置 | 编辑开锁审批配置 — {配置名称} |
| 配置名称 | 空，用户填写 | 预填，**置灰不可改**（R06） |
| 适用设备 | 可勾选/调整 | 预填，**置灰不可改**（R06）；需调整设备时停用旧配置并新增 |
| 审批节点 / 审批超时时间 | 空或默认 1 个空节点（限定合作机构） | 读当前记录，**可改**（限定合作机构） |

| 已停用配置 | — | **不可进入编辑**（第五章 动作矩阵） |

## 布局说明

**顶部导航 / 左侧菜单**：与 [列表页](./门禁开锁审批配置_ASCII_列表页.md)、[详情页](./门禁开锁审批配置_ASCII_详情页.md) 一致（配置管理壳层）。

**标签页（Tabs）**：「首页」「开锁审批」及当前「新增开锁审批配置」或「编辑开锁审批配置 — {配置名称}」。

**页头动作**：

- **返回**：回到列表页（有未保存变更时提示确认）。
- **取消**：同返回，放弃本次编辑。
- **保存**：提交表单并审计（P02）。**不提供**状态下拉——启停仅在列表/详情独立动作。

**表单分区**（字段清单 第一、二章 表单项）：

1. **基础识别与范围**：配置名称、适用设备（弹窗多选）。
2. **审批策略**：审批节点（可增删、拖拽排序，限定当前租户下合作机构）、审批超时时间（`TimeoutHoursInput`，单位内嵌）；**不展示审批方式选项**。

**适用设备选择（UnlockDeviceSelectDialog）**：

- 表单页展示摘要 + `[勾选/调整设备 >]` 按钮（新增态）；编辑态置灰只读
- 弹窗：仓库筛选 + 关键字搜索 + 复选框列表 + 全选/取消全选 + 「确认选择（N 台）」
- 至少选择 1 台设备

**审批节点交互**：

- 每节点 **审批对象类型** 二选一：指定人员 / 指定角色；切换类型时清空已选对象。
- **候选范围限制（P01b）**：下拉数据源严格限定为**当前租户下合作机构**（含本机构及所有生效的合作机构）中启用的数据：
  - 指定人员：单选，展示格式为「姓名（所属机构）」。
  - 指定角色：单选，展示格式为「角色名称（所属机构）」。
- 保存时校验指定人员为启用账号、指定角色至少 1 个启用成员且所属机构在合作关系内（R02）。
- 拖拽 `≡` 调整节点序号。
- 至少保留 1 个节点；删至 0 时保存阻断（R27）。

> **本期不展示**：配置编号、状态、审批方式选项、配置版本、Version、创建/更新人时间、停用原因。

## 保存校验要点

| 规则编号 | 场景 | 预期 |
| :--- | :--- | :--- |
| R04a | 配置名称为空或租户内重复 | 阻断，「配置名称不可为空」或「配置名称已存在」 |
| R01 | 适用设备不存在或已停用 | 阻断，「保存/启用失败：设备{编码}不存在或已停用」 |
| R02 | 指定人员已停用或非合作机构；指定角色无启用成员或非合作机构 | 阻断，「保存/启用失败：审批节点{序号}无效或不属于当前租户合作机构」 |
| R27 | 无节点、节点类型未选、或同一节点混选 | 阻断，提示节点配置不完整 |
| R03 | 同一设备已存在于内容不一致的已启用配置 | 阻断，「保存/启用失败：与配置{编号}存在设备冲突」 |
| R06 | 编辑变更不可变字段 | 服务端拒绝 |
| R07 | Version 冲突 | 阻断，「数据已被他人修改，请刷新重试」 |
| — | 未选设备；超时非正整数 | 阻断 |
