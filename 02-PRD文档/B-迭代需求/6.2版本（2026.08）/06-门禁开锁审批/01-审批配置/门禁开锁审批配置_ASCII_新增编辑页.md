| 对比项 | 新增 | 编辑 |

## 布局说明

**顶部导航 / 左侧菜单**：与 [列表页](./门禁开锁审批配置_ASCII_列表页.md)、[详情页](./门禁开锁审批配置_ASCII_详情页.md) 一致（配置管理壳层）。

**标签页（Tabs）**：「首页」「开锁审批」及当前「新增开锁审批配置」或「编辑开锁审批配置 — {配置名称}」。

**页头动作**：

- **返回**：回到列表页（有未保存变更时提示确认）。
- **取消**：同返回，放弃本次编辑。
- **保存**：提交表单并审计（P02）。**不提供**状态下拉——启停仅在列表/详情独立动作。

**表单分区**（字段清单 第一、二章 表单项）：

1. **基础识别与范围**：配置名称、适用范围类型、**范围选择面板**（`ScopeCascadeSelector`）或全局开关。
2. **审批策略**：审批方式、审批节点（可增删、拖拽排序）、审批超时时间（`TimeoutHoursInput`，单位内嵌）。

**范围选择面板（ScopeCascadeSelector）**：

- 顶部路径摘要 Badge：「范围选择 / {仓库} / {库房…} / {分区…}」
- **适用仓库**：单选下拉；切换时清空库房、分区、已选设备
- **适用库房**：Tag 多选按钮组（库房/分区/指定设备类型展示）；须先选仓库
- **适用分区**：Tag 多选按钮组（分区/指定设备类型展示）；须先选库房
- 未选仓库时：库房/分区区展示「请先选择适用仓库」

**指定设备选择（UnlockDeviceSelectDialog）**：

- 表单页仅展示摘要 + `[勾选/调整设备 >]` 按钮，**不在页内嵌长列表**
- 弹窗：仓库筛选 + 关键字搜索 + 复选框列表 + 全选/取消全选 + 「确认选择（N 台）」

**审批节点交互**：

- 每节点 **审批对象类型** 二选一：指定人员 / 指定角色；切换类型时清空已选对象。
- 指定人员：启用账号单选，展示姓名。
- 指定角色：启用角色单选；保存时校验该角色至少 1 个启用成员（R02）。
- 拖拽 `≡` 调整节点序号；按顺序审批时该顺序即审批链。
- 至少保留 1 个节点；删至 0 时保存阻断（R27）。

> **本期不展示**：配置编号、状态、配置版本、Version、创建/更新人时间、停用原因。

## 保存校验要点

| 规则编号 | 场景 | 预期 |
| :--- | :--- | :--- |
| R04a | 配置名称为空或租户内重复 | 阻断，「配置名称不可为空」或「配置名称已存在」 |
| R01 | 适用仓库/库房/分区/设备不存在或已停用 | 阻断，「保存/启用失败：{位置}不存在或已停用」 |
| R02 | 指定人员已停用；指定角色无启用成员 | 阻断，「保存/启用失败：审批节点{序号}无效」 |
| R27 | 无节点、节点类型未选、或同一节点混选 | 阻断，提示节点配置不完整 |
| R03 | 同一范围已有内容不一致的已启用配置 | 阻断，「保存/启用失败：与配置{编号}存在范围冲突」 |
| R29 | 未绑定位置全局已存在一条已启用配置 | 阻断第二条保存 |
| R06 | 编辑变更不可变字段 | 服务端拒绝 |
| R07 | Version 冲突 | 阻断，「数据已被他人修改，请刷新重试」 |
| — | 审批方式未选；超时非正整数 | 阻断 |

## 6. 场景 E — 未绑定位置全局（新增页片段）

```text
|  ### 基础识别与范围                                                                    |
|  * 配置名称:        [ 未绑定位置全局审批                  ]                              |
|  * 适用范围类型:    [ 未绑定位置全局                     v ]                              |
|  * 未绑定位置设备全局审批开关:  ( ) 关闭    (●) 开启   ?                                   |
|    💡 说明（FieldHelpTooltip / 灰字）:                                                  |
|            关闭=未绑定库房/分区/指定设备的门禁走原有免审直发密码；                       |
|            开启=进入本配置的全局审批。不得将「未命中具体配置」静默当成免审（C04）。      |
|            租户内该类型仅允许 1 条已启用配置（R29）。                                    |
|    （适用仓库/库房/分区/设备选择器已隐藏）                                               |
|                                                                                        |
|  ### 审批策略                                                                          |
|  * 审批方式:        (●) 任一人通过    ( ) 按顺序审批                                     |
|  * 审批节点:        节点1 指定角色 [ 风控经理 v ]                                        |
|  * 审批超时时间:    [  24 | 小时 ]  （单位内嵌）                                          |
```

> 开关为**关闭**时，审批节点与超时仍保存，供日后开启直接生效；运行时关闭=免审，不走审批链。若租户已存在一条已启用的全局配置，再次新增同类型保存阻断（R29）。
