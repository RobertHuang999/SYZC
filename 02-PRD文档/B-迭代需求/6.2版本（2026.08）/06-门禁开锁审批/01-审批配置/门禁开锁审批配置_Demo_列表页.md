## 2. 查询区

### 2.1 布局说明

筛选 Card 容器，顶部 `ConfigFilterHeader`（交互对齐预警配置 `WarningFilterHeader`）：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]` → `[ + 新增配置 ]`（`onAdd`；P02 写权限；无权限隐藏）

**默认行**（4 列栅格）：配置名称、适用范围类型、审批方式、状态。

**展开行**（追加 1 行）：配置编号、适用仓库；**当且仅当**「适用范围类型 = 未绑定位置全局」时展示「全局审批开关」筛选项，否则展示占位提示文案。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 配置名称 | `Input` | 模糊匹配；placeholder：`请输入配置名称` |
| 适用范围类型 | `Select` + `FieldHelpTooltip` | 全部（默认）/ 仓库 / 库房 / 分区 / 指定设备 / 未绑定位置全局；? 提示：「选择未绑定位置全局后，展开筛选将出现全局审批开关」 |
| 审批方式 | `Select` | 全部（默认）/ 任一人通过 / 按顺序审批 |
| 状态 | `Select` | 全部（默认）/ 已启用 / 已停用 |
| 配置编号 | `Input` | 精确匹配；展开筛选展示 |
| 适用仓库 | `Select` | 全部在管仓库；展开筛选展示；P02 数据权限过滤 |
| 全局审批开关 | `Select` + `FieldHelpTooltip` | **联动显隐**：仅当「适用范围类型 = 未绑定位置全局」时展示；选项：全部 / 开启 / 关闭；? hover 说明见 §2.4 |

### 2.3 筛选交互

- 点击「查询」或 Enter：刷新列表，页码重置为 1
- 点击「重置」：恢复各筛选项默认值并刷新
- 切换筛选条件后须点击「查询」才刷新（非即时查询）
- **适用范围类型**切换为非「未绑定位置全局」时：自动将「全局审批开关」重置为「全部」
- 展开筛选且适用范围类型 ≠ 未绑定位置全局 时：第三列展示灰色提示「将适用范围类型选为未绑定位置全局后，可筛选全局审批开关」，**不展示**下拉框

### 2.4 全局审批开关 Tooltip 文案

> 仅适用于「未绑定位置全局」类型配置：控制未绑定仓库/库房/分区/指定设备的门禁，开锁时是否走审批。关闭 = 免审直发密码；开启 = 进入全局审批。

## 4. 表格

### 4.1 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 行勾选 | 不支持 |
| 列宽拖拽 | 支持 |
| 固定列 | 配置名称列左固定；操作列右固定 |
| 分页 | 默认 10 条/页，可选 10/20/50 |
| 默认排序 | 更新时间 DESC |
| 空状态 | 「暂无开锁审批配置」+ 「点击「+ 新增配置」创建」 |

### 4.2 列定义

| 列名 | 内容说明 | 宽度 | 固定 |
| :--- | :--- | :--- | :---: |
| 序号 | 当前页从 1 起 | 64px | |
| 配置编号 | 链接色，跳转详情页 | 140px | |
| 配置名称 | 链接色，跳转详情页 | 180px | 左固定 |
| 适用范围类型 | 5 类枚举文本 | 120px | |
| 适用仓库/设备摘要 | 见 §4.3 摘要规则 | 180px | |
| 审批方式 | 任一人通过 / 按顺序审批 | 110px | |
| 审批超时 | 如 `24 小时` | 90px | |
| 配置版本 | 如 `v1`、`v3` | 90px | |
| 状态 | 状态 Tag | 90px | |
| 创建人/时间 | 合并一列；创建人格式「姓名（所属机构）」 | 140px | |
| 操作 | 行内文字操作 | 160px | 右固定 |

> **不展示列**：适用库房/适用分区明细、审批节点、Version、停用原因、操作审计日志。

### 4.3 「适用仓库/设备摘要」渲染规则

| 适用范围类型 | 摘要文案示例 |
| :--- | :--- |
| 仓库 | `华南二号仓` |
| 库房 | `华东一号仓 / A库` |
| 分区 | `华北三号仓 / 1号库 / 1区` |
| 指定设备 | `华东一号仓 / 已选 3 台` |
| 未绑定位置全局 | `全局开关=开启` 或 `全局开关=关闭` |

### 4.4 状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 已启用 | 绿色 |
| 已停用 | 灰色 |

### 4.5 行内操作

**不渲染 disabled 操作**（无权限时整按钮隐藏）。

| 状态 | 展示的操作 |
| :--- | :--- |
| 已启用 | 编辑 / 详情 / 停用 |
| 已停用 | 详情 / 启用 |

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转 `/配置管理/业务流程管理/开锁审批/编辑/:configNo`（已停用 ❌） |
| 详情 | 跳转 `/配置管理/业务流程管理/开锁审批/详情/:configNo` |
| 停用 | 二次确认弹窗 + 停用原因表单（见 §5） |
| 启用 | 二次确认 MessageBox；重跑 R01–R04、R27、R29 |
