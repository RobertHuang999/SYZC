## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 设备预警配置列表 |
| 页面目标 | IoT 管理员筛选、查看设备预警规则，并进入新增/编辑/详情 |

## 2. 查询区

### 2.1 布局说明

筛选 Card 容器，顶部 `WarningFilterHeader`：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]` → `[ + 新增设备规则 ]`（`onAdd`；IoT 写权限）

**默认行**（4 列栅格）：规则名称、预警类型、预警等级、状态。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 规则名称 | `Input` | 模糊匹配；placeholder：`请输入规则名称` |
| 预警类型 | `Select`（多选） | 5 大类：设备图像识别预警 / 设备物联预警 / 智能挂锁预警 / 人脸门禁预警 / 设备GPS预警 |
| 预警等级 | `SelectWithSearch`（多选） | 读 03/01 **启用**档；展示格式：色块 + `{编码} {名称}`；提交 `severity_level_id` |
| 状态 | `Select` | 全部（默认）/ 生效中 / 停用 / 已失效 |

### 2.3 筛选交互

- 点击「查询」或 Enter：刷新列表，页码重置为 1
- 点击「重置」：恢复各筛选项默认值并刷新
- 切换筛选条件后须点击「查询」才刷新（非即时查询）

## 4. 表格

### 4.1 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 行勾选 | 不支持 |
| 列宽拖拽 | 支持 |
| 固定列 | 规则名称列左固定；操作列右固定 |
| 分页 | 默认 10 条/页，可选 10/20/50 |
| 默认排序 | 更新时间 DESC |
| 空状态 | 「暂无设备预警规则」+ 「点击「+ 新增设备规则」创建」 |

### 4.2 列定义

| 列名 | 内容说明 | 宽度 | 固定 |
| :--- | :--- | :--- | :---: |
| 序号 | 当前页从 1 起 | 64px | |
| 规则名称 | 链接色，跳转详情页 | 160px | 左固定 |
| 预警类型 | 5 大类文本 | 120px | |
| 预警等级 | 色块 + 编码/名称 | 120px | |
| 关联设备范围 | 设备数量摘要或 `仅针对新设备（全局监听）` | 160px | |
| 触发条件 | 监控阈值/触发条件摘要 | 140px | |
| 防抖条件 | 如 `持续>3分钟`、`立即触发` | 120px | |
| 状态 | 状态 Tag | 100px | |
| 创建人/时间 | 合并一列 | 140px | |
| 更新人/时间 | 合并一列 | 140px | |
| 操作 | 行内文字操作 | 180px | 右固定 |

> **不展示列**：规则 ID、Version、通知/升级明细。

### 4.3 状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 生效中 | 绿色 |
| 停用 | 灰色 |
| 已失效 | 橙灰 |

### 4.4 行内操作

**不渲染 disabled 操作**。

| 状态 | 展示的操作 |
| :--- | :--- |
| 生效中 | 编辑 / 详情 / 停用 / 删除 |
| 停用 | 编辑 / 详情 / 启用 / 删除 |
| 已失效 | 详情 / 删除 |

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转编辑页 `/预警配置/设备预警配置/编辑/:id`（已失效 ❌） |
| 详情 | 跳转 `/预警配置/设备预警配置/详情/:id` |
| 停用 | 二次确认弹窗 |
| 启用 | 直接执行（停用态） |
| 删除 | 二次确认弹窗 |

---

## 5. 二次确认弹窗规格

| 触发操作 | 弹窗标题 | 弹窗内容 | 确认按钮 |
| :--- | :--- | :--- | :--- |
| 停用 | 确认停用 | 停用后将暂停事件监听，确认停用？ | **确认停用** |
| 删除 | 确认删除 | 删除后不可恢复，关联未处理预警将置为无效，确认删除？ | **确认删除** |
