## 2. DetailSection 布局规范（⚠️ 生成必遵）

与 dev 共用组件 `@/shared/components/DetailSection` + `index.css`：

| 层级 | 实现 |
| :--- | :--- |
| 分区 | `DetailSection`：标题 + 内容区 Card |
| 内容区 | `detail-section-content`：**4 列 CSS Grid**（≤1100px → 3 列），`gap: 22px 28px` |
| 单字段 | `DetailField`：**label 在上、value 在下**（`flex-direction: column; gap: 6px`） |
| label 样式 | 13px、`#86909c`（`detail-field-label`） |
| value 样式 | 14px、`#1d2129`（`detail-field-value`） |

```text
┌─ DetailSection: 基本信息 ─────────────────────────────────────────────┐
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   ← 4列 grid         │
│  │规则 ID   │ │规则名称  │ │预警类型  │ │预警子类型│                       │
│  │rule-…   │ │库温超标…│ │设备物联…│ │温度异常  │   ← 上名下达           │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘                       │
└────────────────────────────────────────────────────────────────────────┘
```

**禁止**：ElDescriptions 横向「左 label 右 value」、或 `el-form` 一行两列的表单行布局。

## 3. 页头识别区

```text
{规则名称}   [ {状态Tag} ]          [ ← 返回 ]  [ 编辑 ]  [ 停用/启用 ]  [ 删除 ]
```

容器：`rounded-xl border bg-card p-4`，`lg:flex-row` 左右布局。

### 3.1 页头操作（按状态）

| 状态 | 展示的操作 |
| :--- | :--- |
| 生效中 | 返回 / 编辑 / 停用 / 删除 |
| 停用 | 返回 / 编辑 / 启用 / 删除 |
| 已失效 | 返回 / 删除 |

---

## 4. 基本信息卡片（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| 规则 ID | UUID 只读 |
| 规则名称 | 文本 |
| 预警类型 | 5 大类 |
| 预警子类型 | 已选子类型列表 |
| 预警等级 | 色块 + 编码 + 名称 + HEX |

---

## 5. 关联设备与触发条件卡片（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| 仅针对新设备 | 是/否 |
| 防抖判定模式 | 按持续时长 / 按连续次数 |
| 防抖生效条件 | 如 `持续超过 3 分钟` 或 `立即触发` |
| 监控阈值 | 数值型展示最低/最高 |
| 关联设备范围 | 摘要 + `[查看设备清单 >]` 只读展开（可跨列） |
| 触发条件摘要 | 如 `温度 > 35℃ 或 < -5℃`（可跨列） |

---

## 6. 通知与升级策略卡片（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| 通知渠道 | 站内信、短信等；未配置展示 `—` |
| 预警对象 | 人员列表 |
| 升级预警 | 如 `持续未解除 3 天后 ➔ 王总监`；未配置展示 `—` |

> 全局新设备规则**不展示升级区块**（R13）。

---

## 7. 系统审计卡片（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| Version | 整数（R07） |
| 状态 | 生效中 / 停用 / 已失效 |
| 失效原因 | 仅已失效展示（C06） |
| 创建人 / 创建时间 | — |
| 更新人 / 更新时间 | — |

---

## 8. 二次确认弹窗

| 操作 | 内容 | 确认按钮 |
| :--- | :--- | :--- |
| 停用 | 停用后将暂停事件监听，确认停用？ | **确认停用** |
| 删除 | 删除后不可恢复，关联未处理预警将置为无效，确认删除？ | **确认删除** |

## 9. Mock 数据

对齐 ASCII「库温超标预警」示例：生效中、L4、6 台温湿度计、-5~35℃、3 分钟防抖、站内信+短信、Version=2。

**已失效态示例**：传感器离线，失效原因「关联设备已全部移除（C06）」，页头仅返回+删除。
