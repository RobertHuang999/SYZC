## 布局说明

**顶部导航 / 左侧菜单**：与 [列表页](./设备预警配置_ASCII_列表页.md)、[详情页](./设备预警配置_ASCII_详情页.md) 一致（设备与预警管理壳层）。

**标签页（Tabs）**：「首页」「设备预警配置」及当前「新增设备规则」或「编辑设备规则 — {规则名称}」。

**页头动作**：

- **返回**：回到列表页（有未保存变更时提示确认）。
- **取消**：同返回，放弃本次编辑。
- **保存并生效**：提交表单并审计；成功后返回列表页（第四章 新增/编辑流转）。**不提供**状态下拉——保存不改变启停态；启停仅在列表/详情独立动作。

**表单分区**（字段清单 第二章 全部表单项）：

1. **基本信息**：规则名称、预警类型、预警子类型（动态复选）、预警等级。
2. **关联设备与触发条件**：仓库筛选、关联设备穿梭、仅针对新设备（条件展示）、数值阈值、防抖模式与时长/次数。
3. **通知与升级策略**：通知渠道（短信/邮件，选填）、预警对象、升级天数与升级对象；系统小角标自动更新，不可配置。

**动态联动**（选类型/子类型后即时生效，详见 第5章）：

- 子类型变更 → 防抖区 R01/R02 置灰或激活；数值阈值区显隐（R09）。
- 勾选「仅针对新设备」→ 隐藏关联设备穿梭框（R05/R08）；**隐藏升级预警区**，`upgrade_days` 强制 0（R13）。
- 预警类型变更 → 子类型选项重载（附录 A）。

> **本期不展示**：规则 ID、创建人/时间、状态标签（系统后台维护；状态见列表/详情）。

## 保存校验要点

| 规则编号 | 场景 | 预期 |
| :--- | :--- | :--- |
| R01 | 瞬态子类型配置防抖 >0 | 前端锁定「立即触发」；服务端阻断 |
| R02 | 持续型防抖 ≤0 | 阻断，提示「持续防抖时长必须大于 0」 |
| R03 | 名称空或重复 | 阻断，提示租户内唯一 |
| R04 | 设备 + 子类型重复 | 阻断，提示已存在同类型规则 |
| R05 | 全局新设备规则重复 | 阻断，提示该类型全局规则已存在 |
| R06 | 编辑变更不可变字段 | 服务端拒绝 |
| R07 | Version 冲突 | 阻断，提示刷新重试 |
| R08 | 未勾选新设备且未选设备 | 阻断，提示请选择关联设备 |
| R09 | 最低 ≥ 最高 | 阻断，提示阈值区间不正确 |
| R10 | 未选或选停用等级 | 阻断，提示请选择预警等级 |
| R11 | 预警对象空；升级天数>0 但升级对象空 | 阻断 |
| R12 | 设备超出仓库权限 | 阻断或过滤不可见设备 |
| R13 | 勾选仅针对新设备且 upgrade_days>0 | 阻断，提示不支持升级预警 |
