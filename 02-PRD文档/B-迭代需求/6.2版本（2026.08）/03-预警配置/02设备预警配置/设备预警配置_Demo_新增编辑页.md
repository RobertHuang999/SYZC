## 2. 页头操作栏

| 按钮 | 规格 |
| :--- | :--- |
| 返回 / 取消 | 次操作；有未保存变更时确认「放弃未保存的修改？」 |
| 保存并生效 | **主操作**；保存即生效，无审核流；**不提供**状态下拉 |

> 启停仅在列表/详情独立动作，表单内不可改状态。

---

## 3. 新增态 vs 编辑态差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 页头标题 | 新增设备规则 | 编辑设备规则 — {规则名称} |
| 规则名称 | 空，可填 | 预填，**Readonly**（R06） |
| 预警类型 / 子类型 | 可选 | 预填，**Readonly**（R06） |
| 预警等级 | 须选启用档 | 读当前，可改 |
| 关联设备/阈值/防抖/通知 | 空或默认 | 读当前，可改 |
| Version | 不展示 | 只读展示，提交须携带（R07） |
| 保存后状态 | 生效中 | 保持原状态 |
| 已失效规则 | — | **不可进入编辑** |

## 4. 基本信息卡片

卡片标题：**基本信息**。2 列栅格。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 规则名称 | `Input` | 是 | ≤50 字，租户内唯一（R03）；编辑 Readonly |
| 预警类型 | `Select` | 是 | 5 大类；编辑 Readonly；变更重载子类型 |
| 预警子类型 | `CheckboxGroup` | 是 | 随类型动态加载（附录 A）；至少 1 项；编辑 Readonly；**「xxx设备上线」类与其他子类型互斥（R14）** |
| 预警等级 | `SelectWithSearch` | 是 | 03/01 启用档 2~20；展示色块+编码+名称；提交 `severity_level_id`（R10） |

## 5. 关联设备与触发条件卡片

卡片标题：**关联设备与触发条件**。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 所属仓库筛选 | `Select` | 否 | P02 仓库权限过滤；辅助设备穿梭框 |
| 选择关联设备 | 设备穿梭框 + `[勾选/调整设备 >]` | 条件 | R08：未勾选「仅针对新设备」时必填 |
| 仅针对新设备 | `Checkbox` | 否 | 仅当**唯一选中**当前大类「xxx设备上线」时展示（R14/R05）；勾选后隐藏穿梭框并锁定子类型 |
| 数值阈值 (最低/最高) | `NumberInput` ×2 | 条件 | R09：数值型子类型展示；最低 < 最高；温度可负 |
| 防抖判定模式 | `RadioGroup` | 是 | 按持续时长 / 按连续超标次数；瞬态 R01 锁定「立即触发」置灰 |
| 防抖时长/次数阈值 | `NumberInput` | 是 | R02 持续型须 >0；瞬态置 0 且禁用 |

### 5.1 动态表单场景（ASCII 第4~6章）

| 场景 | 关联设备 | 阈值 | 防抖 | 升级区 |
| :--- | :--- | :--- | :--- | :--- |
| A 持续型（温度异常） | 穿梭框必选 | 数值最低/最高 | 可配 | 可配 |
| B 瞬态型（剪杆破坏） | 穿梭框必选 | 隐藏 | 锁定立即触发 | 可配 |
| C 全局新设备（xxx设备上线单选） | **隐藏** | 隐藏 | 锁定立即触发 | **隐藏**（R13） |

## 6. 通知与升级策略卡片

卡片标题：**通知与升级策略**。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |

| 升级预警对象 | `SelectWithSearch`（多选） | 条件 | 超时升级接收人 |
| Version | `ReadonlyText` | 编辑 | 编辑页只读展示 |

## 7. 保存校验要点

| 规则 | 场景 | 反馈 |
| :--- | :--- | :--- |
| R03 | 名称空或重复 | 字段红字 + 阻断 |
| R04 | 设备+子类型重复 | Toast 阻断 |
| R08 | 未选设备且未勾新设备 | Toast 阻断 |
| R09 | 最低 ≥ 最高 | 字段红字 |
| R10 | 未选等级 | 字段红字 |
| R11 | 预警对象空；升级配置不完整 | 字段红字 |
| R13 | 全局新设备配置升级 | 阻断 |
| R14 | 设备上线类与其他子类型混选 | Toast 阻断 |
| R07 | Version 冲突 | Toast「请刷新后重试」 |

**保存成功**：Toast「保存成功」→ 返回列表页。
