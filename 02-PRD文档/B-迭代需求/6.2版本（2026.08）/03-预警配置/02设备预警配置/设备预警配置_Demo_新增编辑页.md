# 设备预警配置_Demo_新增编辑页

> **文档定位**：**衍生文档**——由三件套派生的原型输入；**非独立真源**。业务见[主PRD §4 PC 新增/编辑页](./设备预警配置主PRD.md#42-pc-新增编辑页)，字段见[字段清单](./设备预警配置字段清单.md)，规则见[业务规则规格](./设备预警配置业务规则规格.md)，线框见[ASCII](./设备预警配置_ASCII_新增编辑页.md)。变更须先更新三件套。

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 设备预警配置新增 / 编辑 |
| 页面目标 | 配置设备侧预警规则、触发条件、通知与升级策略 |
| 菜单路径 | `预警配置 → 设备预警配置 → 新增 / 编辑` |
| 新增路径 | `/预警配置/设备预警配置/新增` |
| 编辑路径 | `/预警配置/设备预警配置/编辑/:id` |
| 骨架结构 | 页头操作栏 → 基本信息卡片 → 关联设备与触发条件卡片 → 通知与升级策略卡片 |

> **平台不再配置防抖**：设备事件由厂商侧预过滤后回调；编辑保存 Version+1 不回写未处理流水（C08）。

---

## 2. 页头操作栏

| 按钮 | 规格 |
| :--- | :--- |
| 返回 / 取消 | 次操作；有未保存变更时确认「放弃未保存的修改？」 |
| 保存并生效 | **主操作**；保存即生效，无审核流；**不提供**状态下拉 |

> 启停仅在列表/详情独立动作，表单内不可改状态。

---

## 3. 新增态 vs 编辑态差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 页头标题 | 新增设备规则 | 编辑设备规则 — {规则名称} |
| 规则名称 | 空，可填 | 预填，**Readonly**（R06） |
| 预警类型 / 子类型 | 可选 | 预填，**Readonly**（R06） |
| 预警等级 | 须选启用档 | 读当前，可改 |
| 关联设备/阈值/通知 | 空或默认 | 读当前，可改 |
| Version | 不展示 | 只读展示，提交须携带（R07） |
| 保存后状态 | 生效中 | 保持原状态 |
| 保存后 Version | Version=1 | Version+1（C08 不回写未处理流水） |
| 已失效规则 | — | **不可进入编辑** |

## 4. 基本信息卡片

卡片标题：**基本信息**。2 列栅格。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 规则名称 | `Input` | 是 | ≤50 字，租户内唯一（R03）；编辑 Readonly |
| 预警类型 | `Select` | 是 | 5 大类；编辑 Readonly；变更重载子类型 |
| 预警子类型 | `CheckboxGroup` | 是 | 随类型动态加载（附录 A）；至少 1 项；编辑 Readonly；**「xxx设备上线」类与其他子类型互斥（R14）** |
| 预警等级 | `SelectWithSearch` | 是 | 03/01 启用档 2~20；展示色块+编码+名称；提交 `severity_level_id`（R10） |
| 处置策略 | `RadioCardGroup` ×3 | 是 | 三档：`触发即结案` / `人工解除结案` / `恢复自动结案`；chip=系统推荐（R15）；**R15c** 非白名单子类型灰显且保存阻断；偏离推荐二次确认（R15）；`RECORD_ONLY` 隐藏升级（R15a） |

### 4.1 处置策略卡片说明

| 展示名 | 枚举 | 说明 |
| :--- | :--- | :--- |
| 触发即结案 | `RECORD_ONLY` | 写入设备预警信息，触发时直接「已结案 · 有效」 |
| 人工解除结案 | `ACTION_REQUIRED` | 落账「待处置 · 有效」，须人工解除，可配升级 |
| 恢复自动结案 | `AUTO_RECOVER` | 落账「待处置 · 有效」，**R03 恢复后**自动结案；**仅 R15c 白名单**（传感器/离线/GPS 等） |

## 5. 关联设备与触发条件卡片

卡片标题：**关联设备与触发条件**。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 所属仓库筛选 | `Select` | 否 | P02 仓库权限过滤；辅助设备穿梭框 |
| 选择关联设备 | 设备穿梭框 + `[勾选/调整设备 >]` | 条件 | R08：未勾选「仅针对新设备」时必填 |
| 仅针对新设备 | `Checkbox` | 否 | 仅当**唯一选中**当前大类「xxx设备上线」时展示（R14/R05）；勾选后隐藏穿梭框并锁定子类型 |
| 数值阈值 (最低/最高) | `NumberInput` ×2 | 条件 | R09：数值型子类型展示；最低 < 最高；温度可负；二氧化碳使用 ppm，示例 400~1500 |

### 5.1 动态表单场景（ASCII 第4~6章）

| 场景 | 关联设备 | 阈值 | 升级区 |
| :--- | :--- | :--- | :--- |
| A 持续型（温度异常） | 穿梭框必选 | 数值最低/最高 | 可配（非 RECORD_ONLY） |
| D 持续型（二氧化碳异常） | 穿梭框必选 | 最低 400 ppm / 最高 1500 ppm | 可配（非 RECORD_ONLY） |
| B 瞬态型（剪杆破坏） | 穿梭框必选 | 隐藏（事件型文案） | 可配 |
| C 全局新设备（xxx设备上线单选） | **隐藏** | 隐藏 | **隐藏**（R13） |

## 6. 通知与升级策略卡片

卡片标题：**通知与升级策略**。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 通知渠道 | `CheckboxGroup` | 否 | 短信 / 邮件（选填；系统小角标自动更新） |
| 预警对象 | `SelectWithSearch`（多选） | 是 | R11 首次通知接收人 |
| 升级预警 | `Checkbox` + 天数 + 对象 | 条件 | R11：天数 >0 时升级对象必填；全局新设备规则**隐藏**（R13） |
| 升级预警天数 | `NumberInput` | 条件 | 正整数 |
| 升级预警对象 | `SelectWithSearch`（多选） | 条件 | 超时升级接收人 |
| Version | `ReadonlyText` | 编辑 | 编辑页只读展示 |

## 7. 保存校验要点

| 规则 | 场景 | 反馈 |
| :--- | :--- | :--- |
| R03 | 名称空或重复 | 字段红字 + 阻断 |
| R04 | 设备+子类型重复 | Toast 阻断 |
| R08 | 未选设备且未勾新设备 | Toast 阻断 |
| R09 | 最低 ≥ 最高 | 字段红字 |
| R10 | 未选等级 | 字段红字 |
| R11 | 预警对象空；升级配置不完整 | 字段红字 |
| R13 | 全局新设备配置升级 | 阻断 |
| R14 | 设备上线类与其他子类型混选 | Toast 阻断 |
| R07 | Version 冲突 | Toast「请刷新后重试」 |

**保存成功**：Toast「保存成功」→ 返回列表页。
