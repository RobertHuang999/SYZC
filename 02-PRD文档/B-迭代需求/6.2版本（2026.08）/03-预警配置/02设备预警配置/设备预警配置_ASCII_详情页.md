## 布局说明

**页头识别区**（`rounded-xl border bg-card p-4`）：规则名称、状态标签；右侧动作按 [第五章 动作能力矩阵](./设备预警配置业务规则规格.md#五动作能力矩阵) 显隐：

| 状态 | 页头动作 |
| :--- | :--- |
| 生效中 | 返回、编辑、停用、删除 |
| 停用 | 返回、编辑、启用、删除 |
| 已失效 | 返回、删除 |

**内容分区**（`DetailSection` 卡片）：

| 分区 | 字段（按 grid 单元排列） |
| :--- | :--- |
| 基本信息 | 规则 ID、规则名称、预警类型、预警子类型、预警等级（色块 + 编码 + 名称 + HEX） |
| 关联设备与触发条件 | 仅针对新设备、防抖判定模式、防抖生效条件、监控阈值、关联设备范围（可跨列 + 查看设备清单）、触发条件摘要（可跨列） |
| 通知与升级策略 | 通知渠道、预警对象、升级策略；**全局新设备规则不展示升级区块**（R13） |
| 系统审计 | Version（R07）、状态、创建/更新人与时间；**已失效**追加「失效原因」（C06） |

> **本期不展示**：关联未处理流水数量、引擎同步日志（运维走后台）。删除时触发 C01（未处理流水置无效）+ C04（停升级），见 第四章 删除动作二次确认文案。
