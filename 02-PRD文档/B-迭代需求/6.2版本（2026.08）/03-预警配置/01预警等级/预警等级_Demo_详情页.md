## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 预警等级详情 |
| 页面目标 | 只读查看单档预警等级的完整配置信息，并执行编辑/删除 |

## 2. DetailSection 布局规范（⚠️ 生成必遵）

与 dev 共用组件 `@/shared/components/DetailSection` + `index.css`：

| 层级 | 实现 |
| :--- | :--- |
| 分区 | `DetailSection`：标题 + 内容区 Card |
| 内容区 | `detail-section-content`：**4 列 CSS Grid**（≤1100px → 3 列），`gap: 22px 28px` |
| 单字段 | `DetailField`：**label 在上、value 在下**（`flex-direction: column; gap: 6px`） |
| label 样式 | 13px、`#86909c`（`detail-field-label`） |
| value 样式 | 14px、`#1d2129`（`detail-field-value`） |

```text
┌─ DetailSection: 基本信息 ─────────────────────────────────────────────┐
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   ← 4列 grid         │
│  │等级 ID   │ │序号      │ │严重度排序│ │等级编码  │                       │
│  │a1b2…    │ │5        │ │5        │ │L5       │   ← 上名下达           │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘                       │
└────────────────────────────────────────────────────────────────────────┘
```

**禁止**：ElDescriptions 横向「左 label 右 value」、或 `el-form` 一行两列的表单行布局。

## 3. 页头识别区

```text
{等级编码} {显示名称}   [ 已启用 / 已停用 ]          [ ← 返回 ]  [ 编辑 ]  [ 删除 ]
```

容器：`rounded-xl border bg-card p-4`，`lg:flex-row` 左右布局。

| 元素 | 规格 |
| :--- | :--- |
| 主标题 | `{等级编码}` + 空格 + `{显示名称}`，如「L5 紧急危险」 |
| 状态 Badge | 启用 → `已启用`（绿色）；停用 → `已停用`（灰色） |
| 操作按钮 | 页头右侧，见 §3.2 |

### 3.2 页头操作按钮

按使用状态与权限动态展示。**不渲染 disabled 操作**。

| 使用状态 | 展示的操作 | R-SYS-ADMIN | R-RISK-MGR |
| :--- | :--- | :---: | :---: |
| 启用 | 返回 / 编辑 / 删除 | ✅ | 返回 |
| 停用 | 返回 / 编辑 / 删除 | ✅ | 返回 |

| 操作 | 行为 |
| :--- | :--- |
| 返回 | 回到列表页，保留列表页筛选条件 |
| 编辑 | 跳转编辑页 `/预警配置/预警等级/编辑/:id` |
| 删除 | 二次确认弹窗 → 执行 R08/R09 预检后删除 |

> 配置字典范式 B **无**「已失效」态；启停通过编辑页或列表操作切换。

### 3.3 停用态页头差异示例

```text
L3 关注   [ 已停用 ]                          [ 返回 ]  [ 编辑 ]  [ 删除 ]
```

基本信息区「是否启用」展示「否」，附辅助说明「停用后 03/02、03/03 规则下拉不可选本档」。

## 4. 基本信息卡片（DetailSection）

卡片标题：**基本信息**。所有字段只读，`DetailField` 4 列栅格排列。

| 字段 | 展示规格 |
| :--- | :--- |
| 等级ID | 完整 UUID 只读展示；辅助说明「只读，下游规则/流水外键」 |
| 序号 | 整数，反映列表排序位置 |
| 严重度排序 | 整数 + 辅助文案「越高越严重」 |
| 等级编码 | 文本 |
| 显示名称 | 文本 |
| 标签颜色 | 色块圆点 + HEX 文本，如 `🔴 #C03639` |
| 同步至订单预警 | 「是」/「否」；标签旁 `[?]` hover/tap Tooltip（文案见字段清单 §2.1） |
| 是否启用 | 「是」/「否」或启用/停用 Tag |
| 等级说明 | 多行文本；空值展示 `—` |

> **不展示**：更新人/时间（见列表页；P03 后台审计）；通知渠道/预警对象/升级（R06）。

## 5. 二次确认弹窗规格

| 触发操作 | 弹窗标题 | 弹窗内容 | 确认按钮文案 | 取消按钮文案 |
| :--- | :--- | :--- | :--- | :--- |
| 删除 | 确认删除 | 删除后不可恢复，确认删除？ | **确认删除** | 取消 |
