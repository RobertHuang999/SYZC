## 3. 新增 / 编辑差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 页签标题 | 新增预警等级 | 编辑预警等级 — {等级编码} |
| 页头标题 | 新增预警等级 | 编辑预警等级 — L5 |
| 等级编码 | 空，用户填写 | 预填，可改（R03 租户唯一） |
| 标签颜色默认 | `#409EFF`（色板首项） | 读当前记录 |
| 同步至订单预警默认 | 否 | 读当前记录 |
| 是否启用默认 | 启用 | 读当前记录 |
| 严重度排序 | 保存时追加至末尾（R12，`sort_order = N+1`） | 不在本页修改，列表 ≡ 拖拽 |
| 等级ID | 保存时系统生成（R02） | 不可见、不可改 |

## 布局说明

**顶部导航 / 左侧菜单**：与列表页、详情页一致（设备与预警管理壳层；预警配置 → 预警等级选中）。

**标签页（Tabs）**：「首页」「预警等级」及当前「新增预警等级」或「编辑预警等级 — L5」。

**页头动作**：

- **返回**：回到列表页（有未保存变更时提示确认）。
- **取消**：同返回，放弃本次编辑。
- **保存**：提交表单并审计（P03），成功后返回列表页（第四章 新增/编辑流转）。

**表单区**：字段清单 第二章 全部表单项；「同步至订单预警」标签旁 `[?]`，hover / 移动端 tap 展示 文字提示 (Tooltip)（文案见 第4章）。

**不提供**：通知渠道、预警对象、升级天数/对象（R06，本页无对应表单项）。

> **本期不展示**：等级ID、序号/严重度排序、更新人/时间（系统后台维护，P03）；OPT-FUSE-01 见业务规则规格 C04。

## 保存校验要点

| 规则编号 | 场景 | 预期 |
| :--- | :--- | :--- |
| R03 | 编码重复 | 阻断保存，提示租户内唯一 |
| R07 | 新增且已有 20 档 | 「+ 新增等级」不可用或保存拦截 |
| R10 | 编辑停用 | 有关联生效规则则阻断或提示 |
| R11 | 编辑停用 | 启用数不得为 0 |
| R06 | API 写入通知字段 | 拒绝历史「通知强度」等字段 |

## 4. 「同步至订单预警」Hover 说明

| 项目 | 内容 |
| :--- | :--- |
| **触发** | 字段标签旁 `[?]` 图标；PC hover 显示，移动端 tap 显示 |
| **展示页面** | 列表表头；新增页、编辑页；详情页只读标签同样提供 |
| **规则依据** | R13、C02 |

**文字提示 (Tooltip) 文案（定稿）**：

```text
开启后：设备告警且仓库有在押订单时，订单侧同步生成预警并通知。
关闭后：仅保留设备侧告警。
6.2 不锁定出库、不触发业务熔断。
```

> 不在 文字提示 (Tooltip) 中引导用户前往其他菜单配置通知策略；仅解释本开关业务含义。
