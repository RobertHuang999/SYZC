## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 预警等级新增 / 编辑 |
| 页面目标 | 租户管理员创建或修改预警等级标签及「同步至订单预警」穿透开关 |
| 菜单路径 | `预警配置 → 预警等级 → 新增 / 编辑` |
| 新增路径 | `/预警配置/预警等级/新增` |
| 编辑路径 | `/预警配置/预警等级/编辑/:id` |
| 容器类型 | 独立页面 |
| 骨架结构 | 页头（标题 + 操作按钮）→ 基本信息表单卡片 |
| 适用端 | PC 端 |

> **本页无**：商品/明细卡片、通知渠道/预警对象/升级字段（R06）、等级ID/序号/严重度排序表单项（系统维护）。

---

## 2. 页头操作栏

| 元素 | 规格 |
| :--- | :--- |
| 位置 | 页头右侧，与标题同一行 |
| 按钮顺序（从左到右） | `返回` → `取消` → `保存` |
| `返回` | 次操作（文字/边框按钮）；有未保存变更时弹出「放弃未保存的修改？」确认 |
| `取消` | 次操作；行为同「返回」 |
| `保存` | **主操作**（实心主色按钮）；提交表单，保存即生效，无「保存并提交」 |

> 配置字典范式 B **无审核流**；不提供「保存并提交」按钮。

## 3. 新增态 vs 编辑态差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 浏览器 Tab / 页签标题 | 新增预警等级 | 编辑预警等级 — {等级编码} |
| 页头标题 | 新增预警等级 | 编辑预警等级 — {等级编码} |
| 等级编码 | 空，用户填写 | 预填当前值，可改（R03 租户唯一） |
| 标签颜色默认值 | `#409EFF`（色板首项） | 读当前记录 |
| 同步至订单预警默认值 | 否 | 读当前记录 |
| 是否启用默认值 | 启用 | 读当前记录 |
| 等级说明 | 空 | 读当前记录 |
| 严重度排序 | 保存时追加至末尾（R12，`sort_order = N+1`） | **不在本页修改**；列表页 ≡ 拖拽 |
| 等级ID | 保存时系统生成（R02） | 不可见、不可改 |

## 4. 基本信息卡片

卡片标题：**基本信息**。布局：桌面端 2 列栅格，字段自上而下排列。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 等级编码 | `Input` | 是 | placeholder：`请输入等级编码`；2~16 字符；字段下方辅助文案「2~16 字符，租户内唯一」；校验见 R03 |
| 显示名称 | `Input` | 是 | placeholder：`请输入显示名称`；2~20 字符（R05） |
| 标签颜色 | `ColorPicker` | 是 | 色板预设 + HEX 输入；默认新增 `#409EFF`；展示 `(●) #HEX` + `[色板]` 按钮；合法 HEX 校验（R05） |
| 同步至订单预警 | `RadioGroup` | 是 | 选项：`否` / `是`；标签旁 `[?]` hover/tap Tooltip（文案见 §4.1）；新增默认「否」 |
| 是否启用 | `RadioGroup` | 是 | 选项：`停用` / `启用`；新增默认「启用」；字段下方辅助文案「停用后，预警规则配置中不可选本档」 |
| 等级说明 | `Textarea` | 否 | placeholder：`等级说明（选填）`；≤100 字，右下角字数统计 |

> **不提供表单项**：通知渠道、预警对象、升级天数/对象（R06）。

### 4.1 「同步至订单预警」字段 Tooltip

| 项目 | 规格 |
| :--- | :--- |
| 触发 | 字段标签旁 `[?]`；PC hover，移动端 tap |
| 展示页面 | 新增页、编辑页（列表表头、详情页只读项同理） |
| 文案 | 见字段清单 §2.1 定稿文案 |

## 6. 保存校验与阻断反馈

| 规则 | 场景 | 页面反馈 |
| :--- | :--- | :--- |
| R03 | 编码重复或格式错误 | 字段下方红字 + 阻断保存 |
| R05 | 名称/颜色格式错误 | 字段下方红字 + 阻断保存 |
| R07 | 新增且已有 20 档 | 入口 disabled 或保存拦截 Toast |
| R10 | 编辑停用且有关联生效规则 | Toast「停用失败，须先解绑规则」 |
| R11 | 编辑停用导致启用数为 0 | Toast「启用数不得为 0」 |
| R06 | 尝试写入通知相关字段 | API 拒绝（本页无对应控件） |

**保存成功**：Toast「保存成功」→ 自动返回列表页。

## 10. 通用交互规范

### 10.1 必填标识

- 必填字段标签前加红色星号 `*`
- 点击「保存」时校验；未填必填项标红并聚焦首个错误字段

### 10.2 并发保护

- 编辑页打开时记录数据版本
- 保存时对比版本；若已被他人修改则 Toast「数据已被他人修改，请刷新后重试」
