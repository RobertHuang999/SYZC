## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 预警等级列表 |
| 页面目标 | 租户管理员查看、筛选、排序全部预警等级档位，并进入新增/编辑/详情 |
| 菜单路径 | `预警配置 → 预警等级` |
| 页面路径 | `/预警配置/预警等级` |
| 骨架结构 | 页头标题 + 筛选 Card（WarningFilterHeader）+ 数据表格 + 底栏摘要（**无分页组件**） |
| 适用端 | PC 端（6.2 移动端不提供本菜单写操作） |

> **模块特性说明**：配置字典范式 B，**无单据状态 Tab**；「启用 / 停用」通过筛选区过滤，不作为 Tab 栏。

## 2. 查询区

### 2.1 布局说明

筛选 Card 容器，顶部 `WarningFilterHeader`：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]` → `[ + 新增等级 ]`（`onAdd`；P02；达 20 档时 disabled，R07）

**默认行**：是否启用。

> 本页仅 1 个筛选项，「展开筛选」无额外行，可隐藏展开按钮或保持占位与 dev 一致。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 是否启用 | `Select` | 选项：`全部`（默认）/ `是` / `否`；切换后须点击「查询」刷新列表 |

> 字段清单第一章未标记其他「可筛选」字段；本页筛选项仅「是否启用」，与主 PRD、ASCII 线框一致。

### 2.3 筛选交互

- 筛选值为草稿态，点击「查询」后生效
- 点击「重置」恢复默认（是否启用=全部）并刷新
- 点击「查询」：按当前筛选条件刷新表格，**不清空**拖拽排序结果
- 字典体量 2~20 档，**不展示分页器**（R01）

## 4. 表格

### 4.1 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 行勾选 | **不支持** |
| 列宽拖拽 | 支持 |
| 固定列 | 拖拽手柄列、序号列左固定；操作列右固定 |
| 分页 | **无**；底栏展示「共 N 档（租户 2~20 档，无需分页）」 |
| 拖拽排序 | 左侧 `≡` 手柄拖拽调整严重度排序（R04、R12）；`sort_order` 越大越严重 |
| 空状态 | 展示「暂无预警等级」插图 + 「点击「+ 新增等级」创建第一档」 |
| 加载状态 | 表格区域 Skeleton 占位 |
| 错误状态 | Toast「加载失败，请重试」+ 表格区「重新加载」按钮 |

### 4.2 列定义

| 列名 | 内容说明 | 宽度 | 固定 |
| :--- | :--- | :--- | :---: |
| ≡（拖拽手柄） | 拖拽排序入口，hover 显示 move 光标 | 48px | 左固定 |
| 序号 | 整数 1~N，反映当前严重度排序 | 64px | 左固定 |
| 等级编码 | 可点击链接色，跳转详情页（只读） | 100px | |
| 显示名称 | 可点击链接色，跳转详情页（只读） | 120px | |
| 标签颜色 | 色块圆点 + HEX 悬停 Tooltip 展示完整色值 | 100px | |
| 同步至订单预警 | 展示「是」/「否」；**表头**旁 `[?]` 图标 hover/tap 展示 Tooltip（文案见 §4.4） | 140px | |
| 是否启用 | 展示「是」/「否」或启用/停用 Tag | 100px | |
| 等级说明 | 超长截断 + 悬停 Tooltip 全文；空值展示 `—` | 160px | |
| 更新人/时间 | 合并一列：`{更新人} / {MM-DD HH:mm}` | 160px | |
| 操作 | 行内文字操作（见 §4.5） | 120px | 右固定 |

> **不展示列**：等级ID（R02）；通知渠道/对象/升级相关字段（R06）。

### 4.3 使用状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 启用（是） | 绿色 |
| 停用（否） | 灰色 |

### 4.4 「同步至订单预警」表头 Tooltip

| 项目 | 规格 |
| :--- | :--- |
| 触发 | 表头「同步至订单预警」旁 `[?]`；PC hover，移动端 tap |
| 文案 | 见字段清单 §2.1（定稿，不在此重复定义业务规则） |

### 4.5 行内操作

行内操作使用**文字动作**，按权限与规则动态展示。**不渲染 disabled 操作**。

| 使用状态 | 展示的操作 | 权限 |
| :--- | :--- | :--- |
| 启用 | 编辑 / 删除 | R-SYS-ADMIN |
| 停用 | 编辑 / 删除 | R-SYS-ADMIN |
| 任意（只读角色） | — | R-RISK-MGR 无行内写操作 |

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转编辑页 `/预警配置/预警等级/编辑/:id` |
| 删除 | 弹出二次确认弹窗（见 §5） |

## 5. 二次确认弹窗规格

| 触发操作 | 弹窗标题 | 弹窗内容 | 确认按钮文案 | 取消按钮文案 |
| :--- | :--- | :--- | :--- | :--- |
| 删除 | 确认删除 | 删除后不可恢复，确认删除？ | **确认删除** | 取消 |

**删除失败反馈**（R08/R09 预检不通过）：Toast「删除失败，{引用/下限}不满足条件」；若 R09 引用校验失败，提示须先解绑规则。
