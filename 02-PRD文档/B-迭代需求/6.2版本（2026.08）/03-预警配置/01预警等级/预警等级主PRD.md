# 预警等级 主PRD

> **模块定位**：物联网 IoT 与风控预警体系的公共基础字典中枢，统管全平台预警严重度的度量标尺与严重度分级底座。通过为租户提供 2~20 档严重度动态字典维护能力，规范等级编码、显示名称、标签高亮色彩、拖拽排序权重（`sort_order`）及「同步至订单预警」穿透开关，为设备预警配置与订单预警配置提供标准化字典供给与司法存证快照保障。  
> **版本**：V4.0 | **更新时间**：2026-09-18 | **责任人**：森云科技（Senyun Technology）  
> **编写依据**：[预警等级字段清单.md](./预警等级字段清单.md) 是本模块所有字段定义、枚举与页面展示的唯一定义来源；[预警等级业务规则规格.md](./预警等级业务规则规格.md) 是本模块状态机、严重度权重算法、物联穿透机制、底线防御及防并发控制的唯一定义来源；配套衍生原型输入详见 [预警等级_ASCII_列表页.md](./预警等级_ASCII_列表页.md)、[预警等级_ASCII_新增编辑页.md](./预警等级_ASCII_新增编辑页.md) 与 [预警等级_ASCII_详情页.md](./预警等级_ASCII_详情页.md)。

## 一、业务背景与业务痛点

### 1.1 业务背景
在 SYZC 供应链金融动产质押风控体系中，预警事件来源多元、类型繁杂，涵盖物联网硬件异常（如摄像头离线、挂锁非法开启）、仓储环境越界（如温湿度失衡、有害气体泄漏）以及金融订单风控异动（如质押率破平仓线、存货价格暴跌等）。为了在全系统建立一致的风险严重度度量基准，指导风控人员梯次响应处置，必须设立统一的公共严重度底座。

【预警等级】字典（菜单：预警配置 → 预警等级，代号 03/01）是全平台预警严重度的**公共标签与权重底座**。系统为租户提供 2~20 档严重度动态字典维护能力，包含等级编码、对外显示名称、标签高亮色彩、拖拽排序权重（`sort_order`）及「同步至订单预警」穿透开关，为下游设备预警配置与订单预警配置提供标准化字典供给。

### 1.2 核心业务痛点
1. **【严重度口径分散导致跨域响应失准】**：各子业务系统自定等级编码（有的用数字 1~5，有的用高/中/低），导致同一事件在设备侧与订单侧显示不一致，风控人员难以横向比较风险烈度；
2. **【硬编码枚举使得定制能力丧失】**：不同资方（商业银行 vs 地方保理公司）风控等级划分深度不同（3 档 vs 5 档 vs 7 档），硬编码枚举无法适配多租户差异化风控诉求；
3. **【历史数据回写破坏司法存证】**：若等级名称、颜色或排序修改后直接级联回写历史已产生的告警单据，会导致司法取证时的历史定级事实被篡改，丧失证据效力；
4. **【物联告警泛滥引发信贷风控疲劳】**：若所有设备小微故障均穿透到金融订单侧，会造成信贷审批人员被大量无效通知淹没，缺乏灵活的等级级穿透过滤开关。

## 二、功能范围

| 包含功能范围 (In Scope) | 不包含功能范围 (Out of Scope) |
| :--- | :--- |
| - **动态档位梯次维护**：支持单租户配置 2~20 档预警等级，支持动态新增、编辑、启用、停用及拖拽调整严重度排序；<br/>- **等级视觉与语义标定**：配置等级编码、对外显示名称、标签渲染十六进制颜色（HEX）及等级业务说明；<br/>- **严重度权重度量**：以正整数 `sort_order` 作为全系统跨模块严重度判定与平仓线合规性校验的唯一度量基准；<br/>- **物联穿透开关控制**：独立维护「同步至订单预警」开关，控制设备告警是否跨域自动生成押品预警流水；<br/>- **底线防御与安全保护**：内置租户最低 2 档保护机制，严禁将全量等级删空；被有效规则引用的等级强校验阻断删除；<br/>- **停用底线控制**：停用操作强制校验租户内至少保留 1 个处于启用的等级；<br/>- **不可变历史快照机制**：预警流水产生时严格固化当前等级快照，字典修改绝对不回写历史流水；<br/>- **平铺数据表格展示**：PC 端提供整页平铺展示、手柄拖拽实时排序与列表快速启停/穿透开关。 | - **通知渠道与升级配置**：短信/邮件通知渠道、通知对象及升级时效，归属于具体【设备预警配置】(03/02) 与【订单预警配置】(03/03)；<br/>- **信贷业务熔断执行**：出库熔断与额度冻结由风控中台熔断引擎执行，本字典仅提供严重度标记；<br/>- **超过 20 档超大字典**：单租户硬性上限为 20 档，防止严重度划分碎片化；<br/>- **审批流管理**：等级字典保存即生效，系统设计不设审批流与草稿箱，全流程记录操作审计；<br/>- **移动端字典维护**：预警等级策略维护强约束在 PC 端完成，移动端不提供等级字典编辑功能。 |

## 三、模块定位与系统链路

### 3.1 模块定位矩阵

| 项目 | 内容 |
| :--- | :--- |
| **模块层级** | **【风控基础字典与元数据层】**（定义全系统严重度衡量标尺与穿透开关，非底层流水账） |
| **核心职责** | 纳管 2~20 档预警等级的编码、名称、色彩、严重度排序权重及穿透开关，为全平台预警体系提供统一的公共严重度底座 |
| **配置来源** | 授权风控或系统管理人员在 PC 端手动新增、编辑或拖拽调序维护（保存即生效） |
| **上游依赖** | **系统内置模板基线**：新租户初始化时自动开通 5 档预警等级示例数据（L1~L5）；<br/>**RBAC 权限体系**：严格限定管理员角色（`R-SYS-ADMIN`）具备维护权限。 |
| **下游影响** | **【设备预警配置】策略（菜单：预警配置 → 设备预警配置，代号 03/02）**：提供等级下拉选项与严重度快照源头；<br/>**【订单预警配置】策略（菜单：预警配置 → 订单预警配置，代号 03/03）**：提供等级下拉选项与监管业务率双控（LTV_DUAL）严重度比较依据；<br/>**【设备预警信息】台账（菜单：预警信息 → 设备预警信息，代号 02/01）**：告警触发时固化等级快照，依据穿透开关决定是否外送；<br/>**【押品预警信息】台账（菜单：预警信息 → 押品预警信息，代号 02/02）**：承接开启穿透开关且库房有在押订单的物联穿透告警流水。 |

## 五、状态机与动作能力矩阵

### 5.1 状态定义
* 预警等级作为风控基础配置字典，**不设审批单据状态机**，采用二态使用状态管理：
  - **启用 (`ENABLED`)**：有效状态。下游预警规则下拉框可见并允许配置；
  - **停用 (`DISABLED`)**：停用状态。下游规则下拉框不可新选，存量规则保留快照继续运行。

### 5.2 动作能力控制矩阵

| 动作名称 | 启用状态 (`ENABLED`) | 停用状态 (`DISABLED`) | 核心前置约束与边界条件 |
| :--- | :---: | :---: | :--- |
| **查看列表 / 详情** | ✅ | ✅ | 具备字典查看权限，全量可见 |
| **新增等级** | ✅ | ✅ | 租户当前等级档位总数必须在 $[2, 20)$ 范围内；达到 20 档自动置灰禁用 |
| **编辑等级** | ✅ | ✅ | 编码租户内唯一，支持修改名称、颜色与说明；修改后不回写历史流水 |
| **拖拽调整排序** | ✅ | ✅ | 鼠标释放后在单事务内重新计算并持久化当前列表全量记录的 `sort_order` |
| **快速切换穿透开关** | ✅ | ✅ | 列表行内点击 Switch 快速翻转 `sync_to_order_warn`，热更新风控引擎 |
| **停用等级** | ✅ | ❌ | 强校验租户内必须保留至少 1 档处于启用状态（遵循 R05）；仅剩 1 档启用时阻断 |
| **启用等级** | ❌ | ✅ | 点击后立即恢复下游规则下拉可选资格 |
| **删除等级** | ✅ (需校验) | ✅ (需校验) | 1. 租户档位数 $> 2$（最低 2 档保护）；<br/>2. 未被任何有效规则引用（遵循 R04 强阻断） |

## 六、页面交互规格索引

### 6.1 PC 端列表页（`P-WCFG-001`）
* **对应文档**：[预警等级_ASCII_列表页.md](./预警等级_ASCII_列表页.md)
* **核心规格**：
  - **页面布局**：平铺数据表格（无分页，整页展示 2~20 条数据）；
  - **顶部操作栏**：
    - 左侧展示「当前档位数：X / 20」轻量容量计数；
    - 右侧提供黄色主按钮【+ 新增预警等级】（达到 20 档上限时置灰并悬浮提示）；
    - 筛选控件：单选切换「全部 / 仅启用」；
  - **数据表格区（10 列）**：
    - `序号`（含拖拽手柄图标）、`等级编码`、`显示名称`、`标签颜色`（色块+HEX文本）、`严重度排序`（数值越大越严重）、`同步至订单预警`（行内 Switch 开关）、`是否启用`（行内 Switch 开关）、`等级说明`、`更新人/时间`（双行）、`操作`；
  - **拖拽调序**：鼠标按住列表左侧手柄上下拖动，释放后自动发起调序请求并全量重算 `sort_order`；
  - **行操作列**：提供【详情】、【编辑】、【删除】（悬浮提示删除保护规则）。

### 6.2 新增 / 编辑抽屉页（`P-WCFG-001-DRAWER`）
* **对应文档**：[预警等级_ASCII_新增编辑页.md](./预警等级_ASCII_新增编辑页.md)
* **核心规格**：
  - **唤起方式**：点击【+ 新增预警等级】或行操作【编辑】从屏幕右侧滑出抽屉；
  - **表单输入项**：
    - 等级编码：单行文本输入框，2~16 字符，英文/数字组合，租户内唯一，编辑时只读锁定；
    - 显示名称：单行文本输入框，2~20 字符，必填，如「严重风险」；
    - 标签颜色：颜色选择器（ColorPicker），提供推荐预置色板，支持输入标准十六进制 HEX 色值；
    - 同步至订单预警：滑动开关，默认关闭；
    - 是否启用：滑动开关，默认开启；
    - 等级说明：多行文本框，最多 100 字符，选填；
  - **底栏动作**：【取消】与黄色主按钮【保存】，保存成功后关闭抽屉并刷新列表。

### 7.2 非功能性需求
* **调序响应时效**：拖拽排序持久化更新事务耗时 $\le 500\text{ms}$，字典读缓存支撑万级预警高频匹配并发；
* **数据一致性保护**：删除操作与下游规则库执行分布式事务强一致性校验，杜绝悬空引用与脏数据；
* **不可变操作审计**：等级的新增、编辑、排序调整、启停用与删除操作 100% 记录操作人、时间、客户端 IP 与前后数据镜像，审计日志保存 5 年以上备查。
