## 布局说明

**页头识别区**（`rounded-xl border bg-card p-4`，左右 flex）：等级编码 + 显示名称、启用/停用状态标签；右侧动作按 [第三章 动作能力矩阵](./预警等级业务规则规格.md#三动作能力矩阵)：

| 使用状态 | 页头动作 |
| :--- | :--- |
| 启用 | 返回、编辑、删除 |
| 停用 | 返回、编辑、删除 |

> 配置字典范式 B **无**「已失效」态；启停通过编辑页或列表开关操作（第四章 流转表）。

**内容分区**（`DetailSection` 卡片）：

| 层级 | 规格 |
| :--- | :--- |
| 分区容器 | 白底 Card：标题栏 `detail-section-header` + 内容区 `detail-section-content` |
| 内容区栅格 | `display: grid; grid-template-columns: repeat(4, 1fr); gap: 22px 28px` |
| 响应式 | `max-width: 1100px` 时降为 **3 列** |
| 单字段 | `DetailField`：**label 在上、value 在下**（`flex-direction: column`），每个字段占 1 个 grid 单元 |
| 跨列字段 | 等级说明等长文本可 `grid-column: 1 / -1` 占满整行 |

| 分区 | 字段（按 grid 单元排列） |
| :--- | :--- |
| 基本信息 | 等级ID（R02）、序号、严重度排序（R04）、等级编码、显示名称、标签颜色、同步至订单预警（R13、C02，含 `[?]` Tooltip）、是否启用（R10~R11、C03）、等级说明（R14） |

> **删除二次确认**：「删除后不可恢复，确认删除？」；若 R09 引用校验失败，轻提示 (Toast) 提示须先解绑规则。
