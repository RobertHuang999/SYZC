## 3. 新增态 vs 编辑态差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 规则名称 | 空，可填 | Readonly（R06） |
| 关联订单 | 可选（过滤已有规则订单） | Readonly（R06） |
| 订单类型/货主/货物 | 选订单后按订单主数据自动带出全部货物，多个货物逐项平铺（R02） | 只读 |
| 各风控策略启用开关 | 默认 OFF | 读当前启用状态 |
| Version | 不展示（首次策略保存后生成） | 只读，**每次策略保存**携带（R07） |
| 保存粒度 | **逐条策略保存**；首次保存创建主表 | **逐条策略保存**；保持生效中 |
| 关闭已启用子项 | 保存 OFF 后生效 | 该子项未处理流水置无效（C01a） |

## 4. 基本信息卡片

| 字段 | 控件类型 | 必填 | 规格 |
| :--- | :--- | :---: | :--- |
| 规则名称 | `文本输入框` | 是 | ≤50 字，租户唯一（R01）；编辑 Readonly |
| 关联订单 | `下拉选择框WithSearch` | 是 | 仅返回有效抵/质押订单；R03/R04；编辑 Readonly |
| 订单类型 | `ReadonlyText` | 自动 | 抵押 / 质押 / 监管服务三类之一；旧历史“监管”不展示 |
| 货主 | `ReadonlyText` | 自动 | 脱敏手机号 |
| 货物 | `ReadonlyText` | 自动 | 大类/品类/规格 - 数量+单位；多个货物逐项平铺 |
| Version | `ReadonlyText` | 编辑 | 乐观锁；每次策略保存成功后刷新 |

> **首次保存时机**：新增页在用户点击任一策略卡片「保存该策略」时，一并校验并提交基本信息字段（R01/R04），创建综合规则主表。

## 5. 预警策略配置区（6 大卡片）

卡片标题：**预警策略配置（逐条独立保存 · 至少启用 1 项 · R07a）**。

每张策略卡片结构：

```text
[Switch ON/OFF]  策略 N：{名称}  [ 收起/展开 ▼▲ ]
  └─ 策略专属参数字段
  └─ 预警等级（SelectWithSearch，提交 severity_level_id）
  └─ 通知渠道（CheckboxGroup：`短信`/`邮件`，选填；移动端「押品预警信息」待处置红点自动展示，无需配置）
  └─ 预警对象（多选，选填；仅勾选短信/邮件后展示）
  └─ 升级预警（Checkbox + 天数 + 对象；文案随已选渠道动态生成，如「将通过短信、邮件逐级上报」；仅勾选短信/邮件后展示）
  └─ 底部操作区：● 未保存 / ✓ 已保存  |  [ 取消修改 ]  [ 关闭并停用 ]  [ 保存该策略 ]
     · 取消修改：脏态时出现（outline）
     · 关闭并停用：已保存为启用态时出现（destructive，位于保存左侧）
     · 保存该策略：primary
```

### 5.1 六策略卡片清单

| # | 策略名称 | 适用说明 | 核心参数字段 |
| :---: | :--- | :---: | :--- |
| **【价格下跌】(1)** | 价格下跌 | 仅抵押/质押 | 跌幅比例（R15） |
| **【抵/质押率双控】(2)** | 抵/质押率双控 | 仅抵押/质押 | 当前 抵/质押率（LTV, Loan-to-Value） 只读 / 补仓·平仓双阈值 / 分线解除方式 / 单等级（R10、R12a、R13d） |
| **【仓储巡检超期】(3)** | 仓储巡检超期 | 三类订单 | 巡检人 + 周期动态表格（R17） |
| **【解抵押/解质押/监管服务】(4)** | 解抵押/解质押/监管服务超时监控 | 按订单类型生成 | 订单货物行自动带出，仅填写超时天数（R14） |
| **【盘点账实差异】(5)** | 盘点账实差异 | 三类订单 | 盘点差异参数（R16） |
| **【贷中风控模型】(6)** | 贷中风控模型 | 仅抵押/质押 | 模型参数与台账同步（R18） |

> 实际 6 卡片命名与 ASCII 线框一致：价格下跌、抵质押率双控、仓储巡检、解抵押/解质押/监管服务超时、盘点差异、贷中风控。超时卡片中的货物行来自订单主数据，不能单独添加批次或删除货物。

### 5.2 订单类型下线约束

订单选择器仅返回抵押、质押、监管服务三类有效订单；旧历史“监管”不返回、不展示，也不映射为“监管服务”。

### 5.3 抵/质押率（LTV, Loan-to-Value） 双阈值 · 分线解除 · 单等级（表格布局）

原型组件：`LtvDualStrategyFields`（策略 2 卡片内嵌）

- 只读展示**当前订单抵/质押率 (抵/质押率（LTV, Loan-to-Value）)**（如 `88.50%`）；无法计算时展示 `—`，并在下方紧邻 `抵/质押率（LTV, Loan-to-Value）_UNAVAILABLE_HINT` 说明原因（DZY-R08a）。
- 有当前率时展示**刻度示意条**（当前点 / 补仓线 / 平仓线）。
- **双行表格**：列 `类型 | 触发条件 | 解除方式（多选）`。
  - 触发条件：`若 抵/质押率 (抵/质押率（LTV, Loan-to-Value）) 超过 [阈值] % 时触发预警` + 小字 `不含等于该阈值`
  - 解除方式：checkbox 多选 `补仓 / 平仓 / 部分结清`
- 卡片底部短提示（抵质押率底部提示）：R13d/R13e 命中与解除规则。
- **Mock 无 抵/质押率（LTV, Loan-to-Value） 示例**：编辑 `owc-011`（PO202604-20）或新增时选 `PO202608-1002`。
- 整个卡片仅绑定一个 `severity_level_id`（R10）；R09 要求平仓线严格高于补仓线。
- **R12a**：两线解除方式各至少选 1 项；保存未选时字段下红字提示。

### 5.4 仓储巡检超期 · 责任人 + 独立周期（动态表格）

原型组件：`InspectionConfig标签页le`（策略 3 卡片内嵌）

- 标题「巡检责任人配置」，右上角 `[ + 添加巡检人 ]`；至少保留 1 行，末行不可删至 0 行。
- **动态表格**列：`序号 | 巡检人 | 巡检周期 | 操作（删除）`。
- **巡检人**：`OrgUser下拉选择框` 按组织架构级联选择，`max下拉选择框ion=1`（每行单选 1 人）；展示格式如「孙巡检(仓管部)」。
- **巡检周期**：数字输入 + 文案「每 [N] 天超期预警」；须为正整数。
- **R17**：策略开启状态 保存时至少 1 组有效「巡检人 + 周期」；巡检人不可重复。
- **Mock 示例**：编辑 `owc-001` 可见孙巡检 7 天 + 李四 14 天两行配置。

## 6. 卡片交互规则

### 6.1 编辑与展开

- 策略开关关闭：折叠面板收起，内部字段不校验
- 策略开关开启：展开面板，**保存时**校验该子项全部必填
- 新增页默认全部 OFF；编辑页读真实状态
- 下拉等级读 03/01 启用档；展示编码+名称+色块

### 6.2 逐条保存（核心交互）

| 行为 | 规格 |
| :--- | :--- |
| **保存该策略** | 每张卡片底部 primary 按钮；API 仅提交当前 `strategy_type` + 基本信息（新增首次）+ Version |
| **取消修改** | 脏态时出现；恢复该卡片至 baseline 快照，Toast「{策略名称}已恢复至上次保存内容」 |
| **关闭并停用** | 已保存为启用态时出现（destructive）；ORD-R07a 阻断或弹窗确认后自动 OFF 保存；Toast「{策略名称}已关闭并停用」 |
| **预警通知对象** | 选填（ORD-R19）；勾选短信/邮件后展示，无必填星号 |
| **升级预警文案** | `buildUpgradeWarningLabel(notify_channels)` 动态生成（ORD-R21） |
| **脏数据状态** | 卡片内字段变更后显示「● 未保存」；保存成功后显示「✓ 已保存」并刷新 Version |
| **保存成功** | 浮窗提示：「{策略名称}保存成功」；**不跳转列表**，停留当前页继续配置其他策略 |
| **策略开关关闭 保存** | 提交 策略处于关闭状态；若为最后 1 项已启用策略则 R07a 阻断 |
| **阈值修改保存** | 修改阈值保存成功后，系统即时触发实时重算，若仍命中且有未解除流水则旧流水置作废（C07）并生成新流水推送 |
| **升级策略保存** | 修改升级天数或开启升级保存后，即时根据首次触发时间重算升级状态（R20a/R24a），超期立即补发升级预警 |
| **并发** | 携带 Version；冲突时 浮窗提示：「数据已被他人修改，请刷新重试」 |
| **离开拦截** | 任一卡片处于「未保存」状态点击返回/取消 → 确认弹窗 |

### 6.2.1 关闭并停用确认弹窗

原型组件：`Dialog`（`OrderWarningConfigFormPage`）

| 项 | 规格 |
| :--- | :--- |
| 触发 | 点击「关闭并停用」且通过 R07a 前置校验 |
| 标题 | 关闭并停用该策略 |
| 说明 | 关闭后将停止「{策略名称}」的风控判定，该策略下未处理的预警流水将自动作废，相关升级任务同步终止。此操作保存后立即生效。**不向用户展示规则编号。** |
| 按钮 | 【取消】outline · 【确认关闭并停用】destructive |

### 6.3 新增首次保存

1. 校验基本信息 R01/R04
2. 创建 `order_rule_config`（Version=1，状态=生效中）
3. Upsert 当前策略子项
4. 若启用贷中风控子项 → 触发 C04 台账同步

## 7. 保存校验（单策略粒度）

| 规则 | 反馈 |
| :--- | :--- |
| R01 名称重复（首次保存） | 阻断 |
| R04 订单已有规则（首次保存） | 阻断 |
| R07a 关闭最后 1 项已启用策略 | 「请至少启用一项预警策略」 |
| R08~R09 抵/质押率（LTV, Loan-to-Value） 区间（保存抵质押率 LTV 子项） | 「平仓线必须高于补仓线」 |
| R10 未选等级（保存该开启子项） | 「请选择{子项}的预警等级」 |
| ORD-R19 预警通知对象 | 选填；勾选渠道后展示，未配置不阻断保存 |
| ORD-R21 升级文案联动 | Checkbox 文案随 `notify_channels` 实时更新；升级下发渠道与已选渠道一致 |
| R20 已勾选短信/邮件且开启升级但不完整 | 「请完善升级天数与对象」；升级通知仅短信 |
| R12 监管提交禁用策略 | 服务端拒绝 |
| R07 Version 冲突 | 「数据已被他人修改，请刷新重试」 |
