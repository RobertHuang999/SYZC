## 4. 新增 / 编辑差异对照

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 页签标题 | 新增订单规则 | 编辑订单规则 — {规则名称} |
| 规则名称 | 空，用户填写 | 预填，**置灰不可改**（R06） |
| 关联订单 | 可选（过滤已有规则订单） | 预填，**置灰不可改**（R06） |
| 各子项开关与参数 | 默认关闭，按需开启配置 | 读当前各子项真实开启状态与参数，支持自由开关与修改 |
| Version | 不展示 | 只读展示，提交须携带（R07 乐观锁） |
| 保存后状态 | 生效中（ACTIVE） | 保持生效中 |
| 子项关闭影响 | — | 若关闭原启用的子项，该子项未处理流水自动置无效（C01a） |

## 5. 保存校验要点

| 规则编号 | 场景 | 预期处理 |
| :--- | :--- | :--- |
| **R01** | 名称空或重复 | 阻断，提示「规则名称已存在」 |
| **R04** | 选择已配置过规则的订单 | 阻断，提示「该订单已配置预警规则，请前往编辑」 |
| **R07a** | 6 项策略全部处于关闭 [OFF] 状态点击保存 | 阻断，提示「请至少启用一项预警策略」 |
| **R08~R09** | 抵质押率开启，平仓线 ≤ 补仓线 | 阻断，提示「平仓线必须高于补仓线」 |
| **R10/R10a** | 任意开启的子项未选预警等级 | 阻断，提示「请选择{子项名称}的预警等级」 |
| **R19** | 任意开启的子项未选预警对象 | 阻断，提示「请配置{子项名称}的预警对象」 |
| **R20** | 开启升级预警但天数空或对象空 | 阻断，提示「请完善升级天数与对象」 |
| **R12** | 监管订单强行提交抵质押率/贷中参数 | 服务端拒绝保存 |
