## 4. 逐条策略保存交互说明

> **技术约束**：策略子项（`order_rule_strategy`）在服务端按 `strategy_type` 维度独立写入，不支持整页 6 条策略一次性提交。前端交互须与 API 粒度对齐：**每条策略卡片独立编辑、独立保存**。

### 4.1 页级操作

| 操作 | 说明 |
| :--- | :--- |
| **← 返回 / 取消** | 返回列表页；若存在**未保存**的策略卡片修改，弹出二次确认 |
| ~~保存并生效~~ | **已移除**——不再提供整页统一保存入口 |

### 4.2 策略卡片级操作

| 元素 | 说明 |
| :--- | :--- |
| **● 未保存 / ✓ 已保存** | 卡片底部左侧脏数据状态指示；保存成功后刷新为「已保存」并更新 Version |
| **[ 取消修改 ]** | 仅脏态时出现（outline）；恢复该卡片至上次保存快照，不弹窗、不离开页面 |
| **[ 关闭并停用 ]** | 仅对已保存为启用态（`savedStrategies=ON`）的卡片展示（destructive）；位于「保存该策略」左侧；确认后自动以 OFF 提交保存 |
| **[ 保存该策略 ]** | 每张已展开的策略卡片底部 primary 主操作；仅提交当前 `strategy_type` 对应字段 |
| **策略开关（开启/关闭）** | 开关变更后须点击该卡片「保存该策略」才生效；亦可通过「关闭并停用」一键关闭并保存 |
| **预警通知对象** | 勾选短信/邮件后展示组织选择器；**选填**（ORD-R19），未配置不阻断保存 |
| **启用升级预警** | Checkbox 文案随已选 `短信`/`邮件` 动态联动（ORD-R21）；开启后升级天数与升级对象必填 |

### 4.2.1 关闭并停用确认弹窗（用户可见文案）

| 项 | 说明 |
| :--- | :--- |
| **标题** | 关闭并停用该策略 |
| **说明** | 关闭后将停止「{策略名称}」的风控判定，该策略下未处理的预警流水将自动作废，相关升级任务同步终止。此操作保存后立即生效。 |
| **按钮** | 【取消】（outline）· 【确认关闭并停用】（destructive） |
| **R07a 前置阻断** | 若为最后 1 项已启用策略，不弹窗，浮窗提示「综合预警规则必须至少保留 1 项有效开启的策略」 |
| **保存成功** | 浮窗提示「{策略名称}已关闭并停用」；卡片折叠为 OFF |

### 4.3 新增 vs 编辑保存流程

```text
【新增】
  1. 填写基本信息（规则名称 + 关联订单）
  2. 展开目标策略卡片 → 配置参数 → 点击 [ 保存该策略 ]
     └─ 首次保存：校验 R01/R04 后创建综合规则主表 + 该策略子项（Version=1）
     └─ 后续保存：仅 upsert 对应 strategy_type 子项（Version+1）
  3. 按需重复步骤 2 配置其余策略；不要求一次配齐 6 项

【编辑】
  1. 基本信息只读（R06）
  2. 修改任意策略卡片 → 点击该卡片 [ 保存该策略 ]
     └─ 携带 Version 乐观锁（R07）；仅更新当前子项
     └─ 阈值修改后保存 → 立即触发当前订单实时重算；若仍命中且有未解除流水，旧流水置已作废（C07）并生成新预警流水推送
     └─ 升级天数/开关修改后保存 → 立即按首次触发时间重算升级状态（R20a/R24a），已超期立即补发升级预警
  3. 关闭子策略：可手动关 Switch 后点「保存该策略」，或点「关闭并停用」确认后自动 OFF 保存 → 该子项 is_enabled=0，级联作废未处理流水（ORD-C01a）
```

### 4.4 R07a 校验时机调整

| 场景 | 预期处理 |
| :--- | :--- |
| 保存某策略且 策略开启状态 | 仅校验该子项 R08~R20 参数 |
| 保存某策略且 策略关闭状态 | 若其为**最后 1 项**已启用策略 → 阻断，提示「请至少启用一项预警策略」 |
| 新增页尚未保存任何策略 | 允许离开；列表不出现该规则（主表尚未创建） |
| 编辑页全部策略均已关闭后保存最后 1 项为 OFF | 阻断（R07a） |

| 规则名称 | 空，用户填写 | 预填，**置灰不可改**（R06） |
| 关联订单 | 可选（过滤已有规则订单） | 预填，**置灰不可改**（R06） |
| 各子项开关与参数 | 默认关闭，按需开启配置 | 读当前各子项真实开启状态与参数，支持自由开关与修改 |
| Version | 不展示（首次策略保存后生成） | 只读展示，**每次策略保存**须携带（R07 乐观锁） |
| 保存粒度 | **逐条策略保存**；首次保存创建主表 | **逐条策略保存**；保持生效中 |
| 子项关闭影响 | — | 保存 OFF 后，该子项未处理流水自动置无效（C01a） |
| 页级保存按钮 | **无** | **无** |

## 6. 保存校验要点

| 规则编号 | 场景 | 预期处理 |
| :--- | :--- | :--- |
| **R01** | 首次策略保存时名称空或重复 | 阻断，提示「规则名称已存在」 |
| **R04** | 首次策略保存时选择已配置过规则的订单 | 阻断，提示「该订单已配置预警规则，请前往编辑」 |
| **R07a** | 保存 OFF 且为最后 1 项已启用策略 | 阻断，提示「请至少启用一项预警策略」 |
| **R08~R09** | 保存监管业务率双控子项且开启，平仓线 ≤ 补仓线 | 阻断，提示「平仓线必须高于补仓线」 |
| **R10** | 保存某开启子项未选预警等级 | 阻断，提示「请选择{子项名称}的预警等级」 |
| ~~R19~~ | ~~已勾选短信/邮件但未选预警对象~~ | **已废弃**：预警通知对象改为选填；勾选渠道后未配置对象时不阻断保存 |
| **R20a** | 已勾选短信/邮件且开启升级，但升级配置不完整 | 阻断，提示「请完善升级天数与对象」；升级下发渠道随已选通知渠道（ORD-R21） |
| **R12** | 提交旧历史“监管”类型 | 服务端拒绝；提示订单类型已下线且不映射为监管服务 |
| **R07** | 编辑时 Version 冲突 | 阻断，提示「数据已被他人修改，请刷新重试」 |
