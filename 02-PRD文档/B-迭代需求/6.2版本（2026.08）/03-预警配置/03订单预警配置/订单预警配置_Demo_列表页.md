## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 订单预警配置列表 |
| 页面目标 | 风控人员筛选一站式多策略订单规则，进入新增/编辑/详情 |
| 菜单路径 | `预警配置 → 订单预警配置` |
| 页面路径 | `/预警配置/订单预警配置` |

## 2. 查询区

### 2.1 布局说明

筛选 Card 容器，顶部 `WarningFilterHeader`：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]` → `[ + 新增订单规则 ]`（`onAdd`；风控写权限）

**默认行**：规则名称、订单号、订单类型、已启用预警项（多选）、状态。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 规则名称 | `Input` | 模糊匹配 |
| 订单号 | `Input` | 模糊匹配 |
| 订单类型 | `Select` | 全部（默认）/ 抵/质押 / 监管 |
| 已启用预警项 | `Select`（多选） | 6 类：超时/跌价/盘点/巡检/抵质押率/贷中；命中任一即返回 |
| 状态 | `Select` | 全部（默认）/ 生效中 / 已失效 |

### 2.3 筛选交互

- 筛选值为草稿态，点击「查询」后生效，页码重置为 1
- 点击「重置」恢复默认筛选并刷新

## 4. 表格

### 4.1 列定义

| 列名 | 内容说明 | 宽度 |
| :--- | :--- | :--- |
| 序号 | 当前页从 1 起 | 64px |
| 规则名称 | 链接色进详情 | 180px |
| 订单号 | 文本 | 140px |
| 订单类型 | 抵/质押 / 监管 | 100px |
| 货主/货物摘要 | 货主 + 货物简写 | 160px |
| 已启用预警项摘要 | 彩色徽章集合，如 `[跌价(L3)] [质押率(L3/L4)]` | 240px |
| 状态 | Tag | 100px |
| 更新时间 | `YYYY-MM-DD HH:mm:ss` | 160px |
| 操作 | 行内文字 | 140px |

### 4.2 状态 Tag

| 状态 | 颜色 |
| :--- | :--- |
| 生效中 | 绿色 |
| 已失效 | 橙灰 |

### 4.3 行内操作

| 状态 | 展示的操作 |
| :--- | :--- |
| 生效中 | 编辑 / 详情 / 删除 |
| 已失效 | 详情 / 删除 |

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转 `/预警配置/订单预警配置/编辑/:id` |
| 详情 | 跳转 `/预警配置/订单预警配置/详情/:id` |
