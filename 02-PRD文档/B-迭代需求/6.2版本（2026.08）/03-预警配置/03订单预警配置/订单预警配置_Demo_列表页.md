## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 订单预警配置列表 |

## 2. 查询区

### 2.1 布局说明

筛选区卡片顶部：

- 左侧：筛选条件
- 右侧：展开筛选 / 收起筛选 → 重置 → 查询 → + 新增订单预警规则（需风控写权限）

**默认行**（与字段清单第一章「筛选控件与匹配=是」一致）：规则名称、订单编号、订单类型、已启用预警项、规则状态。

### 2.2 查询条件

| 字段名称 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 规则名称 | 单行文本输入框 | 模糊匹配 |
| 订单编号 | 单行文本输入框 | 精确匹配 |
| 订单类型 | 下拉单选框 | 全部（默认）/ 抵押 / 质押 / 监管服务 |
| 已启用预警项 | 下拉多选框 | 六类子策略；命中任一已启用项即返回该规则 |
| 规则状态 | 下拉单选框 | 全部（默认）/ 生效中 / 已失效 |

### 2.3 筛选交互

- 筛选值为草稿态，点击「查询」后生效，页码重置为 1
- 点击「重置」恢复默认筛选并刷新

## 4. 表格

### 4.1 列定义

列名与 [字段清单 §四 列表展示顺序](./订单预警配置字段清单.md#四展示与引用规则) 一致：

| 列名 | 内容说明 | 备注 |
| :--- | :--- | :--- |
| 序号 | 当前页从 1 起 | 翻页重计 |
| 规则名称 | 链接色，点击进入详情 | |
| 订单编号 | 关联订单编号 | |
| 订单类型 | 抵押 / 质押 / 监管服务 | |
| 货主姓名/手机号 | 货主姓名与脱敏手机号，可双行 | 字段清单合并展示口径 |
| 在押货物摘要 | 货物明细摘要 | 多货品逐项摘要 |
| 已启用预警项 | 彩色标签集合，展示已开启子项 | 如「价格下跌」「监管业务率双控」 |
| 规则状态 | 状态标签 | |
| 创建人/创建时间 | 双行 | |
| 更新人/更新时间 | 双行；列表默认按更新时间降序 | |
| 操作 | 行内文字按钮 | |

### 4.2 规则状态标签

| 规则状态 | 颜色 |
| :--- | :--- |
| 生效中 | 绿色 |
| 已失效 | 橙灰 |

### 4.3 行内操作

| 规则状态 | 展示的操作 |
| :--- | :--- |
| 生效中 | 编辑 / 详情 / 删除 |
| 已失效 | 详情 / 删除 |

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转 /预警配置/订单预警配置/编辑/:id |
| 详情 | 跳转 /预警配置/订单预警配置/详情/:id |
