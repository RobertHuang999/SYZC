# 供应链监管业务 · 6.2 下线与退役说明

> **版本归属**：SYZC 6.2 版本（2026.08）  
> **模块动作**：⚠️ **【下线退役（Decommissioned / Cancelled）】**  
> **原菜单路径**：`融资/监管 → 监管业务 → 供应链监管业务`  
> **页面 ID**：P-RZ-010  
> **权限状态**：`cancelled`（参见 [功能与数据权限清单.csv](../../../🌟🌟🌟-最新基准版/00-功能与数据权限/功能与数据权限清单.csv) 第 104 行）  
> **责任团队**：森云科技（Senyun Technology）产品与架构组

---

## 一、下线原因与背景

1. **订单模型统一升级**：
   - 在 6.2 版本前，存货监管业务存在历史旧单据形态（“供应链监管订单 / 监管”）。
   - 6.2 版本对存货质押与动态监库的订单预警体系进行了全面重构，统一收口为三类标准订单类型：`抵押`、`质押`、`监管服务`。
2. **菜单功能退役**：
   - 原独立的「供应链监管业务」菜单（URL: `/wrlaa/jgdd`）所承载的旧历史监管订单业务正式下线，不再作为独立菜单向用户提供服务。
   - 存货监管全生命周期管理全面合流并入新的抵质押与监管服务订单体系。
