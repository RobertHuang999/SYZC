## 二、监管管理 · 三种可运营单据（6.2 产品口径）

### 2.1 与旧文案「监管订单关闭」的关系（必读）

| 概念 | 6.2 口径 |
| :--- | :--- |
| **旧监管订单 / 供应链监管业务** | 原路径 `融资/监管 → 监管业务 → 供应链监管业务`（`12-监管业务-供应链监管业务`）**6.2 菜单下线**，不恢复独立入口。 |
| **基准 PRD V2.6「监管订单关闭」** | 描述 **上述旧菜单** 与 **H5 独立「监管订单」菜单** 下线，**不是** 否定第三种单据类型。 |
| **6.2 第三种类型** | **监管管理** 内可运营 **监管订单**（Tab 展示名 **监管服务**），与 **抵押订单**、**质押订单** 并列。 |

### 2.2 PC · 监管管理页

- **三个 Tab**：【抵押订单】｜【质押订单】｜【监管服务】。
- Tab「监管服务」对应单据类型 **监管订单**（新运营）；与旧「供应链监管业务」**无菜单复用**。
- 旧链路历史数据：**只读**归档。

### 2.3 H5 · 工作台

| 调整前 | 调整后 |
| :--- | :--- |
| **抵质押订单** + **监管订单** 两个菜单 | **监管管理** 单入口，Tab：**抵押 / 质押 / 监管服务** |
| **线上抵质押办理** | **线上监管业务办理** |
