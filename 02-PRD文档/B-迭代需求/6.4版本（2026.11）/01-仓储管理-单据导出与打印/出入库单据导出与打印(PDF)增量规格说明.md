## 一、 需求背景与核心设计决策

### 1.1 业务场景与设备介质特性
在供应链金融存货质押与大宗仓储实际作业中，存货发生物理出入库时，需要生成具有法律留痕效力的纸质凭证，供货主、仓管员、承运司机与监管员现场核对并手写签字。
不同作业终端和流转环节使用的打印设备与纸张截然不同，系统必须提供一套能自适应多种纸张尺寸的导出/打印方案：
1. **通用办公激光/喷墨打印机**：
   * **A4 尺寸（210 mm × 297 mm · 纵向）**：用于银行/资金方审查底稿、司法存证、公司档案室正式归档，版面大、信息完整。
   * **A5 尺寸（210 mm × 148 mm · 横向）**：用于办公室对账、随车携带的便携凭单。
2. **针式点阵式打印机（如 EPSON LQ-630K）**：
   * **二等分连续复写纸（约 241 mm × 139.5 mm · 横向连续走纸）**：现场地磅房/卡口出入库标配，使用多联无碳复写纸，一打多出，司机、仓管、门卫现场手写签字分联留存。

---

### 1.2 核心设计原则与业务规则（已定稿）

| 维度 | 决策方案 | 业务与技术原因 |
| :--- | :--- | :--- |
| **打单介质** | **全空白连续纸** | 由系统直接绘制实线表格线框、文本与表头，不依赖外部预印底纸，通用性最强。 |
| **联次管理** | **免设独立联次标识** | 各联版式完全统一，依赖无碳复写纸本身的纸张颜色（白/红/黄/绿）进行物理分流，降低打单复杂度。 |
| **入库明细深度** | **一级货品汇总（选项 B）** | 仅展示大类、品类、规格、数量与批次，**不拆分二级具体垛位**，保护监管仓库内部微观库容信息。 |
| **出库金额脱敏** | **单价与货值保留列头、数值留空** | 质押/抵押出库涉及敏感货值，对现场承运司机及门卫脱敏，避免商业价格泄露，同时保证表格结构完整。 |
| **敏感字段展示** | **货主手机号与证件号明文展示** | 现场交接与路条查验需要核对真实有效身份，依业务需求展示明文，不做星号掩码。 |
| **防伪与图形码** | **不打印条形码与二维码** | 针式点阵打印机断针易导致图形码无法扫码识别，全单采用纯文本与清晰表格排版。 |
| **合规免责声明** | **不印制声明条款** | 省略冗长声明文字，将宝贵的垂直版面空间全额让渡给货品明细和四方签字捺印框。 |
| **签字留痕要素** | **预留手写日期与盖章/捺印框** | 满足现场风控要求：预留仓管手签、司机手签、货主盖章、门卫核放与手写日期。 |
| **交互与导出** | **预览弹窗 + 纯文件下载** | 提供 A4 / A5 / 连续纸三种模式切换预览，点击【下载单据文件 (PDF)】直接保存，无多余外链跳转。 |
| **单据抬头系统名称** | **取当前租户配置，禁止写死** | 抬头全称、针式纸短名称随登录租户（门户/租户档案）下发。ASCII 中的「森云科技供应链金融存货监管系统」仅为当前演示租户样例，换租户即换名称。 |
| **混单位合计** | **按计量单位分组加总，不得混加** | 同一张单内不同货品单位可以不同（如吨与公斤）。明细按行带本行单位；合计只把相同单位的数量加在一起，用「 / 」拼出多段，禁止把吨和公斤加出一个假总数。 |

## 二、 交互层：操作入口与打印预览弹窗

### 2.1 页面操作入口
1. **列表页操作列**：
   * 在【仓储 → 入库管理 → 入库记录】与【仓储 → 出库管理 → 出库记录】列表表格行操作区（更多操作下拉或平铺操作项），提供 **【单据下载】** 按钮；
   * 仅针对状态为【已生效】/【已归档】的正式单据可用。
2. **详情页顶部操作栏**：
   * 在单据详情页右上角操作按钮区，提供 **【单据下载】** 按钮。

### 2.2 打印预览弹窗 ASCII 线框

## 五、 本地制作与导出 PDF 模板指南

在本地制作和调试上述单据的 PDF 模板，主要有两种途径：

### 5.1 途径 A：纯前端/本地 HTML 单文件制作（研发交付与样板首选）
最简便、最保真的方式是建立一个独立的本地 `.html` 文件，使用浏览器原生打印渲染机制。

#### 核心 CSS 样式代码片段
在 HTML 中加入以下尺寸与打印样式：
```css
/* 针对屏幕预览的模拟纸张 */
.sheet {
  background: white;
  margin: 20px auto;
  box-shadow: 0 0 10px rgba(0,0,0,0.15);
  font-family: "PingFang SC", "Microsoft YaHei", sans-serif;
  box-sizing: border-box;
}

/* 纸张物理尺寸定义 */
.sheet-a4 { width: 210mm; min-height: 297mm; padding: 10mm; }
.sheet-a5 { width: 210mm; min-height: 148mm; padding: 8mm 10mm; }
.sheet-continuous { width: 241mm; min-height: 139.5mm; padding: 5mm 13mm; }

/* 针式打印防断针原则：实线黑边框，严禁灰度背景 */
table { border-collapse: collapse; width: 100%; border: 1px solid #000; }
th, td { border: 1px solid #000; padding: 4px 6px; font-size: 11px; }

/* 打印驱动导出控制 */
@media print {
  body { margin: 0; background: none; }
  .sheet { box-shadow: none; margin: 0; width: 100%; }
  .no-print { display: none !important; }
}
```

#### 本地导出 PDF 操作流程：
1. 双击用 Chrome 浏览器打开 HTML 文件；
2. 按 `Cmd + P`（Mac）或 `Ctrl + P`（Windows）；
3. **目标打印机**：选择【另存为 PDF】；
4. **选项设置**：勾选【背景图形】，边距选择【无】或【默认】；
5. 点击【保存】生成标准矢量 PDF 文件。

---

### 5.2 途径 B：使用 Word / WPS 本地制作模板
若使用 Word/WPS 排版并直接另存为 PDF，关键在于**自定义纸张尺寸与边距**：
1. **设置页面大小**：
   * 点击【布局】→【纸张大小】→【其他页面大小】；
   * A4 模式：宽 21 厘米，高 29.7 厘米，纵向；
   * A5 模式：宽 21 厘米，高 14.8 厘米，横向；
   * 二等分模式：宽 24.1 厘米，高 13.95 厘米，横向。
2. **设置页边距**：
   * A4 / A5：上下左右设为 1 厘米；
   * 二等分连续纸：上 0.5 厘米、下 0.5 厘米；左 1.3 厘米、右 1.3 厘米（避开走纸拖纸孔带）。
3. **绘制表格**：
   * 插入表格，边框粗细统一设为 `1 磅` 黑色；
   * 字体选择“黑体”或“微软雅黑”，字号 10.5 磅（五号）；
   * 质押出库单中的【单价】与【货物价值】列单元格留空；
4. **导出**：点击【文件】→【导出为 PDF】。

## 六、 研发落地与验收标准

### 6.1 前端研发关注点
1. **打印样式表独立**：打印样式独立打包为 `receipt-print.css`，通过 `@media print` 隔离常规 Web 样式，避免污染全局主题。
2. **无碳多联物理防穿透**：纯纯黑色文字（`#000000`）与细实线（`1px solid #000000`），严禁使用带 `opacity` 的透明颜色或灰度渐变背景。
3. **连续走纸分页断行**：当明细行数超出页面容量时，必须依靠表格自身的 `page-break-inside: avoid;` 与 `tr` 保护，防止文字从行中被横切斩断。

### 6.2 验收标准清单
- [ ] 在出库记录列表与详情页点击【单据下载】，均能正常弹出预览弹窗。
- [ ] 切换 A4、A5、二等分连续纸三种单选项，弹窗内单据纸张宽高比例与排版随之即时切换。
- [ ] 出库单预览与打印内容中，质押出库单价与货物价值列数值确认为留空/空白，未透出真实价格。
- [ ] 入库单与出库单货主联系电话与身份证号/信用代码均完整明文展示。
- [ ] 点击【下载单据文件 (PDF)】，系统能调起标准打印流或保存生成无失真的 PDF 矢量文件。
