# 贷中风控管理字段清单

> **文档定位**：贷中风控管理列表、详情、单条执行、批量执行及风控模型执行记录的字段定义来源。订单、货主、押品和订单预警配置字段引用所属模块定义；本文件只定义贷中风控管理自身的展示、筛选和追溯口径。
>
> **版本**：V1.0 | 更新时间：2026-08-18
>
> **页面范围**：本版本不提供新增页和编辑页。记录由订单预警配置保存成功后按订单自动生成或更新；执行结果由智风控平台异步回传。

## 0. 字段层级与核心约束

1. **基础识别字段**：用于识别订单、货主、押品、订单生成时间、订单类型和关联风控模型。
2. **执行概览字段**：用于判断是否执行、执行次数、预警次数和最近一次执行结果。
3. **执行记录字段**：仅在详情中展示每次向智风控平台提交的申请及其最终结果。
4. **系统追溯字段**：用于订单唯一约束、配置版本、异步回调、幂等和审计，不作为普通列表字段展示。

贷中风控管理以订单为唯一业务粒度，同一订单始终只有一条管理记录。订单预警配置选择预警类型为“贷中风控预警”并保存成功后，系统按订单唯一标识执行幂等新增或更新；不得因配置编辑、重复保存或批量提交生成重复的管理记录。

列表数据权限继承订单权限。订单状态、贷中风控预警配置状态和最近一次执行状态共同决定“是否可执行”；该字段由服务端计算，前端不可直接改写。

| 执行记录 | 执行记录号 | 系统生成 | 全局唯一 | 详情记录 | 唯一定位一次提交申请 | 单条执行和批量执行均为每个订单生成独立记录 |
| 执行记录 | 执行批次号 | 系统生成 | 批量执行生成批次号；单条执行生成单条批次号 | 详情记录 | 关联一次用户操作提交的记录集合 | 批次号不改变每条申请独立计数和独立结果 |
| 执行记录 | 风控模型 | 订单预警配置/智风控平台 | 模型名称及执行时产品标识 | 详情记录 | 执行时使用的模型快照 | 模型后续更名或停用不得改写历史记录 |
| 执行记录 | 提交时间 | 服务端 | 日期时间 | 详情记录 | 向智风控平台提交申请的时间 | 以服务端时间为准 |

| 执行记录 | 提交状态 | 智风控接口 | 提交中、提交成功、提交失败 | 详情记录 | 平台是否受理申请 | 失败时展示失败原因 |
| 执行记录 | 智风控任务号/受理编号 | 智风控平台 | 平台返回的任务或受理编号 | 详情记录 | 支持任务中心和智风控平台追溯 | 无返回时展示“--” |
| 执行记录 | 后续处理状态 | 智风控平台/任务中心 | 无需补充资料、待补充资料、处理中、已完成、处理失败 | 详情记录 | 平台要求补充资料或继续流程时的状态 | 待补充资料时提供任务中心联登入口 |

| 执行记录 | 结果描述 | 智风控回调 | 文本 | 详情记录 | 模型返回的最终结果描述 | 预警内容中的“预警描述”取此字段 |
| 执行记录 | 最终结果时间 | 智风控回调 | 日期时间 | 详情记录 | 平台返回最终结果的时间 | 提交失败时为空 |
| 执行记录 | 失败原因 | 接口/任务中心 | 文本 | 详情记录 | 提交失败、处理失败或回调异常原因 | 原因以平台返回和服务端错误信息为准 |

## 四、页面展示与筛选规则

- 列表默认展示近一年数据，默认“是否可执行=可执行”“是否已执行=全部”“风控模型=全部”。订单生成时间支持开始时间和结束时间范围查询，时间跨度不得超过一年。
- 列表展示顺序建议为：序号、订单号、货主名称、货主标识、押品信息、订单生成时间、订单类型、风控模型、是否可执行、是否已执行、执行次数、预警次数、最近一次执行状态、最近一次执行时间、最近一次提交人、操作。
- 订单号、货主名称和货主标识支持模糊匹配；订单生成时间支持范围筛选；风控模型支持多选；是否可执行和是否已执行支持单选；其余概览字段仅展示。
- 不可执行数据的操作区不展示或禁用“执行风控模型”；悬停提醒图标展示订单状态、预警配置状态和最近一次执行状态的具体值。批量勾选时仅允许选择可执行数据。
- 订单号可点击进入订单详情；详情展示订单基础信息、当前配置状态和全部执行记录。
