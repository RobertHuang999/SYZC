# 押品预警信息字段清单

> **文档定位**：押品预警信息列表、详情、预警处理和风险公示页面的字段定义来源。订单、预警规则、设备和仓库位置在预警触发时保存快照；规则配置字段分别引用[订单预警配置字段清单](../../08-配置管理/19-风险管理-订单预警配置/订单预警配置字段清单.md)和[设备预警配置字段清单](../../08-配置管理/20-风险管理-设备预警配置/设备预警配置字段清单.md)。
>
> **版本**：V1.4 | 更新时间：2026-08-18
>
> **页面范围**：当前版本覆盖押品预警信息列表、详情、解除预警处理及风险公示入口；不包含预警规则新增或编辑。预警信息由订单预警配置命中订单业务数据、订单绑定设备事件或相关业务模块后自动生成。

## 0. 字段层级说明

1. **基础识别字段**：用于识别预警订单、触发规则、预警类型、发生内容、时间和当前状态。
2. **解除预警字段**：仅在支持人工解除且记录为“未处理（有效）”时展示；自动解除不展示人工处理表单。
3. **系统字段与追溯字段**：用于幂等、历史快照、记录有效性、通知和公示审计，不作为普通列表字段展示。

“处理时间”“处理人”“预警状态”和“是否公示”由系统维护，用户不能直接修改。人工解除、公示风险和批量公示风险属于受权限控制的操作，不是新增或编辑预警记录。

押品预警与设备预警按业务数据归属分工，不建立大类一对一映射：押品预警必须具备订单关联，承接订单维度的风险记录；设备预警配置及设备预警信息只管理设备资产维度的规则和预警记录。设备事件是否同时形成押品预警，以事件是否携带有效订单唯一标识及接入规则判定；同一事件不得在两个模块重复生成同一条押品预警。11个押品预警大类与5个设备预警大类之间的正式映射表列为后续优化项。

## 四、页面展示与引用规则

- 列表展示顺序：序号、预警订单、预警类型、预警内容、预警抓拍图、预警时间、处理时间、是否公示、处理人、预警状态、操作。
- 当前已确认的筛选字段：预警订单（精确匹配）、预警类型（11个大类精确匹配）、是否公示（精确匹配）、预警状态（组合状态精确匹配）。预警时间、处理时间和处理人仅展示，不作为筛选条件。
- “操作”属于列表交互列，不作为业务字段。详情入口始终按权限展示；“解除预警”仅在记录为“未处理（有效）”、预警类型允许人工解除且用户具备处理权限时展示；“去处理”用于跳转【抵质押单据】页面处理订单预警。两种入口的处理结果模型一致，均回写预警状态、处理时间（历史“预警解除时间/解除时间”）、处理人、情况说明、现场照片、解除预警抓拍图及审计日志；区别仅为处理入口不同。点击“去处理”时若登录账号无项目管理菜单权限，提示：`您暂无相关权限，请联系相关负责人开通项目管理功能权限！`
- 已处理（有效）且未产生任何公示记录的记录进入批量公示候选；单条“公示风险”先判断是否已有公示记录，有记录直接进入最近一次公示详情，无记录且满足已解除、关联有效订单等条件时进入风险公示信息确认。未处理或无效记录不得进入首次/批量公示候选。
- 列表抓拍图默认展示默认图，不在列表初始化时加载真实图片；点击放大后由前端通过后端换取真实图片，并执行租户、菜单和订单/仓库数据权限校验。无图片、抓拍失败或换取失败时展示对应状态。
- 预警订单跳转必须使用订单唯一标识和筛选参数；目标订单列表再次执行服务端权限校验，不能通过前端拼接 URL 绕过订单数据权限。
- 预警状态与配置状态独立维护。配置修改、删除或关联对象失效不回写已产生的历史快照；关联未处理记录按业务规则置为“未处理（无效）”。单据下货物全部出库或完成对应解抵、解质押、解监管时，按最高优先级将关联未处理记录置为“未处理（无效）”。
- 涉及预警处理、图片、订单跳转、批量公示和公示状态变更的操作，应采用服务端版本校验、幂等键或防并发锁，并记录操作前后数据版本。
- 跨模块列表展示为待优化项：当前字段清单与项目背景、[设备预警配置字段清单](../../08-配置管理/20-风险管理-设备预警配置/设备预警配置字段清单.md)的列表展示要求存在差异，本版本保留押品预警侧字段口径，不将两套列表强行合并；后续需统一公共字段、模块专属字段及展示顺序。
- RBAC 权限矩阵待补充；本文件当前仅描述字段可见性和操作的原则性约束，不视为最终角色、菜单、按钮和数据权限矩阵。

## 六、解除方式总览

| 预警类型 | 当前解除方式 | 是否展示人工解除表单 |
| :--- | :--- | :--- |
| 解抵/质押/监管超时 | 对应解抵、解质押、解监管或出库业务完成后，由业务模块回写已处理 | 通过“去处理”进入【抵质押单据】页面完成；成功后按直接解除相同模型回写，押品预警页面不得绕过业务完成条件直接解除 |
| 价格下跌 | 押品预警信息页面人工确认处置结果，或收到有效恢复估值结果后按规则解除 | 是，人工解除时展示 |
| 抵/质押率异常 | 完成命中线对应的补仓、平仓或部分结清后自动解除；失败或未完成时保持未处理 | 按处置方式决定 |
| 物联设备（数值/烟感） | 收到有效恢复值或恢复事件后自动解除；采集空值不解除 | 否 |
| 图像识别、盘点、巡检、智能挂锁、人脸门禁、GPS | 由对应业务模块提供完成/恢复结果；未提供自动恢复结果的人工解除 | 按具体子类型和业务模块权限决定 |
| 贷中风控预警 | 由风控模型结果或人工复核结果回写；模型调用失败不视为解除 | 按风控结果决定 |

具体预警类型的触发条件、恢复事件和配置参数继承订单预警配置、设备预警配置及对应业务模块；本模块只维护风险信息记录、处理材料和处理结果。
