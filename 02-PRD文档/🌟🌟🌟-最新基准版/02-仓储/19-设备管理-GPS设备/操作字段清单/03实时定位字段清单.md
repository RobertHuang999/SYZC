# GPS设备-实时定位字段清单

> **所属板块**：GPS设备
> **字段类型**：行操作只读字段
> **主数据引用**：[GPS设备字段清单](../GPS设备字段清单.md)
> **流程规则**：[GPS设备主PRD·5.4 实时定位](../GPS设备主PRD.md#54-实时定位)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 请求上下文 | 是 | 用于请求定位数据 |
| 系统内名称 | 主数据 | 信息弹窗 | 系统带出 | 展示定位设备名称 |
| 车牌号 | 定位/车辆数据 | 地图标记及弹窗 | 有车辆时展示 | 引用车辆信息中的车牌号 |
| 司机姓名 | 三方车辆/司机数据（待确认） | 信息弹窗 | 有司机时展示 | 司机关联来源、无司机展示规则由三方接口确认；未确认前无值展示“--” |
| 手机号码 | 三方车辆/司机数据（待确认） | 信息弹窗 | 有司机时展示 | 按角色脱敏；手机号是否由三方返回及字段格式待确认 |
| 当前位置 | 三方定位接口（待确认） | 地图及信息弹窗 | 有定位时展示 | 坐标、地址解析服务和精度待三方接口确认；地址解析失败不得使用旧地址 |
| 状态 | 三方定位接口（待确认） | 信息弹窗 | 是 | 状态枚举、编码、判定来源、优先级和持续时长计算待三方接口确认 |
| 更新时间 | 定位服务 | 信息弹窗 | 是 | 格式为 `YYYY-MM-DD HH:mm:ss`，不是设备主数据更新时间 |
| 地图定位标记 | 三方定位接口/地图服务（待确认） | 地图 | 有定位时展示 | 地图底图、坐标系、标记渲染服务和失败降级规则待确认 |
| 加载/异常状态 | 系统/第三方 | 页面状态 | 是 | 加载中、无定位、接口失败或第三方不可用 |
