# GPS设备-运动轨迹字段清单

> **所属板块**：GPS设备
> **字段类型**：行操作查询字段
> **主数据引用**：[GPS设备字段清单](../GPS设备字段清单.md)
> **流程规则**：[GPS设备主PRD·5.5 运动轨迹](../GPS设备主PRD.md#55-运动轨迹)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 查询上下文 | 是 | 使用设备编码查询历史轨迹 |
| 设备信息 | 主数据/车辆数据 | 查询区 | 系统带出 | 有车牌时展示系统内名称和车牌；无车牌标识未绑定 |
| 开始时间 | 用户选择 | 日期时间控件 | 是 | 与结束时间组成查询范围 |
| 结束时间 | 用户选择 | 日期时间控件 | 是 | 查询范围最长31天 |
| 状态分段 | 三方历史轨迹接口（待确认） | 列表/卡片 | 有轨迹时展示 | 按三方返回状态分段；状态枚举、编码和分段算法待确认 |
| 状态持续时长 | 三方历史轨迹接口/系统计算（待确认） | 分段卡片及详情 | 有状态时展示 | 按天、小时、分钟展示；起算时间和计算责任方待确认 |
| 车牌号 | 车辆数据 | 轨迹详情 | 有车辆时展示 | 引用车辆信息 |
| 司机姓名 | 车辆数据 | 轨迹详情 | 有司机时展示 | 无值展示规则待确认 |
| 手机号 | 车辆数据 | 轨迹详情 | 有司机时展示 | 按角色脱敏 |
| 开始地址 | 三方历史轨迹接口/地图服务（待确认） | 轨迹详情 | 有地址时展示 | 轨迹起点地址；地址解析服务和失败降级规则待确认 |
| 结束地址 | 三方历史轨迹接口/地图服务（待确认） | 轨迹详情 | 有地址时展示 | 轨迹终点地址；地址解析服务和失败降级规则待确认 |
| 总里程 | 三方历史轨迹接口或系统计算（待确认） | 轨迹详情 | 有轨迹时展示 | 单位、精度、计算责任方和异常值处理待确认 |
| 轨迹地图 | 三方历史轨迹接口/地图服务（待确认） | 地图 | 有轨迹时展示 | 展示历史行驶路径；轨迹接口、坐标系和地图服务待确认 |
| 查询状态 | 系统生成 | 页面状态 | 是 | 加载中、无数据、查询失败或成功 |

开始时间至结束时间超过31天时阻止查询；具体接口字段和异常状态以主PRD补充规则为准。
