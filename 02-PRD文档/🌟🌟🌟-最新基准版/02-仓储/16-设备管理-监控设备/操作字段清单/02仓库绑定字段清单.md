# 监控设备-仓库绑定字段清单

> **所属板块**：监控设备
> **字段类型**：行操作编辑字段
> **主数据引用**：[监控设备字段清单](../监控设备字段清单.md)
> **流程规则**：[监控设备主PRD·5.3 仓库绑定](../监控设备主PRD.md#53-仓库绑定)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 隐藏请求参数 | 是 | 使用设备编码作为幂等关联键 |
| 绑定仓库 | 用户选择 | 单选下拉框 | 选填 | 仅展示当前用户有权限的仓库 |
| 绑定库房 | 用户选择 | 多选下拉框 | 选填 | 必须归属于所选仓库 |
| 绑定分区 | 用户选择 | 多选下拉框 | 选填 | 必须归属于所选仓库和库房 |
| 具体位置 | 用户录入 | 文本输入框 | 选填 | 用于补充设备实际安装或布设位置，最多50个字 |
| 已选位置 | 系统计算 | 只读列表 | 系统生成 | 展示仓库、库房、分区完整层级 |
| 操作结果 | 系统生成 | 消息提示 | 是 | 保存成功更新主数据；失败不得部分更新 |

清空绑定也属于本操作；保存前必须重新校验设备当前订单绑定、数据权限和版本号。
