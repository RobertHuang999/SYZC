# 监控设备-移除设备字段清单

> **所属板块**：监控设备
> **字段类型**：行操作变更字段
> **流程规则**：[监控设备主PRD·5.7 移除设备](../监控设备主PRD.md#57-移除设备)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 确认弹窗上下文 | 是 | 使用设备编码作为幂等关联键 |
| 设备类型 | 主数据 | 确认弹窗只读 | 系统带出 | 展示当前设备类型 |
| 系统内名称 | 主数据 | 确认弹窗只读 | 系统带出 | 展示当前设备名称 |
| 移除说明 | 用户录入 | 文本域 | 是 | 记录本次移除原因和业务说明 |
| 联动处理结果 | 系统生成 | 结果明细 | 是 | 风险失效、订单解绑、规则解绑、仓库解绑等结果 |
| 操作结果 | 系统生成 | 消息提示 | 是 | 任一联动失败不得提示完整成功 |
| 操作审计日志 | 系统生成 | 不展示 | 是 | 记录操作前后快照、操作人、时间、请求标识和结果 |

移除失败时保留设备原状态和原关联；设备重入只恢复第三方基础识别信息，其他系统配置按主PRD规则清空。
