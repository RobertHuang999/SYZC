# 物联设备-设备数据字段清单

> **所属板块**：物联设备
> **字段类型**：行操作只读字段
> **主数据引用**：[物联设备字段清单](../物联设备字段清单.md)
> **流程规则**：[物联设备主PRD·5.2 设备数据](../物联设备主PRD.md#52-设备数据)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 请求上下文 | 是 | 使用设备编码请求当前实时数据和预警记录 |
| 系统内名称 | 主数据 | 页面标题 | 系统带出 | 展示当前物联设备 |
| 设备类型 | 主数据 | 页面上下文 | 系统带出 | 决定请求温度、湿度、二氧化碳、氧气、烟感或组合指标 |
| 当前物联数据 | 第三方平台 | 实时数据卡片 | 接口返回 | 仅展示本次请求实际返回的温度、湿度、二氧化碳、氧气、烟感指标；未返回时展示“暂无数据”，不得使用历史值 |
| 数据更新时间 | 第三方平台 | 数据卡片 | 接口返回 | 优先展示第三方返回的指标采集时间；缺失、格式非法或晚于服务端当前时间时标记数据时间异常，不使用旧时间冒充本次返回时间 |
| 温度 | 第三方平台 | 实时数据卡片 | 有返回时展示 | 展示第三方本次返回的原始数值、单位和精度；单位、精度、采集时间字段待三方接口确认；无返回或异常时展示“暂无数据”并标记异常 |
| 湿度 | 第三方平台 | 实时数据卡片 | 有返回时展示 | 展示第三方本次返回的原始数值、单位和精度；单位、精度、采集时间字段待三方接口确认；无返回或异常时展示“暂无数据”并标记异常 |
| 二氧化碳 | 第三方平台 | 实时数据卡片 | 有返回时展示 | 展示第三方本次返回的原始数值、单位和精度；单位、精度、采集时间字段待三方接口确认；无返回或异常时展示“暂无数据”并标记异常 |
| 氧气 | 第三方平台 | 实时数据卡片 | 有返回时展示 | 展示第三方本次返回的原始数值、单位和精度；单位、精度、采集时间字段待三方接口确认；无返回或异常时展示“暂无数据”并标记异常 |
| 烟感 | 第三方平台 | 实时数据卡片 | 有返回时展示 | 展示第三方本次返回的原始数值、单位、精度或枚举；具体口径待三方接口确认；无返回或异常时展示“暂无数据”并标记异常 |
| 指标异常状态 | 系统生成 | 实时数据卡片 | 接口返回异常时展示 | 第三方返回空值、NaN、格式非法、超出接口约定范围或采集时间无效时标记“数据异常”；异常指标不得参与风险预警计算 |
| 指标异常说明 | 系统生成/第三方平台 | 实时数据卡片 | 有异常时展示 | 展示“暂无数据”“数据格式异常”“采集时间异常”等可读原因；不得用历史值替换本次异常结果 |
| 温湿度预警记录 | 风险模块 | 预警列表 | 有数据时展示 | 只读展示订单、预警类型、监测值、阈值、状态和处理信息；当前已确认预警范围为温度和湿度 |
| 预警订单信息 | 风险模块 | 预警列表 | 有数据时展示 | 展示产生温度或湿度预警的订单标识或名称 |
| 预警类型 | 风险模块 | 预警列表 | 有数据时展示 | 当前版本仅展示温度预警或湿度预警 |
| 预警监测值 | 风险模块 | 预警列表 | 有数据时展示 | 展示产生预警时的温度或湿度实际值 |
| 预警阈值信息 | 风险模块 | 预警列表 | 有数据时展示 | 展示命中的预警阈值或规则区间 |
| 预警处理状态 | 风险模块 | 预警列表 | 有数据时展示 | 只读展示当前处理状态 |
| 预警处理人 | 风险模块 | 预警列表 | 已处理时展示 | 展示风险模块返回的处理人 |
| 预警处理时间 | 风险模块 | 预警列表 | 已处理时展示 | 展示风险模块返回的处理时间 |
| 预警处理说明 | 风险模块 | 预警列表 | 已处理时展示 | 展示风险模块返回的处置说明 |
| 加载状态 | 系统生成 | 页面状态 | 是 | 当前数据和预警记录分区处理加载、空数据和失败 |

本操作不持续轮询，不修改设备、订单或预警处理状态。二氧化碳、氧气和烟感在风险阈值未完成三方接口与风险规则确认前，只展示本次返回值，不自行生成风险预警。

| 烟感 | 待三方接口确认 | 待三方接口确认 | 优先使用三方采集时间；字段格式待确认 | 空值、非法枚举、异常码或时间无效时标记异常 | 当前不生成预警；正常值/异常值枚举及处置动作待确认 | 物联设备对接研发、风险规则负责人；风险规则评审前 |
