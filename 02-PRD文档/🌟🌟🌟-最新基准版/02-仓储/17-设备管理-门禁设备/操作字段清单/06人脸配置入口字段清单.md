# 门禁设备-人脸配置入口字段清单

> **所属板块**：门禁设备
> **适用设备**：人脸门禁
> **完整字段引用**：[人脸配置字段清单](../../21-设备管理-人脸配置/人脸配置字段清单.md)
> **流程规则**：[门禁设备主PRD·5.6 人脸配置入口](../门禁设备主PRD.md#56-人脸配置入口)

门禁设备模块只维护当前设备上下文和入口字段，不复制人脸配置模块的人员、人脸、密码、授权和下发字段。

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 页面上下文 | 是 | 携带当前人脸门禁设备上下文 |
| 设备名称 | 主数据 | 页面标题 | 系统带出 | 展示当前设备系统内名称 |
| 绑定仓库 | 主数据 | 权限上下文 | 系统带出 | 用于设备数据权限校验 |
| 人员名称 | 人脸配置模块 | 查询输入框 | 选填 | 对当前设备可分配人员模糊查询 |
| 人脸配置人员列表 | 人脸配置模块 | 平铺列表 | 有数据时展示 | 只展示满足准入条件且有权限的人员 |
| 授权状态 | 人脸配置模块 | Switch | 是 | 当前设备与人员的授权关系；具体下发规则由人脸配置维护 |
| 空状态跳转 | 系统生成 | 链接/按钮 | 无数据时展示 | 携带当前设备上下文前往人脸配置管理页面 |

门禁设备页面不负责维护人脸照片、开锁密码和授权下发进度。
