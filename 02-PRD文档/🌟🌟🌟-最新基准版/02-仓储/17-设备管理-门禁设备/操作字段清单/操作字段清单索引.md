# 门禁设备操作字段清单索引

> 本目录是[门禁设备字段清单](../门禁设备字段清单.md)的操作字段子清单。门禁设备主字段只维护设备本身；密码、人脸授权、事务和风险记录分别维护各自操作或关联模块字段。

| 操作字段清单 | 操作类型 | 展示条件 | 说明 |
| :--- | :--- | :--- | :--- |
| [重命名字段清单](./01重命名字段清单.md) | 编辑 | 所有门禁设备 | 继承设备通用重命名规则 |
| [仓库绑定字段清单](./02仓库绑定字段清单.md) | 编辑 | 所有门禁设备 | 继承设备通用仓库绑定规则 |
| [设备数据字段清单](./03设备数据字段清单.md) | 查询 | 所有门禁设备 | 事务记录和风险记录按关联模块引用 |
| [获取门锁密码字段清单](./04获取门锁密码字段清单.md) | 敏感操作 | 挂锁门禁 | 维护事由、备注、短信和有效期 |
| [获取门禁密码字段清单](./05获取门禁密码字段清单.md) | 敏感操作 | 人脸门禁 | 维护事由、次数、有效期和临时密码 |
| [人脸配置入口字段清单](./06人脸配置入口字段清单.md) | 关联入口 | 人脸门禁 | 门禁设备只维护设备上下文，人脸字段引用人脸配置模块 |
| [移除设备字段清单](./07移除设备字段清单.md) | 变更 | 所有门禁设备 | 继承设备通用移除规则 |

挂锁门禁和人脸门禁的密码操作字段不得合并；人脸配置完整字段见[人脸配置字段清单](../../21-设备管理-人脸配置/人脸配置字段清单.md)。
