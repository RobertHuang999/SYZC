# 风险公示字段清单

> **版本**：V2.2 | 2026-09-17  
> **编写依据**：[风险公示主PRD](./风险公示主PRD.md)、[风险公示业务规则规格](./风险公示业务规则规格.md)、[押品预警信息字段清单](../06-风险信息-押品预警信息/押品预警信息字段清单.md)  
> **真源声明**：本字段清单是风险公示对外台账列表、详情抽屉、首次确认模态弹窗及取消公示核查弹窗的**唯一数据字典真源（SSOT）**。包含标准 11 维业务字段定义、控件规格、必填性、数据来源及关联业务规则。所有交互控件术语均已全面汉化。  
> **当前订单范围**：监管订单当前关闭。新增、编辑、批量提交和取消公示等写操作仅适用于有效抵押/质押订单；历史监管公示仅支持查询、详情和审计。

### 1.4 押品预警发起 · 公示确认页字段（跨模块引用）

> **入口**：【押品预警信息】列表/详情行操作【公示风险】→ 押品侧「公示确认页」（未公示）或「公示详情页」（已公示/已取消）；列表【批量公示】→ 批量公示确认页（PC 左列表+右表单 / H5 订单 Pill + 同款表单）逐条编辑后提交全部。  
> **字段真源**：确认页可编辑字段定义继承 [押品预警信息字段清单](../06-风险信息-押品预警信息/押品预警信息字段清单.md) 中解除/处置快照字段；本菜单台账不重复定义控件规格。  
> **展示分区**：确认页与详情页统一按「公示信息 + 处置信息」两卡片呈现，**不使用**合成的「公示标题 / 对外公示内容」独立字段。

| 分区 | 字段名称 | 控件与约束 | 必填 | 可编辑 | 说明 |
| :--- | :--- | :--- | :---: | :---: | :--- |

| 公示信息 | 预警时间 | 日期时间 | 是 | 是 | 原预警触发时间快照 |
| 公示信息 | 预警类型 | 文本（≤20字） | 是 | 是 | 7 大类枚举快照 |
| 公示信息 | 位置 | 文本（≤50字） | 是 | 是 | 仓库/库区/货位 |
| 公示信息 | 设备名称 | 文本（≤50字） | 条件 | 是 | 物联类展示 |

| 处置信息 | 解除方式 | 文本（≤50字） | 条件 | 是 | 仅自动解除类展示 |

## 2. 交互控制与状态联动规格

1. **行级操作按钮呈现逻辑**：
   - 【详情】：主列表常态展示，点击从右侧滑出详情抽屉；
   - 【取消风险公示】：仅在详情抽屉内展示，且仅在当前记录状态为 `已公示` (PUBLICIZED) 且操作人具备 `R-RISK-MGR` 权限时呈现；点击弹出包含固定合规文案的模态弹窗；若状态为 `已取消` (REVOKED)，该按钮绝对隐藏。
2. **列表筛选交互行为**：
   - 默认进入页面时，系统自动选中 `公示状态=已公示`，仅展示对外公开展现中的记录；
   - 若用户切换下拉单选框选择 `已取消` 或 `全部`，系统支持按权限调阅已被撤回的历史公示流水。
