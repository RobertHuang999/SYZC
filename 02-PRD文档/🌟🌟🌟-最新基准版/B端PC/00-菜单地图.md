## 二、工作中心 · 审批中心（首页卡片）

> **完整 taxonomy**：[01-工作中心/01-审批中心/审批中心总索引.md](./01-工作中心/01-审批中心/审批中心总索引.md)

首页「审批中心」为**聚合入口**，**无左侧 Sidebar**（与线上采集一致；PC 原型 `shouldShowSidebar()` 对工作中心返回 false）。子区块包括：

| 区块 | 典型子项 | 备注 |
| :--- | :--- | :--- |
| 业务管理审批 | 待处理 / 已处理 / 抄送我的 / **我的申请管理** / 业务申请管理 / 监管委托受理 | 首页指标「待确认合计」；默认选中「待处理」展示 5 条预览 |
| 客户需求审批 | 客户入库/出库预约、融资需求、尽调、销售/采购需求 | 选中后下方 5 条预览 +「查看更多」 |
| **其他审批** | 政策资讯审核、**开锁审核**、贷中风控受理等 | 未接入「接入流程配置」；**不进**待处理/已处理池 |

**首页 UI 布局（2026-09-03）**：三大区块 **单行三列** 并排（组名在上、子类型在下、组内 Grid 均分）；详见 [07/开锁审核_ASCII_审批中心入口.md](../../B-迭代需求/6.2版本（2026.08）/07-审批中心/05-其他审批/03-开锁审核/开锁审核_ASCII_审批中心入口.md) 与 `AGENTS.md` §4.3。

### 6.2 开锁审批相关路径（PC）

| 角色 | 菜单路径 |
| :--- | :--- |
| **审批人** | 工作中心 → 审批中心 → 其他审批 → **开锁审核** |
| **申请人查询** | 工作中心 → 审批中心 → **我的申请管理** → Tab「我的开锁申请」 |
| **发起申请** | 6.2 目标：物联网IOT与预警 → 门禁设备；上线前采集：仓储 → 设备管理 → 门禁设备 |
| **审批配置** | 配置管理 → 业务流程管理 → **开锁审批** |
