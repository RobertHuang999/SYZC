## 二、工作中心 · 审批中心（首页卡片）

> **完整 taxonomy**：[01-工作中心/01-审批中心/审批中心总索引.md](./01-工作中心/01-审批中心/审批中心总索引.md)

首页「审批中心」为**聚合入口**，**无左侧侧边导航栏（No Sidebar）**（与线上采集一致；PC 原型 `shouldShowSidebar()` 对工作中心路由返回 `false`）。三大区块包括：

| 区块 | 典型子项 | 业务与流转特征说明 |
| :--- | :--- | :--- |
| **业务管理审批** | 待处理 / 已处理 / 抄送我的 / **我的申请管理** / 业务申请管理 / 监管委托受理 | 接入通用流程配置引擎；首页展示待确认合计；申请人统一在「我的申请管理」跟踪在途单据 |
| **客户需求审批** | 客户入库/出库预约、融资需求、尽调、销售/采购需求 | 选中后下方展示 ≤ 5 条预览 +「查看更多 >」 |
| **其他审批** | 政策资讯审核、**开锁审核**、贷中风控受理等 | 门禁与挂锁开锁审核直通**专网专道**；**不进入**通用待处理/已处理池，保障毫秒级响应 |

**首页 UI 布局规范**：三大区块 **单行三列并排**（组名在上、子类型在下方横向网格均分、图标+文案每行 4 汉字断行、角标红点展示待办数）；详见 `AGENTS.md` 4.3 节 与 [审批中心主PRD](./01-工作中心/01-审批中心/01-审批中心主PRD.md)。

### 门禁开锁审批全链路闭环路径对照

| 角色与业务场景 | 菜单路径 | 规范参考 |
| :--- | :--- | :--- |
| **审批人审核** | 工作中心 → 审批中心 → 其他审批 → **开锁审核** | 专网专道，自审禁止（P06/R11），屏蔽密码明文 |
| **申请人发起** | 物联网IOT与预警 → 物联网IOT管理 → **门禁设备**（列表行操作【获取门锁密码】/【获取门禁密码】） | 命中启用配置弹出申请弹窗，未命中免审直发 |
| **申请人进度追踪** | 工作中心 → 审批中心 → 业务管理审批 → **我的申请管理**（开锁审批标签页） | 支持在途申请主动撤回、查看临时密码明文 |
| **管理员审批配置** | 配置管理 → 业务流程管理 → **开锁审批** | 设备范围唯一性绑定、审批流快照不可回写 |
