## 二、工作中心 · 审批中心（首页卡片）

首页「审批中心」为**聚合入口**，非左侧树形菜单。子区块包括：

| 区块 | 典型子项 | 备注 |
| :--- | :--- | :--- |
| 业务管理审批 | （待确认枚举） | 首页指标「待确认合计」 |
| 客户需求审批 | （待确认枚举） | — |
| **其他审批** | **开锁审批**、贷中风控受理、政策资讯审核等 | 未接入「接入流程配置」的独立审批 |
| 内部审批（平台） | 待处理 / 已处理 / 抄送我的 / **我的申请记录** | 已接入流程配置的子类型 |

### 6.2 开锁审批相关路径（PC）

| 角色 | 菜单路径 |
| :--- | :--- |
| **审批人** | 工作中心 → 审批中心 → 其他审批 → **开锁审批** |
| **申请人查询** | 工作中心 → 审批中心 → **我的申请记录**（子类型=开锁申请） |
| **发起申请** | 仓储 → 设备管理 → 门禁设备 → 行操作「获取门锁密码」（命中需审批规则） |
| **审批配置** | 配置管理 → 业务流程管理 → **开锁审批** |
