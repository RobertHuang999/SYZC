## 共同口径

1. **金额**：预计与实际收支分开记录，毛利 = 实际收入 − 实际支出；小数位与单位待确认；
2. **状态**：结算单从待结算 → 已结算 → 已结清，作废为终态；
3. **权限**：按功能权限与账号数据权限控制，跨机构不可见；
4. **导出**：异步任务，统一在导出记录中下载。
