# 客户管理字段清单

> **文档定位**：交易 / 客户管理模块（主列表台账页、查询筛选区、客户详情模态弹窗、导出记录模态弹窗、Excel 异步导出字段映射及 C 端源头认证数据穿透）全量业务字段的唯一数据真源。  
>
> **引用与继承规则**：
> - `客户账号`：继承自 C 端用户首次通过手机验证码完成注册的主账号（11 位手机号码），默认中间 4 位掩码脱敏。
> - `个人认证状态` / `认证信息`：继承自 C 端用户个人实名二元校验（真实姓名 + 18 位身份证号）及实人一体人脸活体核身结果。
> - `企业认证状态` / `认证信息`：继承自 C 端用户企业实名认证流程（营业执照正面照片 OCR 智能解析 + 国家工商业四要素权威比对）。
> - `经办人手机号`：继承自提交企业认证时 C 端当前登录账号绑定的手机号码，置灰锁定不可修改。
> - `营业执照凭证`：继承自 C 端拍摄/上传并成功通过 OCR 与四要素比对的不可篡改电子证照原件快照。
> - 行操作、状态机流转、脱敏查看审计与接口规则由 [客户管理业务规则规格.md](./客户管理业务规则规格.md) 唯一定义；C 端移动端源头实名规则由 [C端H5/01-用户认证](../../../C端H5/01-用户认证/) 唯一定义；主 PRD 与原型实现按字段名称与规范引用本文件。  
>
> **修改原则**：字段定义变化只修改本文件，并同步更新版本和修订记录。严禁凭空创建数据。  
>
> **版本**：V1.5 | **更新时间**：2026-09-22 | **责任人**：森云科技（Senyun Technology）  
>
> **页面范围**：覆盖客户管理主列表页（`P-JY-003`）、客户详情模态弹窗（`P-JY-003-DETAIL`）、导出记录模态弹窗（`P-JY-003-EXPORT`）及后台异步导出 Excel 任务。本模块定位为**全网客户 C 端注册与实名资质监控台账**，B 端不提供人工物理新增或编辑入口。

## 0. 对象与字段层级说明

本文件根据客户全生命周期与跨端协同链路，将字段划分为四大层级：
1. **主列表与查询筛选区字段（PC 端·`P-JY-003`）**：定义后台客户台账检索条件、表格列数据规格、格式化规则、脱敏展示与页面级导出按钮；
2. **客户详情模态弹窗字段（PC 端·`P-JY-003-DETAIL`）**：定义垂直时间轴结构（注册、个人认证、企业认证）三节点全要素字段、明文/脱敏切换与证照预览；
3. **导出记录模态弹窗字段（PC 端·`P-JY-003-EXPORT`）**：定义异步导出任务监控台账的列表字段、生成状态、操作人与下载凭证；
4. **后台导出 Excel 明细列规格**：定义点击【导出为Excel】后实际生成 `.xlsx` 报表的完整数据列字典。
