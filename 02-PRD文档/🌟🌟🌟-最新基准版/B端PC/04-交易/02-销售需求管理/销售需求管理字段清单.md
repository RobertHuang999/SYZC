# 销售需求管理字段清单

> **文档定位**：交易 / 销售需求管理模块（主列表台账页、查询筛选区、线索详情模态弹窗、线索跟进模态弹窗、工作中心审核意见弹窗及 C 端源头提报表单映射）全量业务字段的唯一数据真源。  
> **数据继承与映射规范**：
> - `货主` / `货主名称`：继承自 C 端实名认证主体信息（个人认证真实姓名，或企业认证法定名称 + 注册手机号脱敏）；
> - `线索类型`：支持 `存货` 与 `仓单` 两种资产凭证类型；
> - `线索信息（存货/仓单货物）`：
>   - **存货类**：多选关联货主名下处于 `已入库` 或 `部分出库` 状态的真实货物（按照二维码批次维度：`{大类}-{品类}-{规格}-{数量}{单位}`）；
>   - **仓单类**：多选关联持有人为当前货主且状态正常的有效电子仓单编号（如 `CD1961651101066789985`）；
> - `审核处理人`：继承自工作中心审核人员真实账号名称及其归属机构法定全称；
> - `跟进提交人`：继承自当前登录操作人员系统账号名称及其账号归属机构法定全称；
> - 行操作、状态机与强校验拦截业务逻辑由 [销售需求管理业务规则规格.md](./销售需求管理业务规则规格.md) 唯一定义；上游审批源头规格由 [客户销售需求字段清单.md](../../01-工作中心/01-审批中心/04-客户需求审批/05-客户销售需求/客户销售需求字段清单.md) 唯一定义；主 PRD 与下游原型实现按字段名称与规范引用本文件。  
> **修改原则**：字段定义变化只修改本文件，并同步更新版本和修订记录。严禁凭空发明字段。  
> **版本**：V2.0 | **更新时间**：2026-09-22 | **责任人**：森云科技（Senyun Technology）  
> **页面范围**：覆盖交易销售需求管理列表页（`P-JY-002`）、线索详情模态弹窗（`P-JY-002-DETAIL`）、线索跟进模态弹窗（`P-JY-002-FOLLOW`）、工作中心客户销售需求审核意见弹窗（`P-GZZX-AUDIT-SALE`）及 C 端线索发布提报表单。本模块定位为**已审批通过的合规销售需求（线索）监管、供需跟进与履约归档台账**，B 端不提供手工直接新增入口。

## 0. 对象与字段层级说明

```mermaid
flowchart TD
    subgraph S1[数据源头层 · C 端线索提报]
        A1["货主身份认证 (个人/企业)"]
        A2["线索基础要素 (名称/有效期/图片/描述)"]
        A3["标的物资产 (在库存货二维码 / 正常电子仓单)"]
    end

    subgraph S2[审批流转层 · 工作中心合规裁决]
        B1["审核意向与备注 (是否同意 / 备注说明)"]
        B2["审核轨迹 (处理人账号 / 机构全称 / 审核时间)"]
    end

    subgraph S3[交易台账层 · 销售需求管理 (本模块)]
        C1["单据主表与检索字段 (货主/类型/状态/交易状态)"]
        C2["详情镜像穿透 (标的物资 / 仓单凭单 / 隐私脱敏显隐)"]
        C3["运营跟进流水 (情况描述 / 凭证图片 / 提交人及机构)"]
        C4["履约监控与定时调度 (到期失效 / 存货全出库或仓单全注销触发交易成功)"]
    end

    A1 & A2 & A3 -->|提交申请| S2
    B1 & B2 -->|审核通过| S3
```

本文件根据销售需求全生命周期与跨端协同链路，将字段划分为四大标准层级：
1. **第一层：单据级主表与多维检索字段**：定义 PC 端台账主列表行基础列、顶部多维检索项、分页与操作行为；
2. **第二层：标的物资产与线索要素明细字段**：定义线索关联的底层存货规格数量、电子仓单编号、货物样品影像及补充说明；
3. **第三层：线索跟进与运营闭环字段**：定义运营人员执行行操作【线索跟进】时提交的现场进展事实、凭证图片及历史时间轴；
4. **第四层：系统、状态机与履约审计字段**：定义生命周期状态、B 端专有交易状态、有效期倒计时、操作人账号及机构追溯。

## 五、数据字典与枚举说明

### 5.1 线索类型枚举 (`clue_type`)
| 字典编码 | 枚举值 | 英文标识 | 对应选择资产模式 | 详情展示规则 |
| :--- | :--- | :--- | :--- | :--- |
| `1` | **存货** | `INVENTORY` | 选择在库存货（已入库/部分出库） | 标签为 `存货:`，展示规格与数量 |
| `2` | **仓单** | `WAREHOUSE_RECEIPT` | 选择正常电子仓单 | 标签为 `仓单:`，展示编号 + 【查看详情】链接 |

### 5.2 需求状态枚举 (`demand_status`)
| 字典编码 | 枚举值 | 英文标识 | B 端本台账展示 | C 端展示 | 状态说明 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| `0` | **待审核** | `PENDING_AUDIT` | 否 | 是（审核中） | C 端提报成功待审批，仅在工作中心与 C 端展示 |
| `1` | **发布中** | `PUBLISHING` | **是（初始态）** | 是 | 审批通过，全网大盘挂牌展示，倒计时计时中 |
| `2` | **未通过** | `AUDIT_REJECTED` | 否 | 是（未通过） | 审批驳回，仅 C 端可见，支持修改后重新发布 |
| `3` | **已失效** | `EXPIRED` | **是（终态）** | 是（失效） | 倒计时届满达到线索有效期，系统自动下架 |
| `4` | **已撤销** | `REVOKED` | **是（终态）** | 是（已撤销） | 用户在 C 端主动下架/撤回线索发布 |

### 5.3 交易状态枚举 (`trade_status`) —— B 端专有
| 字典编码 | 枚举值 | 英文标识 | 判定触发逻辑 | B端展示 | C端可见性 | 说明 |
| :--- | :--- | :--- | :--- | :---: | :---: | :--- |
| `0` | **交易未成功** | `TRADE_FAILED` | 初始默认态；或失效/撤销时关联资产仍未全部出库/注销 | 是 | **不可见** | 挂牌资产尚未全部履约完毕 |
| `1` | **交易成功** | `TRADE_SUCCESS` | 线索中关联的存货全部出库、仓单全部注销时触发 | 是 | **不可见** | 每日凌晨跑定时任务更新为交易成功 |

### 5.4 线索有效期枚举 (`validity_period`)
| 字典编码 | 枚举值 | 天数数值 | 倒计时计算逻辑 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `1` | **7天** | 7 | 审批通过时刻 $T_{\text{pass}} + 7 \times 86400$ 秒 | 短期挂牌意向 |
| `2` | **15天** | 15 | 审批通过时刻 $T_{\text{pass}} + 15 \times 86400$ 秒 | 中期供需撮合 |
| `3` | **30天** | 30 | 审批通过时刻 $T_{\text{pass}} + 30 \times 86400$ 秒 | 当前系统支持的最大有效期限 |
