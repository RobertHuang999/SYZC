### PC 菜单路径与角色映射对照

| 角色场景 | 菜单路径 | 核心业务特征 |
| :--- | :--- | :--- |
| 平台待办处理 | 工作中心 → 审批中心 → 业务管理审批 → 待处理 / 已处理 / 抄送我的 | 遵循通用流程引擎待办，支持单据详情与处理 |
| 申请人追踪中枢 | 工作中心 → 审批中心 → 业务管理审批 → **我的申请管理** | 三标签页架构（仓储业务 / 融资业务 / 开锁审批），支持在途撤回与密码查验 |
| 现场开锁专网审核 | 工作中心 → 审批中心 → **其他审批** → **开锁审核** | 专网专道流转，毫秒级响应，绝对自审禁止，严格屏蔽密码明文 |

### 首页 UI 布局规范（严格对齐线上与前端原型）

| 布局维度 | 规范说明 |
| :--- | :--- |
| 侧边导航栏（Sidebar） | **彻底移除**：工作中心模块在顶栏进入后为全宽卡片聚合页，原型通过 `shouldShowSidebar()` 隐藏侧边栏 |
| 导航区结构 | **三大区块单行三列并排**：业务管理审批 / 客户需求审批 / 其他审批；区块名称居上，组内子类型在下方横向网格均分（Grid），图标 + 文案（每行 4 个汉字折行，角标红点展示待办数） |
| 联动预览区 | 选中任一子类型，下方展示 **≤ 5 条** 卡片预览；超出卡片支持右上角【查看更多 >】深层跳转至对应完整功能页 |
