# 客户销售需求字段清单

> **文档定位**：工作中心 / 审批中心 / 客户需求审批 / 客户销售需求模块（审批主列表台账页、查询筛选区、审核意见表单弹窗、线索详情模态弹窗及审核记录时间轴）全量业务字段的唯一数据真源。  
> **数据继承与映射规范**：
> - `货主` / `货主名称`：继承自 C 端实名认证主体信息（个人实名真实姓名，或企业认证法定名称 + 注册手机号脱敏）；
> - `货物名称`：
>   - **存货类**：多选关联货主名下处于 `已入库` 或 `部分出库` 状态的在库存货，按二维码批次维度展示：`{大类}-{品类}-{规格}-{数量}{单位}`；
>   - **仓单类**：多选关联持有人为当前货主且状态正常的有效电子仓单编号（如 `CD1981651101066788865`）；
> - `审核处理人`：自动获取当前登录审批操作人员系统账号真实名称及其归属机构法定全称；
> - 行操作、状态机与强校验拦截业务逻辑由 [客户销售需求业务规则规格.md](./客户销售需求业务规则规格.md) 唯一定义；下游承接台账规格由 [销售需求管理字段清单.md](../../../../04-交易/02-销售需求管理/销售需求管理字段清单.md) 唯一定义；主 PRD 与下游原型实现按字段名称与规范引用本文件。  
> **修改原则**：字段定义变化只修改本文件，并同步更新版本和修订记录。严禁凭空发明字段。  
> **版本**：V2.0 | **更新时间**：2026-09-22 | **责任人**：森云科技（Senyun Technology）  
> **页面范围**：覆盖工作中心客户销售需求列表页（`P-GZZX-005`）、审核意见模态弹窗（`P-GZZX-AUDIT-SALE-DIALOG`）及线索详情模态弹窗（`P-GZZX-DETAIL-SALE-DIALOG`）。


本文件根据客户销售需求审批业务全生命周期，将字段划分为四大标准层级：
1. **第一层：审批列表与查询筛选区字段**：定义审批池多维检索条件、表格列基础数据规格、格式化与状态驱动的动态行操作；
2. **第二层：线索详情与标的物查验明细字段**：定义线索全要素镜像、存货规格数量、电子仓单穿透查阅及手机号显隐切换；
3. **第三层：审核意见录入表单字段**：定义审批人点击【去处理】时呼出的结构化表单录入项（是否同意、字数限制备注）；
4. **第四层：【审核记录】时间轴与审计字段**：定义审批节点时间戳、处理人账号、归属机构全称、审批结论与存证快照。
