# 客户采购需求字段清单

> **文档定位**：工作中心 / 审批中心 / 客户需求审批 / 客户采购需求模块（审批主列表页、查询筛选区、审核意见弹窗、需求详情模态弹窗及审核记录时间轴）所有业务字段的唯一定义真源。行操作与审批业务逻辑由 [客户采购需求业务规则规格.md](./客户采购需求业务规则规格.md) 唯一定义；主 PRD 与下游原型按字段所属层级引用，不重复定义字段规则。  
> **引用与继承规则**：
> - `发布人`：继承自 C 端个人实名认证主体信息（真实姓名 + 注册手机号脱敏）。
> - `需求产品`：级联继承自货品主档已启用的品类、货品及规格信息。
> - `需求数量单位`：自动继承所选货品主档配置的基础计量单位。
> - `送货地区 / 产品产地`：遵循国家标准省市区三级联动地址库规范。
> - `审核处理人`：自动获取当前登录审批操作员账号真实姓名及其归属机构法定全称。
> - 本模块定位为**工作中心前置客户采购需求受理与审批中枢**，B 端不提供人工物理新增或编辑入口。  
> **修改原则**：字段定义变化只修改本文件，并同步更新版本和修订记录。严禁凭空创造数据。  
> **版本**：V1.2 | **更新时间**：2026-09-22 | **责任人**：森云科技（Senyun Technology）  
> **页面范围**：覆盖工作中心客户采购需求列表页（`P-GZZX-006`）、审核意见模态弹窗（`P-GZZX-AUDIT-DIALOG`）及需求详情模态弹窗（`P-GZZX-DETAIL-DIALOG`）。PC 端从【工作中心 → 审批中心 → 客户需求审批 → 客户采购需求】进入。

## 0. 对象与字段层级说明

本文件根据客户采购需求审批业务全生命周期，将字段划分为四大层级，各层级表格统一采用标准 11 列表头规范：
1. **单据级主表业务字段（11 个核心列）**：定义审批池基础表格列、头部筛选区及操作行为（序号、需求创建时间、需求名称、需求产品、需求数量、发布人、产品产地、采购频率、需求有效期、状态、操作）。
2. **审核意见模态弹窗字段（`P-GZZX-AUDIT-DIALOG`）**：定义点击【去处理】时呼出的结构化表单录入项（是否同意、备注说明）。
3. **详情弹窗扩展明细字段（`P-GZZX-DETAIL-DIALOG`）**：定义居中弹窗上半区展现的送货地区、长文本采购要求、关于我们长文本及图片资料附件。
4. **审核记录追溯字段（详情弹窗下半区）**：定义审核历史节点的审核时间、处理结果、处理人账号及归属机构全称、审核意见与备注说明。
5. **系统字典与状态机字段**：定义审批流转状态、采购频率、需求有效期等标准枚举与倒计时计算规则。

## 五、枚举值与系统数据字典

### 5.1 审批流转状态枚举

| 状态名称 | 业务定义 | 列表展示样式 | 适用范围与流转说明 |
| :--- | :--- | :--- | :--- |
| **待审核** | C 端刚提交或重新发布提交后待后台审核 | 橙黄色标签 | 审批待办初始态；展示【去处理】按钮 |
| **发布中** | 审批通过，需求正式在全平台公开展示生效 | 翠绿色标签 | 审核通过流转态；同步落入交易台账，【去处理】隐藏 |
| **未通过** | 平台审批驳回，说明理由并可重新编辑发布 | 红色标签 | 审核驳回流转态；留存审核记录，【去处理】隐藏 |
| **已失效** | 需求运行达到选择的有效期天数，系统自动下架 | 浅灰色标签 | 倒计时到期终态；归档留存，【去处理】隐藏 |
| **已撤销** | C 端用户在有效期内主动点击撤销发布 | 弱化灰色标签 | 用户自主撤回终态；归档留存，【去处理】隐藏 |
