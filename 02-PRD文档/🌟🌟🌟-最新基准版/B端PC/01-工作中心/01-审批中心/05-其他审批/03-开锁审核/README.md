- **申请人侧**：现场作业人员在门禁设备处或通过 [03-业务审批/04-我的申请管理](../../03-业务审批/04-我的申请管理/README.md) 发起开锁申请与查看下发密码；
- **配置策略侧**：开锁审批策略由 [配置管理/22-业务流程管理-开锁审批](../../../../08-配置管理/22-业务流程管理-开锁审批/README.md) 维护指定设备一机一配；
- **审批人侧（本目录）**：风控专员或仓管负责人在本工作台独立审查并执行通过/驳回。
