## 审批任务字段字典

> 通过 `biz_type`（业务类型）+ `apply_no`（业务单号）关联各子类型申请主表。适用于**已接入通用流程配置**并进入待办/已办/抄送的子类型。
> 遵循【审批任务双通道分流规则】(APV-TASK-F01) 与【自审禁止与本人单据过滤规则】(APV-TASK-F03)。

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 新增页 | 编辑页 | 列表展示 | 筛选控件与匹配 | 详情展示 | 字段说明与关联规则 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **任务编号** | 系统生成 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 单行文本输入框；精确匹配 | 是 | 审批任务全局唯一编号，遵循【审批任务幂等创建与并发控制规则】(APV-TASK-F02) | 只读文本 |
| **业务类型** | 系统快照 | 枚举（Enum） | 系统自动 | 不适用 | 不涉及 | 是 | 下拉单选框；精确匹配 | 是 | 取值见数据字典（如仓储预约、融资审批等）；决定待办卡片扩展展示模板与路由 | 状态徽章（Badge） |
| **业务类型名称** | 系统快照 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 下拉单选框；精确匹配 | 是 | 与 `biz_type` 严格对应展示文案 | 只读文本 |
| **业务单号** | 系统关联 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 单行文本输入框；精确匹配 | 是 | 关联业务申请单据主键，点击跳转该业务申请独立详情模态弹窗或详情页 | 链接文本 |
| **审批顺序号** | 系统生成 | 整数（Integer） | 系统自动 | 不适用 | 不涉及 | 否 | 不可筛选 | 是 | 当前审批节点在流程链中的序号（从 1 开始）；严格按序推进 | 只读文本 |
| **审批节点名称** | 系统快照 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 不可筛选 | 是 | 审批流程配置中的节点展示名称（如部门经理复核、风控总监终审） | 只读文本 |
| **审批对象类型** | 系统快照 | 枚举（Enum） | 系统自动 | 不适用 | 不涉及 | 否 | 不可筛选 | 是 | 枚举值：`SPECIFIED_USER`（指定人员）、`SPECIFIED_ROLE`（指定角色） | 只读文本 |
| **处理人账号** | 系统带出并快照 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 单行文本输入框；精确匹配 | 是 | 当前任务指定处理人用户账号，遵循【自审禁止与本人单据过滤规则】(APV-TASK-F03) 剔除本人 | 只读文本 |
| **处理人姓名** | 系统快照 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 单行文本输入框；模糊匹配 | 是 | 处理人真实姓名，用于待办列表及流转时间轴展示 | 只读文本 |
| **任务状态** | 系统维护 | 枚举（Enum） | 系统自动 | 不适用 | 不涉及 | 是 | 下拉多选框；包含匹配 | 是 | 枚举值：`PENDING`（待处理）、`APPROVED`（已通过）、`REJECTED`（已驳回）、`CLOSED`（已关闭）。遵循【审批任务流转与终态更新规则】(APV-TASK-F04) | 状态徽章（Badge） |
| **审批结果** | 审批人操作 | 枚举（Enum） | 条件必填 | 不适用 | 不涉及 | 是 | 下拉单选框；精确匹配 | 是 | 枚举值：`APPROVE`（通过）、`REJECT`（驳回）。已处理列表必显 | 状态徽章（Badge） |
| **审批意见** | 审批人录入 | 文本（Text） | 选填 | 不适用 | 不涉及 | 否 | 不可筛选 | 是 | 最多支持录入 200 个字符；审批通过时可选填 | 多行文本输入框 |
| **驳回原因** | 审批人录入 | 文本（Text） | 条件必填 | 不适用 | 不涉及 | 否 | 不可筛选 | 是 | 审批驳回时强制必填，最多支持录入 200 个字符；遵循【审批驳回强制必填与全链阻断规则】(APV-TASK-F05) | 多行文本输入框 |
| **申请人姓名** | 业务主表 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 单行文本输入框；模糊匹配 | 是 | 业务申请发起人真实姓名，展示于卡片首行 | 只读文本 |
| **申请人企业** | 业务主表 | 字符串（String） | 系统自动 | 不适用 | 不涉及 | 是 | 下拉单选框；精确匹配 | 是 | 申请人所属企业全称，遵循多租户数据权限隔离 | 只读文本 |
| **提交时间** | 业务主表 | 日期时间（DateTime） | 系统自动 | 不适用 | 不涉及 | 是 | 日期时间范围选择器；区间匹配 | 是 | 业务申请提交时间，格式：`YYYY-MM-DD HH:mm:ss` | 只读文本 |
| **处理时间** | 系统生成 | 日期时间（DateTime） | 系统自动 | 不适用 | 不涉及 | 是 | 日期时间范围选择器；区间匹配 | 是 | 审批人点击完成处理的时间戳；待处理时置空 | 只读文本 |

> **边界说明**：开锁审批单据（`biz_type=UNLOCK_APPLY`）直通专网专道，走 [05-其他审批/03-开锁审核](../05-其他审批/03-开锁审核/开锁审核主PRD.md)，不进入本任务表。
