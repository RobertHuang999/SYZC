# 客户融资需求线索 主PRD

> **模块定位**：融资管理第 1 节点菜单，统一接收外部融资申请生成线索记录，支持运营基础校验、受理、“需要尽调”路由分流派单及异常驳回入池。
> **移动端对应**：[B端H5/03-业务办理/03-客户需求审批/03-客户融资需求线索](../../../../B端H5/03-业务办理/03-客户需求审批/03-客户融资需求线索/README.md)（`biz-approve-customer-finance-leads`）
> **版本**：V1.3 | **更新时间**：2026-09-02 | **责任人**：森云科技（Senyun Technology）

---

## 1. 业务背景与功能范围

承接外部 C 端提交的融资申请，统一存储申请信息快照，支持运营方基础校验、受理后分配跟进（按“需要尽调=是/否”自动路由分流）及异常驳回入池管理。

| 包含功能 | 不包含功能 |
| :--- | :--- |
| 外部申请接收与生成线索；列表与详情查看；基础校验受理；分配跟进（按需要尽调路由分流）；驳回入池（记录驳回原因）。 | C 端申请提交界面；尽调任务具体办理；资方授信审核。 |

## 2. 单据与状态机

### 2.1 状态枚举

| 状态 | 含义 | 是否终态 |
| :--- | :--- | :---: |
| **待受理** | 外部申请成功接入后的初始状态，等待运营基础校验 | 否 |
| **已受理** | 运营基础校验通过，等待路由分配 | 否 |
| **申请失败** | 运营校验不通过或已受理后主动驳回的结果状态 | 否（统一进入被拒退回池【线索被拒页签】） |

> **注**：线索记录先经运营基础校验进入“已受理”，再执行“分配跟进”。分配成功后根据路由生成下游任务，本节点线索记录保留处理记录与最新流转状态。

### 2.2 状态流转表

| 当前状态 | 动作 | 前置条件 | 结果状态 | 二次确认 | 后置影响 | 失败处理 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **待受理** | 基础校验通过并受理 | 申请信息完整合规 | 已受理 | 无 | 固化受理人、受理时间，开放路由分配 | Toast：“受理失败，请检查申请资料” |
| **待受理** | 驳回并填写原因 | 资料不合规或不准入；驳回原因必填 | 申请失败（入池） | 需确认 | 记录驳回原因与处理人；入【被拒退回池 -> 线索被拒页签】 | Toast：“请填写驳回原因” |
| **已受理** | 分配跟进（路由流转） | 需要尽调字段已保存；路由对象有效 | 流转下游（待尽调 / 授信已受理） | 无 | 需要尽调=是：指派尽调人员；需要尽调=否：分配资方机构；固化处理人与处理时间 | Toast：“缺少有效路由配置或指派失败” |
| **已受理** | 主动驳回并填写原因 | 驳回原因必填 | 申请失败（入池） | 需确认 | 记录驳回原因与处理人；入【被拒退回池 -> 线索被拒页签】 | Toast：“请填写驳回原因” |

### 2.3 动作能力矩阵

| 动作 | 待受理（线索） | 已受理（线索） | 申请失败（驳回入池） |
| :--- | :---: | :---: | :---: |
| **查看详情** | ✅ | ✅ | ✅ |
| **基础校验通过并受理** | ✅ | ❌ | ❌ |
| **分配跟进（路由分配）** | ❌ | ✅（按需要尽调分流） | ❌（在被拒池操作重新指派） |
| **驳回并填写原因** | ✅ | ✅ | ❌ |

## 3. 核心业务规则

1. **R01（生成规则）**：外部申请成功接收后，系统自动生成客户融资需求线索主记录（初始状态：待受理），同一申请标识按幂等性处理不重复生成。
2. **R02（路由快照）**：“需要尽调”根据融资产品配置自动带出（是、否），并在申请生成时保存快照，后续流程以此快照为准。
3. **R03（受理后分流）**：运营先将资料完整合规的线索置为“已受理”，再操作“分配跟进”。系统根据快照规则强校验：需要尽调=是：仅能指派尽调人员进入【待尽调】；需要尽调=否：分配资方机构后直接进入【授信已受理】。
4. **R04（入池规则）**：运营驳回的线索置为“申请失败”，统一进入【被拒退回池 -> 线索被拒页签】，支持在被拒池执行“按路由重新指派”或“重新救活”。

## 4. 功能清单与端侧能力

### 一、功能矩阵清单

| 功能编号 | 功能名称 | 适用角色 | PC 端能力 | 移动端能力 | 关键控制与规则 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L-01** | 申请接收与生成 | 系统、运营 | 接收记录、查看来源与时间 | 查看接收记录 | 上游提交后自动生成待受理线索记录；按申请标识幂等防护 |
| **L-02** | 线索列表与筛选 | 运营 | 全量列表、组合筛选（产品/状态/日期）、导出 | 列表展示、快捷筛选 | 支持产品名称、申请人名称、需要尽调、融资状态组合检索 |
| **L-03** | 线索详情查看 | 运营、客户 | 完整详情、附件预览、明细展示 | 详情弹窗、附件查看 | 继承申请人及产品明细，敏感信息按角色规则脱敏 |
| **L-04** | 基础校验与受理 | 运营 | 校验通过/驳回、填写说明 | 校验通过/驳回 | 校验通过更新为“已受理”；不通过更新为“申请失败”并进入被拒池 |
| **L-05** | 路由分配跟进 | 运营 | 分配跟进弹窗、选择人员/资方 | 单笔分配跟进 | 仅“已受理”状态可操作；需要尽调=是指派尽调人员，需要尽调=否分配资方机构 |
| **L-06** | 已受理后主动驳回 | 运营 | 主动驳回、填写原因 | 单笔主动驳回 | 已受理状态下触发，更新为“申请失败”，进入被拒池【线索被拒页签】 |
| **L-07** | 处理进度与时间轴 | 运营、客户 | 状态变更历史、操作人、时间轴 | 状态展示、处理进度 | 融资金额/期数不可直接下拉修改，由系统维护状态 |

### 二、端侧差异说明

- **PC 端**：提供全量线索列表、组合筛选、批量导出、驳回原因弹窗及路由分配指派操作；
- **移动端（H5）**：挂载于「业务办理 → 客户需求审批 → 客户融资需求线索」，提供线索列表、快捷筛选、详情查看及单笔分配跟进/驳回审批操作。
