# 客户融资尽调办理主PRD

> **模块定位**：融资监管 / 融资管理第 2 节点业务单据，承接上游“需要尽调=是”的融资申请件，解耦提供【待尽调】与【尽调完成】双标签页视图，支持尽调专员推进主体资质复核、同组织任务转交、智风控模型异步调用、线下实地核验报告归档，以及审批通过后向合作资方机构的派发流转与异常单据驳回入池。  
> **移动端对应**：`B端H5/02-工作台/02-融资监管/05-客户融资尽调办理`  
> **版本**：V1.4 | **更新时间**：2026-09-16 | **责任人**：森云科技（Senyun Technology）  
> **编写依据**：[《客户融资尽调办理字段清单》](./客户融资尽调办理字段清单.md) 是展示、筛选及明细字段的唯一基准；[《客户融资尽调办理业务规则规格》](./客户融资尽调办理业务规则规格.md) 是双标签页状态机、尽调转交、智风控回调及报告分配资方的唯一定义真源。

## 1. 业务背景与核心痛点

### 1.1 业务背景
大宗动产质押融资金额巨大，仅凭线上填报资料无法完全排除“虚假贸易背景、壳公司骗贷、空仓无货、涉诉查封”等高危违约风险。对于高风险或大金额融资产品，平台要求必须开展线下实地尽调与第三方大数据风控扫描。

系统通过建设**客户融资尽调办理**模块，作为风控执行与实地验核的操作中枢，赋能尽调专员对接智风控引擎排查企业资信，组织实地验库核查质押物真实物理状态，出具不可推翻的尽调报告，为出资金融机构提供确凿的贷前尽职调查证据。

### 1.2 核心业务痛点
1. **尽调人员调休外出，任务交接难流转**：传统线下交接容易漏单，缺乏同组织专员在线转交与权责审计机制；
2. **外部风控对接等待耗时，流程卡死**：智风控模型计算存在秒级至分钟级延迟，若采用同步等待极易超时崩溃；
3. **完成件与待办件混杂，操作易误触**：已办结或已失败的单据若与待办单据混排，专员难以快速识别处理优先级；
4. **尽调报告上传不严肃，资方审核缺依据**：缺少强制上传尽调报告卡口，容易出现“仅点击通过但无实地报告”的合规漏洞。

## 2. 功能范围 (Scope)

| 包含功能（已纳入范围） | 不包含功能（超出范围） |
| :--- | :--- |
| - **双标签页业务架构解耦**：划分【待尽调标签页】（承载待尽调、受理中状态）与【尽调完成标签页】（承载受理成功、受理失败、申请失败状态）；<br>- **多维条件组合检索与导出**：支持按产品名称、申请人名称、尽调状态、尽调人员及时间区间筛选，支持列表数据导出；<br>- **同组织任务转交**：尽调专员支持将名下待尽调任务转交给同一组织机构下的其他同事，转交后记录流转轨迹；<br>- **主体要素核对与发起智风控**：核对企业工商/个人身份证要素，一键异步调用第三方智风控 OpenAPI，状态自动推进至“受理中”；<br>- **智风控异步回调与人工复核**：接收 `PASS`（受理成功）、`REJECT`（受理失败入池）、`REVIEW`（需人工复核）模型结论；<br>- **尽调报告附件归档与分配资方**：受理成功后，强制上传线下尽调报告盖章件（PDF/Word），分配已启用的合作资方机构并向【客户融资授信办理】流转；<br>- **专员手动拒绝与入池归集**：现场排查严重异常时支持手动拒绝，强制填写原因，单据标记为“申请失败”并可靠写入【被拒退回池】。 | - **外部 C 端前置线索接入与初审受理**：由【客户融资需求线索】模块承载；<br>- **智风控平台内部大数据清洗与评分模型算法开发**：由第三方专业风控平台提供；<br>- **资方信贷核心系统的授信审批决策**：由【客户融资授信办理】与资方银行核心承载；<br>- **被拒尽调任务的二次调度与救活**：在【被拒退回池 -> 尽调失败标签页】中闭环处理。 |

## 4. 业务场景与用户故事

| 场景编号 | 业务场景 | 触发角色 | 核心交互与风控约束 | 业务价值 |

| **场景 2【主体要素核对与发起智风控模型核验】(S02)** | 主体要素核对与发起智风控模型核验 | 尽调专员本人 | 专员核对借款企业统一信用代码无误后，点击【发起尽调】。系统异步调用第三方智风控平台，状态流转为“受理中”。专员可继续处理其他单据，无需白屏死等。5 秒后智风控回调返回 `PASS`，单据自动变更为“受理成功”并移入【尽调完成标签页】。遵循【尽调责任人独占与主体资质核验规则】(R01) 与【智风控异步回调与复核状态收敛规则】(R06)。 | 自动化大数据风控秒级初筛，极大提升业务办理吞吐效率。 |

## 5. 页面功能与交互说明

### 5.1 客户融资尽调办理主列表页（`P-RZ-002`）
* **页面路径**：`工作台 → 融资监管 → 融资管理 → 客户融资尽调办理`
* **顶部双标签页切换**：
  1. **【待尽调标签页】**：角标展示待处理数字红点，展示 `待尽调` 与 `受理中` 任务；
  2. **【尽调完成标签页】**：展示历史归档的 `受理成功`、`受理失败` 及 `申请失败` 单据（遵循只读保护规则 R05）。
* **筛选查询区排布（横向排列）**：
  1. **综合搜索输入框**（单行文本输入框，占位提示“请输入产品名称/申请人”，支持双模糊匹配）；
  2. **状态筛选**（下拉单选框，依据当前标签页自适应选项）：
     - 待尽调标签页选项：`全部`、`待尽调`、`受理中`；
     - 尽调完成标签页选项：`全部`、`受理成功`、`受理失败`、`申请失败`；
  3. **尽调人员**（下拉单选框，列出当前登录机构下在职尽调专员）；
  4. **时间**（日期时间范围选择器，检索任务分配时间区间）；
  - 右侧配置橙黄色实心【查询】按钮、白底【重置】按钮及【导出】操作链接。
* **数据表格呈现（11 列）**：
  1. **序号**（数字递增，翻页重新计算）；
  2. **产品名称**（融资产品名称）；
  3. **申请人名称**（企业全称或个人货主姓名）；
  4. **意向融资金额（元）**（金额数值，千分位，保留 4 位小数，遵循 R07）；
  5. **意向融资期数**（如 `12期`）；
  6. **抵/质押物**（`存货` 或 `仓单`，仓单支持点击穿透仓单详情）；
  7. **尽调状态**（彩色徽章展示：`待尽调` 橙底、`受理中` 蓝底、`受理成功` 绿底、`受理失败`/`申请失败` 红底灰字）；
  8. **尽调人员**（当前负责尽调专员姓名）；
  9. **尽调分配时间**（任务指派至当前专员的时间戳）；
  10. **处理时间**（最近一次更新时间戳）；
  11. **操作列**（动作随状态与标签页动态渲染）：
      - `待尽调`：【查看】、【发起尽调】、【任务转交】、【手动拒绝】；
      - `受理中`：【查看】（若命中需人工复核展示【人工复核】）；
      - `受理成功`：【查看】、【分配给资方】、【下载尽调报告】；
      - `受理失败` / `申请失败`：【查看】、【下载报告】（只读归档，支持在被拒退回池调度）。

### 5.2 尽调详情抽屉/页面
* **主体基本信息卡片**：企业工商注册信息、信用代码、法人及经办人脱敏联系方式；
* **智风控报告专区**：通过后端生成的临时 Token（15 分钟时效 P02）内嵌渲染智风控综合评分、司法涉诉雷达图与负面舆情监控；
* **现场尽调材料清单**：展示现场勘验照片、权属证明文件，以及盖章版尽调报告附件，支持在线预览与下载；
* **审批轨迹时间轴**：按时间先后记录“线索指派 $\rightarrow$ 专员转交 $\rightarrow$ 智风控调用 $\rightarrow$ 报告上传 $\rightarrow$ 资方分配”完整链路。

### 5.3 交互模态弹窗规格
1. **任务转交模态表单**：
   - 标题：“任务转交”；
   - 目标专员下拉单选框（仅展示同机构同事，跨机构阻断 C01）；
   - 转交原因说明（单行文本输入框，选填）；
   - 点击【确认转交】即时生效并记录审计。
2. **手动拒绝模态弹窗**：
   - 标题：“拒绝尽调任务”；
   - 警示文案：“*确认拒绝该尽调任务？拒绝后将移入完成页签并入被拒池。*”；
   - 拒绝分类下拉单选框（`企业资信不良`、`现场无实物`、`司法涉诉严重`、`其他原因`）；
   - 详细拒绝说明（多行文本输入框，必填，限制 $\le 300$ 字，缺失阻断 C02）；
   - 点击【确认拒绝】后单据移入完成标签页并入池。
3. **分配资方模态表单**：
   - 标题：“分配给合作资方”；
   - 尽调报告检查：自动校验附件列表中是否包含尽调报告，无报告禁止提交 (C03)；
   - 合作资方机构下拉单选框（列出有效合作资方银行）；
   - 业务备注（单行文本输入框，选填）；
   - 点击【确认分配】后流转至授信模块。

## 8. 非功能性需求（NFR）与审计存证

### 8.1 性能与稳定性
* **双标签页切换秒级响应**：在十万级尽调任务量下，切换【待尽调】与【尽调完成】标签页数据渲染耗时 $\le 500\text{ms}$；
* **智风控异步解耦吞吐**：风控调用采用异步消息队列削峰，支持每秒并发派发 100+ 笔风控核验任务；
* **大文件报告快速上传与分发**：支持最大 50MB 的 PDF/Word 尽调报告直传对象存储（OSS），支持分片断点续传。

### 8.2 司法存证与防篡改
* **尽调结论不可撤销**：手动拒绝入池与资方分配推向下游后，单据进入司法不可变归档态，严禁二次修改结论；
* **全生命周期审计追踪**：全路径记录转交人、智风控原始响应快照、拒绝原因、尽调报告 Hash 散列值与时间戳。

## 9. 验收标准与测试重点

| 验收编号 | 验收项与测试用例 | 预期结果与合格标准 | 对应规则 |
| :--- | :--- | :--- | :--- |
