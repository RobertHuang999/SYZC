# 11 - 设备管理与查看监控

> **归档位置**：`02-PRD文档/🌟🌟🌟-最新基准版/B端PC/03-融资监管/07-抵质押业务-抵质押业务管理/采集的资料/`  
> **模块定位**：抵质押业务管理 · 订单行操作【设备管理】与【查看监控】详尽规约  
> **核心使命**：提供订单项下物联监控设备（摄像头、温湿度、门禁）的全生命周期管理、远程实时视频监控、云台控制与现场抓拍。

---

## 1. 总体业务流程图

```mermaid
flowchart TD
    A["点击行操作【设备管理】或【查看监控】"] --> B{"订单当前是否已绑定 IoT 设备?"}
    
    B -- "未绑定 (空态)" --> C["展示【无设备空态引导页】\n提示: 当前订单尚未绑定任何智能监管设备！\n按钮: 【去绑定设备】"]
    C --> C1["进入【设备绑定向导】\n勾选所在仓库内的摄像头/温湿度/门禁，提交生效"]
    
    B -- "已绑定" --> D{"操作入口区分"}
    
    D -- "【设备管理】" --> E["展示【订单设备管理抽屉/弹窗】"]
    E --> E1["多品类设备矩阵卡片: 摄像头、温湿度计、智能门禁"]
    E1 --> E2["设备独立开关: 开启/关闭该设备对应的预警规则"]
    E1 --> E3["设备生命周期动作: 【重新绑定】 / 【解除绑定】"]
    
    D -- "【查看监控】" --> F["展示【实时监控与云台大屏】"]
    F --> F1["WebRTC / HLS 实时视频低延迟直播流"]
    F --> F2["云台 PTZ 控制盘: 八向转动、焦距变倍、预置位轮巡"]
    F --> F3["【一键抓拍】: 实时截图并自动生成防伪存证相册"]
```

## 2. 无设备空态保护机制 (Empty State Guard)

* **设计背景**：新开立的订单或尚未分配固定库位的订单，往往暂无绑定硬件。若直接打开空白监控大屏会引起操作误解。
* **空态界面原型**：
  ```
  +-------------------------------------------------------------+
  |  查看监控 - 订单号：ZY-20260818-0021                    [X] |
  +-------------------------------------------------------------+
  |                                                             |
  |                        [ 📷 无设备图标 ]                    |
  |                                                             |
  |              当前订单暂未绑定任何智能监控设备！              |
  |     为了保障质押物安全，建议立即前往关联库位绑定监控设备。   |
  |                                                             |
  |                      [ 立即去绑定设备 ]                     |
  |                                                             |
  +-------------------------------------------------------------+
  ```

### 4.2 抓拍存证规范
* **水印字段**：订单编号、摄像头编号、货位编号、抓拍时间戳（精确到毫秒）、GPS 经纬度、操作人账号；
* **存储归档**：抓拍图片自动上传至云端私有存储，并在【查看详情-资产明细】与【资料管理】中实时展示。
