> **适用功能**：抵质押业务管理 · 23-风险公示  
> **版本**：V1.0 定稿版 | **更新时间**：2026-09-11 | **责任人**：合规与法务团队

---

## 1. 状态机模型与流转表

```mermaid
stateDiagram-v2
    [*] --> UNPUBLICIZED : 预警处置完成结案 (准入公示)
    UNPUBLICIZED --> PUBLICIZED : 确认公示 (同步至司法存证链)
    PUBLICIZED --> REVOKED : 撤销公示 (仅限 R-RISK-MGR，必填撤销原因)
    REVOKED --> PUBLICIZED : 重新确认公示
    PUBLICIZED --> [*]
```

---

## 2. 核心业务规则 (Business Rules)

### 2.1 [DZY-R23] 仅限已结案风险事件准入公示 (Resolved-Only Guard)
严禁对未结案、处于核查中的在途预警发起对外公示，防止因事实不清对借款企业商誉造成侵权。

### 2.2 [DZY-R23a] 取消公示权限与审计留痕 (Revocation Audit)
取消公示仅对具备 `R-RISK-MGR` 角色用户开放；弹窗强制录入 $\ge 10$ 字撤回原因；撤销前后数据快照写入不可变存证链。

## 3. 风险公示交互时序图

```mermaid
sequenceDiagram
    autonumber
    actor User as 风险合规专员
    participant Web as 风险公示控制台
    participant Core as 预警台账
    actor Mgr as 高级风控主管 (R-RISK-MGR)
    participant Chain as 司法区块链

    User->>Web: 勾选已结案预警，点击【批量公示】
    Web->>Chain: 上链同步风险事实与处置整改报告
    Chain-->>Web: 返回存证哈希，状态更新为【已公示】
    Note over Web, Mgr: 发现需要撤销公示
    Mgr->>Web: 凭 R-RISK-MGR 权限点击【取消公示】，录入撤回原因
    Web->>Chain: 发送撤回信令，状态置为【已撤销公示】，永久记录审计日志
```
