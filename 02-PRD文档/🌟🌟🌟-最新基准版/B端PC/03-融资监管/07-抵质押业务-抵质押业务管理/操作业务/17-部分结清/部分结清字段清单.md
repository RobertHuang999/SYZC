# 结算管理与部分结清字段清单

> **业务场景**：流动资金贷款分期还本 / 提前归还部分借款 / 抵押率动态压降  
> **对象类型**：还款申请单 + 资金流水台账 + 银行到账凭据附件  
> **数据结构**：结算台账主表 + 还款录入申请表 + 试算测算数据模型 + 银行回单存证  
> **业务目的**：规范借款企业在监管期内的部分本金还款流程，严格校验开区间金额范围，动态扣减在押贷款余额并压降抵押率。  
> **数据来源**：资方信贷核心 / 银企直联系统 / 银行电子回执 / 风控抵押率计算引擎  
> **首个正式状态**：待审核（`SUBMITTED`，挂载单据排他在途锁）  
> **状态终点**：已结清落账（`SETTLED`，释放互斥锁，扣减余额） / 已驳回（`REJECTED`）  
> **版本**：V1.0 定稿版 | **更新时间**：2026-09-11 | **责任人**：产品团队
