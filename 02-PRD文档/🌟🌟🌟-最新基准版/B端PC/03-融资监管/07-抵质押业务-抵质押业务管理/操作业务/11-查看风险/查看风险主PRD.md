## 1. 业务背景与功能定位

动产抵质押监管存续期内，押品可能遭遇市场跌价、设备掉线、异常移库、现场盘亏等多种风险。**【查看风险】**（原查看预警）提供订单级的集中风险看板，采用【未处理风险】与【已处理风险】双 Tab 架构，实现预警穿透查看、现场核查处置解除，并驱动订单列表红标的点亮与清零自动消除。

---

## 2. 业务全景流转架构

```mermaid
flowchart TD
    Start(["点击行操作【查看风险】"]) --> OpenDrawer["打开【订单风险中心】抽屉"]
    OpenDrawer --> TabCheck{"默认聚焦 Tab"}
    
    TabCheck --> TabPending["【未处理风险】Tab"]
    TabPending --> PendingList["展示未结案预警流水 (跌价/移库/离线/盘点短少)"]
    PendingList --> DoResolve["经办人点击行操作【核查处置】"]
    DoResolve --> FormInput["录入核查结论、上传带防伪水印现场整改照片"]
    FormInput --> SubmitResolve["确认解除结案"]
    SubmitResolve --> BadgeCheck{"[DZY-R11] 检查该订单所有未处理预警计数"}
    BadgeCheck -- "未处理数 > 0" --> KeepRed["订单列表保持红标警示"]
    BadgeCheck -- "未处理数 = 0" --> ClearRed["系统自动抹除订单列表红标，恢复正常绿标监控"]
    
    TabCheck --> TabDone["【已处理风险】Tab"]
    TabDone --> DoneList["展示历史已解除、已结案的风险记录 (可查阅归档)"]
```

## 3. 页面功能说明与界面骨架

### 3.1 订单风险中心抽屉
1. **双 Tab 导航**：`[ 未处理风险 ( 1 ) ]`（红色角标高亮）、`[ 已处理风险 ( 3 ) ]`；
2. **未处理风险列表**：预警编号、分类、等级（严重/中度/轻微）、触发时间、原因分析、行操作 `[ 核查处置 ]`；
3. **核查处置弹窗**：展示触发时详情快照、核查整改结论输入框（必填 $\ge 10$ 字）、现场整改防伪照片上传。
