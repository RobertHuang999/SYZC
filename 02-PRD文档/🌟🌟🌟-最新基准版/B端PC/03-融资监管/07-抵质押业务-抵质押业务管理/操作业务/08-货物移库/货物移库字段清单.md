# 货物移库字段清单

> **业务场景**：同仓内部库位调整 / 检修倒垛 / 监控设备自动换绑  
> **对象类型**：业务申请单 + 移库物料明细 + 自动抓拍存证  
> **数据结构**：移库申请主表 + 移位明细表 + 目标库位映射表 + 设备换绑流水表  
> **业务目的**：规范在押动产在同仓库内的库位变动，固化跨仓强阻断、毫秒级球机自动抓拍及物联监控自动换绑数据链。  
> **数据来源**：订单在押明细 / 仓库网格化货位台账 / 智能云台球机自动抓拍 / 流程中心  
> **首个正式状态**：待审批（`SUBMITTED`，挂载单据排他互斥锁）  
> **状态终点**：已移库生效（`APPROVED`，货位变更落账且监控换绑） / 已驳回（`REJECTED`）  
> **版本**：V1.0 定稿版 | **更新时间**：2026-09-11 | **责任人**：产品团队
