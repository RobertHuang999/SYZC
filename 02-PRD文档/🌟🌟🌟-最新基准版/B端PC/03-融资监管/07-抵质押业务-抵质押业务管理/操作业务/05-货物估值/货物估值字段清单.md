# 行业参考价与货物估值字段清单

> **业务场景**：大宗商品公允价值盯盘 / 货物单价与总价重新估值 / 未定价风险标定  
> **对象类型**：外部行情报价快照 + 估值调整申请单 + 试算测算数据模型  
> **数据结构**：行情参考价格库 + 货物估值操作表 + 试算效果面板表  
> **业务目的**：规范全系统统一的行业参考价口径，提供双轨制货物估值调整能力，解决打包一口价倒算精度损失问题，联动风控重算。  
> **数据来源**：第三方权威行情网站（SMM、Mysteel、生意社） / 资方风控估值意见 / 现场实物台账  
> **首个正式状态**：待审核（`SUBMITTED`，挂载单据排他在途锁）  
> **状态终点**：已生效（`EFFECTIVE`，热刷新存货估值与订单总货值） / 已驳回（`REJECTED`）  
> **版本**：V1.0 定稿版 | **更新时间**：2026-09-11 | **责任人**：产品团队
