# 货物出库字段清单

> **业务场景**：质押存货部分出库 / 电子仓单物料提取 / 现场监管出库验真核销  
> **对象类型**：业务申请单 + 出库明细清单 + 提货人信息 + 现场核销存证  
> **数据结构**：出库申请主表 + 拟出库物料明细表 + 提货司机信息表 + 现场核销流水表  
> **业务目的**：规范借款企业按履约进度提取部分在押货物的全流程，固化防全额提空拦截与 PDA 现场扫码核销数据链路。  
> **数据来源**：订单在押资产台账 / 用户录入 / 提货司机证件 / 现场手持 PDA 扫描  
> **首个正式状态**：待审批（`SUBMITTED`，挂载单码在途出库锁）  
> **状态终点**：已出库核销（`VERIFIED_OUTBOUND`，在押资产正式扣减落账） / 已驳回（`REJECTED`）  
> **版本**：V1.0 定稿版 | **更新时间**：2026-09-11 | **责任人**：产品团队

## 三、不可变快照与审计说明

| 快照业务节点 | 快照固化字段集合 | 原始数据源头 | 固化目的与合规依据 |
| :--- | :--- | :--- | :--- |
| **出库审批通过** | 出库单号、提货司机身份证/车牌、允许出库的物料条码与数量快照、放行时计算的剩余货值与抵押率 | 出库申请单、信贷批复、风控引擎 | 形成具有法律效力的电子《出库放行通知书》，作为现场提货放行的唯一凭证 |
| **现场扫码出库核销** | PDA 扫描条码时间戳、现场道闸抓拍车辆进出场照片、核销经办监管员、实际出库重量流水 | 现场手持 PDA、门禁车牌识别系统、地磅数据 | 证明货物物理真实交付出库，防范虚假提货与监守自盗风险 |
