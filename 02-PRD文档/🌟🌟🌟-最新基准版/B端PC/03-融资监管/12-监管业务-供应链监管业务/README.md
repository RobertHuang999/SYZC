## 模块下线说明

1. **下线背景**：
   - 在 SYZC 6.2 版本架构升级中，存货质押与监管业务订单模型已全面重构升级。
   - 订单预警与风控体系已收口并统一支持三类标准订单类型：`抵押`、`质押`、`监管服务`。历史旧版本的“供应链监管订单 / 监管”单据与独立菜单不再保留，于 6.2 版本正式下线退役。

2. **文档维护策略**：
   - 本目录作为当前线上采集的基准占位，**不再编制 6.2 增量 PRD 三件套**。
   - 6.2 版本专门设立了退役归档：详见 [6.2 供应链监管业务下线与退役说明](../../../B-迭代需求/6.2版本（2026.08）/08-下线与退役模块/12-监管业务-供应链监管业务/README.md)。
   - 目标态菜单架构中已移除该菜单，详见 [6.2 PC 菜单地图（目标态）](../../../B-迭代需求/6.2版本（2026.08）/00-PC菜单地图（目标态）.md) §三 与 [6.2 菜单迭代记录](../../../B-迭代需求/6.2版本（2026.08）/00-菜单迭代记录.md)。
   - 后续待 6.2 版本正式割接上线后，本目录将根据线上最终下线验收结果进行正式归档或移除。
