# 客户融资授信办理 字段清单

> **文档定位**：客户融资授信办理菜单字段清单（唯一引用标准：《融资管理字段清单》）。
> **节点说明**：本表为【节点三：客户融资授信办理】页面的字段展示、筛选与审核操作口径。
> **版本**：V1.3 | **更新时间**：2026-09-02 | **责任人**：森云科技（Senyun Technology）

## 一、业务字段

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **产品名称** | 运营产品配置/系统带出 | 继承自线索；运营配置的产品名称 | 系统自动 | 是 | 是（综合搜索） | 是 | 客户申请对应的融资产品 | 只读不可手工修改 |
| **需要尽调** | 融资产品配置/系统带出 | 枚举：是、否；继承自线索快照 | 系统自动 | 是 | 是（Select） | 是 | 是否需要现场尽调 | 只读展示 |
| **申请人类型** | C端申请/系统带出 | 枚举：企业货主、个人货主 | 系统自动 | 是 | 是（Select） | 是 | 申请人主体类型 | 继承自线索 |
| **申请人名称** | C端申请/系统带出 | 企业取公司全称，个人取姓名 | 系统自动 | 是 | 是（综合搜索） | 是 | 申请人名称 | C端带入，列表标签为“申请人” |
| **抵/质押物** | C端申请/系统带出 | 枚举：存货、仓单 | 系统自动 | 是 | 否 | 是 | 抵/质押物类型 | 仓单可点击查看详情 |
| **意向融资金额（元）** | C端申请/系统带出 | 单位：元，保留小数点后4位 | 系统自动 | 是 | 否 | 是 | 客户意向融资金额 | 继承自线索 |
| **意向融资期数** | C端申请/系统带出 | 正整数，单位：期 | 系统自动 | 是 | 否 | 是 | 客户意向融资期限 | 继承自线索 |
| **授信金额（元）** | 资方审核录入 | 资方核准授信额度；单位：元，保留4位小数 | 标记成功必填 | 是 | 否 | 是 | 授信核准金额 | 标记申请成功时录入 |
| **授信期数** | 资方审核录入 | 资方核准授信期限；正整数，单位：期 | 标记成功必填 | 是 | 否 | 是 | 授信核准期限 | 标记申请成功时录入 |
| **融资状态** | 系统维护 | 枚举：授信已受理、申请成功、申请失败 | 系统自动 | 是 | 是（Tab/Select）| 是 | 当前授信审核状态 | 状态流转控制 |
| **拒绝原因** | 资方审核录入 | 资方标记申请失败时的审核原因说明 | 标记失败必填 | 否 | 否 | 是 | 资方拒绝原因 | 写入被拒退回池备查 |
