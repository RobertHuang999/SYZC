## 共同口径

1. **数据范围**：总机构看全部机构与仓库；机构看按账号机构权限与仓库权限过滤；
2. **只读**：六个看板均不提供业务写入，行操作只做查看或跳转；
3. **时间口径**：按业务发生时间统计，不按制单时间；
4. **待确认**：指标公式、金额小数位与单位需业务确认后升正式版。
