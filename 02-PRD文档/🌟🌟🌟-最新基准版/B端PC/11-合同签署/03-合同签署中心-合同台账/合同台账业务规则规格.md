## 一、业务规则

### 【合同台账合同数据范围与权限规则】(P01)

1. 页面访问、按钮操作与数据范围按权限清单控制，数据范围：功能权限；
2. 合同内容与签署附件按项目脱敏与下载权限规则处理；
3. 无权限的记录不可见。

### 【合同台账合同状态与操作规则】(R01)

1. 合同按「草稿 → 待签署 → 签署中 → 已完成 / 已撤销 / 已失效」流转；
2. 已完成与已撤销合同不可再编辑，只可查看与下载；
3. 撤销、删除须二次确认并记录原因，操作留痕；
4. 批量操作只对状态允许的记录生效，部分失败时逐条返回结果。

### 【合同台账模板与签署联动规则】(R02)

1. 模板停用后不可用于新发起，已发起合同不受影响；
2. 发起签署时固化模板版本与合同正文快照，后续模板修改不回写；
3. 直接发起、复制模板需具备对应按钮权限。

### 【合同台账异常与边界】(C01)

| 情况 | 系统处理 | 提示 |
| :--- | :--- | :--- |
| 合同已撤销再操作 | 阻断 | 合同已撤销，无法继续操作 |
| 模板被引用时删除 | 阻断 | 模板已被合同引用，无法删除 |
| 签署链接过期 | 阻断 | 签署链接已过期，请重新发起 |
