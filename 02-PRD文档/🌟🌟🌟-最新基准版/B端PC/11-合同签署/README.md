## 共同口径

1. **合同状态**：草稿 → 待签署 → 签署中 → 已完成 / 已撤销 / 已失效；
2. **模板冻结**：发起签署时固化模板版本与合同正文快照，后续改模板不回写历史合同；
3. **删除保护**：被合同引用的模板不可删除；
4. **权限**：按功能权限控制页面与按钮，数据范围按机构。
