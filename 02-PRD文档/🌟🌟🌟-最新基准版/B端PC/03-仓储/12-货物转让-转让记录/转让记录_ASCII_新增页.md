## 3. 受让人【货主档案】选择与快捷新增弹窗线框（6.3 替换二元认证弹窗）

> **6.3 变更**：本节原为「新接收方二元认证弹窗」。6.3 起受让人统一引用货主信息档案：检索命中即带出；未命中走【+ 快捷新增货主】表单，保存即挂接「货主·正常」，**不发送短信**。地址唯一校验移到转让生效节点（【转让生效地址唯一校验与双向快照】(R09)）。

```text
+------------------------------------------------------------------------+
| 选择受让人档案                                                      [X]|
|                                                                        |
|   搜索: [ 姓名 / 身份证号 / 统一社会信用代码            ]  [ 搜索 ]    |
|                                              [ + 快捷新增货主 ]        |
|                                                                        |
|   候选主体:                                                            |
|   +------------------------------------------------------------------+ |
|   | 示例受让人 · 个人 · 420822****3418 · 四川省成都市…   [查看档案]  | |
|   | 另一货主   · 企业 · 91341202MA2U0JHJ3F · 安徽省阜阳市…          | |
|   +------------------------------------------------------------------+ |
|                                                                        |
|                                  [ 取 消 ]    [ 确 定 ]                |
+------------------------------------------------------------------------+
```

> 命中候选即选中并回填；无匹配走【+ 快捷新增货主】，保存后回填为「未验证」，不触发短信。

> **6.3 线框补充**：弹窗顶部为检索框（姓名 / 身份证号 / 统一社会信用代码）+【+ 快捷新增货主】；中部落选中的主体卡片（名称、类型、脱敏证号、证件地址、【查看档案】）；底部【取消】【确定】。
