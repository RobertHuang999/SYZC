## 2. 交互弹窗：撤销确认弹窗

```text
+-----------------------------------------------------+
|                                                   X |
|   ! 确定要撤销盘点单？                              |
|                                                     |
|                [  确 定  ]     [  取 消  ]          |
+-----------------------------------------------------+
```

*注：撤销仅在“未开始”状态且制单人本人可见；点击【确定】后任务作废，流转为【已撤销】终态。遵循【操作动作与按钮权限矩阵】(R02)。*
