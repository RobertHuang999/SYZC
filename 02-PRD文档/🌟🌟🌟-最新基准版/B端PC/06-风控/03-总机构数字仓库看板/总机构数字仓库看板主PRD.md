## 1. 业务背景与定位

总机构需要一屏看清所有租户、所有仓库的数字化运行状态：仓库有没有在线、设备是否齐全、监控是否可用、异常仓库在哪里。看板同时提供「分享链接」能力，便于把某个仓库的实时画面或看板视图发给外部合作方查看；每次分享都会留下记录，支持随时失效。

**定位**：只读总览看板 + 分享台账，不承载设备配置与预警处置（那些在 [物联网IOT管理](../../07-物联网IOT与预警/01-物联网IOT管理/物联网IOT管理总索引.md) 与 [预警信息](../../07-物联网IOT与预警/02-预警信息/预警信息总索引.md)）。

## 2. 页面功能说明

### 2.1 入口与骨架

1. 侧栏：风控 → 风控中心，只有 **总机构风控管理看板、机构风控管理看板、总机构数字仓库看板、机构数字仓库看板** 四项；
2. 页面顶部：标题「总机构数字仓库看板」+ 数据更新时间；
3. 筛选区：仓库名称、仓库类型、在线状态，共 3 项 + 【查询】【重置】；
4. 指标区：仓库总数、在线仓库数、设备总数、在线设备数、监控可用率；
5. 内容区：仓库卡片/列表，展示仓库基础信息与设备在线情况；
6. 页内能力：右上角【链接分享记录】，打开同一个页面内的分享台账抽屉/弹窗。

### 2.2 链接分享记录（页内能力，不是侧栏菜单）

- 点击【链接分享记录】打开台账，列出本账号发起过的分享链接：文件名/仓库、分享人、分享时间、有效期、状态、操作；
- 操作只提供【查看页面】【失效】；失效后链接立即不可访问，记录保留；
- 台账按账号数据权限过滤：总机构账号可见全部，机构账号仅可见本机构；
- 权限清单保留 `总机构数字仓库看板 / 链接分享记录` 与 `机构数字仓库看板 / 链接分享记录` 两行，用于按钮级授权。

### 2.3 数据范围

- 总机构看板：可见全部租户、全部仓库；
- 机构看板：按账号机构权限与仓库权限过滤；
- 分享链接访问：按分享时固定的仓库与有效期校验，不继承分享人的其他权限。

## 3. 业务场景

### 场景 1【总机构巡览全部仓库在线情况】(S01)
运营人员进入看板，按「离线」筛选，定位到三家离线仓库，点击仓库卡片查看设备明细，通知对应机构处理。

### 场景 2【把某仓库实时画面分享给合作方】(S02)
运营人员选中仓库，生成分享链接并设置有效期，发给合作方；合作方通过链接查看该仓库画面。到期或运营人员手动【失效】后链接不可再访问，分享记录仍可追溯。

---

## 4. 验收标准

- [ ] 侧栏「风控中心」只有四个看板，无「链接分享记录」子菜单；
- [ ] 点【链接分享记录】在看板页内打开台账，可查看与失效；
- [ ] 分享链接过期或被失效后不可访问；
- [ ] 总机构与机构看板的数据范围符合账号权限。
