> **文档定位**：总机构数字仓库看板的数据范围、分享链接与只读规则的唯一真源；机构数字仓库看板复用本规格，仅数据范围不同。

>

## 一、业务规则

### 【数字仓库看板数据范围与只读规则】(R01)

1. **总机构看板**：可见全部租户、全部仓库；**机构看板**：按账号机构权限与仓库权限过滤。
2. 本页只读：不提供设备重命名、绑定、移除、配置等写操作；需要处理时跳转 [物联网IOT管理](../../07-物联网IOT与预警/01-物联网IOT管理/物联网IOT管理总索引.md) 对应页面。
3. 指标与列表为查询时点快照，刷新后重新计算；不订阅实时推送。
4. 账号无某仓库权限时，该仓库不出现在列表、指标与分享选择器中。

### 【链接分享记录生成与失效规则】(R02)

1. **分享入口**：看板内的分享能力生成带签名的临时访问链接，链接绑定分享时选定的仓库/视图与有效期。
2. **记录落账**：每次分享在上方台账生成一条记录（分享对象、分享人、分享时间、有效期、状态），不可删除。
3. **访问校验**：外部访问只按分享时固定的范围与有效期校验，不继承分享人的其他权限；过期立即不可访问。
4. **手动失效**：台账【失效】二次确认后立即生效，状态置为「已失效」，记录保留。
5. **审计**：分享生成、访问、失效均记审计日志，至少保留操作人、时间、对象与结果。

### 【看板下钻与监控查看规则】(R03)

1. 点击仓库卡片下钻到该仓库的设备明细，按仓库权限校验；
2. 监控画面按不超过 15 分钟的时效签名拉流，禁止长期有效的直链；
3. 无监控权限时展示占位图与提示，不报错。

### 【链接分享记录权限规则】(P01)

1. 权限清单保留「数字仓库看板 / 链接分享记录」行，用于按钮级授权；
2. 无「查看页面」权限时，台账入口隐藏；
3. 无「失效」权限时，操作列只显示【查看页面】；
4. 台账数据按账号数据权限过滤，机构账号不可见其他机构分享记录。

## 二、异常与边界

### 【分享链接被冒用或泄露】(C01)

| 情况 | 系统处理 |
| :--- | :--- |
| 链接在有效期内被转发 | 访问仍受限定的仓库/视图与有效期；操作人可在台账立即失效 |
| 超过有效期访问 | 页面提示「链接已过期」，不返回画面 |
| 仓库被删除或停用 | 链接自动失效，台账状态更新为「已失效」 |
