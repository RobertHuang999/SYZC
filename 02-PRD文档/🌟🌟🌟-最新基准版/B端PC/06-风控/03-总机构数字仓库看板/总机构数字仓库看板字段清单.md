>
> **版本**：V1.0 | **更新时间**：2026-11-11
>
> **采集依据**：06-08-03 页面采集 P-FK-003（当时仅记录到仓库名称与数字控件，字段待按实际页面补全）；补齐时以本清单为准更新。

## 一、筛选区

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 控件 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 仓库名称 | 仓库档案 | 文本；模糊匹配 | 选填 | 单行文本 | 占位符「请输入仓库名称」 |
| 仓库类型 | 仓库档案 | 枚举：监管仓 / 普通仓 / 合作仓等 | 选填 | 下拉单选 | 枚举以仓库管理档案为准 |
| 在线状态 | 设备汇总 | 枚举：`在线`、`离线`、`部分离线` | 选填 | 下拉单选 | 按仓库下设备在线比例判定 |
| 查询 / 重置 | 页面控件 | 按钮 | — | — | 重置不清空账号权限范围 |

---

## 二、指标卡

| 字段名称 | 计算口径 | 展示格式 |
| :--- | :--- | :--- |
| 仓库总数 | 权限范围内仓库去重计数 | 整数 |
| 在线仓库数 | 设备全部在线的仓库数 | 整数 + 占比 |
| 设备总数 | 仓库下监控、门禁、物联、GPS 设备合计 | 整数 |
| 在线设备数 | 最近一次心跳正常的设备数 | 整数 + 在线率 |
| 监控可用率 | 可播放监控数 / 监控总数 | 百分比，保留 1 位小数 |

| 字段名称 | 字段来源 | 展示 |
| :--- | :--- | :--- |

| 最后上报时间 | 设备心跳 | 日期时间；无上报展示 `--` |

## 四、链接分享记录台账

| 字段名称 | 字段来源 | 取值说明 | 展示 |
| :--- | :--- | :--- | :--- |
| 序号 | 系统生成 | 弹窗内自增 | 是 |
| 分享对象 | 分享时选择 | 仓库名称 / 看板视图名称 | 是 |
| 分享人 | 系统记录 | 姓名(所属机构) | 是 |
| 分享时间 | 系统记录 | `YYYY-MM-DD HH:mm:ss` | 是 |
| 有效期 | 分享时设置 | 日期时间或「长期」 | 是 |
| 状态 | 系统维护 | `有效`、`已过期`、`已失效` | 是 |
| 操作 | 页面控件 | 【查看页面】【失效】 | 是；已失效/已过期仅保留【查看页面】 |
