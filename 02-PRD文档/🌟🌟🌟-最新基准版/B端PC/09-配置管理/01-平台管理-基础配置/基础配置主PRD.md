## 1. 业务背景与设计目标

### 1.1 业务定位
**基础配置（P-PZ-004）** 是 SYZC 供应链金融存货监管系统的平台级运行底座与系统参数控制中心。系统连接资金方（银行/保理）、监管方、核心企业及仓储现场硬件设施，涉及大量三方安全认证接口、物联网硬件通讯、合规电子签章及用户法律协议。  
本模块面向平台管理员与机构系统管理员，提供**业务流程开关控制、法律协议多端呈现、外部数据源认证、物联网硬件网关对接及邮件通道调度**五位一体的一站式参数纳管中心。

### 1.2 核心痛点与解决目标
1. **业务风控与审批差异化痛点**：不同监管仓库对移库业务的审核严格程度不同。系统提供租户级【移库是否需要审核】全局控制开关，精准阻断或放行免审出入库流程。
2. **多终端多场景协议规范痛点**：针对登录端、仓单开立端等多触点，需要灵活上架《用户隐私协议》、《告知书》等法律文件。系统支持按展示位置动态分组配置、文件格式校验及版本更新。
3. **敏感凭证防泄漏与独立热更新痛点**：三方数据源（如工商四要素、OCR、中仓登）及硬件中台（如赛达监控、芯途异构、享宇智能挂锁）密钥属于核心保密资产。系统推行**敏感数据掩码脱敏（`*****`）、清空重录机制**与**卡片级独立编辑保存**，避免因单个接口变动导致全量数据源误覆盖或停机重启。
4. **告警多渠道通知保障痛点**：预警升级与事务通知高度依赖 SMTP 邮件链路。系统新增多节点邮件服务器配置，支持即时发送测试邮件校验连通性，防止预警漏发。

## 2. 功能范围 (In/Out of Scope)

### 2.1 本期范围 (In Scope)
* **页签一：基础参数配置**
  * 支持配置【移库是否需要审核】全局单选开关（是/否）；
  * 支持多组【协议配置】动态增删（展示位置、协议名称、协议文件上传）；
  * 底部提供统一【取消】与【保存】操作，支持离开前未保存强阻断提示。
* **页签二：数据源参数**
  * 纳管 9 大类数据源接口：企业四要素、营业执照 OCR、房产登记、个人二元、验证码短信、通知短信、地图、实人一体、电子签章；
  * 提供置顶数据保密与安全提醒；
  * 采用卡片式独立【编辑】/【保存】机制与全字段掩码脱敏。
* **页签三：硬件参数**
  * 纳管 9 大类硬件设备通讯协议：赛达监控设备(掌宇)、赛达温湿度设备、赛达人脸门禁、赛达监控报警(掌宇)、赛达GPS设备、芯途异构温湿度设备、芯途异构锁设备、芯途异构监控设备、享宇智能挂锁；
  * 提供流媒体协议、存储类型、监控报警服务商路由及 AK/SK 配置；
  * 采用卡片式独立【编辑】/【保存】机制。
* **页签四：邮件配置**
  * 支持维护多条 SMTP 邮件服务器配置行（服务器地址、端口、发件人邮箱、密码/授权码）；
  * 提供行操作【发送测试邮件】（弹窗输入收件邮箱实时验证握手）、【编辑】、【保存】、【删除】及底部【+ 新增发送邮件】。
* **通用全局交互**：
  * 未保存退出拦截弹窗：编辑过程中切换菜单或页签时，系统弹出阻断确认框。

### 2.2 不在本期范围 (Out of Scope)
* **不包含平台端数据源与硬件厂商的授权分配**：机构可配置的数据源与硬件范围受限于平台端（SaaS 管理端）赋予该机构的权限范围，本模块仅负责机构权限内的参数维护；
* **不包含协议在线富文本排版**：协议文件采用图片/PDF 格式上传，不提供内嵌 HTML 富文本在线编辑；
* **不包含历史参数版本回滚树**：本期参数保存即热生效并固化审计日志，不提供历史参数一键还原按钮。

### 3.2 页面分区与交互规格（按页签展开）

#### 3.2.1 【基础参数配置】页签
* **业务开关区**：
  * `* 移库是否需要审核：` 胶囊按钮单选切换组 `[ 是 ]`（主色高亮选中）与 `[ 否 ]`，默认根据当前机构存量配置回显。
* **协议与文件配置区**：
  * 区域标题：`协议：`；
  * **动态协议卡片组**：支持 1~N 组并联排列；
    * **展示位置**：下拉单选框，选项包含【登录】、【仓单开立】；
    * **协议名称**：单行文本输入框，最多 50 字符，默认占位文案“请输入协议名称”；
    * **协议文件上传**：上传控件，限制格式为图片（JPG/PNG）与 PDF，上传成功展示文件图标、文件名及绿色就绪勾选标识；
    * **组级操作**：右上角/右下角提供 `🗑 删除一组`（红色文字链接）与 `+ 添加一组`（橙色文字链接）。
* **底部固定操作栏**：
  * `[ 取消 ]`（次色按钮）：还原所有未保存修改并重置表单；
  * `[ 保存 ]`（主色按钮）：执行前置必填与格式校验，校验通过提交保存并热生效。

#### 3.2.2 【数据源参数】页签
* **安全提示栏（置顶红字）**：
  > `*重要提示：此类目为保密信息且涉及机构数据源安全性问题，为防止数据泄露系统不做历史配置数据展示。每次编辑保存前需要将您使用的各类接口调用信息全量重新录入再提交，否则将导致未配置信息的数据源不可用。`
* **独立数据源卡片矩阵（共 9 项，垂直陈列）**：
  * 各项均包含独立区域标题、配置输入表单与底栏 `[ 编辑 ]` `[ 保存 ]` 按钮；
  * **查看态**：所有密钥类输入框置灰且显示 `*****` 掩码脱敏；
  * **编辑态**：点击当前卡片 `[ 编辑 ]`，该卡片密钥输入框清空，高亮激活聚焦供用户全量录入；其他卡片仍保持查看态；
  * **保存动作**：点击当前卡片 `[ 保存 ]`，校验字段完整性后仅提交该卡片参数并热更新。

#### 3.2.3 【硬件参数】页签
* **安全提示栏（置顶红字）**：同数据源保密提示，明确硬件通信参数保密机制；
* **独立硬件卡片矩阵（共 9 项，垂直陈列）**：
  * 各项包含所属厂商类型、网关接口及通信协议输入框；
  * 直播流协议下拉/单选、存储类型（云存/本存）、监控报警服务商路由选择；
  * 同样支持卡片级独立的 `[ 编辑 ]` 与 `[ 保存 ]` 交互。

#### 3.2.4 【邮件配置】页签
* **顶部安全提示**：说明 SMTP 授权码保密原则；
* **邮件服务器配置列表**：
  * 每行展示一个 SMTP 账号配置卡片；
  * 包含字段：`* SMTP服务器地址`、`* SMTP端口`、`* 发件人邮箱`、`* 发件人密码/授权码`（掩码展示）；
  * 行级操作按钮栏：
    * `[ 发送测试邮件 ]`：弹出收件邮箱输入对话框，执行在线联通性测试；
    * `[ 编辑 ]`：激活该行输入框，清空密码授权码重新录入；
    * `[ 保存 ]`：提交保存该行配置；
    * `[ 删除 ]`：弹出二次确认弹窗，确认后彻底删除该行 SMTP 节点。
* **底部添加按钮**：`+ 新增发送邮件`，点击在列表末尾追加一行空配置行并自动进入编辑模式。

#### 3.2.5 通用未保存拦截弹窗
* **触发场景**：任一页签处于编辑模式且表单有 Dirty 修改时，用户点击切换页签、点击其他系统菜单或点击浏览器前进/后退。
* **弹窗视觉**：
  * 标题：`提示`
  * 图标：⚠️ 橙色感叹号
  * 正文：`您有配置内容未保存，若直接退出编辑内容将丢失，请确认是否退出？`
  * 按钮：`[ 取消 ]`（关闭弹窗保留当前编辑状态）、`[ 确定 ]`（放弃修改并执行页面跳转）。

## 4. 核心业务场景与用户旅程

### 场景 1【上线新协议配置】(CFG-S01)
1. 系统管理员进入 `配置管理 / 平台管理 / 基础配置`，默认处于【基础参数配置】页签；
2. 管理员查看【移库是否需要审核】保持为“是”；
3. 点击协议区域的 `+ 添加一组`，表单新增一组协议空白项；
4. 展示位置选择【仓单开立】，录入协议名称《仓单确权及代管服务协议》，点击上传《仓单确权协议.pdf》；
5. 点击底部【保存】，系统校验协议名称长度与文件完整性，保存成功弹出 Toast 提示：`“保存成功”`；
6. 后续货主在进行线上仓单开立申请时，前端自动调取并展示该份最新协议文件。

### 场景 2【更新高德/百度地图密钥】(CFG-S02)
1. 运维人员切换至【数据源参数】页签；
2. 浏览至【地图】卡片，当前查看态显示 Key: `*****`，服务端AK: `*****`；
3. 运维人员点击卡片右下角的 `[ 编辑 ]` 按钮；
4. 该卡片输入框解除锁定并清空，运维人员输入新的浏览器 Key 与服务端 AK；
5. 点击 `[ 保存 ]`，系统校验两项均非空后提交风控底座热更新，保存成功后输入框重新置为脱敏态 `*****`；
6. 其他数据源（企业四要素、电子签章等）未被改动，不受影响。

### 场景 3【新增预警通知发件邮箱并完成测试】(CFG-S03)
1. 运维人员切换至【邮件配置】页签；
2. 点击底部 `+ 新增发送邮件` 按钮，列表末尾新增一行；
3. 运维人员录入 SMTP 服务器地址 `smtp.qiye.aliyun.com`、端口 `465`、发件人邮箱 `alert@senyun.com` 及授权码；
4. 录入完毕点击该行 `[ 保存 ]` 成功；
5. 运维人员点击该行 `[ 发送测试邮件 ]`，弹出收件人弹窗，输入测试接收邮箱 `devops@senyun.com` 并点击【发送】；
6. 系统后台使用配置的 SMTP 参数发起握手并投递测试邮件，前端反馈：`“测试邮件发送成功，SMTP 连接正常”`。

## 5. 业务规则与约束摘要 (引用规则规格)

* **【移库审核全局拦截规则】(CFG-R01)**：开关置为“是”时，所有移库申请强制进入工作中心开锁与移库审批流；置为“否”时现场直通执行并生成免审审计流水。
* **【协议展示位置与防重复规则】(CFG-R02)**：协议展示位置限定于【登录】与【仓单开立】；协议名称 ≤ 50 字符；单组文件不可为空。
* **【未保存离开拦截规则】(CFG-R03)**：页面 Dirty 且未保存时，跨页签切换或菜单离开强制弹出阻断确认框。
* **【敏感参数掩码脱敏与重录规则】(CFG-R04)**：所有 APIKey、Secret、Token、私钥密码及短信签名在查看态统一采用 `*****` 掩码脱敏，严禁明文反显；点击编辑强制清空重新录入。
* **【卡片级独立保存与热更新规则】(CFG-R05)**：数据源与硬件配置采用卡片独立提交机制，单项更新立即生效，避免全量重提风险。
* **【SMTP 联通性即时验证规则】(CFG-R06)**：测试邮件发送必须实时校验网络连通、TLS 握手及密码鉴权，异常时反馈精准错误信息。
* **【平台授权范围隔离规则】(CFG-P01)**：机构仅可查看与配置平台端授权白名单内的数据源和硬件型号，跨越权限范围的接口强行拦截。

## 7. 验收标准 (Acceptance Criteria)

| 编号 | 验收项 | 操作与输入条件 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **V01** | 移库审核开关切换 | 在基础参数中将移库审核由“是”切换为“否”并保存 | 保存成功，后续移库业务不再触发审批流，直接放行 |
| **V02** | 协议增删与校验 | 添加一组协议，协议名称输入 51 个字符并尝试保存 | 系统前端拦截，提示“协议名称不得超过50字符”，阻断提交 |
| **V03** | 协议文件格式限制 | 上传 `.exe` 或 `.txt` 文件 | 系统文件选择器拦截或前端校验报错，仅允许图片与 PDF |
| **V04** | 未保存离开拦截 | 在基础参数或数据源中修改参数后，直接点击侧边栏其他菜单 | 阻断离开，弹出未保存离开二次确认框 |
| **V05** | 数据源敏感数据脱敏 | 进入数据源参数页签，查看已配置的企业四要素卡片 | ApiKey 与 SecretKey 均显示为 `*****` 掩码 |
| **V06** | 数据源独立卡片保存 | 仅编辑修改【营业执照OCR】卡片并保存 | 仅更新 OCR 配置，其他 8 类数据源状态与存量配置不受影响 |
| **V07** | 邮件配置连通性测试 | 输入正确的 SMTP 参数并点击【发送测试邮件】，输入有效收件邮箱 | 系统返回发送成功提示，收件箱成功收到测试验证邮件 |
| **V08** | 邮件测试失败反馈 | 输入错误的端口或授权码并点击测试 | 系统准确捕获 SMTP 握手或鉴权失败，弹出明确错误提示 |
