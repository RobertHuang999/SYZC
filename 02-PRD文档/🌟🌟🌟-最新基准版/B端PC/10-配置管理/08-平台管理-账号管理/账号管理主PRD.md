## 1. 业务背景与目标

维护登录账号、所属机构、角色与状态。

本页为 **只读查看与受控维护** 页面，不承接其他模块的业务审批；数据范围严格按账号的机构、仓库或数据权限过滤。

## 3. 页面功能说明

### 3.1 入口与骨架

1. **入口**：配置管理 → 平台管理 → 账号管理；
2. **筛选区**：4 项条件，提供【查询】【重置】；
3. **内容区**：列表，底栏统一分页（10 条/页）；
4. **状态**：无数据时展示业务空态，不显示报错。

### 3.4 操作与权限

- 权限清单登记的功能按钮：**查看(页面)、新增账号、编辑、停/启用、删除**；
- 数据可见范围：1、新增账号弹窗 - 所属机构：必填，单选，仅展示登录账号权限内的机构； / 2、新增账号弹窗 - 角色：必填，多选，仅展示登录账号权限内的角色； / 3、可见数据根据登录账号角色的数据权限决定；；
- 无权限的按钮不展示或置灰，具体以权限清单为准。

### 3.5 交互规则

1. 【查询】按当前筛选重新加载；【重置】恢复默认条件（穿透锁定的参数不被清空）；
2. 列表/看板切换或翻页保留筛选；
3. 行操作点击后按目标页面权限校验，无权限给出明确提示；
4. 导出与下载类操作走异步任务，统一在导出记录中查看。

## 4. 典型场景

### 场景 1【按权限查看本模块数据】(S01)
业务人员进入「配置管理 → 平台管理 → 账号管理」，按时间与状态筛选后查看结果；越权数据不可见，导出得到的是权限内全量数据。

### 场景 2【发现异常并转下游处理】(S02)
在列表或看板发现异常记录，点击行操作跳到对应业务详情；本页不直接修改业务状态。
