## 口径说明

1. **机构类别 / 机构管理 / 角色管理 / 账号管理**：新增数据的可选机构、角色、权限范围只能是当前账号权限内的数据；
2. **流程配置**：模板保存产生新版本，发布前必须有有效任务节点；停用只影响新流程；
3. **产地区域管理**：可选仓库受账号仓库权限限制，导入导出走统一记录；
4. **删除保护**：被下游引用的配置一律阻断删除。
