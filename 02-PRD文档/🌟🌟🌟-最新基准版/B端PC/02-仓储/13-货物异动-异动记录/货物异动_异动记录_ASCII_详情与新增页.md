# 货物异动-异动记录 ASCII 详情与新增页规格

> **文档定位**：仓储 / 货物异动 / 异动记录模块（`P-CKG-013`）新增与详情交互界面的 ASCII 线框图及交互打点规格。
> 包含三大部分：
> 1. **新增异动存货明细选择弹窗**（`P-CKG-013-SELECT`，过滤并选择普通存货）；
> 2. **异动申请发起页**（`P-CKG-013-APPLY`，表单填写与差额试算）；
> 3. **异动详情多卡片聚合弹窗**（`P-CKG-013-DETAIL-MODAL`，一单多卡片纵向聚合与审批时间轴）。

### 1.2 关键交互与风控规格
1. **唤起方式**：在 `P-CKG-013` 列表页右上角点击【新增异动】按钮唤起本弹窗。
2. **风控红线拦截（R01）**：
   - 筛选区【入库类型】直接固化锁定为 `普通入库`，禁用下拉切换；
   - 后台强规则前置过滤：`status = 'IN_STOCK' AND in_type = 'NORMAL' AND available_qty > 0`；
   - 处于质押、抵押监管状态的货品，**严禁**在本弹窗中展现；严禁仓储端直接对在押资产调账。
3. **行操作跳转**：点击操作列【异动申请】（文本链接，采用系统主题色），弹窗关闭，前端路由携参（`stock_id`, `in_order_id`, `bar_code`）无缝跳转至 `P-CKG-013-APPLY` 异动申请发起页。

### 2.2 字段与交互规则规格
1. **基础信息区快照**：
   - 字段全量只读继承自源头入库单；
   - 【入库单号】右侧提供 `[查看 >]` 文本链接（采用系统主题色），点击在新标签页弹出入库单详情只读底单。
2. **存货数据溯源**：
   - 【期初堆放数量】：展示该批次货物入库验收时的法定初始数量，终身不可变；
   - 【可用数量】：当前账面实时动态可用数，作为本次调账计算的基础；
   - 【异动前剩余可用数量】：右上角右对齐展示，与当前可用数量一致。
3. **异动表单输入与动态试算（R04）**：
   - **异动后可用数量**：必填数字输入框，**严格校验 $>0$**。若用户输入 $\le 0$，红字阻断报错：`异动后数量必须大于0`；
   - **实时动态试算反馈**：在输入框右侧即时回显：
     - 若 $\Delta Q > 0$：展示 `现存量 X单位 ⬆ 增量 Y单位`（红色箭头与数值）；
     - 若 $\Delta Q < 0$：展示 `现存量 X单位 ⬇ 减量 Y单位`（绿色箭头与数值）；
     - 若 $\Delta Q = 0$：阻断提交，提示 `异动后数量未发生改变，无需提交异动申请`。
   - **异动类型**：必选单选框组（`盘盈`、`盘亏`、`损耗`、`其他`）。
   - **异动原因**：文本域，最大限制 500 字，支持右下角 `0/500` 动态字数统计。
   - **附件上传**：最多上传 3 张图片（jpg/jpeg/png），单张 $\le 5\text{MB}$，支持上传进度条与缩略图删除。
4. **提交与审批联动**：
   - 点击【提交申请】：二次确认弹窗 `确认提交货物异动申请？`；
   - 确认后后端生成 19 位异动单号，物理货位状态切换为【异动申请中】，进入审批中心 `P07-05-04` 货物异动审核池；
   - 页面吐出成功 Toast 并自动重定向返回 `P-CKG-013` 列表页。

### 3.2 弹窗交互与结构细节打点

1. **弹窗布局与滚动机制**：
   - 弹窗采用居中模态框形式，最大宽度 `820px`，高度自适应，最大高度不超过屏幕 `85%`，超出时右侧展示平滑滚动条；
   - 右上角提供 `[X]` 关闭按钮，底部提供 `[关闭]` 按钮，支持 Esc 键与遮罩层点击快速关闭。
2. **多卡片纵向排布架构（一单多物）**：
   - 当一笔异动单包含多个货品记录时，弹窗**不对单据做拆分展示**，而是在同一个弹窗内按货品明细顺序纵向渲染多张独立卡片；
   - 每张卡片均独立展示：异动单号、单据类型标签徽标、货品名称、剩余数量带差额横幅、二维码生成时间、存放位置、变动前/后数量、变动类型、变动原因、附件缩略图及该货品所属申请信息。
3. **高亮数据横幅（剩余数量与差额）**：
   - 每张卡片顶部设有浅灰色底纹数据横幅，左侧标明 `剩余数量`；
   - 右侧主数量采用**系统主题橙色**加粗展示（如 `100.9873公斤`、`99斤`）；
   - 差额部分紧随主数量后方：
     - **盘盈 / 增量**：展示**红色加粗向上箭头 `⬆`** + 红色差异数量（如 `⬆ 98.3206公斤`）；
     - **盘亏 / 损耗 / 减量**：展示**绿色加粗向下箭头 `⬇`** + 绿色差异数量（如 `⬇ 1斤`）。
4. **二维码生成时间与展开控件**：
   - 展现该货位在系统内打印/激活存货条码的时间戳；
   - 右侧提供 `展开 v` / `收起 ^` 交互控件，点击可展开查看该二维码的具体批次编码、防伪哈希及绑定设备等扩展信息。
5. **原因与附件展示**：
   - **变动原因**：在灰色圆角长条框中回显。若未填写，规范展示【`--`】；若填写，完整展示说明文本；
   - **附件图片**：若发起时上传了图片，以等比缩略图展示；点击缩略图调用系统图片预览组件，支持放大、缩小、旋转与下载。
6. **审批记录与时间轴（底部聚合）**：
   - 单据末尾统一展示【审批记录】区块；
   - **流程名标牌**：带黄色链条图标 `🔗`，如 `总流程名：抵质押简总流程`、`流程名称：大数据流程`；
   - **时间轴节点**：纵向橙色/黄色圆点连线卡片；
   - 节点内容包含：节点名称（`申请提交`、`分配`、`任务`、`估值`）、操作时间戳、发起人/处理人名称及机构全称；
   - 审批环节卡片右下角提供 `任务详情 >` 文本链接（采用系统主题色），点击在新窗口打开工作中心该任务节点的审批快照。
