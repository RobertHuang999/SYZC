## 2. 交互细节与浮层线框

### 2.1 提货状态筛选下拉框展开态
```text
提货状态: [ 全部                    |v]
          +-------------------------+
          | 全部                    |
          | 已取消                  |
          | 未提货                  |
          | 已提货                  |
          +-------------------------+
```

### 2.2 企业提货人 Hover【更多】悬浮气泡（Popover）
当提货人类型为【企业】时，经办人后方带有 `经办人` 角色标识，鼠标悬浮至橙色文字 **【更多】** 时触发气泡浮层：

```text
| 客户纠纷(199****2233)经办人        |
|   [更多]                           |
        |
        | Hover 悬浮触发 Popover
        v
    +-------------------------------------------------+
    | 企业名称：放多个                                |
    | 企业标识：00898199NDJUT2CXJU                   |
    +-------------------------------------------------+
```

### 2.3 行操作按钮状态矩阵展示
1. **未提货状态**（全量操作高亮可用）：
   ```text
   查看详情    操作记录
   核销提货码  取消提货
   确认提货
   ```
2. **已提货 / 已取消状态**（履约动作置灰禁用）：
   ```text
   查看详情    操作记录
   [核销提货码] [取消提货]   <-- 浅灰色字体，禁行光标 (not-allowed)，不可点击
   [确认提货]                <-- 浅灰色字体，禁行光标 (not-allowed)，不可点击
   ```

## 3. 布局与响应式规范说明

1. **筛选区域规范**：
   - 筛选标签采用 `标签名: [输入框/下拉]` 格式，水平单行排列；
   - 筛选区右侧仅放置金色实心【查询】按钮，**无重置按钮**；
   - 提货状态默认显示“全部”。
2. **表格列宽自适应与断行策略**：
   - `序号`：固定宽度 60px，居中对齐；
   - `货主`：固定宽度 240px，企业名称较长时自动折行，展示统一信用代码；个人展示姓名及脱敏手机号；
   - `货物`：自适应宽度（约 260px~320px），支持多行排列展示（大类-品类-规格-数量）；
   - `提货人`：固定宽度 220px，个人单行展示；企业展示经办人及下方【更多】；
   - `出库类型`：固定宽度 100px，居中展示；
   - `状态`：固定宽度 80px，居中展示；
   - `操作人`：固定宽度 180px，展示发起出库申请的制单人及所属机构；
   - `时间`：固定宽度 160px，居中展示提货单生成时间；
   - `操作`：固定宽度 160px，多行文本按钮对齐排列。
3. **底栏分页规范**：
   - 左侧展示记录总条数 `共 515 条` 与分页下拉 `10条/页`（支持切换 20/50/100 条）；
   - 右侧展示翻页按钮 `< 1 2 3 ... 52 >` 与跳转输入框 `前往 [  ] 页`。
