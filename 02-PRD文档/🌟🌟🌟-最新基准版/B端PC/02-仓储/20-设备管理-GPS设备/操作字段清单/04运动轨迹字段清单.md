# GPS设备-运动轨迹字段清单

> **所属板块**：仓储 / 设备管理 / GPS设备  
> **文档定位**：GPS 历史运动轨迹查询、分段明细与地图渲染字段定义真源  
> **主数据引用**：[《GPS设备字段清单》](../GPS设备字段清单.md)  
> **业务规则规格**：遵循 [《GPS设备业务规则规格》](../GPS设备业务规则规格.md) 中的【运动轨迹31天时限强校验规则】(R02)、【轨迹详情结构化展现与里程核算规则】(R04)、【轨迹跨度超限阻断】(C01) 及【敏感隐私合规脱敏】(P02)  
> **版本**：V1.4 | **更新时间**：2026-09-16 | **责任人**：森云科技（Senyun Technology）

## 字段规格清单

| 字段名称 | 来源 | 控件与交互形态 | 必填性 | 字段规格与业务规则 |
| :--- | :--- | :--- | :---: | :--- |
| **设备编码** | 设备主数据 | 查询上下文（隐藏参数） | 是 | GPS 硬件 IMEI，作为调取历史轨迹时空数据库的唯一业务主键 |
| **设备信息** | 设备主数据/运力档案 | 轨迹面板顶部只读信息区 | 系统带出 | 回显设备系统内名称与车牌号；无车牌时展示“未绑定车辆” |
| **开始时间** | 用户选择 | 日期时间选择器 | 是 | 查询历史轨迹起始时间，格式为 `YYYY-MM-DD HH:mm:ss` |
| **结束时间** | 用户选择 | 日期时间选择器 | 是 | 查询历史轨迹截止时间，格式为 `YYYY-MM-DD HH:mm:ss` |
| **时间跨度校验** | 系统前端/服务端 | 强校验与红字提示 | 是 | 遵循【运动轨迹31天时限强校验规则】(R02) 与【轨迹跨度超限阻断】(C01)：$$\text{结束时间} - \text{开始时间} \le 31\text{ 天}$$。超出时阻断查询并浮窗提示：“*暂时只支持查询31天内的数据*” |
| **车牌号** | 运力档案 | 轨迹详情卡片粗体文本 | 有车牌时展示 | 承运车辆车牌号（如 `苏B·88998`） |
| **司机姓名** | 运力档案 | 轨迹详情卡片文本 | 有司机时展示 | 承运司机姓名（如 `张*强`） |
| **手机号** | 运力档案 | 轨迹详情卡片文本 | 有司机时展示 | 司机联系电话，严格掩码脱敏（如 `138****8888`），遵循【敏感隐私合规脱敏】(P02) |
| **总里程** | 历史轨迹数据核算 | 轨迹概览卡片数值 | 有轨迹时展示 | 本次查询区间车辆累计行驶总里程，单位千米（`km`），保留 1 位小数 |
| **开始地址** | GIS逆地理编码 | 轨迹概览卡片文本 | 有轨迹时展示 | 历史轨迹起点物理地址，解析失败展示经纬度或待解析占位 |
| **结束地址** | GIS逆地理编码 | 轨迹概览卡片文本 | 有轨迹时展示 | 历史轨迹终点物理地址，解析失败展示经纬度或待解析占位 |
| **状态分段列表** | 轨迹网关清洗聚合 | 分段折叠面板/数据卡片 | 有轨迹时展示 | 遵循【轨迹详情结构化展现与里程核算规则】(R04)，按行驶与停留状态切分区间，展示开始时间、结束时间、分段里程及分段停留时长 |
| **状态持续时长** | 轨迹网关/系统核算 | 分段卡片文本 | 有状态时展示 | 换算为“天-小时-分钟”格式（如 `45分钟`、`1天3小时`），天与小时为0时不展示0天0小时 |
| **轨迹地图** | GIS地图服务 | 全景轨迹地图图层 | 有轨迹时展示 | 绘制平滑运动折线，标注起点（绿）与终点（红），支持点击分段地图自动平移并高亮对应路段 |
| **查询状态** | 系统生成 | 页面状态占位/浮窗提示 | 是 | 状态包括：查询中、暂无轨迹数据、超限拦截警告、接口超时重试 |
