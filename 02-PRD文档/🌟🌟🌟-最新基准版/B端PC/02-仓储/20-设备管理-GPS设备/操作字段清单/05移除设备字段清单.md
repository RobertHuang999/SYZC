# GPS设备-移除设备字段清单

> **所属板块**：仓储 / 设备管理 / GPS设备  
> **文档定位**：GPS 设备报废或拆机移除操作字段及级联解绑规格真源  
> **主数据引用**：[《GPS设备字段清单》](../GPS设备字段清单.md)  
> **业务规则规格**：遵循 [《GPS设备业务规则规格》](../GPS设备业务规则规格.md) 中的【移除设备全链路解绑与强一致回滚规则】(R08)、【移除设备并发冲突阻断】(C03) 及【移除设备不可变历史快照审计规则】(R10)  
> **版本**：V1.4 | **更新时间**：2026-09-16 | **责任人**：森云科技（Senyun Technology）

## 字段规格清单

| 字段名称 | 来源 | 控件与交互形态 | 必填性 | 字段规格与业务规则 |
| :--- | :--- | :--- | :---: | :--- |
| **设备编码** | 设备主数据 | 模态弹窗上下文（隐藏参数） | 是 | GPS 硬件 IMEI，作为移除接口幂等主键 |
| **系统内名称** | 设备主数据 | 模态弹窗只读展示文本 | 系统带出 | 回显待移除的设备名称 |
| **车辆信息** | 设备主数据 | 模态弹窗只读展示文本 | 系统带出 | 回显当前关联车牌号（如 `苏B·88998`），提醒用户即将解除运力关联 |
| **移除说明** | 用户录入 | 多行文本输入框 | 是 | 强制录入本次移除原因（5~200 个字符），不允许空值或纯空白字符，遵循【移除设备全链路解绑与强一致回滚规则】(R08) |
| **级联解绑处理结果** | 核心业务引擎 | 系统执行与状态反馈 | 是 | 自动执行以下级联操作：<br>1. 解除与在押或监管订单绑定；<br>2. 注销相关风险与预警规则关联；<br>3. 清空通知规则接收配置；<br>4. 解除仓库/库房/分区空间绑定；<br>任一失败全量强一致事务回滚，设备保留有效 |
| **操作结果** | 系统生成 | 浮窗提示（Toast） | 是 | 移除成功提示“*设备已成功移除，关联已全量解绑*”；失败提示具体错误原因并保持原状态 |
| **历史存证快照** | 系统后台 | 不可变司法存证数据 | 是 | 设备移出有效列表，其历史运动轨迹、运力绑定记录与操作审计日志永久保留快照，遵循【移除设备不可变历史快照审计规则】(R10) |
