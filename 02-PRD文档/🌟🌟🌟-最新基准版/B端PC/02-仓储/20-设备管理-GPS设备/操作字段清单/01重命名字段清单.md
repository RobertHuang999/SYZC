## 字段规格清单

| 字段名称 | 来源 | 控件与交互形态 | 必填性 | 字段规格与业务规则 |
| :--- | :--- | :--- | :---: | :--- |
| **设备编码** | 设备主数据 | 隐藏请求参数（上下文） | 是 | GPS 设备硬件唯一识别码（IMEI），作为重命名接口幂等关联键，严禁使用列表行序号 |
| **原系统内名称** | 设备主数据 | 模态弹窗只读展示文本 | 系统带出 | 当前生效的设备名称，用于用户对照与变更前快照记录 |
| **系统内名称** | 用户录入 | 单行文本输入框 | 是 | 自定义设备别名；最多 50 个字符，不允许提交空值或纯空格；遵循【GPS设备命名继承与重命名保护规则】(R06)，保存后持久化锁定，三方同步不覆盖 |
| **操作结果** | 系统生成 | 浮窗提示（Toast） | 是 | 校验通过并保存成功提示“*设备重命名成功*”；失败弹出明确错误提示并保留原值，不产生部分更新 |
| **操作审计日志** | 系统生成 | 后台不可变存证 | 是 | 自动记录操作人、操作时间、客户端 IP、设备编码、重命名前后值及操作结果 |
