## 字段规格清单

| 字段名称 | 来源 | 控件与交互形态 | 必填性 | 字段规格与业务规则 |
| :--- | :--- | :--- | :---: | :--- |
| **设备编码** | 设备主数据 | 请求上下文（隐藏参数） | 是 | GPS 设备硬件唯一识别码（IMEI），作为调取第三方定位数据接口的业务主键 |
| **系统内名称** | 设备主数据 | 模态弹窗信息卡片文本 | 系统带出 | 当前生效的设备系统内名称 |
| **车牌号** | 运力/定位数据 | 地图标记与卡片粗体文本 | 有车牌时展示 | 承运车辆车牌号（如 `苏B·88998`），无绑定车辆时展示“未绑定” |
| **司机姓名** | 运力档案/定位返回 | 模态弹窗信息卡片文本 | 有司机时展示 | 承运司机姓名（如 `张*强`），脱敏规则遵循【敏感隐私合规脱敏】(P02) |
| **手机号码** | 运力档案/定位返回 | 模态弹窗信息卡片文本 | 有司机时展示 | 司机联系方式；严格执行掩码脱敏（前3后4中间4位 `*`，如 `138****8888`），遵循【敏感隐私合规脱敏】(P02) |
| **当前位置** | 第三方逆地理编码 | 地图标记与信息卡片文本 | 有定位时展示 | 经纬度逆解析街道门牌级真实地址，解析失败或无定位时展示“位置解析中”或“暂无可用定位”，禁止调用历史过期地址冒充 |
| **设备状态** | 第三方定位网关 | 彩色状态徽章 | 是 | 车辆定位客观运动状态（`离线`、`停车`、`行驶`、`静止`），遵循【设备状态客观展示与不设业务状态机规则】(R09) |
| **状态持续时长** | 定位网关/系统换算 | 模态弹窗信息卡片文本 | 有状态时展示 | 状态持续时间，统一换算为“天-小时-分钟”（如 `2小时15分钟`），天与小时为0时不展示0天0小时，无数据展示“--” |
| **更新时间** | 定位服务回传 | 模态弹窗信息卡片文本 | 是 | 定位帧最新上报时间戳，格式 `YYYY-MM-DD HH:mm:ss`，非设备主数据修改时间 |
| **地图定位标记** | GIS地图服务 | 居中模态弹窗地图图层 | 有定位时展示 | 地图正中渲染车辆定位图标，支持点击展开定位浮层卡片；底图异常时降级展示基础文本数据卡片 |
| **加载/异常状态** | 系统前端/第三方网关 | 页面状态浮窗/占位提示 | 是 | 区分展示“定位加载中”、“暂无有效定位”、“定位接口超时”等友好交互空态与错误状态 |
