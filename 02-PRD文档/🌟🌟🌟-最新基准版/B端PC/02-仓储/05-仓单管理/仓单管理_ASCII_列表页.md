## 3. 操作列微观规格（各状态 1:1 对比）

### 3.1 正常态（存货人与持有人一致 或 不一致）
```text
[ 详情 ]     [ 仓单补货 ]     [ 仓单出库 ]
[ 仓单入库 ] [ 仓单移库 ]
[ 仓单移除 ] [ 注销 ]         [ 下载 ]
```
* **特点**：
  * 存货人与持有人无论一致或不一致，8 个按钮全部高亮可用！
  * **移动端人脸识别强绑定机制**：所有涉及资产动碰的业务（补货、出库、入库、移库、移除、注销）均需法定主体进行活体人脸识别，因此在 PC 端点击上述按钮时，系统唤起【移动端人脸识别办理引导弹窗】（附带业务直达二维码），由经办人在手机端核验人脸并提交审批；移动端现场用户亦可直接在 **`工作台 → 仓单管理`** 中查看名下仓单并办理；
  * **流程并发防护**：受 `R-DWR-04` 单流程互斥锁保护。若该仓单已有在途审批，点击弹出 Toast：“您还有【${流程名称}】正在审批中，暂无法发起新的流程！”。

### 3.2 审批中 / 冻结 / 注销状态（严格按最新指令）
```text
[ 详情 ]     [ 下载 ]
```
* **特点**：严格仅保留【详情】与【下载】两个高亮文字链接。彻底屏蔽所有动碰类操作入口，确保金融质押资产司法合规。

## 5. 仓单出库全选货物强拦截弹窗（保底规则）

当用户在仓单出库勾选全部货物时，系统强行阻断操作并弹出模态提醒：

```text
+-------------------------------------------------------------+
|  提示                                                  [ X ]|
+-------------------------------------------------------------+
|                                                             |
|           /!\  仓单提货仅支持部分提取，若您需要提取         |
|                仓单内所有货物，请发起仓单注销流程！         |
|                                                             |
+-------------------------------------------------------------+
|                                                [ 我知道了 ] |
+-------------------------------------------------------------+
```
* **交互规格**：点击 `[ 我知道了 ]` 关闭弹窗，停留在当前选货页面，清空全选状态。

## 6. 仓单注销二次确认提示弹窗

当用户在仓单注销【重要提醒】页面点击【下一步】后，系统呼出模态确认弹窗：

```text
+-------------------------------------------------------------+
|  仓单注销确认                                          [ X ]|
+-------------------------------------------------------------+
|                                                             |
|           您是否仔细阅读重要提醒，且已知晓仓单注销后果！    |
|           若您已确认并仍需注销仓单，请点击继续！            |
|                                                             |
+-------------------------------------------------------------+
|                             [ 取 消 ]          [ 继 续 ]    |
+-------------------------------------------------------------+
```
* **交互规格**：
  * 点击 `[ 继 续 ]`：进入下一步进行【电子签章】（当事人活体人脸识别）；
  * 点击 `[ 取 消 ]`：中止操作，关闭弹窗并直接返回仓单管理列表页面。
