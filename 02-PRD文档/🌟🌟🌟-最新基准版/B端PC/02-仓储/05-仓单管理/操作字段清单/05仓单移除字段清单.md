# 仓单管理-仓单移除字段清单

> **所属板块**：仓单管理  
> **字段类型**：行操作资产解绑输入字段（解绑还原为普通库存）  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-04/R-DWR-09](../仓单管理业务规则规格.md) · [仓单管理主PRD·场景S04](../仓单管理主PRD.md#4-业务场景与用户故事)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **仓单编码** | 主数据 | 隐藏/顶部只读 | 系统带出 | 锁定待移除货物的目标仓单 |
| **拟移除货物批次** | 用户选择 | 货物卡片复选 | 是 | 勾选本次需要从仓单中解绑剔除的货物批次 |
| **移除模式** | 用户选择 | 单选 Pill | 是 | 枚举值：`整批移除`、`部分数量移除`（展开录入） |
| **本次移除数量** | 用户录入 | 数字输入框 | 条件必填 | 仅部分移除时录入；必须满足：$0 < \text{移除数量} \le \text{该批次在单数量}$ |
| **解绑后状态** | 系统规则 | 文本只读展示 | 系统固定 | **关键业务属性：固定为【存货中】（普通可用库存），不发生实体物理出库** |
| **移除原因** | 用户录入 | 多行文本框 | 选填 | 补充解绑剔除说明，最多 140 字 |

> **业务后置影响**：审批通过后，被移除的货物从该仓单中解绑剔除，物理库存状态由【仓单中】还原为【存货中】，恢复为自由可用库存；详情【变更记录】新增一条“货物移除”流水。
