# 仓单管理-仓单下载字段清单

> **所属板块**：仓单管理  
> **字段类型**：行操作存证文件下载与审计导出字段  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-05/R-DWR-09](../仓单管理业务规则规格.md)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **仓单编码** | 主数据 | 文件名/参数 | 系统带出 | 作为生成与下载 PDF 文件的唯一业务识别码（如 `CD20967...pdf`） |
| **文件类型** | 系统维护 | 下载选项/单选 | 是 | 枚举值：`电子仓单正本(PDF)`、`仓单变更确认单(PDF)` |
| **电子签章水印** | 系统生成 | PDF文件内嵌 | 系统生成 | 包含存货人电子签章、监管方签章、中仓登备案标语及防伪时间戳水印 |
| **防伪存证哈希** | 区块链/司法存证 | PDF底部文本 | 系统生成 | 展示 SHA-256 数据指纹，供司法鉴定与资方验真核验 |
| **下载操作人** | 系统记录 | 审计日志只读 | 系统生成 | 记录执行下载操作的登录人账号、所属机构及 IP 地址 |
| **下载时间** | 系统记录 | 审计日志只读 | 系统生成 | 记录下载请求发起的高精度系统时间戳 |

> **合规与审计**：在【正常】、【冻结】、【注销】、【审批中】四大状态下，以及详情页【变更记录】中，均提供合规的下载入口；每次下载操作必须完整记录审计日志，确保存证文件调阅可追溯。
