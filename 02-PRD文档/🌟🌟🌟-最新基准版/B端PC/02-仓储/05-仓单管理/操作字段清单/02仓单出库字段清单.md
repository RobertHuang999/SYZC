# 仓单管理-仓单出库字段清单

> **所属板块**：仓单管理  
> **字段类型**：行操作流转输入字段（两步式提货出库）  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md) · [出库记录字段清单](../../10-出库管理-出库记录/出库记录字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-04/R-DWR-07](../仓单管理业务规则规格.md) · [仓单管理主PRD·场景S02](../仓单管理主PRD.md#4-业务场景与用户故事)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **仓单编码** | 主数据 | 隐藏/顶部只读 | 系统带出 | 作为出库绑定的源单据索引，锁定关联关系 |
| **出库货物勾选** | 用户选择 | 货物卡片复选 | 是 | 平铺展示仓单内全量货物；**保底强校验：禁止勾选全部货物（必须至少剩下一组货物）** |
| **出库模式** | 用户选择 | 单选 Pill | 是 | 每个批次卡片内单选：`全部出库`（该批次全额）、`部分出库`（展开输入） |
| **本次出库数量** | 用户录入 | 数字输入框 | 条件必填 | 仅部分出库时展示；必须满足：$0 < \text{出库数量} \le \text{该批次仓单数量}$ |
| **提货人类型** | 用户选择 | 单选 Pill | 是 | 枚举值：`个人`、`企业`；控制身份证号/统一社会信用代码切换 |
| **提货人姓名** | 用户录入 | 文本输入框 | 是 | 1~30 字符；个人录入提货人姓名，企业录入公司名称 |
| **提货人身份证号** | 用户录入 | 文本输入框 | 条件必填 | 提货人为个人时必填；校验 18 位公民身份证号合法性，界面脱敏展示 |
| **提货人电话** | 用户录入 | 文本输入框 | 是 | 11 位手机号码；用于提货通知与现场核销校验 |
| **车牌号** | 用户录入 | 文本输入框 | 选填 | 现场运输车辆车牌号，格式如 `皖K·88888`；无车牌可留空 |
| **出库日期** | 用户选择 | 日期时间选择器 | 是 | 格式：`YYYY-MM-DD HH:mm:ss`；默认当前时间，不可选择晚于当前时间 |
| **备注** | 用户录入 | 多行文本框 | 选填 | 最多 140 字符；超出禁止输入；无内容入库时记录占位符 `--` |
| **现场照片** | 用户上传 | 图片上传控件 | 是 | 必填；最多上传 10 张；支持 `jpg`、`png`、`jpeg` 格式，单张不超过 5MB |

> **审计与异常**：勾选全部货物时强阻断并弹窗提示：“仓单提货仅支持部分提取，若您需要提取仓单内所有货物，请发起仓单注销流程！”；提交后进入出库审批流程，终审通过后自动核减仓单批次数量并生成提货单。
