# 仓单管理-仓单入库字段清单

> **所属板块**：仓单管理  
> **字段类型**：行操作入库流程联动参数字段  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md) · [入库记录字段清单](../../09-入库管理-入库记录/入库记录字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-10](../仓单管理业务规则规格.md) · [入库记录业务规则规格·R04](../09-入库管理-入库记录/入库记录业务规则规格.md)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **入库类型** | 系统带出 | 下拉单选（只读锁定） | 系统锁定 | **强约束：自动锁定并反显为 `仓单入库`，置灰不可修改** |
| **关联单号** | 主数据 | 文本输入（只读锁定） | 系统锁定 | **强约束：自动带出并锁定为当前仓单编号（如 `CD20967...`），置灰不可修改** |
| **货主主体** | 主数据 | 文本/下拉只读 | 系统带出 | 自动带出当前仓单的存货人主体信息与统一信用代码/标识 |
| **入库仓库** | 主数据 | 文本/下拉只读 | 系统带出 | 自动带出当前仓单所在的实体监管仓库，不可跨仓入库 |
| **入库库房/分区** | 用户选择 | 级联下拉 | 是 | 选择拟入库堆放的目标库房与物理分区 |
| **入库货物明细** | 用户录入 | 货品卡片与垛位分配 | 是 | 录入新增入库的货物大类、规格、数量及具体堆放垛位位置 |
| **现场照片与过磅** | 用户上传 | 图片上传控件 | 是 | 继承入库标准，上传入库过磅单与现场核对照片 |

> **业务流转与入账**：本操作由仓单列表行操作【仓单入库】触发跳转至入库发起；入库单据审批通过后，新增的物理批次自动并入该仓单名下台账，并写入仓单详情的【货物明细】与【变更记录】中。
