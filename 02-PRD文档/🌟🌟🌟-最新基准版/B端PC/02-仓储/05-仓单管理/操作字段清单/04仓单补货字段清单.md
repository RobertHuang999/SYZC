# 仓单管理-仓单补货字段清单

> **所属板块**：仓单管理  
> **字段类型**：行操作资产追加输入字段  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md) · [库存明细字段清单](../../03-库存查询-库存明细/库存明细字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-04/R-DWR-09](../仓单管理业务规则规格.md) · [仓单管理主PRD·场景S04](../仓单管理主PRD.md#4-业务场景与用户故事)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **仓单编码** | 主数据 | 隐藏/顶部只读 | 系统带出 | 锁定待追加资产的仓单业务编号 |
| **存货人主体** | 主数据 | 文本只读 | 系统带出 | 锁定可选库存归属货主，防止不同货主资产混淆 |
| **实体仓库** | 主数据 | 文本只读 | 系统带出 | 锁定可选库存所在仓库，必须在同仓库内补货 |
| **可选普通库存列表** | 库存系统 | 列表/弹窗勾选 | 是 | 动态过滤：`货主==当前存货人` 且 `仓库==当前仓库` 且 `状态=='存货中'` 且 `可用数量>0` |
| **批次存货条码** | 批次数据 | 二维码图标展示 | 系统带出 | 展示拟追加货物的唯一条码与物理垛位 |
| **本次补货数量** | 用户录入 | 数字输入框 | 是 | 必填；必须满足：$0 < \text{补货数量} \le \text{该批次普通可用数量}$ |
| **补货说明** | 用户录入 | 多行文本框 | 选填 | 补充资产追加原因，最多 140 字 |

> **业务后置影响**：审批通过后，被选中的普通物理库存状态由【存货中】原子转为【仓单中】，并入该仓单资产池，仓单总数量相应增加。
