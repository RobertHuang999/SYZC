# 仓单管理-仓单注销字段清单

> **所属板块**：仓单管理  
> **字段类型**：行操作终态作废流转字段（多重确认与电子签章）  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-04/R-DWR-11](../仓单管理业务规则规格.md) · [仓单管理主PRD·场景S05](../仓单管理主PRD.md#4-业务场景与用户故事)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **仓单编码** | 主数据 | 顶部只读展示 | 系统带出 | 锁定拟执行注销作废的仓单单号 |
| **重要提醒文案** | 系统配置 | 富文本只读区块 | 是 | 展示固定告知文案，详尽说明注销后仓单不可逆作废的法律后果 |
| **二次确认状态** | 用户操作 | 模态确认弹窗 | 是 | 弹窗：“您是否仔细阅读重要提醒，且已知晓仓单注销后果！若您已确认并仍需注销仓单，请点击继续！” |
| **注销签署协议号** | 系统生成 | 勾选框 + 文字链接 | 是 | 生成仓单注销确认书协议编号，强制勾选“已阅读并同意” |
| **人脸识别状态** | 第三方活体 | 活体核验图标/状态 | 是 | 必须由存货人/法定代表人通过活体人脸识别，确认真实意愿表达 |
| **注销原因** | 用户录入 | 多行文本输入框 | 选填 | 补充仓单注销事由（如：货物全部提货结案、合同到期作废等），最多 140 字 |
| **注销申请单号** | 系统生成 | 审批系统只读 | 系统生成 | 生成注销审批任务实例单号，推送到审批中心【仓单注销】流程池 |
| **注销时间** | 系统生成 | 日期时间只读 | 系统生成 | 审批通过后落库的时间戳，精确到秒，同步回显至仓单详情【注销时间】字段 |

> **效力终结机制**：注销流程审批通过后，该仓单状态置为【注销】，在系统中彻底变为不可用（不可在系统中被抵/质押、监管、融资申请、线索等任何业务发起时选中）；操作列仅保留【详情】与【下载】。
