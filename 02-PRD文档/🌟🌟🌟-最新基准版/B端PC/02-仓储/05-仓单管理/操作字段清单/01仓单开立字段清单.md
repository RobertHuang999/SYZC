# 仓单管理-仓单开立字段清单

> **所属板块**：仓单管理  
> **字段类型**：业务发起/新增开立输入字段  
> **操作入口**：PC 顶栏【仓单开立】（弹出扫码二维码） / 移动端【业务办理 → 业务发起 → 仓单开立】（`biz-init-receipt-issue`）  
> **台账查看**：移动端【工作台 → 仓单管理】（`ws-receipt-mgr`） / PC 端【仓储 → 仓单管理】  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-02/R-DWR-06](../仓单管理业务规则规格.md) · [仓单管理主PRD·场景S01](../仓单管理主PRD.md#4-业务场景与用户故事)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **PC引导二维码** | 系统生成 | 弹窗图形展示 | 是 | PC 端右上角【仓单开立】呼出；包含当前登录机构上下文，扫码直达移动端开立页 |
| **货主类型** | 用户录入 | 单选 Pill | 是 | 枚举值：`企业`、`个人`；切换时动态重置下方证件与名称项 |
| **货主名称** | 用户录入 | 模糊搜索下拉 | 是 | 个人为真实姓名，企业为公司全称；从已建档货主档案中选择或录入新货主 |
| **货主标识** | 系统带出 | 文本只读 | 系统带出 | 个人为脱敏手机号（如 `185****7112`），企业为统一社会信用代码 |
| **身份证号** | 系统带出/录入 | 文本输入/展示 | 条件必填 | 仅个人货主时必填；脱敏展示（如 `420101********6682`），用于活体核验比对 |
| **扣货方式** | 用户选择 | 单选 Pill | 是 | 枚举值：`先入先出`（FIFO，默认）、`自定义`；自定义模式激活排序工具与垛位输入 |
| **总开立数量** | 用户录入 | 数字输入框 + 快捷按钮 | 条件必填 | FIFO 模式下必填；附带【全部开立】按钮；必须大于 0 且小于等于仓库总可用量 |
| **批次开立数量** | 用户录入 | 数字输入框 | 条件必填 | 自定义模式下必填；针对具体垛位批次录入，强校验：$0 < \text{数量} \le \text{批次可用量}$ |
| **签约方式** | 系统固定 | 文本只读 | 是 | 固定取值：`线上`（系统内置权威电子签约通道） |
| **人脸识别状态** | 第三方活体 | 图标 + 状态文本 | 是 | 强制活体比对；未识别提示“请进行人脸识别”，识别成功更新为“人脸识别已完成 ✔” |
| **短信验证码** | 短信网关 | 6位数字输入框 + 按钮 | 是 | 人脸通过后动态唤出；点击【获取验证码】向货主标识手机发送，60s 防刷倒计时 |
| **电子仓单协议号** | 系统预生成 | 勾选框 + 文字链接 | 是 | 预生成 `CD + 19位` 编码协议；点击《CD...》唤起文本，强制勾选“已阅读并同意” |

> **审计与存证**：提交申请时，服务端记录操作人账号、时间戳、IP、活体人脸识别比对置信度分数、短信验证码验证流水及最终生成的唯一仓单编码，写入防伪存证日志。
