# 仓单管理-仓单移库字段清单

> **所属板块**：仓单管理  
> **字段类型**：行操作空间位置变更字段  
> **主数据引用**：[仓单管理字段清单](../仓单管理字段清单.md) · [库存明细字段清单](../../03-库存查询-库存明细/库存明细字段清单.md)  
> **流程规则**：[仓单管理业务规则规格·R-DWR-04/R-DWR-08](../仓单管理业务规则规格.md) · [仓单管理主PRD·场景S03](../仓单管理主PRD.md#4-业务场景与用户故事)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| **仓单编码** | 主数据 | 隐藏/顶部只读 | 系统带出 | 绑定源仓单单号，锁定本次移库归属 |
| **移库货物批次** | 用户选择 | 货物卡片复选 | 是 | 勾选本次拟调整物理存放位置的仓单货物明细（支持单选或多选） |
| **原存放位置** | 主数据 | 文本只读展示 | 系统带出 | 展示原库区空间：`仓库-库房-分区-具体位置` |
| **目标仓库** | 主数据 | 文本只读固定 | 系统带出 | **强约束：固定为当前仓单所在实体仓库，严禁跨仓库选择！** |
| **目标库房** | 用户选择 | 下拉选择器 | 是 | 选择同实体仓库内已启用的目标库房（展示审核/不审核标签） |
| **目标分区** | 用户选择 | 级联下拉选择器 | 是 | 选择目标库房下的有效物理分区标签 |
| **目标具体位置** | 用户选择 | 级联下拉/输入 | 条件必填 | 选择目标分区内的具体垛位编号；若目标分区未划分垛位则记录 `--` |
| **移库原因** | 用户录入 | 多行文本框 | 选填 | 补充移库作业事由，最多 140 字 |

> **并发与强约束**：受 `R-DWR-04` 单流程互斥锁保护；审批通过后原子更新底层库存明细的垛位指针，并在仓单详情的【变更记录】中生成移库记录流水。
