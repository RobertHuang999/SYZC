## 2. 状态大圆章（Stamp）设计规范

详情页头部右侧根据仓单当前状态悬挂实体圆形印章，强化视觉权威性与状态感知：

```text
       【审批中】                   【正常】                    【冻结】                    【注销】
      /-----------\               /-----------\               /-----------\               /-----------\
     /             \             /             \             /             \             /             \
    |    审 批 中   |           |    正   常    |           |    冻   结    |           |    注   销    |
     \  (金黄底色) /             \  (绿色底色)  /             \  (深灰底色) /             \  (深灰底色) /
      \-----------/               \-----------/               \-----------/               \-----------/
```

* **审批中**：土黄/金黄色背景（`#E6A23C`），白字，代表该仓单已被质押申请圈选锁定；
* **正常**：标准生态绿（`#67C23A`），白字，代表仓单资产有效且流转自由；
* **冻结**：深灰蓝（`#909399`），白字，代表处于质押生效锁定或司法查封状态；
* **注销**：中灰色（`#757575`），白字，代表仓单所载货物已完全出库结案或作废。

## 5. 微观交互规格

1. **单号一键复制**：
   * 点击顶部仓单编码旁边的 `[⎘ 复制]` 图标，自动写入系统剪贴板，界面浮现绿色 Toast 提示：`仓单编号已复制到剪贴板！`；
2. **手风琴折叠展开**：
   * 一级货品汇总行点击左侧展开箭头或行主体任意空白处，二级批次明细表格平滑下拉展开；再次点击收起；
   * 支持多货品行同时展开对比，展开状态在页面内保留；
3. **返回列表导航**：
   * 点击右上角 `[ 返 回 ]` 按钮，平滑返回 PC 端仓单管理列表页（`P-CKG-005`），并自动保留离开前的筛选搜索条件与分页页码。
