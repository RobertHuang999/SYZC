## 一、单据与能力定位

| 项目 | 内容 |
| :--- | :--- |
| **单据层级** | **【第2层-台账与执行流水层】**（仓储业务出入库合并台账 —— 统一单据流水监控中心） |
| **核心职责** | 以单据为视角，帮助用户快速根据查询条件掌握仓库业务动态。**本质上是将入库单据和出库单据进行合并归集展示的统一流水看板**。完整记录已生效出库与入库的事实发生时间、业务类型、关联单据、货主、数量及操作人员，打通双向单据追溯与凭证下载。 |
| **单据来源** | **入库与出库终态生效单据双轨归集**：<br/>1. **入库单据流**：入库审批通过并完成入库事务（普通入库、退货入库、质押/抵押/仓单入库、转让入库、移库入库及三类加工产出入库）；<br/>2. **出库单据流**：出库审批通过且现场提货核销出场完成（普通出库、质押/抵押/仓单出库、转让出库、移库出库及三类加工领料出库）。 |
| **上游依赖** | **入库管理 (P-CKG-009)**：提供全部终态为【已通过】的入库业务单据；<br/>**出库管理 (P-CKG-010)**：提供全部终态为【已出库/已核销】的出库业务单据；<br/>**存货管理 (P-CKG-001)**：接收宏观看板发起的【库存流水】穿透请求，根据触发来源分别锁定仓库、货物或货主主体。 |
| **下游影响** | **单据详情穿透**：根据业务单据性质，点击【详情】分别穿透至 `P-CKG-009-DETAIL`（入库详情）或 `P-CKG-010-DETAIL`（出库详情）；<br/>**金融审计与凭证管理**：提供正式带章 PDF 凭证下载及微观明细 Excel 下载，作为司法存证与企业财务核算底账。 |
| **数据边界准则** | **【已完成单据硬约束】**：本页面仅展示且只展示**已完成生效**的终态业务流水，处于申请中、审批中、已驳回或已撤销的流转中单据严禁进入本台账。 |

## 二、数量与金额核算口径隔离表

| 口径名称 | 存在位置 | 业务含义与计算公式 | 约束与边界条件 |
| :--- | :--- | :--- | :--- |
| **入库单据数** | 顶部汇总条 | 当前筛选范围内已完成生效的入库业务单据全局去重总笔数 $N_{\text{in}}$ | 整数 $\ge 0$；随筛选条件动态重算；如 `入库单届数285` |
| **入库发生总量** | 顶部汇总条 | 当前筛选范围内所有已完成入库单据中的货品入库数量绝对累加：<br/>$$Q_{\text{in\_sum}} = \sum Q_{\text{in}}$$ | 数值 $\ge 0$，4 位小数；忽略不同货品计量单位直接绝对累加；如 `入库数量17475069422.5493` |
| **出库单据数** | 顶部汇总条 | 当前筛选范围内已完成核销的出库业务单据全局去重总笔数 $N_{\text{out}}$ | 整数 $\ge 0$；随筛选条件动态重算；如 `出库单届数895` |
| **出库发生总量** | 顶部汇总条 | 当前筛选范围内所有已完成出库单据中的货品出库数量绝对累加：<br/>$$Q_{\text{out\_sum}} = \sum Q_{\text{out}}$$ | 数值 $\ge 0$，4 位小数；忽略不同货品计量单位直接绝对累加；如 `出库数量95233693.9771` |
| **数量 (单据发生量)** | 列表表格主列 | 该笔业务单据实际履约完成的货品总量绝对值 | 数值 $> 0$，4 位小数；千分位展示；不考虑单位直接呈现数量 |

## 五、业务规则明细 (Rule 01 ~ 18)

### 4.1 统一单据归集与终态准入规则 (R01 ~ R03)
* **R01【入库与出库单据合并模型】**：
  * 本模块将入库台账与出库台账在底层通过标准数据视图进行抽象合并；
  * 前台统一以 `业务单号`、`业务时间`、`业务类型`、`关联单据`、`数量` 等标准化表头呈现，实现进出存动态在同一屏幕上无缝流转呈现。
* **R02【终态单据准入硬隔离】**：
  * 列表只展示业务状态为终态的单据：
    * 入库单必须处于 **`已通过`（`APPROVED`）** 状态；
    * 出库单必须处于 **`已出库/已核销`** 状态；
  * 处于待审核、审批中、驳回或撤销的半成品单据一律被拦截在外，严禁污染业务流水。
* **R03【顶部动态汇总看板条】**：
  * 页面顶部常驻提示条，格式：`合计：入库单届数{N1} 入库数量{Q1} | 出库单届数{N2} 出库数量{Q2}`；
  * 当用户在下方筛选了业务单号、日期、货主、仓库、货品、类型或制单时间后，该汇总条必须**与列表数据保持 100% 同步重算**。

### 4.2 存货管理穿透联动与参数锁定规则 (R04 ~ R06)
* **R04【仓库视图穿透锁定】**：从《存货管理》（`P-CKG-001`）仓库 Tab 点击【库存流水】进入本页：
  1. 系统自动在 URL 注入参数 `?warehouse_id=xxx`；
  2. 筛选区【仓库名称】强制锁定为当前仓库且置灰只读，用户仅可下拉选择库房；
  3. 点击【重置】不解除仓库锁定。
* **R05【货物视图穿透锁定】**：从《存货管理》货物 Tab 点击【库存流水】进入本页：
  1. 系统自动注入 `?goods_id=xxx`；
  2. 筛选区【货品名称】强制锁定为当前货品且置灰只读，全生命周期聚焦该货品的出入动态。
* **R06【货主视图穿透锁定】**：从《存货管理》货主 Tab 点击【库存流水】进入本页：
  1. 系统自动注入 `?owner_id=xxx`；
  2. 筛选区【货主名称/标识】强制带入当前货主名称并置灰只读，完整跟踪该客户资产的进出全貌。

### 4.3 列表呈现、多维排序与超长控制规则 (R07 ~ R11)
* **R07【双列升降序排序机制】**：
  * **默认排序规则**：列表初始默认严格按 **【业务时间】倒序**（最新发生的单据排在最前）；
  * **用户自定义排序**：
    * 表头 **【业务时间 ▲▼】** 提供升降序切换；
    * 表头 **【制单时间 ▲▼】** 提供升降序切换；
    * 两列排序互斥，点击其中一列时另一列排序状态恢复默认。
* **R08【关联单据回显与空值占位】**：
  * 关联金融订单（质押/抵押）、电子仓单（`CD...`）、移库单、加工单或转让单的业务，此列完整反显上游单号；
  * 普通入库与普通出库属于无关联上游协议的自有货物流动，本列统一规范展示占位符【`——`】。
* **R09【货品与仓库多项超高折叠控制】**：
  * 当单笔业务单据包含多个货品（如一张入库单包含 5 种不同品类货物）或涉及多个库区时：
  * 表格单元格强制固定行高，多个货品以中划线与逗号拼接展示（如 `冻货-牛肉-36个月, 冻货-鸡...`）；
  * 鼠标 Hover 或点击单元格时，弹出黑色气泡浮层展示该单据涉及的**全量货品清单与规格列表**。
* **R10【货主与二元识别展示】**：
  * 企业货主：展示 `企业全称 (18位统一社会信用代码)`；
  * 个人货主：展示 `真实姓名 (脱敏手机号)`（中间 4 位星号）。
* **R11【数量绝对累加与精度】**：数量列不考虑各类货品计量单位差异（如个、斤、吨），直接按物理数值累加求和，统一格式化为 4 位小数。

### 4.4 行操作三重凭证与穿透追溯规则 (R12 ~ R14)
每行操作列均提供三个采用系统主题色的文字操作链接：
* **R12【行操作【详情】智能路由穿透】**：
  * 点击【详情】，系统根据该行单据属性执行**智能路由分流**：
    * 若该行为 **入库类单据**：在新标签页打开 `入库记录详情页`（`P-CKG-009-DETAIL`）；
    * 若该行为 **出库类单据**：在新标签页打开 `出库记录详情页`（`P-CKG-010-DETAIL`）；
  * 确保用户完整查阅原始审批流、入库/出库现场照片及 IoT 设备抓拍证据链。
* **R13【行操作【单据下载】带章凭证导出】**：
  * 点击【单据下载】，系统调用 PDF 生成服务，直接下载该笔出入库单据的标准版带章电子凭据（`.pdf` 文件），供资方存档或现场货车司机签收。
* **R14【行操作【下载记录】多库位堆放明细导出】**：
  * 点击【下载记录】，系统下载该笔业务单据在底层细分到库房、分区、垛位的完整明细清单（`.xlsx` 格式），与入库/出库管理行操作能力强一致。

### 4.5 权限隔离与安全规范 (R15 ~ R18)
* **R15【RBAC 权限码矩阵】**：
  * `P-CKG-004:VIEW`：库存流水列表浏览权限；
  * `P-CKG-004:EXPORT_PDF`：单据下载（PDF）凭证导出权限；
  * `P-CKG-004:EXPORT_EXCEL`：下载记录（Excel）明细导出权限；
  * `P-CKG-009:DETAIL_VIEW` 与 `P-CKG-010:DETAIL_VIEW`：跨模块单据详情查看权限。
* **R16【数据范围仓库权限强隔离】**：基于当前登录用户的组织架构和分配的实体仓库权限，实时查询管辖范围内的数据，严禁越权返回未经授权仓库的流水记录。
* **R17【查询防抖机制】**：【查询】按钮在触发后置入 1 秒 Loading 状态，防止高频重复请求。
* **R18【重置保持穿透锁定】**：点击【重置】清空其他筛选项，但不解除由存货管理带来的参数锁定。

## 六、异常与边界处理 (C01 ~ C05)

| 异常编号 | 异常场景 | 系统判定与控制动作 | 前端反馈与提示 |
| :--- | :--- | :--- | :--- |
| **C01** | 业务日期起止倒置 | 筛选区选择 `开始日期 > 结束日期` | 失去焦点时自动修正结束日期为开始日期，Toast 提示：`开始时间不得晚于结束时间` |
| **C02** | 检索无匹配流水 | 当前组合条件下无任何符合条件的出入库记录 | 列表展示标准空态插画，文案提示：`暂无匹配的库存流水记录` |
| **C03** | 单据 PDF 生成中 | 刚完成出入库但后台电子章或 PDF 异步签章尚未合成 | 操作列【单据下载】置灰，点击提示：`单据凭证正在合成中，请稍候再试` |
| **C04** | 跨模块单据不存在 | 点击【详情】时源头入库或出库单据已物理归档或权限不足 | 页面提示：`抱歉，关联的源头业务单据不存在或您暂无查看权限` |
| **C05** | 超大导出并发拥堵 | 连续点击多行【下载记录】导致并发过大 | 前端阻断超量并发，Toast 提示：`下载任务已提交，请等待上一个文件下载完成` |
