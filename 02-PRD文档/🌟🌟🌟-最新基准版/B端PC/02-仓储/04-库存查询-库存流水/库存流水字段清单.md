# 库存流水字段清单

> **文档定位**：仓储 / 库存查询 / 库存流水模块（顶部出入库汇总条、筛选区、列表表格、凭证导出及单据穿透）所有字段的唯一定义来源。行操作与核算业务逻辑由 [库存流水业务规则规格.md](./库存流水业务规则规格.md) 唯一定义；下游需求文档、原型和关联模块按字段所属层级引用，不重复定义字段规则。
>
> **引用规则**：
> - 仓库与库区字段继承自仓库管理基础档案。
> - 货物名称与规格字段继承自货品管理基准配置。
> - 货主主体全称与二元识别码继承自货主管理主体档案。
> - 业务类型严格映射自入库管理（`P-CKG-009`）与出库管理（`P-CKG-010`）的终态业务分类。
>
> **修改原则**：字段定义变化只修改本文件，并同步更新版本和修订记录。严禁凭空创建数据。
>
> **版本**：V1.0 | **更新时间**：2026-09-08 | **责任人**：森云科技（Senyun Technology）
>
> **页面范围**：覆盖库存流水列表页（`P-CKG-004`）。本模块定位为**以单据为视角的出入库统一流水台账，本质上是将已完成的入库单据与出库单据进行合并归集展示的监控中心**。

## 0. 对象与字段层级说明

本文件根据库存流水业务全景，将字段划分为三大层级：
1. **页面顶部汇总与控制字段**：涵盖入库单据笔数、入库发生总量、出库单据笔数、出库发生总量四项全局动态流水指标。
2. **列表筛选区字段**：涵盖业务单号（精准匹配）、业务日期时间段、货主名称/标识、仓库级联多选、货品级联多选、业务类型（入库/出库双大类分组单选）及制单时间区间。
3. **列表表格业务字段**：以生效单据为主键，包含序号、业务单号、业务时间（支持排序）、业务类型、关联单据、货主（企业税号/个人脱敏手机号）、货物名称（超长折叠与Hover展开）、数量（绝对累加）、仓库、制单人、制单时间（支持排序）及三重操作（详情、单据下载、下载记录）。

## 四、业务类型分组枚举字典

> 库存流水业务类型采用两层分组结构，覆盖全系统所有生效出入库业务类别：

| 大类分组 | 业务类型名称 | 业务属性 | 触发与扣减机制说明 |
| :--- | :--- | :--- | :--- |
| **入库类** | **普通入库** | 主动制单入库 | 普通自有货物入库，无关联单号 |
| **入库类** | **退货入库** | 联动逆向入库 | 提货单取消提货确认后，自动联动退库分配库位入库 |
| **入库类** | **质押入库** | 金融关联入库 | 入库时绑定质押订单，货物入库后确权并计入质押清单 |
| **入库类** | **抵押入库** | 金融关联入库 | 入库时绑定抵押订单，货物入库后确权并计入抵押清单 |
| **入库类** | **仓单入库** | 仓单关联入库 | 关联标准仓单，入库后数量计入电子仓单 |
| **入库类** | **转让入库** | 货权联动入库 | 货物转让完成时，受让人侧系统自动联动生成入库流水 |
| **入库类** | **移库入库** | 调拨联动入库 | 移库单审核成功后，移入仓库系统自动生成移入流水 |
| **入库类** | **普通加工入库** | 加工产出入库 | 普通货物深加工登记产出时系统自动生成 |
| **入库类** | **质押加工入库** | 加工产出入库 | 质押货物深加工登记产出时自动生成，无缝继承质押货权 |
| **入库类** | **抵押加工入库** | 加工产出入库 | 抵押货物深加工登记产出时自动生成，无缝继承抵押货权 |
| **出库类** | **普通出库** | 主动制单出库 | 普通自有存货经出库审批并核销出场，扣减实物库存 |
| **出库类** | **质押出库** | 金融解除出库 | 关联质押订单发起解押出库，核销后从质押清单扣除 |
| **出库类** | **抵押出库** | 金融解除出库 | 关联抵押订单发起解押出库，核销后从抵押清单扣除 |
| **出库类** | **仓单出库** | 仓单核销出库 | 关联电子仓单提货出库，核销后从仓单有效量扣减 |
| **出库类** | **转让出库** | 货权联动出库 | 货物转让完成时，出让人侧系统自动联动生成出库流水 |
| **出库类** | **移库出库** | 调拨联动出库 | 移库单审核成功后，移出仓库系统自动生成调拨出库流水 |
| **出库类** | **普通加工出库** | 生产领料出库 | 普通存货领料进入车间加工，系统自动生成领料出库 |
| **出库类** | **质押加工出库** | 生产领料出库 | 质押货物领料进入车间加工，系统自动生成领料出库 |
| **出库类** | **抵押加工出库** | 生产领料出库 | 抵押货物领料进入车间加工，系统自动生成领料出库 |

## 五、展示、筛选与引用规则

- **列表展示顺序与默认排序**：
  - 列表业务字段展示顺序固定为：`序号`、`业务单号`、`业务时间`（带排序 `▲▼`）、`业务类型`、`关联单据`、`货主`（双元标识）、`货物名称`（多物截断 Hover 气泡展开）、`数量`（千分位）、`仓库`、`制单人`、`制单时间`（带排序 `▲▼`）、`操作`（详情、单据下载、下载记录）；
  - 默认按 `业务时间` 倒序排列（最新业务发生单据排在最前）；支持按业务时间与制单时间双列单列升降序排序。
- **筛选字段与映射关系**：
  - 筛选字段：业务单号（模糊/精确）、业务日期（日期区间）、货主名称/标识（综合输入）、业务类型（两层分组单选下拉：入库类 10 项 / 出库类 9 项）、仓库名称（下拉单选）、货物名称（树形下拉）、制单时间（日期区间）；
  - 顶部常驻动态汇总看板条，随当前筛选条件实时同步重算。
- **敏感信息脱敏规则**：
  - 个人货主手机号码在列表展示时统一隐藏中间 4 位（展示如 `133****0005`）；
  - 统一社会信用代码超长时缩略展示。
- **空值与占位符规范**：
  - 普通入库与普通出库无关联单据时，关联单据列统一展示占位符【`——`】；
  - 仓库或货物信息不全时统一展示【`--`】；避免空白引起歧义。
- **字段引用与接口边界**：
  - 业务单号为入库单号（19位）或出库单号（19位）；
  - 行操作【详情】根据入库或出库类型智能路由打开 `P-CKG-009-DETAIL` 或 `P-CKG-010-DETAIL`；
  - 行操作【单据下载】调取带章 PDF 凭证下载接口；【下载记录】调取多库位明细 Excel 下载接口。
