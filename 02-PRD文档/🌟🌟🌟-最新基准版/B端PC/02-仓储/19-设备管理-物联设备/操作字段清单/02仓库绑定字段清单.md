# 物联设备-仓库绑定字段清单

> **所属板块**：物联设备
> **主数据引用**：[物联设备字段清单](../物联设备字段清单.md)
> **流程规则**：继承[监控设备仓库绑定字段清单](../../16-设备管理-监控设备/操作字段清单/02仓库绑定字段清单.md)及[监控设备主PRD·5.3](../../16-设备管理-监控设备/监控设备主PRD.md#53-仓库绑定)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 隐藏请求参数 | 是 | 使用设备编码作为幂等关联键 |
| 绑定仓库 | 用户选择 | 单选下拉框 | 选填 | 仅展示当前用户有权限的仓库 |
| 绑定库房 | 用户选择 | 多选下拉框 | 选填 | 必须归属于所选仓库 |
| 绑定分区 | 用户选择 | 多选下拉框 | 选填 | 必须归属于所选仓库和库房 |
| 具体位置 | 用户录入 | 文本输入框 | 选填 | 用于补充设备安装位置，最多50个字 |
| 操作结果 | 系统生成 | 消息提示 | 是 | 保存成功更新绑定；失败不得部分更新 |

保存前必须校验租户、机构、仓库数据权限、层级归属和数据版本。
