# 监控设备-查看回放字段清单

> **所属板块**：监控设备
> **字段类型**：行操作查询字段
> **流程规则**：[监控设备主PRD·5.5 查看回放](../监控设备主PRD.md#55-查看回放)

| 字段名称 | 来源 | 控件/展示 | 必填性 | 字段规则 |
| :--- | :--- | :--- | :--- | :--- |
| 设备编码 | 主数据 | 请求上下文 | 是 | 用于查询回放和关联预警 |
| 系统内名称 | 主数据 | 页面标题或设备标识 | 系统带出 | 展示当前设备名称 |
| 回放时间范围 | 用户选择 | 日期时间范围 | 是 | 按第三方回放接口支持范围校验 |
| 回放地址或播放句柄 | 第三方接口 | 视频播放器 | 接口返回 | 仅用于当前回放会话 |
| 预警时间 | 风险模块 | 预警列表 | 有预警时展示 | 展示预警产生时间 |
| 预警类型 | 风险模块 | 预警列表 | 有预警时展示 | 展示命中的图像识别类型 |
| 预警描述 | 风险模块 | 预警列表 | 有预警时展示 | 展示预警具体描述 |
| 预警处理结果 | 风险模块 | 预警详情 | 已处理时展示 | 展示处理人、解除时间、情况说明和现场照片 |
| 异常信息 | 系统/第三方 | 错误提示 | 异常时展示 | 直播、回放接口异常统一提示 |

预警处理由风险模块负责，本操作只读展示，不提供处理或解除入口。
