# 存货管理主PRD

> **模块定位**：仓储资产实时监控与核算中枢，统领全平台物理库存的宏观全貌、微观分布与动态货值。提供“仓库-货物-货主”三重视图切换，把控可用库存与审批流转冻结库存的精准动态平衡，无缝穿透联动至多级库存明细与履约流水，打通“实物存货-监管权属-金融风控”的数据闭环。  
> **版本**：V1.0 | **更新时间**：2026-09-07 | **责任人**：森云科技（Senyun Technology）  
> **编写依据**：[存货管理字段清单.md](./存货管理字段清单.md) 是本模块所有字段定义、枚举与页面展示的唯一基准；[存货管理业务规则规格.md](./存货管理业务规则规格.md) 是本模块状态机、核算恒等式、穿透锁定机制及异步导出的唯一定义来源；[存货管理_ASCII_列表页.md](./存货管理_ASCII_列表页.md) 是界面交互与布局的基准来源。

## 1. 业务背景与业务痛点

### 1.1 业务背景
在供应链金融存货质押与第三方监管体系中，资产的物理在库状态时刻处于高频流转之中（入库验收、质押申请、移库调拨、深加工、部分解押出库等）。商业银行、保理商、监管企业及核心企业急需一个**准实时、高透明、穿透式**的资产全局看板，以秒级掌握当前全仓实际货值、各仓库实际吞吐饱和度、特定大宗商品分布以及融资主体的抵质押余量。

### 1.2 核心业务痛点
1. **可用与流转混淆，引发超卖与超额质押风险**：传统 WMS 仅体现物理账面库存，无法与金融审批流打通。若货物正处于质押申请中或出库审批中，若不将该部分数量即时冻结，容易造成“一货两抵”或“已锁货仍被误出库”的重大合规事故；
2. **多方视角割裂，协同成本高昂**：
   * 现场仓库主管关注**物理仓库**的库容与出入库动态；
   * 风控与交易专员关注**具体货品规格**的单价估值与市场风险；
   * 客户经理与资金方关注**授信客户（货主）**名下的净资产与履约能力。单一维度的报表无法满足多角色协同需求；
3. **未定价大宗商品引发资产虚高隐患**：现货贸易中常存在暂定价或待点价结算货品，若粗暴赋 0 或按历史价盲目汇总，会导致资产总值失真；
4. **统计区间与系统录入时差脱节**：仓管员线下填单与系统录入往往存在时间差，若系统按照“制单时间”统计，将严重扭曲特定业务周期内的真实进出存业绩；
5. **上下游分析链条割裂**：用户在宏观汇总表发现异常后，往往需要手动跳出到明细表重新输入仓库、货品、货主进行搜索，缺乏上下文自动锁定的穿透追溯体验。

## 2. 功能范围 (Scope)

| 包含功能 (In Scope) | 不包含功能 (Out of Scope) |
| :--- | :--- |
| - **三重视图灵活切换**：支持【仓库视图】、【货物视图】、【货主视图】独立切换，自适应渲染专属表头与筛选项；<br/>- **顶部多维指标实时动态重算**：总价（含浅蓝 ¥ 水印）、货品种类数、仓库数量、货主数量（货主视图前置），严格随当前所选主体与业务时间动态联动；<br/>- **未定价商品智能感知与预警**：未定价商品展示 `--`，顶部总价自动点亮黄色叹号 `(!)`，Tooltip 提示“当前存在未定价货物”；<br/>- **数量守恒与冻结划分**：实时践行 $\text{库存总数} = \text{可用数量} + \text{冻结数量}$，10 类审批流转中单据全额切入冻结池，高亮警示展示；<br/>- **单据业务时间基准核算**：按填写的业务发生时间精准统计本期入库总量与本期出库总量，仅纳入终态有效单据；<br/>- **智能穿透与上下文锁定**：<br/>  1. 点击【库存分布】跳转 `03-库存明细`（`P-CKG-003`），按触发来源分别只读锁定仓库、货物或货主；<br/>  2. 点击【库存流水】跳转 `04-库存流水`（`P-CKG-004`），按触发来源只读锁定上下文；<br/>- **仓库画像悬浮感知**：鼠标 Hover 仓库名称即时展示仓库类型、管理方及详细地理位置；<br/>- **货主二元核验与隐私脱敏**：企业货主识别 18 位社会信用代码，个人货主降级展示脱敏手机号，联系方式全量中间 4 位星号脱敏；<br/>- **双轨导出体系**：<br/>  1. 【批量导出】：异步生成当前视图维度的 Excel 统计报表；<br/>  2. 【导出记录】：弹窗查看历史导出文件并提供安全下载。 | - **页面直接录入或修改**：本看板为全只读分析平台，不提供新增、编辑、删除等物理写操作（写操作由入库、出库、移库等单据模块驱动）；<br/>- **草稿箱与暂存机制**：不支持草稿状态；<br/>- **负库存支持**：严禁出现可用数量或库存总数小于 0 的违规数据；<br/>- **跨租户越权查询**：严禁突破当前机构的数据安全边界。 |

## 6. 页面交互规格索引

本模块在 PC 端通过 Tab 切换展示三大标准视图及一个独立弹窗，界面线框详见 [存货管理_ASCII_列表页.md](./存货管理_ASCII_列表页.md)：

### 6.1 存货管理 — 仓库视图（`Tab 1`）
* **定位与入口**：`仓储 / 库存查询 / 存货管理`（默认激活）；
* **顶部指标**：总价卡片（含叹号）、货品种类(个)、仓库数量(个)；
* **核心交互**：仓库名称 Hover 气泡画像；表头问号提示；行操作【库存分布】与【库存流水】跳转并锁定当前仓库。

### 6.2 存货管理 — 货物视图（`Tab 2`）
* **定位与入口**：点击【货物】Tab；
* **顶部指标**：扩充展示【货主数量(位)】第 4 张卡片；
* **核心交互**：单价与计量单位成对展示；未定价商品展示 `--`；行操作跳转并锁定当前货品。

### 6.3 存货管理 — 货主视图（`Tab 3`）
* **定位与入口**：点击【货主】Tab；
* **顶部指标**：【货主数量(位)】前置至第 2 位；
* **核心交互**：企业 18 位信用代码与个人脱敏手机号二元展示；冻结数量大于 0 醒目高亮；行操作跳转并锁定当前货主。

### 6.4 导出记录 — 异步历史弹窗（`Modal`）
* **定位与入口**：点击页面右上角【导出记录】按钮呼出居中弹窗；
* **核心交互**：展示历史生成的报表列表；状态为【成功】时提供私有 OSS 鉴权下载直链。

## 7. 四维一体验收标准

### 7.1 功能与交互完整性
- [ ] 页面在切换【仓库】、【货物】、【货主】Tab 时，筛选项与表格列必须即时刷新且排布严密，无闪烁与空白列；
- [ ] 顶部指标卡片必须根据当前所选维度与【业务时间】重新拉取接口并动态计算；
- [ ] 存在未定价商品时，总价卡片黄色感叹号 `(!)` 准确点亮，点击或悬浮均能正确提示“当前存在未定价货物”。

### 7.2 计算与守恒准确性
- [ ] 严格满足各行 $\text{库存总数} = \text{可用数量} + \text{冻结数量}$；
- [ ] 未定价货物总价必须展示 `--`，不得显示为 `0` 或空文本；
- [ ] 本期入库与出库总量必须严格匹配填报的单据业务时间，与系统录单操作时间完全脱钩。

### 7.3 穿透联动与参数锁定
- [ ] 从仓库 Tab 点击【库存分布】，进入 `P-CKG-003` 时必须锁定当前仓库且仓库选择器置灰，仅允许操作员进一步选择库房和分区；
- [ ] 从货物 Tab 点击【库存分布】，进入 `P-CKG-003` 时必须锁定当前货品；
- [ ] 从货主 Tab 点击【库存分布】，进入 `P-CKG-003` 时必须锁定当前货主；
- [ ] 【库存流水】的跳转穿透严格执行相同维度的上下文参数锁定。

### 7.4 导出安全与数据隔离
- [ ] 点击【批量导出】能成功向后台投递导出作业，并在【导出记录】弹窗中即时生成一条“处理中”记录；
- [ ] 任务执行完成后状态更新为“成功”，点击【下载】可成功调起 Excel 下载且文件命名规范；
- [ ] 数据严格按照当前登录用户的租户及仓库管辖权限进行数据隔离，禁止越权透传数据。
