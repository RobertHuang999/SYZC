## 一、单据与能力定位

| 项目 | 内容 |
| :--- | :--- |
| **单据层级** | **【第3层-台账与中枢监控层】**（仓储资产全局管控中枢 —— 存货与资产核算中枢） |
| **核心职责** | 实时汇总纳管全平台监管实体仓库的在库存货全貌，实现“仓库-货物-货主”三重视图切换，严格平衡“可用数量 + 审批冻结数量 = 库存总数”的守恒关系；动态监控未定价货物并预警；提供穿透至微观明细/流水的上下文锁定能力；支持报表异步批量生成与历史下载。 |
| **数据来源** | **底层单据全生命周期原子事件驱动**：<br/>1. **入库驱动**：入库单审核通过归档，即时计入在库实物库存与可用数量；<br/>2. **出库驱动**：出库单发起审批，申报数量全额切入冻结池；出库核销出场后，扣减实物总库存与冻结池；<br/>3. **质押/抵押/监管/仓单/转让/加工/异动驱动**：各类流转单据在发起审批中时产生冻结数量，审批通过后更新对应权属或状态。 |
| **上游依赖** | **仓库档案**：提供实体仓库、库房、管理方、类型及地址等物理主档；<br/>**货品主档**：提供货品三段式名称（大类-品类-规格）、法定单位及基准核算单价；<br/>**货主档案**：提供企业统一社会信用代码、个人姓名、身份证号及脱敏联系方式；<br/>**仓储与风控单据流**：入库单、出库单、移库单、质押单、抵押单、仓单、加工单、转让单。 |
| **下游影响** | **库存明细 (P-CKG-003)**：行操作【库存分布】反向携带仓库/货物/货主上下文只读穿透；<br/>**库存流水 (P-CKG-004)**：行操作【库存流水】携带主体参数穿透查看全息流水日志；<br/>**风控与监管中心**：为贷前资产评估、贷中跌价预警、质押率试算及司法合规审计提供不可篡改的数据真源。 |
| **台账业务边界** | **【只读监控与分析】**：本模块为纯粹的只读聚合看板与异步导出平台，不支持前台新增、编辑或作废操作；数据状态变迁完全由各业务单据审批流驱动。 |

## 二、数量与金额核算口径隔离表

| 口径名称 | 存在位置 | 业务含义与计算公式 | 约束与边界条件 |
| :--- | :--- | :--- | :--- |
| **库存总数** | 三重视图列表主列 | 该实体/货品/货主在监管库区内的实际物理存货总量：<br/>$$Q_{\text{total}} = Q_{\text{available}} + Q_{\text{frozen}}$$ | 数值 $\ge 0$，4 位小数；纯数字呈现，不带单位。表头带 `?` 提示：`库内所有库存，包含可用库存+业务冻结库存，不包含已出库待提货的` |
| **可用数量** | 三重视图列表主列 | 当前未处于任何单据申请审批流程中、可自由支配调拨的净额存货：<br/>$$Q_{\text{available}} = Q_{\text{total}} - Q_{\text{frozen}}$$ | 数值 $\ge 0$，4 位小数；不带单位。严禁出现可用数量小于 0 的超卖或超抵异常 |
| **冻结数量** | 三重视图列表主列 | 处于出库、移库、质押、抵押、仓单、转让、异动、加工等流转审批中被锁定的存货数量：<br/>$$Q_{\text{frozen}} = \sum Q_{\text{applying}}$$ | 数值 $\ge 0$，4 位小数；为 0 时正常显示，大于 0 时前台强制采用醒目高亮警示色显示 |
| **单价** | 货物视图列表列 | 货品基准核算价格（万元/法定单位） | 仅在【货物】Tab 独立呈现；未定价商品展示占位符 `--` |
| **总价(万)** | 顶部卡片 / 列表对应列 | 基于货品单价与对应数量加权求和的货值估值：<br/>$$\text{总价} = \sum (\text{单价}_i \times Q_i)$$ | 满足恒等式：$\text{库存总价} = \text{可用总价} + \text{冻结总价}$；无单价商品展示 `--` 且不计入总价；若存在未定价货物，顶部卡片点亮黄色叹号 `(!)` 提示“当前存在未定价货物” |
| **本期入库总量** | 三重视图列表列 | 所选【业务时间】区间内已完成生效的入库单总量累计：<br/>$$Q_{\text{in}} = \sum Q_{\text{in\_approved}}$$ | 仅统计单据填写的业务发生时间，排除系统制单时间；仅统计终态为已通过的入库单 |
| **本期出库总量** | 三重视图列表列 | 所选【业务时间】区间内已完成出场核销的出库单总量累计：<br/>$$Q_{\text{out}} = \sum Q_{\text{out\_verified}}$$ | 仅统计单据填写的业务发生时间；仅统计终态为已核销出库单，排除审批中单据 |

## 三、存货状态机与冻结映射矩阵

### 3.1 状态定义与数量归属矩阵
系统基于 18 项状态驱动底层资产流向，各状态与可用/冻结池的归属划分如下：

| 状态名称 | 状态编码 (`Enum`) | 状态类别 | 可用数量归属 | 冻结数量归属 | 计入库存总数 | 业务触发与流转说明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| **存货中** | `IN_STOCK` | 基准在库态 | ✅ 是 | ⚠️ 锁定转出 | ✅ 计入 | 合并原【已入库未分配二维码】与【已入库】；日常存放为可用，发起流转时锁定 |
| **质押申请中** | `PLEDGE_APPLY` | 审批流转态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 质押业务申请审批中，对应货品全额锁定为冻结 |
| **质押中** | `PLEDGING` | 质押生效态 | ✅ 在押可用 | ⚠️ 锁定转出 | ✅ 计入 | 质押合同生效；若从质押中发起质押出库申请，被申领部分产生冻结数量 |
| **抵押申请中** | `MORT_APPLY` | 审批流转态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 抵押业务申请审批中，对应货品全额锁定为冻结 |
| **抵押中** | `MORTGAGING` | 抵押生效态 | ✅ 在押可用 | ⚠️ 锁定转出 | ✅ 计入 | 抵押合同生效；抵押出库申请时产生冻结数量 |
| **监管申请中** | `SUPERV_APPLY` | 审批流转态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 第三方委托监管申请审批中，全额计入冻结 |
| **监管中** | `SUPERVISING` | 监管生效态 | ✅ 在管可用 | ⚠️ 锁定转出 | ✅ 计入 | 监管协议生效；发起监管出库/调拨时产生冻结 |
| **移库申请中** | `TRANSFER_APPLY` | 审批流转态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 移库单审核流转中，移出方待调拨数量全额锁定为冻结 |
| **出库申请中** | `OUT_APPLY` | 审批流转态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 出库单审核流转中，申报出库数量全额锁定为冻结 |
| **仓单申请中** | `RECEIPT_APPLY` | 审批流转态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 申请签发电子仓单流转中，标的存货全额锁定为冻结 |
| **仓单中** | `RECEIPT_ACTIVE` | 仓单生效态 | ✅ 仓单可用 | ⚠️ 锁定转出 | ✅ 计入 | 电子仓单生效存续中；仓单质押或仓单出库审批时产生冻结 |
| **平仓申请中** | `LIQ_APPLY` | 风控清收态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 触及平仓线风控处置流转中，全额锁定为冻结 |
| **平仓中** | `LIQUIDATING` | 风控清收态 | ✅ 清收可用 | ⚠️ 锁定转出 | ✅ 计入 | 平仓执行处置中；进入处置出库等流转环节产生冻结 |
| **转让申请中** | `ASSIGN_APPLY` | 审批流转态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 货物转让协议审批中，标的货物全额锁定为冻结 |
| **异动申请中** | `ANOMALY_APPLY` | 异常调整态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 存货损益、盘亏、破损等异动单据审批中，全额锁定为冻结 |
| **加工申请中** | `PROCESS_APPLY` | 生产加工态 | ❌ 0 | ✅ **100% 计入** | ✅ 计入 | 深加工单据申请审批中，待领料原料全额锁定为冻结 |
| **加工中** | `PROCESSING` | 生产加工态 | ✅ 在制可用 | ⚠️ 锁定转出 | ✅ 计入 | 加工单执行中；产出核销结算流转时产生冻结 |
| **已出库** | `OUT_COMPLETED` | 历史完结态 | ❌ 0 | ❌ 0 | ❌ **不计入** | 实物已出库完成且核销，不再计入在库实物库存总数 |
| **出库待核销** | `OUT_TO_VERIFY` | 废弃废止态 | - | - | ❌ **已废除** | **系统已废除该状态**，严禁产生任何数量记录 |

## 五、业务规则明细 (Rule 01 ~ 20)

### 4.1 数据守恒与未定价规则
* **R01【数量平衡恒等式】**：三重视图下每行数据必须满足 $\text{库存总数} = \text{可用数量} + \text{冻结数量}$。
* **R02【货值平衡恒等式】**：三重视图下每行数据必须满足 $\text{库存总价} = \text{可用总价} + \text{冻结总价}$。
* **R03【未定价商品占位】**：若货物未维护单价，单价列与对应总价列统一展示 `--`，不参与总价合计，严禁以 0 元干扰均价。
* **R04【未定价黄色叹号预警】**：当所选统计范围内存在至少 1 笔未定价存货时，顶部总价卡片右侧必须点亮黄色感叹号 `(!)`，点击或 Hover 展示 Tooltip：`当前存在未定价货物`。
* **R05【总价表头防歧义绑定】**：列表中 3 列同名的 `总价(万)` 分别与前一列强绑定：
  * 第 1 个 `总价(万)` $\rightarrow$ 对应【库存总数】；
  * 第 2 个 `总价(万)` $\rightarrow$ 对应【可用数量】；
  * 第 3 个 `总价(万)` $\rightarrow$ 对应【冻结数量】。

### 4.2 视图自适应与指标联动规则
* **R06【Tab 切换状态隔离】**：默认激活【仓库】Tab；切换 Tab 时，页面自适应调整首个筛选项、表头列及指标卡片。
* **R07【仓库视图卡片布局】**：展示 3 张卡片：`总价 (¥ 水印+叹号)` $\rightarrow$ `货品种类(个)` $\rightarrow$ `仓库数量(个)`。
* **R08【货物视图卡片布局】**：展示 4 张卡片：`总价` $\rightarrow$ `货品种类(个)` $\rightarrow$ `仓库数量(个)` $\rightarrow$ `货主数量(位)`。
* **R09【货主视图卡片布局】**：展示 4 张卡片，**权属前置**：`总价` $\rightarrow$ `货主数量(位) ⭐` $\rightarrow$ `货品种类(个)` $\rightarrow$ `仓库数量(个)`。
* **R10【指标实时联动重算】**：当用户在下方调整实体筛选（仓库/货物/货主）或【业务时间】并点击【查询】后，顶部指标卡片必须同步重新拉取计算。
* **R11【仓库名称 Hover 气泡】**：在仓库视图中鼠标悬停仓库名称，唤起黑底白色气泡，展示 `仓库类型`、`管理方` 及 `位置`；若仓库位置未在主档中维护，位置项统一展示为【`--`】。
* **R12【货主二元标识与脱敏】**：企业货主标识展示统一社会信用代码；个人货主标识展示脱敏手机号；所有联系方式统一执行中间 4 位星号脱敏（`1xx****xxxx`）。

### 4.3 业务时间与单据准入规则
* **R13【业务时间核算基准】**：出入库统计必须严格对齐单据填写的**实际业务发生时间（`business_date`）**，严禁使用系统制单时间（`created_at`）。
* **R14【终态单据统计闭环】**：【本期入库总量】仅统计终态为【已通过】的入库单；【本期出库总量】仅统计终态为【已核销】的出库单；处于审批流转中的单据不得计入。

### 4.4 穿透追溯与上下文锁定规则
* **R15【库存分布穿透锁定】**：点击行操作【库存分布】复用跳转至 `03-库存明细`（`P-CKG-003`）：
  * 来自【仓库 Tab】：锁定当前仓库（下拉框置灰只读），仅可选择库房与分区；
  * 来自【货物 Tab】：锁定当前货物（下拉框置灰只读）；
  * 来自【货主 Tab】：锁定当前货主（输入框置灰只读）。
* **R16【库存流水穿透锁定】**：点击行操作【库存流水】复用跳转至 `04-库存流水`（`P-CKG-004`），按触发来源分别锁定对应仓库、货物或货主主体。

### 4.5 异步导出与系统权限规则
* **R17【批量导出异步任务】**：点击右上角【批量导出】，读取当前 Tab 维度与筛选条件，提交后台生成报表任务，规范命名为 `库存统计-{Tab维度}-{YYYYMMDDHHmmss}.xlsx`。
* **R18【导出记录历史弹窗】**：点击右上角【导出记录】，居中呼出弹窗展示历史任务列表（序号、文件名、操作人、时间、状态、操作）；成功任务提供 OSS 安全下载。
* **R19【RBAC 权限码控制】**：
  * `P-CKG-001:VIEW`：页面访问权限；
  * `P-CKG-001:DIST_JUMP`：库存分布穿透权限；
  * `P-CKG-001:STREAM_JUMP`：库存流水穿透权限；
  * `P-CKG-001:BATCH_EXPORT`：批量导出触发权限；
  * `P-CKG-001:EXPORT_HIST`：导出记录查看与下载权限。
* **R20【租户与仓库数据隔离】**：数据严格按登录人员所属机构及被授权监管仓库进行圈定，严禁越权穿透。
