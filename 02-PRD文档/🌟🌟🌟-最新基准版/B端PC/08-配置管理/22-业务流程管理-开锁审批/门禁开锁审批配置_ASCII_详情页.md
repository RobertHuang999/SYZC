> **字段排版**：每个 `DetailField` 为**上 label、下 value** 纵向堆叠；分区内容区为 **4 列 CSS Grid**（≤1100px 降为 3 列）。**禁止** label 与 value 同一行左右并列。
> **条件字段**：适用库房/适用分区/适用设备/全局开关按适用范围类型显隐；本例为库房，不展示适用设备与全局开关。

## 布局说明

**页头识别区**（`rounded-xl border bg-card p-4`）：配置名称、状态标签；右侧动作按 [第五章 动作能力矩阵](../../../../B-迭代需求/6.2版本（2026.08）/06-门禁开锁审批/01-审批配置/门禁开锁审批配置业务规则规格.md#五动作能力矩阵) 显隐：

| 状态 | 页头动作 |
| :--- | :--- |
| 已启用 | 返回、编辑、停用 |
| 已停用 | 返回、启用 |

**内容分区**（`DetailSection` 卡片）：

| 分区 | 字段（按 grid 单元排列） |
| :--- | :--- |
| 基础识别与范围 | 配置编号、配置名称、适用范围类型、适用仓库；条件展示适用库房、适用分区、适用设备（可跨列 + 查看设备清单）、未绑定位置设备全局审批开关 |
| 审批策略 | 审批方式、审批超时时间、配置版本；审批节点表跨列（节点序号、审批对象类型、指定人员/指定角色） |
| 系统审计 | 状态、创建人/时间、更新人/时间；**已停用**追加停用原因 |

> **本期不展示**：Version（系统隐藏，仅编辑提交携带，R07）、操作审计日志（详情展示=否，完整留痕走后台 A01–A02）；下游在途申请列表（运行时匹配不在本模块页面处理）。
