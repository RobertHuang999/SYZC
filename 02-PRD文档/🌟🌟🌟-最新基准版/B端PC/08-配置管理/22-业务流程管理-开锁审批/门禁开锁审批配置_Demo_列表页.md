## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 开锁审批配置列表 |
| 页面目标 | 审批配置管理员筛选、查看开锁审批规则，并进入新增/编辑/详情 |
| 菜单路径 | `配置管理 → 业务流程管理 → 开锁审批` |
| 页面路径 | `/配置管理/业务流程管理/开锁审批` |
| 骨架结构 | 页头标题 + 筛选 Card（ConfigFilterHeader）+ 数据表格 + 分页 |
| 权限 | 列表 P01；新增 P02 子权限 |

> **无状态 Tab 栏**：配置状态通过筛选区「状态」下拉过滤，与 ASCII 线框一致。
> **无导出**；**已停用**行/详情提供逻辑删除（C08），已启用不提供删除。

## 2. 查询区

### 2.1 布局说明

筛选 Card 容器，顶部 `ConfigFilterHeader`：

- 左侧：`筛选条件`
- 右侧：`[展开筛选/收起筛选]` → `[重置]` → `[查询]` → `[ + 新增配置 ]`（P02 写权限；无权限隐藏）

**默认行**（2 列栅格）：配置名称、状态。

**展开行**（追加 1 行）：配置编号。

### 2.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 配置名称 | `Input` | 模糊匹配；placeholder：`请输入配置名称` |
| 状态 | `Select` | 全部（默认）/ 已启用 / 已停用 |
| 配置编号 | `Input` | 精确匹配；展开筛选展示 |

### 2.3 筛选交互

- 点击「查询」或 Enter：刷新列表，页码重置为 1
- 点击「重置」：恢复各筛选项默认值并刷新
- 切换筛选条件后须点击「查询」才刷新（非即时查询）

## 3. 表格

### 3.1 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 行勾选 | 不支持 |
| 列宽拖拽 | 支持 |
| 固定列 | 配置名称列左固定；操作列右固定 |
| 分页 | 默认 10 条/页，可选 10/20/50 |
| 默认排序 | 更新时间 DESC |
| 空状态 | 「暂无开锁审批配置」+ 「点击「+ 新增配置」创建」 |

### 3.2 列定义

| 列名 | 内容说明 | 宽度 | 固定 |
| :--- | :--- | :--- | :---: |
| 序号 | 当前页从 1 起 | 64px | |
| 配置编号 | 链接色，跳转详情页 | 140px | |
| 配置名称 | 链接色，跳转详情页 | 180px | 左固定 |
| 适用设备摘要 | 如 `已选 3 台` | 140px | |
| 审批方式 | 固定展示「任一人通过」 | 110px | |
| 审批超时 | 如 `24 小时` | 90px | |
| 配置版本 | 如 `v1`、`v3` | 90px | |
| 状态 | 状态 Tag | 90px | |
| 创建人/时间 | 合并一列；创建人格式「姓名（所属机构）」 | 140px | |
| 操作 | 行内文字操作 | 160px | 右固定 |

> **不展示列**：审批节点、Version、停用原因、操作审计日志。

### 3.3 状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 已启用 | 绿色 |
| 已停用 | 灰色 |

### 3.4 行内操作

**不渲染 disabled 操作**（无权限时整按钮隐藏）。

| 状态 | 展示的操作 |
| :--- | :--- |
| 已启用 | 编辑 / 详情 / 停用 |
| 已停用 | 详情 / 启用 / 删除 |

| 操作 | 行为 |
| :--- | :--- |
| 编辑 | 跳转编辑页（已停用 ❌） |
| 详情 | 跳转详情页 |
| 停用 | 二次确认弹窗 + 停用原因表单（见 §4） |
| 启用 | 二次确认 MessageBox；重跑 R01–R04、R27 |
| 删除 | 二次确认 MessageBox（destructive）；仅已停用；见 §4.3 |

## 4. 二次确认弹窗规格

### 4.1 停用

| 项目 | 规格 |
| :--- | :--- |
| 弹窗标题 | 确认停用 |
| 弹窗内容 | 停用后新申请不再命中本配置，在途申请不受影响，确认停用？ |
| 表单项 | **停用原因** `Textarea`，必填，≤200 字 |
| 确认按钮 | **确认停用** |
| 成功反馈 | Toast「停用成功」 |

### 4.2 启用

| 项目 | 规格 |
| :--- | :--- |
| 弹窗标题 | 确认启用 |
| 弹窗内容 | 启用后新申请将按本配置匹配，确认启用？ |
| 确认按钮 | **确认启用** |
| 成功反馈 | Toast「启用成功」 |

### 4.3 删除（逻辑）

| 项目 | 规格 |
| :--- | :--- |
| 可见条件 | **仅** `status=已停用` 的行操作与详情页头 |
| 弹窗标题 | 确认删除 |
| 弹窗内容 | 删除后列表将不再展示本配置，历史申请仍保留配置快照，确认删除？ |
| 确认按钮 | **确认删除**（destructive） |
| 成功反馈 | Toast「删除成功」；列表移除该配置 |
| 失败反馈 | Toast「删除失败：配置状态已变更」 |
