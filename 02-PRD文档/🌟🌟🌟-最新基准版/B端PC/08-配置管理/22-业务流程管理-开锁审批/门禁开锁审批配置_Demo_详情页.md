## 2. DetailSection 布局规范（⚠️ 生成必遵）

与 dev 共用组件 `@/shared/components/DetailSection` + `index.css`（对齐设备/订单预警配置详情）：

| 层级 | 实现 |
| :--- | :--- |
| 分区 | `DetailSection`：标题 + 内容区 Card |
| 内容区 | `detail-section-content`：**4 列 CSS Grid**（≤1100px → 3 列），`gap: 22px 28px` |
| 单字段 | `DetailField`：**label 在上、value 在下**（`flex-direction: column; gap: 6px`） |
| label 样式 | 13px、`#86909c`（`detail-field-label`） |
| value 样式 | 14px、`#1d2129`（`detail-field-value`） |

```text
┌─ DetailSection: 基础识别与范围 ───────────────────────────────────────┐
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   ← 4列 grid         │
│  │配置编号   │ │配置名称  │ │适用范围  │ │适用仓库  │                       │
│  │UNLOCK-… │ │华东一号…│ │库房      │ │华东一号仓│   ← 上名下达           │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘                       │
└────────────────────────────────────────────────────────────────────────┘
```

**禁止**：ElDescriptions 横向「左 label 右 value」、或 `el-form` 一行两列的表单行布局。

> **审批节点**：跨列只读表格，表头「节点序号 / 审批对象类型 / 指定人员或指定角色」。

## 3. 页头识别区

```text
{配置名称}   [ {状态Tag} ]          [ ← 返回 ]  [ 编辑 ]  [ 停用/启用 ]
```

容器：`rounded-xl border bg-card p-4`，`lg:flex-row` 左右布局。

### 3.1 页头操作（按状态）

| 状态 | 展示的操作 |
| :--- | :--- |
| 已启用 | 返回 / 编辑 / 停用 |
| 已停用 | 返回 / 启用 |

---

## 4. 基础识别与范围卡片（DetailSection）

| 字段 | 展示规格 | 条件 |
| :--- | :--- | :--- |
| 配置编号 | 如 `UNLOCK-CFG-001` | 始终 |
| 配置名称 | 文本 | 始终 |
| 适用范围类型 | 5 类枚举 | 始终 |
| 适用仓库 | 仓库名 | 仓库/库房/分区/指定设备 |
| 适用库房 | 多选摘要或 `—` | 库房/分区/指定设备 |
| 适用分区 | 多选摘要或 `—` | 分区/指定设备 |
| 适用设备 | 摘要 + `[查看设备清单 >]` 只读抽屉（可跨列） | 指定设备 |
| 未绑定位置设备全局审批开关 | 开启 / 关闭 | 未绑定位置全局 |

### 4.1 范围区差异示例

**指定设备**（UNLOCK-CFG-002）：适用设备 `已选 3 台 · LK-2024-0082 / LK-0085 / FACE-01`

**未绑定位置全局**（UNLOCK-CFG-003）：仅展示全局开关，不展示仓库/库房/分区/设备

## 5. 审批策略卡片（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| 审批方式 | 任一人通过 / 按顺序审批 |

## 6. 系统审计卡片（DetailSection）

| 字段 | 展示规格 |
| :--- | :--- |
| 状态 | 已启用 / 已停用 |
| 创建人 / 创建时间 | 创建人格式「姓名（所属机构）」；时间 `YYYY-MM-DD HH:mm:ss` |
| 更新人 / 更新时间 | 同上 |
| 停用原因 | 仅**已停用**展示；≤200 字 |

> **不展示**：Version（系统隐藏）、操作审计日志全量流水。
