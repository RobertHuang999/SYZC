## 1. 页面概述

| 项目 | 内容 |

## 2. 页头操作栏

| 按钮 | 规格 |
| :--- | :--- |
| 返回 / 取消 | 次操作；有未保存变更时确认「放弃未保存的修改？」 |
| 保存 | **主操作**；新增/编辑均二次确认后提交；**不提供**状态下拉 |

### 2.1 保存二次确认

| 场景 | 确认文案 | 确认按钮 |
| :--- | :--- | :--- |
| 新增 | 保存后新申请将按本配置匹配，确认保存？ | **确认保存** |
| 编辑 | 修改将生成新版本，在途申请继续使用旧版本快照，确认保存？ | **确认保存** |

> 启停仅在列表/详情独立动作；表单内不可改状态。编辑保存成功后旧版本→已停用，新版本→已启用，配置版本 +1（C05）。

## 3. 新增态 vs 编辑态差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 页头标题 | 新增开锁审批配置 | 编辑开锁审批配置 — {配置名称} |
| 配置名称 | 空，可填 | 预填，**Readonly**（R06） |
| 适用设备 | 可勾选/调整 | 预填，**Readonly**（R06）；调设备须停用旧配置并新增 |
| 审批节点 / 审批超时 | 空或默认 1 个空节点 | 读当前，可改 |
| 审批方式 | 不展示；系统默认任一人通过 | 不展示 |
| Version | 不展示 | **不展示**；随表单隐藏字段提交（R07） |
| 配置编号 / 配置版本 / 状态 | 不展示 | 不展示 |
| 保存后 | 已启用，配置版本=1 | 新版本已启用，旧版本已停用，配置版本+1 |
| 已停用配置 | — | **不可进入编辑**（动作矩阵） |

## 4. 基础识别与范围卡片

卡片标题：**基础识别与范围**。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 配置名称 | `Input` | 是 | ≤50 字，租户内唯一（R04a）；编辑 Readonly |
| 适用设备 | 摘要 + `[勾选/调整设备 >]` 按钮 | 是 | 新增态可编辑；编辑 Readonly；点击打开 `UnlockDeviceSelectDialog`；至少 1 台 |

### 4.1 设备选择弹窗（UnlockDeviceSelectDialog）

> **组件路径**：`components/UnlockDeviceSelectDialog.tsx`

| 能力 | 规格 |
| :--- | :--- |
| 仓库筛选 | 顶栏 `Select`：全部仓库 / 各在管仓库；**仅用于弹窗内定位设备，不作为配置范围** |
| 关键字搜索 | `Input` + 搜索图标：匹配设备名称、编码、绑定位置 |
| 列表 | 复选框列表；展示名称、编码 Badge、仓库·位置 |

## 5. 审批策略卡片

卡片标题：**审批策略**。

> **审批方式**：6.2 不展示选项，系统默认「任一人通过」；可在卡片顶部以灰字说明：「审批方式：任一人通过（任一名审批人通过即完成）」。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 审批节点 | 可编辑表格 + 拖拽 | 是 | 至少 1 个；见 §5.1 |
| 审批超时时间 | `TimeoutHoursInput` | 是 | 正整数；**「小时」内嵌于输入框右侧** |

### 5.1 审批节点子表

表格列：

| 列 | 控件 | 规格 |
| :--- | :--- | :--- |
| ≡ 拖拽 | 拖拽手柄 | 调整节点序号 |
| 节点序号 | 只读文本 | 从 1 递增，拖拽后重算 |
| 审批对象类型 | `Select` | 指定人员 / 指定角色；切换时清空对象 |
| 审批对象 | `SelectWithSearch` | 类型=人员：启用账号单选；类型=角色：启用角色单选 |
| 操作 | 删除 | 至少保留 1 行 |

底部：`[ + 添加审批节点 ]`

**校验（R27）**：同一节点不可混选人员与角色；不同节点可分别配置。

## 6. 保存校验要点

| 规则 | 场景 | 反馈 |
| :--- | :--- | :--- |
| R04a | 名称空或租户内重复 | 字段红字 / Toast |
| R01 | 设备无效 | Toast「保存/启用失败：设备{编码}不存在或已停用」 |
| R02 | 人员停用或角色无启用成员 | Toast「保存/启用失败：审批节点{序号}无效」 |
| R27 | 无节点或节点不完整 | Toast 节点配置不完整 |
| R03 | 设备冲突 | Toast「保存/启用失败：与配置{编号}存在设备冲突」 |
| R06 | 编辑变更不可变字段 | 服务端拒绝 |
| R07 | Version 冲突 | Toast「数据已被他人修改，请刷新重试」 |
| — | 未选设备；超时非正整数 | 字段红字 |

**保存成功**：Toast「保存成功」→ 返回列表页。
