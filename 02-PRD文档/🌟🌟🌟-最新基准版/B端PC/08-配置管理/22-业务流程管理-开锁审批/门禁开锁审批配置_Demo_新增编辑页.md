## 2. 页头操作栏

| 按钮 | 规格 |
| :--- | :--- |
| 返回 / 取消 | 次操作；有未保存变更时确认「放弃未保存的修改？」 |
| 保存 | **主操作**；新增/编辑均二次确认后提交；**不提供**状态下拉 |

### 2.1 保存二次确认

| 场景 | 确认文案 | 确认按钮 |
| :--- | :--- | :--- |
| 新增 | 保存后新申请将按本配置匹配，确认保存？ | **确认保存** |
| 编辑 | 修改将生成新版本，在途申请继续使用旧版本快照，确认保存？ | **确认保存** |

> 启停仅在列表/详情独立动作；表单内不可改状态。编辑保存成功后旧版本→已停用，新版本→已启用，配置版本 +1（C06）。

## 3. 新增态 vs 编辑态差异

| 对比项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 页头标题 | 新增开锁审批配置 | 编辑开锁审批配置 — {配置名称} |
| 配置名称 | 空，可填 | 预填，**Readonly**（R06） |
| 适用范围类型及范围字段 | 可选，按类型联动 | 预填，**Readonly**（R06）；调范围须停用旧配置并新增 |
| 未绑定位置设备全局审批开关 | 类型=未绑定位置全局时可配 | 可改（保存生成新版本） |
| 审批方式 / 审批节点 / 审批超时 | 空或默认 1 个空节点 | 读当前，可改 |
| Version | 不展示 | **不展示**；随表单隐藏字段提交（R07） |
| 配置编号 / 配置版本 / 状态 | 不展示 | 不展示 |
| 保存后 | 已启用，配置版本=1 | 新版本已启用，旧版本已停用，配置版本+1 |
| 已停用配置 | — | **不可进入编辑**（动作矩阵） |

## 4. 基础识别与范围卡片

卡片标题：**基础识别与范围**。上方 2 列栅格放「配置名称 / 适用范围类型」；下方按类型展示 **范围选择面板**（`ScopeCascadeSelector`）或全局开关区。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 配置名称 | `Input` | 是 | ≤50 字，租户内唯一（R04a）；编辑 Readonly；可带 `?` |
| 适用范围类型 | `Select` + `?` | 是 | 仓库 / 库房 / 分区 / 指定设备 / 未绑定位置全局；编辑 Readonly；变更联动范围面板 |
| **范围选择面板** | `ScopeCascadeSelector` | 条件 | 见 §4.1；仓库/库房/分区/指定设备时展示；编辑 Readonly |
| 适用设备 | 摘要 + `[勾选/调整设备 >]` 按钮 | 条件 | 仅「指定设备」；点击打开 `UnlockDeviceSelectDialog`；编辑 Readonly |
| 未绑定位置设备全局审批开关 | `RadioGroup` + `?` | 条件 | 仅「未绑定位置全局」；开启 / 关闭（C04、R29） |

### 4.1 范围选择面板（ScopeCascadeSelector）

> **组件路径**：`components/ScopeCascadeSelector.tsx`  
> **交互原则**：仓库 → 库房 → 分区 **级联**；库房/分区支持 **Tag 多选**；切换仓库清空下级已选。

| 子区域 | 控件 | 规格 |
| :--- | :--- | :--- |
| 路径摘要 | Badge 行 | 顶部展示「范围选择 / {仓库} / {库房…} / {分区…}」 |
| 适用仓库 | `Select` 单选 | 须先选；切换时清空库房、分区、已选设备 |
| 适用库房 | Tag 多选按钮组 | 库房/分区/指定设备类型展示；选项来自已选仓库；至少选 1（库房类型） |
| 适用分区 | Tag 多选按钮组 | 分区/指定设备类型展示；选项来自已选库房；至少选 1（分区类型） |

**未选仓库时**：库房/分区区展示「请先选择适用仓库」。

### 4.2 设备选择弹窗（UnlockDeviceSelectDialog）

> **触发**：指定设备类型下点击 `[勾选/调整设备 >]`  
> **组件路径**：`components/UnlockDeviceSelectDialog.tsx`

| 能力 | 规格 |
| :--- | :--- |
| 仓库筛选 | 顶栏 `Select`：全部仓库 / 各在管仓库；默认带入范围面板已选仓库 |
| 关键字搜索 | `Input` + 搜索图标：匹配设备名称、编码、绑定位置 |
| 列表 | 复选框列表；展示名称、编码 Badge、仓库·位置 |
| 批量 | 「全选当前结果 / 取消全选当前结果」 |
| 确认 | 「确认选择（N 台）」；取消不保存 |

> **不在表单页内嵌长列表勾选**，避免操作路径过长。

### 4.3 动态表单场景

| 场景 | 适用范围类型 | 范围选择面板 | 设备弹窗 | 全局开关 |
| :--- | :--- | :--- | :--- | :--- |
| A 仓库 | 仓库 | *适用仓库（单选） | 隐藏 | 隐藏 |
| B 库房 | 库房 | *适用仓库 + *适用库房（Tag 多选） | 隐藏 | 隐藏 |
| C 分区 | 分区 | *适用仓库 + *适用库房 + *适用分区（Tag 多选） | 隐藏 | 隐藏 |
| D 指定设备 | 指定设备 | *适用仓库（可选上下文）+ 库房/分区（可选收窄） | **展示**摘要 + 按钮 | 隐藏 |
| E 未绑定位置全局 | 未绑定位置全局 | **隐藏** | 隐藏 | **展示** Radio + `?` |

**场景 E 辅助说明**（`FieldHelpTooltip` 或字段下灰字）：

- 关闭：未绑定具体位置设备走原有免审直发密码
- 开启：进入本配置的全局审批；不得静默免审（C04）
- 租户内该类型仅允许 1 条已启用配置（R29）

## 5. 审批策略卡片

卡片标题：**审批策略**。

| 字段 | 控件类型 | 必填 | 详细规格 |
| :--- | :--- | :---: | :--- |
| 审批方式 | `RadioGroup` | 是 | 任一人通过 / 按顺序审批；按顺序时节点顺序即审批链 |
| 审批节点 | 可编辑表格 + 拖拽 | 是 | 至少 1 个；见 §5.1 |
| 审批超时时间 | `TimeoutHoursInput` | 是 | 正整数；**「小时」内嵌于输入框右侧**（带左边框分隔），非独立外挂文案 |

### 5.1 审批节点子表

表格列：

| 列 | 控件 | 规格 |
| :--- | :--- | :--- |
| ≡ 拖拽 | 拖拽手柄 | 调整节点序号；按顺序审批时决定激活顺序 |
| 节点序号 | 只读文本 | 从 1 递增，拖拽后重算 |
| 审批对象类型 | `Select` | 指定人员 / 指定角色；切换时清空对象 |
| 审批对象 | `SelectWithSearch` | 类型=人员：启用账号单选，展示姓名；类型=角色：启用角色单选 |
| 操作 | 删除 | 至少保留 1 行 |

底部：`[ + 添加审批节点 ]`

**校验（R27）**：同一节点不可混选人员与角色；不同节点可分别配置。

## 6. 保存校验要点

| 规则 | 场景 | 反馈 |
| :--- | :--- | :--- |
| R04a | 名称空或租户内重复 | 字段红字 / Toast |
| R01 | 仓库/库房/分区/设备无效 | Toast「保存/启用失败：{位置}不存在或已停用」 |
| R02 | 人员停用或角色无启用成员 | Toast「保存/启用失败：审批节点{序号}无效」 |
| R27 | 无节点或节点不完整 | Toast 节点配置不完整 |
| R03 | 同级范围冲突 | Toast「保存/启用失败：与配置{编号}存在范围冲突」 |
| R29 | 全局类型第二条已启用 | Toast 阻断 |
| R06 | 编辑变更不可变字段 | 服务端拒绝 |
| R07 | Version 冲突 | Toast「数据已被他人修改，请刷新重试」 |
| — | 审批方式未选；超时非正整数 | 字段红字 |

**保存成功**：Toast「保存成功」→ 返回列表页。
