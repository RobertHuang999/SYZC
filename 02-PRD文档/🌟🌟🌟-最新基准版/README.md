## 一、双端目录结构

与 `03-前端原型demo/`（`B端PC`、`B端H5`）及 `08-系统采集/` 采集口径对齐：

```text
🌟🌟🌟-最新基准版/
├── README.md                 # 本文件
├── 00-功能与数据权限/        # 全平台功能按钮 + 数据权限基准清单（CSV）
├── B端PC/
│   ├── 00-菜单地图.md        # PC 导航唯一定义来源
│   ├── 01-工作中心/ … 08-配置管理/   # PC 模块 PRD 基准
│   └── 样式规范- PC端/
└── B端H5/
    ├── README.md
    ├── 00-菜单地图.md / 01-功能清单与原型路由.md   # H5 导航索引
    ├── 01-首页/ … 03-业务办理/ / 04-机构权限/       # 与 H5 原型板块分类对齐（占位待回写）
    └── 样式规范- H5端/
```

| 目录 | 对应产品 | 菜单唯一定义来源 |
| :--- | :--- | :--- |
| **[00-功能与数据权限](./00-功能与数据权限/README.md)** | PC + H5 全端 | [功能与数据权限清单.csv](./00-功能与数据权限/功能与数据权限清单.csv) · [菜单模块映射](./00-功能与数据权限/00-菜单模块映射.md) |
| **[B端PC](./B端PC/00-菜单地图.md)** | PC 机构后台 | [B端PC/00-菜单地图.md](./B端PC/00-菜单地图.md) · [08-系统采集](../../08-系统采集/01-系统菜单与页面地图.md) |
| **[B端H5](./B端H5/README.md)** | 移动机构 App | [B端H5/00-菜单地图.md](./B端H5/00-菜单地图.md) · [01-功能清单与原型路由.md](./B端H5/01-功能清单与原型路由.md) |

**原则**

1. **业务规则唯一定义来源 尽量端无关**：状态机、字段语义、权限口径一份；仅**菜单路径、页面布局、ASCII/Demo**按端拆分。
2. **6.2 迭代文档**引用本目录菜单地图写端差异入口，不把迭代版本再套一层 B端PC/H5。
3. **H5 按原型板块分类**：`B端H5/` 目录树与 `mobileMenuData.ts`（首页/工作台/业务办理）对齐，**不是** PC 目录镜像；占位待回写 H5 端差异。导航见 `B端H5/00-菜单地图.md`、`01-功能清单与原型路由.md`。
