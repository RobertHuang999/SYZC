## 二、双端数据穿透机制

客户在 C 端移动端完成的注册流水、个人认证快照与企业认证凭证，自动作为源头数据落账至 B 端管理中台：
* **注册流水**：自动生成 B 端客户账号档案（状态：未认证）；
* **个人认证成功**：B 端更新 `个人认证 = 已认证`，记录认证时间戳与身份证、姓名脱敏快照；
* **企业认证成功**：B 端更新 `企业认证 = 已认证`，记录认证时间戳、企业全称、统一社会信用代码、法人信息及营业执照不可变影像凭证。
