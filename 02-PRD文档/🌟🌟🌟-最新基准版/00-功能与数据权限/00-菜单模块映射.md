
## 四、角色按钮矩阵（2026-11-10 TSV）与权限清单的关系

> **角色级真源**：`00-草稿对话/2026.11.10-系统菜单角色权限矩阵_按钮分格版.tsv`（231 行，含平台运营方、仓储服务方、监管服务方、资金服务方四类角色的按钮）。

| 文档 | 承担什么 | 不承担什么 |
| :--- | :--- | :--- |
| **TSV 角色按钮矩阵** | 每个页面对四类角色分别开放哪些按钮；业务规则与权责说明 | 菜单模块编码、基准文档路径、记录状态 |
| **[功能与数据权限清单.csv](./功能与数据权限清单.csv)** | 页面级权限主表：模块、菜单路径、按钮并集、**四类角色按钮列**、数据范围、记录状态与基准目录 | 角色之外的细粒度字段权限（后续接口规格承担） |
| **本文件** | 模块与目录映射、角色列使用说明 | 逐页按钮明细 |
| **[页面-基准文档映射.csv](./页面-基准文档映射.csv)** | 每个页面对应的基准三件套路径 | 权限口径 |

**使用顺序**：先看 TSV 确认某角色能点什么 → 再看权限清单确认该页属于哪个模块、是否上线（记录状态）→ 最后按页面映射打开三件套。

**口径说明**：

1. 权限清单的四列角色按钮由 TSV 合并而来；`—` 表示该角色无按钮；
2. 同一页面 TSV 有多行（如监管档案九个 Tab、监管委托受理三类任务）时，按钮合并到对应页面行；
3. TSV 中「页面访问」统一记为「查看页面」；
4. TSV 含 **C端门户（19 行）与 SAAS 运营端（4 行）**，已并入权限清单，模块编号 **12/13/14**，映射见本章第五节；
5. TSV 与原型不一致的 H5 页面（合同签署两页、风险公示、发起签署）在清单中标记为 `planned`，原型补齐后转 `active`。

## 六、记录状态口径

| 记录状态 | 判定规则（变更说明字段） | 原型页展示 |
| :--- | :--- | :--- |
| `active` | 默认；线上可用或基准已定义 | 主列表 |
| `6.2-target` | CSV `记录状态=6.2-target` | 主列表（标识 `6.2目标`）及「6.2目标菜单」聚合弹窗；上线后提升为 active |
| `planned` | 含「计划中」 | 「待开发规划」弹窗 |
| `cancelled` | 含「版本取消」或「取消.*菜单」 | 「已取消菜单」弹窗 |
