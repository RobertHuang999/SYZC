>

## 一、与菜单地图的关系

| 端 | 菜单唯一定义来源 | 权限清单字段 |
| :--- | :--- | :--- |
| **B端PC** | [B端PC/00-菜单地图.md](../B端PC/00-菜单地图.md) | `所属模块` → 顶栏模块；`一级菜单` → 侧栏/卡片域；`二级菜单` / `Tab` → 页面 |
| **B端H5** | [B端H5/00-菜单地图.md](../B端H5/00-菜单地图.md) | `所属模块` → 底栏 Tab；`一级菜单` → 宫格板块；`二级菜单` → 功能页 |

**页面路径拼装规则**（与 PC 原型「功能与数据权限」页一致）：

```text
{顶栏/底栏模块名} / {一级菜单} / {二级菜单} / {Tab}
```

空段与 `-` 省略；Tab 为 `-` 时表示该二级菜单无 Tab 拆分。

## 四、记录状态口径

| 记录状态 | 判定规则（变更说明字段） | 原型页展示 |
| :--- | :--- | :--- |
| `active` | 默认；线上可用或基准已定义 | 主列表 |
| `6.2-target` | CSV `记录状态=6.2-target` | 主列表（标识 `6.2目标`）及「6.2目标菜单」聚合弹窗；上线后提升为 active |
| `planned` | 含「计划中」 | 「待开发规划」弹窗 |
| `cancelled` | 含「版本取消」或「取消.*菜单」 | 「已取消菜单」弹窗 |
