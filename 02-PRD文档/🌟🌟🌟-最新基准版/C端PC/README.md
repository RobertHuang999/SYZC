# SYZC 客户端 PC 端（C端PC）· 文档索引

> **版本**：V1.0 | **创建日期**：2026-09-22 | **责任人**：森云科技（Senyun Technology）
> 
> **定位**：面向外部客户、货主及借款企业的 Web 门户端（货主服务平台），承接线上现货交易、仓单确权、融资申请及企业/个人实名认证查询等服务。

---

## 一、目录规划

```text
C端PC/
├── README.md                 # 本索引文档
├── 01-用户中心/              # 账号注册、登录、实名认证（个人二元/实人核验、企业四要素/OCR）
├── 02-资产大盘/              # 存货查看、仓单查询、出入库记录
└── 03-交易撮合/              # 销售意向发布、采购需求发布、合同线上签署
```

---

## 二、与各端联动关系

1. **与 B端PC 联动**：客户在 C 端注册与认证生成的基础档案与资质证明，实时同步并呈现于 B端PC【交易 → 客户管理】（`P-JY-003`）进行集中监控与风控台账管理；
2. **与 C端H5 联动**：C 端移动端（H5/小程序）与 PC 端统一使用底层用户与认证中台，账号互通、认证资质与状态强一致。
