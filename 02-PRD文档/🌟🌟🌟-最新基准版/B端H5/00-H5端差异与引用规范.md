# B端H5 · 端差异与引用规范

> **版本**：V1.0 | **更新日期**：2026-11-11 | **责任人**：森云科技（Senyun Technology）
>
> **定位**：统一规定 B 端 H5 页面如何引用 PC 基准三件套、哪些内容必须在 H5 单独写。解决「H5 复制一套 PRD 导致双轨维护」的问题。
>
> **上位规则**：[AGENTS.md 4.0](../../../AGENTS.md) 三件套 SSOT、**4.2.1** 双端标注对齐；[原型双端标注对齐说明](../../../03-前端原型demo/原型双端标注对齐说明.md)。

---

## 一、总原则（说人话）

1. **业务正文只有一份，放在 PC**：字段定义、状态机、业务规则、权限口径都以 PC 三件套为准，H5 不另写一套。
2. **H5 只写「端差异」**：入口位置、页面骨架、控件形态、交互手势、底栏与导航、哪些能力 H5 不做。
3. **引用要能点开**：每个 H5 页面的 README 至少挂一条 PC 真源链接；联调时按链接直接查规格。
4. **不反向改 PC**：H5 发现 PC 规格缺口时，先回写 PC 三件套，再更新 H5 端差异。

---

## 二、H5 通用端差异规则

| 维度 | PC 口径 | H5 口径 |
| :--- | :--- | :--- |
| 壳层 | 顶栏模块 + 左侧栏 + 多页签 | 四个底栏 Tab（首页 / 工作台 / 业务办理 / 我的），无侧栏；页面用 `NavBar` 44px，四个主 Tab 页不显示返回 |
| 列表 | 筛选区默认 4 项 + 展开；表格行高 72px | 卡片流；筛选收进底部抽屉；顶部保留搜索；分页改为上拉加载 |
| 详情 | 子板块分区、标签页 | 纵向卡片分区；标签页改顶部横向滑动 |
| 新增/编辑 | 单页表单或配置卡片 | 分步表单 + 步骤条；提交按钮固定在底部，带安全区 |
| 批量操作 | 支持复选与批量按钮 | 默认不提供批量，逐条处理；确需批量的单列说明 |
| 导出 | 同步/异步导出、导出记录 | 仅保留必要下载；组合导出、PDF 单据、Excel 明细默认不在 H5 提供 |
| 权限 | 菜单 + 按钮 + 数据权限 | 与 PC 完全一致，不因端不同放宽 |
| 标注 | 琥珀色迭代打点 | 同一 id 同序号，只加【H5 端差异】后缀 |

## 四、写 H5 文档时的最少要求

1. 文头写清：菜单路径、moduleId、原型路由、**PC 真源链接**；
2. 正文只写【H5 端差异】五条以内，不重复 PC 规则；
3. 涉及规则时写全名称与编号，例如「【装卸货位变更记录】(R12)」，不单抛代号；
4. 同一菜单双端标注使用同一 annotation id 与序号，H5 只加 `contentSuffix`；
5. 页面未实现时保留占位 README，但 PC 真源链接必须先挂上。
