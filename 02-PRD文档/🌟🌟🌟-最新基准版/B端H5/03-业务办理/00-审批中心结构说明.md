## 四、业务发起（H5 聚合入口说明）

PC 端无独立的「业务发起」审批卡片，其入口分散于各业务主流程中；H5 端移动办公场景将高频新建/申报聚合为 **9 项** 快捷业务发起：

| 序号 | H5 业务发起项 | 对应 PC 菜单路径 | H5 目录 |
| :---: | :--- | :--- | :--- |
| 01 | 入库发起 | 仓储 → 入库管理 → 入库 | [01-入库发起/](./02-业务发起/01-入库发起/README.md) |
| 02 | 出库发起 | 仓储 → 出库管理 → 出库 | [02-出库发起/](./02-业务发起/02-出库发起/README.md) |
| 03 | 移库发起 | 仓储 → 移库管理 → 移库 | [03-移库发起/](./02-业务发起/03-移库发起/README.md) |
| 04 | 货物转让 | 仓储 → 货物转让 → 转让 | [04-货物转让/](./02-业务发起/04-货物转让/README.md) |
| 05 | 仓单开立 | 仓储 → 仓单管理 → 仓单开立 | [05-仓单开立/](./02-业务发起/05-仓单开立/README.md) |
| 06 | 抵质押业务办理 | 融资/监管 → 抵质押业务 → 发起 | [06-抵质押业务办理/](./02-业务发起/06-抵质押业务办理/README.md) |
| 07 | 异动申请 | 仓储 → 存货异动 → 申请 | [07-异动申请/](./02-业务发起/07-异动申请/README.md) |
| 08 | 盘点发起 | 仓储 → 货物盘点 → 新增盘点 | [08-盘点发起/](./02-业务发起/08-盘点发起/README.md) |
| 09 | 加工发起 | 仓储 → 加工管理 → 加工申请 | [09-加工发起/](./02-业务发起/09-加工发起/README.md) |
