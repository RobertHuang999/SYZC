## 一、功能说明

规范存货在移动端（App/PDA）发起的加工申请（切割、拆分、熔炼、组装等）。支持现场监管员/业务员选择货主主体与加工类型，从在库可用库存中勾选投入物料，配置预计产出规格与数量，现场抓拍/拍照上传实证，提交后系统即时锁定计划投入库存并生成审批流。

---

## 二、移动端核心交互与界面要求

| 步骤/区块 | 核心字段与操作 | 移动端交互要求与校验 |
| :--- | :--- | :--- |
| **1. 基础信息** | 加工日期、货主、加工类型、关联单号、仓库 | ① 加工日期默认当前时间，禁止选择未来时间；<br/>② 货主变更时联动清空已选投入货物与单据；<br/>③ 加工类型选“抵押货/质押货”时，需选择有效抵质押单，系统自动过滤仓单货物。 |
| **2. 投入货物明细** | 货品名称、规格、批次/条码、单位、实时可用量、计划投入量 | ① 底部弹出抽屉/列表选择在库可用库存；<br/>② 强校验“三同”（同货主、同仓库、同加工类型）；<br/>③ 录入计划投入量，校验 $0 < \text{计划量} \le \text{可用量}$；支持条码扫码快捷定位物料。 |
| **3. 产出货物明细** | 产出大类、品类、规格名称、预计产出数量、单位 | ① 级联选择产出规格；<br/>② 录入预计产出数量（$>0$）；<br/>③ 阻断同 SKU 同数量的无效加工申请；<br/>④ 自动试算预计产出总金额（缺价提示「存在未定价货物」）。 |
| **4. 现场实证与抓拍** | 现场照片、IoT设备抓拍图 | ① 支持调用手机/PDA摄像头现场拍照或上传相册图片；<br/>② 联动库区监控抓拍（抓拍失败记录日志，不阻断提交）。 |
| **5. 提交申请** | 底部固定【提交加工申请】按钮 | ① 点击二次确认；<br/>② 提交成功原子锁定计划投入库存，生成 19 位加工单号（`PRO` 开头），进入审批流；<br/>③ 成功后 Toast 提示并跳转至 [我的申请记录](../../01-内部审批/04-我的申请记录/) 或 [加工管理记录](../../../02-工作台/01-仓储/10-加工管理/)。 |

## 三、权限与风控约束

- **操作权限**：仅具备管辖仓库权限的仓库监管员或业务操作员可发起；
- **防重复质押/抽逃**：抵质押货物加工申请提交后即时打上“加工锁定”标记，严禁在审批期间被出库、移库或重复质押。
