## 功能说明

移动端 **手工入库制单** 入口：两步填写货主与入库信息、货品多库位堆放、现场拍照后提交审批。与 **入库管理**（`ws-inbound-mgr`，已通过台账）为 **独立菜单**，不在台账列表提供悬浮制单。  
**6.3**：支持 `?sourceRegId=REG-...` 由 [入库暂存登记](../../../../../B-迭代需求/6.3版本（2026.09）/09-仓储管理-入库暂存登记/) 转正预填（H5 **P10**；仓单暂存 PC 转正须跳转本入口）。
