## 【H5 端差异】

1. **入口**：业务办理 → 内部审批区块，3×2 卡片之一，图标 `FileSignature`，右上角展示待办角标；
2. **列表**：按三类任务分组（抵押 / 质押 / 监管服务信息确认），卡片展示客户名称、订单号、任务状态、发起时间；
3. **处理**：点击【去处理】进入任务详情，按 PC 同一套确认逻辑处理；H5 不提供批量处理；
4. **数据权限**：按任务数据权限过滤，只看分配给自己或本机构的任务；
5. **角标**：与底栏「业务办理」角标共用服务端待办字段，联调后替换 Mock。
