## 功能说明

本人发起的流程申请及 **6.2 开锁申请**，按类型拆分为**三个独立 Tab**，与 PC「我的申请管理」对齐（**非**混合列表 + 业务类型筛选）。

| Tab（H5） | 对应 PC Tab | `tab` 参数 | 说明 |
| :--- | :--- | :--- | :--- |
| 流程申请 | 我的流程申请 | `process` | 沿用线上流程卡片 |
| 政策资讯 | 我的政策资讯申请 | `policy` | 占位「功能开发中」 |
| **开锁审核** | 我的开锁申请 | `unlock-applies` | 开锁卡片；设备/凭证/事由摘要；含需审批与免审 |

| 能力 | 说明 |
| :--- | :--- |
| URL 同步 | Tab 切换写入 `?tab=`；返回详情保留 Tab 与筛选（sessionStorage） |
| 与审批人侧区分 | 「其他审批 → 开锁审批」为**审批人**入口，见 [02-开锁审批](../../04-其他审批/02-开锁审批/README.md) |
| Deep link | `ROUTE-IOT-APPR-01`：默认 Tab=开锁审核 + 打开 `apply_no` 详情 |
| 详情口径 | **不含**「关联事务」分区（W00）；凭证查看/短信重发见 04-开锁审批 Demo |
