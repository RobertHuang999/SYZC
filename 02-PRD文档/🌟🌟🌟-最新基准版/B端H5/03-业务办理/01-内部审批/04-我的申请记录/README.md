## 功能说明

本人发起的流程申请（入库、出库、移库、仓单、抵质押等）及 **6.2 新增开锁申请** 的统一列表。

| 能力 | 说明 |
| :--- | :--- |
| 流程申请 | 沿用线上；筛选左栏既有大类 |
| 开锁申请 | 筛选左栏「开锁审核」；卡片摘要含设备、仓库、凭证状态 |
| 与审批人侧区分 | 「其他审批 → 开锁审批」为审批人入口，见 [07/05/03-开锁审核](../../../../B-迭代需求/6.2版本（2026.08）/07-审批中心/05-其他审批/03-开锁审核/开锁审核主PRD.md) |
