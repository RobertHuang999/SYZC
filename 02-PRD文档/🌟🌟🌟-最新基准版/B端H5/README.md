## 一、目录与原型对齐

```text
B端H5/
├── 00-菜单地图.md / 01-功能清单与原型路由.md   ← H5 导航与路由索引
├── 01-首页/          ← primaryModule = 首页
├── 02-工作台/        ← primaryModule = 工作台（仓储/融资监管/交易/风控/结算/配置）
├── 03-业务办理/      ← primaryModule = 业务办理（内部审批/发起/客户需求/其他审批）
├── 04-机构权限/      ← 底栏 Tab /m/profile
└── 样式规范- H5端/
```

| 规则 | 说明 |
| :--- | :--- |
| **结构唯一定义来源** | `03-前端原型demo/B端H5/src/data/mobileMenuData.ts` |
| **一级目录** | 底栏 Tab：首页 / 工作台 / 业务办理 / 机构权限 |
| **二级目录** | `secondaryCategory`（如仓储、融资监管、其他审批） |
| **功能目录** | `{序号}-{菜单名}`，与 B端PC 一致；`设备管理` 等多 Tab 项为 `{序号}-设备管理-{子Tab}` |
| **占位态** | 各功能 `README.md` 含 moduleId、原型路由、PC 原路径 |
| **业务规则** | 端无关规则引用 [B端PC/](../B端PC/) 或 6.2 迭代；H5 只写布局/交互差异 |
| **回写** | 6.2 定稿后写入**本树对应路径**，不另起平行目录 |
