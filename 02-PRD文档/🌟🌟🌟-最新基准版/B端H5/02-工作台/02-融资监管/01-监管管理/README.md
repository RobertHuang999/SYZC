> **原型路由**：`/m/module/ws-pledge-order-mgr`
> **文档状态**：6.3 端差异版 — 页面骨架与规则引用 PC 监管管理三件套
> **PC 业务真源**：[07-监管业务-监管管理](../../../../B端PC/04-融资监管/07-监管业务-监管管理/监管管理主PRD.md)

## 一、页面结构（一个入口，三个 Tab）

| Tab | 展示内容 | 说明 |
| :--- | :--- | :--- |
| **抵押单** | 抵押类监管订单列表与卡片 | 与 PC 监管管理「抵押订单」Tab 同源 |
| **质押单** | 质押类监管订单列表与卡片 | 与 PC「质押订单」Tab 同源 |
| **监管服务单** | 监管服务类订单列表与卡片 | 与 PC「监管服务」Tab 同源；原独立「监管订单」菜单已并入此处 |

- 顶部为横向滑动 Tab，默认落在第一个有权限的 Tab；
- 列表为卡片流：订单号、货主、仓库、在押数量、监管业务率、状态、起止时间；
- 筛选收进「筛选」底部抽屉：订单号、货主、仓库、状态、时间范围；
- 行操作按状态展示：详情、操作记录、资料管理、置换、加/补仓、解抵押、估值、盘点、盘点报告、移库、监控、平仓、风险、设备、结果录入、监管报告、部分结清、安全线、异动、入库、日常监管、风险公示、加工等（具体按 PC 权限与状态置灰规则）。

## 二、【H5 端差异】

1. **入口**：工作台「融资/监管」分组下只有一个「监管管理」磁贴，不再有独立「抵质押订单」「监管订单」两个入口；
2. **Tab**：PC 为页内三 Tab，H5 改为顶部横向滑动标签条，顺序固定「抵押单 → 质押单 → 监管服务单」；
3. **列表/详情**：PC 表格改为卡片流；详情纵向分区，操作收进底部「更多」；
4. **选货与办理**：复杂选货、批量操作以 PC 为主；H5 只保留单笔办理与查看；
5. **权限**：三 Tab 数据权限与 PC 一致，按订单数据权限过滤；旧 `ws-supervision-order-mgr` 深链只读并重定向到本页「监管服务单」Tab。

## 三、历史兼容

原 H5 独立「监管订单」菜单（`ws-supervision-order-mgr`）已关闭并合并到本页「监管服务单」Tab；历史数据仅按权限只读查询、审计和资料查看，不允许新建或写操作。

> 字段、状态机与操作规则以 [PC 监管管理三件套](../../../../B端PC/04-融资监管/07-监管业务-监管管理/监管管理主PRD.md) 为准，H5 不单独定义。
