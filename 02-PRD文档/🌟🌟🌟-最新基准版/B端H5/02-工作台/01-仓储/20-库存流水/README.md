## 【H5 端差异】

1. **入口**：工作台「仓储」分组新增磁贴，顺序按 `WORKSPACE_ITEM_ORDER` 固定；
2. **列表**：卡片流展示业务单号、业务时间、业务类型、货主、数量、仓库；顶部保留「合计：入库 / 出库」汇总条；
3. **筛选**：收进「筛选」底部抽屉，支持业务日期、业务类型、仓库、货主；
4. **详情**：点击卡片新页打开对应入库/出库详情；H5 不提供 PDF 单据下载与微观垛位 Excel 下载；
5. **批量导出**：6.3 仅 PC 提供，H5 不展示。
