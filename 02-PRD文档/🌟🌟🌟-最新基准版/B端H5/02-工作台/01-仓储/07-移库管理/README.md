## 功能说明

管理库区内的货位变更作业。通过事前授权与轨迹监控防范“调包/偷换”风险，移位完成后实时更新空间坐标及质押绑定状态。

### 双端与架构约定
1. **工作台·移库管理（台账）**：只提供移库单流水记录查询、多维筛选（状态/仓库/类型）与详情下钻，严格不在列表页放巨型发起按钮。
2. **业务办理·移库发起（作业）**：统一从移动端底部 Tab「业务办理 → 业务发起 → 移库发起」进入，对齐现网两步作业流程（Step 1 基础信息与单据关联 ➔ Step 2 货品明细与目标货位分配，路由为 `/m/transfer/initiate` 与 `/m/transfer/initiate/goods`）。
3. **真实 Mock 支撑**：贴近大宗商品（电解铜、热卷、铝锭）真实业务场景，数据模型与 PC 端完全同构对齐。
