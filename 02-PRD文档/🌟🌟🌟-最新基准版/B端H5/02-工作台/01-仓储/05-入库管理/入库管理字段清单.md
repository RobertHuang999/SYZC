## 一、入库管理 — 列表卡片（对齐现网 store-record）

| 字段名称 | 控件 | 说明 |
| :--- | :--- | :--- |
| 入库单号 | 文本 | 卡片内展示 |
| 货主名称 / 货主标识 | 文本 | 同行或双行，标识脱敏 |
| 入库类型 | 文本 | 12 类字典展示名 |
| 仓库名称 | 文本 | |
| 入库货品摘要 | 文本 | 首规格 +「等 N 种」（R15 / P09） |
| 入库货品清单 | 文本数组 | 与 PC `goodsNames` 一致；多货品 Sheet 展示 |
| 入库日期 | 文本 | |
| 入库数量 | 文本 | |
| 制单人 / 制单时间 | 文本 | 卡片底部 |
| 未打印二维码标识 | 图标 | 可选警示，配合「仅查看未打印二维码订单」筛选 |

**列表不含**：入库单状态 Badge、审核状态下拉（台账仅已通过）。

**筛选**：货主名称/标识搜索；左侧漏斗打开 **入库日期范围、制单时间范围**（对齐现网 `outbound-filter-modal`）；**货物**为 **大类-品类-规格三级联选**（对齐现网 `cascade-three-select`）；仓库、入库类型、制单人为下拉框；`unPrintFlag` 未打印二维码开关。

**行操作**：【下载记录】【单据】【查看详情】。

## 二、入库发起 — 基础信息与货品（R04f）

| 字段名称 | H5 控件 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| 货主类型 | 双按钮 | 是 | 企业 / 个人 |
| 货主名称 | 输入 + 候选 | 是 | 企业可 OCR Mock |
| 入库类型 | 下拉 | 是 | 普通、质押、抵押、仓单、监管服务入库 |
| 关联单号 | 选择 | 条件 | 非普通必填 |
| 入库库房 | 多选 | 是 | R06 |
| 现场照片 / 补充资料 | 上传 | 照片必填 | R16/R17 |

### 2.1 货品明细卡片（步骤 2）

| 字段名称 | H5 控件 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| 入库货品 | 单行 + 底部三列级联 Sheet | 是 | P08；展示「大类 · 品类 · 规格」摘要；数据源同 PC R11 |
| 计量数量 | 数字输入 | 是 | 标签随 SKU（如重量）；未选 SKU 时禁用 |
| 计量单位 | 只读灰底块 | 是 | R11b；随 SKU 带出，不可下拉切换 |
| 其他收集信息 | 动态表单项 | 选填 | SKU 绑定的入库收集项 |
| 堆放位置 | 多行：库房/分区/位置/数量 | 条件 | R12、R13、R14 |
| 现场照片 / 补充资料 | 纵向上传区 | 照片必填 | R16/R17 |

其余库位枚举、汇总底栏字段同 PC 新增页字段清单第二节、第三节。

## 三、入库管理 — 详情（仅已通过）

| 字段名称 | 展示 | 说明 |
| :--- | :--- | :--- |
| 入库单状态 | 状态章 | **仅已通过** |
| 入库货品 | 卡片标题/明细行 | 大类 · 品类 · 规格（与发起 P08 一致） |
| 计量数量 | 明细行 | 标签随 SKU（如重量）；数值 + 单位空格展示（R11b） |
| 其他收集信息 | 明细行 | 发起页 collectValues 快照 |
| 备注信息 | 明细行 | **货品行**备注，非单据头备注 |
| 堆放位置 | 嵌套卡片 | 库房-分区-位置 + 堆放数量（带单位） |
| 现场照片 | 货品行展开区 | R16；缩略图点击全屏相册；与 PC 附件弹窗第一分区同源 |
| 补充资料 | 货品行展开区 | R17；凭据图片缩略图 + PDF 行【预览】；与 PC 弹窗第二分区同源 |
| 设备抓拍图 | 货品行展开区 | R18；列表展示 `iotCaptures`（设备名、时间、缩略图）；空态「抓图失败或无监控设备接入」 |
| 审核记录 | Tab | 历史审批节点只读 |
| 入库信息修改记录 | Tab 或空态 | 无数据时说明 |

**不含**：撤销按钮、流程编辑。
