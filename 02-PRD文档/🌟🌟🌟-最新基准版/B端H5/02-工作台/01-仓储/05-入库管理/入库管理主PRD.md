# 入库管理主PRD（B端H5）

> **端**：B端H5（移动机构端）  
> **双入口（两个独立菜单，非同一页面）**：  
> - **入库管理** `ws-inbound-mgr`：工作台 → 仓储 → 入库管理 → **已通过入库归档台账**  
> - **入库发起** `biz-init-inbound`：业务办理 → 业务发起 → 入库发起 → **手工制单与提交审批**  
> **原型路由**：`/m/workspace/inbound-records` · `/m/workspace/inbound-records/:id` · `/m/inbound/initiate` · `/m/inbound/initiate/goods`  
> **PC 对照**：[B端PC 入库记录](../../../../B端PC/02-仓储/09-入库管理-入库记录/入库记录主PRD.md)（台账口径一致）；流程中单据对照 PC **入库申请**。  
> **编写依据**：[入库管理字段清单.md](./入库管理字段清单.md) · [入库管理业务规则规格.md](./入库管理业务规则规格.md)  
> **跨端规则真源**：R03、R04、R06、R11、R11b、R13、R16~R19、R26 等与 PC 入库记录共用编号；本文件定义 **H5 双入口页面与交互差异**（含 **P08** 级联选货）。

---

## 1. 业务背景与移动端定位

移动端 **入库发起** 承担现场收货、理货堆放与提交审批（对齐现网 `warehousing-order.vue` / `warehousing-details.vue`）。**入库管理** 与 PC「入库记录」同为 **仅已通过（`APPROVED`）** 的归档查询台账（对齐现网 `store-record.vue` 列表接口 `status: [2]`）；审批中、未通过、已撤销等 **流程中单据不在本菜单展示**，归属 PC/H5 **入库申请**、工作中心审批、我的申请等流程池。

## 3. 页面功能说明

### 3.1 入库管理列表（`P-H5-INBOUND-LIST`）

- **路径**：`/m/workspace/inbound-records`  
- **入口**：工作台 → 仓储 → 入库管理（`ws-inbound-mgr`）  
- **布局**（对齐现网 `store-record.vue`）：顶栏标题 + 货主名称/标识搜索；单行四筛（仓库、货物、入库类型、制单人）；「仅查看未打印二维码订单」开关；卡片列表。  
- **数据范围**：仓库数据权限；接口 **仅已通过** 单据（与 PC 入库记录 R26 一致）。列表 **不展示** 流程状态 Badge， **不提供** 审核状态下拉。  
- **行操作**：卡片内【下载记录】【单据】、进入详情；无列表编辑。

### 3.2 入库发起（`P-H5-INBOUND-INIT`）

- **路径**：`/m/inbound/initiate` → `/m/inbound/initiate/goods`  
- **入口**：**仅** 业务办理 → 业务发起 → 入库发起（`biz-init-inbound`）；与入库管理列表 **无** 悬浮制单按钮。  
- **步骤条**：① 基础信息 → ② 货品明细。  
- **基础信息**：货主信息 + 入库信息卡片；入库类型可选普通/质押/抵押/仓单/监管服务（R04f）；关联单号、仓库、库房（R06）、备注。  
- **暂存转正预填（6.3）**：URL 带 `sourceRegId=REG-...` 时（H5 暂存详情转正，或 PC 仓单暂存跳转）按登记快照预填步骤 ①/②，顶部展示来源登记单只读条与「查看暂存详情」链接；提交成功回写【已转正式】（**P10** / R32）。  
- **货品明细**：多货品卡片；**入库货品**单行唤起三列级联 Sheet（大类 / 品类 / SKU，P08，与 PC R11 同口径）；计量数量可填、**计量单位随 SKU 只读（R11b）**；入库收集项随 SKU；多库位堆放；现场照片（R16）、补充资料纵向排列；底栏汇总；提交审核触发 R13、R03。

### 3.3 入库管理详情（`P-H5-INBOUND-DETAIL`）

- **路径**：`/m/workspace/inbound-records/:id`  
- **数据前提**：均为 **已通过** 归档单据。  
- **布局**：单号 + **已通过** 状态章、基础信息、Tab【入库明细】【审核记录】【入库信息修改记录】；**各货品行**展开后纵向三块附件：**现场照片**（R16，缩略图 + 全屏相册）、**补充资料**（R17，凭据缩略图 + PDF 预览层）、**设备抓拍图**（R18，按该行 `iotCaptures` 展示设备名/时间/缩略图，空态「抓图失败或无监控设备接入」）；存货二维码入口与 PC 同口径。
- **与 PC 差异（仅壳层）**：PC 详情一级表【查看附件】集中弹窗；H5 在同货品行卡片内 inline 展示，**字段与 R16~R18 真源一致**，Mock 与 PC 共用 `shared/inbound/inbound-approved-seed.ts`。  
- **不提供** 撤销、驳回重提等流程操作（流程态在入库申请/审批中心处理）。

---

## 4. 状态与权限摘要

本菜单列表与详情 **仅已通过**；内部编码 `APPROVED` 与 PC 一致。撤销、审批、特权修改等见 PC 入库申请与工作中心规则，不在本 PRD 重复定义。

---

## 5. 验收要点

1. `ws-inbound-mgr` 与 `biz-init-inbound` 两入口路由与菜单可达且职责分离。  
2. 入库管理列表数据范围与 PC 入库记录一致（仅已通过）；筛选与「未打印二维码」与现网一致。  
3. 入库发起两步可走通；P08 级联选货与 R11b 单位只读与 PC 口径一致；R13/R03/R06 阻断有效。  
4. 入库管理详情各货品行展示现场照片/补充资料/设备抓拍（与 PC 附件弹窗三分区同口径），审核与修改记录 Tab 只读，无撤销按钮。  
5. 原型挂载本目录三件套；规则 ID 与 PC 入库记录规格一致。  
6. **6.3**：`sourceRegId` 暂存转正预填两步可走通；仓单暂存从 PC 跳转本页可提交；回写登记单【已转正式】。
