## 【H5 端差异】

1. **列表**：卡片流展示主体名称、类型、脱敏证件号、角色状态；顶部搜索框按姓名/证件号/手机号检索。
2. **新增**：右下角固定悬浮【+】进入新增页（需新建权限），表单与 PC 一致但分步展示；不提供「保存并验证」短信按钮，统一先存为「未验证」。
3. **详情**：只读档案卡 + 操作记录；【编辑】进入轻量编辑页。
4. **改址**：H5 不提供证件地址编辑与改址复合弹窗，提示「请到 PC 端合作方档案修改」。
5. **权限**：与 PC 四子菜单分别授权，H5 不共用目录权限。
