## 功能说明

一户一档全量档案库，聚合入库/出库/移库单据、仓单、抵押单、质押单、风险公示及资料存证。

## 【H5 端差异】

1. **入口**：工作台宫格「用户中心」分组下的「监管档案」磁贴，路由 `/m/module/ws-supervision-archive`；不再出现在「融资/监管」分组。
2. **视图切换**：PC 用页内九 Tab；H5 用顶部横向可滑动标签条，九视图顺序与 PC 一致，默认落在第一个有权限的视图。
3. **筛选**：H5 将四项筛选收进右上角「筛选」按钮打开的底部抽屉；主体选择用搜索页，选中后返回。
4. **列表与操作**：卡片式列表，每张卡展示主体关键字段 + 2~3 个主操作；全部行操作跳转下游详情，不做页内编辑。
5. **数据权限**：与 PC 完全一致，按仓库 / 订单权限过滤。

> 字段、规则本体一律引用 [PC 监管档案三件套](../../../../B端PC/02-用户中心/03-监管档案/监管档案主PRD.md)，H5 不单独定义。
