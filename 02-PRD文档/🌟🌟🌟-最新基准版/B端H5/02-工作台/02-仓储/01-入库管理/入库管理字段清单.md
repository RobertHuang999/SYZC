# 入库管理字段清单（B端H5）

> **文档定位**：移动端「入库管理列表 / 入库发起 / 入库详情」字段与控件规格；单据级、货品级、库位级定义与 [PC 入库记录字段清单](../../../../B端PC/02-仓储/09-入库管理-入库记录/入库记录字段清单.md) **同名字段同口径**，下文仅补充 **H5 展示与步骤** 差异。  
> **版本**：V1.0 | **更新时间**：2026-10-12

---

## 0. 页面与步骤映射

| 页面 | 步骤/区域 | 继承 PC 字段章节 |
| :--- | :--- | :--- |
| 入库发起 · 基础信息 | 货主信息卡片 | 单据级：货主类型、货主名称、货主标识、联系电话、货主身份证号 |
| 入库发起 · 基础信息 | 入库信息卡片 | 单据级：入库日期、入库类型、关联单号、入库仓库、入库库房、备注 |
| 入库发起 · 货品明细 | 合计 + 货物卡片 | 一级货品 + 二级堆放 + 现场照片、补充资料 |
| 入库发起 · 货品明细 | 底栏汇总 | 品类数、总数量、堆放数量（只读试算） |
| 入库管理列表 | 卡片 | 入库单号、货主名称/标识、入库类型、仓库、货物摘要、数量、**入库单状态（H5 展示）** |
| 入库详情 | 头部+Tab | 同 PC 详情概览 + 明细 + 审核记录；**设备抓拍图**在附件区 |

---

## 一、列表卡片字段（H5 专有展示）

| 字段名称 | 控件 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| 入库单状态 | 状态 Badge | 系统 | 审核中 / 已通过 / 未通过 / 已撤销；列表 **必展示**（与 PC 台账不同） |
| 货物摘要 | 文本 | 系统 | 首货品规格 +「等 N 种」 |
| 入库数量摘要 | 文本 | 系统 | 主计量单位汇总文案 |

其余筛选：审核状态下拉（全部 + 四态）；搜索框匹配单号、货主、仓库、货品关键字。

---

## 二、入库发起 — 步骤 1~2（与 PC 新增对齐）

| 字段名称 | H5 控件 | 必填 | 与 PC 差异 |
| :--- | :--- | :---: | :--- |
| 货主类型 | 双按钮宫格 | 是 | 文案「企业」「个人」，映射企业货主/个人货主 |
| 货主名称 | 单行输入 + 下拉候选 | 是 | 支持 OCR Mock（企业） |
| 入库日期 | 日期时间 | 是 | 默认当前，不可晚于当前时间 |
| 入库库房 | 多选标签 | 是 | 同 R06，混选审核/免审拦截 Toast |
| 备注 | 多行 | 否 | 最多 140 字，计数展示 |

入库类型、关联单号、仓库选项枚举与 PC `ManualInboundType` 及 10 类口径一致；仓单入库在 H5 可展示但提交时 Toast 引导至仓单作业（与 PC 提示一致）。

---

## 三、入库发起 — 步骤 3 货品卡片

| 字段名称 | H5 控件 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| 货品大类/品类/规格 | 三级 Select | 是 | 联动 R11 |
| 计量参数 | 数字 + 单位 Select | 是 | 未堆放数量标题行红色展示 |
| 入库库房/分区/具体位置/堆放数量 | 堆放行内 Select+输入 | 是 | 可多行【+ 添加位置】 |
| 现场照片 | 上传区 | 是 | 最多 10 张，jpg/png/jpeg |
| 补充资料 | 上传区 | 否 | 图片+PDF 合计最多 10 |

| :--- | :--- | :--- |
