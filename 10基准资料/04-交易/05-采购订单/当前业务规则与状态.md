# 采购订单｜当前业务规则与状态

- 来源：本次需求输入
- 当前状态：基准规则已提供；页面采集与系统菜单中尚未发现对应采购订单菜单

## 状态与动作

| 状态 | 可用动作 | 关键限制 |
| ---- | -------- | -------- |
| 草稿 | 编辑、删除、提交审核 | 供应商、仓库、明细、数量和单价满足要求后才能提交 |
| 待审核 | 审核通过、驳回、作废 | 审核通过后关键字段锁定 |
| 待入库 | 创建入库单、作废 | 允许多次入库，不支持直接关闭 |
| 部分入库 | 创建入库单、关闭订单 | 关闭后剩余数量不再接收 |
| 已完成 | 查看 | 终态 |
| 已作废 | 查看 | 终态，不可恢复 |

## 本次需求必须遵循的规则

- 一张采购订单至少有一行商品明细；采购数量必须大于 0，单价必须大于等于 0。
- 采购订单审核通过后，供应商、仓库、商品、采购数量、单价、税率均不可直接修改。
- 只有待入库、部分入库的订单可创建采购入库单；默认不支持超收。
- 批量导入只负责创建采购订单草稿，不改变既有审核、入库、作废和关闭状态流转。
- 导入入口仅对采购员、管理员展示；具体是否细分到组织或数据范围，待业务负责人确认。
